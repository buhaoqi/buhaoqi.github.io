逐题说明：

  • 第 1 题（最易失分）：按教材任务一的划分填"户外、垂直竖井、楼层平面、用户端、机房、布线配线"。若你们老师按 568A 标准叫法讲，则填"建筑物入口、设备间、干线、机架、水平布线、工作区"。两套答案指的是同一套系统，答题时任选一套、顺序对齐即可；如果考场允许，先写工程叫法再括注标准叫法最稳。
  • 第 2 题（必背）：568B = 白橙、橙、白绿、蓝、白蓝、绿、白棕、棕。口诀"橙白橙、绿白蓝、蓝白绿、棕白棕"。若问 568A，则是"绿白绿、橙白蓝、蓝白橙、棕白棕"——A、B 只把橙对与绿对（1-2 与 3-6）互换。
  • 第 3 题：光纤按传输模式分为单模（SMF） 与多模（MMF）。单模芯径小（约 9μm）、传得远（数公里以上）、用激光光源；多模芯径大（50／62.5μm）、传得近（几百米到 2km）、用 LED 光源、成本低。
  • 第 4 题：教材体系下答 EIA/TIA（具体为 TSB-67《非屏蔽双绞线布线系统传输性能现场测试标准》）。若题干强调"我国行业测试标准"，也可答 GB 50312《综合布线工程验收规范》——两种口径都出现过，以教师讲的为准。
  • 第 5 题（六个空）：综合布线的六大特点按顺序记 实用、灵活、开放、模块化、可扩展、经济。"模块化"与"可扩展性"是两个不同的空，不要合并成一个答，否则会少填一格。
  • 第 6 题：信息模块（RJ-45 信息插座背后的打线模块）端接遵循 T568A 与 T568B 两种线序标准——这正好呼应任务二的"接头与引脚的连接方式"。
  • 第 7 题：答"用户所在的区域，也称工作区子系统"即可，可补一句"主要包括信息插座与活动短线"。
  • 第 8 题：光纤三层结构自内向外——纤芯（传光）→包层（折射率低，把光全反射回纤芯）→涂覆层／被覆层（机械保护）。注意别把"涂覆层"写成"外套"，外套（护套）是成缆后的最外层，不是光纤本体的一部分。
  • 第 9 题（五个空）：综合布线工程的测试内容按链路参数分——接线图（连通性）、长度、衰减、近端串扰、回波损耗。核心是"通、长、衰、串"四项，回波损耗属进阶项。若试卷只印了 4 个空，就填前四项。
  • 第 10 题：网络管理功能分为网络监视与网络控制——先"看"（监视采集数据）再"动"（控制调整参数），这是一切网管动作的两半。
  • 第 11 题：网络管理信息储存在 MIB（Management Information Base，管理信息库） 中，由被管设备上的代理维护，管理站通过 SNMP 读写。

题号答案解析
1B综合布线系统的拓扑结构一般为星型——任务一明确"主干布线要采用星型拓扑结构"、"楼层平面子系统拓扑结构为星型拓扑"。星型的意义：任一节点故障不影响其他节点，且改跳线即可改连接
2A干线（垂直竖井）子系统连接的是设备间与各楼层管理间（配线间），所以设计范围是"管理间与设备间之间的线缆"。B 是水平子系统的范围；C、D 都不是干线的定义范围
3A"直接与用户终端设备相连"的是用户端子系统（工作区子系统）——它由信息插座与活动短线组成，活动短线一头插网卡、一头插插座。B 水平子系统连的是插座背后的水平电缆
4C四对双绞线的四种颜色是蓝、橙、绿、棕（每对为"白＋本色"）。A 多了"紫色"、B 把"橙"误作"红"、D 把"蓝"误作"白"——三组都是干扰项
5A信息插座是水平子系统的终点、又是工作区的起点，所以它连接工作区与水平子系统。这是布线的"分界点"，也是最常考的一句话
6C工作区内信息插座到计算机终端用活动短线，一般保持在 5m 以内（任务一给的上限是 L≤3m，教材此处按"一般保持 5m 以内"命题）。B 90m 是水平电缆、D 100m 是链路总长，别混
7D"从配线架到用户插座"这一段就是水平电缆（链路），不能超过 90m。注意题目问的是这一段，不是"信息插座到计算机"，所以不是 5m 也不是 100m
8C按信道链路模型测试，理论长度最大 100m（= 90m 水平线 + 两端跳线各 5m 的余量）。A 90m 是"从配线架到插座"的永久链路长度，两个概念差 10m，是本套题最容易错的对比
9ACAT5（5 类） 的最高传输速率为 100Mb/s（100BASE-TX）。B 155Mb/s 是 ATM；C 250Mb/s 属 CAT6 量级；D 600Mb/s 属 CAT6A／CAT7 量级
10C性能管理管"快不快、稳不稳"——采集性能变量数据（流量、响应时间、利用率），B"跟踪不同版本软硬件对网络的影响"属配置管理，A 也是配置管理，D 属安全管理
11A配置管理管"网络里有什么、怎么配"——监控配置信息、软硬件版本、参数变更。B"测量资源利用率"、C"收集性能变量"都属性能管理，D 属安全管理
12C安全管理管"谁能访问什么"——监控机密网络资源的访问点、访问控制、审计日志。A 属性能管理、B 属配置管理、D 属配置管理
13B管理站（网管主机）不直接问设备，而是通过设备上运行的 SNMP 代理（Agent） 取信息。代理是"驻留在被管设备里的代言人"——这是 SNMP 模型的核心一层
14C题目问"不正确"。网络管理之所以必需，是因为应用普及、网络组成复杂、手工管理有局限——A、B、D 都成立。而"个人计算机技术的快速发展"与"为什么需要网络管理"没有直接因果关系，属于硬凑的选项
15B路由器转发靠路由表（目的网络→下一跳／出接口）。A MAC 表是交换机用的（MAC 地址→端口）；C、D 不是规范术语
16DSNMP（Simple Network Management Protocol）是网络管理协议。A ICMP 是控制报文协议（ping 用的），B IGRP 是路由协议，C SMTP 是邮件协议
17C网络拓扑结构取决于通信子网（由路由器、链路组成的"传数据的部分"）的构成方式；资源子网（主机、终端、软件资源）提供的是"处理与使用"能力。通信子网定拓扑，资源子网定应用

三、问答题参考答案​

第 1 题：什么是综合布线？由几个部分组成？各部分功能？​

定义：综合布线（结构化布线）是指用标准的组网器件、按照标准的连接方法进行的规范化布线；其最大特点是布线的结构与当前所连接的设备无关，同一条线路的接口可连接不同设备。

组成与功能（六个子系统）：

子系统功能
户外（建筑物入口）楼宇之间的通信设备及通道；含建筑物配线架与建筑群配线架，提供其他楼宇与本楼的连接点
垂直竖井（干线）把各楼层配线架与设备间串联；由楼层垂直线缆与楼间线缆组成；承载汇总流量，须高带宽、星型拓扑、按 EIA/TIA 607 接地
楼层平面（水平布线）从机房布线架到用户端子区；含水平线缆、连接头、配线架与跳线；星型；L+M+N≤100m（M≤90m）
用户端（工作区）用户所在区域；由信息插座＋活动短线组成，连接网卡与插座；每 10m² 一个插座、每区 ≥2 个接口
机房（设备间）放置交换机、配线架、机架、UPS 等；楼层间垂直贯通、管道套管保护、UPS 供电
布线配线（机架／管理）由跳线板与跳线组成，以交接／互联方式连接并管理各子系统，用标签夹条标识线缆

第 2 题：非屏蔽双绞线与光缆布线的特点​

非屏蔽双绞线（UTP）：

  • 优点：价格低、施工简单（易弯曲、易端接）、重量轻、体积小、技术成熟、配套器件（RJ-45、配线架、模块）最齐全；100m 内可满足百兆／千兆到桌面。
  • 缺点：传输距离受限（100m）、带宽有限、抗电磁干扰能力弱（无屏蔽层）、易被窃听（无物理防护）、线对间存在串扰。

光缆：

  • 优点：带宽极高、传输距离远（多模数百米至 2km，单模数公里以上）、抗电磁干扰与防雷击、不产生电磁泄漏、保密性好、体积小重量轻、无金属（可用于强电磁与易燃环境）。
  • 缺点：造价高（光模块、熔接设备昂贵）、施工与端接工艺要求高（需熔接机／专用工具）、弯曲半径要求严、故障定位与修复较难。

结论（答题落点）：水平／桌面用 UTP 求经济，主干与楼间用光缆求带宽与距离——这正是"光纤到主干、双绞线到桌面"的典型设计。

第 3 题：选用线管、线槽和桥架时要考虑的问题​

  1. 容量与截面利用率：管内穿线总截面一般不超过管内截面的 40%（槽内不超过 50%~60%），留足扩容余量。
  2. 机械强度与承重：桥架需按线缆重量核算支撑间距与吊架承载，避免下垂变形。
  3. 材质与防火：选用阻燃／难燃材料（如 PVC 阻燃管、金属桥架），穿越防火分区处做防火封堵。
  4. 屏蔽与接地：金属线槽／桥架须可靠接地，与强电线路保持安全间距（一般 ≥30cm，交叉时 ≥10cm 并加隔板）。
  5. 电磁兼容与布线分离：强弱电分槽敷设，避免平行长距离走线造成干扰。
  6. 环境适应性：潮湿、腐蚀环境选防腐／防水型；吊顶、地板下、外墙等不同场所选明装／暗敷不同形式。
  7. 路由与美观：走向短直、少转弯，弯曲半径不小于线缆允许值（UTP 一般 ≥4 倍线径，光缆 ≥10~20 倍）；与建筑、水暖、电气专业协调避让。
  8. 标识与管理：线槽分段、桥架分层，配合标签夹条便于后期维护与查线。

第 4 题：楼层平面子系统设计应考虑的问题​

  1. 拓扑与距离：采用星型拓扑，严格控制 L+M+N≤100m，其中水平电缆 M≤90m、活动短线 L≤3m。
  2. 信息点布置：按每 10m² 一个信息插座、每工作区 ≥2 个（语音＋数据）预留；考虑办公家具、隔断变更的灵活性。
  3. 介质选型：语音多用 3 类／5 类 UTP，数据用 5e／6 类 UTP，高带宽或强干扰场合用光缆到桌面。
  4. 布线方式：根据建筑条件选暗管暗槽（预埋）、吊顶内、地板下（线槽／网络地板）、墙面线槽等方式。
  5. 路由与长度核算：走线短直、避开强电与水源，逐点核算实际长度，超长时调整配线间位置或增设楼层配线间（二级配线）。
  6. 配线间（管理间）位置：尽量位于楼层中心，使各点距离均等，减少最长链路。
  7. 接地与防火：金属槽管接地，穿墙与防火分区处封堵。
  8. 标识与文档：插座、配线架、跳线统一编号，出竣工图与测试报告，便于运维与扩容。

第 5 题：什么是网络管理？功能是什么？​

定义：网络管理是指对网络、设备和主机进行监视与控制，通过采集、分析网络运行状态信息，协调与配置网络资源，使网络稳定、高效、安全、经济地运行。

功能（ISO 五大功能域）：

功能域核心任务
配置管理掌握网络的拓扑与配置信息，跟踪软硬件版本与参数变更
性能管理采集流量、响应时间、正确率、线路利用率，评估并优化性能
故障管理发现、定位、排除故障，恢复正常运行
安全管理访问控制、身份鉴别、审计，保护网络资源不被非授权使用
计费管理按时间或流量计量网络使用，核算成本

教材口径的二分法：网络管理功能分为网络监视与网络控制（填空第 10 题）。

第 6 题：网络管理的基本模型​

四个基本要素：

  1. 管理站（Manager，网管平台）——运行网管软件，发起请求、接收数据、呈现结果；
  2. 管理协议（如 SNMP）——管理站与代理之间的通信规则；
  3. 代理（Agent）——驻留在被管设备中的软件，响应管理站请求、主动上报告警（Trap）；
  4. 管理信息库（MIB）——代理维护的被管对象数据库。

工作过程：管理站发出 Get／Set 请求 → 代理查询／修改 MIB → 返回响应；设备异常时代理主动发 Trap 上报。

一句话：管理站通过协议，向代理读写 MIB。

第 7 题：什么是 MIB？简述组成​

定义：MIB（Management Information Base，管理信息库） 是被管设备中所有可被管理对象的集合，是一个树状的层次化数据库，每个对象用唯一的 OID（对象标识符） 定位（如 1.3.6.1.2.1 为 mib-2）。

组成（mib-2 主要分组）：

组内容
system设备名称、描述、位置、运行时间等系统信息
interfaces网络接口的数量、状态、流量统计
ip／icmpIP 层与 ICMP 的转发、差错统计
tcp／udp传输层的连接数、重传、端口统计
snmpSNMP 自身的收发报文统计

结构特点：树状分层、对象唯一编号（OID）、只读对象与可读写对象并存；管理站用 SNMP 按 OID 读取或设置这些对象。

第 8 题：Ping 命令的使用方法​

作用：用 ICMP 回送请求／应答报文测试连通性与往返时延（ping 工作在网络层）。

常用格式与参数：

ping 目标IP或域名
ping -t 192.168.1.1        # 持续 ping，Ctrl+C 停止（Windows）
ping -n 10 192.168.1.1     # 发送 10 个报文
ping -l 1472 192.168.1.1   # 指定报文长度（用于测 MTU）
ping -w 1000 192.168.1.1   # 等待超时 1000ms

结果解读：

  • 出现 Reply from ... → 链路连通；
  • Request timed out → 目标不可达或未响应（可能被防火墙拦截 ICMP）；
  • Destination host unreachable → 路由不可达（本地路由表／网关问题）；
  • 统计行的 时间、TTL、丢包率可判断时延抖动与链路质量。

典型用法：先 ping 127.0.0.1 验本机协议栈 → ping 本机IP 验网卡 → ping 网关 验局域网 → ping 外网地址／域名 验出口与 DNS，由近及远逐段定位。

第 9 题：ipconfig 命令的使用方法​

作用：查看与刷新本机 TCP/IP 配置（IP 地址、子网掩码、默认网关、DNS、MAC 地址等）。

命令作用
ipconfig显示基本信息（IP、掩码、网关）
ipconfig /all显示全部信息，含 MAC 地址、DHCP 服务器、租约、DNS
ipconfig /release释放当前 DHCP 地址
ipconfig /renew重新申请 DHCP 地址
ipconfig /flushdns清空 DNS 缓存（域名解析异常时常用）
ipconfig /displaydns显示 DNS 缓存内容
ipconfig /registerdns重新注册 DNS

排障顺序：先 ipconfig /all 看有没有拿到地址、网关对不对；若 IP 为 169.254.x.x 说明 DHCP 获取失败（APIPA 地址），此时 release + renew 或检查 DHCP 服务与链路。

第 10 题：SNMP 的管理模型​

三部分构成：

  1. SNMP 管理站（NMS）——网管平台，运行管理进程；
  2. SNMP 代理（Agent）——运行在被管设备（路由器、交换机、服务器）上；
  3. MIB——代理侧的管理信息库。

协议本身：SNMP 建立在 UDP 之上（代理用 161、告警 Trap 用 162 端口），无连接、不可靠，但开销小、实现简单，适合周期性采集。

五类操作：

操作方向含义
Get管理站 → 代理读取单个对象
GetNext管理站 → 代理读下一个对象（遍历表格用）
Set管理站 → 代理修改对象值（配置）
Response代理 → 管理站返回结果
Trap代理 → 管理站设备主动告警（如端口 Down）

补充：SNMPv3 引入认证与加密（USM 用户安全模型），解决了 v1／v2c 中 community 明文的安全缺陷。

第 11 题：如何诊断网络故障？​

总体思路：分层排查、由近及远、先软后硬、先单点后全局。

五步法（教材口径）：

  1. 排定优先顺序——先处理影响面大、损失大的故障；
  2. 收集信息——问用户、看现象、查日志与指示灯；
  3. 设想可能的原因——按 OSI 分层（物理→数据链路→网络→传输→应用）列出候选；
  4. 排除问题——逐项验证，每次只改一个变量；
  5. 测试结果——确认恢复并记录归档，防止复发。

常用命令链（由近及远）：

步骤命令验证对象
1ping 127.0.0.1本机 TCP/IP 协议栈
2ipconfig /all本机地址、掩码、网关、DNS
3ping 网关局域网与本地链路
4ping 外网IP出口路由／NAT
5ping 域名 / nslookupDNS 解析
6tracert路径上哪一跳中断
7netstat -an / telnet IP 端口端口与服务是否可达
8arp -a局域网内 IP-MAC 对应（判断 ARP 欺骗）

故障定位口诀：物理层看灯看线，链路层看 MAC 与 VLAN，网络层看地址与路由，传输层看端口，应用层看服务与配置。

第 12 题：网络规划应考虑的主要因素​

  1. 需求分析：用户数量与分布、业务类型与流量特征、现有与未来的应用（是否跑视频、语音、数据库）。
  2. 拓扑与结构：星型／树型分层设计（核心—汇聚—接入），冗余与可靠性（双链路、双电源）。
  3. 传输介质与带宽：水平用 UTP、主干用光缆；带宽按当前需求 × 增长系数预留。
  4. 设备选型：交换机／路由器／防火墙的端口数、背板带宽、包转发率、可管理性与品牌兼容性。
  5. 地址规划：IP 网段与子网划分、VLAN 划分、DHCP 与 DNS 规划、NAT 方案，并预留扩展空间。
  6. 安全设计：边界防火墙、访问控制、VLAN 隔离、身份认证与审计、病毒防护。
  7. 布线工程：结构化布线按标准设计（六子系统、100m 限制），与土建同步、留扩容余地。
  8. 网络管理：是否部署网管平台（SNMP）、监控指标、故障响应流程与运维人员配置。
  9. 机房与环境：UPS 供电、空调、消防、防雷接地、机柜布局。
  10. 投资与实施：预算控制、分期实施、施工组织与验收标准（含测试报告与竣工文档）。

答题落点：网络规划的核心是"需求驱动 + 标准约束 + 留有余地"——教材在任务二最后一段正是这个意思。
