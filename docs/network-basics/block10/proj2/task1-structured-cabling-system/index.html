任务一 认识结构化布线系统

知识点​

1.项目二要学什么？​

项目导入：在网络组建过程中，布线是网络系统的一个重要组成部分，布线结构是否合理、布线的质量好坏将直接影响到整个网络系统的工作。本项目学习结构化布线的标准及实施等内容。

知识目标：

  1. 了解结构化布线系统的构成。
  2. 理解各个布线子系统的功能。
  3. 熟悉 TIA/EIA 568A 布线标准。

能力目标：

  1. 掌握 TIA/EIA 568 标准中对 RJ-45 线序的定义。
  2. 掌握各个布线子系统的功能。
  3. 了解智能大厦的组成。

素质目标：规范对结构化布线相关技术的理解，增强对网络标准化建设的认识。

2.一个必须先记住的数字：70%​

预备知识：据统计，网络中 70% 的故障都是由于布线不当引起的。

这句话是项目二的教学动机，也是常见的判断题、选择题考点——布线不当是网络故障的第一大来源。

布线可以遵循的两套标准：

标准全称／性质说明
EIA/TIA 568国际通用标准（美国）本书主要讲解的一套，最详尽、最完善
GB 50311—2016我国国家标准《综合布线系统工程设计规范》，国内工程验收常用

记忆要点：国际看 568，国内看 50311。

3.结构化布线的定义（必背）​

历史由来：20 世纪 90 年代以来，非屏蔽双绞线（UTP） 在电信行业得到广泛应用。为了节约资源、提高线缆的复用，人们把电话线路的连接方法应用到网络布线中，于是产生了最早的计算机网络布线系统。

定义：所谓"结构化布线"，是指用标准的组网器件、按照标准的连接方法进行的规范化布线，也称为"综合布线"。

三个关键词（背这三条就够）：

  1. 标准的组网器件——用什么。
  2. 标准的连接方法——怎么连。
  3. 规范化——结果可复现、可维护、可扩展。

核心特征（与传统布线的最大区别）：结构化布线与传统布线系统的最大区别是布线的结构与当前所连接的设备无关，同一条线路的接口可以连接不同的设备（如多媒体线及多媒体插座）。

通俗理解：传统布线是"设备决定线"（换设备就要重新拉线），结构化布线是"线不动、设备随便换"（只在配线间改跳线）。这正是它能支撑数据、话音、图形图像、UTP／光纤／STP／同轴等多种传输载体，支持多用户、多类型产品与高速网络应用的原因。

4.六个子系统（本项目第一大考点）​

按照一般划分，结构化布线系统包括 6 个子系统：户外子系统、垂直竖井子系统、楼层平面子系统、用户端子系统、机房子系统、布线配线子系统（教材图 10-2 以三层楼剖面图示意）。

一句话记住六个：户外 → 竖井 → 楼层 → 用户 → 机房 → 配线，即"从楼外进来，垂直往下，水平铺开，到桌面，中间有设备和配线架管着"。

（1）户外子系统​

定义：指楼宇之间的通信设备及通道。

  • 如果网络分布在多栋楼宇，则每栋大楼的入口都会有主干线进入。
  • 入口位置应包括两种配线架：
配线架连接对象
建筑物配线架连接大楼内的垂直干缆
建筑群配线架连接楼宇之间的干缆
  • 主干交换机所在的设备间应位于入口附近，它提供其他楼宇与本楼宇内布线的连接点。

（2）垂直竖井子系统​

定义：将楼宇内每楼层的配线架与设备间串联起来，或是通过楼宇的入口与其他楼宇的网络相连。

由两种线缆组成：

  1. 连接各楼层的垂直线缆；
  2. 连接不同楼宇的线缆。

注意：连接网络机房与楼宇主干线的线缆也是垂直竖井子系统的组成部分（教材原话，易漏）。

两条硬性要求：

  1. 主干线上承载了各分支线缆汇总的网络流量，所以主干线应具有较高的网络带宽，否则会成为信息传输的瓶颈。
  2. 主干布线要采用星型拓扑结构，接地应符合 EIA/TIA 607 规定的要求。

（3）楼层平面子系统（数字最密集，重点）​

定义：指从机房的布线架到用户端子区的这段电缆，它包含水平线缆、电缆连接头、配线架与跳线。

拓扑结构：星型拓扑。

为什么有线长限制：由于双绞线的传输距离限制为 100m，因此用户计算机与交换机（或其他中心连接设备）之间的实际线长是三段线长之和（教材图 10-3）。

代号含义长度要求
L信息插座网络接口至计算机的活动短线L≤3m
M水平电缆M≤90m
N配线架到交换机的跳线通常较短
合计用户计算机到交换机的实际线长L+M+N≤100m

三句话记住这张表：

  1. 总长卡 100m；
  2. 水平电缆卡 90m（留 10m 给两端跳线）；
  3. 活动短线卡 3m（所以 N 必然 ≤7m）。

易错提醒：题目问"水平电缆最长多少"答 90m；问"从配线架到用户插座（链路）最长多少"答 90m；问"信息插座到计算机的连线最长多少"答 3m 或 5m（同步训练第 6 题给的是 5m，按教材"一般保持在 5m 以内"记）；问"双绞线传输距离／信道链路最大长度"答 100m。同一个 100m，问法不同答案不同。

（4）用户端子系统​

定义：是用户所在的区域，也称为工作区子系统。

主要包括：用户设备连接的信息插座与活动短线。

  • 信息插座：包括 RJ-45 接口或光纤的转接头等；
  • 活动短线：包括线缆与接头，用于连接网卡与信息插座的接口。

布线要求（相对简单，但配置指标是考点）：

  1. 每 10m² 的工作区应布置一个信息插座；
  2. 每个工作区应配置两个以上独立的网络接口，以预留网络接入位置，方便移动、添加和变更设备。

为什么至少两个插座：本任务后文与 568A 部分都强调——一个用于语音连接，另一个用于数据连接（"在每个工作区至少应有两个信息插座"）。

（5）机房子系统​

定义：机房是指在楼宇的每个楼层中用于放置网络设备及器材的场所，如把交换机、配线架、机架、UPS 等网络设备放置在里面。

规划要求（四条）：

  1. 每一个楼层最好能垂直连接起来，贯穿整栋大楼——这样可以缩短网络主干线缆的长度，使得布线更集中、管理更容易；
  2. 每一个楼层的机房应有垂直互通的管道，干线电缆必须在管道内穿越；
  3. 通常应有套管保护线缆；
  4. 机房应由 UPS 系统供电。

地位：机房是布线系统最主要的区域，该楼层的网络连接线都由线缆传送至此。

（6）布线配线子系统​

定义：由各种跳线板和跳线组成，用来连接各子系统。

位置：一般放置在机架内。机架用于放置网络器材、设备——交换机、配线架、UPS 或者其他网络设备等都应放置到机架上，这样有助于对网络线缆的管理。因机房网络线缆繁多，一定不能乱放器材。

工作方式（两种）：

  1. 交接方式——用跳线或软线连接；
  2. 互联方式。

用这两种方式管理垂直竖井系统和楼层平面系统，以及使用标签夹条标识线缆。

六子系统对照表（速记）​

序号子系统覆盖范围关键数字／要点
1户外楼宇之间建筑物配线架（楼内垂直干缆）＋建筑群配线架（楼间干缆）
2垂直竖井楼层配线架↔设备间星型；EIA/TIA 607 接地；高带宽
3楼层平面机房布线架↔用户端子区星型；L≤3m、M≤90m、L+M+N≤100m
4用户端（工作区）用户桌面每 10m² 一个信息插座；每区 ≥2 个接口
5机房每楼层设备间垂直贯通、管道套管、UPS 供电
6布线配线机架内跳线板＋跳线；交接／互联

5.两套六子系统名称的对应（本任务最易混的考点）​

教材在任务一用工程习惯名称（户外／垂直竖井／楼层平面／用户端／机房／布线配线），在任务二介绍 568A 时又给出标准名称（建筑物入口／设备间／干线／机架／水平布线／工作区）。两套名称指的是同一套系统，只是叫法不同，考试可能任选一套问，务必能互相翻译：

教材任务一（工程叫法）568A 标准叫法含义提示
户外子系统建筑物入口子系统楼与楼之间、楼宇入口
垂直竖井子系统干线子系统垂直主干
楼层平面子系统水平布线子系统同层水平铺设
用户端子系统工作区子系统桌面区域
机房子系统设备间子系统放设备的地方
布线配线子系统机架子系统（也叫管理子系统）跳线、配线架管理

答题策略：题目如果已经给出"户外子系统……"就顺着工程叫法填；如果给的是"建筑物入口子系统……"就顺着 568A 叫法填。两套都写、顺序对齐最保险。

6.标准组网器件​

（1）七类器件（"包括"型考点）​

结构化布线系统中，标准的组网器件主要包括：连接器、传输线、插头／插座、跳线、配线架、插座板、线槽和管道等。

（2）为什么强调"标准"​

再次强调结构化布线与传统布线系统的最大区别——布线的结构与当前所连接设备无关，同一条线路的接口可以连接不同的设备，如多媒体线及多媒体插座。

再次强调插座数量：在每个工作区至少应有两个信息插座，一个用于语音连接，另一个用于数据连接。

（3）六类设备器件（教材图 10-4 ~ 10-8）​

结构化布线系统所用的设备器件主要有：配线架、跳线、接插软线（活动短线）、机架、信息插座、标签夹条等。

器件作用细节要点
配线架集中端接与管理线缆分电缆配线架与光缆配线架：前者用接线块和连接块，后者用光纤连接器；教材图 10-4 是 110 配线架（多媒体配线架，含 12 口电话模块、光纤配线盘、楼层配线架、语音主干缆、6 类非屏蔽／屏蔽线、光纤主干缆）
跳线管理垂直竖井系统与平面楼层系统的转换、配线架与交换机之间的连接、对用户端子系统的管理典型用途：把某个信息插座添加至网络或从网络中移出；教材图 10-5 是 RJ-45 跳线
接插软线也称活动短线，用于用户端子区是电线或光缆接头的连接线，连接终端客户机与信息插座（图 10-6）
机架放置网络设备的柜式或支架式设备交换机、配线架、UPS 都上架（图 10-7）
信息插座结构化布线系统在各用户端子区的接口，与水平电缆和水平光缆相连接接口有 RJ-45、RJ-11 或光缆接口；与活动短线相连；可放置于墙面或地面（图 10-8）
标签与夹条给线缆做标记结构化布线系统中每条线缆必须标记清楚

易混点：跳线（在配线架／机架侧做管理）与接插软线／活动短线（在用户桌面侧连终端）不是一回事，虽然外形都像一段两端带插头的短线。判断依据看用在哪一侧。

RJ-45 与 RJ-11：RJ-45 是 8 芯（4 对）网络接口；RJ-11 是 4 芯（2 对）电话接口。信息插座上可能同时提供两者。

9.课堂提示（讲课参考）​

  • 开场用 70% 这个数字：让学生先建立"布线比设备更容易出问题"的直觉，再讲标准。
  • 画一张三层楼剖面图（可直接用教材图 10-2）：从楼外箭头进来 → 竖井 → 每层水平 → 桌面，边画边报六个名字，学生跟着复述两遍，比背表格有效。
  • L/M/N 用实物演示：一根 3m 跳线、一段 90m 水平线、一根短跳线，让学生明白"100m 不是一根线的长度，是三段之和"。
  • 两套名称对照表务必板书：这是学生做同步训练时最容易卡住的地方。
