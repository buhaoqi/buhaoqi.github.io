任务二 计算机网络安全体系

知识点​

1.任务描述​

计算机网络安全体系是指为了保障计算机网络系统及其信息的安全而建立的一系列防护措施和管理机制。

建设路径（教材原句）：通过建立完善的安全策略和政策、健全的安全管理机制、安全防护体系和安全事件应急响应体系，可以有效地保障计算机网络的安全。

本任务的三块内容：网络安全机制 → 安全分类 → 法律法规。

一句话记住体系结构：策略（定规矩）+ 管理（抓落实）+ 防护（上技术）+ 应急（出事怎么办）。

2.网络安全机制总览（八种）​

为维护网络安全应该采用的措施和机制共有 八种：

序号机制解决什么问题
1加密机制信息保密（防窃取、防破译）
2访问控制机制防非法使用系统资源
3数据完整性机制防篡改、防丢失、防乱序
4数字签名机制防否认、防伪造、防冒充、防篡改
5交换鉴别机制确认对方身份
6公证机制第三方取证、仲裁纠纷
7流量填充机制防流量分析
8路由控制机制控制数据走的路径

记忆：加（加密）— 控（访问控制）— 完（完整性）— 签（数字签名）— 鉴（交换鉴别）— 证（公证）— 填（流量填充）— 路（路由控制）。

3.加密机制​

地位：加密是提供信息保密的核心方法。

两种分类方式（必考，别混）：

分类依据分出的两类
按密钥的类型对称密钥算法 和 非对称密钥算法
按密码体制的不同序列密码算法 和 分组密码算法

注意："对称/非对称"看的是密钥是否相同；"序列/分组"看的是对数据怎么处理（逐位流式处理 / 按块处理）。两套分类是交叉的，不是一回事。

加密算法的额外作用：加密算法除了提供信息的保密性之外，往往和其他技术结合，例如 Hash 函数，还可以提供信息的完整性验证。

软件加密技术：加密技术不仅应用于数据通信和存储，也应用于程序的运行，通过对程序的运行实行加密保护，可以防止软件被非法复制，防止软件的安全机制被破坏，这就是软件加密技术。

4.访问控制机制​

作用：访问控制可以防止未经授权的用户非法使用系统资源。这种服务不仅可以提供给单个用户，也可以提供给用户组的所有用户。

定义：访问控制是通过对访问者的有关信息进行检查来限制或禁止访问者使用资源的技术。

两个层次（重点区分）：

层次依据具体内容
高层访问控制用户身份与权限包括身份检查和权限确认，是通过对用户口令、用户权限、资源属性的检查和对比来实现的
低层访问控制通信协议中的特征信息是通过对通信协议中的某些特征信息的识别、判断，来禁止或允许用户访问的措施。如在路由器上设置过滤规则进行数据包过滤，就属于低层访问控制

判断口诀：看"人"的是高层（口令、权限），看"包"的是低层（协议特征、过滤规则）。

5.数据完整性机制​

数据完整性包括两个方面：数据单元的完整性 和 数据序列的完整性。

（1）数据单元的完整性

定义：指组成一个单元的一段数据不被破坏和增、删、篡改。

实现方法：通常是把包括有数字签名的文件用 Hash 函数产生一个标记，接收者在收到文件后也用相同的 Hash 函数处理一遍，判断产生的标记是否相同就可知道数据是否完整。

（2）数据序列的完整性

定义：指发出的数据分割为按序列号编排的许多单元时，在接收时还能按原来的序列把数据串联起来，而不要发生数据单元的丢失、重复、乱序、假冒等情况。

两者区别：单元完整性管"内容有没有被改"，序列完整性管"顺序对不对、有没有少或多"。

6.数字签名机制（本节重点）​

（1）数字签名要解决的四个安全问题​

问题说明
① 否认发送者不承认信息是他发送的
② 伪造自己伪造了要发送的信息，却声称是别人发送的
③ 冒充冒充别人的身份在网络中传送信息
④ 篡改接收者私自篡改信息的内容

（2）数字签名的四个特性​

数字签名机制具有：可证实性、不可否认性、不可伪造性和不可重用性。

记忆：证得出（可证实）、赖不掉（不可否认）、仿不了（不可伪造）、搬不走（不可重用）。

（3）数字签名的工作过程（服务端 → 客户端版）​

  1. 服务端先用 Hash 算法对报文进行计算，得到信息摘要；
  2. 服务端用自己的私钥对信息摘要进行加密，得到的密文称为数字签名；
  3. 服务端把报文和数字签名一起发送给客户端；
  4. 客户端先对数字签名用公钥进行解密，得到信息摘要；
  5. 再对报文进行 Hash 计算，将计算值和信息摘要进行对比，两者相同则说明报文没有被修改。

关键提醒（教材原注）：这里的 Hash 算法一定是不可逆的算法。

（4）图 9-1 的完整解读（甲发送、乙接收，共 7 步）​

图 9-1 的标题是"数字签名机制下的数据传输过程"，左右两栏分别是甲（发送方）与乙（接收方），图中同时画了两条并行的保护：上半部分走"加密保保密"，下半部分走"签名防篡改、防否认"。

步骤做什么用谁的密钥
①甲使用乙的公钥对明文进行加密，生成密文信息乙的公钥（只有乙的私钥能解）
②甲使用 Hash 算法对明文进行 Hash 运算，生成数字指纹无密钥（不可逆）
③甲使用自己的私钥对数字指纹进行加密，生成数字签名甲的私钥
④甲将密文信息和数字签名一起发送给乙—
⑤乙使用甲的公钥对数字签名进行解密，得到数字指纹甲的公钥
⑥乙接收到甲的加密信息后，使用自己的私钥对密文信息进行解密，得到最初的明文乙的私钥
⑦乙使用 Hash 算法对还原出的明文用与甲相同的 Hash 算法进行 Hash 运算，生成数字指纹，然后与从甲得到的数字指纹比较：一致则接受明文，不一致则丢弃明文无密钥

图 9-1 里的四个标注要认准：

  • 明文：Hell, Word（书中原文如此）；
  • 数字指纹：Hash 运算的结果，图中标注形如 &3112*9；
  • 数字签名：指纹被甲的私钥加密后的密文，图中标注形如 &4152*9；
  • 比较框："比较是否一致，一致时接受明文，不一致时丢弃"。

结论（教材原句）：从以上数字签名的加/解密过程中可以看出，数字签名技术不但证明了信息未被篡改，还证明了发送方的身份。

核心口诀（务必记牢）：

  • 公钥加密、私钥解密 —— 用于保密（①⑥：谁能解，说明是发给谁的）；
  • 私钥加密、公钥解密 —— 用于签名（③⑤：谁能解，说明是谁签的）。

一句话："用对方的公钥加密"是为了只有对方能看；"用自己的私钥加密"是为了谁都能验证是我发的。

（5）数字签名的缺点​

由于服务端的公钥是对外公开的，客户端获取公钥的途径是否安全，存在着公钥被调包的可能——即客户端以为拿到的是服务端的公钥，实际上是第三方的公钥，从而第三方冒充服务端与客户端进行信息交互，骗取客户端的重要信息。

这正是"数字证书"要解决的问题：让**可信第三方（CA）**给公钥"签名担保"，防止公钥被调包。

7.交换鉴别机制​

定义：交换鉴别机制是通过互相交换信息的方式来确定彼此的身份。

三种技术（必背）：

技术做法
① 口令由发送方给出自己的口令，以证明自己的身份，接收方则根据口令来判断对方的身份
② 密码技术发送方和接收方各自掌握的密钥是成对的。接收方在收到已加密的信息时，通过自己掌握的密钥解密，能够确定信息的发送者是掌握了另一个密钥的那个人。在许多情况下，密码技术还和时间标记、同步时钟、双方或多方握手协议、数字签名、第三方公证等相结合，以提供更加完善的身份鉴别
③ 特征实物例如 IC 卡、指纹、声音频谱、虹膜生物特征等

记忆：知道的（口令）— 掌握的（密钥）— 自带的（指纹虹膜）。安全性也大致按这个顺序升高。

8.公证机制​

背景：网络上用户繁杂，为提高信息安全程度，可以找一个大家都信任的公证机构，各方交换的信息都通过公证机构来中转，公证机构从中转的信息里提取必要的证据，日后一旦发生纠纷，就可以据此做出仲裁。

数字证书技术就是一种公证机制。

数字证书的四个要点：

  1. 采用公钥体制，利用一对互相匹配的密钥进行加密、解密；
  2. 数字证书是一个经证书授权中心数字签名的、包含着公钥拥有者信息以及公钥的文件；
  3. 以数字证书为核心的加密技术（加密传输、数字签名、数字信封等安全技术）可以对网络上传输的信息进行加密和解密、数字签名和签名验证；
  4. 目的是确保网络传递信息的机密性、完整性及不可抵赖性。

注意用词：公证机制解决的是"事后有纠纷怎么办"，它提供的是"证据"和"仲裁依据"，不是"防止攻击"。

9.流量填充机制​

作用：流量填充机制提供针对流量分析的保护。

为什么需要：外部攻击者有时能够根据数据交换的出现、消失、数量或频率而提取出有用信息（这叫流量分析，属于被动攻击）。

怎么实现：流量填充机制能够保持流量基本恒定，因此观测者不能通过流量的变化获取任何信息。流量填充的实现方法是动态随机生成数据并对其加密，再通过网络发送。

通俗理解：没话说的时候也要"占着话筒"，让外人看不出什么时候真的在传重要数据。

10.路由控制机制​

作用：路由控制机制使得可以指定通过网络发送数据的路径。

两个好处：

  1. 可以选择那些可信的网络节点，从而确保数据不会暴露在安全攻击之下；
  2. 如果数据进入某个没有正确安全标志的专用网络时，该数据包将会被拒绝进入。

11.网络安全分类​

（1）按中国国家计算机安全规范分三类​

根据中国国家计算机安全规范，计算机的安全大致可分为 3 类：

类别包括什么
实体安全机房、线路、主机等
网络与信息安全网络的畅通、准确以及网上信息的安全
应用安全程序开发运行、I/O、数据库等的安全

（2）按功能分四个类别​

类别具体内容
① 基本安全类访问控制、授权、认证、加密以及内容安全
② 管理与记账类安全策略的管理、实时监控、报警以及企业范围内的集中管理与记账
③ 网络互联设备安全类网络互联设备包括路由器、通信服务器、交换机等，网络互联设备安全正是针对上述这些互联设备而言的，它包括路由安全管理、远程访问服务器安全管理、通信服务器安全管理以及交换机安全管理等
④ 连接控制类负载均衡、可靠性以及流量管理等

趋势（教材原句）：由于网络安全范围的不断扩大，如今的网络安全不再是仅仅保护内部资源的安全，还必须提供更进一步的服务。

两组分类别混："3 类"是按"保护对象"分（实体、网络与信息、应用），"4 类"是按"安全功能"分（基本、管理记账、设备、连接控制）。

12.网络安全法律法规​

我国已制定的主要法律、法规和国家标准：**《网络安全法》《网络安全等级保护条例》**和 GB/T 22239-2019 等。

（1）《网络安全法》​

立法目的：为了保障网络安全，维护网络空间主权和国家安全、社会公共利益，保护公民、法人和其他组织的合法权益，促进经济社会信息化健康发展而制定的法律。

两个关键时间（必背）：

事项时间
发布2016 年 11 月 7 日
施行2017 年 6 月 1 日

地位（四个排比句）：《网络安全法》是我国第一部全面规范网络空间安全管理方面问题的基础性法律，是我国网络空间法治建设的重要里程碑，是依法治网、化解网络风险的法律重器，是让互联网在法治轨道上健康运行的重要保障。

作用：将近年来一些成熟的好做法制度化，并为将来可能的制度创新做了原则性规定，为网络安全工作提供切实法律保障。

三项基本原则：

  1. 网络空间主权原则——《网络安全法》第 1 条"立法目的"开宗明义，明确规定要维护我国网络空间主权。网络空间主权是一国国家主权在网络空间中的自然延伸和表现；
  2. 网络安全与信息化发展并重原则——网络安全和信息化必须统一谋划、统一部署、统一推进、统一实施；
  3. 共同治理原则——网络空间安全仅仅依靠政府是无法实现的，需要政府、企业、社会组织、技术社群和公民等网络利益相关者的共同参与。

（2）《网络安全等级保护条例》​

发布：2018 年 6 月 27 日，公安部发布了《网络安全等级保护条例》（以下简称《条例》）。

核心制度：明确我国实行网络安全等级保护制度，对网络实施分等级保护、分等级监管。

适用范围：《条例》适用于我国境内建设、运营、维护、使用的网络，个人及家庭自用的网络除外。

保护的范围（两块）：

  1. 将风险评估、安全监测、通报预警、案事件调查、数据防护、灾难备份、应急处置、自主可控、供应链安全、效果评价、综治考核等重点措施纳入等级保护制度并实施；
  2. 将网络基础设施、重要信息系统、网站、大数据中心、云计算平台、物联网、工控系统、公众服务平台、互联网企业等全部纳入等级保护监管。

保护重点：涉及国家安全、国计民生、社会公共利益的网络的基础设施安全、运行安全和数据安全。

五个保护等级（必背，按"受破坏后的危害程度"递进）：

等级受破坏后的后果
第一级对相关公民、法人和其他组织的合法权益造成损害，但不危害国家安全、社会秩序和公共利益的一般网络
第二级对公民、法人和其他组织的合法权益造成严重损害，或者对社会秩序和公共利益造成危害，但不危害国家安全的一般网络
第三级对公民、法人和其他组织的合法权益造成特别严重损害，或者会对社会秩序和社会公共利益造成严重危害，或者对国家安全造成危害的重要网络
第四级对社会秩序和公共利益造成特别严重危害，或者对国家安全造成严重危害的特别重要网络
第五级一旦受到破坏后会对国家安全造成特别严重危害的极其重要网络

记忆链：害民（1、2、3）→ 害社会（2、3、4）→ 害国家（3、4、5）。三条线逐级上移一格，这就是表 9-1 的由来。

（3）表 9-1：网络的五个安全保护等级​

表 9-1 是按"受侵害的客体"与"对客体的侵害程度"两个维度交叉定位安全等级：

受侵害的客体一般损害严重损害特别严重损害
公民、法人和其他组织的合法权益第一级第二级第三级
社会秩序、公共利益第二级第三级第四级
国家安全第三级第四级第五级

读表方法（三步）：

  1. 先看"害了谁"——公民/社会/国家，往下走一行，等级加一；
  2. 再看"害到什么程度"——一般/严重/特别严重，往右走一列，等级加一；
  3. 两格交叉处就是定级结果。

举例：某系统被破坏后只损害公民合法权益，且程度一般 → 交叉点是 第一级；若危害国家安全且程度特别严重 → 第五级。

一处需要你核对原件的地方：教材表 9-1 中"社会秩序、公共利益 × 严重损害"与"国家安全 × 一般损害"两格，扫描件字迹模糊（放大后近似"第二级""第一级"），但按《条例》第二、三、四、五级的定义原文推导，这两格都应为"第三级"。上表按定义给出，讲课时可对照纸质教材原件确认；若考题直接照抄教材表格，请以教师口径为准。
