## 知识点

### 1.模块九与项目一要学什么？

**模块九 学习要点**：

1. **掌握网络威胁的分类及特点**；
2. **掌握网络安全的组成**；
3. **掌握防火墙的基本原理**；
4. **了解网络病毒与黑客攻击**。

**重点难点**：**网络威胁的分类**；**防火墙的实现方式**。

**项目导读**：**网络安全是一门涉及计算机科学、网络技术、通信技术、密码技术、信息安全技术、应用数学、数论、信息论等多种学科的综合性科学**。网络安全**主要内容是保护网络、设备和数据免遭未经授权的访问或使用**，从而确保信息的**机密性、完整性和可用性**等。为了维护网络的安全，保证计算机网络正常运行，应该**建立完善的网络安全机制**，并对其进行**合理地分类**，**形成网络安全体系**。本项目学习**网络安全的组成**与**网络安全体系架构**等内容。

**项目导读里的两个关键点**：

1. 网络安全是**交叉学科**——涉及 **8 个以上**领域（计算机、网络、通信、密码、信息安全、应用数学、数论、信息论）；
2. 网络安全的目标是**保护"网络、设备、数据"三类对象**，落脚点是**机密性、完整性、可用性**。

**项目一的两个任务**：**网络安全概述** → **计算机网络安全体系**。

### 2.任务描述

**网络安全是指网络系统的硬件、软件及其系统中的数据受到有效保护**，**不因偶然的或者恶意的原因而遭受到破坏、更改、泄露**，**系统连续可靠、正常地运行**，**网络服务稳定、连续**。

**这句话里要抓四个点**：

1. **保护对象**——**硬件、软件、数据**（三者缺一不可）；
2. **威胁来源**——**偶然的**（意外、故障）或**恶意的**（人为攻击）；
3. **三种损害**——**破坏、更改、泄露**；
4. **目标状态**——**系统连续可靠运行，服务稳定连续**。

### 3.网络安全的内容

**定义（教材原句）**：网络安全是指**网络系统的硬件、软件及系统中的数据受到保护**，**不受偶然的或者恶意的原因而遭到破坏、更改、泄露**，**确保系统能连续、可靠、正常地运行，网络服务不中断**。

**本质（必背）**：**网络安全从其本质上来讲就是网络上的信息安全**。

**广义范围**：**凡是涉及网络上信息的保密性、完整性、可用性、可控性和不可否认性等的相关技术和理论都是网络安全的研究领域**。

### 4.网络安全的五个特性（核心考点）

| 特性 | 定义 | 被破坏的例子 |
|------|------|--------------|
| **保密性** | **信息不泄露给非授权用户** | 机密文件被窃取、外传 |
| **完整性** | **数据未经授权不能进行改变**，即信息在**存储或传输**过程中保持**不被修改、不被破坏和不丢失**的特性 | 数据被篡改、删改、丢失 |
| **可用性** | **可被授权实体访问并按需求使用**的特性，即**当需要时能否存取所需的信息** | **拒绝服务攻击**、破坏网络和有关系统的正常运行，都**属于对可用性的攻击** |
| **可控性** | **对信息的传播及内容具有控制能力** | 无法屏蔽、过滤违法有害信息 |
| **不可否认性** | **信息发送方不能否认信息是由己方发出** | 发送方事后抵赖，说自己没发过 |

**五性的记忆口诀**：**保（不泄露）— 完（不被改）— 用（能用）— 控（管得住）— 认（赖不掉）**。

**最容易考"可用性"**：**拒绝服务（DoS）攻击破坏的是可用性**——它不改数据、不偷数据，只是让你**用不了**。

### 5.网络安全包括哪四个方面

**网络安全包括物理安全、逻辑安全、操作系统安全、联网安全等方面**。

**（1）物理安全**

**定义**：物理安全是指**用来保护计算机硬件和存储介质的装置和工作程序**。

**包括**：**防盗、防火、防静电、防雷击、防电磁泄漏**等**技术和制度**。

**（2）逻辑安全**

**实现手段**：**口令字、文件许可、查账**等方法。

**关键结论**：**防止计算机黑客的入侵主要依赖计算机的逻辑安全**。

**具体做法（四种）**：

1. **限制登录的次数**，或对**试探性操作加上时间限制**；
2. 用**软件**保护存储在计算机文件中的信息——该类软件**可以限制其他用户存取非自己所有的文件**，直到**该文件的所有者明确准许**其他用户存取为止；
3. **通过硬件完成**限制存取——在接收到存取要求后，**先询问并校核口令**，然后**访问存在于目录中的授权用户标志号**；
4. 有些安全软件可以**跟踪可疑的、未授权的存取企图**，如**多次登录**或**访问其他用户的文件**。

**（3）操作系统安全**

**地位**：**操作系统是计算机中最基本、最重要的软件**，**同一计算机可以安装几种不同的操作系统**。

**核心要求**：如果计算机系统**可提供给许多人使用**，**操作系统必须能区分用户**，以便**防止他们相互干扰**。

**举例**：多数的**多用户操作系统**，**不会允许一个用户删除属于另一个用户的文件**，除非**第二个用户明确地给予允许**。一些**安全性较高、功能较强**的操作系统可以为**计算机的每一位用户分配账户**，通常**一个用户分配一个账户**。**操作系统不允许一个用户修改由另一个账户产生的数据**。

**（4）联网安全**

**联网的安全性只能通过以下两方面的安全服务来达到**：

| 服务 | 作用 |
|------|------|
| **访问控制服务** | 用来**保护计算机和联网资源不被非授权使用** |
| **通信安全服务** | 用来确保**数据的保密性与完整性**，以及**通信的可信赖性** |

**举例**：**基于互联网或 WWW 的电子商务**就必须**依赖并广泛采用通信安全服务**。

**四个方面的层次感**：**物理（机房设备）→ 逻辑（口令权限）→ 操作系统（用户隔离）→ 联网（传输安全）**，一层比一层更靠"软"，也一层比一层**更难防**。

### 6.网络安全威胁的两大类

**计算机网络所面临的威胁包括对网络中信息的威胁和对网络中设备的威胁**。

**影响计算机网络的因素很多**：

- 可能是**有意的**，也可能是**无意的**；
- 可能是**人为的**，也可能是**非人为的**；
- 还可能是**外来黑客对网络系统资源的非法入侵、使用**等。

### 7.人为的无意失误

**举例**：

1. **操作员安全配置不当**造成的安全漏洞；
2. **用户安全意识不强**；
3. **用户口令选择不慎**；
4. 用户**将自己的账号随意转借给他人**或**与别人共享**等。

**注意**：这一类**没有主观恶意**，但**后果一样严重**——很多入侵事件都是从"配置不当"和"口令太弱"开始的。

### 8.人为的恶意攻击（最大威胁，重点）

**地位**：**人为的恶意攻击，是计算机网络面临的最大威胁**，**黑客的攻击和计算机犯罪都属于这一类**。

**两种类型（必考，务必分清）**：

| 类型 | 目的 | 是否影响网络正常工作 | 典型手段 |
|------|------|----------------------|----------|
| **主动攻击** | 以各种方式**有选择地破坏信息的有效性和完整性** | **会影响**（改变数据、中断服务） | 篡改、伪造、重放、中断、拒绝服务 |
| **被动攻击** | **在不影响网络正常工作的情况下，进行截获、窃取、破译**以获得重要机密信息 | **不影响**（只"偷看"，不改动） | **截获、窃听、流量分析、破译** |

**共同后果**：**这两种攻击均可对计算机网络造成极大的危害，并导致机密数据的泄露**。

**判断口诀**：**改数据的是主动，只偷看的是被动**；**被动攻击最隐蔽**（因为网络照常运行，用户毫无察觉）。

### 9.网络软件漏洞和"后门"

**漏洞**：**网络软件不可能是百分之百无缺陷和无漏洞的**，然而**这些漏洞和缺陷恰恰是黑客进行攻击的首选目标**。曾经出现过的**黑客攻入网络内部的事件，大部分是因为安全措施不完善**所招致的后果。

**"后门"**：软件的**"后门"都是软件公司的设计、编程人员为了调试方便而设置的**，**一般不为外人所知**。但**一旦"后门"打开，造成的后果将不堪设想**。

**两者区别**：**漏洞是"无意留下的"（缺陷），后门是"有意留下的"（方便调试）**——但**危险程度一样**。

### 10.四组威胁细目（本节最全的知识清单）

#### （1）系统漏洞造成的威胁

**① 乘虚而入**

例如，用户 A 由于某种原因**暂时停止了与某个系统的通信**，但**该系统上的对应端口仍处于激活状态**。这时，**用户 B 通过这个端口（不必通过任何申请使用端口的安全检查）就可以开始与这个系统通信**。

**② 不安全服务**

**操作系统的一些服务程序可以绕过计算机的安全系统**。

**③ 配置和初始化**

因各种原因**必须重新启动服务器**时，可能会**导致文件丢失或篡改**。这可能是在**系统重新初始化时，安全系统没有被正确地初始化**，从而**留下了安全漏洞被人利用**。

#### （2）身份鉴别威胁

| 手段 | 做法 |
|------|------|
| **① 口令圈套** | 常用的口令圈套**通过一个编译代码模块实现**，它**运行起来和登录屏幕一样**。它被**插入到正常登录过程之前**，用户看到的只是**先后两个登录屏幕**。第一次登录失败了，所以用户被要求再输入用户名和口令。实际上，**第一次登录并没有失败，而是将登录数据（用户名和口令）窃取了** |
| **② 口令破解** | **破解口令就像是猜测密码锁的数字组合一样**，在该领域中**已有许多能提高破解成功率的技巧** |
| **③ 算法考虑不周** | **口令输入过程必须在满足一定条件下才能正常地工作**，这个过程**通过某些算法实现**，而由于**算法的设计考虑不周全**，从而导致**产生安全漏洞** |
| **④ 编辑口令** | 编辑口令**需要依靠内部漏洞**，如果**公司内部的人建立了一个虚设的账户**或**修改了一个隐含账户的口令**，这样**任何知道那个账户的用户名和口令的人便可以访问该计算机** |

**口令圈套的记忆**：**假登录界面 + 两次输入 = 第一次是"钓鱼"**。这也就是今天说的"**钓鱼网站**"的雏形。

#### （3）线缆连接威胁

**网络线缆的连接会对计算机数据造成新的安全威胁**，主要包括：

1. **线缆窃听**；
2. **拨号进入**；
3. **冒名顶替**等。

#### （4）有害程序威胁

**① 病毒**

**计算机病毒可以通过网络快速传播，危害计算机资源和网络信息安全**。

**② 代码炸弹**

代码炸弹**不像病毒那样四处传播**，**程序员将代码炸弹写入软件中**，使其**产生了一个不能轻易找到的安全漏洞**。**一旦该代码炸弹被触发后，这个程序员便会被请回来修正这个错误，并赚一笔钱**。被这种**高技术敲诈**的受害者**甚至不知道自己被敲诈**，**即便他们有疑心也无法证实自己的猜测**。

**③ 特洛伊木马**

特洛伊木马程序**一旦被安装到计算机上，便可按编制者的意图行事**。特洛伊木马**能够摧毁数据**，有时**伪装成系统上已有的程序**，或者**创建供攻击者使用的用户名和口令**。

**④ 更新或下载**

**不同于特洛伊木马**，有些网络系统**允许通过网络进行固件和操作系统更新**，于是**非法闯入者便可以解开这种更新方法，对系统进行非法更新**。

**四种有害程序对照（易考区分）**：

| 名称 | 是否自我传播 | 核心特征 |
|------|--------------|----------|
| **病毒** | **会**，通过网络快速传播 | 依附于程序/文件，**危害资源和信息安全** |
| **代码炸弹** | **不会**四处传播 | 由**程序员预埋**，触发后**敲诈**，隐蔽性极强 |
| **特洛伊木马** | **不会**自我复制 | **伪装**成正常程序，**按编制者意图行事**，可窃取账号口令 |
| **非法更新** | — | 利用**固件/系统在线更新**通道，**非法更新系统** |

### 11.网络出现安全威胁的六条原因（重点，常考简答）

**（1）认证环节薄弱**

网络上的认证**通常是使用口令来实现的**，而**口令可以通过许多方法破译**，其中**最常用的两种方法是把加密的口令解密**和**通过信道窃取口令**。

例如，**普通用户可轻松取得 UNIX 操作系统加密的口令文件**，**使用解密程序对口令进行解密**，然后用它来**获取对系统的访问权**。

**另一层问题**：由于**一些 TCP 或 UDP 服务只能对主机地址进行认证，而不能对指定的用户进行认证**，所以，**即使一个服务器的管理员只信任某一主机的一个特定用户**，并希望授予该用户访问权，**也只能给使用该主机的（所有）用户访问权**。

**（2）监视未加密的传输口令**

用户使用 **Telnet 或 FTP** 连接其在远程主机上的账户，**在网络上传输的口令是没有加密的**，**入侵者可以通过监视携带用户名和口令的包获取它们**，然后**使用这些用户名和口令通过正常渠道登录到系统**。

**后果**：**如果被截获的是管理员的口令，那么获取特权级访问就变得轻而易举**。

**（3）IP 地址欺骗（五个步骤，必背）**

在 **TCP 或 UDP 协议**的通信过程中，**攻击者的主机可以冒充一个被信任的主机或客户**：

1. **攻击者要使用那个被信任的客户的 IP 地址取代自己的地址**；
2. **攻击者构造一条要攻击的服务器和其主机间的直接路径**，**把被信任的客户作为通向服务器的路径的最后节点**；
3. **攻击者用这条路径向服务器发出客户申请**；
4. **服务器接受客户申请，就好像是从可信任客户直接发出的一样**，然后**给可信任客户返回响应**；
5. **可信任客户使用这条路径将包向前传输给攻击者的主机**。

**五步的记忆**：**换地址 → 搭路径 → 发申请 → 服务器回给"真客户" → 真客户把包转给攻击者**。核心是**利用"基于 IP 地址的信任"**。

**（4）利用相互主机间的信任关系**

**主机的安全管理既困难又费时**，为了**降低管理难度并增强局域网安全性**，一些站点使用了诸如 **NIS 和 NFS** 之类的服务。这些服务**通过允许一些数据库（如口令文件）以分布式方式管理**以及**允许系统共享文件和数据**，在很大程度上**减轻了管理工作量**，但**这些服务带来了不安全因素**，**可以被有经验的闯入者利用以获得访问权**。

**连锁风险**：**如果一个中央服务器遭受到损失，那么其他信任该系统的系统会更容易遭受损害**。

**（5）系统配置过于复杂**

**主机系统的访问控制配置复杂且难于验证**，因此**偶然的配置错误会使闯入者获取访问权**。有些 **UNIX 用户会把 UNIX 操作系统配置成具有最大访问权的系统**，这将导致**未经许可的访问**。**许多人侵者可以通过开放的源代码，研究其中可利用的缺陷来侵入系统**。

**（6）对系统的安全性估计不足**

**没有对主机系统的安全性进行科学、合理的评估**。随着**一个网络中主机数量的增加**，**确保每台主机都处在高水平的安全性的能力却在下降**。如果**只用管理一台系统安全性的能力，来管理网络中如此多的系统就容易出错**；**另一因素是，系统管理的方式经常变换**，**一些系统的安全性比另一些要低，从而形成薄弱环节，降低了整个系统的安全性**。

**六条原因的记忆链**：**认证弱 → 口令明文 → IP 可冒充 → 信任被利用 → 配置太复杂 → 评估不到位**。前三条是**技术手段**，后三条是**管理问题**。
