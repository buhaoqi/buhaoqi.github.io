## 参考答案

### 一、填空题答案

| 题号 | 答案 |
|---|---|
| 1 | **集中式**网络管理模式；**分布式**网络管理模式 |
| 2 | **网络管理协议**；**网络管理平台（网管平台）**；**网络管理应用（网管应用）** |
| 3 | **攻击者（黑客）** |
| 4 | **读**；**写**；**执行** |
| 5 | **预防**；**检测**；**清除（消除）** |
| 6 | **数据备份**；**系统备份** |
| 7 | **数字签名** |
| 8 | **保密性**；**完整性**；**可用性**；**可控性**；**不可否认性** |
| 9 | **网络层**；**传输层** |

**逐题说明**：

- **第 1 题**：网络管理模式按管理信息的分布方式分为**集中式**（一个管理站管全网，简单但管理站是单点瓶颈）与**分布式**（多个管理站分担，灵活但协调复杂）。记忆法：**"一个大脑"与"多个大脑"**。
- **第 2 题**：教材体系下的标准答法是**协议 + 平台 + 应用**三层——协议负责"怎么问"（如 SNMP），平台负责"在哪问"（网管平台软件），应用负责"问完干什么"（拓扑发现、性能报表）。若你们教材采用另一种表述（**用户界面、管理功能、数据库**），以教师口径为准。
- **第 3 题（易错）**：安全扫描是**从攻击者的角度**看系统——它模拟黑客的探测手法，找出"能被利用的弱点"，所以结果带**风险视角**，而不是"合规视角"。
- **第 4 题**：选择性访问控制（DAC）对文件的访问类型一般就是**读、写、执行**三种基本操作；有的教材把"删除"单列，若题目给了 3 个空，按**读写执行**填。
- **第 5 题**：防病毒的三个环节构成一条链——**预防**（不让进来）→ **检测**（进来能发现）→ **清除**（发现能杀掉）。三者缺一不可。
- **第 6 题（易混）**：注意**"按用途"分两种**：**数据备份**（备份业务数据）与**系统备份**（备份整个操作系统与配置）。而按"备份数据的特点"分才是**完全备份、增量备份、系统备份**三种（任务一正文）。**两套分类不能混答**。
- **第 7 题**：防抵赖靠**数字签名**——用私钥签名后，签名者**无法否认**（因为只有他有私钥）。
- **第 8 题**：五大要素必须按顺序记熟：**保密性（C）、完整性（I）、可用性（A）、可控性、不可否认性**。
- **第 9 题**：包过滤防火墙检查的是**网络层 IP 首部**（源／目的 IP、协议号、TTL）与**传输层首部**（TCP／UDP 的源／目的端口、标志位），所以填**网络层和传输层**。**只填"网络层"会丢一个空**。

### 二、选择题答案与解析

**答案速查**：**C　C　C　B　B　C　D　D　C　A　C**

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **C** | **SNMP**（简单网络管理协议）是网络管理协议。A 的 **DES**、D 的 **RSA** 是**加密算法**，B 的 **UNIX** 是**操作系统**——三个都是"陪跑项" |
| 2 | **C** | 计算机网络安全**主要是指网络中信息的安全**。设备环境安全属**物理安全**，使用者安全与财产安全都不是网络安全的核心定义——项目一开头就点明"**本质是网络上的信息安全**" |
| 3 | **C** | 防"来自 Internet 的黑客入侵"，靠**边界访问控制**＝**防火墙**。A 网管软件只管监控不管拦截；B 邮件列表毫不相干；D 防病毒软件防的是**病毒**，不防黑客扫描与入侵 |
| 4 | **B** | 题干关键词"**标志通信双方身份信息的一系列数据**"＋"**验证身份**"＝**数字证书**。A、D 是"认证"这个**动作/过程**，C"电子证书"不是规范术语 |
| 5 | **B** | 防火墙**不保护存储数据的安全**——它只管**进出的流量**，管不到硬盘上的文件。A、C、D 都是防火墙的真实功能（过滤、封堵、记录日志） |
| 6 | **C** | 计算机病毒是**一段程序（代码）**，不是软件故障、不是硬件故障、更不是细菌。"**病毒**"只是比喻 |
| 7 | **D** | **数据完整性机制**防的是**数据被篡改或破坏**。A（假冒源地址）靠**鉴别/认证**；B（抵赖）靠**数字签名/公证**；C（窃听）靠**加密**。**四种攻击对应四种机制，一一对应别串** |
| 8 | **D** | 保密性（不让别人看懂）的**基础**是**加密机制**——不加密，完整性与签名都保不了密 |
| 9 | **C** | 题目问"**不包括**"。包过滤的真实局限是：**不能进行内容控制**（只看包头不看内容）、**规则制定复杂**、**不支持内外网地址转换**（NAT 要另外做）。而"**访问控制机制**"本身是**另一种安全机制的名称**，**根本不是"局限"**，所以选 C |
| 10 | **A** | **身份鉴别**＝**加密机制 + 数字签名机制**（加密保证传输中不被窃取，签名保证"确实是他发的"）。**注意**：教材此处选项印作"加密机制**的**数字签名机制"，从四个选项的排布看，"的"应为"**和**"（B、C、D 都是"××机制和××机制"的结构）。答题按 **A** |
| 11 | **C** | 题干关键词"**在网络层**""**根据数据包中包头信息**""**有选择地允许和阻断**"——这是**包过滤技术**的定义。A 应用网关看的是**应用层内容**；B 状态检测要**维护连接状态表**；D 代理服务器是**应用层中转** |

### 三、问答题参考答案

#### 第 1 题：什么是网络安全，主要包括几个方面的安全？

**定义**：网络安全是指**保护网络、设备和数据免遭未经授权的访问或使用**，从而确保信息的**机密性、完整性和可用性**；其**本质是网络上的信息安全**。

**四个方面**：

| 方面 | 内容 |
|---|---|
| **物理安全** | 防盗、防火、防水、防静电、防雷击、**防电磁泄漏**等，保护硬件与机房环境 |
| **逻辑安全** | **口令字、文件许可、查账**等，**防黑客主要靠逻辑安全** |
| **操作系统安全** | 操作系统**必须能区分用户**，并对其操作进行控制与审计 |
| **联网安全** | **访问控制服务**（谁能进、能访问什么）＋**通信安全服务**（传输中的保密与完整） |

#### 第 2 题：网络面临的安全威胁有哪几种？

**分法一（按对象）**：**对网络中信息的威胁**、**对网络中设备的威胁**。

**分法二（按成因，教材主线）**：

1. **人为的无意失误**——误操作、误删、配置不当、口令泄露；
2. **人为的恶意攻击**——又分**主动攻击**（破坏信息的**有效性与完整性**）和**被动攻击**（**截获、窃取、破译**，且**不影响网络正常工作**）。

**分法三（按手段细目）**：**系统漏洞、身份鉴别、线缆连接、有害程序**四组。

#### 第 3 题：网络系统本身存在哪些安全漏洞？

**四组细目**：

| 组别 | 具体漏洞 |
|---|---|
| **系统漏洞** | **乘虚而入**、**不安全服务**、**配置和初始化错误** |
| **身份鉴别** | **口令圈套**、**口令破解**、**算法考虑不周**、**编辑口令** |
| **线缆连接** | **窃听**、**拨号进入**、**冒名顶替** |
| **有害程序** | **病毒**、**代码炸弹**、**特洛伊木马**、**更新或下载** |

**一句话**：漏洞不只在技术里，**也在"人怎么配、口令怎么设、线怎么走"里**。

#### 第 4 题：计算机网络安全的基本要素有哪些？

**五大要素**：

1. **保密性**——信息不泄露给非授权者；
2. **完整性**——信息不被非法篡改、不丢失；
3. **可用性**——授权用户随时能用（**DoS 攻击破坏的正是可用性**）；
4. **可控性**——信息的内容与传播可被控制；
5. **不可否认性（不可抵赖性）**——事后不能否认做过的事。

#### 第 5 题：列举出网络安全的主要防护技术

**八种安全机制**：**加密机制、访问控制机制、数据完整性机制、数字签名机制、交换鉴别机制、公证机制、流量填充机制、路由控制机制**。

**四类工程手段**：

1. **防火墙**（边界访问控制）；
2. **防病毒系统**（主机／服务器两级）；
3. **数据备份与 RAID**（容灾恢复）；
4. **VPN 与加密传输**（远程接入的保密通道）。

**答题技巧**：先答**八种机制**（教材术语），再补**防火墙 + 防病毒 + 备份 + VPN**（工程手段）——两类都写上，才完整。

#### 第 6 题：对称加密算法与非对称加密算法的最大的区别是什么？

**最大区别**：**密钥个数与密钥的可推性**。

| 比较项 | 对称加密 | 非对称加密 |
|---|---|---|
| **密码个数** | **1 个** | **2 个**（公钥 + 私钥） |
| **算法对称性** | 对称，**解密密钥可从加密密钥推算出来** | 不对称，**解密密钥不能从加密密钥推算出来** |
| 速度 | **较快** | **较慢** |
| 主要用途 | **数据的加密和解密** | **数字签名、确认、鉴定、密钥管理、数字封装** |
| 典型算法 | DES、Triple-DES、RC2、RC4、IDEA、Skipjack | Diffie-Hellman、RSA、椭圆曲线加密 |

**为什么这个区别最关键**：对称加密的**分发密钥极其困难**（必须先把钥匙安全送到对方手里）；非对称加密的**公钥可以公开**，**天然解决了密钥分发问题**，代价是速度慢——**数字信封正是两者的折中**。

#### 第 7 题：网络访问控制方法有哪些？各有什么特点？

| 方法 | 特点 |
|---|---|
| **入网访问控制** | **第一道关卡**：控制**谁能登录**。三层——**用户名的识别与验证**、**用户口令的识别与验证**、**用户账号的缺省限制检查**；三次输入错误即**锁定账号** |
| **网络的权限控制** | 针对**用户和用户组**，规定其**可访问的目录与文件**。实现方式有**受托者指派**、**继承权限**、**属性控制** |
| **目录级安全控制** | 对**目录与文件**设置八种权限：**读、写、执行、删除、创建、查找、属性、授权（改权限）** |
| **属性安全控制** | 给文件／目录打**属性标记**（如只读、隐藏、系统、归档），**优先级高于权限**，用于**防止误删与越权修改** |
| **网络服务器安全控制** | 通过**服务器控制台**锁定、注销、监控，防止非法在服务器上操作 |
| **网络监测与锁定控制** | 记录**登录时间、地点、次数**，异常即**锁定并报警** |
| **网络端口与节点安全控制** | 用**防火墙、路由器 ACL** 控制**哪些端口／节点可通** |
| **防火墙控制** | 在**网络边界**实施统一的进出策略，是**最高层、最集中**的访问控制 |

**记忆线**：**进门（入网）→ 分权（权限）→ 细到文件（目录、属性）→ 守住机器（服务器、端口）→ 守住边界（防火墙）**。

#### 第 8 题：如何保证网络的物理安全？

六个层面：

1. **环境安全**——机房**防火、防水、防潮、防雷击、防静电、防尘**，控制**温度与湿度**，**防电磁泄漏**（屏蔽、干扰）；
2. **设备安全**——**防盗、防毁**，关键设备**冗余**（双电源、双机热备、UPS），**接地良好**；
3. **介质安全**——**存储介质分类管理、登记借阅、废弃介质彻底销毁**（消磁／物理破坏）；
4. **访问控制**——机房**门禁、身份验证、出入登记、分区授权**，重要区域**双人同在**；
5. **线路安全**——**线缆走线隐蔽、加金属管屏蔽**，防止**窃听与搭线**；重要链路**光纤化**；
6. **备份与恢复**——**异地备份**、定期**恢复演练**，保证灾害后能重建。

**为什么物理安全是基础**：**逻辑安全防的是"进来的人"，物理安全防的是"碰到机器的人"**——机器被人抱走，什么加密都白搭。

#### 第 9 题：什么是数字签名？请叙述数字签名的使用过程

**定义**：数字签名是**以电子形式存在于数据信息之中、或作为其附件、或与之有逻辑关联的数据**，用于**辨别数据签署人的身份**，并**表明签署人对数据信息中包含的信息的认可**。它要解决四个问题：**否认、伪造、冒充、篡改**。

**四个特性**：**可证实**、**不可否认**、**不可伪造**、**不可重用**。

**使用过程（六步）**：

1. 发送方对**原文**计算**信息摘要（Hash／数字指纹）**；
2. 发送方用自己的**私钥**对摘要加密，得到**数字签名**；
3. 把**原文 + 数字签名**一起发送（如需保密，再用**接收方公钥**加密）；
4. 接收方收到后，用**发送方的公钥**解密数字签名，得到**摘要 1**；
5. 接收方对收到的原文**重新计算摘要**，得到**摘要 2**；
6. **比对摘要 1 与摘要 2**：一致则说明**内容未被篡改、且确实是该私钥持有者所发**；不一致则**拒收并报警**。

**两句口诀**：**公钥加密、私钥解密＝保密；私钥加密、公钥解密＝签名**。

**为什么"加密摘要"而不是"加密全文"**：全文太长、非对称加密又慢；**摘要短且能唯一代表原文**，改一个字摘要就全变。

#### 第 10 题：什么是数字证书？请叙述数字证书的使用过程

**定义**：数字证书是**由权威的认证机构（CA）签发的、包含持有者身份信息与其公钥的电子文件**，相当于**网络上的身份证**。

**为什么需要它**：数字签名有个致命缺口——**公钥可能被调包**（攻击者把自己的公钥冒充成对方的）。数字证书就是用 **CA 的签名**给"公钥 + 身份"做背书。

**使用过程（五步）**：

1. **申请**：用户生成**密钥对**，把**公钥 + 身份材料**提交给 **CA**；
2. **审核签发**：CA 核验身份后，用自己的**私钥**对"公钥 + 身份 + 有效期"签名，形成**数字证书**发给用户；
3. **分发**：用户把证书随报文一起发送，或发布在公开目录中；
4. **验证**：接收方用 **CA 的公钥**验证证书上的签名——**验签通过即证明证书未被伪造、公钥确实属于该持有者**；
5. **使用**：从证书中取出**对方公钥**，用于**加密**或**验证数字签名**；同时检查**有效期与吊销列表（CRL）**。

**一句话**：**CA 给公钥签个字，公钥就"有了身份"**。

#### 第 11 题：什么是防火墙？防火墙分为哪几类？防火墙有哪些功能和特点？

**定义**：防火墙是一种**保障信息安全的设备或软件**，依照**特定的规则**，**允许或禁止**传输的数据通过；可以是**专门的硬件**，也可以是**运行在硬件上的软件**。

**四类（按实现方式）**：

| 类型 | 工作层次 | 原理 | 优缺点 |
|---|---|---|---|
| **包过滤防火墙** | **网络层、传输层** | 按**包头信息**（源／目的 IP、端口、协议）逐包比对规则 | 快、透明、便宜；**不能看内容**、规则复杂、**不支持 NAT** |
| **应用网关（代理）防火墙** | **应用层** | 为每种应用做**代理**，拆包看内容再转发 | **安全性高、能做内容控制与审计**；**慢**、每种应用都要单独代理 |
| **状态检测防火墙** | 传输层及以下 | 建立并维护**连接状态表**，按"连接"而非"单包"判断 | 比包过滤**更智能**、性能好；对**应用层攻击**仍无力 |
| **复合型防火墙** | 多层 | 上述多种技术**组合**（如包过滤 + 状态检测 + 应用代理） | **综合能力强**，配置复杂 |

**三大功能**：

1. **过滤进出网络的数据包**；
2. **封堵某些禁止的访问行为**；
3. **记录通过防火墙的信息内容和活动**（**日志与审计**）。

**特点（也是局限，考试常考"防火墙不能做什么"）**：

- **不能保护存储数据的安全**（管不到硬盘上的文件）；
- **不能防范病毒**（病毒藏在合法流量的内容里）；
- **不能防范来自内部的攻击**（内网互访不过边界）；
- **不能防范绕过防火墙的连接**（如拨号、私接热点）；
- 自身也可能成为**性能瓶颈与单点故障**。

#### 第 12 题：在组建 Intranet 时，应该如何设置防火墙？

**总体架构：两道防火墙、三个区域**（对应教材图 8-11）：

```text
Internet → 通用防火墙 → Extranet（Web/E-mail/FTP 服务器）→ 内部防火墙 → Intranet
```

**设置要点（七条）**：

1. **分区部署**——**外部防火墙**隔开 Internet 与 Extranet，**内部防火墙**隔开 Extranet 与 Intranet，**不把内部网直接暴露**在 Internet 上；
2. **默认拒绝**——策略基调是"**未明确允许的一律拒绝**"，而不是"未禁止的一律允许"；
3. **最小开放**——只放行**必需的服务与端口**（对外一般只开 **80／443、25、21** 等），其余全部关闭；
4. **建立 DMZ**——对外提供服务的服务器（Web、邮件、FTP）放在**Extranet（非军事区）**，**不放在内网**，被攻破也不影响内部数据；
5. **双向策略**——**入站**严格控制，**出站**也要限制（防内部主机被控后外联）；
6. **地址转换与隐藏**——用 **NAT** 隐藏内部地址结构；
7. **日志与审计 + 定期评审**——记录所有被拒绝与被允许的连接，**定期检查规则是否失效或过宽**。

**一句话**：**外紧内松、层层设卡；对外只开一扇窗，对内再设一道门**。

#### 第 13 题：什么是计算机病毒？网络病毒有哪些特点？简述网络病毒的防治措施

**定义**：计算机病毒是**编制者在计算机程序中插入的、破坏计算机功能或者数据安全的代码**，它**隐藏在计算机系统的信息资源中**，利用系统信息资源进行**繁殖并且生存**，能**影响计算机系统正常运行**，并借**存储介质、网络**等载体**传染**。

**网络病毒的四个特点**：

1. **传染方式多**——主机 → **服务器硬盘** → **共享目录或服务** → 其他主机；
2. **传播速度快**——借**网络通信机制与网络介质**迅速扩散，**指数增长**，可经**远程访问**瞬间传到千里之外；
3. **清除难度大**——**只要一台主机未消毒干净**，全网就会**重新被感染**，**仅对主机杀毒不能彻底解决**；
4. **破坏性强**——轻则**降低速度**，重则**网络瘫痪、破坏服务器资源、造成数据损失**。

**防治措施（两类 + 四项管理）**：

| 层面 | 措施 |
|---|---|
| **基于主机** | 装**单机反病毒软件／防病毒卡**；用**主机病毒防护芯片**（装在网卡 **Boot ROM 剩余空间**、插于 **EPROM 槽**） |
| **基于服务器** | **扫描范围广**、**实时在线扫描（24 小时、多线程）**、**定期集中扫描**、**自动报告与病毒存档**、**主机扫描**、**开放病毒特征接口实现自动升级** |
| **管理措施** | 及时**打补丁**、关闭**不必要共享与端口**、**不打开陌生附件**、**重要数据定期备份**、**全网同时杀毒** |

#### 第 14 题：什么是数据备份？说明热备份和数据备份的区别

**数据备份**：把**文件或数据库从原来存储的地方复制到其他地方**的过程，目的是在**设备故障或灾害**时保护数据，把破坏程度**减到最小**。

**区别对照**：

| 比较项 | **热备份** | **数据备份** |
|---|---|---|
| **本质** | **在线冗余**（RAID1、双机热备），**同一份数据同时存在两份** | **离线复制**（拷到磁带、另一块盘、异地） |
| **时机** | **系统运行中持续、实时**同步 | **按计划**（每天／每周）或**手动**执行 |
| **目的** | 防**硬件故障**，保证**业务不中断** | 防**误删、误改、病毒、灾害**，保证**能回到某个时间点** |
| **能防误删吗** | **不能**——删除会被同步到镜像，两份一起没了 | **能**——可以恢复到删除前的版本 |
| **恢复速度** | **快**（切换即可） | **慢**（要回拷数据，可能几小时） |
| **成本** | 高（**一倍存储**） | 低（磁带／压缩存储） |

**一句话**：**热备份保"不停机"，数据备份保"不丢数据"；两者互补，不能替代**。

#### 第 15 题：什么叫漏洞？漏洞与后门是一回事吗？

**漏洞**：系统在**硬件、软件、协议的具体实现或安全策略**上存在的**缺陷**，使攻击者**能够在未授权的情况下访问或破坏系统**。它通常是**无意造成的**（设计疏漏、编码错误、配置不当）。

**不是一回事**。区别如下：

| 比较项 | **漏洞** | **后门** |
|---|---|---|
| **成因** | **无意**（设计／实现／配置缺陷） | **有意**（人为预留的入口） |
| **谁留下的** | 开发者、管理员**都不希望有** | **开发者、厂商或攻击者故意留下** |
| **发现方式** | 靠**扫描、审计、补丁公告**发现 | 往往**极隐蔽**，常规扫描难以发现 |
| **处置方式** | **打补丁、改配置**即可修补 | 需**清除代码／重装系统**，常常只能重装 |
| **关系** | 漏洞**可被利用来植入后门** | 后门**常常通过漏洞植入** |

**结论**：**漏洞是"墙上的裂缝"，后门是"自己开的暗门"**——成因不同、处置不同，**不能混为一谈**。

#### 第 16 题：可用于数字签名的加密机制是单钥体制还是双钥体制？为什么？

**答案：双钥体制（非对称加密／公钥密码体制）。**

**三条理由**：

1. **签名的本质是"只有我能做、谁都能验"**——这正好对应**私钥签名、公钥验证**。单钥体制中双方共用一把钥匙，**谁都能生成同样的签名**，无法判断是谁签的。
2. **不可否认性要求密钥专属**——私钥**只有签名者本人持有**，所以签了**无法抵赖**；单钥体制下**双方都能签**，出了纠纷**无法仲裁**。
3. **可验证性要求验证方不需要秘密**——公钥可以**公开分发**，任何人都能验证；单钥体制要求验证者**也持有密钥**，等于把签名能力也给了他。

**一句话**：**单钥只能"证明是我们俩之一"，双钥才能"证明就是你"**。

#### 第 17 题：怎样可以防止抵赖和鉴别文档是否被修改？

**四项技术组合**：

1. **数字签名**——发送方用**私钥**对摘要签名，**防抵赖**（只有他能签）＋**防冒充**；
2. **信息摘要（Hash）**——对文档计算**数字指纹**，**文档改一个字节，摘要就完全不同**，从而**鉴别是否被修改**；
3. **数字证书（CA 背书）**——保证**验证用的公钥确实属于声称的发送者**，堵住"公钥调包"的漏洞；
4. **时间戳与第三方公证**——由**可信第三方**记录"**何时**收到、内容是什么"，解决"**事后否认收到**"与**时间先后争议**。

**完整链条**：**算摘要 → 私钥签名 → 附证书发送 → 对方用 CA 验证书 → 用公钥验签 → 重算摘要比对 → 第三方存证**。

#### 第 18 题：网络黑客的非法攻击分为几类？其攻击技术的原理是什么？

**分类一（按是否改变数据流，最常考）**：

| 类别 | 手段 | 特点 |
|---|---|---|
| **被动攻击** | **截获／窃听、流量分析** | **不修改数据、不影响网络正常工作**，**极难发现**，防的重点是**加密** |
| **主动攻击** | **中断（拒绝服务）、篡改、伪造** | **破坏信息的有效性与完整性**，**容易被发现**，防的重点是**鉴别与完整性校验** |

**分类二（按目的）**：**获取口令、获取数据、获取超级用户权限、拒绝服务（DoS）、控制中间站点**。

**原理（三条根源）**：

1. **利用系统漏洞**——协议设计缺陷、软件实现错误、**补丁未打**；
2. **利用配置与管理缺陷**——**弱口令、默认账号、开放多余端口与服务、信任关系过宽**；
3. **利用"人"的弱点**——**口令圈套（钓鱼）、社会工程、木马诱骗**。

**共同逻辑**：**绕过或突破系统的安全措施 → 取得访问权 → 提权 → 驻留（后门）→ 横向扩散**。

#### 第 19 题：黑客攻击通常分为哪几个阶段？实际中如何发现有黑客在进行网络监听？

**三个阶段**：

1. **确定目标**——选定有价值的站点、ISP 或敌对宣传站点；可借 **DNS** 查机器名、IP、机器类型与隶属单位；
2. **搜集信息并找出安全漏洞**——用 **SNMP、TraceRoute、Whois、DNS、Finger、Ping** 六种公开工具侦察；再用**自编程序（利用补丁接口）**或**公开扫描工具（ISS、SATAN）**找漏洞；
3. **实施攻击**——**清除痕迹并留后门、安装探测软件（含木马）窥探账号口令、借信任关系横向扩散、窃取或毁坏数据**。

**发现网络监听的六种迹象**：

1. **网卡处于混杂模式**——`ipconfig /all` 或 `ifconfig` 查看是否被置为 **promiscuous**，这是最直接的证据；
2. **网络流量异常增大**——尤其是**与业务无关的持续上行流量**；
3. **网络时延明显变大、带宽被占用**——因为监听程序要复制所有包；
4. **DNS 反向解析异常**——大量地址解析不到主机名，说明有陌生设备接入；
5. **交换机的 MAC 地址表／ARP 表出现异常**——同一 MAC 对应多个端口、ARP 冲突；
6. **IDS／防火墙日志告警**——出现**端口扫描、ARP 欺骗、异常登录**记录。

**处置**：**隔离该主机 → 抓包取证 → 查进程与启动项 → 改口令 → 重装或彻底清除 → 复查全网**。

#### 第 20 题：我国关于网络安全的法律法规主要有哪些？

| 层级 | 法律法规 | 要点 |
|---|---|---|
| **法律** | **《中华人民共和国网络安全法》** | **2016.11.7 发布，2017.6.1 施行**；确立**网络空间主权**、**等级保护**、**关键信息基础设施保护**、**实名制**等制度 |
| **法律** | **《中华人民共和国数据安全法》** | 数据分类分级保护、重要数据出境安全评估 |
| **法律** | **《中华人民共和国个人信息保护法》** | 处理个人信息的**合法、正当、必要**原则与**告知同意**规则 |
| **法律** | **《中华人民共和国密码法》** | 密码的分类管理（核心、普通、商用密码） |
| **法律** | **《中华人民共和国刑法》**（第 285～287 条） | 非法侵入计算机信息系统罪、破坏计算机信息系统罪等 |
| **行政法规** | **《网络安全等级保护条例》** | **2018.6.27 公安部发布**；适用范围**不含个人及家庭自用**；分**五个安全保护等级** |
| **行政法规** | 《计算机信息系统安全保护条例》 | 我国计算机安全保护的基础性行政法规 |
| **部门规章** | 《计算机信息网络国际联网安全保护管理办法》 | 国际联网的安全管理 |
| **相关** | 《治安管理处罚法》 | 对尚不构成犯罪的网络违法行为予以处罚 |

**三条基本原则（《网络安全法》）**：**网络空间主权原则、网络安全与信息化发展并重原则、共同治理原则**。

**记忆法**：**"三法一条例"打底（网络安全法、数据安全法、个人信息保护法 + 等级保护条例），刑法兜底，规章补细节**。
