## 知识点

### 1.任务描述：什么是计算机病毒

**计算机病毒（Computer Virus）**是**编制者**在计算机程序中**插入的**、**破坏计算机功能或者数据安全**的代码，它**隐藏在计算机系统的信息资源中**，利用系统信息资源进行**繁殖并且生存**，**能影响计算机系统正常运行**，并**存储介质、网络等载体**进行**传染**。

**把定义拆成五个要素**：

| 要素 | 内容 |
|---|---|
| **谁做的** | 人（**编制者**）编写 |
| **是什么** | 一段**代码**（程序），不是硬件故障 |
| **藏在哪里** | **隐藏在**计算机系统的**信息资源**中 |
| **怎么活** | 利用系统信息资源**繁殖并生存** |
| **造成什么** | 破坏功能或数据、影响正常运行，并借**存储介质、网络**传染 |

**本任务两块内容**：**网络病毒的特点** → **网络病毒的防治**。

### 2.网络病毒与单机病毒的关系

**前提（教材因果句）**：**计算机网络系统的建立使多台计算机能够共享数据资料和外部资源**，然而**也给计算机病毒带来了更为有利的生存和传播环境**。

**关键结论**：在**网络环境下**，病毒可以按**指数增长模式**进行传染。病毒一旦侵入计算机网络，会导致：

1. 计算机**性能急剧下降**；
2. **系统资源**遭到严重破坏；
3. **短时间内**造成网络系统的**瘫痪**。

**所以**：网络病毒**除具有单机病毒的特点外**，还具有以下**四个特点**。也就是说，**四个特点是"网络带来的增量"，不是全部特点**——问答题里若问"网络病毒有哪些特点"，答这四条即可。

### 3.网络病毒的四个特点（本节重点）

#### （1）传染方式多

病毒入侵网络系统的**主要途径**是：通过**主机**传播到**服务器硬盘**，再由服务器的**共享目录或服务**传播到**其他主机**。

**路径图**：**某台主机 → 服务器硬盘 → 共享目录／服务 → 其他主机**。

**为什么"多"**：单机只能靠**软盘、U 盘、文件拷贝**；网络中多了**共享目录、网络服务、邮件、下载**等通道，入口成倍增加。

#### （2）传播速度快

在网络中，病毒可通过**网络通信机制**，借助于**网络介质**迅速扩散。由于传播速度非常快，其**扩散范围很大**——不但能**迅速传染局域网内所有计算机**，还能通过**远程访问**将病毒**瞬间传播到千里之外**。

**对比记忆**：单机病毒的传播速度取决于**人的操作**；网络病毒的传播速度取决于**网络带宽**。

#### （3）清除难度大

- **单机上**：再顽固的病毒也可通过**删除带毒文件、重装硬盘**等措施**完全清除**；
- **网络中**：只要**有一台主机未消毒干净**，就可使**整个网络全部重新被感染**；甚至**刚刚完成消毒工作的一台主机**也可能被**网上另一台主机的带毒程序**所传染。

**结论（教材原句）**：因此，**仅对主机进行杀毒处理并不能彻底解决网络病毒问题**。

**这句话是本节的核心考点**：网络杀毒必须**全网同时进行**，单机杀毒等于没杀。

#### （4）破坏性强

网络病毒将**直接影响网络的正常使用及功能提供**：**轻则降低速度、影响工作效率**，**重则造成网络系统的瘫痪、破坏服务器系统资源、造成数据损失**。

### 4.网络病毒防治的两大类方法

**总纲**：网络病毒的防治方法主要分为**基于主机**和**基于服务器**两种。

| 方法 | 防的是谁 | 一句话理由 |
|---|---|---|
| **基于主机** | 每一台**客户机（主机）** | **主机是网络的门户**，把门关好就能有效防止病毒入侵 |
| **基于服务器** | **服务器** | **服务器是网络的核心**，一旦被感染会导致整个网络瘫痪 |

**记忆**：**主机防"进门"，服务器防"心脏"**。

### 5.基于主机的防治方法

#### （1）单机反病毒手段照样有用

**原理**：**主机是网络的门户**，只要把这扇门关好，就能**有效地防止病毒的入侵**。

**手段**：**单机反病毒软件、防病毒卡**等，同样可保护**主机内存和硬盘**的清洁。

**结论**：这些手段在网络反病毒战中**仍然大有用武之地**，在一定程度上**可以有效阻止病毒在网络中的传播**。

#### （2）主机病毒防护芯片（硬件思路）

**为什么另想一招**：由于受**硬件防毒技术**的影响，反病毒专家推出了另一种基于主机的病毒防治方法——**主机病毒防护芯片**。

**做法**：将**防病毒功能集成在一个芯片上**，安装于**网络主机**，以便**经常性地保护主机及其通往服务器的途径**。

**基本原理（逻辑链）**：

1. 网络上的**每台主机都要求安装网络接口卡**；
2. 网络接口上有一个 **Boot ROM 芯片**；
3. 多数网卡的 **Boot ROM 并没有充分利用，都会剩余一些使用空间**；
4. 所以如果**防毒程序够小**，就可以**安装在 Boot ROM 的剩余空间内**，而**不必另插一块芯片**；
5. 这样就把**主机存取控制与病毒保护能力合二为一**地插在网卡的 **EPROM 槽**内，用户可以**免去许多烦琐的管理工作**。

**记忆点**：**Boot ROM 装"引导"，剩余空间装"防毒"；插在 EPROM 槽里，一块芯片两件事**。

### 6.基于服务器的防治方法

**为什么必须防服务器**：**服务器是网络的核心**，一旦服务器被病毒感染，就会使**服务器无法启动**，**整个网络陷于瘫痪**，造成**灾难性后果**。

**技术名称**：基于网络服务器的**实时扫描病毒**的防护技术，一般具有以下**六项功能**。

#### ① 扫描范围广

采用此技术，可**随时对服务器中的所有文件实施扫描**，并且可对**所有文件集中检查**是否带毒。若有带毒文件，则向网络管理员提供**几种处理方法**：允许用户**清除病毒**，或**删除带毒文件**，或**更改带毒文件名成为不可执行文件**，并**隔离到一个特定的病毒文件目录**。

**四个动作记法**：**清除 → 删除 → 改名（不可执行）→ 隔离**。

#### ② 实时在线扫描

必须保持**全天 24 小时监控**网络中是否有带毒文件进入服务器。为了保证病毒监测的**实时性**，通常采用**多线程**的设计方法，让检测程序作为一个**随时可以激活的功能模块**。实时在线扫描能**及时追踪病毒的活动**，**及时报告**网络管理人员和主机用户。

#### ③ 服务器扫描选择

该功能允许网络管理员**定期检查**服务器中是否带毒，例如可按**每月、每星期、每天**集中扫描一下网络服务器，这样**网络用户拥有极大的操作选择余地**。

#### ④ 自动报告功能及病毒存档

当网络用户将带毒文件**有意或无意**拷入服务器中时，网络防病毒系统必须**立即通知网络管理员**，同时**记入档案**。

**病毒档案一般包括**：**病毒类型、病毒名称、带毒文件所存的目录、主机标识**等；另外还要**登记对病毒的处理方法**。

**五个字段记法**：**类型 → 名称 → 目录 → 主机 → 处理法**。

#### ⑤ 主机扫描

**问题**：基于服务器的防病毒软件**不能保护本地主机硬盘**。

**补法**：可以在**服务器上安装防毒软件**，同时在**网上主机内存中调入一个常驻扫描程序**，**实时检测在主机运行的程序**。

#### ⑥ 对用户开放的病毒特征接口

**目的**：使防病毒系统能**对付不断出现的新病毒**，就要求杀毒软件具有**自动升级**功能，其典型做法是**开放病毒特征数据库**。

**做法**：用户随时将遇到的带毒文件，经过**病毒特征分析程序**，**自动将病毒特征加入特征库**，以随时增强抗毒能力。

**为什么需要**：病毒是**不断出现的新病毒**，特征库**不更新就防不住**——所以"开放接口"本质上是**众包升级**。

### 7.基于服务器防治方法的优点

教材给出**五项**：

1. **不占用主机的内存**；
2. 可以**集中扫毒**；
3. 能实现**实时扫描**功能；
4. **软件安装和升级都方便**；
5. **特别是如果联网计算机很多**，用这种方法比**为每台主机都安装防病毒产品要节省成本**。

**一句话总结**：**集中管、不占内存、省钱**。

### 8.两种防治方法对比表

| 比较项 | 基于主机 | 基于服务器 |
|---|---|---|
| **防护对象** | 每台主机（客户机） | 服务器 |
| **核心理由** | 主机是网络的**门户** | 服务器是网络的**核心** |
| **典型手段** | 单机反病毒软件、防病毒卡、主机病毒防护芯片（Boot ROM） | 实时扫描服务器、集中扫毒、病毒存档、特征库升级 |
| **优点** | 保住入口、可离线防护 | 不占主机内存、集中管理、升级方便、规模化省钱 |
| **不足** | **不能保护本地主机硬盘**（服务器方案的缺口）／单机方案保护不了全网 | 保护不了本地主机硬盘（需配主机扫描程序弥补） |
| **结论** | 两者**互补**，不能只做一头 | 两者**互补**，不能只做一头 |
