任务二 网络拓扑结构

知识点​

一、基础概念​

  1. 什么是拓扑学？它与计算机网络有什么关系？ 答：拓扑学是几何学分支，由图论演变而来；把实体抽象成无关大小形状的点，连接线路抽象成线，研究点线面关系。计算机网络设计借用了这一思想。

拓扑学是研究事物之间的关系的学科。在研究关系时，忽略事物的大小、形状、距离。只关注关系。

计算机拓扑学：将网络设备抽象为点，将通信线路抽象为线，研究网络中各实体之间的结构关系。

  1. 什么是计算机网络拓扑结构？ 答：不考虑地理位置，将网络中的计算机、网络设备抽象为节点，通信线路抽象为连线，由点、线构成的几何图形，用来表示网络各实体之间的连接关系。

  2. 网络拓扑结构能反映什么？ 答：反映网络中各实体之间的结构关系。

  3. 网络拓扑结构在网络设计中的作用，为什么说它是网络设计第一步？ 答：①需要确定网络设备的位置；②拓扑直接决定网络性能、系统可靠性、通信费用与建设投资；③是实现各类网络协议的基础。

二、局域网拓扑分类​

  1. 局域网的拓扑结构主要有哪些？还有哪些其他拓扑？ 答：局域网主要三种：星型、总线型、环型；另外还有混合拓扑、蜂窝拓扑结构。

主要有三种：

  • 星型：一个中心节点，若干个直接连接中心节点的其他节点
    • 中心节点：集线器或交换机
    • 特点：集中控制型网络
    • 传输介质：双绞线或光纤
  • 总线型：所有节点连接到总线（主干电缆）
    • 传输介质：同轴电缆或光缆
    • 特点：1. 没有中心节点 2. 串行传递、两端扩散（广播式网络）
  • 环型拓扑结构：所有节点通过点到点首尾相连，形成一个闭环。
    • 传输材质：公共传输电缆
    • 特点：沿环型节点传输
    • 典型局域网的拓扑结构主要有哪些？：令牌网

三、星型拓扑结构​

  1. 什么是星型拓扑结构？中心节点可以是什么设备？ 答：以一个节点作为中心节点，其余所有节点直接和中心节点相连。中心节点可以是文件服务器、集线器、交换机等连接设备。

  2. 星型拓扑的控制方式是什么？节点之间如何通信？ 答：属于集中控制型网络，由中心节点统一管理。节点通信都要经过中心节点：发送方先发给中心节点，再由中心节点转发给目标节点；中心节点负担重，外围节点通信处理简单。

  3. 星型拓扑的优点 答：①控制简单，便于监控管理；②故障诊断与隔离容易，单点故障仅影响单个设备，不影响全网；③方便提供网络服务，便于网络重新配置。

  4. 星型拓扑的缺点 答：①需要大量电缆，安装维护工作量大；②中心节点容易形成性能瓶颈，一旦故障，全网瘫痪。

  5. 目前应用最广泛的局域网拓扑是哪一种？原因是什么？ 答：星型拓扑。原因：结构简单、便于管理、建网容易；使用双绞线/光纤，符合综合布线标准，能满足多种带宽需求；故障隔离简单，方便运维与网络调整。

四、总线型拓扑结构​

  1. 什么是总线型拓扑结构？总线一般使用什么传输介质？ 答：所有节点直接连接到一条主干电缆（总线），无中心节点；介质常用同轴电缆（粗缆、细缆）或光缆。

  2. 为什么总线型网络称为广播式网络？信息如何传递？ 答：信息以基带形式串行传输，从发送节点向总线两端扩散，类似广播。各节点收到信息后校验地址，只有地址匹配的节点才接收数据。

  3. 总线型拓扑结构特点 答：①无需额外互联设备，组网成本低；②节点共享总线带宽，用户越多传输速度越低；③扩展灵活，但可接入节点数量有限；④单个节点故障不影响全网；总线主干一旦断裂，网络瘫痪，主干故障排查困难；⑤同一时刻只允许一个节点发送数据，其余节点等待获取发送权。

五、环型拓扑结构​

  1. 什么是环型拓扑结构？ 答：各节点通过点到点链路首尾相连，形成闭合环路；数据沿固定单向方向，在环路各节点之间依次传输。

  2. 环型拓扑适用什么网络？什么是令牌？ 答：多用于IEEE 802.5令牌环网。令牌是一个数据帧，包含控制信息、数据信息；控制信息包含源地址、目标地址、忙/闲状态，用来控制节点的数据发送权限，令牌在环上依次传递。

  3. 环型拓扑结构特点 答：①组网简单、投资省，无需交换机/集线器等集中设备；②维护困难，任意节点故障就会造成全网中断，故障查找难度大；③扩展性差，增删节点需要中断整个网络；④数据单向流动，两点之间仅有一条路径，路径选择逻辑简单；⑤节点过多时，串行转发会降低传输速率，网络响应变慢。

六、混合拓扑、蜂窝拓扑​

  1. 什么是混合拓扑结构？有什么特点？ 答：由多种拓扑组合而成（例如星型+总线型），可以兼顾不同拓扑结构各自的优点。

  2. 什么是蜂窝拓扑结构？特点与适用场景？ 答：无线局域网常用拓扑，以微波、卫星、红外等无线介质进行点到点/多点传输；每个蜂窝中心部署无线收发设备；适用于无线局域网、城域网。

  • 蜂窝拓扑结构是指网络节点按照蜂窝状结构排列形成的网络结构。
  • 特点：①属于无线拓扑结构 ②点到点传输 或 多点传输 ③无线传输介质（微波、卫星、红外）

七、任务实施​

  1. 本任务（网络拓扑结构）实施步骤 答：①打开计算机，使用关键词“计算机网络的拓扑结构”搜索资料；②整理分析搜索结果，总结各类拓扑结构特点；③确定应用最广泛的拓扑，从连接、维护等角度分析其普及原因。
