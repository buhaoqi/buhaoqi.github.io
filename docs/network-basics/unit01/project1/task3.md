### 一、移动互联网

1. **问答题：什么是移动互联网？** 

移动互联网是移动通信和互联网融合的产物。

- 运营商提供：无线接入
- 互联网企业提供：Application

特点：移动、分享

2. **问答题：列举移动互联网典型的业务与应用。** 

- 浏览网页
- 浏览视频
- 下载文件
- 位置服务
- 在线游戏

3. **问答题：简述移动互联网的5个发展特征。** 

特征 1：潮流：引领新潮流，超越 PC 互联网

特征 2：新模式：移动互联网和传统行业融合，催生新的应用模式

特征 3：用户体验：不同终端的用户体验更受重视

特征 4：多样化：移动互联网商业模式多样化

特征 5：跨平台：跨平台互通互联是当前技术突破的重点


4. **问答题：移动互联网相比传统PC互联网，终端设备发生了什么变化？** 答：PC只是互联网终端之一，智能手机、平板、阅读器、电视、车载设备、家电、穿戴设备都可以成为网络终端。
5. **问答题：移动互联网与传统行业融合带来哪两方面改变？** 答：一方面作为业务推广手段，打造行业APP与推广平台；另一方面重构移动端业务模式，改造医疗、教育、旅游、交通、传媒等行业。
6. **问答题：为什么跨平台互通互联是移动互联网的发展趋势？** 

- 部署方便
- 成本低
- 使用灵活
- 扩展性强

### 二、无线网络

1. **问答题：什么是无线网络？** 答：无线网络依靠无线设备发射无线电波，在无线客户端和网络之间完成数据传输，是灵活的传输系统，可以实现随时随地联网。
2. **问答题：无线网络的4点技术优势是什么？** 答：①部署方便，无需网线，部署灵活机动性强；②成本低廉，省去布线、穿墙等工程成本；③使用灵活，信号覆盖广，不受上网区域限制；④扩展性强，可增加无线AP扩大覆盖范围。
3. **问答题：无线网络的3个发展趋势是什么？** 答：①实现接入灵活性，随时随地在办公室、家庭、公共区域上网；②强化无线网络的安全防护能力；③无线网络和有线网络相互融合配合工作。
4. **问答题：无线网络为什么不能完全取代有线网络？** 答：无线网络在数据传输速率、网络安全性上存在劣势，未来会和有线网络配合使用，不会完全替代有线网络。

### 三、物联网技术

1. **问答题：什么是物联网？** 答：物联网借助传感器、射频识别RFID、GPS、红外感应器等传感设备，采集物体声光热、力学、位置等信息，和互联网结合形成巨型网络，实现物与物、物与人的信息交互，无需人工干预。
2. **问答题：物联网的三大特征是什么？** 答： ①广泛应用各类感知技术，海量传感器实时周期性采集更新环境数据； ②建立在互联网之上的泛在网络，依靠有线、无线网络传输海量感知数据； ③具备智能处理能力，结合云计算、模式识别对海量数据加工分析，实现智能控制。
3. **问答题：物联网的核心和基础是什么？** 答：物联网最重要的基础与核心仍然是互联网。

### 四、云服务技术

1. **问答题：云服务包含哪两大核心部分？** 答：云存储、云计算。
2. **问答题：简述什么是云存储？** 答：云存储依靠集群、网格、分布式文件系统，整合网络中大量存储设备协同工作，对外统一提供数据存储与访问服务；用户可以在任意时间、地点，使用联网设备存取数据，保障数据安全、节省存储空间。
3. **问答题：什么是云计算？** 答：云计算是基于互联网的计算新模式，通过互联网提供虚拟化、可动态扩展的IT资源；用户不用了解底层硬件细节，按需获取、付费使用计算资源，类似水电取用模式。
4. **问答题：云计算的基础架构由哪三部分组成？** 答：计算（服务器）、网络、存储。

### 五、大数据技术

1. **问答题：什么是大数据技术？** 答：大数据技术指从海量的数据资源中提取有价值的数据，完成分析与处理的技术。
2. **问答题：大数据的4V特征分别是什么？分别解释含义。** 答： ①Volume（数据量大）：采集、存储、计算的数据体量巨大，计量单位为P、E、Z； ②Variety（类型繁多）：数据来源格式多样，包含结构化、半结构化、非结构化数据（视频、图片、日志、定位信息等）； ③Value（价值密度低）：数据总量庞大，但有效价值占比很小，需要算法挖掘有效信息； ④Velocity（速度快、时效高）：数据产生、处理速度快，对实时性要求很高。
3. **问答题：简述大数据技术的4个发展趋势。** 答： ①数据分析成为大数据技术的核心； ②广泛采用实时性的数据处理方式； ③基于云的数据分析平台更加完善，云计算为大数据提供算力与存储支撑； ④开源软件成为推动大数据发展的新动力，开源与商业软件优势互补。
4. **问答题：为什么大数据需要实时的数据处理方式？** 答：在线推荐、股票交易、实时路况等场景要求秒级数据处理；传统批量、小时级的数据处理方式无法满足高时效性业务需求。
