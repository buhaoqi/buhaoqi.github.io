项目一 网络发展与基本概念

知识点​

一、计算机网络基础概念​

  1. 计算机网络是什么？ 答：计算机网络是计算机技术与通信技术紧密结合的产物，综合计算机与通信新技术。

  2. 世界第一台电子数字计算机叫什么？哪年在哪诞生？ 答：ENIAC，1946年，美国。

  3. 计算机网络一共经历几代发展？ 答：5代。

  4. 写出计算机网络5个发展阶段名称。 答： ①第一代：以单机为中心（面向终端）的通信系统 ②第二代：多个计算机互联的计算机网络 ③第三代：以OSI为核心的国际标准化计算机网络 ④第四代：高速和多媒体应用为核心的计算机网络 ⑤第五代：移动互联、物联应用为特征的计算机网络

二、第一代计算机网络（面向终端）​

  1. 第一代计算机网络又称什么网络？ 答：面向终端的计算机网络，以单机为中心的通信系统。

  2. 第一代网络里，终端Terminal有没有自主处理能力？ 答：终端不具备自主处理功能，系统只有一台主机HOST。

  3. 第一代面向终端网络3种结构分别是什么？ 答： ①终端直接和主机通信线路相连 ②多个终端共享一条通信线路 ③增加前端处理机FEP/CCP、集中器的结构

  4. 第一代网络中，当多个终端共享线路，主机负担变重，用什么设备减轻主机负担？ 答：前端处理机FEP（通信控制处理机CCP）、集中器。

  5. 前端处理机FEP的作用？ 答：专门负责通信控制；主机只负责数据处理。

  6. 集中器的作用？ 答：设在远程终端处，实现多个终端共享同一条通信线路。

  7. 远距离通信，第一代网络借助什么公共网络+什么设备传输？ 答：公共交换电话网PSTN，调制解调器Modem。

  8. 第一代计算机网络典型实例是什么？ 答：20世纪60年代初美国航空公司与IBM联合研制飞机订票系统；一台主机+2000多个终端。

  9. 第一代网络用户共享什么资源？ 答：只能共享一台主机里面软硬件资源。

三、第二代计算机网络（多机互联）​

  1. 第二代计算机网络时间？典型代表网络名称？英文缩写？ 答：20世纪60年代末；ARPANET（高级研究计划局网络）。

  2. 第二代网络主机之间主从关系吗？ 答：没有主从关系。

  3. 第二代网络也叫什么系统？ 答：共享系统资源计算机网络。

  4. 第二代网络用户可以共享哪些资源？ 答：共享整个资源子网全部软硬件资源。

  5. ARPANET三大贡献是什么？ 答： ①两级网络结构：资源子网 + 通信子网 ②报文分组交换方式 ③层次结构的网络协议

  6. 什么是通信子网？由什么设备组成？功能？ 答：IMP（接口报文处理机）构成；负责全网全部通信工作。

  7. 什么是资源子网？由哪些部分组成？ 答：主机HOST、各类终端T、主机与终端上软件、数据库；负责数据处理、提供资源。

  8. IMP中文名称？ 答：接口报文处理机。

四、第三代计算机网络（国际标准化）​

  1. 第三代计算机网络特点？ 答：统一网络体系结构，遵循国际标准化协议，实现不同网络互联。

  2. 第二代网络存在什么缺点促使标准化出现？ 答：各个厂商各自开发产品，标准不统一，设备之间不能互通，标准转换困难，阻碍网络普及。

  3. ISO哪一年发布OSI/RM？中文全称？ 答：1980年；开放系统互联参考模型。

  4. OSI/RM作用？ 答：世界网络体系公共标准，方便实现不同网络互联。

ISO：国际标准化组织

五、第四代计算机网络​

  1. 第四代计算机网络时间范围？ 答：20世纪90年代中期～21世纪初期。

  2. 第四代计算机网络核心特点？ 答：全面互联、高速、智能化；高速大容量综合性数字信息传递。

  3. 第四代网络以哪些技术为基础？ 答：千兆交换以太网、ATM、帧中继、波分多路复用。

六、第五代计算机网络​

  1. 第五代计算机网络特征？ 答：移动互联、物联网应用；移动通信网+互联网融合。

  2. 第五代网络目标连接规模？ 答：全球50亿互联网移动用户，500亿物联网设备互联。

  3. 第五代网络两大技术融合是什么？ 答：移动互联网与物联网。

七、拓展概念（课本知识目标）​

  1. 计算机网络两大子网名称：通信子网、资源子网。各自作用？ 答： 通信子网：负责全网通信传输； 资源子网：负责数据处理，向用户提供软硬件资源。

  2. 资源共享含义：网络用户可以使用网络中其他计算机的硬件、软件、数据资源。

  3. 计算机网络协议是什么：网络中设备通信必须共同遵守的一套规则。

  4. 移动互联网是什么：互联网与移动通信网相互融合形成网络。

  5. 物联网：物物相连，大量物理设备接入网络。

  6. 云计算、云存储：网络提供存储、计算服务，本地不用高性能硬件。

八、实操任务类简答（考试也会考）​

  1. 从资源共享角度简述计算机网络五代发展，资源共享如何变化？ 答： 第一代：只能共享单台主机资源； 第二代：可以共享整个资源子网全部主机资源； 第三~五代：标准化、高速、万物互联，资源共享范围扩大到全网、云端、物联网设备。

  2. 双绞线、无线路由器属于哪一类网络硬件？ 答：通信子网的网络传输、互联设备。

四、简答题​

  1. 简述ARPANET的三项主要技术贡献。 答： ①采用资源子网、通信子网两级网络结构； ②采用报文分组交换方式； ③采用层次结构的网络协议。

  2. 写出计算机网络5代发展阶段完整名称。 答： ①第一代：以单机为中心的通信系统（面向终端的计算机网络） ②第二代：多个计算机互联的计算机网络 ③第三代：以OSI为核心的国际标准化计算机网络 ④第四代：以高速和多媒体应用为核心的计算机网络 ⑤第五代：以移动互联、物联应用为特征的计算机网络

  3. 通信子网和资源子网各自功能是什么？ 答： 通信子网：负责全网全部通信、数据转发工作。 资源子网：负责数据处理，向用户提供硬件、软件、数据库等各类资源。
