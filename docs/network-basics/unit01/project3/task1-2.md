## 知识点
### 1. 同轴电缆是什么

- 是一种有线传输介质
- 结构：一根铜线 + 三个保护层
  - 内导体：铜线
  - 绝缘层：泡沫塑料
  - 屏蔽层：金属
  - 绝缘层：塑胶

### 2. 为什么叫同轴电缆

内导体和保护层共用一根轴线

### 3. 同轴电缆的主要特点

- 抗干扰能力强
- 传输距离远
- 传输速率低
- 不易维护管理

### 4. 使用同轴电缆组网的拓扑结构是什么

总线形拓扑结构

### 5.为什么现在组网很少使用同轴电缆

- 传输速率低
- 不易维护管理

### 6. 同轴电缆的分类

- 细缆：阻抗 50Ω  传输距离：185m  速率：10Mb/s
- 粗缆：阻抗 50Ω 传输距离：500m

### 7. 光纤是什么

是一种利用光信号传输信息的有线传输介质。

### 8. 光缆是什么

- 光缆是一条或多条光纤组成的有线传输介质。（多可达数百条光纤）

### 9. 多模光纤的结构是什么

- 纤芯
- 包层
- 涂覆层

### 10. 光纤的分类是什么

按照传输模式，光纤可分为：

- 单模光纤：传输方式是单一模式(单色光)

  - 特点：频带宽、容量大、距离远、价格贵

- 多模光纤：传输方式是多模式（多色光、多角度）

  - 特点：频带窄、容量小、距离近、价格便宜

  ### 11. 光纤的优点

- 频带宽、容量大

- 传输速率高

- 误码率低

- 绝对的抗干扰

- 安全性好

- 体积小、重量轻

### 12. 光纤的缺点

- 安装难：精度高、技术难
- 双向传输难(麻烦)
- 分接困难

### 13.单模光纤 VS 多模光纤

| 对比项 | 单模光纤（SMF） | 多模光纤（MMF） |
|---|---|---|
| **纤芯直径** | 很细，约 9 μm | 较粗，50 μm 或 62.5 μm |
| **光源** | 激光器（激光） | LED / VCSEL（发光管） |
| **传输模式** | 光只沿一条直线传播 | 光以多条路径（多种角度）同时反射传播 |
| **传输距离** | 远，几公里到几十公里 | 近，一般几百米（如 100m~550m） |
| **带宽 / 容量** | 极高 | 相对较低（多路径会造成"模式色散"，信号失真） |
| **成本** | 高（光源贵） | 较低 |
| **典型应用** | 长途骨干网、城域网、跨楼宇主干 | 楼宇内部、机房到交换机、短距离局域网 |
