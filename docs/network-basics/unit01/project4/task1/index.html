任务一 网络的组成

知识点​

1. 计算机网络由哪两部分组成​

从系统角度：

  • 网络硬件
  • 网络软件

2. 硬件和软件的关系​

  • 硬件是物质基础
  • 软件确保硬件性能正常发挥作用

3. 计算机网络由哪两部分组成​

从逻辑角度

  • 资源子网：网络中提供的资源（服务器、客户机、存储器）
  • 通信子网：网络中负责通信的部分（交换机、网桥、集线器、网卡等）

4. 网络的硬件组成有哪些​

  • 网络服务器：一台电脑主机
  • 客户端：可以是一台电脑客户端
  • 通信处理设备：交互机、路由器、防火墙、网卡等
  • 打印机
  • 通信线路：双绞线、同轴电缆、光纤、光缆、微波、红外、无线电波

5. 网络软件组成有哪些​

  • 网络操作系统: 是实现网络资源共享的操作系统
  • 网络协议软件： TCP/IP 协议、IEEE 802.5
  • 网络管理软件：管理网络的软件，五大管理：性能、配置、故障、计费、安全
  • 网络通信软件：控制通信、处理数据的网络软件
  • 网络应用软件：厂商提供的通用应用软件 + 基于各种具体业务的软件
    • 软件分类并不绝对：QQ 即是网络通信软件也是网络应用软件

  8. 通信子网指网络中负责________的部分。
  9. 计算机网络的硬件组成通常由网络服务器、客户端、________、打印机和通信线路等几部分组成。
  10. 通信线路是传输信息的载体，也叫通信信道或________。
  11. 通信线路包括有线（如双绞线、同轴电缆、光纤等）和________（如微波、红外和卫星线路等）两类。

  19. 网络管理软件的管理对象除计算机外，还可以是________、交换机等。
  20. 网络通信软件控制通信应用程序与多个站点进行通信，并对大量的通信数据进行________和处理。
  21. 网络应用软件是在网络环境下直接面向________的软件。
  22. 网络应用软件可分为两类：一类是通用应用工具软件，如Outlook、Web服务器和________等。
  23. 另一类网络应用软件是基于不同用户________的软件，如金融业务、电信业务等。
  24. 以QQ为例，其既是网络________软件，同时也是网络应用软件。
  25. 按照《计算机网络基础综合模拟实训》中“项目十二 双机连接通信实验”的方法与步骤，进行________网络连接的操作。
