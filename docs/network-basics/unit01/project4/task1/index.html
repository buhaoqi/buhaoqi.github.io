任务一 网络的组成

知识点​

一、 项目导读与目标​

1. 计算机网络由哪两部分组成？它们的关系是什么？ 答：由硬件部分和软件部分组成。硬件部分是网络存在的物质基础，软件部分确保硬件性能正常发挥作用，两者协调工作、缺一不可。

2. 计算机网络的功能可以概括为什么？通过什么来实现？ 答：概括为便捷通信和资源共享，通过相应的网络操作软件来实现。

3. 计算机网络的两个组成是什么？ 答：硬件部分和软件部分。

4. 网络操作系统的作用是什么？ 答：网络操作系统是网络环境下的操作系统，是各类网络软件的工作平台，负责把网络中各个计算机有机地联系起来，以实现共享资源。

5. 当前常用的网络操作系统有哪些？ 答：Windows、UNIX、Linux、鸿蒙等。

6. 网络资源共享的内涵是什么？ 答：网络中的用户都可以享用系统的各种资源（硬件、软件、数据等）。

7. 各种网络应用形式有哪些特点？ 答：应用形式繁多，并且随着技术的发展而快速推陈出新。

8. 掌握计算机网络的组成，具体需要掌握什么？ 答：掌握硬件和软件两大部分的具体构成。

9. 了解网络操作系统完成的功能有哪些？ 答：负责把网络中各个计算机有机联系起来，实现资源共享，并提供各类网络软件的工作平台。

10. 掌握各种网络功能的内在含义是什么？ 答：便捷通信和资源共享。

11. 素质目标中，规范认识网络中的软件、硬件资源的要求是什么？ 答：规范认识网络中的软件、硬件资源，增强对国产网络操作系统的认识。

12. 培养学生对规范的网络管理的认识与理解属于什么目标？ 答：素质目标。

13. 培养学生正确认识网络功能属于什么目标？ 答：素质目标。

14. 通过对目前国内互联网+新业态的认识，培养什么能力？ 答：培养自我总结、归纳能力。

15. 从系统角度看，计算机网络由哪两大部分组成？ 答：硬件和软件两大部分。

16. 从逻辑功能角度看，计算机网络由哪两部分组成？ 答：资源子网和通信子网。

17. 什么是资源子网？包含哪些部分？ 答：资源子网指网络中提供资源的部分，有服务器、客户机、存储器、相关软件等。

18. 什么是通信子网？包含哪些部分？ 答：通信子网指网络中负责通信的部分，包括各种通信设备（网卡、Modem、集线器、交换机等）及通信软件等。

二、 网络的硬件组成​

19. 计算机网络的硬件组成通常包括哪几部分？ 答：网络服务器（主机Host）、客户端（终端Terminal）、通信处理设备（网卡、交换机、路由器、防火墙等）、打印机和通信线路。

20. 什么是通信线路？它又叫什么？ 答：通信线路是传输信息的载体，也叫通信信道（Channel）、通信链路（Link）。

21. 通信线路分为哪两类？ 答：有线（如双绞线、同轴电缆、光纤等）和无线（如微波、红外和卫星线路等）两类。

三、 网络的软件组成​

22. 网络中的软件主要包括哪些？ 答：网络操作系统、网络协议软件、网络管理软件、网络通信软件和网络应用软件等。

23. 什么是网络操作系统（NOS）？ 答：网络操作系统是网络环境下的操作系统，是各类网络软件的工作平台，与网络的硬件结构相联系。

24. 网络操作系统与单机版操作系统有什么区别？ 答：虽然网络中各个计算机都可以有自己的操作系统，但网络操作系统负责把它们有机地联系起来，以实现共享资源。

25. 什么是网络协议软件？其作用是什么？ 答：网络协议软件是计算机网络运行时必须遵守的通信规则，它定义了通信各实体之间交换信息时的顺序、格式和词汇，是网络通信必不可少的基础条件。

26. 典型的网络协议有哪些？ 答：TCP/IP、IPX/SPX、IEEE 802标准系列协议和X.25协议等。

27. 什么是网络管理软件？ 答：网络管理软件又称网络管理系统，是软件、硬件结合而以软件为主的分布式网络应用系统。

28. 网络管理软件的主要功能是什么？提供哪五大功能？ 答：主要功能是管理、维护网络，使网络正常高效地运行。提供性能管理、配置管理、故障管理、计费管理和安全管理五大功能。

29. 网络管理软件的管理对象可以是什么？ 答：除计算机外，还可以是路由器、交换机等。

30. 什么是网络通信软件？其主要功能是什么？ 答：网络通信软件控制通信应用程序与多个站点进行通信，并对大量的通信数据进行加工和处理，使用户在不必详细了解通信控制规程的情况下进行通信。主要功能是方便与主机连接，具有完备的多媒体传输、文件传输等功能。

31. 什么是网络应用软件？ 答：网络应用软件是在网络环境下直接面向用户的软件。

32. 网络应用软件可分为哪两类？ 答：一类是由网络软件厂商开发的通用应用工具软件，如Outlook、Web服务器和搜索工具等；另一类是基于不同用户业务的软件，如金融业务、电信业务、交通管理和办公自动化等软件。

33. 网络软件的划分是绝对的吗？请举例说明。 答：不是绝对的。以QQ为例，其既是网络通信软件，同时也是网络应用软件。

四、 任务实施​

34. 任务实施中，启动计算机后要求以什么为关键词进行搜索？ 答：以“计算机网络的组成”为关键词进行搜索。

35. 任务实施中，要求分析总结计算机网络的哪些内容？ 答：①分析总结计算机网络的硬件组成，如设备类型、具备功能等；②分析总结计算机网络的软件组成，包括网络操作系统及应用软件。

36. 任务实施中，要求按照哪本书中的哪个实验进行双机网络连接操作？ 答：按照《计算机网络基础综合模拟实训》中“项目十二 双机连接通信实验”的方法与步骤进行双机网络连接的操作。
