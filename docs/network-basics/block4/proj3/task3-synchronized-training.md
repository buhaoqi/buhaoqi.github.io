**逐题解析**：

- **第1题 B**：TCP/IP 起源于美国国防部高级研究规划署的 **ARPANET**。
- **第2题 B**：源主机不知道目标主机的 MAC 地址，只能用**广播**发送 ARP 请求；ARP 应答才是单播。
- **第3题 C**：TCP 面向连接、可靠；UDP 无连接、不可靠。
- **第4题 D**：**TCP 工作在传输层**，**IP 工作在互联网层（网络层）**。
- **第5题 A**：IPv4 地址为 **32 位**（IPv6 为 128 位）。
- **第6题 D**：B 类首字节范围 128~191。`112`、`23` 属 A 类，`210` 属 C 类，**`156` 属 B 类**。
- **第7题 D**：Telnet（远程登录）属于应用层；UDP、TCP 属传输层，IP 属互联网层。
- **第8题 B**：HTTP 是应用层协议。
- **第9题 B**：IP 报头固定 20 字节，选项字段最多 40 字节，故最大 **60 字节**。
- **第10题 C**：`255.255.255.224` 的二进制为 `11111111 11111111 11111111 11100000`，前 **27 位**为 1，即网络 ID 占 27 位（等价于 `/27`）。
- **第11题 B**：UDP 是传输层协议。
- **第12题 A**：TCP/IP 的应用层对应 OSI 的**应用层、表示层、会话层（上三层）**，只对应应用层是错误的。
- **第13题 B**：子网掩码中**对应网络地址的位为 1**，对应主机地址的位为 0。
- **第14题 C**：掩码 `255.255.0.0` 表示网络 ID 取前 **16 位**。A、B、D 的网络 ID 都是 `172.25.0.0`，而 **C 是 `172.16.0.0`**，不在同一子网。
- **第15题 D**：IPv6 只有**单播、组播（多播）、任意播**三类，没有"特殊播"。
- **第16题 A**：链路本地地址前缀为 `FE80::/10`（即 FE80~FEBF）。B 的 `FEC0` 是本地站点地址；C 的 `FF02` 是组播地址；D 的 `FED0` 超出该前缀范围。

### 3.问答题参考答案

**1. 描述 TCP/IP 模型。**

TCP/IP 参考模型把网络通信功能分为 **4 个层次**，从上到下依次为：**应用层、传输层、互联网层、网络接口层**。

| 层次 | 数据单位 | 核心内容 |
|------|---------|---------|
| 应用层 | 报文 | 合并了 OSI 会话层与表示层的功能，为应用程序提供网络服务接口，含 HTTP、FTP、DNS、SMTP 等协议 |
| 传输层 | 数据段 | 为应用进程提供端到端通信，含 TCP（可靠面向连接）与 UDP（不可靠无连接） |
| 互联网层 | 数据包 | 负责编址、路由与分组转发，实现异构网互联，含 IP、ARP、RARP、ICMP、IGMP |
| 网络接口层 | 帧/比特 | 对应 OSI 的数据链路层与物理层，负责在具体链路上收发数据帧 |

其特点是：**先有协议、后有模型**，与底层网络技术无关，扩展性好，是事实上的工业标准。

**2. TCP/IP 模型分为几层？各层的功能是什么？每层包含什么协议？**

分为 **4 层**。

| 层次 | 功能 | 主要协议 |
|------|------|---------|
| **应用层** | 为用户应用程序提供网络服务，定义应用间交换数据的规则；合并会话层和表示层功能 | HTTP、FTP、SMTP、DNS、DHCP、Telnet、SNMP、RIP、POP3、IMAP |
| **传输层** | 为应用层提供会话和数据报通信服务，实现端到端（进程到进程）的数据传输与流量控制 | **TCP**、**UDP** |
| **互联网层** | 定义数据包格式与编址规则，完成寻址、路由选择、分组转发和拥塞控制，实现异构网互联 | **IP**、ARP、RARP、ICMP、IGMP（IPv6 为 IPv6、ICMPv6、NDP、MLD） |
| **网络接口层** | 为 IP 模块发送和接收数据，为 ARP/RARP 发送请求和接收应答；解决封装成帧、透明传输、差错检测 | 以太网、无线局域网、帧中继、ATM 等链路层协议 |

**3. 简述 OSI 参考模型与 TCP/IP 参考模型的异同点。**

**相同点**：

1. 都采用**分层**的体系结构，将复杂的通信问题分解
2. 都基于**协议栈**的概念，各层通过接口向上提供服务
3. 都有**网络层（互联网层）** 负责寻址与路由、**传输层**负责端到端通信
4. 目的相同：实现异构系统之间的互联互通

**不同点**：

| 比较项 | OSI | TCP/IP |
|--------|-----|--------|
| 层数 | 7 层 | 4 层 |
| 制定背景 | ISO 制定的**国际标准**，理论先导 | 由 ARPANET 实践发展而来，**事实标准** |
| 会话层、表示层 | 独立两层 | 并入应用层 |
| 数据链路层、物理层 | 独立两层 | 合并为网络接口层 |
| 通用性 | 通用性强，但体系复杂、实现困难 | 实用性强，与具体网络技术无关，应用广泛 |
| 服务/接口/协议 | 三者定义清晰、区分严格 | 未严格区分服务、接口与协议 |

**4. TCP 协议与 UDP 协议各有什么特点？它们之间有什么区别和联系？**

**TCP 的特点**：面向连接；提供可靠的、有序的、无差错的数据传输（排序、确认、重传）；面向字节流；有流量控制（滑动窗口）与拥塞控制；一对一通信；首部 20 字节，开销大。

**UDP 的特点**：无连接；不可靠（不保证到达、不保证顺序、不重传）；面向报文（不拆分不合并）；无流量控制；可一对一、一对多；首部仅 8 字节，开销小、速度快。

**区别**：

| 比较项 | TCP | UDP |
|--------|-----|-----|
| 连接 | 面向连接（三次握手，四次挥手） | 无连接 |
| 可靠性 | 可靠 | 不可靠 |
| 数据形式 | 字节流 | 报文 |
| 首部 | 20 字节 | 8 字节 |
| 流量控制 | 有 | 无 |
| 适用 | 文件传输、Web、电子邮件 | 视频会议、聊天、流媒体、DNS、DHCP、RIP |

**联系**：

1. 两者都工作在**传输层**，都建立在 **IP 协议**之上，都通过**端口号**标识进程
2. 都为应用层提供服务，应用可根据对**可靠性**与**实时性**的不同需求选择
3. 两者可以共存于同一主机，由 **IP 首部的协议字段**（6 表示 TCP，17 表示 UDP）区分

**5. 简述 DNS 协议的工作过程。**

1. 用户在浏览器中输入域名（如 `www.qq.com`），操作系统先检查**本地 DNS 缓存**中是否有映射，有则直接完成解析
2. 若缓存没有，则查本机 **hosts 文件**，有则完成解析
3. 若都没有，则向 TCP/IP 参数中设置的**首选 DNS 服务器（本地 DNS 服务器）** 发起查询；该服务器若在其 **DNS 数据库**中有记录，直接返回结果
4. 若数据库中没有，但服务器**已缓存**过该映射，则调用缓存完成解析
5. 若仍失败，则按设置决定查询方式：
   - **未启用转发**：本地 DNS 向 **13 台根 DNS 服务器**发问，根服务器返回负责该**顶级域（如 `.com`）** 的服务器地址；本地 DNS 再逐级查询 `.com` → `qq.com`，直至找到目标主机的 IP（**迭代查询**）
   - **启用转发**：把请求**转发给上一级 DNS 服务器**，由其解析；不行再向上级或根服务器转发（**递归查询**）
6. 最终结果逐级返回到**本地 DNS 服务器**，再由它返回给**客户机**，浏览器用得到的 IP 地址与 Web 服务器建立 TCP 连接

**6. IPv4 中的地址有几种类型？它们是怎样分类的？判断下列地址属于哪类 IP 地址？**

IPv4 地址分为 **5 类（A、B、C、D、E）**，按**第一个字节的取值范围**（即地址的高位特征）分类：

| 类别 | 首字节范围 | 高位特征 | 网络 ID / 主机 ID | 用途 |
|------|-----------|---------|------------------|------|
| A 类 | 1~126 | 最高位为 0 | 1 字节 / 3 字节 | 大型网络 |
| B 类 | 128~191 | 前两位为 10 | 2 字节 / 2 字节 | 中型网络 |
| C 类 | 192~223 | 前三位为 110 | 3 字节 / 1 字节 | 小型网络 |
| D 类 | 224~239 | 前四位为 1110 | — | **多播（组播）** 地址 |
| E 类 | 240~255 | 前四位为 1111 | — | 试验性用途 |

**判断结果**：

| 地址 | 首字节 | 类别 |
|------|--------|------|
| （1）96.1.4.100 | 96（1~126） | **A 类** |
| （2）133.12.6.50 | 133（128~191） | **B 类** |
| （3）192.168.1.1 | 192（192~223） | **C 类**（且为私有地址） |
| （4）233.2.5.9 | 233（224~239） | **D 类**（多播地址） |

**7. 在 IPv4 中，什么是子网掩码？子网掩码的作用是什么？**

**定义**：子网掩码是一个 **32 位**的二进制数，其中与 **网络 ID 对应的位全部置 1**，与**主机 ID 对应的位全部置 0**；通常用点分十进制表示，如 `255.255.255.0`，也可写为 `/24`。

**作用**：

1. **区分网络 ID 与主机 ID**：通过与运算求出 IP 地址的网络 ID（子网地址），从而判断该地址属于哪个网络
2. **判断两台主机是否在同一子网**：将两主机 IP 分别与掩码相与，结果相同则在同一子网，可直接通信；不同则需经网关转发
3. **支持子网划分**：从主机位借位作为子网号，形成"网络 ID + 子网 ID + 主机 ID"三级结构，提高地址利用率并便于管理
4. 求主机地址范围与广播地址（主机位全 0 为网络地址，全 1 为广播地址）

**8. IPv4 与 IPv6 的主要区别是什么？**

| 比较项 | IPv4 | IPv6 |
|--------|------|------|
| 地址长度 | 32 位 | **128 位** |
| 地址数量 | 约 40 亿个 | 约 3.4×10 的 38 次方个 |
| 地址表示 | 点分十进制 | **冒号十六进制**（可用 `::` 简化、可内嵌 IPv4） |
| 地址结构 | 网络 ID + 主机 ID，需子网掩码 | 子网标识（前缀）+ 接口 ID，用前缀长度表示 |
| 首部 | 固定 20 字节，含检验和、标识、标志、偏移 | 基本头部固定 **40 字节**，取消检验和，可选字段移入**扩展头部** |
| 分片 | 路由器可分片 | 由**源节点**分片，路由器不再分片 |
| 地址配置 | 手工或 DHCP | 支持**无状态自动配置**（链路本地地址自动生成） |
| 安全性 | 需额外 IPsec | **内置**认证与机密处理 |
| 广播 | 有广播地址 | **取消广播**，改用组播 |
| 地址类型 | 单播、广播、组播 | **单播、组播、任意播** |

**9. IPv6 的地址是如何分类的，每类地址有什么特征？**

IPv6 地址分为**单播、组播、任意播**三类：

| 类型 | 特征 |
|------|------|
| **单播** | 标识**单一接口**，发往单播地址的数据包只送到**一个**接口。包括：**全球单播地址**（前 3 位 `001`，全球可路由）、**链路本地地址**（`FE80::/10`，同一链路内通信、自动配置与邻居发现，路由器不转发）、**本地站点地址**（`FEC0::/10`，相当于 IPv4 私网地址，可跨路由器但不能在互联网使用）、**唯一本地地址**（`FC00::/7`，常用 `FD00::/8`）、其他单播地址（`::` 未指定、`::1` 回送、`::w.x.y.z` 兼容 IPv4、`::FFFF:w.x.y.z` IPv4 映射） |
| **组播（多播）** | 标识**一组接口**，发往组播地址的数据包送到**多个**接口。以 `FF00::/8` 开始，结构为：8 位前缀 + 4 位标志（0 为 IANA 固定分配、1 为临时）+ 4 位范围（1 本地接口、2 本地链路、5 本地专用）+ 112 位组 ID |
| **任意播** | 标识**一组接口**（一般属于不同节点），发往任意播地址的数据包**只送到路由距离最近的**那个接口。格式与单播相同、无法从地址本身区分；由路由协议定义，不能手工配置；**只能用作目的地址**，不能作为源地址 |

**补充**：IPv6 中**取消了广播地址**，原来广播的功能由组播实现。
