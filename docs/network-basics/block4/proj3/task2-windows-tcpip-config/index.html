任务二 Windows中TCP/IP组件的配置

知识点​

1.为什么必须正确配置TCP/IP？​

TCP/IP 已经成为行业标准的协议套件，所有现代操作系统的核心中都已包含了 TCP/IP 协议软件，因此系统都会自动安装 TCP/IP 组件。

但 TCP/IP 在正常使用前必须进行正确配置，配置正确与否将会影响系统的网络通信和能力。

2.Windows中TCP/IP组件是如何安装的？可以卸载吗？​

在默认情况下，Windows 系统中的 TCP/IP 是自动安装的，显示为"网络连接"文件夹中的"Internet 协议（TCP/IP）"组件。

Windows 版本是否可卸载说明
Windows 2000 及以前版本可以卸载"Internet 协议（TCP/IP）"组件可以卸载
后续 Windows 版本不能卸载但可以通过使用 netsh interface IP reset 命令还原默认配置

Internet 协议（TCP/IP）组件可配置为自动获取其配置，或从手动指定的设置文件中获取其配置。默认情况下，此组件被配置为"自动获取 IP 地址"（对应"Internet 协议版本 4（TCP/IPv4）属性"对话框中的"常规"选项卡）。

3.什么是自动配置？​

如果指定了自动获取 IP 地址，则当 Windows 启动时，Internet 协议（TCP/IP）组件将尝试查找一个 DHCP 服务器，从而获取 IP 地址等相关配置信息。

要点：

  1. 自动配置的前提是网络中存在 DHCP 服务器
  2. 由 DHCP 服务器下发 IP 地址、子网掩码、网关、DNS 等参数（DHCP 的工作过程见任务一）
  3. 适合主机数量多、位置经常变动的网络（如办公网、校园网、无线网）

4.手动（静态）配置必须设置哪两个参数？​

手动配置 Internet 协议（TCP/IP）组件（又称静态配置）时，必须配置以下两个参数：

（1）IP 地址

  • 是 32 位的逻辑地址
  • 设置时应与本网络其他主机具有相同的网络 ID，但要保证主机 ID 不可与其他主机重复
  • 一台主机可以根据需要设置多个 IP 地址

（2）子网掩码

  • 子网掩码使 TCP/IP 协议能够通过计算得到主机的网络 ID 和主机 ID
  • 该参数在设置时要与所在网络的其他主机保持一致

配置检查口诀：网络 ID 相同（同网段）、主机 ID 不重（不冲突）、子网掩码一致（同掩码）。

5.网关的作用是什么？如何设置？​

（1）何时需要配置网关

如果主机要连接到所在网络之外的节点，则还必须配置网关的 IP 地址。

（2）网关的定义

网关又称为网间连接器、协议转换器，它是在网络层及以上层次实现网络互连时使用的设备。在联网实践中，网关通常是连接本地网络与其他网络的路由器。

（3）网关的作用过程

  1. 当本地网络内的节点需要与远程网络的主机进行通信时，TCP/IP 协议会将那些要发送到远程网络的数据包首先发送到网关中
  2. 之后网关在它所安装的协议控制下，将数据信息向目标节点所在网络转发
  3. 目标节点的回送信息也要通过网关转发给本地网络内的节点

（4）设置方法

在"Internet 协议版本 4（TCP/IPv4）属性"对话框中填写"默认网关"的 IP 地址。默认网关的地址一般就是与本机同网段的路由器接口地址（如本机 192.168.1.100，网关 192.168.1.254）。

6.DNS服务器参数如何设置？​

作用：TCP/IP 协议使用 DNS 服务器来将字符化的名称（如 www.sbs.edu.cn）解析为 IP 地址。

设置内容：手动配置首选 DNS 服务器和备用 DNS 服务器的 IP 地址。当首选 DNS 服务器不可用时，系统会使用备用 DNS 服务器继续解析，从而提高可靠性。

注意：DNS 服务器地址一般由网络管理员或运营商（ISP）提供，不需要与主机处于同一网段。

7.如何进行多参数设置？​

点击"Internet 协议版本 4（TCP/IPv4）属性"对话框中的"高级"按钮，进入"高级 TCP/IP 设置"窗口。

选项卡可进行的设置
IP 设置一台主机可以根据需要设置多个 IP 地址；也可以根据网络实际，设置多个网关参数。点击相应的"添加"按钮，即可进行多参数设置
DNS除首选 DNS 服务器和备用 DNS 服务器参数外，可以在"DNS"选项卡中根据需要设置多个 DNS 服务器

为什么需要多个 IP 地址/网关：一台主机（如服务器）可能同时接入多个网段，或需要同时通过不同网关访问不同网络，此时需要配置多个 IP 地址和多个网关。

8.一个完整的配置示例是怎样的？​

以图 4-27、图 4-28 所示的配置为例：

参数取值说明
IP 地址192.168.1.100与所在网络其他主机网络 ID 相同（192.168.1.0），主机 ID 不重复
子网掩码255.255.255.0网络 ID 占 24 位
默认网关192.168.1.254与本机同网段的路由器接口地址
首选 DNS 服务器192.168.1.200由管理员指定
备用 DNS 服务器202.100.66.95首选不可用时启用

在"高级 TCP/IP 设置"窗口的"IP 设置"中，还可看到已添加的 IP 地址 10.1.2.43（子网掩码 255.255.255.0）与网关 10.1.2.254，即同一台主机配置了两个不同网段的 IP 地址和两个网关。

9.配置完成后如何验证？​

检查项常用方法判断标准
参数是否生效ipconfig /all能看到配置的 IP 地址、子网掩码、默认网关、DNS 服务器
本机协议栈是否正常ping 127.0.0.1有应答，说明 TCP/IP 协议安装正常
到网关是否连通ping 默认网关地址有应答，说明本机到网关链路正常
域名解析是否正常ping 域名（如 ping www.sbs.edu.cn）能解析出 IP 地址并收到应答，说明 DNS 配置正确
能否访问外网ping 外网 IP 或访问网站有应答说明网关与路由配置正确

排错思路：本机回送不通 → 协议栈问题；网关不通 → IP/掩码/网关或链路问题；网关通但域名不通 → DNS 问题。

参数作用配置要点
IP 地址32 位逻辑地址，标识主机网络 ID 与同网段一致，主机 ID 唯一；可配多个
子网掩码计算网络 ID 与主机 ID与同网段其他主机一致
默认网关转发发往其他网络的数据包通常为同网段路由器接口地址；访问外网必需
首选/备用 DNS域名解析为 IP 地址由管理员或 ISP 提供；可配多个
