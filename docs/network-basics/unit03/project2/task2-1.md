#### 模拟数据链路层帧（以太网帧）
>物理层过来的原始比特（图片数据片段，一串0、1）：
`1011001010011100` 【这就是上层下来的数据（载荷）】

✅封装：加上【帧头】+【帧尾】
```
【帧头】| 载荷(数据)        |【帧尾CRC校验】
目的MAC | 源MAC |类型| 1011001010011100 | CRC校验码
```

完整二进制样例

- 目的MAC（目标网卡地址，帧头一部分）：`00001111 00001111 00001111`
- 源MAC（发送方网卡地址，帧头一部分）：`11110000 11110000 11110000`
- 类型字段（帧头，标记上层是IP）：`00001000 00000000`
- 载荷（图片数据）：`1011001010011100`
- 帧尾CRC校验码：`10011101`

组装成完整帧：
`000011110000111100001111 111100001111000011110000 0000100000000000 1011001010011100 10011101`

一句话解释

1. 帧头：存放目的MAC、源MAC、类型。告诉交换机：这帧从哪块网卡来、要发给局域网里哪块网卡。
2. 载荷：就是网络层交付过来的数据包（咱们例子里是微信图片的一段二进制）
3. 帧尾CRC：校验码。接收方收到整个帧，重新计算校验值，判断传输时比特有没有损坏。
4. 接收端解封装操作：收到完整帧 → 先用帧尾CRC校验，无误 → 剥掉帧头+帧尾，拿出中间载荷，交给网络层。




### 11.链路层和其他层的区别

1. 数据链路层：相邻节点之间，用MAC地址。（同一个小区里面，楼栋之间送货）
2. 网络层：主机‑主机跨网络，用IP地址。（从一个城市送到另外一座城市）
3. 传输层：进程‑进程，用端口号。（送到家里交给对应的软件）
4. 物理层只管一长串连续01，分不清哪里是一段数据的开头结尾；
5. 数据链路层加帧头帧尾，把连续比特切分成帧，识别一段数据的起点终点。


### 5.链路层的典型设备是什么

链路层设备**基于MAC地址工作**；传输介质负责传送比特，介质本身只负责信号传输，不做帧的校验与转发。

硬件设备：

1. **网卡（网络适配器）**
负责实现数据链路层功能；封装/解封装帧；进行MAC地址识别；完成串并转换；具备差错检测。
2. **网桥**
连接两个局域网；基于MAC地址转发帧；隔离冲突域；不能隔离广播域。
3. **交换机（多端口网桥）**
多端口，每个端口独立冲突域；依据MAC地址表转发数据帧；全双工通信，提升传输效率；不能隔离广播域。

物理介质：

1. **双绞线**
成本低、易施工；传输距离有限；抗干扰能力弱（屏蔽双绞线抗干扰更强）。
2. **光纤**
传输速率高、距离远；抗电磁干扰能力极强；保密性好；价格偏高，需要光电转换。
3. **同轴电缆**
抗干扰较好；带宽有限；现在很少使用。
4. **无线介质（无线电波）**
无需布线，灵活；易受干扰，存在信号衰减。

### 1.流量控制是什么？

- 当发送方发送数据的速率高于接收方处理数据的速率时，某些数据可能因接收缓冲区溢出而丢失，流量控制就是防止这种情况发生。

- 数据链路层通过滑动窗口协议（Sliding Window Protocol）来处理相邻节点之间的流量控制。


### 2.滑动窗口协议中窗口大小W是什么？

- W是发送窗口的大小，等于接收方缓冲区的大小，也就是接收方可接收来自给定发送方的消息数量。
- W表示发送方在未收到确认之前所能发送的最大帧数，从而保证接收方缓冲区不会溢出。

### 3.根据网络规模，数据链路层协议分为哪两类？

分为两类：

- 局域网协议
    - LLC:逻辑链路控制子层
    - MAC:介质访问控制子层
- 广域网协议
    - HDLC（高级数据链路控制，ISO 标准）
    - PPP（点对点协议，互联网 Internet 广泛使用）

### 4.HDLC协议的主要特点有哪些？

① 协议不依赖于任何一种字符编码集；
② 数据报文可透明地传输；
③ 用于实现透明传输的0比特插入法，易于硬件实现；
④ 全双工通信，不必等待确认便可连续发送数据，传输效率较高；
⑤ 所有帧均采用CRC校验，对信息帧进行编号，可防止漏收或重传，传输可靠性高；
⑥ 传输控制功能与数据处理功能分离。

### 5.0比特插入法是什么？

0比特插入法是为保证HDLC帧中标志码01111110的唯一性而采用的透明传输措施。

- 发送端监视除标志码以外的所有字段，当发现连续5个1出现时，便在其后添插一个0；
- 接收端同样监视除起始标志码以外的所有字段，当连续发现5个1后，若其后是一个比特0则自动删除它，以恢复原来的比特流；若发现连续6个1，则可能是插入的0发生差错变成了1，也可能是收到了帧的终止标志码，可通过帧检验序列进一步区分。

### 6.HDLC协议中主站、从站和组合站是什么。

- 主站：在链路上用于控制目标站，负责对数据流进行组织，并对链路上的差错实施恢复。主站发往从站的帧称为命令帧。
- 从站：受主站控制的站。由从站返回主站的帧称为响应帧。
- 组合站：那些兼备主站和从站功能的站。

### 7.HDLC协议中有哪3种常用的操作方式？

- ① 正常响应方式（NRM）：非平衡数据链路操作方式，适用于面向终端的点到点或一点与多点链路。主站负责启动传输、管理链路、控制超时与重发；从站只有收到主站某个命令帧后才能作出响应向主站传输信息。
- ② 异步响应方式（ARM）：非平衡数据链路操作方式，从站启动传输过程、控制超时和重发，从站可主动发送包含数据信息、控制信息等的帧。
- ③ 异步平衡方式（ABM）：允许任何节点来启动传输过程，主站、从站都能启动数据传输过程，每个站既可作为主站又可作为从站（即都是组合站），各站对差错恢复过程负有相同的处理权限。

### 8.HDLC协议的帧由哪几部分组成？

HDLC协议的帧由:
- 标志字段（F）:8比特
- 地址字段（A）:8比特
- 控制字段（C）:8比特
- 信息字段（I）:长度任意
- 帧校验序列字段（FCS）:16比特

组成。

### 9.HDLC协议有哪3种类型的帧？

- 信息帧（I帧）：用于传送有效信息或数据。
- 监控帧（S帧）：用于差错控制和流量控制。
- 无编号帧（U帧）：用于提供对链路的建立、拆除及其他控制功能。

### 10.介质访问控制子层（MAC）的基本功能是什么？

MAC的最基本功能是控制不同用户数据传输中对物理层传输介质的访问，包括介质访问时的寻址（通过MAC地址），以及解决介质访问冲突（"仲裁介质的使用权"，规定网络节点何时可以使用公共通信介质）。

其主要功能包括：数据帧的封装/卸装、帧的寻址和识别、帧的接收与发送、帧的差错控制、介质访问冲突控制等。

### 11.列举与MAC子层相关的IEEE 802标准。

- IEEE 802.3：以太网标准，规范总线型网络结构下如何使用传输介质；
- IEEE 802.4：令牌总线（Token-Bus）标准，规范总线结构下利用令牌控制传输介质的使用；
- IEEE 802.5：令牌环（Token-Ring）标准，规范环状网络结构下利用令牌控制传输介质的使用；
- IEEE 802.11：无线局域网标准，规范无线局域网络结构下控制传输介质的使用。

### 12.逻辑链路控制子层（LLC）的基本功能是什么？

LLC的最基本功能是负责数据链路层中逻辑链路的控制，包括逻辑链路的建立和释放、控制信号交换、数据流量控制、解释上层通信协议传来的命令并产生相应响应，以及克服数据传送过程中可能发生的问题（如数据错误、重复收到相同数据、接收顺序与传送顺序不一致等）。

### 13.IEEE 802系列标准中LLC对应的标准是什么？

IEEE 802.2是各种不同局域网都遵守并使用的LLC通信标准。由于网络层上可能有多种通信协议同时存在，LLC从MAC收到一个数据包时必须能够判断要送给网络层的是哪一个通信协议。
