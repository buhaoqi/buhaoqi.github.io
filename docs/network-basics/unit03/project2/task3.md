## 知识点



### 1.网络层是什么

- 网络层负责在不同网络之间实现主机到主机的数据传递。
- 它上承传输层（接收报文段），下接数据链路层（封装为数据包）

### 2.网络层的功能是什么

网络层主要负责把分组从源主机发送到目的主机，可能跨越多个不同的网络。

- 往哪里送、怎么选路、如何跨网络把分组送到目标主机
- 网络层通常只提供“尽力而为”的服务，不保证可靠、不保证顺序、不负责重传。可靠性一般由传输层（如 TCP）来保证。


核心功能：

1. 逻辑寻址  
   为网络中的设备分配逻辑地址，例如 IP 地址。IP 地址包含网络号和主机号，用于标识设备所在的网络和具体主机。

2. 路由选择  
   根据网络拓扑、路由表和路由协议，决定分组从源到目的应该走哪条路径。常见路由协议有 OSPF、BGP、RIP 等。

3. 分组转发  
   路由器收到分组后，根据目的 IP 地址查路由表，把分组从合适的接口转发出去。这是逐跳进行的。

4. 网络互连  
   连接不同的网络或子网，屏蔽底层数据链路层和物理层的差异，使它们看起来像一个统一的网络。

5. 分片与重组  
   当分组大小超过链路的最大传输单元（MTU）时，网络层可以分片；到达目的端后再重组。IPv4 支持路由器分片，IPv6 通常由源端处理分片。

6. 拥塞控制  
   当网络负载过高时，采取一定机制避免或缓解拥塞，例如 ICMP 源抑制、ECN、RED 等。

7. 差错报告与诊断  
   通过 ICMP 等协议报告网络不可达、超时、重定向等错误信息，帮助诊断网络问题。

8. 服务质量与流量管理  
   在某些网络中，网络层可以提供优先级、流量整形、拥塞避免等 QoS 功能。

### 网络层的数据单位是什么
分组 / 数据报（Packet / Datagram）

### 网络层的典型设备是什么
路由器、三层交换机

### 网络层的典型协议是什么
IP、ICMP、ARP、RARP、OSPF、BGP、RIP、IPsec 等

### 分组是什么
分组（Packet），也常叫“包”，是网络层传输的数据单元。在 OSI 模型中，网络层的协议数据单元（PDU）就是分组。

简单理解：
分组 = 网络层首部 + 载荷

- 首部：包含控制信息，如源 IP 地址、目的 IP 地址、协议类型、生存时间 TTL、校验和等。
- 载荷：上层交下来的数据，通常是传输层的 TCP 段或 UDP 数据报。

为什么需要分组？
网络不是一次把整个文件直接发过去，而是把数据切成许多小块，每块加上地址等信息，变成一个个分组。这样做的目的：
- 便于在网络上传输，适应不同链路的 MTU；
- 每个分组可以独立选路，路由器逐跳转发；
- 多个用户可共享网络，提高线路利用率；
- 某个分组出错或丢失，只需重传这一小块，不必重传整个文件。

分组交换：
互联网采用分组交换。路由器收到分组后，根据目的 IP 地址查路由表，把分组从合适接口转发出去。分组可能走不同路径，到达目的端后再由上层重组。

与其他层数据单位的区别：
- 物理层：比特（bit）
- 数据链路层：帧（Frame），含 MAC 地址，负责相邻节点传输
- 网络层：分组 / 数据报（Packet / Datagram），含 IP 地址，负责跨网络端到端传输
- 传输层：段（TCP Segment）或数据报（UDP Datagram），含端口号，负责进程到进程通信
- 应用层：报文（Message）

举例：
你发送一个网页请求，HTTP 数据先被 TCP 分成段，加上 TCP 头；再交给 IP，加上 IP 头，变成 IP 分组；然后交给以太网，加上帧头帧尾，变成帧；最后物理层变成电信号或光信号发出去。

所以，分组就是网络层用来承载和转发数据的“包裹”，里面装着上层数据，外面贴着源和目的 IP 地址等“快递单”。


### 3.网络层和其他层的区别

数据链路层：负责同一网络内相邻节点之间的数据帧传输，可以经过多个节点，但不能跨子网；
网络层：负责跨多个网络（子网） 的端到端数据包传输，实现不同子网之间的数据交付。

①收到数据包，读取目标 IP；
②在路由表里查找匹配的目的网段；
③找到匹配条目：按条目里的下一跳 + 出接口转发；
④找不到匹配条目：
   - 有默认路由：发给默认路由指定的下一跳；
   - 无默认路由：丢弃数据包，不再转发。

- 数据链路层负责相邻节点之间的帧传输；
- 网络层负责跨网络的主机到主机通信；
- 传输层负责进程到进程通信。

### 简述网络层寻址的作用
- 寻址用来对网络节点做统一身份标识，解决节点到节点的报文通信编址问题；
- OSI网络层采用NSAP（网络服务访问点）地址标识源端和目标端。

### 路由选择是什么？
答：路由选择是网络层核心功能，负责确定收到的报文从哪个输出接口发出。数据包交换方式下，每个节点对每一个收到的报文都要做路由选择；

### 路由选择算法的特点是什么
答：路由算法一般具有正确性、简单性、强壮性、稳定性、公平性和最优性等特点。

### 路由选择算法分为哪两类
- 动态路由算法：根据网络当前传输量和拓扑结构进行路由选择，算法较复杂；
- 静态路由算法：静态路由算法比较简单。

### 网络拥塞是什么？
答：通信子网内报文过多，子网中间节点因无空闲缓冲区不断丢弃报文，造成整个网络性能降低的现象称为拥塞。

### 网络层拥塞控制是什么

- 要防止拥塞出现；拥塞发生或即将发生时，找到拥塞原因，消除拥塞状态。

### 拥塞的控制策略是什么
控制策略包括缓冲区预分配、报文丢弃法、流量控制、抑制报文分组等。

### RIP协议是什么

- RIP即路由信息协议，是较早使用的内部网关协议，适用于小型、同类型网络；
- RIP封装在UDP协议的数据报中；
- 使用更新（UPDATES）和请求（REQUESTS）两种数据包传输信息；
- 路由器每隔30秒向直连路由器广播更新信息。

### OSPF协议是什么
- OSPF即开放最短路径优先协议
- 基于链路状态的内部网关协议，链路状态包含连通性、费用、距离、时延、带宽等信息，选路考虑更全面；
- OSPF直接使用IP数据报封装传送。
- OSPF效率高，适用于较大型的网络。
### OSPF的工作原理是什么
- ①OSPF使用泛洪法向所有路由器发送本路由器相邻路由器的链路状态信息；
- ②仅当链路状态发生变化时，才使用泛洪法转发信息；
- ③所有路由器得到全网拓扑结构，根据拓扑图使用最短路径算法计算最短路径，将下一跳信息填入路由表。

### BGP协议是什么
BGP是边界网关协议，属于路径向量协议，目标不是找到最短路径，而是找到合适的路径。

原因：
- ①互联网规模太大，使用最短路径算法计算耗时久；
- ②不同自治系统拥有不同策略，部分路由器会过滤请求，降低效率。

### BGP的工作过程是什么
- ①在每个独立网络选择至少一个BGP主站，主站和相邻独立网络交换信息，信息包含到达某个网络要经过的一系列独立网络；
- ②BGP主站交换网络可达性信息后，根据自身策略从路由信息中选出到达目标独立网络合适的路由。


### 跨网络传输是什么意思
跨网络 = 跨越多个独立的子网，不同子网有各自独立的编址体系，需要路由器（网络层设备）转发。比如：
- 一个局域网到另一个局域网
- 家庭内网→互联网
- 你手机（家里局域网）访问百度服务器（百度机房另一个局域网）

### 链路层有没有跨多个节点？
- 链路层可以跨多个节点，但这些节点必须在同一个网络（同一个子网）里面。
- 链路层只负责相邻节点之间，一跳一跳地传递帧，依靠MAC地址寻址；它只能在同一个局域网内工作，不能跨子网。

举个对比：
- 同一个宿舍局域网内，电脑A →交换机→电脑B：链路层，同网络，多个节点，MAC寻址，不需要网络层路由。
- 宿舍电脑 →路由器 →外网服务器：跨网络，要经过多个子网。链路层只能完成相邻一段的传输；网络层负责端到端、跨子网的寻址和选路，决定数据包整体走哪条路径穿过多个网络。
