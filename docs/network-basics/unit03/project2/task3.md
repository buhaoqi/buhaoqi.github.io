## 知识点
### 1.网络层是什么

- 网络层是OSI参考模型的第3层，位于传输层之下，数据链路层之上。
- 网络层负责在不同网络之间实现主机到主机的数据传递。
- 它上承传输层（接收报文段），下接数据链路层（封装为数据包）

### 2.网络层的数据单位是什么

- 数据单位：数据包(含 IP 地址，负责跨网络端到端传输)
- 数据包 = 包头(源节点和目标节点的网络地址) + 数据报文

与其他层数据单位的区别：
- 物理层：比特（bit）
- 数据链路层：帧（Frame），含 MAC 地址，负责相邻节点传输
- 网络层：分组 / 数据报（Packet / Datagram），含 IP 地址，负责跨网络端到端传输
- 传输层：段（TCP Segment）或数据报（UDP Datagram），含端口号，负责进程到进程通信
- 应用层：报文（Message）

### 3.网络层的功能是什么

网络层主要负责把分组从源主机发送到目的主机，可能跨越多个不同的网络。核心功能：

- 寻址
- 路由选择
- 拥塞控制

### 4.寻址是什么

- 寻址即为网络节点进行编址
- 节点的编址问题是网络层必须重点解决的问题。
- 网络节点不一定相邻，必须对节点做出统一标准下的身份识别，
- OSI网络层采用NSAP（网络服务访问点）通用网络地址标准进行编址，标识源端和目标端。。

### 5.路由选择是什么？
答：路由选择是网络层的核心功能，负责根据路由算法，选择一条最合适的路径(下一跳)传输数据包。常见路由协议有 OSPF、BGP、RIP 等。

### 6.路由选择算法的特点是什么
答：路由算法一般具有正确性、简单性、强壮性、稳定性、公平性和最优性等特点。

### 7.路由选择算法分为哪两类
- 动态路由算法：根据网络当前传输量和拓扑结构进行路由选择，算法较复杂；
- 静态路由算法：静态路由算法比较简单。

### 8.网络拥塞是什么？
当通信子网有过多报文时，不当的路由选择会导致网络“拥塞“，即：因没有空闲缓冲区而不断丢弃报文。

### 9.拥塞的控制策略是什么
控制策略包括缓冲区预分配、报文丢弃法、流量控制、抑制报文分组等。

### 10.网络层的特点是什么

- 主要负责如何跨网络把分组送到目标主机，往哪里送、怎么选路
- 网络层通常只提供“尽力而为”的服务，不保证可靠、不保证顺序、不负责重传。可靠性一般由传输层（如 TCP）来保证。

### 11.网络层的典型设备是什么
路由器、交换机(三层)

### 12.网络层的典型协议是什么
- 路由算法协议：RIP、OSPF、BGP
- 编址协议：NSAP

### 13.RIP协议是什么

- RIP即路由信息协议，是较早使用的内部网关协议，适用于小型、同类型网络；
- RIP封装在UDP协议的数据报中；
- 使用更新（UPDATES）和请求（REQUESTS）两种数据包传输信息；
- 路由器每隔30秒向直连路由器广播更新信息。

### 14.OSPF协议是什么
- OSPF即开放最短路径优先协议
- 基于链路状态的内部网关协议，链路状态包含连通性、费用、距离、时延、带宽等信息，选路考虑更全面；
- OSPF直接使用IP数据报封装传送。
- OSPF效率高，适用于较大型的网络。

### 15.BGP协议是什么
BGP是边界网关协议，属于路径向量协议，目标不是找到最短路径，而是找到合适的路径。

原因：
- ①互联网规模太大，使用最短路径算法计算耗时久；
- ②不同自治系统拥有不同策略，部分路由器会过滤请求，降低效率。

### 16.网络层和其他层的区别

数据链路层：负责同一网络内相邻节点之间的数据帧传输，可以经过多个节点，但不能跨子网；
网络层：负责跨多个网络（子网） 的端到端数据包传输，实现不同子网之间的数据交付。

①收到数据包，读取目标 IP；
②在路由表里查找匹配的目的网段；
③找到匹配条目：按条目里的下一跳 + 出接口转发；
④找不到匹配条目：
   - 有默认路由：发给默认路由指定的下一跳；
   - 无默认路由：丢弃数据包，不再转发。

- 数据链路层负责相邻节点之间的帧传输；
- 网络层负责跨网络的主机到主机通信；
- 传输层负责进程到进程通信。

### 17.跨网络传输是什么意思
跨网络 = 跨越多个独立的子网，不同子网有各自独立的编址体系，需要路由器（网络层设备）转发。比如：
- 一个局域网到另一个局域网
- 家庭内网→互联网
- 你手机（家里局域网）访问百度服务器（百度机房另一个局域网）
