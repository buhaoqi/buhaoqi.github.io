任务二 数据链路层(一)10

知识点​

1.数据链路层在OSI模型中的位置​

数据链路层是OSI参考模型中的第二层，位于物理层和网络层之间。

2.数据链路层是什么​

数据链路层负责将物理层收到的比特流封装成帧，在相邻节点之间透明可靠的传输帧；

  • 相邻两个节点之间，比如：比如主机 ↔ 交换机

  • 数据单元：帧（Frame）

  • 链路：指相邻两个节点之间的物理通道（一根网线、一段WiFi连接，一段点对点的通路）。链路=相邻两点之间的通路。

  • 数据链路：在这条物理链路之上，增加一套控制规则，让这条链路可以可靠传输数据帧。

物理链路只是一根线；数据链路 = 物理线路 + 链路层通信规则。 这一层就是管理「数据链路」，所以叫数据链路层。

3.为什么需要数据链路层​

物理层只能发送无边界的01信号，有3个解决不了的问题，链路层来搞定：

  1. 分不清数据边界 物理层就是源源不断的0和1，不知道哪一段是一条完整消息。链路层打包成帧，标出从哪开始、到哪结束。
  2. 局域网里不知道发给谁 IP是跨网络用的。在同一个局域网内部，需要MAC地址，找到相邻那一台设备。
  3. 不知道传输有没有出错 线路干扰会把0变成1。链路层增加CRC校验，检查这帧数据是否损坏。 额外：多个设备共用一条网线时，协调谁能发数据，避免信号打架冲突。

4.链路层的主要功能是什么​

  • 组帧：把比特流打包成帧，加帧头、帧尾(地址：MAC地址（物理地址），写在帧头部)
  • 差错检测：检错（常用CRC校验），一般只检错，不纠错
  • 介质访问控制MAC：多个设备共享一条链路时，决定谁能占用线路（如以太网CSMA/CD）
  • 流量控制：防止发送方发太快，接收方接收不过来
  • 链路管理:在两个网络实体之间提供数据链路通路的建立、维持和释放管理。实现面向连接的服务

5.链路层的典型设备是什么​

链路层设备基于MAC地址工作；传输介质负责传送比特，介质本身只负责信号传输，不做帧的校验与转发。

硬件设备：

  1. 网卡（网络适配器） 负责实现数据链路层功能；封装/解封装帧；进行MAC地址识别；完成串并转换；具备差错检测。
  2. 网桥 连接两个局域网；基于MAC地址转发帧；隔离冲突域；不能隔离广播域。
  3. 交换机（多端口网桥） 多端口，每个端口独立冲突域；依据MAC地址表转发数据帧；全双工通信，提升传输效率；不能隔离广播域。

物理介质：

  1. 双绞线 成本低、易施工；传输距离有限；抗干扰能力弱（屏蔽双绞线抗干扰更强）。
  2. 光纤 传输速率高、距离远；抗电磁干扰能力极强；保密性好；价格偏高，需要光电转换。
  3. 同轴电缆 抗干扰较好；带宽有限；现在很少使用。
  4. 无线介质（无线电波） 无需布线，灵活；易受干扰，存在信号衰减。

6.数据链路层的特点是什么？​

  • "透明性":指该层上传输数据的内容、格式及编码没有限制，也没有必要解释信息结构的意义。
  • "可靠性": 让高层用户不必担心（丢失信息、干扰信息、顺序错误等情况）

7.链路层的数据单位是什么？​

帧是数据链路层的数据传送单位。

由于物理层不保证原始比特流的正确性，数据链路层将比特流组合成帧，以帧为单位传输，并在帧中加入校验码，使接收方能发现传输中的差错，从而只对出错的有限数据进行重发。

8.简述4种可行的成帧方法。​

  • ① 字符计数法：在帧头用一个字段标明帧内字符数。缺点是计数字段出错会造成无法纠正的错误，现已很少采用。
  • ② 首尾标志法(字符填充)：以DLE STX开头、DLE ETX结束，遇到DLE字符则插入DLE转义。缺点是使用麻烦、依赖ASCII编码、兼容性差。
  • ③ 首尾标志法(位填充)：用特殊比特串01111110作为开始和结束标志，发送数据中出现01111110时以0111111010形式传送。允许任意长短字符，易于硬件实现，性能优于字符填充法。
  • ④ 物理层编码违例法：在物理层采用特定比特编码方法时使用，适用于采用冗余技术的网络，如局域网IEEE 802标准。

模拟数据链路层帧（以太网帧）​

物理层过来的原始比特（图片数据片段，一串0、1）： 1011001010011100 【这就是上层下来的数据（载荷）】

✅封装：加上【帧头】+【帧尾】

【帧头】| 载荷(数据)        |【帧尾CRC校验】
目的MAC | 源MAC |类型| 1011001010011100 | CRC校验码

完整二进制样例

  • 目的MAC（目标网卡地址，帧头一部分）：00001111 00001111 00001111
  • 源MAC（发送方网卡地址，帧头一部分）：11110000 11110000 11110000
  • 类型字段（帧头，标记上层是IP）：00001000 00000000
  • 载荷（图片数据）：1011001010011100
  • 帧尾CRC校验码：10011101

组装成完整帧： 000011110000111100001111 111100001111000011110000 0000100000000000 1011001010011100 10011101

一句话解释

  1. 帧头：存放目的MAC、源MAC、类型。告诉交换机：这帧从哪块网卡来、要发给局域网里哪块网卡。
  2. 载荷：就是网络层交付过来的数据包（咱们例子里是微信图片的一段二进制）
  3. 帧尾CRC：校验码。接收方收到整个帧，重新计算校验值，判断传输时比特有没有损坏。
  4. 接收端解封装操作：收到完整帧 → 先用帧尾CRC校验，无误 → 剥掉帧头+帧尾，拿出中间载荷，交给网络层。

9.ARQ是什么？​

ARQ即自动请求重发方法，是数据链路层控制差错的方法。

  • 发送方将要发送的数据帧附加一定的冗余检错码一并发送
  • 接收方根据检错码对数据帧进行错误检测；若发现错误，就发送请求重发应答，
  • 发送方收到后重新传送该数据帧。

10.ARQ方法最基本的两种方案是什么？​

最基本的两种方案是:

  • 空闲重发请求（Idle RQ）
  • 连续重发请求（Continuous RQ）。
    • Go-back-N
    • 选择重发

11.链路层和其他层的区别​

  1. 数据链路层：相邻节点之间，用MAC地址。（同一个小区里面，楼栋之间送货）
  2. 网络层：主机‑主机跨网络，用IP地址。（从一个城市送到另外一座城市）
  3. 传输层：进程‑进程，用端口号。（送到家里交给对应的软件）
  4. 物理层只管一长串连续01，分不清哪里是一段数据的开头结尾；
  5. 数据链路层加帧头帧尾，把连续比特切分成帧，识别一段数据的起点终点。
