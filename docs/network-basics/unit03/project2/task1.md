## 知识点
### 1. 物理层是什么

物理层负责在物理传输介质上将比特流从一个节点传输到下一个节点，也就是把比特变成信号发出去，并在另一端正确接收。

### 2.物理层的典型设备

- 中继器、集线器(只放大电信号，广播转发比特，不能识别 MAC 地址。)

### 3.物理层的传输介质
- 双绞线、光纤、同轴电缆、无线电波（WiFi 无线信号）；
- 标准举例：RJ45 网线接口、RS232。

### 3.物理层的主要功能

1. 保证物理线路通畅：为数据链路层提供物理连接，建立、维持、断开物理通路。
2. 定义物理接口特性：机械特性、电气特性、功能特性、规程特性。
3. 将比特流转换为传输介质上的电 / 光信号，完成比特的发送与接收。
4. 规定传输速率、同步方式、传输方向（单工、半双工、全双工）。
5. 对信号进行放大，补偿传输带来的信号衰减。

### 4.物理层的物理接口特性是什么

四大特性
- 机械特性：物理接口的外形（RJ45、8针、USB、Typec-C）
- 电气特性: 就电特性，物理接口上的电信号具体参数（比如：用多大电压表示0和1）
- 功能特性：规定每条信号线的用途。（哪条线发数据，哪条线收数据，哪条线是地线）
- 规程特性：如何使用接口线。
  - 建立连接和拆除连接的规则和顺序。
  - 规程特性与信息传输方式有关
    - 信息传输方式：单工、半双工、全双工

### 5.物理层和其他层的区别是什么
1. **处理对象不同**
物理层：处理**比特（0、1信号）**，看不到完整数据、地址；
上层：数据链路层处理帧，网络层处理分组，传输层处理段，应用层处理应用数据。

2. **工作内容不同**
物理层：只负责电/光信号传输、放大，**不做差错校验、寻址、封装**；
上层：负责封装、地址识别、纠错、路由、端口、应用交互。

3. **设备不同**
物理层：中继器、集线器；
数据链路层：网桥、交换机；网络层：路由器。

4. **PDU（协议数据单元）不同**
物理层PDU：**比特 bit**
数据链路层：帧 frame
网络层：分组/包 packet
传输层：段 segment / 数据报 datagram

5. **关注点**
物理层：**传输介质、接口、信号**；
上层：数据内容、目标地址、数据可靠性。
