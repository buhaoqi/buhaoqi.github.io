## 知识点
1. 实体是什么？
答：每一层中，用于实现该层功能的活动单元被称为实体（Entity）实体既可以是

- 软件实体：进程、电子邮件系统、应用程序；软件实体可以嵌入在本地操作系统中，或者用户应用程序中。
- 硬件实体：终端、智能输入/输出芯片



2. 什么是对等实体？
答：
**不同主机上，处在同一网络层次、执行相同功能的实体，称为对等实体**

例子：主机 A 传输层的传输实体 和 主机 B 传输层的传输实体，互为对等实体。

简化：不同主机同一层次、功能相同的实体。例：两台主机传输层的传输实体互为对等实体

3. 传输实体是什么
传输层里负责实现传输层全部功能的软件 / 硬件模块，就是传输层的实体

传输层中实现传输层服务的模块（TCP/UDP）

举例：
主机 A 的 TCP 模块、主机 B 的 TCP 模块，都是**传输实体**；UDP 模块也属于传输实体。

4. 对等层是什么？
答：不同主机之间的相同层次被称为对等层（Peer）。

7. 对等层协议是什么？
答：对等实体之间交换数据或通信时必须遵守的规则称为对等层协议（Peer Protocol）。

对等实体之间逻辑通信，双方互相交换协议数据单元（PDU），按约定规则解析对方发来的数据。

除物理层外，其他六个层都存在对应的协议。

对等层协议是不同主机同一层次对等实体交换数据时遵守的规则，对等实体间需要传递并解析协议数据单元。
物理层只在传输介质上传送原始比特流，没有协议数据单元，不存在对等实体之间的数据封装与解析过程。物理层仅规定硬件接口的机械、电气等特性，因此物理层没有对等层协议。其余六层对等实体间都有对应的协议数据单元，需要协议完成双方数据交互。

- 2~7 层：对等实体互相发 PDU → 有对等协议
- 物理层：只传裸比特，无 PDU → 无对等层协议

8. 对等层之间通信的特点是什么
答：对等层之间的通信是虚拟通信，它们之间的通信是使用下一层提供的服务来实现的。

9. “协议是水平的“这句话的含义？
答：同一网络中不同主机的对等层，要安装运行相同的网络协议，主机间才能进行有效通信，概括为“协议是水平的”。

协议是对等实体之间的约定，作用在**同一层次**（水平方向）。不同主机同一层的对等实体，依靠相同协议完成逻辑通信，所以说协议是水平的。

> 
> 配套对比考点：**服务是垂直的**
> 下层实体向上层实体提供服务，是在同一台主机内部，由低层向高层提供，是垂直方向。

精简版（适合填空 / 短答）

协议作用于不同主机的**对等层（水平方向）**，对等实体之间依靠协议通信，因此协议是水平的。

考试一句话区分

✅ 协议：水平，**主机之间，同层对等实体**
✅ 服务：垂直，**同一主机，下层给上层**

> 
> 举例子：
> 主机 A 传输层 TCP ↔ 主机 B 传输层 TCP（水平，遵守 TCP 协议）
> 同一主机：网络层 → 传输层（垂直，下层提供服务）

10. 服务是什么？
答：在OSI分层结构模型中，每一层实体为相邻的上一层实体提供的通信功能称为服务。

11. “服务是垂直的”这句话的含义是什么

答：N层实体利用N-1层实体所提供的服务，向N+1层实体提供功能更强大的服务，概括为“服务是垂直的”。

12. N层实体如何和下层服务打交道？
答：不需要知道N-1层实体所提供的服务是如何实现的以及N-1层实体间的协议，只需要知道下层能提供哪些服务、通过什么接口提供。

13. 什么是SAP？
答：N层的服务访问点SAP（Service Access Point）是N层实体提供服务给N+1层的地方，可以理解为下层实体之间的逻辑传输通道。

每一层的SAP都有一个唯一标明它的地址，一个N层可能存在多个SAP。

15. 接口和SAP的关系是什么？
答：接口是为其他实体提供服务的入口，是一个大的概念；SAP是下层对高层提供服务的一个入口，是对高层的一个逻辑接口；接口包含SAP，也还包括其他服务提供方式。

16. OSI环境中依靠哪3种数据单元完成通信传输？

- 服务数据单元SDU：为实现N层服务所要传送的逻辑数据单元，称为N层服务数据单元（Service Data Unit，SDU），简称（N）SDU。

- 协议数据单元PDU：对等实体之间为实现该层协议所交换的信息单元（Protocol Data Unit，PDU），称为协议数据单元。

- 接口数据单元IDU：在同一系统上下两层实体的交换信息中，经过SAP的信息单元（Interface Data Unit，IDU），称为接口数据单元。

19. 发送端N层实体对SDU如何处理？接收端呢？
答：发送端：N层实体根据本层的协议，将一个SDU划分为多个PDU；接收端：N层实体要将多个PDU恢复成一个本层的SDU。


21. N层IDU由哪两部分组成？
答：N层IDU包括N层服务数据单元和一些供下一层实体用的控制信息（称为接口控制信息ICI）。

22. 相邻两层中，谁是服务提供者，谁是服务用户？
答：下层为服务提供者，上层为服务用户。

23. 下层向上层提供的服务分为哪两类？
答：面向连接服务（Connection Oriented Service）和无连接服务（Connectionless Service）。

24. 简述面向连接服务的通信过程。
答：两个N层实体在数据交换前，必须先建立连接，初始化状态信息，并且为该层实体的信息传输建立一个通道；传输阶段跟踪PDU与SDU交换；数据交换结束后释放连接，去除状态信息，释放网络资源。

25. 简述无连接服务的通信特点。
答：两个N层实体通信前，不需要先建立一个连接。发送端到相同目标地址的信息块都独立发送，接收端无需返回确认信息。如果信息块在传输中丢失，就不再重发。无连接的服务通常被称为数据报服务。

26. OSI模型中服务通过什么来描述？一共分为几类？
答：服务是通过一组服务原语（Primitive）来描述的；服务原语被分为4类。

27. 四类服务原语分别是什么？
答：请求（Request）、指示（Indication）、响应（Response）、证实（Confirmation）。

28. 请求（Request）原语的作用？
答：由服务用户发往服务提供者，请求它完成某项工作。

29. 指示（Indication）原语的作用？
答：由服务提供者发往服务用户，指示发生了某些事件。

30. 响应（Response）原语的作用？
答：由服务用户发往服务提供者，对前面已经发出的指示的响应。

31. 证实（Confirmation）原语的作用？
答：由服务提供者发往服务用户，对前面已经发出的请求的证实。

32. OSI模型数据封装时，数据发送方向上层向下层传递数据，每层进行什么操作？
答：每一层都会给上层递交下来的数据加上自己的报头；数据链路层还要加上尾部DT，形成帧。

33. 写出各层报头缩写：应用层、表示层、会话层、传输层、网络层、数据链路层。
答：应用层AH，表示层PH，会话层SH，传输层TH，网络层NH，数据链路层DH。

34. 目标主机接收数据时，数据链路层对收到的帧做哪些处理？
答：数据链路层负责去掉数据帧的帧头部DH和尾部DT，同时还进行数据校验。如果数据没有出错，则递交到网络层。

35. 接收端OSI模型的数据解封装流程特点是什么？
答：数据从下层向上层递交，每一层会剥掉本层对应的头部（和尾部），逐层递交，最终原始数据递交给目标主机的应用程序。
