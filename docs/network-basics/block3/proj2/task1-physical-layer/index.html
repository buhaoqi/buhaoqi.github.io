任务一 物理层

知识点​

1.物理层在OSI模型中的地位是什么？​

物理层（Physical Layer）位于OSI参考模型的最底层，是构成计算机网络的基础。所有通信设备、主机都需要用物理线路相互连接。物理层建立在通信介质之上，是系统与通信介质的物理接口，因此物理层是整个开放系统的基础。

数据传输单位：比特（bit）

2.物理层的主要功能是什么？​

物理层负责网络设备之间实际的物理连接，将每个比特从一个节点传输到下一个节点。在接收数据后，物理层将接收到的信号转换成0和1上交给数据链路层。

核心功能：提供数据终端设备（DTE，如计算机）和数据通信设备（DCE，如网卡）之间的二进制数据传输的物理连接，将数据信息以二进制串形式从一个实体经物理信道传输到另一实体，向数据链路层提供透明的比特流传输服务。

透明传输的含义：确保当发送实体发送信号1时，接收实体能收到信号1，而不是信号0；发送实体发送信号0时，接收实体能收到信号0，而非信号1。

具体功能包括：通信线路的建立、保持和断开物理连接3个过程。

3.物理层接口的四个特性是什么？​

为了实现物理层的功能，需要规定物理接口的机械特性、电气特性、功能特性和规程特性等，以便不同制造厂家各自独立地制造设备又能使各厂家的产品相互兼容。

特性说明
机械特性指DTE和DCE之间接口互联时的连接方式，包括可插接连接器的尺寸、插头的针和孔的数量与排列状况、信号线数目和排列方式、连接器的形状等
电气特性指DTE和DCE接口线的电气连接方式，规定了导线的电气连接方式、信号电平（如多大电压表示0，多少电压表示1）、信号波形和参数、同步方式等
功能特性指DTE和DCE间每一条接口线的功能分配和确切定义，包括每条信号线的用途（如发送数据线、接收数据线、信号地线和时钟线等）
规程特性定义了如何使用这些接口线，即完成物理连接的建立、维护、信息交换和拆除连接时，DTE和DCE在各线路上的动作规则和动作序列。与信息的传输方式（单工、半双工、全双工）有关

4.DTE和DCE分别是什么？​

缩写全称说明例子
DTEData Terminal Equipment（数据终端设备）信源和信宿设备计算机
DCEData Communication Equipment（数据通信设备）连接DTE与传输信道的设备网卡、调制解调器

5.EIA-232-D标准的具体内容是什么？​

EIA-232-D是常用的物理层标准（简称232接口），由美国电子工业协会EIA制定，对应的OSI标准为ISO 2110。

特性具体内容
机械特性宽47.04 +/- 0.13mm（螺丝中心间的距离）的25针插头/插座
电气特性低于-3伏的电压表示1，高于+4伏的电压表示0
功能特性规定了25针分别与哪些电路连接及信号线信号的含义
规程特性协议基于"行为-应答"的关系
