## 知识点

### 1.网络层在OSI模型中的地位是什么？

网络层是OSI参考模型中的**第三层**，介于传输层和数据链路层之间。其功能主要是管理网络中的数据通信，将数据包从源节点端经过若干个中间节点传送到目的节点，从而向传输层提供最基本的端到端的数据传送服务。

**数据传输单位**：数据包（Packet）

### 2.网络层的主要功能有哪些？

网络层的主要功能包括：**寻址、路由选择、拥塞控制及网络互联**。

### 3.什么是寻址？

网络层用于解决节点到节点间的传输。由于各网络节点不一定相邻，必须对节点做出统一标准下的身份标识（如互联网中的IP地址），才能进行报文的通信。因此，网络节点的编址问题是网络层必须重点解决的问题。

**OSI网络层编址**：采用NSAP（网络服务访问点，Network Service Access Point）地址来标识源端和目标端。NSAP地址是一个通用的网络地址标准。

### 4.什么是路由选择？

路由选择是网络层的核心功能，负责确定收到的报文应从哪一个输出接口发出。

**与通信子网交换方式的关系**：

- 如果采用**数据包交换方式**：每一个节点对收到的每一个报文都要做路由选择
- 如果采用**虚电路交换方式**：仅当建立一条新的虚电路时做一次路由选择，此后所有报文在这条虚电路上传输

### 5.路由选择算法应具备哪些特点？

| 特点 | 说明 |
|------|------|
| **正确性** | 算法要简单有效 |
| **简单性** | 算法不应过于复杂 |
| **强壮性** | 能适应网络拓扑结构的变化及通信量的变化，长时间无错误运行 |
| **稳定性** | 动态运行一段时间后能趋于稳定 |
| **公平性** | 公平对待各节点 |
| **最优性** | 找到最优路径 |

**注意**：公平性和最优性有时候是相互矛盾的，优秀的路由算法应能找到两者之间的平衡点。

### 6.路由选择算法分为哪两类？

| 类型 | 特点 |
|------|------|
| **动态路由算法** | 能根据网络当前的传输量和拓扑结构进行路由选择，算法比较复杂 |
| **静态路由算法** | 算法比较简单 |

### 7.什么是拥塞控制？

当通信子网中有过多的报文时，子网中的中间节点可能因没有空闲缓冲区而不断地丢弃报文，从而导致整个网络性能降低，这种现象称为**拥塞**。

**控制策略**：缓冲区预分配、报文丢弃法、流量控制、抑制报文分组等。

### 8.什么是RIP路由信息协议？

| 项目 | 内容 |
|------|------|
| **全称** | Routing Information Protocol |
| **缩写** | RIP |
| **适用范围** | 小型、同类型网络 |
| **算法基础** | 距离矢量算法 |
| **衡量标准** | "跳数"——从源到目标节点需要经过的路由器的个数 |
| **传输协议** | 处于UDP协议上层，路由信息封装在UDP数据报中 |
| **数据包类型** | 更新（UPDATES）和请求（REQUESTS） |
| **更新周期** | 每隔30秒广播更新信息 |

**工作过程**：

- RIP作为系统长驻进程存在于路由器中
- 负责从网络系统的其他路由器接收路由信息，动态维护路由表
- 同时广播本路由器的路由信息，通知相邻路由器作相应修改
- 路由选择信息数据库每个条目由"局域网上能达到的IP地址"和"与该网络的距离"两部分组成

### 9.什么是OSPF开放最短路径优先协议？

| 项目 | 内容 |
|------|------|
| **全称** | Open Shortest Path First |
| **缩写** | OSPF |
| **适用范围** | 较大型的网络 |
| **算法基础** | 最短路径优先算法 |
| **类型** | 内部网关协议，基于链路状态 |
| **封装方式** | 直接使用IP数据报进行封装传送 |
| **链路状态信息** | 连通性、费用、距离、时延、带宽等 |

**工作原理**：

1. 使用泛洪法向所有输出接口发送信息，最终所有路由器都会收到消息
2. 发送的信息是与本路由器相邻的路由器的链路状态信息
3. 只有当链路状态发生变化时，才使用泛洪法转发信息
4. 每个路由器最终得到一个全网的拓扑结构（类似于带权无向图）
5. 根据拓扑结构使用最短路径算法找到一条最短路径

**与RIP的区别**：OSPF考虑路由更为全面（不仅考虑跳数，还考虑时延、带宽等），每个路由器能得到全网拓扑结构（RIP没有这个），效率更高。

### 10.什么是BGP边界网关协议？

| 项目 | 内容 |
|------|------|
| **全称** | Border Gateway Protocol |
| **缩写** | BGP |
| **类型** | 路径向量协议 |
| **目标** | 不是发现最短路径，而是找到合适的路径 |

**设计考虑**：

1. 互联网规模太大，使用最短路径算法计算时间将会很久
2. 不同的自治系统有不同的策略，有些路由器可能会过滤一些请求

**工作过程**：

1. 在每个独立网络中选择至少一个BGP主站
2. BGP主站与相邻的独立网络系统交换信息（包括到达某个网络所要经过的一系列独立网络）
3. 各BGP主站根据所采用的策略从收到的路由信息中找出到达目标独立网络的合适路由

### 11.三种路由算法的综合对比

| 对比项 | RIP | OSPF | BGP |
|-------|-----|------|-----|
| **类型** | 内部网关协议 | 内部网关协议 | 外部网关协议 |
| **算法** | 距离矢量算法 | 最短路径优先算法 | 路径向量协议 |
| **衡量标准** | 跳数 | 链路状态（连通性、费用、距离、时延、带宽） | 策略 |
| **封装** | UDP数据报 | IP数据报 | - |
| **更新方式** | 每30秒广播 | 链路状态变化时泛洪 | BGP主站间交换 |
| **全网拓扑** | 无 | 有 | - |
| **适用规模** | 小型网络 | 较大型网络 | 互联网规模 |
| **目标** | 最少跳数路径 | 最短路径 | 合适路径 |
