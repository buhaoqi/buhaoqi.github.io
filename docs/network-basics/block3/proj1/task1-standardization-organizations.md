## 知识点

### 1.什么是"标准"？为什么网络需要标准？

**标准**包含某一特定产品或服务应如何设计或实施的技术规范或其他要求。通过标准，不同的生产厂商可以确保产品、生产过程以及服务适合于具体要求。

**网络标准的重要性**：由于目前网络中所使用的硬件、软件种类繁多，标准尤其重要。如果不遵守共同的标准，就会出现：

- 一种网络硬件不能与另一种网络硬件兼容
- 一个网络应用程序不能与另一个网络应用程序通信

标准化在网络建设领域的重要性主要包括：

1. 保证网络资源的兼容性
2. 提高系统和数据的安全性
3. 改善网络工程质量
4. 加强网络管理

### 2.国际标准化组织（ISO）

| 项目 | 内容 |
|------|------|
| **全称** | International Standards Organization |
| **缩写** | ISO |
| **总部** | 瑞士日内瓦 |
| **性质** | 代表全球各个国家的标准组织的集体 |
| **目标** | 制定国际技术标准以促进全球信息交换和无障碍贸易 |
| **适用领域** | 信息处理和通信工业、纺织品业、包装业、货物分发、能源生产和利用、造船业以及银行业务和金融服务等 |

### 3.电子工业联盟（EIA）

| 项目 | 内容 |
|------|------|
| **全称** | Electronic Industries Association |
| **缩写** | EIA |
| **性质** | 商业组织，由美国主要的电子制造公司组成 |
| **历史** | 1924年作为RMA（无线电生产厂商协会）产生 |
| **涉及领域** | 电视机、半导体、计算机以及网络设备 |

**主要职能**：

- 为自己的成员设定标准
- 帮助制定ANSI标准
- 促使建立更有利于计算机和电子工业发展的立法

**下属组织**：

- 电信工业协会（TIA）
- 用户电子生产商协会（CEMA）
- 电子部件组装、设备与供应协会（ECA）
- 联合电子设备工程委员会（JEDEC）
- 固态技术协会
- 政府处
- 电子信息组（EIG）

### 4.电气与电子工程师学会（IEEE）

| 项目 | 内容 |
|------|------|
| **全称** | Institute of Electrical and Electronics Engineers |
| **缩写** | IEEE（也称为I3E） |
| **性质** | 由工程专业人员组成的国际组织 |
| **目的** | 促进电气工程和计算机科学领域的发展和教育 |

**主要活动**：

- 每年主办大量的研讨会
- 发行刊物以推动技术的进步
- 有自己的标准委员会，为电子和计算机工业制定标准
- 对其他标准制定组织（如ANSI）的工作提供帮助

### 5.国际电信同盟（ITU）

| 项目 | 内容 |
|------|------|
| **全称** | International Telecommunication Union |
| **缩写** | ITU |
| **性质** | 隶属于联合国的国际电信管理机构 |
| **曾用名** | CCITT（国际电报电话协商委员会） |

**管理范围**：

- 无线电和电视频率
- 卫星和电话的规范
- 网络基础设施
- 全球通信所使用的关税率
- 为发展中国家提供技术支持和设备以提高其技术基础

### 6.国际电工委员会（IEC）

| 项目 | 内容 |
|------|------|
| **全称** | International Electrotechnical Commission |
| **缩写** | IEC |
| **成立时间** | 1906年 |
| **创始人** | 英国电气工程师协会（IEE）和美国电气电子工程师协会（IEEE）等共同成立 |
| **地位** | 世界上成立最早的国际性电工标准化机构 |

**主要职责**：

- 负责有关电气工程和电子工程领域中的国际标准化工作
- 与ISO联合制订信息技术领域中的国际标准
- 制订的最有名的OSI（开放系统互联）标准，成为各计算机网络之间进行接口的权威技术

### 7.国家标准化管理委员会（SAPRC）

| 项目 | 内容 |
|------|------|
| **全称** | Standardization Administration of the People's Republic of China |
| **缩写** | SAPRC |
| **性质** | 我国管理全国标准化工作的机构 |

**主要职责**：

- 代表国家参加国际标准化组织、国际电工委员会和其他国际或区域性标准化组织
- 对国际标准进行评估和必要的修订
- 使之成为国家标准

### 8.各标准化组织综合对比

| 组织 | 缩写 | 性质 | 主要领域 |
|------|------|------|---------|
| 国际标准化组织 | ISO | 全球国家标准组织集体 | 国际技术标准，促进信息交换和无障碍贸易 |
| 电子工业联盟 | EIA | 美国商业组织 | 电子产品、计算机、网络设备标准 |
| 电气与电子工程师学会 | IEEE | 国际专业组织 | 电气工程、计算机科学标准 |
| 国际电信同盟 | ITU | 联合国机构 | 无线电、电视频率、卫星、电话、网络基础设施 |
| 国际电工委员会 | IEC | 最早的国际电工标准化机构 | 电气工程、电子工程标准化 |
| 国家标准化管理委员会 | SAPRC | 中国政府机构 | 中国国家标准管理 |
