逐题解析：

  • 第1题 B：IBM公司推出的网络体系结构是SNA（系统网络体系结构）。DAA是DEC公司的DNA，TCP/IP是ARPANET发展而来的事实标准，ARPA是美国国防部高级研究计划局（机构名，非体系结构名）。
  • 第2题 C：协议是水平的（对等层之间的通信规则），服务是垂直的（相邻上下层之间通过SAP提供）。
  • 第3题 C：网络层负责路由选择、拥塞控制和网络互联；传输层负责端到端可靠传输。
  • 第4题 C：路由选择的实质是每个网络节点收到一个分组后，确定到达下一个节点的路径，而不是建立物理或逻辑链路。
  • 第5题 C：端到端通信是通信双方（端点）之间的通信，端点在资源子网中（主机、终端），通信子网只负责数据转发。
  • 第6题 D：数据链路层的流量控制是相邻节点之间（链路上）的流量控制；源端到目的端的流量控制由传输层完成。
  • 第7题 B：7DH = 0111 1101，从左到右扫描发现连续 5 个 1（011111 中的后 5 位），在其后插入一个 0，得到 0 11111 0 01 = 011111001，故选 B。
  • 第8题 B：HDLC是面向比特型的同步协议；面向字符型的典型协议是BSC，面向字节计数的典型协议是DDCMP。
  • 第9题 C：数据链路层用**物理地址（MAC地址/硬件地址）**标识同一链路上的主机；端口号属传输层，IP地址属网络层。
  • 第10题 D：规定通信设备与传输媒体之间接口特性（机械、电气、功能、规程）的是物理层。
  • 第11题 D：通信子网由物理层、数据链路层、网络层组成，其中网络层是通信子网的最高层，资源子网的最高层是应用层。
  • 第12题 D：A、B、C均为教材所列的分层原则（各层相对独立、层次数量适中、同类功能集中于同一层）；D项"高层对低层提供的服务与低层如何完成无关"说的是层间透明性带来的结果，并非划分层次的原则本身，故选 D。
  • 第13题 D：分层的目的之一就是保持网络灵活且易于修改（A），做法是把相关的网络功能组合在同一层中（C）；B项错误，各体系结构的层次名称和功能并不相同。

3.问答题参考答案​

1. 网络的体系结构为什么要采用分层的结构？

  • 结构清晰、便于实现：把复杂的通信问题分解为若干个相对独立、功能单一的层次，每一层只解决一部分问题，降低整体设计与实现的难度。
  • 各层独立、便于维护：某一层的内部实现发生变化，只要接口不变，就不影响其他层。
  • 灵活、易于扩展：某层功能需要更新时只改动该层，便于技术演进。
  • 促进标准化：每层的功能与接口有统一定义，不同厂商的设备可以互联互通。
  • 便于教学与学习：分层后概念清晰，便于分层次理解和描述网络行为。

2. 什么叫网络体系结构？为什么要制定OSI开放系统互联参考模型？

  • 网络体系结构：计算机网络各层及其协议的集合，即网络的分层结构、各层功能以及同层实体间通信规则的总体描述。体系结构是抽象的，只描述"做什么"，不规定"怎样做"（实现细节由具体产品决定）。
  • 制定OSI的原因：各厂商自行研制的网络体系结构（如IBM的SNA、DEC的DNA）互不兼容，异构系统之间无法互联。ISO制定OSI/RM，为不同厂商、不同型号的计算机互联提供统一的标准框架，实现开放系统之间的互操作，使网络设计有章可循。

3. 网络体系结构分层的原则是什么？

  1. 各层相对独立，某一层的内部变化不影响另一层；
  2. 层次数量适中，不应过多，也不宜太少；
  3. 每层具有特定的功能，类似功能尽量集中在同一层；
  4. 层间边界的选择应使通过接口的信息量尽可能少；
  5. 每层只与相邻层发生接口关系，下层对上层提供服务，上层使用下层的服务；
  6. 对等层之间按协议通信，不同节点的对等层安装相同的协议。

4. 举出一个生活中采用分层的实例。

邮政系统是典型的分层实例：用户只需写信、装信封并投递（相当于应用层）；邮政局负责收寄、盖邮戳、分拣（相当于表示层、会话层）；运输部门负责火车、汽车、飞机运送（相当于网络层、数据链路层）；道路与交通工具本身负责实际位移（相当于物理层）。

好处是：用户不必关心邮件如何运输，运输部门更换车辆或路线也不影响用户写信的方式；每一层只对本层的上一层负责，层与层之间有明确的交接规则。

5. 什么是网络通信协议？简述网络协议的3个要素。

网络协议是计算机网络中进行数据交换而建立的规则、标准或约定的集合。三要素：

要素含义
语法定义数据与控制信息的结构或格式，即"怎么讲"（报文的字段与格式）
语义确定控制信息的选择与使用，以及完成何种动作、做出何种响应，即"讲什么"（含义）
时序规定各步操作的实现顺序，也称定时、同步，即"什么时候讲"（顺序与速度匹配）

6. 协议和服务有什么区别？

比较项协议服务
方向水平方向，对等层之间垂直方向，相邻上下层之间
内容对等实体之间交换数据时必须遵守的规则下层向上层提供的通信能力（功能）
是否可见对上层是透明的，上层不需要知道协议细节上层看得见，通过服务访问点SAP使用
关系协议是"如何实现"服务是"提供什么"，由协议来实现

要点：服务由协议实现，但协议对服务的使用者是透明的；本层协议的变化不影响上层所得到的服务。

7. OSI/RM模型划分为哪些层次？其中哪几层体现了通信子网的功能？

OSI/RM分为7层，从低到高依次为：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

其中低3层（物理层、数据链路层、网络层）体现通信子网的功能，负责数据传输与交换；高3层（会话层、表示层、应用层）体现资源子网的功能，面向信息处理；传输层是两者的中间层，起承上启下的作用，实现端到端的通信。

8. 数据链路层和网络层有哪些主要功能？

层次主要功能
数据链路层①链路管理（建立、维持、释放数据链路）；②组装成帧（帧同步）；③差错控制（CRC校验、ARQ重传）；④流量控制（滑动窗口）；⑤寻址（用MAC/物理地址标识节点）；⑥透明传输（零比特插入法、字符填充）
网络层①逻辑寻址（IP地址等网络地址）；②路由选择；③拥塞控制；④网络互联（异构网互连）；⑤分组的分片与重组；⑥差错报告与流量控制

9. 简单描述OSI模型中各层数据单位有什么不同。

层次数据单位说明
应用层、表示层、会话层报文（Message）用户间交换的完整信息单位
传输层数据段（Segment）将报文划分成较小的数据段，便于传输，接收端按序重组
网络层数据包/分组（Packet）加上含源、目的网络地址的包头
数据链路层帧（Frame）在包的基础上加首部和尾部（含MAC地址、FCS校验）
物理层比特（bit）以比特流形式在传输媒体上传送

数据自上而下逐层封装：报文 → 数据段 → 数据包 → 帧 → 比特流；接收端自下而上逐层拆封。

10. 简单比较OSI模型中数据链路层、网络层和传输层地址的概念有什么区别？

层次地址类型作用范围特点
数据链路层物理地址（MAC地址/硬件地址）同一链路（同一局域网）内的相邻节点由网卡厂家固化，通常48位，标识"某一链路上的某个节点"；跨网时逐跳改变
网络层逻辑地址（IP地址等网络地址）整个互联网，全局唯一由网络管理员/协议分配，标识"网络中的某台主机"，路由选择依据它，端到端传送过程中一般不变
传输层端口号主机内部16位，标识主机中的某个进程/应用，实现进程到进程（端到端）的通信

一句话概括：MAC地址找人（节点）、IP地址找主机（网络位置）、端口号找进程（应用）。

11. 局域网由哪些层次组成，它为什么没有网络层？请说明原因。

  • 组成：局域网的参考模型（IEEE 802系列标准）只对应OSI的物理层和数据链路层；其中数据链路层又划分为介质访问控制子层（MAC）和逻辑链路控制子层（LLC）。
  • 没有网络层的原因：
    1. 局域网覆盖范围小，站点通过共享传输介质直接相连，任意两个站点之间不需要经过中间节点转接，因而不需要路由选择；
    2. 局域网内通信依靠MAC地址即可完成寻址，不必使用网络层地址；
    3. 介质访问控制（如CSMA/CD）等原本由低层完成的功能已能保证数据正确送达，网络层的功能被弱化或由低两层替代。

当局域网需要与其他网络互联时，则由网间连接设备（路由器）来完成网络层及以上的功能。

12. 下述问题在OSI的哪一层描述？

小题所描述的问题所属层次理由
（1）确定一接插件的机械尺寸和电气特性物理层属于接口的机械特性与电气特性
（2）将传输的数据划分为帧数据链路层组装成帧是数据链路层的核心功能
（3）决定路由网络层路由选择由网络层完成
（4）检查远程登录用户身份的合法性应用层用户身份认证由具体的网络应用（如Telnet、登录程序）实现
（5）将数据压缩和解压缩表示层压缩、加密、语法转换是表示层的三大任务
（6）控制打印机打印头换行应用层打印控制属于面向用户的具体应用功能，由应用程序（应用层）处理
