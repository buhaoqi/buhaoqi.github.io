## 知识点

### 1.传输层在OSI模型中的地位是什么？

传输层（Transport Layer）位于OSI模型的**第四层**，负责**端口到端口**的通信。它具有以下特殊地位：

- 是七层模型中负责**数据通信的最高层**
- 又是面向网络通信的低三层和面向信息处理的高三层之间的**中间层**
- 是七层模型中**最重要、最关键**的一层
- 是**唯一**负责总体数据传输和控制的一层

**数据传输单位**：数据段（Segment）

### 2.传输层的两个主要目的是什么？

1. **提供可靠的端到端的通信**
2. **向会话层提供独立于网络的传输服务**

### 3.传输层的基本功能是什么？

- 从会话层接收数据
- 如果接收的报文过大，则将报文划分成较小的**数据段（Segment）**，再传送给网络层
- 保证各段信息的正确性
- 在接收端将接收的较小报文按照发送顺序拼接成报文，正确地交给接收端的会话层

### 4.传输层提供哪些服务？

传输层提供的服务包括以下方面：

| 服务 | 说明 |
|------|------|
| **服务类型** | 面向连接的服务（可靠，需要建立/维持/拆除连接，提供流量控制、差错控制和序列控制）和面向无连接的服务（数据报服务，不可靠） |
| **服务等级** | 允许用户选择传输层所提供的服务等级，包括差错和丢失数据的程度、允许的平均延迟和最大延迟、允许的平均吞吐率及优先级水平等 |
| **数据传输** | 在两个传输实体之间传输用户数据和控制数据，分为普通数据传输和紧急数据传输（优先权高，可终止当前数据传输） |
| **用户接口** | 提供多种用户接口方式，包括过程调用、通过邮箱传输数据和参数等 |
| **连接管理** | 连接建立、拆除和终止连接的功能 |
| **状态报告** | 向传输层用户提供传输实体或传输连接的状态信息 |
| **安全保密** | 对发送者和接收者的确认、数据的加密等 |

### 5.传输层协议服务等级分为哪4类？

| 等级 | 说明 |
|------|------|
| **可靠的面向连接的协议** | 提供可靠的数据传输 |
| **不可靠的无连接协议** | 提供不可靠的数据报服务 |
| **需要定序和定时运输的话音运输协议** | 适用于语音传输 |
| **需要快速和高可靠的实时协议** | 适用于实时应用 |

### 6.什么是服务质量（QoS）？

服务质量（Quality of Service，QoS）是指在传输连接点之间看到的某些传输连接的特征，反映了传输质量及服务的可用性。

**QoS可用以下参数描述**：

- 连接建立延迟
- 连接建立失败概率
- 吞吐量
- 输送延迟
- 残留差错率
- 连接拆除延迟
- 连接拆除失败概率
- 运输失败率

**特点**：用户可以在连接建立时指明所期望的、可接受的或不可接受的QoS参数值。通常通过连接建立原语在用户与传输服务提供者之间协商QoS，协商好的QoS在整个传输连接的生存期内不变。

### 7.ISO定义了哪5种传输层协议等级？

传输层协议实现的难易程度与网络层提供的服务直接相关。如果网络层服务质量高，则传输层协议容易实现。ISO定义了5种类型的传输层协议：

| 等级 | 名称 | 功能特点 |
|------|------|---------|
| **TP0** | 最简单 | 仅包括连接建立、数据传输和错误报告；没有多路复用、流量控制和拆除连接等功能 |
| **TP1** | 基本错误恢复级 | 在TP0基础上增加了基本差错恢复、流量控制、加速数据传输、连接拆除等功能；但无多路复用功能 |
| **TP2** | 多路复用级 | 具有多路复用功能，包括TP1的功能；但没有错误检测和恢复功能 |
| **TP3** | 差错恢复与多路复用 | 具有差错恢复功能和多路复用功能，集中了TP1、TP2级功能 |
| **TP4** | 最复杂 | 可在网络任务较重时确保高可靠性数据传输；具有差错控制、差错恢复、多路复用功能，还能处理报文丢失、报文重复及网络层和其他各层的错误，并有超时和检验机制 |

### 8.传输层与网络层的关系是什么？

| 对比项 | 传输层 | 网络层 |
|-------|--------|--------|
| **通信类型** | 端到端通信 | 节点到节点通信 |
| **数据单位** | 数据段（Segment） | 数据包（Packet） |
| **地址** | 端口号 | 网络地址（如IP地址） |
| **可靠性** | 提供可靠的端到端通信 | 提供尽力而为的服务 |
| **依赖关系** | 传输层协议依赖于网络层提供的服务质量 | - |

传输层是唯一负责总体数据传输和控制的一层，它向会话层提供独立于网络的传输服务，屏蔽了低三层（网络实体）的详细操作。
