任务二 会话层、表示层和应用层

知识点​

1.OSI高3层的共同特点是什么？​

会话层、表示层和应用层属于OSI模型的高3层，其共同特点：

  1. 处理的信息都是报文，报文是用户间交换的完整信息单位
  2. 提供面向用户的服务
  3. 端到端的数据处理，不考虑信息的传输及怎样传输的问题

2.会话层的主要功能是什么？​

会话层（Session Layer）的主要功能是在两个网络节点间建立、维护和释放面向用户的连接，并对会话进行管理和控制，保证会话数据可靠传输。

会话是指提供建立连接并有序传输数据的一种方法。例如通过会话可以使一个远程终端登录到远程计算机进行文件传输或其他应用。

3.会话连接和传输连接之间有哪3种关系？​

关系说明
一对一一个会话连接对应一个传输连接
一对多一个会话连接对应多个传输连接
多对一多个会话连接对应一个传输连接

4.会话层如何管理对话？​

会话层需要决定使用全双工通信还是半双工通信：

  • 全双工通信：会话层在对话管理中要做的工作就很少
  • 半双工通信：会话层通过数据令牌来协调会话，保证每次只有一个用户能够传输数据

令牌机制：

  1. 会话建立时，先让一个用户得到令牌
  2. 只有获得令牌的用户才有权进行发送
  3. 如果接收方想要发送数据，可以请求获得令牌
  4. 由发送方决定何时放弃
  5. 一旦得到令牌，接收方就转变为发送方

5.会话层的同步功能是什么？​

会话层使用校验点可使通信会话在通信失效时从校验点继续恢复通信，这种能力对于传送大的文件极为重要。

示例：下载一个100MB的文件，当下载到95MB时网络断线，会话层通过在数据流中定义**检查点（Check Point）**来把会话分割成明显的会话单元。当网络故障出现时，从最后一个检查点开始重传数据。

6.常见的会话层协议有哪些？​

  • 结构化查询语言（SQL）
  • 远程进程呼叫（RPC）

7.表示层的主要功能是什么？​

表示层（Presentation Layer）以下的各层只关心可靠地传输比特流，而表示层关心的是传输信息的语法和语义。表示层专门负责有关网络中计算机信息表示方式的内容，包括转换、加密和压缩。

三大功能：

功能说明
语法转换将抽象语法转换成传送语法，并在对方实现相反的转换。涉及代码转换、字符转换、数据格式修改、数据压缩、加密等
语法协商根据应用层的要求协商选用合适的语法，确定传送语法并传送
连接管理利用会话层服务建立表示连接，管理数据传输和同步控制，以及正常或异常地终止连接

8.表示层的语法转换实例是怎样的？​

场景：基于ASCII码的计算机要将信息 HELLO 通过网络传送到基于EBCDIC码的计算机。

  • ASCII编码的 HELLO 对应：48454C4C4F
  • EBCDIC编码的 HELLO 对应：C8C5D3D3D6

如果以ASCII编码发送，虽然下5层可以将 48454C4C4F 正确无误地传送到对方，但在对方计算机中，48454C4C4F 并不表示 HELLO。所以数据在交给接收方计算机时，必须执行转换：

  • 可以是发送方转换
  • 也可是接收方转换
  • 或者双方都向一种标准格式转换

9.表示层的加密和压缩功能是什么？​

  • 加密：数据在发送端被加密，在接收端解密，分别使用加密密钥来对数据进行加密和解密
  • 压缩：通过算法来压缩文件的大小，降低传输费用

10.应用层的主要功能是什么？​

应用层（Application Layer）是OSI参考模型中最靠近用户的一层，负责为用户的应用程序提供网络服务。

与其他层的区别：它不为任何其他OSI层提供服务，而只是为OSI模型以外的应用程序提供服务（如电子表格程序和文字处理程序）。

主要功能：

  • 为相互通信的应用程序或进程之间建立连接
  • 进行同步
  • 建立关于错误纠正和控制数据完整性过程的协商

11.应用层有哪些常见协议？​

  • 文件传输协议
  • 电子邮件协议
  • 超文本传输协议（HTTP）

在OSI参考模型中应用层协议最多、最复杂。

12.OSI七层模型各层功能总结​

层号层名数据单位主要功能所属层次
7应用层报文为应用程序提供网络服务高3层（面向应用）
6表示层报文语法转换、加密、压缩高3层（面向应用）
5会话层报文会话建立、维护、释放、同步高3层（面向应用）
4传输层数据段（Segment）端到端通信、可靠传输中间层
3网络层数据包（Packet）寻址、路由选择、拥塞控制低3层（依赖网络实体）
