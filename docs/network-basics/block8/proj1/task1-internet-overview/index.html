任务一 Internet概述

知识点​

1.模块八与项目一要学什么？​

模块八 学习要点：

  1. 掌握 Internet 的技术实现；
  2. 了解 Internet 接入方式、Internet 上运行的服务；
  3. 了解 Intranet 技术。

重点难点：Internet 技术实现。

项目导读：Internet 是使用 TCP/IP 协议将不同网络互连起来的、世界上分布最广泛的网络，网络中有交换机、路由器等硬件设备、各种不同形式的连接链路、种类繁多的服务器和大量的计算机等终端。Internet 是现代信息社会的基础，是世界上规模最大的网络，其接入方式按照终端数量包括 PSTN、ISDN、局域网接入等多种形式。网页浏览器是用来显示网页服务器系统提供的文件、并支持用户与这些文件进行互动的一种软件，用来显示在网络中以 HTTP、HTTPS 协议共享的文字、音视频或其他类型的信息。本项目学习 Internet 的接入方式及网络浏览器的使用。

目标类别内容
知识目标① 了解 Internet 的发展过程；② 理解对 Internet 进行管理的内涵；③ 了解中国四大互联网络；④ 理解 Internet 的接入规模对 Access 形式的影响；⑤ 熟悉接入 Internet 的各种方式；⑥ 了解浏览器的功能；⑦ 理解浏览器功能，理解 HTML 语言是网页开发语言；⑧ 熟悉常用浏览器的操作
能力目标① 了解 CNNIC 的作用；② 了解 Internet 文化的发展过程；③ 掌握接入 Internet 的接入方式并分析特点；④ 掌握网络地址转换设备在接入 Internet 时的应用；⑤ 了解宽带技术的发展；⑥ 掌握常用浏览器的操作使用方法；⑦ 掌握浏览器与标记语言的关系；⑧ 了解浏览器类软件在功能、使用方法等方面的共性
素质目标① 规范对 Internet 发展过程、技术管理等方面的认识；② 认识 Internet 应用形式的丰富多彩；③ 规范对 Internet 各种接入方式的认识；④ 通过对 NAT 设备的认识，增强对网络层设备功能不同侧重的理解；⑤ 规范对浏览器软件的认识；⑥ 通过对浏览器的操作，增强对 Internet 上共享资源类型的理解

项目一的三个任务：Internet 概述 → Internet 的接入方式 → 网络浏览器。

2.任务描述​

Internet，中文译名为因特网，又叫作国际互联网，简称互联网。它是由使用 TCP/IP 协议互相通信的计算机连接而成的全球网络。一个网络满足 Internet 的协议要求，就可以同它连接，使其成为 Internet 的组成部分。

这句话包含两个考点：

  1. Internet 不是"一个"网络，而是"网络的网络"——把不同的网络用 TCP/IP 互连起来；
  2. 接入 Internet 的唯一门槛是"遵守 TCP/IP 协议"，而不是"必须是某种特定的硬件"。

3.什么是 Internet​

受欢迎的原因：Internet 在为人们提供计算机网络通信设施的同时，还为广大用户提供了非常友好的、人们乐于接受的访问方式。Internet 上的计算机工具、网络技术和信息资源不仅被科学家、工程师和计算机专业人员使用，同时也为广大群众服务，进入非技术领域、进入商业、进入千家万户。

改变了什么：Internet 已经成为当今社会最有用的工具，正在改变着人们的生活方式——与朋友实时交谈、收发电子邮件、浏览新闻、网络订餐、网络出行等。

透明性（重要特点）：用户不必关心 Internet 是如何组合在一起的、被访问的对象在哪里，只要通过身边的接入终端就可以访问互联网。这也叫"网络对用户透明"。

4.Internet 是多层次的网络结构（必背三层）​

层次构成地位
（1）主干网一般由政府提供的多个主干网络互联而成是 Internet 的基础和支柱
（2）中间层网由地区网络和商业网络构成承上启下
（3）底层网主要由基层的大学、企业等网络构成面向终端用户

记忆口诀：主干撑着、中间连着、底层用着。

5.Internet 的发展（时间线，必背）​

年份事件关键数字
1968美国国防部高级研究计划署（ARPA） 提出 ARPANet 的研制计划目的是方便美国各研究机构和政府部门使用
19694 个节点的实验性 ARPANet 诞生被认为是现代网络的起源，也是 Internet 的起源
1983ARPA 和美国国防部通信局研制成功用于异构网络的 TCP/IP 协议；美国加利福尼亚伯克利分校把该协议作为其 BSD UNIX 的一部分，使协议在社会上流行起来当时共有主机 300 多台
1984ARPANet 分解为两个网络：一个沿用 ARPANet 称谓作为民用科研网，另一个是 MILNet 作为军用计算机网络军用与民用分家
1985美国国家科学基金会（NSF） 提出建立 NSFNet 的计划，任务是围绕其 5 个大型计算机中心建设计算机网络；第一步先把全美五大超级计算机中心用通信干线连接起来，组建全美范围的科学技术网成为美国 Internet 的第二个主干网，传输速率 56kb/s
1986NSF 建立起美国国家科学基金网 NSFNet，是三级计算机网络，分为主干网、地区网和校园网，覆盖美国主要的大学和研究所；NSFNet 后来接管了 ARPANet，并将网络改名为 Internet"Internet" 这个名字正式出现
1987NSF 采用招标方式，由 IBM、MCI 和 MERIT 3 家公司合作建立作为美国 Internet 网的主干网由全美 13 个主干节点构成
1991由于多种学术团体、企业研究机构甚至个人用户的进入，使用者不再限于计算机专业人员，容量满足不了需要，美国政府决定将 Internet 主干网络转交给私人公司经营，并开始对接入 Internet 的单位收费商业化起点
1993Internet 主干网的速率提高到 45Mb/s—
1996速率为 155Mb/s 的 Internet 主干网建成—
目前主干线路速率已达 622Mb/s，部分速率已达到 100Gb/s—

目前的规模：Internet 已经覆盖全球超过 160 个国家和地区、100 万多个子网、5 亿多台电脑主机，直接的用户超过 39 亿，成为世界上信息资源最丰富的计算机公共网络，Internet 已经成为全球信息高速公路。

记忆主线（四句话串起来）：

  1. 1969 四节点起步（ARPANet）；
  2. 1983 TCP/IP 统一语言（异构网络能互连了）；
  3. 1986 改名 Internet（NSFNet 接管，三级结构）；
  4. 1991 走向商业化（私营 + 收费，用户爆炸）。

易错点：

  • 1969 年是"4 个节点"，不是"4 台主机"；
  • 1985 年是 56kb/s，1993 年是 45Mb/s，1996 年是 155Mb/s，目前 622Mb/s——四级速率不要记串；
  • 改名为 Internet 的是 1986 年的 NSFNet，不是 ARPANet。

6.Internet 的组织与管理​

本质：Internet 是一个通过统一协议和互联设备连接起来、遵守共同规则的联合体，它的管理机构是 Internet 协会，这是一个由各国志愿者组成的团体。

三个主要组织：

组织全称职责
IABInternet 体系结构委员会制定 Internet 的技术标准、制定并发布 Internet 工作文件、制定 Internet 技术的发展规划，并进行 Internet 技术的国际协调工作
NOCInternet 网络运行中心负责保证 Internet 的日常运行以及监督 Internet 相关活动
NICInternet 网络信息中心为 Internet 代理服务商及广大用户提供信息服务

IAB 下面的两个任务组（易混）：

  • IETF（工作/工程任务组） —— 负责 Internet 的技术管理工作；
  • IRTF（研究任务组） —— 负责 Internet 的技术发展工作。

记忆：IETF 管"怎么用"（工程），IRTF 管"往哪走"（研究）。

7.中国 Internet 的管理组织：CNNIC​

全称：中国互联网络信息中心（CNNIC），是中国 Internet 的管理组织。

组成：主要成员是国内专家以及国内的四大互联网。

三项主要职责：

  1. 向我国的 Internet 用户提供域名注册、IP 地址分配等；
  2. 向我国的 Internet 用户提供政策法规、网络技术资料、入网方法、用户培训资料等信息服务；
  3. 向我国的 Internet 用户提供网络通信目录、主页目录与各种信息库的目录服务。

记忆：一号（域名/IP）、二料（资料）、三录（目录）。
