## 知识点

### 1.任务描述

**Internet 是目前应用最为广泛的网络**，具有**资源丰富、应用类型多**等优势，已经融入了人们**工作、生活、娱乐**等各个方面。Internet 具有**多种接入方式**，从**早期的单点接入**到**现在的局域网接入**。本任务介绍**常见接入方式的使用方法**等内容。

### 2.互联网服务提供商（ISP）与三大衍生角色

**ISP（Internet Service Provider，互联网服务提供商）**：是向广大用户**综合提供互联网接入业务、信息业务和增值业务**的**电信运营商**。也就是说，**ISP 是进入 Internet 的关口**。

**三种细分角色（极易混考）**：

| 缩写 | 全称 | 提供什么 |
|------|------|----------|
| **IAP** | **Internet Access Provider** | 向用户提供**接入网络**（卖"通道"） |
| **ICP** | **Internet Content Provider** | 向用户提供**全方位信息服务**（卖"内容"） |
| **ASP** | **Application Service Provider** | **应用服务提供商**——通过**网络**给商家或个人提供**配置、租赁和管理应用解决方案**的专业化服务公司（卖"应用"） |

**记忆**：**A=Access 通道、C=Content 内容、A=Application 应用**。

**世界范围较大的网络 ISP**：**美国科学基金会 NSFNet**、**澳大利亚的 AARNet**、**美国国家航空宇航局科学网 SNI**、**瑞士科学与研究网 SWITCH**。

### 3.我国接入 Internet 的历史起点

- **1987 年**，**中国科学院高能物理研究所**最早开始**通过国际网络线路接入 Internet**（我国第一个"触网"的单位，不是四大骨干网之一）；
- **1994 年**，随着**"巴黎统筹委员会"的解散**，**美国政府取消了对中国政府进入 Internet 的限制**，我国互联网建设**全面展开**。

**注意区分**：**1987 年是"某单位首次接入"**，**1994 年才是"国家层面全面展开"**。

### 4.我国四大骨干网络（必背）

**（1）中国科学技术网（CSTNet）**

| 项目 | 内容 |
|------|------|
| **开通时间** | **1994 年 5 月** |
| **前身/工程** | 中国科学院的**"中国国家计算机与网络设施工程"** |
| **主管** | **中国科学院** |
| **地位** | 我国**第一个与 Internet 连接**的网络 |
| **组成** | 主要包括**中科院网、清华大学校园网和北京大学校园网** |
| **性质** | 利用**公用数据通信网**为基础的**信息增值服务网**，地理上覆盖全国各省市，逻辑上连接各部委和各省、市科技信息机构，是**国家科技信息系统骨干网** |

**服务功能上是 Intranet 和 Internet 的结合**：

- **Intranet 功能**——为国家科委系统内部提供**办公自动化的平台**以及国家科委、地方省市科委和其他部委科技司局之间的**信息传输渠道**；
- **Internet 功能**——主要服务于**专业科技信息服务机构**，包括国家或地区、地方省市和各部委科技信息服务机构。

**（2）中国教育科研网（CERNet）**

| 项目 | 内容 |
|------|------|
| **开通时间** | **1995 年 12 月**正式开通 |
| **归属** | 教育部的**"中国教育和科研计算机网示范工程"** |
| **网络管理中心** | 设在**清华大学**，负责主干网的**规划、实施、管理和运行** |
| **服务对象** | 为**教育、科研和国际学术交流**服务；连接和管理以 **edu.cn** 为后缀的、国内 **500 多所**高校和科研单位的网络 |
| **目标** | 建设**全国性的教育科研基础设施**，把全国大部分高校连接起来，**实现资源共享** |
| **地位** | **全国最大的公益性互联网络** |

**四级管理（必背）**：**全国网络中心 → 地区网络中心和地区主节点 → 省教育科研网 → 校园网**。

- **全国网络中心**负责**全国主干网的运行管理**；
- **地区网络中心和地区主节点**分别设在**清华大学、北京大学、北京邮电大学、上海交通大学等 10 所高校**，负责**地区网的运行管理和规划建设**。

**IPv6 的两个"第一"**：

1. 中国教育科研网是**中国开展下一代互联网研究的试验网络**，以现有网络设施和技术力量为依托，建立了**全国规模的 IPv6 试验环境**；
2. **1998 年**正式参加下一代 IP 协议（**IPv6**）试验网 **6BONE**，**同年 11 月成为其骨干网成员**；在**全国第一个实现了与国际下一代高速网 Internet 2 的互联**。

**（3）中国公用计算机互联网（CHINANet）**

| **主管与地位** | 由**中国电信**主管，是目前**国内拥有最多带宽的网络**，也是我国的**第一大主干网** |

**（4）国家公用经济信息通信网（中国金桥信息网）**

### 5.CNNIC 的成立与职责

**成立**：**1997 年 6 月 3 日**经国家主管部门批准组建的**中国互联网络信息中心（CNNIC）**，行使**国家互联网络信息中心**的职责。

**职责（六项）**：

1. **互联网地址资源注册管理**；
2. **互联网调查与相关信息服务**；
3. **目录数据库服务**；
4. **互联网寻址技术研发**；
5. **国际交流与政策调研**；
6. 承担**中国互联网协会政策与资源工作委员会秘书处**等工作。

**重要产出**：**CNNIC 每年都会发布有关 Internet 在我国发展状况的统计报告**，总结 Internet 的发展状况。

### 6.带宽：窄带与宽带的界限

**问题**：提到接入方式，**首先涉及带宽问题**；随着互联网技术发展，接入网络的带宽被分为**窄带**和**宽带**，业内专家普遍认为**宽带接入是未来发展方向**。

**宽带的定义（必背）**：所谓 **"宽带"** 是指**在同一传输介质上**，**使用特殊的技术或者设备**，**利用不同的频道进行多路、并行传输**，并且**速率在 256kb/s 以上**。

**注意**：**到底多少速率以上算作宽带，目前并没有国际标准**。这里**按照网络多媒体视频数据传输对带宽的要求**作为标准，即 **256kb/s**。

**优势**：与传统的互联网接入技术相比，**宽带接入技术最大的优势就是其带宽速率可以保证用户有良好的用网体验**。

### 7.九种常见的 Internet 接入方式

**（1）PSTN 拨号**

| 项目 | 内容 |
|------|------|
| 实现 | 利用 **PSTN** 通过**调制解调器（Modem）拨号**实现用户接入 |
| 地位 | **曾经是使用最广泛**的一种接入方式 |
| 最高速率 | **56kb/s**——**已经达到香农定理（Shannon）确定的信道容量极限** |
| 实际上网速率 | **9.6~56kb/s** |
| 缺点 | 速率**远远不能满足宽带多媒体信息**的传输需求，**这种方式已经被淘汰** |
| 优点 | **电话网络非常普及**，**Modem 很便宜**，而且**不需申请就可开户**，只要家里有电脑，把电话线接入 Modem 就可以直接上网，**比较经济** |
| 仍有用途 | 在**远程对服务器直接联网**时，只要两端有电话线路就可以联网，所以在**重要的数据传输场合，PSTN 连接仍然是一种备用连接方式** |

**（2）ISDN 拨号**

- **基本速率接口**有**两条 64kb/s 的数据信道**和**一条 16kb/s 的控制信道**，简称 **2B+D**；
- **当有电话拨入时，它会自动释放一个 B 信道来进行电话接听**（这就是"一线两用"的实现原理）；
- 需要**申请开户**；
- **极限带宽为 128kb/s**（2 × 64kb/s，不含 16kb/s 的 D 信道）；
- **并不能有效满足通过网络传输多媒体数据的需要**，所以这种方式**已经被淘汰**。

**（3）DDN 专线**

- DDN 是随着**数据通信业务发展**而迅速发展起来的一种**新型网络**；
- **需要申请开户**；
- 收费一般采用**包月制或者计流量制**，这与**一般用户拨号上网的按时计费**方式不同；
- **租用费较高**，**普通个人用户很难负担得起**，**主要面向集团、公司等单位**。

**（4）ADSL**

| 项目 | 内容 |
|------|------|
| 定位 | 因**下行速率高、频带宽、性能优、安装方便**等特点，成为**继 Modem、ISDN 之后的又一种全新的高效接入方式** |
| **最大特点** | **不需要改造信号传输线路**，可以利用**普通铜质电话线**作为传输介质，配上**专用的 Modem** 即可实现数据高速传输 |
| 速率特点 | **上行和下行传输速率不对称** |
| **上行速率** | **640kb/s ~ 1Mb/s** |
| **下行速率** | **1 ~ 8Mb/s** |
| **有效传输距离** | **3~5km** 范围以内 |
| 结构 | 每个用户都有**单独的一条线路与 ADSL 局端相连**，结构可看作是**星型结构**，**带宽由每一个用户独享** |
| 适用 | 可满足用户**宽带上网**的要求，主要适用于**用户远程通信、远程办公**等连接 |

**（5）VDSL**

- 是**目前能最大限度利用用户铜线设施**的 DSL 技术；
- **最大特点**：可以在**相对较短的距离（0.3~1.5km）** 内以**最高 52Mb/s** 的速度提供**对称或者非对称**数据传输；
- **比 ADSL 更快**：**短距离内最大下载速率可达 55Mb/s**，**上传速率可达 2.3Mb/s**；
- 主要用来提供**全方位的宽带接入**，用于**音频、视频和数据的快速传输**；
- **基于以太网方式的 VDSL**：接入技术使用 **QAM 调制**方式，传输介质也是**一对铜线**，在 **1.5km** 范围内能够达到**双向对称的 10Mb/s** 传输，**即达到以太网的速率**；
- **组网方式**：在**机房端增加 VDSL 交换机**，在**用户端放置用户 CPE（用户前端设备）**，二者之间通过**五类线**连接。

**（6）Cable-Modem（电缆调制解调器）**

- 是一种**超高速 Modem**，利用**有线电视（CATV）网络**进行数据传输，已经是**比较成熟**的一种技术；
- **为什么需要它**：由于有线电视网采用的是**模拟传输协议**，因此网络需要用一个 **Modem** 来协助完成**数字数据的转化**；
- **与普通 Modem 的异同**：原理上**都是将数据进行调制后在 Cable（电缆）的一个频率范围内传输，接收时进行解调**，**传输机理与普通 Modem 相同**；**不同之处**在于它是通过**有线电视 CATV 的某个传输频带**进行调制解调的。

**两种速率类型（必背）**：

| 类型 | 上行速率 | 下行速率 |
|------|----------|----------|
| **对称速率型** | **500kb/s ~ 2Mb/s**（与下行相同） | **500kb/s ~ 2Mb/s** |
| **非对称速率型** | **500kb/s ~ 10Mb/s** | **2 ~ 40Mb/s** |

**缺点**：Cable-Modem 模式采用的是**相对落后的总线型网络结构**，这就意味着**网络用户共同分享有限带宽**；另外**购买 Cable-Modem 和初装费也都不便宜**，这些都**阻碍了 Cable-Modem 接入方式在国内的普及**。

**（7）无源光网络接入——光纤入户（PON）**

**技术特点**：**PON（无源光网络）** 技术是一种**点对多点**的光纤传输和接入技术，**下行采用广播方式，上行采用时分多址方式**，可以灵活地组成**树型、星型、总线型**等拓扑结构，在**光分支点不需要节点设备**，只需要安装一个简单的**光分支器**即可。

**六大优点**：**节省光缆资源、带宽资源共享、节省机房投资、设备安全性高、建网速度快、综合建网成本低**。

**两种类型**：

| 类型 | 全称 | 说明 |
|------|------|------|
| **APON** | **ATM-PON**（基于 ATM 的无源光网络） | 发展较早，具有**综合业务接入、QoS 保证**等独有特点；**ITU-T 的 G.983** 规范了其网络结构、基本组成和物理层接口；我国信息产业部也已制定完善的 APON 技术标准 |
| **EPON** | **Ethernet-PON**（基于以太网的无源光网络） | 基于以太网帧传输 |

**设备组成与容量计算（必背）**：

- 组成：**OLT（光网络终端/光网络单元）、ONT、ONU**，由**无源光分路器件**将 OLT 的光分到**树型网络的各个 ONU**；
- **一个 OLT 可接 32 个 ONT 或 ONU**；
- **一个 ONT 可接 8 个用户**；
- **一个 ONU 可接 32 个用户**；
- 因此，**一个 OLT 最大可负载 1024 个用户**（32 × 32 = 1024）。

**传输指标**：

- 传输介质采用**单芯光纤**；
- **接入点到用户端最大距离为 20km**；
- 接入系统总的传输容量为**上行和下行各 155Mb/s**；
- **一个 OLT 上所接的用户共享 155Mb/s 带宽**；
- **每个用户使用的带宽可以从 64kb/s ~ 155Mb/s 灵活划分**。

**（8）LMDS 接入**

**全称**：**本地多点分配业务（Local Multipoint Distribute Service，LMDS）**，是一种**无线接入 Internet** 的方式。

| 项目 | 内容 |
|------|------|
| 覆盖 | **一个信号基站可以覆盖直径 20km 的区域** |
| 用户数 | **每个基站可以负载 2.4 万用户** |
| 单用户带宽 | **每个终端用户的带宽可达到 25Mb/s** |
| 总容量 | 带宽**总容量为 600MB/s**，**每基站中的用户必须共享带宽** |
| 局限 | 一个基站**负载用户较多**时，**每个用户分到的带宽就很小**，所以这种技术**对于有较多用户的接入是不合适的** |
| 仍可用之处 | 用户端设备**可以捆绑在一起**，用于**宽带运营商的城域网互联** |
| 好处 | 可以在**已建好的宽带地区迅速开通运营，缩短建设周期** |

**（9）局域网接入**

- **LAN 方式接入**是利用**以太网技术**，采用**光缆和双绞线**的方式进行**综合布线**；
- 现在局域网的网速可以达到 **100Mb/s，甚至 1000Mb/s**；
- **优势**：**以太网技术成熟、成本低、结构简单、稳定性好、可扩充性好，便于网络升级**，同时可实现**实时监控、智能化物业管理、远程抄表**等，可提供**智能化、信息化的办公与家居环境**，满足不同层次人们对网络应用的需求。

**（10）卫星接入（补充方式）**

- 即所谓的 **"星网通"** 或者**数字卫星服务（Digital Satellite Service，DSS）**；
- **"星网通"是一种非对称的卫星高速数据接入方式**：**用户上行采用 Modem 或其他方式（如专线等）**，**下行由卫星高速直接向用户提供所需服务**，**速率可达 400kb/s**；
- 用户需要**按月支付一定的卫星通信线路费用**；
- 目前世界上有约 **300 万用户**使用卫星 Internet 接入方式，但主要还集中在**欧美、日本等发达国家**。

**卫星接入的四个优点（必背）**：

1. **避开公共电信网络**，直接通过卫星连接到 Internet；
2. 采用**非对称线路**的传输方法，可使 **ISP 根据其业务需求租用所需转发器的容量**；
3. **经济高效**——通常光缆建设要花几年时间及几十亿美元投资，而**卫星的建设要比光缆快而且经济得多**；
4. 可以很方便地作为**多信道广播业务**的平台。

### 9.局域网接入 Internet 的基本思想

**核心**：**同一局域网内的多台电脑，通过集线器或者交换机连接在一起，共用一个 Internet 接口**，这就是**局域网共享接入 Internet** 的基本思想。

**目的**：**充分利用 Internet 接入资源，以节约成本**。

**最简单、最通用的做法**：使用**代理服务器**连接 Internet。

### 10.代理服务器

**（1）概念**

**代理服务器（Proxy Server）** 是**局域网和 ISP 之间的中间代理**，它负责**转发合法的网络信息**，并对转发的数据**进行控制和登记**。代理服务器作为**连接 Internet 与局域网的桥梁**，在实际应用中发挥着极其重要的作用。

**基本功能是连接**，此外还包括**安全性、缓存、内容过滤和访问控制管理**等功能。

**（2）代理服务的过程（四步）**

1. 局域网中**不能直接访问 Internet** 的计算机，将**上网请求**（如浏览某个网页）发给**能够直接访问 Internet 的代理服务器**；
2. 代理服务器**代理完成这个上网请求**，将所要浏览的网页**调入代理服务器的缓存**；
3. 然后**将这个页面传给请求者**；
4. 这样局域网中的计算机**就像能够直接访问 Internet 一样**。

**此外**，代理服务器还可以**对一些网站及内容进行过滤**，并完成**对网内计算机访问互联网的控制**。

**（3）代理服务器的四项功能（必背）**

**① 作为防火墙**

- 代理服务器可以**保护局域网的安全，起到防火墙的作用**；
- 因为它**工作在 TCP/IP 的应用层**，所以属于**应用层防火墙**；
- 应用层防火墙可以**针对不同的网络服务提供细致而又安全的网络保护**，它对**每一种网络服务分别进行安全隔离**，**内部网络不直接与外部网络连接**；
- 由此可见，通过设置这种防火墙，**大大降低了分组过滤的复杂性**，可以作为**分组过滤技术的重要补充**，为单位内部网络提供**安全边界**，**防止外界侵入**；
- 在使用过程中，**即使防火墙发生了问题，外部网络也无法获得被保护网络中的信息**。

**② 实现网络地址转换（NAT）**

- **NAT（Network Address Translation）最主要的功能是实现 IP 地址的多对多或者多对一的映射**，从而**节约 IP 地址空间**；
- 使用这种功能，通过代理服务器访问 Internet 便可以**解决公有的 IP 地址不够用**的问题：单位局域网的用户通过代理服务器访问 Internet 时，**只要把私有 IP 地址映射为一个公有 IP 地址**，这样单位局域网就**不必向 ISP 租用多个 IP 地址**了。

**三段私有 IP 地址（必背）**：

| 类别 | 范围 | 前缀表示 |
|------|------|----------|
| **A 类** | **10.0.0.0 ~ 10.255.255.255** | **10.0.0.0/8** |
| **B 类** | **172.16.0.0 ~ 172.31.255.255** | **172.16.0.0/12** |
| **C 类** | **192.168.0.0 ~ 192.168.255.255** | **192.168.0.0/16** |

**它们只能在局域网中使用。**

**NAT 通常被集成到**：**路由器、防火墙或者单独的 NAT 设备**中。

**NAT 的三种类型（必背）**：

1. **静态 NAT（Static NAT）**——一对一的固定映射；
2. **动态地址 NAT（Pooled NAT）**——从地址池中动态分配；
3. **网络地址端口转换 NAPT（Port-Level NAT）**——多对一，**用端口号区分不同内网主机**（最常用）。

**③ 网址过滤和访问权限限制**

代理服务器可以设置 **IP 地址（Internet 或局域网内部 IP 地址）过滤**，**限制不同用户不同的访问权限**。例如，代理服务器可以用来**限制封锁 IP 地址，禁止用户对某些不良网页进行浏览**。

**④ 提高访问速度**

代理服务器将**互联网远程服务器提供的数据保存在自己的缓存中**，如果有许多用户同时使用这个代理服务器，他们对 Internet 站点所有的访问都会**经由这台代理服务器来提供**，而**不必再从远程服务器上去取得**。因此，它可以**节约带宽、提高访问速度**。

**（4）常用代理软件与提醒**

在 **Windows** 操作系统环境下，常用的代理服务器软件有 **Sygate、WinRoute 和 WinGate** 等。但是由于 **Windows 本身的安全问题**，使用此类代理服务器**不适合对安全性要求比较高的局域网**。

### 11.宽带接入的发展

**（1）宽带接入 Internet 应具备的七个条件（必背）**

1. 应在**现有的物理铜线**上进行**模拟信号传输的同时传输数据信号**；
2. **双向对称上下行传输的速率应在 4Mb/s 以上**；
3. **传输距离应该在 2km 以上**；
4. **数据流并发要在 10 000 用户以上**；
5. **数据在传输过程中互不干扰**；
6. 在**数据信号传输过程中不影响模拟信号的传输与使用**；
7. **网络物理结构必须符合星型、点对点的传输方式**。

**（2）宽带替代窄带（五条原因）**

1. **我国宽带基础设施基本完成**，发展宽带产业的**硬性条件已经完全具备**；
2. 随着基础设施基本完成和**运营商的大力推广**，**宽带概念已经深入人心**，宽带已经步入 **"应用为王"** 时代，**宽带服务内容正不断丰富**；
3. **互联网经济**已经越来越成为我国经济发展中的重要组成部分，而**宽带产业在互联网产业中处于关键地位**，**接入业务的宽带化已经成为不可逆转的趋势**；
4. **价格的下降**使宽带越来越**平民化**，为宽带普及奠定了良好基础；
5. 经过**市场培育以及基础设施建设**的完成，**宽带业务已经进入快速增长时期**。

**（3）从宽带接入走向宽带应用**

全球宽带互联网正**由宽带接入走向宽带应用**。随着宽带接入技术的成熟，**互联网潜力进一步发挥，宽带应用日渐趋热**，**电子商务和休闲娱乐**等宽带应用已发展到相当大的市场规模，并且**仍然保持高速增长**。

**（4）宽带推动行业融合（三网融合）**

在**新技术、新市场规范、新需求**的推动下，**互联网、通信网络、广播电视网络三网的建设和运营**、**三网融合的步伐**以及相关产业链的演变**正加快脚步**。

**三方面原因**：

1. **国家在行业监管、法律法规等政策方面**促进了三网融合的发展；
2. **不断出现的新的业务增长点**（如 **IPTV、VoIP、手机电视**等），以及**传统业务模式下用户数量以及收入不断下降**的情况，**迫使三类业务主体相互渗透**；
3. **相关网络、多媒体技术的迅猛发展**，为三网融合**提供了可能**。

### 12.无线接入 Internet

随着**移动互联网**的发展，**通过无线方式接入 Internet** 现在也成为一种**应用最为普遍**的方式。

**（1）WiFi 接入**

- **WiFi 是一种通用的无线联网技术**，利用**无线电频率**来传输数据；
- **无线网络允许高速互联网连接，无需使用电缆或电线**；
- **WiFi 接入比普通拨号连接快了近 100 倍**；
- **无线电信号从 WiFi 天线发射出来**，被不同类型的 WiFi 接收器接收，如**配备了无线网络卡的计算机和手机**；
- 一台计算机（或移动终端）可以接收到 **50~100m** 范围内的无线网络信号，并创建**用户和 Internet 之间的一个访问连接**。

**（2）卫星通信网络**

- **原理**：**卫星通信就是把卫星作为中继站**，在**地球上（包括地面和低层大气中）的通信站点间进行通信**；
- **组成**：**卫星和地球站**就是卫星通信系统的**重要组成部分**；
- **技术类型**：主要包括 **VSAT 系统**（即**甚小口径终端**）、**中低轨道的移动卫星通信系统**等。

| 优点 | 缺点 |
|------|------|
| **通信区域大、距离远、频段宽、容量大**（只要在卫星发射电波覆盖范围内的任意两点间，都可以互相通信） | **传输时延大** |
| **可靠性高、质量好、噪声小** | **回声大** |
| **可移动性强**，不容易受自然灾害的影响 | **费用高** |

**用途**：**电视广播、远距离的越洋电话、军事通信、应急通信**等。

**定位**：卫星通信作为一种特殊的通信技术，其**基本定位必然是地面系统的有效支持、补充与延伸**，对于**农村及偏远地区的通信**发挥重要作用，使实现**全球通信海陆空一体化的无缝覆盖**成为可能。

**（3）蜂窝移动通信**

**原理**：**蜂窝网络就是把移动电话的服务区分为一个个正六边形的小区**，每个小区设置一个**基站**，这样的结构酷似一个个 **"蜂窝"**。**蜂窝技术是移动通信的基础**，所以把这种移动通信方式称为**蜂窝移动通信**。

**组成**：**移动站、基站子系统、网络子系统**；采用**蜂窝网络**作为无线组网方式，通过**无线信道**将移动终端和网络设备进行连接，使用户在移动中进行**语音、数据通信**业务。

**两种蜂窝技术（必背的覆盖半径）**：

| 类型 | 覆盖半径 | 特点 |
|------|----------|------|
| **宏蜂窝** | 多在 **1~25km** | **覆盖半径大**，但是**存在盲区**；**小区半径缩小时会产生干扰** |
| **微蜂窝** | 一般 **30~300m** | **覆盖范围小、传输功率低、安装方便灵活**，主要用于**提高覆盖率和容量**，作为**宏蜂窝的补充和延伸** |

**主要特征**：**终端的可移动性**，并具有**成熟的切换和漫游方案**；**频率复用技术、多址技术、移动性管理技术**促进了移动通信业务的发展。

**发展**：从**第一代**发展到现在的**第四代（4G）**，成为实现**网络融合和业务融合的统一平台**，也是公认的**下一代网络的核心网架构**。

- **4G 能提供**：除**电信业务、承载业务**在内的基本业务外，还可提供**呼叫前转、呼叫等待、多方通话**等补充业务；支持的**增值服务**包括**网页浏览、图像、音乐、移动游戏、移动冲浪、视频会议、视频点播**、各类信息服务等。
- **5G**：第五代蜂窝系统**已经完成了实验室验证**，**商业化应用正日益临近**；**峰值理论传输速度可达每秒数十 Gb**，比 4G 快**数百倍**；主要目标是**使终端用户始终处于联网状态**，支持的设备**远不止智能手机**，还有**智能手表、健身腕带、智能家居设备**等。
