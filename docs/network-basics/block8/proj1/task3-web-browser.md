## 知识点

### 1.任务描述

**网络浏览器**是用来**显示网页服务器系统内的文件**、并**可以让用户与这些文件进行互动**的一种软件。除了**文字或多媒体信息**，显示的内容也可以是**超链接**，以方便用户可以**迅速浏览各种资讯**。可以在浏览器中显示的网页是**超文本标记语言（HTML）的格式**。本任务主要介绍 **IE 网络浏览器软件**的使用情况。

**三个关键词**：

| 关键词 | 含义 |
|--------|------|
| **显示** | 把服务器上的网页文件**渲染**成可见的页面 |
| **互动** | 可以**点击超链接、填写表单**、执行脚本 |
| **HTML 格式** | 浏览器能"读懂"的网页是**超文本标记语言**写成的 |

### 2.网页与浏览器、标记语言的关系

**网页文件的本质**：网页文件一般是**超文本标记语言（HTML）的格式**。

**为什么需要"特定浏览器"**：**受版本和具体网页开发语言的限制**，**有些网页需要使用特定的浏览器才能正确显示**。

**这句话的考点**：

- **HTML 是网页的开发语言**，浏览器是 HTML 的**解释/渲染器**；
- **同一段 HTML 在不同浏览器（或不同版本）中显示效果可能不同**——这就是"兼容性问题"；
- 所以浏览器与标记语言的关系是：**标记语言定义"内容与结构"，浏览器决定"如何呈现"**。

**超链接的作用**：显示的内容**也可以是超链接**，以方便用户**迅速浏览各种资讯**——这是"**超**文本"（超越线性顺序的文本）的由来。

**HTTP 与 HTTPS**：浏览器用来显示在网络中**以 HTTP、HTTPS 协议共享**的**文字、音视频或其他类型的信息**（见项目导读）。

### 3.常用浏览器

**国外主流浏览器**：

| 浏览器 | 说明 |
|--------|------|
| **Internet Explorer（IE）** | 微软出品，本任务的重点示例 |
| **Opera** | 挪威出品，小巧、早期以速度见长 |
| **Firefox** | 火狐，开源 |
| **Chrome** | 谷歌出品 |
| **Safari** | 苹果出品 |

**国内浏览器软件**：**360 浏览器、腾讯（QQ 浏览器）** 等。

**共性（能力目标第 8 条）**：浏览器类软件在**功能、使用方法**等方面具有**共性**——都会包含**地址栏、前进/后退、刷新、收藏、设置**等基本要素，学会一款即可迁移到其他款。

**为什么以 IE 为例**：**浏览器是经常使用到的客户端程序**，下面**以 IE 为例**进行介绍。

### 4.IE 窗口的组成（七个部分，必背）

| 序号 | 组成部分 | 作用（教材原文要点） |
|------|----------|----------------------|
| **（1）** | **标题栏** | 包括**控制按钮、当前浏览网页的名称、最小化、最大化/还原按钮以及关闭按钮**；通过对标题栏的操作，可以**改变 IE 窗口的大小和位置** |
| **（2）** | **菜单栏** | 提供了**完成 IE 所有功能的命令**；通过打开**下拉菜单**点击相应菜单项，可以完成相应的操作 |
| **（3）** | **工具栏** | 提供了**常用命令的工具按钮**；可以**不用打开菜单**，而是单击相应的按钮来**快捷地执行命令** |
| **（4）** | **地址栏** | 用于指出**要访问的资源在网上的统一资源定位地址（URL）**；输入的地址**默认将以 HTTP 协议**去进行访问，**如果需要使用其他协议，则在 URL 前应加入协议名称及分隔符** |
| **（5）** | **链接栏** | 用于添加一些**常用网页的链接**，单击这些链接就可以访问相应的网页，**省去了在地址栏中输入 URL 的过程** |
| **（6）** | **浏览区** | IE 窗口中**最大面积的区域**，用来**显示当前访问的网页内容** |
| **（7）** | **状态栏** | 位于 IE 窗口的**底部**，可以用来显示正在浏览网页的**下载状态、下载进度和区域属性**等状态信息 |

**记忆顺序（自上而下）**：**标题 → 菜单 → 工具 → 地址 → 链接 → 浏览区 → 状态栏**，即"**三栏两区一状态，地址链接在中间**"。

**地址栏的两个考点**：

1. URL 是**统一资源定位地址**，用于**定位网上的资源**；
2. **默认走 HTTP 协议**；要换协议（如 **FTP、HTTPS、FILE**）**必须在 URL 前写出协议名称加分隔符**，例如 `ftp://` 、`https://` 。

### 5.IE 的菜单（六个主菜单）

IE 的主菜单如图 8-9 所示：**文件、编辑、查看、收藏夹、工具、帮助**。

| 菜单 | 主要功能（教材原文） |
|------|----------------------|
| **（1）"文件"菜单** | 对**文件或页面**进行管理与操作，如对正在显示的网页文件进行 **"保存""打印""页面设置""属性"查看**等操作 |
| **（2）"编辑"菜单** | 完成网页内容的 **"选择""复制""粘贴"** 等操作 |
| **（3）"查看"菜单** | 对 **IE 窗口显示方式**的设置，如**是否显示工具栏、收藏夹、历史记录**；通过 **"后退""前进""刷新"** 等操作**查看访问网页的历史记录**；**查看当前网页的 HTML 源代码**；**设置网页显示比例**等 |
| **（4）"收藏夹"菜单** | 将**当前显示的网页添加到收藏夹**；对**收藏夹内容进行管理** |
| **（5）"工具"菜单** | 提供**对 IE 进行控制**的一组操作，如**删除网页访问历史记录**、**查看或修改 IE 的设置**等 |
| **（6）"帮助"菜单** | 进行 **IE 的帮助系统**；**查看 IE 的版本信息**等 |

**考点提示**：**"查看源代码"在"查看"菜单里**，**"删除历史记录"和"Internet 选项"在"工具"菜单里**——这两个位置最容易混。

### 6.IE 的设置（Internet 选项）

**入口有两个**：

1. **"工具"菜单 → "Internet 选项"子菜单**；
2. **Windows 的"控制面板" → "Internet 选项"对话框**。

**七个大项**：**常规、安全、隐私、内容、连接、程序、高级设置**，可以配置 IE 的**工作状态、工作属性**等。

**四个常用设置（必背）**：

| 设置项 | 所在选项卡 | 作用 |
|--------|------------|------|
| **（1）主页** | **"常规"** | 设置在**运行 IE 时自动打开的网页** |
| **（2）安全级别** | **"安全"** | 用户可**自行定义 IE 访问网页时的安全级别，分高、中、低三级**；可以设置网站访问的**黑名单（不允许访问）**和**白名单（允许访问）**等 |
| **（3）默认浏览器** | **"程序"** | 点按 **"设为默认浏览器"** 按钮，可以将 **IE 设置为默认浏览器** |
| **（4）重置** | **"高级"** | 当 **IE 被破坏或设置的参数需要还原**时，可以点按 **"重置"** 按钮，使 **IE 恢复到刚安装时的状态** |

**记忆**：**主页在常规、级别在安全、默认在程序、重置在高级**。

### 7.任务实施要点

1. 启动计算机，**打开浏览器软件**；
2. **查看浏览器的设置**；
3. 在浏览器中**访问不同类型的网络资源**，如 **BBS、FTP** 等；
4. 按照《计算机网络基础综合模拟实训》中 **"项目十五 IE 的参数设置——浏览器软件的使用"** 的方法与步骤，**设置、使用 IE 浏览器**。
