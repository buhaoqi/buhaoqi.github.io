任务三 网络浏览器

知识点​

1.任务描述​

网络浏览器是用来显示网页服务器系统内的文件、并可以让用户与这些文件进行互动的一种软件。除了文字或多媒体信息，显示的内容也可以是超链接，以方便用户可以迅速浏览各种资讯。可以在浏览器中显示的网页是超文本标记语言（HTML）的格式。本任务主要介绍 IE 网络浏览器软件的使用情况。

三个关键词：

关键词含义
显示把服务器上的网页文件渲染成可见的页面
互动可以点击超链接、填写表单、执行脚本
HTML 格式浏览器能"读懂"的网页是超文本标记语言写成的

2.网页与浏览器、标记语言的关系​

网页文件的本质：网页文件一般是超文本标记语言（HTML）的格式。

为什么需要"特定浏览器"：受版本和具体网页开发语言的限制，有些网页需要使用特定的浏览器才能正确显示。

这句话的考点：

  • HTML 是网页的开发语言，浏览器是 HTML 的解释/渲染器；
  • 同一段 HTML 在不同浏览器（或不同版本）中显示效果可能不同——这就是"兼容性问题"；
  • 所以浏览器与标记语言的关系是：标记语言定义"内容与结构"，浏览器决定"如何呈现"。

超链接的作用：显示的内容也可以是超链接，以方便用户迅速浏览各种资讯——这是"超文本"（超越线性顺序的文本）的由来。

HTTP 与 HTTPS：浏览器用来显示在网络中以 HTTP、HTTPS 协议共享的文字、音视频或其他类型的信息（见项目导读）。

3.常用浏览器​

国外主流浏览器：

浏览器说明
Internet Explorer（IE）微软出品，本任务的重点示例
Opera挪威出品，小巧、早期以速度见长
Firefox火狐，开源
Chrome谷歌出品
Safari苹果出品

国内浏览器软件：360 浏览器、腾讯（QQ 浏览器） 等。

共性（能力目标第 8 条）：浏览器类软件在功能、使用方法等方面具有共性——都会包含地址栏、前进/后退、刷新、收藏、设置等基本要素，学会一款即可迁移到其他款。

为什么以 IE 为例：浏览器是经常使用到的客户端程序，下面以 IE 为例进行介绍。

4.IE 窗口的组成（七个部分，必背）​

序号组成部分作用（教材原文要点）
（1）标题栏包括控制按钮、当前浏览网页的名称、最小化、最大化/还原按钮以及关闭按钮；通过对标题栏的操作，可以改变 IE 窗口的大小和位置
（2）菜单栏提供了完成 IE 所有功能的命令；通过打开下拉菜单点击相应菜单项，可以完成相应的操作
（3）工具栏提供了常用命令的工具按钮；可以不用打开菜单，而是单击相应的按钮来快捷地执行命令
（4）地址栏用于指出要访问的资源在网上的统一资源定位地址（URL）；输入的地址默认将以 HTTP 协议去进行访问，如果需要使用其他协议，则在 URL 前应加入协议名称及分隔符
（5）链接栏用于添加一些常用网页的链接，单击这些链接就可以访问相应的网页，省去了在地址栏中输入 URL 的过程
（6）浏览区IE 窗口中最大面积的区域，用来显示当前访问的网页内容
（7）状态栏位于 IE 窗口的底部，可以用来显示正在浏览网页的下载状态、下载进度和区域属性等状态信息

记忆顺序（自上而下）：标题 → 菜单 → 工具 → 地址 → 链接 → 浏览区 → 状态栏，即"三栏两区一状态，地址链接在中间"。

地址栏的两个考点：

  1. URL 是统一资源定位地址，用于定位网上的资源；
  2. 默认走 HTTP 协议；要换协议（如 FTP、HTTPS、FILE）必须在 URL 前写出协议名称加分隔符，例如 ftp:// 、https:// 。

5.IE 的菜单（六个主菜单）​

IE 的主菜单如图 8-9 所示：文件、编辑、查看、收藏夹、工具、帮助。

菜单主要功能（教材原文）
（1）"文件"菜单对文件或页面进行管理与操作，如对正在显示的网页文件进行 "保存""打印""页面设置""属性"查看等操作
（2）"编辑"菜单完成网页内容的 "选择""复制""粘贴" 等操作
（3）"查看"菜单对 IE 窗口显示方式的设置，如是否显示工具栏、收藏夹、历史记录；通过 "后退""前进""刷新" 等操作查看访问网页的历史记录；查看当前网页的 HTML 源代码；设置网页显示比例等
（4）"收藏夹"菜单将当前显示的网页添加到收藏夹；对收藏夹内容进行管理
（5）"工具"菜单提供对 IE 进行控制的一组操作，如删除网页访问历史记录、查看或修改 IE 的设置等
（6）"帮助"菜单进行 IE 的帮助系统；查看 IE 的版本信息等

考点提示："查看源代码"在"查看"菜单里，"删除历史记录"和"Internet 选项"在"工具"菜单里——这两个位置最容易混。

6.IE 的设置（Internet 选项）​

入口有两个：

  1. "工具"菜单 → "Internet 选项"子菜单；
  2. Windows 的"控制面板" → "Internet 选项"对话框。

七个大项：常规、安全、隐私、内容、连接、程序、高级设置，可以配置 IE 的工作状态、工作属性等。

四个常用设置（必背）：

设置项所在选项卡作用
（1）主页"常规"设置在运行 IE 时自动打开的网页
（2）安全级别"安全"用户可自行定义 IE 访问网页时的安全级别，分高、中、低三级；可以设置网站访问的**黑名单（不允许访问）和白名单（允许访问）**等
（3）默认浏览器"程序"点按 "设为默认浏览器" 按钮，可以将 IE 设置为默认浏览器
（4）重置"高级"当 IE 被破坏或设置的参数需要还原时，可以点按 "重置" 按钮，使 IE 恢复到刚安装时的状态

记忆：主页在常规、级别在安全、默认在程序、重置在高级。

7.任务实施要点​

  1. 启动计算机，打开浏览器软件；
  2. 查看浏览器的设置；
  3. 在浏览器中访问不同类型的网络资源，如 BBS、FTP 等；
  4. 按照《计算机网络基础综合模拟实训》中 "项目十五 IE 的参数设置——浏览器软件的使用" 的方法与步骤，设置、使用 IE 浏览器。
