任务二 Intranet与Extranet

知识点​

1.任务描述​

当人们在谈论 Intranet 和 Extranet 这两个概念时，通常是从软件和服务的角度来考虑网络的。这一点与局域网（LAN）、城域网（MAN）和广域网（WAN）是有区别的。

这句话是理解本任务的关键：

分类角度对应的概念划分依据
按覆盖范围LAN、MAN、WAN地理范围
按软件与服务Intranet、Extranet、Internet谁来用、怎么用、提供什么服务

典型应用软件：Microsoft Windows SharePoint Services 就是一例典型的 Intranet 应用软件。

2.Intranet 概述​

中文名：Intranet 经常被称为内联网。

定义（三个要点）：

Intranet 是一个企业内部信息管理和交换的基础设施，它：

  1. 基于 Internet 通信标准、Web 技术和设备；
  2. 是可以提供 Web 信息服务以及连接数据库等其他应用服务的；
  3. 自成独立体系的企业内部网络。

3.Intranet 与 Internet 的四点不同（重点）​

对比项InternetIntranet
使用范围全世界只在企业内部使用
使用者任何人只有企业内部的人员才能使用
用途信息发布、资源共享（面向全社会）管理和共享一个企业内部信息，完成企业事务的数字处理
带宽—Intranet 比 Internet 具有更高的带宽

Intranet 也可以连接到 Internet 成为其中的一部分，并用防火墙与 Internet 隔离，外来访问者会受到防火墙的限制。

企业信息的两类去向（易考）：

信息类型举例存放位置
供企业内部使用的保密信息内部管理资料往往放在 Intranet 中
向社会开放的公开信息产品广告、销售信息等放在 Extranet 或者直接放在 Internet 上

记忆：保密往内（Intranet），公开往外（Extranet / Internet）。

4.Intranet 提供的服务（十项）​

通常 Intranet 提供的服务包括：

  1. Web 服务；
  2. 文件传送服务 FTP；
  3. 远程登录服务 Telnet；
  4. 电子邮件服务；
  5. 数据库查询服务；
  6. 打印共享管理；
  7. 用户管理；
  8. 视频会议；
  9. 视频点播；
  10. 网络管理等。

目的：支持企业内部办公业务的自动化、电子化和网络化管理。

5.使用 Intranet 的六大优点​

（1）促进企业组织结构的优化和管理

整个企业采用树型结构组织，层次分明。每个部门都可以有自己的主页，可以包含部门的任何信息，如人员、资源、通报等。能够方便地把用户所有的应用、数据结合在一起，用户可以方便地接入自己的业务子系统和扩充系统功能。

（2）提供人性化的文件共享、信息处理操作环境

由于 Web 页面简单易用，企业内的各部门可以通过浏览器存取信息，使得信息很容易共享和操作，且信息的提供及更新的速度可以大大加快。

（3）发布内部文件

将单位内部的一些文件，包括日常新闻、通告等有关文件，以及与职工切身利益相关的信息，通过 Intranet 发送给全体职工。

（4）内部通信

Intranet 中的电子邮件为单位内部的通信提供了一种极为方便的手段。Internet 上的电子邮件虽然用得很普遍，但使用起来仍然很不方便；Intranet 上的电子邮件产品将会使电子邮件的制作过程更为简单，可以方便地在邮件上附以文件、声音、图像和其他多媒体信息。这种电子邮件将成为单位内部的一种标准通信方式。

（5）简单易用，培训负担轻

由于浏览器易于使用，所以信息部门对于系统建成后所负担的培训等责任减轻许多。培训部门最棘手的问题是需要不断更新教材，使培训内容能及时适应各种新的变化。Intranet 上的内部 Web 服务器妥善地解决了这个问题，它可为职工提供包括声音与影视信息等的最新教材，而且职工可根据本人条件掌握培训进度。

（6）跨平台，容易集成

由于 Intranet 使用 Internet 相关技术，其优势是标准化，容易集成各种已有信息系统，可以有效地融合 LAN/WAN。

六条的记忆线索：结构（1）→ 共享（2）→ 发文（3）→ 通信（4）→ 培训（5）→ 集成（6）。

6.构建 Intranet 的五个步骤（必背）​

  1. 进行网络基础建设，也就是网络硬件建设，选择并安装网络设备和布线系统；
  2. 确定网络操作系统。当前常用的网络操作系统包括 UNIX、Linux、Windows、鸿蒙等，它们都支持 TCP/IP 协议；
  3. 建立 Web、FTP、域名和电子邮件等服务；
  4. 实现 Intranet 连接 Internet，并建立防火墙和代理服务器。Intranet 和 Internet 的连接最常见的方式是通过路由器以 DDN 专线的方式接入；
  5. 实现 Web 服务器和数据库的连接。

第 5 步的两种实现方法（易考）：

方法做法
方法一在 Web 服务器和数据库之间建立 CGI（Common Gateway Interface，公共网关接口） 来进行访问
方法二由浏览器中的 Java 等应用程序负责把利用数据库所需的基本功能和数据交给浏览器，再由浏览器形成 SQL 语句对数据库进行查询访问

7.Extranet 概述​

定义：Intranet 只限于企业内部使用，而 Extranet 是企业内联网向企业外部合作伙伴的扩展。也就是说，在两个或更多公司的联网计算机资源间定义并建立起有限的信任关系，所以 Extranet 就被称为了**"外联网"**。

两个关键词：

  1. "扩展"——是 Intranet 向外合作伙伴的延伸，不是另建一张网；
  2. "有限的信任"——只对特定的伙伴开放特定的资源，不是全面开放。

谁会受益：任何公司，如果拥有共同商业投资，如共同运行、项目合作、客户与提供商共享等，都会从 Extranet 中获益。

两个典型实例（必背）：

  • FedEx（联邦快递公司）：客户常可以登录其网站检查发出的货物状况；
  • DELL（戴尔公司）：客户可以登录其网站检查或修改客户服务等级和信息。

8.Extranet 靠什么技术实现：VPN​

问题所在：企业往往通过 Internet 等公共互联网络与分支机构或其他公司建立 Extranet，进行安全地通信，这就要解决 Intranet 与这些远程节点连接通信所用的公共传输网的传输安全、费用和方便性的问题。

答案：目前最常用也是最有效的技术是虚拟专用网（VPN）。

VPN 带来的四点好处（必背）：

  1. 使 Intranet 摆脱部分繁重的网络升级维护工作；
  2. 使公共网络得到有效的利用；
  3. 新用户要进入 Intranet，只需通过 Internet 连接到 Intranet，Intranet 不必再负担专线租用费用；
  4. Intranet 的扩展性大大提高，从而降低了网络使用和升级维护的支出。

9.三网融合的远景​

Extranet 已经成为商业伙伴间首选的互联方法。

从长远的观点来看，随着 VPN 技术的应用和发展，Internet、Intranet 和 Extranet 之间的差别将逐渐减小直至最终消除，各种网络将合成一个独一无二、遍布全球的"大网络"。

  2. 浏览搜索结果中关于内联网及外联网的叙述；
