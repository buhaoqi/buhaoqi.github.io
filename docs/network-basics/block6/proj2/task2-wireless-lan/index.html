任务二 无线局域网

知识点​

1.什么是无线局域网？​

定义：无线局域网（Wireless Local Area Network，WLAN）是指应用无线通信技术将计算机设备互联起来，构成可以互相通信和实现资源共享的网络体系。

与有线网的根本差别：WLAN 不再使用有形介质（如通信电缆）将计算机与网络连接，而是通过无线方式连接，从而使网络的构建和终端的移动更加灵活。

一句话定位：无线局域网就是采用无线传输介质的局域网，是有线局域网的延伸。使用无线技术来发送和接收数据，减少了用户的连线需求。

2.哪些场合非用无线不可？——有线网的局限​

前面几个项目介绍的都是基于有线传输介质的局域网技术，但在某些应用环境中，使用有线网络存在明显的限制：

场景具体例子有线网的困难
用户频繁移动的公共场所机场、车站、码头端口固定，无法随人移动
历史建筑物内缺少网络电缆、不能进行综合布线的建筑破坏建筑结构与外观
受自然条件影响的环境山川、水面等无法实施布线处施工成本极高甚至不可行
需要临时增设节点的场合体育比赛场地、展示会临时布线不经济

而无线局域网恰恰能在这些场合解决有线局域网的局限性——无线联网将真正的可移动性引入了计算机网络领域。

考点提示：这句话是 WLAN 存在价值的标准答案——可移动性 + 免布线。

3.发展脉络：从 AT&T 到 802.11 家族​

时间事件意义
1991 年美国 AT&T 公司率先推出无线局域网产品为无线局域网的设计、与有线网络的互联以及无线 Internet 接入等方面的发展提供了标准
1997 年IEEE 委员会发布 IEEE 802.11 协议无线局域网领域内第一个在国际上被广泛认可的协议
随后802.11a、802.11b、802.11d 等一系列标准相继完成推动 WLAN 走向安全、高速、互联；各生产厂家在 802.11 系列标准协议基础上实现了产品的标准化

4.无线局域网的两种组网模式​

无线局域网的组网模式有两种：对等（Ad-Hoc）网络和结构化（Infrastructure）网络。

（1）对等（Ad-Hoc）网络

  • 做法：网络中的用户通过无线网卡直接连接，不必使用接入点设备；几台计算机装上无线网卡即可达到相互连接、资源共享的目的；
  • 用户数量：一般为 4~8 个，如果有更多用户接入时网络性能较差；
  • 通信距离：用户之间的有效通信距离约为 100m；
  • 局限：该网络无法接入有线网络中，只能独立使用。

（2）结构化（Infrastructure）网络

  • 做法：无线客户机通过一个集中接入设备——接入点（Access Point，AP）进行网络通信；
  • AP 的作用：
    1. 作为无线局域网的中心，负责信号的接收和转发；
    2. 同时还可以作为一个桥梁，实现无线网络和以太网的有机结合，使接入无线网络的客户机可以和以太网中的计算机互相通信、进行数据共享；
  • 覆盖范围：一个 AP 的覆盖范围为 90~150m。

两种模式对比表：

对比项对等（Ad-Hoc）网络结构化（Infrastructure）网络
中心设备无（不需要 AP）有（AP 接入点）
组网方式无线网卡直接互联客户机 → AP → 网络
用户规模4~8 个一个 AP 可接入多个用户
通信距离约 100mAP 覆盖 90~150m
能否接入有线网不能，只能独立使用能，AP 起桥梁作用
典型场景几台笔记本临时互传文件家庭、办公室、校园 WLAN

看图口诀：Ad-Hoc 是"点对点平铺"，Infrastructure 是"以 AP 为圆心的星型"。

5.802.11 标准管哪些层？​

层次归属：IEEE 802.11 标准包括了无线局域网的物理层和 MAC 子层。

层次标准负责的内容具体子标准
物理层规定了无线传输信号等基础规范802.11a、802.11b、802.11d、802.11g、802.11h
MAC 子层在物理层上的一些应用要求规范802.11e、802.11f、802.11i

三种可选的物理层实现方式：

  1. 红外线（IR）基带物理层；
  2. 跳频扩展频谱（Frequency Hopping Spread Spectrum，FHSS）方式——工作在 2.4GHz 频段；
  3. 直接序列式扩频（Direct Sequence Spread Spectrum，DSSS）方式——工作在 2.4GHz 频段。

两种无线频率（RF）物理层即上述 FHSS 与 DSSS。目前 IEEE 802.11 规范的实际应用以使用 DSSS 方式为主流。

考点提示：WLAN 工作在物理层 + MAC 子层（不是整个数据链路层，也不含 LLC 的独立标准）——这与模块五讲过的 802 模型只含物理层与数据链路层完全一致，只是 802.11 只规定了 MAC 子层。

6.为什么无线网用 CSMA/CA 而不是 CSMA/CD？​

IEEE 802.11 标准（包括 802.11b、802.11a 和 802.11g）在 MAC 子层采用带有冲突避免的载波监听/多路访问（Carrier Sense Multiple Access/Collision Avoidance，CSMA/CA）方法。

它与 CSMA/CD 的关系：该方法与 CSMA/CD 方法类似，都是为了解决"谁先说话"的竞争问题。

为什么是"避免（CA）"而不是"检测（CD）"：为了减小无线设备之间在同一时刻同时发送数据导致冲突的风险，802.11 引入了称为请求发送/清除发送（RTS/CTS）的机制。无线站点无法像有线站点那样边发边听（发送时自身信号会淹没接收信号），也无法可靠地"听到"远处的冲突，因此只能在发送前先预约信道。

RTS/CTS 的工作过程：

步骤动作说明
1数据到达基站，若发送目的地是无线节点基站向该无线节点发送一个 RTS 帧
2RTS 帧的作用请求一段用来发送数据的专用时间
3收到 RTS 的无线节点回应一个 CTS 帧表示它将中断其他所有的通信，直到该基站数据传输结束
4其他设备监听到此传输事件将在此时间段的其他传输任务向后推迟
5结果节点间传输数据时发生冲突的概率大大减少

CSMA/CD 与 CSMA/CA 对照：

对比项CSMA/CD（有线以太网）CSMA/CA（无线局域网）
冲突策略检测冲突（Collision Detection）避免冲突（Collision Avoidance）
能否边发边听能，检测到冲突就停止并退避不能，故改为发送前预约
典型机制冲突检测 + 二进制指数退避RTS/CTS 握手 + 退避
适用介质共享有线介质无线介质

7.三个常用子标准​

由于 IEEE 802.11 的速率最高只能达到 2Mb/s，在速率和传输距离上都不能满足人们的需要，IEEE 委员会又相继推出了 802.11b、802.11a 和 802.11g 标准。802.11b 已经成为目前的主流标准，802.11a 和 802.11g 也被广泛使用。

（1）IEEE 802.11b

  • 别名：也称 Wi-Fi；
  • 频段与扩频：采用 2.4GHz 直接序列扩频（DSSS）；
  • 速率：最高数据传输速率为 11Mb/s；
  • 动态速率转换：当射频情况变差时，可将速率降低为 5.5Mb/s、2Mb/s 和 1Mb/s；
  • 覆盖范围：室外开放性区域为 305m，室内封闭性区域为 76~122m；
  • 发射功率：不超过 100 毫瓦，一般工作在 60~70 毫瓦，对人体安全。

（2）IEEE 802.11a

  • 地位：是 802.11b 的后续标准；
  • 频段：工作在 5.1~5.8GHz 频率范围；
  • 速率：最高数据传输速率可达 54Mb/s；
  • 接口能力：可提供 25Mb/s 的无线 ATM 接口和 10Mb/s 的以太网无线帧结构接口；
  • 业务支持：支持语音、数据、图像业务；
  • 接入能力：一个 AP 可接入多个用户，每个用户可带多个用户终端。

（3）IEEE 802.11g

  • 性质：是一种混合标准；
  • 兼容性：既能适应传统的 802.11b 标准（在 2.4GHz 频率下提供 11Mb/s 的数据传输率），也符合 802.11a 标准在 5GHz 频率下提供 54Mb/s 的数据传输率。

三个子标准对比表：

对比项802.11b802.11a802.11g
别名Wi-Fi—混合标准
频段2.4GHz5.1~5.8GHz2.4GHz 与 5GHz 双频兼容
扩频方式DSSS—兼容 b 与 a
最高速率11Mb/s54Mb/s11Mb/s（2.4GHz）/ 54Mb/s（5GHz）
速率档位11 / 5.5 / 2 / 1 Mb/s 动态转换54Mb/s兼容两套
覆盖范围室外 305m；室内 76~122m——
与旧标准兼容是（802.11 原标准）不兼容 802.11b（频段不同）兼容 802.11b
主流程度当时主流广泛使用广泛使用

教材表述差异提示：教材 802.11g 一段写作"在 5GHz 频率下提供 56Mb/s"，而 802.11a 一段写作 54Mb/s，两个数字在同一页自相矛盾。按 IEEE 标准与主流资料，802.11a/g 的最高速率均为 54Mb/s，本讲按 54Mb/s 讲解，若考试按教材原文出题请以教材为准。
