## 知识点

### 1.小型无线路由器网络是什么？

**应用范围**：当前小型无线路由器网络有着**广泛的应用**，如**家庭、办公场所**等。

**组网结构**：这种网络**以小型无线路由器为中心**——

- **对外**：通过**光纤**（或电话线、有线电视信号线等）与**外部网络**相连；
- **对内**：使用**无线信号**与**内部终端设备**连接。

**优点**：**使用方便、管理便利**。

本任务解决三个问题：**怎么连（接口）→ 怎么设（上网配置）→ 怎么防（安全加固）**。

### 2.无线路由器有哪些接口？

无线路由器一般有**三种接口**：

| 接口 | 名称 | 作用 |
|------|------|------|
| **电源接口** | — | 为路由器供电 |
| **WAN 接口** | **广域网接口**（Wide Area Network） | **用来连接广域网络** |
| **LAN 接口** | **局域网接口**（Local Area Network） | **用来以有线方式连接本地设备**；无线路由器一般也提供**有线的连接**，标记为 **LAN** |

**除接口外**还有**无线网络信号的发射天线**：**早期为 1 根，现在一般为 4 或 6 根**。

**两种网口的接法**：

| 接口 | 接什么 |
|------|--------|
| **WAN 口** | 如果是**宽带接入**，该口可**直接接入宽带盒**；如果是**其他接入方式**，则连接从**调制解调器或光电转换盒**输出的插孔 |
| **LAN 口** | 用**双绞线**连接**本地设备**（计算机、交换机等） |

**统一标准**：**WAN 口和 LAN 口均以 RJ45 标准提供。** 教材图 6-11 演示的是**宽带连网方式**——**宽带接入线**接 **WAN 口**，计算机通过网线接 **LAN 口**，无线终端则通过**天线**发出的信号接入。

**考点提示**：**WAN 朝外、LAN 朝内**；**RJ45** 是两种网口共同的物理标准——这一点常与模块五的"双绞线 + RJ45 + 100m"串起来考。

### 3.无线路由器的设置（五步）

**（1）连线并登录**

- 用**网线**将无线路由器的 **LAN 口（任何一个 LAN 口均可）** 和**计算机的网口**连接，**打开两个设备的电源**；
- **阅读无线路由器的说明书**，查看无线路由器的 **IP 地址**；
- 在计算机上**打开浏览器**，**地址栏输入路由器的 IP 地址**。

**默认管理地址**：一般无线路由器的默认 IP 地址为 **192.168.0.1** 或 **192.168.1.1**。

**（2）输入账号密码**

在**登录界面**输入**默认的账号和密码**，账号和密码可以**从说明书中查到**。

**（3）选择上网方式（以电信为例）**

以**电信用户**为例，选择 **PPPoE**，**输入账号和密码**。**其他网络运营商**的，按照**网络运营商提供的资料**选择 **DHCP** 或者**固定 IP 地址**，之后进入下一步。

**（4）选择无线参数**

一般情况下**设置均按默认即可**：

| 参数 | 取值与说明 |
|------|------------|
| **频射开关** | 选择**开启** |
| **频射工作模式** | 选择**混合** |
| **SSID**（Service Set Identifier，**服务集标识**） | 是**无线网络的名称**，可**根据自己的意愿更改**，**中英文均可** |
| **频道** | 可以**自由选择**，一般情况下**默认频道是 6** |

**（5）保存、重启、进高级设置**

设置完成后**进行保存**，之后对路由器进行**断电、重启**；重启后**回到管理页面**，根据用户需要可以进行**高级设置**。如：选择**无线设置 → 安全设置 → 更改认证密钥**（无线路由器的**登录密码**），设置完成并**确定后重启**无线路由器，然后**拔掉网线**。

**设置完成后的使用**：无线终端即可**搜索无线网络**，**发现无线路由器的网络名称**后即可**进行连接**，在**通过身份验证**后进行**上网操作**。

**有线接入的补充**：除了无线连接外，无线路由器一般还提供 **4 个 RJ45 接口**用于**有线连接**。使用**双绞线**将笔记本电脑与无线路由器相连，**根据是否启用无线路由器的 DHCP 服务**，**自动或手工设置**笔记本电脑的 **IP 地址及网关参数**，即可上网访问。

**五步流程速记**：**连线 → 登录 → 选上网方式 → 设 SSID/频道 → 保存重启改密码**（最后**拔网线**）。

### 4.提高无线路由器安全性的五项措施

**（1）修改路由器登录账号和密码**

- **现状**：一般无线路由器**出厂默认登录账号和密码均为 `admin`**；
- **建议**：对登录账号和密码**进行修改**，**防止非法用户修改无线路由器的配置**。

**（2）关闭 SSID 广播**

- **原理**：**SSID 是无线网络的名称**，无线终端设备通过**发现 SSID 网络名称**来与路由器进行无线连接；
- **做法**：可以通过无线路由器的设置**关闭 SSID 广播**；
- **效果**：关闭后，无线终端设备**无法扫描到网络名称**，**只有知道此网络名称的用户**，以**手工方式输入该名称**，才能与路由器进行无线连接。

**（3）启用无线路由器的"白名单"策略**

- **什么是白名单**：大部分品牌的路由器在**无线网络安全设置**选项中有"**白名单**"安全策略，是指**只有列入名单中的移动设备**才可以连接到无线路由器，并**经过路由器访问互联网**；
- **设置过程**：
  1. 打开"**无线 MAC 地址过滤**"；
  2. 在打开的页面中，把"**MAC 地址过滤功能**"**勾选**；
  3. **过滤规则**：**允许列表中生效的 MAC 地址访问本无线网络**；
  4. 点击"**添加新条目**"，**输入允许连接的移动设备无线网卡的 MAC 地址**；
  5. 设置完成后，**将路由器重新启动**；
- **效果**：此时**没有在"白名单"列表中出现的终端设备**，**即使连接到了路由器网络，也不能上网访问**。

**（4）开启路由器防火墙**

通过防火墙中的 **IP 地址和 MAC 地址过滤**，**只允许特定用户的 IP 地址或者 MAC 地址连接 Internet**，可以有效**防止非法接入者共享带宽**。

**（5）启用 WEP 或 WPA（WPA2）加密通讯数据**

无线路由器常用的加密技术有 **3 种**：

| 加密技术 | 全称 | 加密强度 | 说明 |
|----------|------|----------|------|
| **WEP** | **有线对等保密**（Wired Equivalent Privacy） | **最弱** | 三种加密技术中**加密能力最弱**的一种 |
| **WPA** | **Wi-Fi 保护接入**（Wi-Fi Protected Access） | 较强 | 使用了**更复杂的加密技术**和**经过改进的密钥管理技术**，**加密功能更为可靠** |
| **WPA2** | WPA 的第二版 | **最强（教材推荐）** | 同上，安全性优于 WEP，是实际部署的首选 |

**结论**：**WEP 是加密能力最弱的一种**，而 **WPA 或者 WPA2** 则因使用了**更复杂的加密技术和经过改进的密钥管理技术**，**加密功能更为可靠**。

**五项措施速记**：**改密码 → 关广播 → 白名单 → 开防火墙 → 上加密**。前四项是"**谁能进**"，第五项是"**进去了也看不懂**"。

### 6.本任务速查表

| 考点 | 结论 |
|------|------|
| 路由器三种接口 | **电源口、WAN 口、LAN 口** |

| 防蹭网带宽 | **防火墙的 IP 与 MAC 地址过滤** |
| 三种加密 | **WEP（最弱）、WPA、WPA2** |
