任务三 小型无线路由器网络

知识点​

1.小型无线路由器网络是什么？​

应用范围：当前小型无线路由器网络有着广泛的应用，如家庭、办公场所等。

组网结构：这种网络以小型无线路由器为中心——

  • 对外：通过光纤（或电话线、有线电视信号线等）与外部网络相连；
  • 对内：使用无线信号与内部终端设备连接。

优点：使用方便、管理便利。

本任务解决三个问题：怎么连（接口）→ 怎么设（上网配置）→ 怎么防（安全加固）。

2.无线路由器有哪些接口？​

无线路由器一般有三种接口：

接口名称作用
电源接口—为路由器供电
WAN 接口广域网接口（Wide Area Network）用来连接广域网络
LAN 接口局域网接口（Local Area Network）用来以有线方式连接本地设备；无线路由器一般也提供有线的连接，标记为 LAN

除接口外还有无线网络信号的发射天线：早期为 1 根，现在一般为 4 或 6 根。

两种网口的接法：

接口接什么
WAN 口如果是宽带接入，该口可直接接入宽带盒；如果是其他接入方式，则连接从调制解调器或光电转换盒输出的插孔
LAN 口用双绞线连接本地设备（计算机、交换机等）

统一标准：WAN 口和 LAN 口均以 RJ45 标准提供。 教材图 6-11 演示的是宽带连网方式——宽带接入线接 WAN 口，计算机通过网线接 LAN 口，无线终端则通过天线发出的信号接入。

考点提示：WAN 朝外、LAN 朝内；RJ45 是两种网口共同的物理标准——这一点常与模块五的"双绞线 + RJ45 + 100m"串起来考。

3.无线路由器的设置（五步）​

（1）连线并登录

  • 用网线将无线路由器的 LAN 口（任何一个 LAN 口均可） 和计算机的网口连接，打开两个设备的电源；
  • 阅读无线路由器的说明书，查看无线路由器的 IP 地址；
  • 在计算机上打开浏览器，地址栏输入路由器的 IP 地址。

默认管理地址：一般无线路由器的默认 IP 地址为 192.168.0.1 或 192.168.1.1。

（2）输入账号密码

在登录界面输入默认的账号和密码，账号和密码可以从说明书中查到。

（3）选择上网方式（以电信为例）

以电信用户为例，选择 PPPoE，输入账号和密码。其他网络运营商的，按照网络运营商提供的资料选择 DHCP 或者固定 IP 地址，之后进入下一步。

（4）选择无线参数

一般情况下设置均按默认即可：

参数取值与说明
频射开关选择开启
频射工作模式选择混合
SSID（Service Set Identifier，服务集标识）是无线网络的名称，可根据自己的意愿更改，中英文均可
频道可以自由选择，一般情况下默认频道是 6

（5）保存、重启、进高级设置

设置完成后进行保存，之后对路由器进行断电、重启；重启后回到管理页面，根据用户需要可以进行高级设置。如：选择无线设置 → 安全设置 → 更改认证密钥（无线路由器的登录密码），设置完成并确定后重启无线路由器，然后拔掉网线。

设置完成后的使用：无线终端即可搜索无线网络，发现无线路由器的网络名称后即可进行连接，在通过身份验证后进行上网操作。

有线接入的补充：除了无线连接外，无线路由器一般还提供 4 个 RJ45 接口用于有线连接。使用双绞线将笔记本电脑与无线路由器相连，根据是否启用无线路由器的 DHCP 服务，自动或手工设置笔记本电脑的 IP 地址及网关参数，即可上网访问。

五步流程速记：连线 → 登录 → 选上网方式 → 设 SSID/频道 → 保存重启改密码（最后拔网线）。

4.提高无线路由器安全性的五项措施​

（1）修改路由器登录账号和密码

  • 现状：一般无线路由器出厂默认登录账号和密码均为 admin；
  • 建议：对登录账号和密码进行修改，防止非法用户修改无线路由器的配置。

（2）关闭 SSID 广播

  • 原理：SSID 是无线网络的名称，无线终端设备通过发现 SSID 网络名称来与路由器进行无线连接；
  • 做法：可以通过无线路由器的设置关闭 SSID 广播；
  • 效果：关闭后，无线终端设备无法扫描到网络名称，只有知道此网络名称的用户，以手工方式输入该名称，才能与路由器进行无线连接。

（3）启用无线路由器的"白名单"策略

  • 什么是白名单：大部分品牌的路由器在无线网络安全设置选项中有"白名单"安全策略，是指只有列入名单中的移动设备才可以连接到无线路由器，并经过路由器访问互联网；
  • 设置过程：
    1. 打开"无线 MAC 地址过滤"；
    2. 在打开的页面中，把"MAC 地址过滤功能"勾选；
    3. 过滤规则：允许列表中生效的 MAC 地址访问本无线网络；
    4. 点击"添加新条目"，输入允许连接的移动设备无线网卡的 MAC 地址；
    5. 设置完成后，将路由器重新启动；
  • 效果：此时没有在"白名单"列表中出现的终端设备，即使连接到了路由器网络，也不能上网访问。

（4）开启路由器防火墙

通过防火墙中的 IP 地址和 MAC 地址过滤，只允许特定用户的 IP 地址或者 MAC 地址连接 Internet，可以有效防止非法接入者共享带宽。

（5）启用 WEP 或 WPA（WPA2）加密通讯数据

无线路由器常用的加密技术有 3 种：

加密技术全称加密强度说明
WEP有线对等保密（Wired Equivalent Privacy）最弱三种加密技术中加密能力最弱的一种
WPAWi-Fi 保护接入（Wi-Fi Protected Access）较强使用了更复杂的加密技术和经过改进的密钥管理技术，加密功能更为可靠
WPA2WPA 的第二版最强（教材推荐）同上，安全性优于 WEP，是实际部署的首选

结论：WEP 是加密能力最弱的一种，而 WPA 或者 WPA2 则因使用了更复杂的加密技术和经过改进的密钥管理技术，加密功能更为可靠。

五项措施速记：改密码 → 关广播 → 白名单 → 开防火墙 → 上加密。前四项是"谁能进"，第五项是"进去了也看不懂"。

5.任务实施（教材要求的检索）​

  1. 启动计算机，在搜索工具中以"无线路由器"为关键词进行搜索；
  2. 浏览搜索结果中关于无线路由器 WAN 连接介质的叙述；
  3. 搜索提高无线路由器安全性能的方法。
