任务四 同步训练

知识点​

本同步训练位于教材 186 页，是模块六 局域网组网技术的模块级训练——题目不局限于项目二（VLAN 与无线网络），大量题目来自项目一（组网设备与方法），个别题目（如 ATM）属于拓展知识。题目按教材原文收录，答案与解析附于每部分之后。

四、参考答案​

1.填空题答案​

题号答案
1ISA、PCI、PCMCIA、USB
2根据"端口—MAC 地址映射表"转发数据帧（自学习 + 查表转发，查不到则向除源端口外的所有端口广播）
3直接交换、存储转发、混合交换（无碎片交换）
4数据链路层；MAC 网桥；LLC 网桥

第 1 题解析：网卡按总线接口可分为 ISA（8/16 位，已淘汰）、PCI（32/64 位，最普遍）、PCMCIA（笔记本专用）、USB（热插拔，一端 USB 一端 RJ-45）。若考题只给 3 个空，优先填 ISA、PCI、USB。

第 2 题解析：交换机的工作原理可以概括为"学习 + 转发"两条：

  1. 自学习：收到帧时，把源 MAC 地址与接收端口的对应关系写入端口—MAC 地址映射表（有 300s 老化时间）；
  2. 查表转发：以目的 MAC 地址查表——查到则从对应端口定向转发；查不到则向除源端口外的所有端口广播（泛洪）。

第 4 题解析：注意区分"网桥"和"交换机"的填空——网桥是数据链路层设备；按是否转换帧格式分为 MAC 网桥（互联同类型局域网，如以太网—以太网）与 LLC 网桥（互联不同类型局域网，如以太网—令牌环）。

2.选择题答案​

题号12345
答案ADACC

第 1 题解析：集线器物理上是星型、逻辑上是总线型——所有端口共享同一条内部总线，任一时刻只能有一个站点发送，属于共享介质设备，故工作逻辑上是总线型。这是本卷最经典的"物理/逻辑分离"考点，与"令牌环物理星型、逻辑环型"同理。

第 2 题解析：交换机两大性能指标是 MPPS（包转发率） 与 背板带宽（交换容量，单位 Gb/s）。背板带宽决定交换机总的数据交换能力，包转发率决定每秒能转发多少个包；两者要匹配，否则一方成为瓶颈。

第 3 题解析：以太网采用透明网桥（Transparent Bridge，IEEE 802.1d）——各网桥自学习转发表，站点完全感觉不到网桥存在，"透明"由此得名；源路由网桥用于令牌环网。选项 C "MAC" 与 D "LLC" 是网桥的两种类型，不是以太网的具体网桥名称。

第 4 题解析：网关（协议转换器）实现不同协议之间的转换，靠的是适当的硬件与软件配合。注意 B "配置"不是技术手段，D "协议"是被转换的对象而非转换工具。

第 5 题解析：ATM 技术包含交换技术（信元交换）、差错处理技术（信头 HEC 校验）、流量控制技术（使用参数控制 UPC、连接允许控制 CAC），但不包含"可变速率编码技术"——ATM 采用的是固定长度信元与统计（异步）时分复用，"可变速率编码"属于语音压缩编码领域的概念。

3.问答题参考答案​

第 1 题：C/S 模式下对服务器性能的要求

C/S（客户机/服务器）模式中，服务器是服务的提供者，要为多台客户机并发提供服务，因此在性能上有以下要求：

  1. 处理器：主频高、核心多，能同时处理多个客户请求；
  2. 内存：容量大，用于缓存数据与支撑并发进程；
  3. 存储：硬盘容量大、转速高，宜采用 RAID 与热插拔硬盘，保证数据安全与不停机维护；
  4. 网络接口：采用高带宽网卡（千兆/万兆），必要时多网卡绑定做冗余与负载分担；
  5. 可靠性：冗余电源、ECC 内存、风扇冗余，支持 7×24 小时连续运行；
  6. 可扩展性：插槽、盘位、内存槽留有裕量，便于升级；必要时用服务器集群提升整体性能与可用性。

第 2 题：MAC 地址为什么必须唯一？多少位十六进制？

  • 唯一的原因：MAC 地址（物理地址/硬件地址）工作在数据链路层，是帧在同一局域网内寻址的唯一依据。若两块网卡地址相同，交换机/网卡的地址表会出现冲突，帧可能被送到错误的站点，造成通信失败或数据泄露。因此 MAC 地址必须在全球范围内唯一。
  • 组成：MAC 地址由 12 位十六进制数组成，即 48 比特 = 6 字节；其中前 3 字节为厂商代码（由 IEEE 分配），后 3 字节为网卡编号（由厂商分配），如 00-30-21-0B-5E-43。

第 3 题：网卡的接收模式

  • 四种接收模式：广播模式、组播模式、直接（单播）模式、混杂模式。
  • 网卡正常工作时可接收三种数据帧：广播帧（目的地址全 1）、组播帧（发给本组的帧）、发给自己的单播帧。
  • 若要接收所有数据帧，应将网卡设置为 混杂模式（Promiscuous Mode）——此时网卡不再过滤目的地址，把介质上出现的所有帧都交给上层，网络抓包分析正是利用这一模式。

第 4 题：交换机的三种工作模式与工作过程

工作模式工作过程优点缺点
直接交换（Cut-Through）只读取帧的前 6 字节目的 MAC 地址，查表后立即转发，不接收完整帧、不做校验延迟最小不检查差错，坏帧、碎片帧也会被转发
存储转发（Store-and-Forward）把整个帧完整接收并缓存，做 CRC 校验，确认无误后再查表转发可靠性高，可丢弃错帧，支持不同速率端口间转换延迟最大（与帧长有关）
混合交换（无碎片交换）只接收帧的前 64 字节（够读到目的地址且能判断是否为碎片帧）即转发，小于 64 字节的碎片帧直接丢弃延迟与可靠性折中，能过滤冲突产生的碎片仍不做完整 CRC 校验

第 5 题：交换机与 Hub 的主要区别

对比项集线器（Hub）交换机（Switch）
工作层次物理层数据链路层
转发依据无，向所有其他端口广播依据端口—MAC 地址映射表定向转发
带宽所有端口共享总带宽（如 10Mb/s 分给 16 口）每端口独享带宽（10M 全双工为 20M）
双工方式半双工支持全双工
冲突域所有端口同属一个冲突域每个端口一个冲突域，可分割冲突域
广播域一个仍是一个（需 VLAN 或路由器才能划分）
VLAN 支持不支持支持
工作模式—直接交换、存储转发、混合交换

第 6 题：局域网设计应考虑的因素

  1. 需求分析：用户数量、节点分布与地理范围、应用类型（是否含语音/视频）、带宽与峰值流量、可靠性要求、预算；
  2. 拓扑结构：在总线型、星型、环型、树型中选型（现在以星型/多级星型为主）；
  3. 传输介质：双绞线、同轴电缆、光纤、无线，按距离、速率、抗干扰、成本权衡；
  4. 设备选型：网卡、集线器/交换机、路由器、服务器的规格与端口数，是否支持VLAN、堆叠/级联；
  5. 网络操作系统与协议：如 Windows Server 与 TCP/IP 的版本与配置；
  6. 可靠性与冗余：链路备份、设备冗余、UPS 供电；
  7. 安全性：VLAN 隔离、访问控制、防火墙、无线加密；
  8. 可扩展性：端口与带宽留有余量，便于分期扩容；
  9. 与外部网络的互联：出口带宽、NAT、路由；
  10. 综合布线与施工：结构化布线规范、线槽桥架、测试验收；
  11. 管理与维护：可管理型设备、网管软件、维护制度。

第 7 题：ATM 交换原理与传统交换技术的区别

对比项ATM 交换传统电路交换传统分组交换
交换单位固定长度信元（53 字节 = 5 字节信头 + 48 字节净荷）时隙（同步时分）变长分组
连接方式面向连接（先建虚连接）面向连接（建立物理专线）无连接或虚电路
复用方式统计（异步）时分复用，按需占用同步时分复用，固定分配时隙统计复用
寻址标识VPI/VCI（虚路径/虚通道标识）时隙位置分组头地址
处理方式硬件信元交换，逐段不做差错控制与流量控制（交给端到端）硬件交叉连接软件存储转发，逐段检错重发
时延小且稳定（固定信元、硬件交换）最小且恒定大且抖动大
带宽利用率高（无业务时隙可被其他连接使用）低（空闲时隙也独占）较高
适用业务语音、数据、图像综合业务语音（实时恒定速率）数据（突发业务）

核心区别一句话：ATM 用固定长度的短信元 + 硬件交换 + 统计复用，把电路交换的实时性与分组交换的灵活性结合起来，同时简化了逐段差错控制，从而兼顾高速与多业务。

第 8 题：网卡、集线器、交换机所处的层次与功能特点

设备所处层次功能特点
网卡（网络适配器）物理层 + 数据链路层（MAC 子层）① 计算机与传输介质之间的接口；② 并行数据与串行信号的转换；③ 帧的封装与解封、CRC 校验；④ 介质访问控制（CSMA/CD）、编码解码；⑤ 数据缓存；⑥ 提供唯一 MAC 地址；⑦ 支持四种接收模式与无盘工作站 BOOTROM
集线器（Hub）物理层① 本质是多端口中继器；② 对信号再生、放大、整形后向所有其他端口广播；③ 共享带宽、半双工；④ 所有端口同属一个冲突域与广播域；⑤ 无寻址能力，不能隔离流量，已被交换机取代
交换机（Switch）数据链路层① 依据端口—MAC 地址映射表定向转发，自学习 + 300s 老化；② 每端口独享带宽、支持全双工；③ 分割冲突域（每口一个），不分割广播域；④ 支持 VLAN、端口聚合/堆叠/级联；⑤ 三种工作模式；⑥ 延迟几十微秒，远低于路由器

层次速记：物理层——中继器、集线器；数据链路层——网桥、交换机、网卡（含 MAC）；网络层——路由器、三层交换机；应用层——网关。
