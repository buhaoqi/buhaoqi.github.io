## 知识点

### 1.组网时要考虑哪些因素？

局域网组网时要考虑所使用的**传输介质、连接设备**等因素，另外**介质访问控制方法**也是一个重要因素——**不同的局域网组网标准对应着不同的连网实践**。

本任务详细介绍局域网的**建网标准**，如 **10BASE-5、100BASE-T** 等。

**三条主线**：**细缆（同轴）→ 双绞线 → 光纤**，正好对应**总线型 → 星型 → 星型（多级）** 的拓扑演进和 **10M → 100M → 1000M/10G** 的速率演进。

### 2.细缆组网怎么做？

采用**细缆**作为传输介质连接形成局域网，应符合 **10Base-2 标准**，连接为**总线拓扑结构**。

| 项目 | 要求 |
|------|------|
| **标准** | **10Base-2** |
| **拓扑** | **总线型** |
| **网段最大长度** | **185m**；超过则需用**中继器**连接 |
| **除电缆外还需** | **BNC 头、T 型头、终端匹配器** |
| **网卡要求** | 必须带有**细缆连接接口（BNC）** |

**细缆组网的技术参数**（教材四项）：

| 参数 | 数值 |
|------|------|
| 单个网段**最大电缆长度** | **185m** |
| **最大网络电缆长度** | **925m** |
| 单个网段**支持的最大节点数** | **30 个** |
| **BNC、T 型连接器之间的最小距离** | **0.5m** |

**优点**：**结构简单、容易实现、组网成本低**，适合于**实验室环境及其他小型网络**。

**缺点**：**带宽低**；**BNC 接头连接处易出故障**；**维护较麻烦**。

**一处注意**：教材正文写"每个网段的最大长度为 **180m**"，而技术参数与 10BASE-2 标准均为 **185m**（同一段文字内两种说法）。**考试与工程实际以 185m 为准**，答题时若遇到 180m 也应认出指的是同一指标。

### 3.双绞线组网（10Mb/s 以太网）怎么做？

双绞线组网连接如图 6-6 所示：**DTE（计算机）+ 以太网卡 + RJ-45 + 非屏蔽双绞线（UTP）→ Hub**。

符合 **10Base-T 标准**，为**星型拓扑结构**。

**所需基本硬件设备**：

1. 带 **RJ-45 接口**的以太网卡
2. **Hub**（集线器）
3. **3 类或 5 类 UTP**（非屏蔽双绞线）
4. **RJ-45 连接头**（俗称**水晶头**）
5. **专用网钳**

**三条关键指标**：

| 指标 | 数值 |
|------|------|
| **单根双绞线最大距离** | **100m** |
| **Hub 级联** | **不超过 4 级** |
| **使用芯线** | 只用双绞线的 **2 对芯线（1、2、3、6 线）** |

**为什么只用 4 根线**：10BASE-T 是**半双工**，一对线发送（1、2）、一对线接收（3、6），另外两对（4、5、7、8）留着备用（后来的 100BASE-T4、千兆才用满 4 对）。

**为什么级联不超过 4 级**：每级 Hub 都会**再生并引入时延**，级数过多会使**往返时延超过 CSMA/CD 的冲突检测窗口**，导致冲突检测失效。

### 4.双绞线组网（100Mb/s 快速以太网）怎么做？

**100Mb/s 以太网也称快速以太网**。

**所需基本硬件设备**：

| 设备 | 说明 |
|------|------|
| **100Mb/s 的 Hub 或交换机** | 中心设备 |
| **10/100Mbps 自适应以太网卡** | 终端网卡 |
| **5 类 UTP 双绞线** | 传输介质 |

**100Base-T 的网卡有 2 种**：分别支持 **100Base-TX**、**100Base-T4**。组网连接方法与 **10BASE-T 网类似**（如图 6-7）。

**用双绞线组千兆网、万兆网**：拓扑结构、连接方法等与上述操作**都相同**，**只需更换**为支持千兆、万兆的**连接双绞线、交换机、网卡**即可。

**一句话**：**双绞线组网"一代比一代快，接法基本不变"**——换设备、换线缆等级，拓扑和连线方式沿用星型。

### 5.光纤组网（千兆位以太网）怎么做？

**千兆位以太网（1Gb/s 以太网）** 作为一种高速以太网技术，给用户带来了**提高核心网络**的有效解决方案。

**兼容性（为什么要用千兆）**：千兆位以太网技术采用了与 10M 以太网**相同的帧格式、帧结构、网络协议、全双工/半双工工作方式、流控模式以及布线系统**，可与 **10Mb/s 或 100Mb/s** 的以太网很好地**兼容、进行无缝通信**；同时便于 10Mb/s 或 100Mb/s 的以太网**平滑升级**到千兆以太网，而**不必改变网络应用程序、网管方法和网络操作系统**，能够**最大限度地保护用户投资**。

**基本硬件设备**：**1000Mb/s 以太网交换机、1000Mb/s 以太网卡、光缆**。

**三种介质标准**：

| 标准 | 介质 | 距离 |
|------|------|------|
| **1000Base-T** | **5 类 UTP** | **100m** |
| **1000BASE-LX** | **单模光纤** | **3000m** |
| **1000Base-SX** | **多模光纤** | **300~550m** |

**遵循的协议**：

| 协议 | 支持 |
|------|------|
| **IEEE 802.3z** | 支持**光纤和宽带同轴** |
| **IEEE 802.3ab** | 支持**5 类 UTP** |

**组网原则（图 6-8 多级星型网络的带宽分布）**：千兆以太网主要考虑**如何合理分配网络带宽**，实际应用时可根据网络的规模与布局选择**多级星型结构**，并注意以下两点：

1. **主干部分**若选择**千兆以太网交换机**，**支干部分**可选**小型千兆以太网交换机或 100Mb/s 交换机**
2. **部门级**选 **100Mb/s 交换机或 Hub**，**用户端**选用 **10/100Mbps 自适应以太网卡**

**带宽分布的逻辑**：越靠近**核心/服务器**带宽越高（1000M），越靠近**用户端**带宽越低（10M/100M），这样**既满足瓶颈处的大流量，又不为每个桌面过度投资**。

### 6.光纤组网（万兆位以太网）怎么做？

**万兆以太网（10Gb/s 网）** 使用 **IEEE 802.3 以太网介质访问控制（MAC）和 IEEE 802.3 以太网帧格式**，**不需要修改以太网 MAC 协议或分组格式**。

**组成（光纤组网三部分）**：

| 部分 | 作用 |
|------|------|
| **光源（光发送机）** | 把电信号转换成光信号发出 |
| **传输介质（光纤）** | 传输光信号 |
| **检测器（光接收机）** | 把光信号还原成电信号 |

**光端机**：其中**光源和检测器的工作由光端机完成**。光端机是**将多个 E1 信号变成光信号并传输**的设备，它的作用主要就是实现**光/电转换**。

- **E1 的速率**：通常为 **2.048Mb/s**（此标准为**中国和欧洲**采用）
- **复用能力**：一般最小的光端机可以传输 **4 个 E1**，目前最大的光端机可以传输 **4032 个 E1**

**适用场合**：

- 万兆以太网技术适合于**建立交换机到交换机**的连接，可以支持**交换机与服务器之间**的互联
- 万兆以太网能与 **10/100Mbps 或千兆位以太网无缝地集成**在一起

**发展趋势**：在未来几年中，万兆以太网技术将成为**市场的主流产品**；随着**万兆芯片、万兆模块价格不断下降**以及**传输网带宽不断升级**、网络传输和交换容量进一步增大，**万兆交换机**的应用也将日益普遍。

### 7.三种组网方法对比

| 比较项 | 细缆组网 | 双绞线组网 | 光纤组网 |
|--------|----------|------------|----------|
| **标准** | **10Base-2** | **10Base-T / 100Base-T** | **1000Base-X / 10G** |
| **拓扑** | **总线型** | **星型** | **多级星型** |
| **介质** | 50Ω **细同轴电缆** | **3/5 类 UTP**（3 类用于 10M） | **单模/多模光纤** |
| **连接器件** | **BNC 头、T 型头、终端匹配器** | **RJ-45 水晶头**、网钳、Hub/交换机 | **SC/ST 光接口**、光端机 |
| **距离** | 网段 **185m**，全网 **925m** | 单根 **100m** | LX **3000m**、SX **300~550m** |
| **节点数** | 每网段 **30 个** | 受端口数与级联级数限制 | 受端口数限制 |
| **速率** | 10Mb/s | 10/100Mb/s（千兆万兆换设备即可） | 1000Mb/s、10Gb/s |
| **优点** | 简单、便宜、易实现 | 布线方便、故障隔离好、易扩展 | 带宽高、距离远、抗干扰 |
| **缺点** | 带宽低、BNC 易故障、维护麻烦 | 距离短（100m） | 成本高、施工要求高 |
| **适用** | 实验室、小型网络 | 办公/校园主流方案 | 主干、楼间、服务器互联 |

### 8.本任务的任务实施做什么？

1. 启动计算机，在搜索工具中以"**局域网组网方法**"为关键词进行搜索
2. 浏览搜索结果中关于**不同组网标准**的叙述
3. 搜索 **100BASE-T 连网的技术细节**
4. 思考**不同带宽的网络，如 10M/100M/1000M 的网络在互连时，需要注意的技术问题**是哪些

**第 4 题的思路**：速率不匹配会造成**瓶颈与丢包**（低速口成为瓶颈），需要考虑**端口自协商（10/100/1000 自适应）**、**全双工/半双工匹配**（否则易产生冲突与错帧）、**帧格式与 MTU 一致**、**交换机背板带宽与线速转发能力**、**级联带宽与上行链路聚合**。
