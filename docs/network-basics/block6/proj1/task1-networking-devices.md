## 知识点

### 1.本项目（局域网组网设备与组网方法）要学什么？

**学习要点**：

1. 掌握**网卡、集线器、交换机**的特点与使用方式
2. 掌握局域网**组网介质**的特点与连接方法，包括**同轴电缆、双绞线、光纤**
3. 了解**辅助设备**的功能，包括**调制解调器、电源**

**重点难点**：**集线器与交换机的功能区别**；**各种组网介质的特点**。

| 目标类别 | 内容 |
|----------|------|
| **知识目标** | ① 了解中继器、集线器的工作原理；② 理解网桥、交换机的工作原理及工作过程；③ 熟悉调制解调器、UPS 的应用场景及作用；④ 了解各种组网方法所使用介质的特点；⑤ 熟悉使用双绞线组网的方法及所用设备的功能；⑥ 熟悉使用光纤组网的方法及所用设备的功能 |
| **能力目标** | ① 掌握网卡的分类及 MAC 地址的组成；② 掌握交换机的工作过程；③ 掌握交换机上各个端口的使用方法；④ 了解集线器与交换机的不同；⑤ 掌握使用双绞线、光纤应使用的协议及设备；⑥ 了解使用同轴电缆组网的标准 |
| **素质目标** | ① 规范学生对各种局域网硬件设备的理解；② 通过设备使用讲解与实际操作，增强学生实践动手能力；③ 培养学生细致、全面的工作作风；④ 规范学生对于使用双绞线、光纤组网的认识；⑤ 通过实践参观学校局域网，增强学生对网卡、交换机等设备的理解与认识 |

**项目导读**：局域网是**普通用户日常使用**的网络类型，其**硬件设备**将各个节点连接在一起。目前局域网中使用的硬件设备主要包括**网卡、交换机**等。局域网是**应用最广泛、技术最成熟**的网络建设形式，与上一个模块中介绍的各个标准相对应，组网方法包括了使用**细缆、双绞线、光纤**等介质的多种类型。

### 2.局域网的组网设备包括哪些？

局域网的组网设备主要包括**网卡、集线器、交换机**等，一般为**物理层、数据链路层**的设备。这些设备在**功能、连接、设置**等方面各有特点。

| 设备 | 工作层次 |
|------|----------|
| **中继器、集线器** | **物理层** |
| **网卡、网桥、二层交换机** | **数据链路层** |
| **三层交换机** | **网络层** |

### 3.服务器与客户机分别是什么？

**服务器（Server）**：指在网络环境中为**客户机（Client）**提供各种网络服务的**专用计算机**，是基于**客户机/服务器（Client/Server）模式**的网络的重要组成部分。

- **要求**：具有较高的**运行可靠性**、较稳定的**服务提供性**、较宽泛的**可扩展性和可管理性**
- **常见类型**：**文件服务器、打印服务器、应用服务器、通信服务器**等
- **新趋势**：随着网络规模不断扩大，开始采用**服务器集群**等新技术

**客户机**：指客户使用的**连入网络的计算机**，也称为**工作站**。

- 客户机是**网络应用的前端**，网络用户通过它**接受网络提供的服务、访问网络的共享资源**
- 因此客户机应当具有**接受网络服务、访问网络资源和接受网络管理**的接口和能力
- 各种类型的计算机等终端设备**均可**作为网络客户机
- 客户机具有**自己单独的操作系统**，可以**独立运行、工作**，常用的是 **Windows 系列**操作系统

### 4.网卡有哪几种分类方式？

要组建网络，**选择合适的网卡非常重要**。随着计算机网络技术的发展和各种应用环境、应用层次的要求，出现了各种不同类型的网卡，**划分标准也呈现多样化**。

| 分类依据 | 类型 |
|----------|------|
| **按支持的网络类型** | **以太网卡、PCMCIA、ARCNet、ATM、FDDI 网卡**等 |
| **按支持的传输速率** | **10M 网卡、100M 以太网卡、10/100M 自适应网卡、1000Mb/s** 等 |
| **按支持的总线接口** | **ISA 网卡、PCI 网卡、PCMCIA 网卡、USB 网卡** |
| **按网络接口类型** | 以太网的 **RJ-45**、细同轴电缆的 **BNC**、粗同轴电缆的 **AUI**，以及 **FDDI 接口、ATM 接口、光纤的 SC/ST 接口** |
| **按支持的传输介质** | **双绞线网卡、粗缆网卡、细缆网卡、光纤网卡、无线网卡** |
| **按应用领域** | **工作站网卡、服务器网卡** |

**总线接口的细节**：

| 接口 | 特点 |
|------|------|
| **ISA 网卡** | 有 **8 位和 16 位**两种，适用于 PC 和 PC XT 的总线，**目前已逐渐被淘汰** |
| **PCI 网卡** | 有 **32 位和 64 位**两种，适用于 Intel 主导的总线规格，是**目前使用最普遍**的网卡 |
| **PCMCIA 网卡** | 多种规格，**专为笔记本电脑**方便接入网络而设计；现在笔记本已**集成有线和无线网卡**，无需再单独安装 |
| **USB 网卡** | 快速总线技术，**安装简单、支持热插拔**；一般**外置**，一端 **USB**、另一端 **RJ-45**；目前分 **100M 和 10/100M 自适应**两种 |

**服务器网卡的特殊性**：一般工作站网卡也可用到服务器上，但大型网络中服务器通常有**专门的网卡**，在**带宽、接口数量、稳定性、纠错**等方面有明显提高，有的还支持**冗余备份、热插拔**等服务器专用功能。

**多功能网卡**：有的网卡为适应多种环境，同时提供 **RJ-45、BNC 或 AUI** 等多种接口。

### 5.网卡的结构由哪些部分组成？

网卡主要由**主控编码芯片、调控元件、BOOTROM 插槽和指示灯**等部件组成。

**BOOTROM 插槽的作用**：可插入远程引导芯片，使**无盘工作站**从服务器引导启动。

### 6.网卡的 MAC 地址是怎么组成的？

为了标识网络中的每台主机，需要给每台主机上的网卡分配一个**全球唯一**的通信地址，该地址被称为网卡的**硬件地址**（也称为**物理地址**或 **MAC 地址**）。

| 项目 | 内容 |
|------|------|
| **固化位置** | 由网卡生产商**固化在其 ROM** 中 |
| **分配机制** | 每个网卡制造商向 **IEEE 委员会申请地址区间**，制造商只能为自己生产的网卡设置该区间内的地址，且**不能重复**，否则同一地址的网卡接入网络就会**发生冲突** |
| **长度** | **12 位十六进制数**，**48 比特**，共 **6 字节** |
| **组成** | **前 3 字节＝IEEE 分配给制造商的厂商代码**；**后 3 字节＝网络适配器编号** |
| **示例** | `00-30-21-0B-5E-43`：前 3 字节 `00-30-21` 是**生产厂商编号**（**可能出现重复**），后 3 字节 `0B-5E-43` 是**唯一的网卡编号** |
| **查看方法** | Windows 操作系统中可用测试程序 **ipconfig**（`ipconfig /all` 可看到物理地址）查看 |

**为什么前 3 字节可能重复、后 3 字节唯一**：厂商代码由 IEEE 统一分配、**厂商之间不会重复**；同一厂商的不同网卡靠**后 3 字节**区分，因此**整段 6 字节**才是全球唯一。

### 7.网卡的工作方式是什么？

在正常情况下，一个网络接口**只响应以下三种数据帧**：

1. **与自己硬件地址相匹配**的数据帧
2. **广播帧**
3. **组播帧**

在一个网络通信过程中，**数据的收发由网卡完成**。网卡接收到传输来的数据后，网卡内的程序根据接收数据帧的**目标 MAC 地址**以及网卡的**接收模式**，判断并确定**是否接收**。

### 8.网卡有哪四种接收模式？

| 模式 | 行为 |
|------|------|
| **广播方式** | 该模式下的网卡能够接收网络中的**广播信息** |
| **组播方式** | 设置在该模式下的网卡能够接收**组播数据** |
| **直接方式** | 只有数据中的**目标地址为本机的硬件地址**时，网卡才会接收该数据 |
| **混杂模式** | 网卡能够接收**一切通过其接口的数据**，而**不管该数据是不是传给它的** |

**混杂模式的用途**：在**网络安全调试**时，常将网卡设置为混杂模式，以**截获所有通过该网卡所在网段的数据包**，通过分析来判断是否有**入侵行为**发生。（网络嗅探/抓包工具就是这样工作的。）

### 9.中继器的作用与局限是什么？

由于线路中存在**各种损耗**，通过线路传输的信号功率会**逐渐衰减**，衰减到一定程度时将造成**信号失真**，因此会导致**接收错误**——**中继器**就是解决这一问题的设备。

**中继器（Repeater）** 是工作在**物理层**的连接设备，适用于**相同类型的两个网段**的互连。

| 项目 | 内容 |
|------|------|
| **端口数** | **两个端口** |
| **工作过程** | 从**端口 1** 得到信号 → 对信号进行**整形放大** → 将信号从**端口 2** 输出 |
| **信号方向** | **双向** |
| **本质** | 对线路信号进行**再生**的网络设备 |
| **主要作用** | **扩展局域网网段的长度、扩大网络的覆盖范围** |
| **介质** | 一般情况下两端连接**相同的媒体**，但有的中继器也可完成**不同媒体的转接** |

**为什么中继器不能无限使用**：理论上中继器的使用是**无限**的、网络可以无限延长，但事实上不可能——因为**网络协议对信号的延迟时间作了具体规定**，中继器只能在**规定的时间范围内**有效工作，否则**信号发送方会因超时而重发信号**，从而引起网络故障。

### 10.集线器（Hub）的原理、分类与不足

**集线器（Hub）** 也称**集中器**，工作在**物理层**，它是**中继器的一种改进**，作用与中继器类似，**区别仅在于集线器能够提供更多的端口连接**。

- **主要功能**：对从端口接收到的信号进行**再生整形、放大**，以**扩大网络的传输距离**，同时把**所有节点的连接集中在它的端口上**
- **以集线器为中心节点的网络优点**：① **连接简单、方便**；② 当网络中某条线路或某节点出现故障时，**不会影响其他节点的正常工作**
- **缺点**：由于**集线器不具备寻址功能**，所有传输到集线器的数据**均被广播到它的各个端口**，**容易形成广播风暴**

**集线器分类**：

| 分类 | 类型 |
|------|------|
| **按端口数量** | 主要有 **8 口、16 口、24 口**等几大类，少数品牌提供 **4 口、5 口、9 口、12 口、18 口**等非标准端口数 |
| **按带宽** | **10Mb/s、100Mb/s、10/100Mb/s 自适应**三种 |

**"带宽"的关键提醒**：这里的带宽是**整个集线器所能提供的总带宽**，**并非每个端口所能提供的带宽**。例如集线器带宽为 **10Mb/s、共有 16 个端口**，则**每个端口的带宽只有 10/16 Mb/s**——**这点与交换机有根本的区别**。

**集线器的三条不足**：

| 不足 | 表现 |
|------|------|
| **① 用户带宽共享，带宽受限** | 集线器是**共享式设备**，每个端口**没有独立带宽**，所有端口**共享总带宽**；所接用户越多，每户分到的带宽越少，不能满足多媒体、流媒体等对带宽有严格要求的应用 |
| **② 广播工作方式易造成网络风暴** | **网络风暴（广播风暴）** 指由于网络拓扑设计或硬件连接等问题，造成**广播帧在网段内被大量复制、传播**，致使网络性能急剧下降、甚至**堵塞、瘫痪**。集线器**不能识别硬件地址**，只是**向所有端口广播**：A 主机给 B 主机传数据时，集线器对所有节点同时转发，绝大多数流量是**无效**的；而且**每个节点都能侦听到**，**安全性**也降低 |
| **③ 非双工传输，通信效率低** | 同一时刻每个端口**只能进行一个方向**的数据通信（**半双工**），不能像交换机那样**双向全双工**传输 |

**结论**：集线器（Hub）**已经被交换机（Switch）所取代**。

### 11.网桥（Bridge）的作用与特征

**网桥（Bridge）** 是工作在 **OSI 模型数据链路层**的互联设备。数据链路层包括 **MAC 子层及 LLC 子层**，因此网桥也分为：

| 网桥类型 | 连接能力 |
|----------|----------|
| **MAC 子层网桥** | **只能连接相同类型**的局域网 |
| **LLC 子层网桥** | **可以连接不同类型**的局域网 |

**主要功能**：**隔离不同网段之间的数据通信量，提高网络传输性能**。

**工作过程**：网桥的**每个端口连接一个局域网网段**，**监听**与它连接的每个网段上传输的数据：

- 当数据帧的**目标地址和源地址在同一个网段**中时，网桥**丢弃**该数据帧
- 当**目标地址和源地址在两个不同的网段**时，网桥**将该帧转发**到与目标网段相连的**端口**上

**特点与局限**：

- 网桥工作在数据链路层，**不了解**经其转发的数据帧中**高层协议**的信息，因此可以**同时以同种方式处理 IP、IPX 等不同协议**，还具有对**无路由协议的网络进行分段**的功能
- 网桥只能使用 **MAC 地址和物理拓扑**进行工作，**配置、管理较为复杂**，一般适于**小型较简单**的网络

**网桥的 5 个基本特征**：

1. 在**数据链路层**上实现局域网段互连
2. 可连接两个采用**不同传输介质与不同传输速率**的网络
3. 以**接收、存储、地址过滤与转发**的方式实现互连网段之间的通信
4. 需要互连的网络在**数据链路层以上采用相同的协议**
5. 可以**分隔两个网段之间的通信量**，有利于改善互连网络的**性能与安全性**

**两种网桥**：**透明网桥**一般用于连接**以太网段**，**源路由网桥**一般用于连接**令牌环网段**。

### 12.LAN 交换机有哪些主要特性？

**交换机（Switch）** 是**集线器的升级换代产品**，外观上与集线器没有多大差别。由于集线器在**共享介质、单工传输和广播数据发送**等方面存在不足，很难满足用户在速度和性能上的要求，**交换机克服了集线器的不足**，因此在联网实践中得到广泛应用。

**注意术语**：通常所说的交换机是指工作在**数据链路层的二层设备**；目前也有工作在**网络层的交换机**，讨论时特别指出为"**三层交换机**"。本项目讨论的是**传统的二层交换机**，因其在局域网联网中广泛使用，所以也被称为"**LAN 交换机**"。

**主要特性**：

| 特性 | 说明 |
|------|------|
| **① 传输时间延迟小** | LAN 交换机的主要特点是**低交换传输延迟**：交换机为**几十微秒**，网桥为**几百微秒**，路由器为**几千微秒** |
| **② 传输带宽高** | **10Mb/s 端口**：半双工 **10Mb/s**，全双工可达 **20Mb/s**；**100Mb/s 端口**：半双工 **100Mb/s**，全双工 **200Mb/s** |
| **③ 允许 10/100Mbps 共存** | 典型交换机一部分端口支持 **10Base-T**、另一部分支持 **100Base-T**，可完成**不同端口带宽之间的转换**。采用 **10/100Mbps 自动侦测**技术时，端口自动测试所连网卡的**带宽（10 或 100）**与**双工方式（全/半）**并自动调整 |
| **④ 支持虚拟局域网服务** | **VLAN** 是把局域网划分成若干个子网的一种技术，**交换机是虚拟局域网的基础**，通过交换机对数据包的**过滤和转发**可有效**隔离广播风暴**。目前以太网交换机大多支持 VLAN |
| **⑤ 每端口独享总带宽** | 每个端口**独享**交换机的总带宽，在带宽上对每个端口有了**根本保障** |
| **⑥ 有高速端口** | 为实现交换机之间互联或与高档服务器连接，一般拥有一个或几个**高速端口**，如 **100M 以太网端口、FDDI 端口、155M ATM 端口** |
| **⑦ 可识别 MAC 地址** | 工作在数据链路层，能完成**封装、转发数据包、物理编址、网络拓扑结构、错误校验、帧序列以及流量控制**等功能，**每个端口都可连接一个独立的网段** |

### 13.交换机是如何工作的？（图 6-3）

交换机与集线器外形相似、都是多端口设备、都遵循 **IEEE 802.3** 及其扩展标准、介质访问控制方式**都是 CSMA/CD**，但**工作原理有根本不同**：

| 网络类型 | 中心设备 | 带宽 | 同时通信 |
|----------|----------|------|----------|
| **交换式网络** | **交换机** | 每端口**独享** | 所有端口**可同时**通信，全双工下**双倍**速率 |
| **共享式网络** | **集线器** | 所有端口**共享** | 同一时刻只能有**两个端口**（发与收）通信 |

**图 6-3 的结构**：交换机有 **6 个端口**，其中**端口 1、4、5、6** 分别连接**节点 A、B、C、D**；交换机内部包括**地址表、转发机构、缓冲器和各端口**。

| 端口 | 连接的节点 |
|------|-----------|
| 1 | 节点 A |
| 2 | （空） |
| 3 | （空） |
| 4 | 节点 B |
| 5 | 节点 C |
| 6 | 节点 D |

**并发交换的例子**：节点 A 要向节点 C 发送帧（`DA=节点C`），同时节点 D 要向节点 B 发送（`DA=节点B`）。交换机的**交换控制中心**根据"**端口号-MAC 地址映射表**"找出目标地址对应的输出端口号，于是**同时**建立 **端口 1 → 端口 5** 和 **端口 6 → 端口 4** 两条连接。这种连接可以按需要**同时建立多条**，即在多个端口之间建立多个"**并发连接**"——而这种连接是一种"**虚连接**"。

**背板与交换矩阵**：工业生产中将交换机的**主板称为"背板"**，交换机拥有一条**带宽很高的背部总线和内部交换矩阵**，所有端口都挂接在这条背部总线上。控制电路收到数据包后，处理端口**查找内存中的 MAC 地址对照表**，确定目标 MAC 的网卡连接在哪个端口，再通过**内部交换矩阵直接**将数据包传送到**目标节点**（而不是所有节点）；**只有目标 MAC 不存在时，才广播到所有端口**。

**这样做的两个好处**：① **明显提高效率**，不浪费网络资源；② **只对目标地址发送**，**不易造成网络堵塞**，且**数据传输较为安全**。

### 14.交换机的"自学习"与"老化"机制是怎样的？

**问题**：刚加电启动的交换机怎么知道网络中各节点的地址？"端口号-MAC 地址"表是怎样建立的？

**答案**：**初始的 MAC 地址表是空白的**，交换机能够**自动根据收到的以太帧中的源 MAC 地址**更新地址表中的内容。当一台计算机打开电源后，安装在该机上的网卡会**定期发出空闲包或信号**，交换机即可据此得知**它的存在及其 MAC 地址**——即所谓"**自动地址学习**"。

**规律**：交换机运行的**时间越长**，学到的 MAC 地址**越多**，未知的 MAC 地址**越少**，因而**广播的包越少**，**传输速度越快**。

**老化（忘却）机制**：由于交换机**内存容量有限**，能记忆的 MAC 地址数量也有限。为此交换机设定了一个**自动老化时间（忘却机制）**：若某 MAC 地址在一定时间间隔内（**默认为 300s**）**不再出现**，交换机将**自动把该地址从地址表中清除**；下次该地址重新出现时，将被**当作新地址**处理。因此，交换机**不会永久性记住**端口号-地址表中的信息。

**"学习 + 老化"合起来就是**：**来一个、记一个；久不来、就忘掉**——既保持表项新鲜，又不撑爆内存。

| **局域网交换机** | 最常见，用于**连接终端设备**（服务器、工作站、集线器、路由器、网络打印机等），提供**高速的独立通信通道** |

### 16.交换机有哪三种工作模式？

| 模式 | 工作方式 | 优点 | 缺点 |
|------|----------|------|------|
| **① 直接交换方式（直通）** | 只要接收并检测到**目标地址字段**，就**立即转发**，**不管该帧是否出错**，差错检测由**目标节点主机**完成 | **交换延迟短** | **缺乏差错检测能力**；**不支持不同输入/输出速率端口之间**的帧转发 |
| **② 存储转发交换方式** | **完整接收**发送帧，随后进行**差错检测**：正确则按目标地址确定输出端口再转发，**错误则丢弃** | **具有帧差错检测能力**；**支持不同输入/输出速率端口**之间的转发 | **交换延迟增加** |
| **③ 混合交换方式** | 结合前两种：接收到帧的**前 64 个字节**后，判断 Ethernet 帧的**帧头字段**是否正确，正确则转发 | 对**短帧**延迟接近直接交换；对**长帧**只对**地址字段与控制字段**做差错检测，延迟也会减少 | 需按帧长区分处理 |

### 17.交换机的端口有哪几类？

**按对带宽的占用形式**：

| 端口 | 含义 |
|------|------|
| **专用端口** | 该端口带宽被接入该端口的**某节点所专用（独占）** |
| **共享端口** | 该端口带宽被接入该端口的**多个节点共享**（如该端口接了一台 Hub） |

**按工作方式**：**半双工端口、全双工端口**。

**按结构**：

| 端口 | 说明 |
|------|------|
| **普通端口** | 占多数，有 **16 个、24 个、48 个**的。每个端口的 **8 个脚**中，用于通信的只有 **1、2、3、6** 这 4 个脚，其中 **1、2 脚接收信号，3、6 脚发送信号** |
| **级联端口（UP-Link）** | 每台交换机一般**一个**，**专用于交换机之间的级联**。级联时两台交换机距离较远，其 **1、2、3、6** 四个通信脚排列**正好与普通端口相反**，即 **1、2 脚发送、3、6 脚接收**。级联口具有**最大的传输速率**，用于连接**主干交换机** |
| **堆叠端口** | 用于**两个交换机近距离**连接，用**堆叠线**连接后，两台交换机就**相当于一台**交换机在工作 |

**注意**：交换机的**级联端口与某个普通端口**（往往是第 1 个或最后 1 个）是**同一组连线的两个端口**，这两个端口在联网时**只能使用一个**，在面板上可以看到有**虚线**将两个端口连接。

### 18.交换机的级联与堆叠有什么区别？

交换机主要有**两种连接形式——级联和堆叠**：

| 比较项 | 级联 | 堆叠 |
|--------|------|------|
| **连接方式** | 通过交换机的**某个端口**与其他交换机的**级联端口**相连 | 通过交换机的**堆叠接口**连接 |
| **距离** | 一般**较远** | **近距离** |
| **逻辑身份** | 每台交换机在逻辑上**仍是多个被网管的设备** | 多台交换机在逻辑上是**一个被网管的设备** |
| **共同点** | 都可以实现**交换端口数量的扩充** | 同左 |

**一句话**：**级联是"串起来"，堆叠是"并成一个"**。

### 19.交换机与集线器有哪四点区别？

| 区别 | 集线器（Hub） | 交换机（Switch） |
|------|---------------|------------------|
| **① 工作层次不同** | 工作在**第一层（物理层）** | 至少工作在**第二层**，也有工作在**第三层（网络层）**的 |
| **② 数据传输方式不同** | **广播方式** | **交换方式**，只有在自己的 MAC 地址表中**找不到目标地址**时才用广播 |
| **③ 带宽占用方式不同** | 所有端口**共享总带宽** | **每个端口独占**总带宽，故速度更快、时延更小 |
| **④ 传输方式不同** | 共享传输介质，只能**半双工**，一次只能接收**或**发送 | **全双工**，可**同时**接收和发送，系统吞吐量至少快一倍以上 |

### 20.调制解调器（Modem）的作用与三种调制方法

**调制解调器**是网络发展**早期**，计算机之间使用**电话线路**进行通信所**必备**的设备。它由**发送、接收、控制、接口、操纵面板及电源**等部分组成。

- **发送**：计算机以**二进制串行信号**形式提供数据，经接口转换为内部逻辑电平送入发送部分，经**调制电路**调制成线路要求的信号向线路发送
- **接收**：接收部分接收来自线路的信号，经**滤波、反调制、电平转换**后还原成**数字信号**送入计算机

一般电话线路的语音带宽在 **300~3400Hz** 范围内，用它传送数字信号，其信号频率也必须在该范围内。**常用的三种调制方法**：

| 方法 | 原理与实例 |
|------|-----------|
| **① 频移键控（FSK）** | 用**特殊的音频范围**来区别发送和接收数据。如调频 Modem **Bell-103**：发送时信号 **0 为 1070Hz、信号 1 为 1270Hz**；接收时信号 **0 为 2025Hz、信号 1 为 2225Hz** |
| **② 相移键控（PSK）** | 高速 Modem 常用**四相制或八相制**，四相制用 **4 个不同相位**表示 **00、01、10、11** 四个二进制数。如调相 Modem **Bell-212A**，可使 **300b/s 的 Modem 传送 600b/s** 的信息 |
| **③ 相位幅度调制（PAM）** | 把**相位调制和幅度调制相结合**，用 **16 个不同的相位和幅度电平**，使 **1200b/s 的 Modem 传送 19200b/s** 的数据信号，一般用于**高速同步通信** |

**接口**：Modem 通常通过 **RS-232 串行口**信号线与计算机连接；**RS-232 的电气特性属于非平衡传输方式**，**抗干扰能力较弱**，故**传输距离较短，约为 15m 左右**。

### 21.打印机与电源（UPS）怎样配置？

**打印机**：网络环境下配置打印机，应考虑打印机是**本地使用**还是**网络共享**：

1. **网络共享**：将与计算机连接的打印机设置为"**共享**"的**网络打印机**
2. **专用打印服务器**：专门配置一台**打印服务器**，并连接几台打印机
3. **网络专用打印机**：要实现**高速、大量打印**，可配置网络专用打印机，这种打印机**可以不与计算机相连**，而**直接连接到网络**

**电源（UPS）**：为使数据在**电源故障**的情况下**不至于丢失**，可以给重要的计算机、服务器配备**不间断电源系统（UPS）**：

| 设备 | 配置建议 |
|------|----------|
| **普通计算机** | **后备式 UPS** |
| **服务器** | **在线式 UPS（500~1000VA）** |
| **核心机房** | 还应配备**净化交流电源（1000~3000VA）** |

**收尾提醒**：对于组建局域网的各种基本设备，在实际的网络规划和设计中，还需根据**具体的网络方案和网络拓扑结构**做合理的选择，以求得**最优的性价比和网络性能**。
