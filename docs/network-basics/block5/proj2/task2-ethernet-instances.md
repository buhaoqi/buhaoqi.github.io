## 知识点

### 1.本任务讲什么？

本任务主要介绍**以太网的组网标准**，如使用**同轴电缆**的 **10BASE-5 和 10BASE-2**、使用**双绞线**的 **10BASE-T 和 100BASE-T** 等。

**学习顺序**：粗缆（10BASE-5）→ 细缆（10BASE-2）→ 双绞线（10BASE-T）→ 快速（100BASE-T）→ 千兆 → 万兆。这条线索其实就是**传输介质从粗到细、从共享到交换、从 10Mb/s 到 10Gb/s** 的演进史。

### 2.10BASE-5 网络（粗缆以太网）有什么特点？

10BASE-5 及 10BASE-2 网络是**较早**的 Ethernet 网络，其拓扑结构为**总线型**。10BASE-5 也称**粗缆以太网**，采用阻抗为 **50Ω 的粗同轴电缆**作为传输介质。

| 项目 | 具体规定 |
|------|----------|
| **介质** | **50Ω 粗同轴电缆** |
| **连接方式** | 每个网段上的客户机均通过**收发器（Transceiver）**与总线相连 |
| **接口标准** | 收发器与客户机网卡之间的接口标准为 **AUI**，AUI 是一种 **15 针**的插头插座 |
| **终端匹配** | 粗缆**两端应连接 50Ω 的终端匹配器**（也称终端器），**其中一端必须接地**（见图 5-4） |
| **网段最大长度** | **500m**；超过 500m 时需要使用**中继器**以延长网段 |
| **最多网段数** | **5 个**网段 |
| **最大联网距离** | **2500m**（5 × 500） |
| **收发器最小间距** | 每个客户机的收发器在总线上的最小距离为 **2.5m** |
| **每网段客户机数** | 最多可连接 **100 个**客户机 |

**注意"5-5-2.5"这组数字**：**500m 网段、5 个网段、2500m 总长、2.5m 间距**——数字都和"5"有关，很好记。

### 3.10BASE-2 网络（细缆以太网）有什么特点？

10BASE-2 也称**细缆以太网**，采用 **50Ω 的细同轴电缆**作为传输介质。

**最大区别**：10BASE-2 以太网**不需要收发器**，因为**收发器与网卡集成在了一起**。因此，10BASE-2 以太网连接时比 10BASE-5 **简单**，价格也要**低得多**。

| 项目 | 具体规定 |
|------|----------|
| **介质** | **50Ω 细同轴电缆** |
| **网段最大长度** | **185m** |
| **最多网段数** | **5 个** |
| **最大联网距离** | **925m**（5 × 185） |
| **每网段客户机数** | 最多 **30 个** |
| **T 型连接器最小间距** | **0.5m** |
| **终端匹配** | 细缆**两端必须连接 50Ω 的终端匹配器** |
| **连接要求** | **T 型连接器**与网卡上的 **BNC 接口必须直接相连**，**中间不得有任何电缆**；T 型连接器的另外两端连接细缆 |

**T 型连接器**也叫 **T 型头**，是一种**电缆与网卡之间的连接器件**。

**混合使用**：网络中的**粗同轴电缆与细同轴电缆可以混合使用**，在**实时性要求不高**和**站点不太多**的情况下可以采用**总线型网**。

### 4.10BASE-5 与 10BASE-2 对比

| 比较项 | 10BASE-5（粗缆） | 10BASE-2（细缆） |
|--------|------------------|------------------|
| **电缆** | 50Ω **粗**同轴 | 50Ω **细**同轴 |
| **收发器** | **需要**独立收发器 | **不需要**（集成在网卡上） |
| **接口** | **AUI**（15 针） | **BNC** + **T 型头** |
| **网段长度** | **500m** | **185m** |
| **最多网段** | 5 | 5 |
| **最大联网距离** | **2500m** | **925m** |
| **每网段站点数** | **100** | **30** |
| **最小间距** | 收发器间 **2.5m** | T 型头间 **0.5m** |
| **终端匹配器** | 两端 50Ω，一端接地 | 两端 50Ω |
| **成本与施工** | 高、硬、施工难 | **低、简单** |

**记忆**：**粗缆"长而少"（500m/100 台），细缆"短而密"（185m/30 台）**，但都只能挂 **5 个网段**。

### 5.10BASE-T 网络（双绞线以太网）有什么特点？

20 世纪 90 年代以太网技术发展的**一大突破**是使用**非屏蔽双绞线（UTP）**的 10BASE-T 标准。10BASE-T 中的 **T 表示双绞线（Twisted Pair wire）**，它采用**曼彻斯特编码**方式工作。10BASE-T 以太网的拓扑结构为**星型**。

图 5-5 是一个以**集线器**为星型拓扑**中央节点**的 10BASE-T 网络示例：所有的工作站都通过**双绞线**连接到**集线器（Hub）**上。

| 项目 | 具体规定 |
|------|----------|
| **介质** | **非屏蔽双绞线（UTP）** |
| **拓扑** | **星型**（中央节点为 **Hub**） |
| **编码** | **曼彻斯特编码** |
| **工作站与 Hub 间最大距离** | **100m** |
| **接口** | 双绞线两端使用 **RJ45** 接口；**一端接客户机，另一端必须接 Hub** |
| **组网硬件** | **网卡、集线器、交换机、双绞线**等 |

**网络扩展**：10BASE-T 网络扩展可以采用**多个 Hub** 来实现，Hub 之间的连接可以使用**双绞线、同轴电缆或粗缆线、单模/多模光纤**。这种使用**集线器**连接的方式会**降低网络性能**，所以一般都采用**交换机**进行网络扩展。

### 6.10BASE-T 相比 10BASE-5、10BASE-2 有哪些优点？

10BASE-T 以太网一经出现就得到了广泛的认可和应用，与 10BASE-5 和 10BASE-2 相比有如下特点：

| 优点 | 具体表现 |
|------|----------|
| **（1）安装简单、扩展方便** | 网络的建立**灵活、方便**，可以根据网络的大小，选择**不同规格的 Hub 或交换机**连接在一起，形成所需要的网络拓扑结构 |
| **（2）网络的可扩展性强** | 因为**扩充与减少工作站都不会影响或中断**整个网络的工作 |
| **（3）故障隔离作用好** | 集线器或交换机具有很好的**故障隔离**作用：当某个工作站与中央节点之间的连接出现故障时，**不会影响其他节点**的正常运行；当网络中某一个集线器或交换机出现故障时，**只会影响到与该集线器或交换机直接相连**的节点 |

### 7.为什么说 10BASE-T 的出现具有里程碑式的意义？

主要体现在**三点**：

1. **首次将星型拓扑引入了以太网中**
2. **突破了双绞线不能进行 10Mb/s 及以上速率传输的传统技术限制**
3. 在后期发展中，**引入了第 2 层交换机以取代第 1 层集线器作为星型拓扑的核心**，从而使以太网**从共享以太网时代进入了交换以太网时代**

### 8.不同速率的以太网为什么能互相兼容？

以上 3 种以太网在**物理层**存在较大的差异，但它们在**数据链路层都采用 CSMA/CD** 作为介质访问控制协议，并且在 **MAC 子层使用统一的 IEEE 802.3 帧格式**，所以 **10BASE-T 网络与 10BASE-2、10BASE-5 是相互兼容的**。

事实上，在以太网后来的发展中，以太网技术**仍然保留了这种标准的帧格式**，从而使得**所有的以太网系列技术之间能够相互兼容**。

**一句话**：**物理层可以千变万化，数据链路层"帧格式 + CSMA/CD"不变**——这就是以太网"向下兼容"的根本原因。

### 9.100BASE-T 快速以太网是怎么回事？

随着网络应用的不断深入和多媒体技术的发展，**10Mb/s 以太网已难以满足**网络用户的应用需求。IEEE 802.3 委员会在 **1995 年**制定了 **100Mb/s 的快速以太网规范（IEEE 802.3u）**。

- 快速以太网技术 **100BASE-T** 是从 **10BASE-T 标准以太网**发展而来的，可支持 **100Mb/s** 的数据传输速率
- 与 10BASE-T 一样可支持**共享式与交换式**两种使用环境，在**交换式以太网环境**中可以实现**全双工通信**
- **IEEE 802.3u 在 MAC 子层仍然采用 CSMA/CD** 作为介质访问控制方法，并且**保留了 IEEE 802.3 的帧格式**
- 但是，为了实现 100Mb/s 的传输速率，在**物理层**作了一些重要的改进。例如在编码上，采用了效率更高的 **4B/5B 编码**方式

**三种物理层规范**（UTP 为非屏蔽双绞线；STP 为屏蔽双绞线；S/MMF 为单模/多模光纤）：

| 规范 | 介质 | 网段长度 | 实际使用线缆 |
|------|------|----------|--------------|
| **100BASE-TX** | **5 类 UTP 或 STP** 双绞线 | **100m** | 线缆中的 **2 对** |
| **100BASE-T4** | **3~5 类 UTP** 双绞线 | **100m** | 线缆中的 **4 对** |
| **100BASE-FX** | **S/MMF 型光纤** | **400~2000m**；全双工时速率达 **200Mb/s** | **两条光纤**，一条发送、一条接收 |

### 10.快速以太网如何升级？最大优点是什么？

**升级方法**：快速以太网与 10BASE-T **布线兼容**。实现时**无需改变网络拓扑结构**，而且所有在 10BASE-T 上的**应用软件和网络软件功能都可保持不变**，用户只需**更换网卡**和**配置一台 100Mb/s 的集线器（或交换机）**，就可轻易地将 10BASE-T 升级为快速以太网 100BASE-T，获得 100Mb/s 的数据传输速率。

**最大优点**：结构**简单实用、成本低**并**易于普及**，主要用于**快速桌面系统**。

### 11.100BASE-T 与 10BASE-T 有哪些相同与不同？

**（1）相同之处**

1. 采用**相同的介质访问控制方式**，即 **CSMA/CD** 协议
2. 采用**相同的数据传输的帧格式**
3. **相同的组网方法**
4. 均具有**低成本、易扩展**性能

**（2）不同之处**

| 比较项 | 10BASE-T | 100BASE-T |
|--------|----------|-----------|
| **发送时间（每比特）** | **100ns** | **10ns**（降低 10 倍） |
| **工作频率** | **25MHz** | **125MHz**（100BASE-TX/FX） |
| **编码方式** | **曼彻斯特编码** | **4B/5B**（效率更高） |
| **介质无关接口** | **没有** | **有**（介质独立接口，把 MAC 子层与物理层隔开） |

**介质无关接口的意义**：快速以太网采用**介质独立接口**将 **MAC 子层与物理层分隔**开来，使得物理层在实现 100Mb/s 速率时**介质和信号编码的变化不会影响到 MAC 子层**，因此也被称为**介质无关接口**。

### 12.千兆以太网是怎么来的？

随着**多媒体技术、高性能分布计算和视频应用**的不断发展，用户对局域网的**带宽**提出了越来越高的要求；同时 100Mb/s 快速以太网在客观上也要求**主干网、服务器一级**的设备拥有更高的带宽。

在这种需求背景下，IEEE 802 委员会在 **1996 年 3 月**成立了 **IEEE 802.3z 工作组**，专门负责千兆以太网标准的制定，并于 **1998 年 6 月**正式公布关于千兆以太网的标准：

- **IEEE 802.3z**：支持**光纤**传输
- **IEEE 802.3ab**：支持**铜缆**传输

**基本特性**：

- 数据传输率为 **1000Mb/s（即 1Gb/s）**，因此也称**吉比特以太网**
- **基本保留了原有以太网的帧结构**，所以**向下和以太网、快速以太网完全兼容**，使得原有的 10Mb/s 以太网和 100Mb/s 以太网可以**直接连接**到千兆以太网

**物理层 4 个协议规范**：

| 规范 | 介质 | 传输距离 | 速率 | 编码 | 适用 |
|------|------|----------|------|------|------|
| **1000BASE-SX** | 直径 **62.5μm、50μm 的多模光纤** | **260m、525m** | 1Gb/s | **8B/10B** | 建筑物网络系统的**主干通路** |
| **1000BASE-LX** | **多模或单模光纤** | **超过 550m** | 1Gb/s | **8B/10B** | 建筑物主干、**校园及城域主干网** |
| **1000BASE-CX** | **150Ω 平衡屏蔽双绞线（STP）** | **25m** | **1.25Gb/s** | **8B/10B** | **网络设备互联**，如核心机房内连接服务器、办公环境连接客户机 |
| **1000BASE-T** | **4 对 5 类 UTP** | **100m** | **1Gb/s** | — | 结构化布线中**同一层建筑**的通信，可利用已铺设 UTP，也可作建筑物内主干 |

### 13.千兆以太网有哪些主要优点？

| 优点 | 说明 |
|------|------|
| **（1）简易性** | 保持了传统以太网的**技术原理、安装实施和管理维护**的简易性，这是千兆以太网成功的基础之一 |
| **（2）技术过渡的平滑性** | 保持了经典以太网的主要技术特征，采用 **CSMA/CD** 介质访问控制方法，采用**相同的帧格式及大小**，支持**全双工、半双工**工作方式，以确保平滑过渡 |
| **（3）网络可靠性** | 保持经典以太网的**安装和维护方法**，采用**中央集线器或交换机的星型结构**和结构化布线方法 |
| **（4）可管理性和可维护性** | 采用**简单网络管理协议（SNMP）**查找和排除工具 |
| **（5）支持新应用与新数据类型** | 具有支持新应用与新数据类型的高速传输能力 |

**应用位置**：目前千兆以太网主要被用于**主干网络**中，但随着用户需求的增长和设备价格的降低，千兆以太网也日益用于**桌面（即用户端）环境**中。

### 14.万兆以太网的发展情况如何？

在以太网技术中，**快速以太网确立了以太网技术在桌面系统的统治地位**，随后出现的千兆以太网更是加快了以太网的发展。从 **1999 年**开始，快速以太网开始向**万兆以太网技术 10Gb/s** 发展。

- 万兆以太网不仅**再度扩展了以太网的带宽和传输距离**，更重要的是使得以太网**从局域网领域向城域网、广域网领域渗透**
- 现代大型网络的带宽已经达到了 **100Gb/s**
- IEEE 802 委员会在 **1999 年年底**成立了 **IEEE 802.3ae 工作组**进行万兆以太网技术的研究，并于 **2002 年**正式发布 **IEEE 802.3ae 10GE 标准**
- 万兆以太网采用**全双工与光纤**技术，**兼容**以前各种版本的以太网、快速以太网及千兆以太网技术，便于现有网络升级到万兆以太网
- 目前因为**技术与价格**的原因，万兆以太网主要应用在**主干网络**中

### 15.以太网标准演进一览

| 代际 | 标准 | 速率 | 编码 | 典型介质 | 里程碑 |
|------|------|------|------|----------|--------|
| **标准以太网** | 802.3（10BASE-5/2/T/F） | **10Mb/s** | 曼彻斯特 | 粗/细同轴、UTP、光缆 | 统一 MAC 帧格式 |
| **快速以太网** | **802.3u**（100BASE-TX/T4/FX） | **100Mb/s** | **4B/5B** | 5 类 UTP/STP、光缆 | 引入**介质无关接口** |
| **千兆以太网** | **802.3z**（光纤）/ **802.3ab**（铜缆） | **1000Mb/s** | **8B/10B** | 多模/单模光纤、STP、5 类 UTP | 主干普及 |
| **万兆以太网** | **802.3ae** | **10Gb/s** | — | 光纤、全双工 | 由 LAN 向 **MAN/WAN** 渗透 |
