## 知识点

### 1.本项目（以太网）要学什么？

**项目导读**：IEEE 802.3 制定了以太网的技术标准。以太网是一种计算机局域网技术，它规定了包括**物理层的连线、信号类型和介质访问层协议**等内容，是目前**应用最普遍**的局域网技术。本项目学习以太网的**工作方式**及**不同介质组建以太网的标准**等内容。

| 目标类别 | 内容 |
|----------|------|
| **知识目标** | ① 了解 10BASE-2、10BASE-5、10BASE-T 以太网标准；② 理解以太网 **MAC 帧结构**；③ 熟悉 100BASE-T 和千兆、万兆标准 |
| **能力目标** | ① 掌握以太网 MAC 帧结构，解读帧**首部、尾部**数据的含义；② 了解各个以太网标准的含义；③ 了解不同的以太网标准是**如何兼容**的 |
| **素质目标** | ① 规范学生对于以太网及其标准的认识；② 通过对不同标准可以互联的介绍，增强学生对**协议转换、兼容重要性**的理解 |

### 2.以太网是什么？为什么叫"以太"？

**以太网（Ethernet）** 是一种产生**较早**且应用**相当广泛**的局域网，它以**无源的电缆作为总线**来传送数据帧，并以曾经在历史上表示**传播电磁波的介质——以太（Ether）**来命名。

**IEEE 802.3 标准简称以太网**：为了与高速以太网相区别，通常将 IEEE 802.3 标准简称为以太网，即使用**载波监听多路访问及冲突检测（CSMA/CD）**技术、并以 **10Mb/s** 的速率运行在**多种类型的电缆**上。

**发展脉络**：

| 阶段 | 内容 |
|------|------|
| **20 世纪 90 年代后** | **交换型以太网**得到发展，先后推出 **100 兆快速以太网、1000 兆千兆以太网、10000 兆万兆以太网** |
| **现状** | 因为以太网的**帧格式特别适合于传输 IP 数据包**，随着 Internet 快速发展，以太网被广泛使用，成为**事实上的局域网标准** |
| **特点** | **高度灵活、相对简单、易于实现**，成为当今最重要的一种局域网建网技术 |
| **拓展** | 在现代网络技术中，以太网技术开始融入 **WAN 和 MAN** 等大规模、长距离网络的建设领域；**无线以太网**为无线局域网提供**更快的数据传输速率、更远的覆盖距离以及更高的安全性** |

### 3.以太网 MAC 帧的结构是怎样的？

**MAC 帧**是在 **MAC 子层的实体间**交换的**协议数据单元（PDU）**，它经过适当编码后由 MAC 子层**通过接口交给物理层**，以**比特流**形式在介质上传输。

图 5-2 以太网 MAC 帧格式（共 6 个字段）：

| 字段 | 英文/缩写 | 长度 |
|------|-----------|------|
| **前导同步码** | P（Preamble） | **8 字节**（7 个同步字节 + 1 个帧起始定界符） |
| **目的地址** | DA（Destination Address） | **6 字节** |
| **源地址** | SA（Source Address） | **6 字节** |
| **数据类型** | Type | **2 字节** |
| **数据字节** | Data | **46~1500 字节** |
| **帧校验** | FCS | **4 字节** |

**帧总长推算**：最小帧 = 8 + 6 + 6 + 2 + **46** + 4 = **72 字节**；最大帧 = 8 + 6 + 6 + 2 + **1500** + 4 = **1526 字节**（不含前导码时，常说的"最小 64 字节 / 最大 1518 字节"是**从目的地址算起**的口径）。

### 4.MAC 帧各字段的功能是什么？

**（1）前导同步码（8 字节）**

- 由 **7 个同步字节**和 **1 个字节的帧起始定界符（SDF）**组成
- 每个同步字节的位模式是 **`10101010`**，用于实现收发双方的**时钟同步**
- 帧起始定界符的位模式是 **`10101011`**，紧跟在前导同步码后，用于**标识一帧的开始**
- 接收端能根据 **1、0 交替变化**的位模式迅速实现同步；当检测到**连续两个 1**，接收端的**物理层**便将后续的信息**传输给 MAC 子层**

**（2）源地址和目的地址（各 6 字节）**

表示发送和接收帧的工作站的地址，各占据 **6 个字节**。目的地址可以是**单地址**，也可以是**组地址**或**广播地址**：

| 目的地址类型 | 判定规则 | 含义 | 示例 |
|--------------|----------|------|------|
| **单地址（单播）** | 左边**第一位为 0** | 指定网络上**某个特定站点** | `00-0E-9B-1B-10-7E` |
| **组地址（组播）** | 左边第一位为 **1**，且**其余位不全为 1** | 指定网络上**特定的多个站点** | — |
| **广播地址** | **所有位全为 1** | 指定网络上**所有的站点** | `FF-FF-FF-FF-FF-FF` |

**（3）数据类型（2 字节）**

用于指示**接收数据的高层协议**。例如高层是 **IP 协议**，则为 **`0800`**。

**（4）数据字节**

这部分是数据帧的**有效载荷**。在经过**物理层和逻辑链路层的处理**之后，包含在帧中的数据将被传递给在**数据类型中指定的高层协议**。以太网帧中数据字节的长度**最小不低于 46 个字节**（最大 1500 字节）。

**（5）帧校验（4 字节）**

占用 **4 个字节**，采用 **CRC 码**，用于校验**帧传输中的差错**。

**为什么最小 46 字节**：为了让**最短帧**在共享介质上"占满"冲突检测窗口——帧太短，发送方在冲突信号返回之前就已经发完并释放介质，就检测不到冲突了。

### 5.IEEE 802.3 物理层规范的名称是怎么来的？

以太网标准在物理层可以使用**粗同轴电缆、细同轴电缆、非屏蔽双绞线、屏蔽双绞线、光缆**等多种传输介质。在 IEEE 802.3 标准中，为**不同的传输介质**制定了**不同的物理层规范**，对应着各种典型的以太网应用。

**命名由 3 部分组成**：分别代表局域网的**速度、信号方法和物理媒体类型**。

以 **10BASE-T** 为例：

| 部分 | 含义 |
|------|------|
| **10** | 信号的**传输速率为 10Mb/s** |
| **BASE** | 信道上传输的是**基带信号** |
| **T** | 英文 **Twisted-pair wire**（双绞线电缆）的缩写 |

**表 5-1 四种典型的 IEEE 802.3 10Mb/s 以太网的基本特点**：

| 特性 | 10BASE-5 | 10BASE-2 | 10BASE-T | 10BASE-F |
|------|----------|----------|----------|----------|
| **数据速率（Mb/s）** | 10 | 10 | 10 | 10 |
| **信号方式** | 基带 | 基带 | 基带 | 基带 |
| **最大网段长度（m）** | **500** | **185** | **100** | **2000** |
| **网络介质** | **50Ω 粗同轴电缆** | **50Ω 细同轴电缆** | **非屏蔽双绞线** | **光缆** |
| **拓扑结构** | **总线型** | **总线型** | **星型** | **点对点** |

**介质代号记忆**：**5 = 粗缆（500m）、2 = 细缆（185m 近似"2"百）、T = 双绞线、F = 光纤**。

### 6.CSMA/CD 是什么？工作过程如何？

**带冲突检测的载波监听/多路访问（Carrier Sense Multiple Access/Collision Detection，CSMA/CD）** 是一种**介质访问控制方法**，适用于**总线结构及星型结构**的局域网络，传输介质可以是**双绞线、同轴电缆或光纤**。

**工作过程可简单概括为 4 点**：**先听后发、边听边发、冲突停止、随机延迟后重发**。

**具体步骤**：

| 步骤 | 动作 |
|------|------|
| **（1）监听** | 当一个站点想要发送数据时，首先**检测（监听）网络**，查看是否有其他站点正在利用线路发送数据，即监听线路的**忙、闲状态**。有数据在传输则**忙**，没有数据在传输则**空闲** |
| **（2）等待** | 如果线路**忙**，则**等待**，直到线路空闲 |
| **（3）发送** | 如果线路**空闲**，该站点就**发送数据** |
| **（4）边发边听** | 在发送数据的同时，站点**继续监听**网络以确保没有发生冲突——即将**其发送信号的波形**与**从线路上接收（监听）到的信号波形**进行比较：**相同**则没有发生冲突，发完正常结束；**不相同**说明该站点发送数据时其他站点也在发送，即**发生了冲突** |
| **（5）冲突处理** | 若检测到冲突，冲突各方**立即停止发送**，并发出一串**固定格式的阻塞信号**以**强化冲突**，以方便网络中其他站点都能发现，然后过**一段时间（时长随机）**再**重发**。循环上述过程，**只有当线路空闲时，站点才可以发送数据** |

**流程图（图 5-3）的判定链**：`总线空闲？` —— 否 → 继续监听（回到判断）；是 → `发送数据` → `发生冲突？` —— 是 → `随机延迟一段时间` → 回到 `总线空闲？`；否 → `本次发送结束`。

**为什么监听空闲了还会冲突**：因为信号在介质上有**传播延时**，"我听到空闲"只是"**此刻我所在位置**空闲"，不代表别处没有人刚开始发送。

### 7.线路上为什么会发生数据冲突？

线路上发生数据冲突有**两种可能**：

1. **两个节点同时检测到线路空闲**，又**同时发送**数据
2. **第一个站点已经发送数据**，但由于**传输的延时**，第二个站点**没有检测到信号**，认为线路是空闲的，又向线路上发送数据

第一种是"**同时抢发**"，第二种是"**没听见别人已经开讲**"——本质都是**传播延时**造成的。

### 8.实现冲突检测有哪几种方法？

| 方法 | 判据 |
|------|------|
| **（1）通过硬件检查** | 以**信号叠加引起的接收信号电平摆动变大**是否**超过某一阈值**，来判断是否有冲突发生 |
| **（2）通过检查曼彻斯特编码信号** | 检查**每位中间有无过零点（零点是否偏移）**来判断是否发生冲突 |

**曼彻斯特编码的原理**：每位中间必有一次跳变（用作时钟），冲突叠加后**跳变位置错乱、过零点偏移**，因此可以据此判定冲突。

### 9.学习 CSMA/CD 要记住的结论

采用 CSMA/CD 的局域网，能够**有效地解决多个站点在共享传输介质访问时的信道争用问题**。CSMA/CD 是一种**很成熟**的技术，在网络技术中，**以太网、CSMA/CD 和 802.3 可以作为同义语使用**。
