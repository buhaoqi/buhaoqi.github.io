任务一 ARC网络

知识点​

1.本项目（环型网络）要学什么？​

项目导读：ARCNet 是 1977 年由 Datapoint 公司开发的一种局域网技术，它采用令牌总线（Token Bus）方案来管理网络中工作站和其他设备之间的共享线路。

令牌环网（Token Ring） 是一种局域网协议，由 IEEE 802.5 标准进行定义。网络中所有节点都连接到一个由介质组成的环上，每个节点只能同直接相邻的工作站传输数据，通过围绕环流动的"令牌帧"管理各个节点的传输权限。

本项目学习令牌总线和令牌环两种网络的工作方式等内容。

目标类别内容
知识目标① 了解 802.4 标准；② 理解令牌总线等概念；③ 熟悉令牌总线的工作过程；④ 了解环型拓扑结构下的介质访问控制方法；⑤ 理解令牌帧的结构
能力目标① 掌握令牌总线介质访问控制方法；② 了解 802.4 标准在 ARCNet 中的应用方式；③ 掌握使用令牌进行工作的过程；④ 了解特殊情况下令牌的修复、恢复方法
素质目标① 规范学生对于令牌总线网络的认识；② 通过对非以太网络的学习，增强学生对于异构网络的理解；③ 规范学生对于令牌环网络的理解与认识

2.802.3 与 802.4 的主要区别是什么？​

本任务学习的是 IEEE 802.4 标准——令牌总线标准。802.3 与 802.4 的主要区别是两者的物理层特性和介质访问控制方法不同：

标准本质
802.3一个传输基带信号的 CSMA/CD 系统
802.4一个传送令牌的总线系统

一句话：802.3 靠"抢"（争用），802.4 靠"传令牌"（有序）。

3.什么是 ARCNet？​

附加资源计算机网络（Attached Resource Computer Network，ARCNet） 是由美国 Data Point 公司使用 IEEE 802.4 标准开发的一种计算机网络，传输介质是同轴电缆或双绞线。

为什么曾经用得广：由于 ARCNet 连接方便、结构灵活且实时性较好，所以在对实时性要求较高的局域网中应用得较为广泛。

总结特点：联网距离远、结构灵活；在客户机数量较多时，网络整体工作效率仍保持在较高水平（不像共享式以太网那样站点越多、冲突越多、效率越低）。因此 ARCNet 非常适合于对实时性要求较高、联网计算机数量较多的环境。

4.IEEE 802.4 标准规定了什么？​

IEEE 802.4 标准用于通过总线传送令牌访问的方式，以及与之相关的物理层规范和介质访问技术。

共享介质的访问可以分成两个主要类型：

类型含义
广播型介质上的每个站点都可以收到传输的所有信号，通常以物理总线形式构成
顺序型站点按顺序依次获得访问权（如环型）

IEEE 标准只对广播型共享介质方式进行了规范，而 802.4 标准定义的就是一种广播型的总线结构。

802.4 标准规定的内容：

  1. 传输介质的电气和物理特性
  2. 采用电气信号的收发方式
  3. 传送帧的格式
  4. 站点收到数据帧的动作
  5. 介质访问控制子层与位于其上的逻辑链路控制子层之间的接口

5.令牌总线（Token Bus）是怎么工作的？​

Token Bus（令牌总线）网络采用了 IEEE 802.4 标准，是一种在总线型拓扑中利用"令牌（Token）"作为控制节点访问公共传输介质的介质访问控制方法。

三个要点：

要点说明
① 都能收到每个站点都可以收到在总线上传输的所有信号，这一点与 CSMA/CD 相同
② 必须有令牌任何一个站点只有在取得令牌后才能使用共享总线发送数据
③ 逻辑顺序虽然处理的是一个广播型 LAN，然而令牌访问方式在逻辑上却总是顺序的

正常运行时的表现：在正常的、稳定的状态操作期间，对介质的使用权从一个站点传送到另一个站点，物理上的连接与令牌的传送顺序无关——令牌传送范围、顺序由协议配置，称为逻辑环。

图 5-6 物理总线上的逻辑环：A、B、C、D、E、F、G 七个站点都挂在同一条物理总线上（物理拓扑是总线型），而协议配置的"逻辑环"用虚线把其中若干站点串成一个环。图中 A、D 两站虽然能收到总线上传输的数据帧，但由于它们不在逻辑环内、不会得到令牌，因而不能向其他站点发送数据。

这个例子说明："能收到"不等于"能发送"——收是广播的，发是按令牌顺序的。

6.广播型总线 + 逻辑环，好处在哪里？​

方面说明
物理上布线是总线，省线、易扩展、覆盖距离远
逻辑上用令牌把总线上的站点组织成一个逻辑环，访问确定、可预测
实时性每个站点两次获得令牌的最大间隔时间可以算出来（令牌循环时间确定），因此适合实时性要求高的场合
重载表现负荷重时吞吐率高、延迟低，不会像 CSMA/CD 那样因为冲突急剧恶化
代价需要实现复杂的环维护功能（令牌丢失、多令牌、站点入环/退环等）

7.本任务的任务实施做什么？​

  1. 启动计算机，在搜索工具中以"ARC 网络"为关键词进行搜索
  2. 浏览搜索结果中关于令牌总线的叙述
  3. 搜索在 ARC 网络中如果出现多个令牌或无令牌的情况时 ARC 的处理方法
  4. 从网络运行、维修角度分析 ARC 网络的优缺点
