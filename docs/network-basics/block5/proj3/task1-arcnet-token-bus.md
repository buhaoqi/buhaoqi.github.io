## 知识点

### 1.本项目（环型网络）要学什么？

**项目导读**：**ARCNet** 是 **1977 年**由 **Datapoint 公司**开发的一种局域网技术，它采用**令牌总线（Token Bus）**方案来管理网络中工作站和其他设备之间的**共享线路**。

**令牌环网（Token Ring）** 是一种局域网协议，由 **IEEE 802.5 标准**进行定义。网络中所有节点都连接到一个**由介质组成的环**上，每个节点**只能同直接相邻的工作站**传输数据，通过围绕环流动的"**令牌帧**"管理各个节点的**传输权限**。

本项目学习**令牌总线**和**令牌环**两种网络的工作方式等内容。

| 目标类别 | 内容 |
|----------|------|
| **知识目标** | ① 了解 **802.4 标准**；② 理解**令牌总线**等概念；③ 熟悉令牌总线的**工作过程**；④ 了解**环型拓扑结构下的介质访问控制方法**；⑤ 理解**令牌帧的结构** |
| **能力目标** | ① 掌握令牌总线**介质访问控制方法**；② 了解 802.4 标准在 **ARCNet** 中的应用方式；③ 掌握**使用令牌进行工作的过程**；④ 了解特殊情况下令牌的**修复、恢复方法** |
| **素质目标** | ① 规范学生对于令牌总线网络的认识；② 通过对**非以太网络**的学习，增强学生对于**异构网络**的理解；③ 规范学生对于令牌环网络的理解与认识 |

### 2.802.3 与 802.4 的主要区别是什么？

本任务学习的是 **IEEE 802.4 标准——令牌总线标准**。**802.3 与 802.4 的主要区别是两者的物理层特性和介质访问控制方法不同**：

| 标准 | 本质 |
|------|------|
| **802.3** | 一个传输**基带信号**的 **CSMA/CD 系统** |
| **802.4** | 一个**传送令牌**的**总线系统** |

一句话：**802.3 靠"抢"（争用），802.4 靠"传令牌"（有序）**。

### 3.什么是 ARCNet？

**附加资源计算机网络（Attached Resource Computer Network，ARCNet）** 是由美国 **Data Point 公司**使用 **IEEE 802.4 标准**开发的一种计算机网络，传输介质是**同轴电缆或双绞线**。

**为什么曾经用得广**：由于 ARCNet **连接方便、结构灵活且实时性较好**，所以在对**实时性要求较高**的局域网中应用得较为广泛。

**总结特点**：**联网距离远、结构灵活**；在**客户机数量较多**时，网络整体工作效率仍保持在**较高水平**（不像共享式以太网那样站点越多、冲突越多、效率越低）。因此 ARCNet 非常适合于对**实时性要求较高、联网计算机数量较多**的环境。

### 4.IEEE 802.4 标准规定了什么？

IEEE 802.4 标准用于**通过总线传送令牌访问**的方式，以及与之相关的**物理层规范**和**介质访问技术**。

**共享介质的访问可以分成两个主要类型**：

| 类型 | 含义 |
|------|------|
| **广播型** | 介质上的**每个站点都可以收到**传输的所有信号，通常以**物理总线**形式构成 |
| **顺序型** | 站点按顺序依次获得访问权（如环型） |

**IEEE 标准只对广播型共享介质方式进行了规范**，而 **802.4 标准定义的就是一种广播型的总线结构**。

**802.4 标准规定的内容**：

1. 传输介质的**电气和物理特性**
2. 采用**电气信号的收发方式**
3. **传送帧的格式**
4. 站点**收到数据帧的动作**
5. **介质访问控制子层**与位于其上的**逻辑链路控制子层**之间的**接口**

### 5.令牌总线（Token Bus）是怎么工作的？

**Token Bus（令牌总线）网络**采用了 **IEEE 802.4 标准**，是一种在**总线型拓扑**中利用"**令牌（Token）**"作为**控制节点访问公共传输介质**的**介质访问控制方法**。

**三个要点**：

| 要点 | 说明 |
|------|------|
| **① 都能收到** | 每个站点都可以收到在总线上传输的**所有信号**，**这一点与 CSMA/CD 相同** |
| **② 必须有令牌** | 任何一个站点**只有在取得令牌后**才能使用共享总线**发送数据** |
| **③ 逻辑顺序** | 虽然处理的是一个**广播型 LAN**，然而令牌访问方式在**逻辑上却总是顺序的** |

**正常运行时的表现**：在**正常的、稳定的状态操作期间**，对介质的使用权**从一个站点传送到另一个站点**，**物理上的连接与令牌的传送顺序无关**——**令牌传送范围、顺序由协议配置，称为逻辑环**。

**图 5-6 物理总线上的逻辑环**：A、B、C、D、E、F、G 七个站点都挂在**同一条物理总线**上（物理拓扑是总线型），而协议配置的"**逻辑环**"用虚线把其中若干站点串成一个环。图中 A、D 两站虽然**能收到**总线上传输的数据帧，但由于它们**不在逻辑环内、不会得到令牌**，因而**不能向其他站点发送数据**。

**这个例子说明**：**"能收到"不等于"能发送"**——收是广播的，发是按令牌顺序的。

### 6.广播型总线 + 逻辑环，好处在哪里？

| 方面 | 说明 |
|------|------|
| **物理上** | 布线是**总线**，省线、易扩展、覆盖距离远 |
| **逻辑上** | 用**令牌**把总线上的站点组织成一个**逻辑环**，访问**确定、可预测** |
| **实时性** | 每个站点两次获得令牌的**最大间隔时间可以算出来**（令牌循环时间确定），因此适合**实时性要求高**的场合 |
| **重载表现** | 负荷重时**吞吐率高、延迟低**，不会像 CSMA/CD 那样因为冲突急剧恶化 |
| **代价** | 需要实现复杂的**环维护**功能（令牌丢失、多令牌、站点入环/退环等） |
