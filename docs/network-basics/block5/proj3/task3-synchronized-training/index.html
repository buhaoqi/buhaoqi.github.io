（三）问答题参考答案​

1. 局域网常用的拓扑结构

总线型、星型、环型三种为主（此外还有树型）。

拓扑特点
总线型所有站点挂在一条共享总线上，两端接终端匹配器；结构简单、省线，但故障难隔离、冲突多
星型以集线器/交换机为中心，站点单独连线到中心；布线方便、故障隔离好，是现代局域网主流
环型站点经环接口连成闭合环，数据单向逐站传递；时延确定，但一环断开影响全网

局域网一般不采用网状型（成本高、布线复杂，用于广域网骨干）。

2. 决定局域网性能的主要因素

三个主要技术要素：网络拓扑结构、传输介质、介质访问控制方法。

  • 拓扑结构决定线路共享方式与可靠性
  • 传输介质决定速率上限、传输距离、抗干扰能力
  • 介质访问控制方法决定信道利用率、时延、重载下的吞吐率，对网络特性影响最大

（可补充：网络操作系统与联网设备的性能也会影响实际表现。）

3. 局域网的特点与近年新发展

特点：覆盖范围有限（单一组织内部）；数据传输速率高（10~1000Mb/s，甚至 10Gb/s）；传输控制简单（无中间节点、不需路由选择）；延时低、误码率低；支持多种传输介质；拓扑结构简单；可共享昂贵外设与软件、降低成本；易于安装组建维护、保密性好、便于扩展升级。

新发展：

  1. 速率持续提升：10Mb/s → 100Mb/s → 1000Mb/s → 10Gb/s，主干已达 100Gb/s
  2. 共享式 → 交换式：交换机取代集线器，实现独享带宽、全双工，冲突域被分割
  3. 虚拟局域网（VLAN） 广泛应用，用逻辑划分替代物理位置限制
  4. 无线局域网（802.11） 普及，移动接入成为常态
  5. 以太网技术向城域网、广域网渗透（万兆以太网进入 MAN/WAN）
  6. 以太网成为事实上的局域网标准，并向三网融合、工业互联网延伸

4. 局域网主要有哪些协议

层次协议
数据链路层IEEE 802.2（LLC）、802.3（CSMA/CD 以太网）、802.4（令牌总线）、802.5（令牌环）
物理层相关802.3 各物理层规范（10BASE-5/2/T/F、100BASE-TX/T4/FX、1000BASE-SX/LX/CX/T）、802.7 宽带、802.8 光纤（FDDI）
无线/其他802.11（无线局域网）、802.12（100VG-AnyLAN）、802.6（城域网）
高层TCP/IP、IPX/SPX、NetBEUI、AppleTalk

5. 常用的三种介质访问控制方法、特点与适用网络

方法特点适用网络
CSMA/CD先听后发、边听边发、冲突停止、随机延迟后重发；争用型，轻载效率高、重载冲突多总线型、星型以太网（802.3）
令牌环（Token Ring）持有令牌才能发送，单令牌、无冲突，时延确定，需环维护环型网络（802.5）
令牌总线（Token Bus）物理总线 + 逻辑环，按令牌顺序传递，时延确定总线型网络（802.4），如 ARCNet

共同点：都在共享介质上解决"谁能发、什么时候发"的问题；令牌方式的最大令牌间隔可计算，实时性优于 CSMA/CD。

6. CSMA/CD 的工作原理与过程

四句口诀：先听后发、边听边发、冲突停止、随机延迟后重发。

  1. 监听：站点要发送时先检测线路忙/闲
  2. 等待：线路忙则持续监听，直到空闲
  3. 发送：线路空闲立即发送
  4. 边发边听：把自己的发送波形与线上接收波形比较，相同则无冲突，发完正常结束
  5. 冲突处理：波形不同即判定冲突，立即停止发送，发出固定格式的阻塞信号强化冲突，然后随机延迟一段时间后重发，循环直到成功

7. 为什么 CSMA/CD 冲突难免，而令牌方式不会冲突

  • CSMA/CD：站点依据"我听到的是否空闲"自行决定发送。由于信号在介质上存在传播延时，"我处空闲"不代表"全网空闲"，两个站点可能同时判定空闲并同时发送（或后者尚未听到前者的信号），因此冲突在原理上无法消除，只能靠检测 + 退避来减少损失。
  • 令牌方式：发送权是授予的——环/逻辑环中只有一个令牌，只有持有令牌的站点才能发送，同一时刻至多一个站点在发送，因此不会发生冲突。代价是需要复杂的环维护（令牌丢失、多令牌、站点入环退环）。

8. 共享式局域网与交换式局域网的主要区别

比较项共享式交换式
核心设备集线器（Hub，物理层）交换机（数据链路层）
带宽所有端口共享总带宽每个端口独享带宽
工作方式半双工（共享介质）可全双工
冲突域全部端口同一个冲突域每端口一个冲突域
介质访问控制必须运行 CSMA/CD全双工时不需要 CSMA/CD
性能站点越多、冲突越多，效率下降站点增多仍能保持较高吞吐

9. 高速以太网与标准以太网的异同

相同点：① 相同的帧格式（802.3 MAC 帧）；② 半双工时相同的介质访问控制方法 CSMA/CD；③ 相同的组网方法（星型 + 结构化布线）；④ 均低成本、易扩展；⑤ 完全兼容互通。

不同点：

比较项标准以太网高速以太网
速率10Mb/s100Mb/s、1000Mb/s、10Gb/s
比特发送时间100ns10ns（100BASE-T）
工作频率25MHz125MHz（100BASE-TX/FX）
编码曼彻斯特编码4B/5B（100M）、8B/10B（1000M）
介质粗/细同轴、UTP、光缆5 类 UTP/STP、多模/单模光纤
介质无关接口无有（MII/GMII）
双工半双工为主支持全双工（交换式环境）

10. 冲突域与广播域的关系

  • 冲突域：物理层概念，指同一时刻只能有一个站点发送的区域；其内的数据帧会互相冲突。由集线器连接的所有端口属于同一冲突域；交换机每个端口是一个独立冲突域；路由器隔离冲突域。
  • 广播域：数据链路层概念，指一个广播帧能够到达的所有站点集合。**集线器、交换机（未划 VLAN）**都不隔离广播域；路由器（或 VLAN）隔离广播域。
  • 关系：一个广播域可以包含多个冲突域（交换机连接时），但一个冲突域不会跨两个广播域。即：广播域 ≥ 冲突域；用交换机可分割冲突域但不分割广播域，用路由器或 VLAN 才能分割广播域。

11. VLAN 是什么、基于什么实现、有什么优越性

  • 定义：VLAN（Virtual Local Area Network，虚拟局域网）是建立在物理网络基础上的一种逻辑网络，即不改变物理布线，而通过逻辑划分把若干站点组织成若干个"独立的局域网"。
  • 实现基础：支持 VLAN 的交换机（802.1Q 帧标记）。常见划分方式有基于端口、基于 MAC 地址、基于协议（网络层/IP 地址）三种，其中基于端口最常用。
  • 优越性：
    1. 隔离广播域，抑制广播风暴，提高带宽利用率
    2. 增强安全性：不同 VLAN 默认不能直接通信，需经三层设备
    3. 突破地理限制、灵活组网：按部门/功能划分，不受物理位置约束
    4. 简化网络管理：人员调动只需改配置，不必重新布线
    5. 提高网络性能与可扩展性，便于故障隔离

12. WLAN 是什么、802.11 的工作模式

  • 定义：WLAN（Wireless Local Area Network，无线局域网）是以无线介质（无线电波、红外等）代替双绞线/光缆，在有限范围内实现移动接入与资源共享的局域网，标准为 IEEE 802.11 系列。
  • 工作模式：
    1. 基础设施模式（Infrastructure）：以 **AP（接入点）**为中心，站点先关联 AP 再访问网络，可进一步接入有线网——有中心、最常用
    2. 自组网模式（Ad-Hoc）：站点之间对等直连，无 AP、无中心
  • MAC 层两种访问方式：DCF（分布式协调功能，基于 CSMA/CA，必选）与 PCF（点协调功能，由 AP 轮询，可选）。

13. WLAN 中采用什么访问控制技术可以完全避免冲突

采用 CSMA/CA（载波监听多路访问/冲突避免）。

  • 无线环境无法像有线那样边发边听检测冲突（自己发射的信号会淹没接收信号，且存在隐藏站问题），所以把"冲突检测"改为"冲突避免"：
    1. 发送前监听信道，空闲则等待一个 DIFS 再进入退避
    2. 退避计时到 0 才发送；接收方正确收到后回 ACK
    3. 可选 RTS/CTS 握手，预约信道，解决隐藏站问题
  • 另外，PCF 模式下由 AP 轮询授予发送权，也不会冲突（本质同令牌/轮询的"授予式访问"）。

14. 以太网交换机的特点与组 VLAN 的方法

主要特点：

  1. 工作在数据链路层，按 MAC 地址表转发，每端口独享带宽
  2. 支持全双工，全双工时不需要 CSMA/CD
  3. 每端口一个冲突域，可同时多对端口通信
  4. 支持 VLAN、端口聚合、生成树（STP） 等功能
  5. 转发时延小、吞吐量大，可堆叠/级联扩展

组成虚拟局域网的方法：在交换机上创建若干 VLAN，把不同端口划入不同 VLAN（如端口 1–8 划入 VLAN 10、9–16 划入 VLAN 20），同一 VLAN 内端口可二层互通、不同 VLAN 需经**三层设备（路由器/三层交换机）**转发；跨交换机时用 Trunk 链路 + 802.1Q 标签承载多个 VLAN。

15. 令牌环介质访问控制的控制过程

  1. 环上只有一个令牌，沿物理环单向、逐站传递，顺序与站点排列顺序相同
  2. 站点有数据要发时，必须等待空闲令牌到达
  3. 收到空闲令牌后，把令牌的忙/闲标志位由"闲"置为"忙"，随后发送数据帧
  4. 数据帧沿环逐站转发，各站检查目的地址：非目的站转发，目的站接收并在帧中标志"已被正确接收和复制"
  5. 数据帧绕环一周回到源站，源站回收该帧，确认传送结果
  6. 源站把令牌由"忙"改回"闲"，传给下一站，下一站获得发送机会
  7. 环上设监控站，通过令牌监控位完成环维护（令牌丢失、多令牌、环恢复等）

16. 令牌总线介质访问控制的控制过程

  1. 站点物理上连接在一条总线上（广播型介质），但协议为各站配置一个逻辑环，规定令牌传递的顺序与范围
  2. 逻辑环中只有一个令牌，按逻辑顺序依次传递
  3. 某站只有取得令牌才能向总线发送数据（未取得令牌的站点只能接收，不能发送）
  4. 数据以广播方式在总线上传输，所有站点都能收到，但只有目的站接收
  5. 发送结束后，该站把令牌传给逻辑环中的下一站
  6. 环的建立、站点入环/退环、令牌丢失与多令牌处理等由协议的环维护功能完成

17. CSMA/CD、令牌环、令牌总线三种技术的优缺点比较

方法优点缺点
CSMA/CD协议简单、实现容易、成本低；轻载时延小、效率高；站点增删方便、无需配置重载时冲突剧增，吞吐率下降、时延不可预测；无优先级保证；时延不确定，不适合硬实时
令牌环无冲突；时延确定（最大令牌间隔可算）；支持优先级；重载时吞吐率高、延迟低需复杂环维护（令牌丢失、多令牌、环恢复）；单点故障可能影响全网；设备与布线成本较高
令牌总线物理为总线、布线省；逻辑为环、无冲突、时延确定；重载性能好；适合实时、站点多的场合（如 ARCNet）同样需复杂环维护；令牌传递带来额外开销；轻载时延大于 CSMA/CD

选型结论：轻载、突发、成本敏感 → CSMA/CD（以太网）；重载、实时性要求高 → 令牌环/令牌总线。今天因交换式全双工以太网的普及，冲突基本被"消灭"，令牌类网络已退居特定领域。

18. 大型局域网为什么要分成多个网段

  1. 缩小冲突域：减少同一介质上争用的站点数，降低冲突概率、提高有效带宽
  2. 缩小广播域：抑制广播风暴，避免广播包占满带宽、消耗主机 CPU
  3. 提高性能与带宽利用率：分段后各段可并行通信，交换机/路由器实现段间转发
  4. 故障隔离：某一段故障或环路不影响其他网段，便于定位与恢复
  5. 安全与管理：按部门/功能分段（配合 VLAN），限制越权访问，简化管理与计费
  6. 扩展距离与规模：突破单段的最大长度与最大站点数限制（如 10BASE-5 的 500m/100 台）
  7. 便于策略控制：可在段间设置访问控制、QoS、流量管理
