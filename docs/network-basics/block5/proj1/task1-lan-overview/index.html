任务一 局域网概述

知识点​

1.本项目（局域网技术）要学什么？​

项目导读：局域网是在一个有限的地理范围内，将各个节点进行连接的一种网络，使其能够共享资源和交换信息。

维度内容
优点传输速度快、性能稳定、框架简易、技术成熟
技术核心在一个网络内部传递协议数据单元，即主要是物理层和数据链路层的设备
标准依据IEEE 802 委员会的各个子标准定义了不同要素下局域网的实现规范
组成硬件：组成局域网物理结构的传输介质、设备；软件：网络操作系统和协议软件
本模块学习局域网的模型及组成

学习要点（模块五整体）：

  1. 掌握以太网技术标准
  2. 掌握令牌环、令牌总线的工作原理与过程
  3. 掌握虚拟局域网的划分方法
  4. 了解无线局域网技术及标准

重点难点：IEEE 802 标准与以太网、令牌网络、虚拟局域网。

2.局域网是怎么发展起来的？​

局域网（Local Area Network，LAN）产生于 20 世纪 70 年代。由于微型计算机应用的迅速普及和性能的提高，用户对计算机的需求不仅仅局限于单机功能的强弱，而是可以与其他计算机进行快速的资源共享或信息交换，甚至希望共享一些昂贵的硬件或软件资源——计算机局域网就是在这样的客观需求下应运而生的。

年份重要事件关键点
1973Bob Metcalfe 和 David Boggs 发明了以太网起点
1979Bob Metcalfe 开始以太网标准化的研究工作从技术走向标准
1980DEC、Intel、Xerox 三家公司共同制定 10Mb/s 以太网的物理层和链路层标准即 Ethernet V1.0 以太网规范（DIX 联盟）
1983IEEE 802.3 委员会以 Ethernet 2.0 为基础，正式制定并颁布 IEEE 802.3 以太网标准被称为标准以太网（10BASE-5）
1983美国国家标准化委员会 ANSI X3T9.5 委员会提出光纤高速网标准 FDDI（光纤分布式数据接口）传输速率提高到 100Mb/s
1985在 IBM 公司令牌环网的基础上，IEEE 802 委员会制定了令牌环标准 IEEE 802.5令牌环标准化
1990为提高以太网传输速率，IEEE 802 委员会在 10Mb/s 以太网技术基础上开发并推出快速以太网技术10Mb/s → 100Mb/s
1995.6通过 100BASE-T 快速以太网标准 IEEE 802.3u，带宽比以太网提高 10 倍这一阶段是共享传输通道、共享带宽的共享式局域网技术
1995.11IEEE 802.3 委员会组建新的**"高速研究组"，进行千兆**速率以太网的研究千兆起步
1996.3IEEE 组建新的 802.3z 工作组，专门研究千兆以太网、制定相应标准千兆标准化
1999 至今千兆和万兆以太网、无线局域网等标准都已出台成为当前局域网研究的热点领域

现状小结：到目前为止，局域网仍是网络技术发展中的一个活跃领域，在运行速度、带宽等指标方面都有了更大进步，在网络软硬件资源的访问、服务、管理、安全和保密等方面都有了进一步提高。

记忆线索：1973 发明 → 1979 研究标准化 → 1980 三家公司 V1.0 → 1983 两个标准（802.3 与 FDDI）→ 1985 令牌环 802.5 → 1990 快速以太网 → 1995 100BASE-T / 802.3u → 1996 千兆 → 1999 至今 千兆万兆与无线。

3.局域网的定义是什么？​

局域网（LAN） 是将分散在有限地理范围内（如一栋大楼、一个部门）的多台计算机通过传输介质（如双绞线）连接起来的通信网络，通过功能完善的网络软件（如 Windows、Linux）实现计算机之间的相互通信和资源共享。

定义中的三个要件：

要件含义
有限地理范围一栋大楼、一个部门、一个校园
传输介质连接双绞线、光缆、无线介质等
网络软件支撑由网络操作系统（如 Windows、Linux）实现通信与资源共享

辨析：局域网不仅要有"硬"的连接（介质、设备），还必须有"软"的支撑（网络软件、协议）——缺一不成局域网。

4.局域网有哪些典型特点？​

序号特点原因/表现
①覆盖的地理范围有限用于企业、学校、机关等单一组织、有限范围内的计算机联网，实现该组织内部的资源共享
②数据传输速率较高传输距离较短，一般采用通信性能好的通信介质，传输可靠性高，速率可达 10~1000Mb/s，甚至 10Gb/s；目前 10Gb/s 以太网技术已经成熟并应用
③传输控制比较简单对于共享传输线路的局域网来说，网络没有中间节点，不需转发和路径选择
④较低的延时和误码率通信介质性能较好且通信距离较短，因此延时低、误码率大大降低
⑤可以支持多种传输介质如双绞线、光缆等
⑥拓扑结构简单主要采用总线型、星型和环型结构，便于网络的控制与管理，低层协议也比较简单
⑦共享资源、降低成本可以方便地共享昂贵的外部设备、软件和数据，一定程度上降低了成本
⑧易于安装、组建和维护保密性好、可靠性高，便于系统的扩展和升级，各个设备的位置可灵活调整和改变

内在逻辑：距离短（①）→ 可用好介质（⑤）→ 于是速率高（②）、延时小、误码率低（④）；共享线路、无中间节点（⑥）→ 于是传输控制简单（③）。抓住"距离短"这个根，其余特点都能推出来。

5.局域网的 3 个主要技术要素是什么？​

决定局域网特性的主要技术要素有 3 个：网络拓扑结构、传输介质、介质访问控制方法。

技术要素内容
① 网络拓扑结构一般采用总线型、星型、环型等共享线路的拓扑结构
② 传输介质因局域网通信距离较短，通信线路的成本在网络建设的总成本中所占比例不大，因此可以使用价格较高、速率较高的传输介质，由各个节点一起共享
③ 介质访问控制方法将传输介质的频带有效地分配给网络上各站点用户的方法；它是局域网中最重要的一项基本技术，用来解决局域网中多站点如何共享公用传输介质的问题

考点提示：三个要素中，介质访问控制方法最重要——它决定了"谁在什么时候可以发言"，是共享介质局域网的核心。

6.一种理想的介质访问控制方法要实现哪 3 个基本目标？​

  1. 协议要简单，能获得有效的信道利用率，且公平、合理地对待网上各站点的用户
  2. 要确定网络上每一个节点何时可以将本节点的信息发送到公共介质上去
  3. 要解决如何处置节点对共享介质的访问可能带来的冲突问题

用一句话概括：简单高效、定时有序、冲突可控。

7.常用的介质访问控制方法有哪 3 种？​

介质访问控制方法英文/缩写适配的拓扑结构
带冲突检测的载波监听/多路访问CSMA/CD总线型拓扑结构常用
令牌环访问控制方法Token Ring环型拓扑结构
令牌总线访问控制方法Token Bus总线型（逻辑环）

影响：在局域网技术中，上述 3 种介质访问控制方法在很大程度上决定了局域网传输数据的类型、网络的响应时间、吞吐量和利用率以及网络应用等各种网络特性，对网络特性有着十分重要的影响。

一句话对应：总线型 → CSMA/CD，环型 → 令牌环，总线型上的逻辑环 → 令牌总线。
