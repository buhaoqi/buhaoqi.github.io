任务二 局域网参考模型及IEEE 802标准

知识点​

1.局域网的参考模型与 OSI 有什么不同？​

从实现技术上看，局域网是一个通信网，只涉及相当于 OSI 模型中通信子网的功能。由于内部大多数采用共享信道的技术，所以局域网通常不单独设立网络层。局域网的高层功能由具体的局域网操作系统来实现。在局域网技术中，物理层负责物理链路的建立、维持和拆除；由于局域网采用的媒体有多种，对应的媒体访问控制方法也有多种。

2.局域网为什么可以不设网络层？​

局域网具有两个重要的特征：

  1. 它用带地址的帧来传送数据
  2. 不存在中间交换（即在任意两个节点之间只有唯一的一条链路），所以不需要路由选择

正因为"无中间交换、无路由选择"，故而在局域网模型中不单独设置网络层——这是与 OSI 参考模型的重要区别。

NSAP 的位置：

体系网络层服务访问点（NSAP）的位置
OSI 参考模型网络设备应连接到**网络层的服务访问点（NSAP）**上
局域网模型由于不设置网络层，因此将网络层的服务访问点设在 LLC 子层与高层协议的交界面上

考点提示：局域网"没有网络层"不等于"没有网络层的功能"，而是把网络层服务访问点下移到了 LLC 子层与高层的交界处。

3.IEEE 802 模型对应 OSI 的哪几层？​

IEEE 的 802 委员会针对局域网的特征并参照 OSI 参考模型，制定了有关局域网的参考模型（IEEE 802 模型）和相关标准（称为 IEEE 802 系列标准）。

IEEE 802 模型仅包含 OSI 参考模型的物理层和数据链路层。

为了使局域网的数据链路层不至于太复杂，将局域网的数据链路层划分为两个子层：

子层全称主要职责（本任务层面）
MAC 子层介质访问控制（Media Access Control）解决多站点共享介质的访问控制
LLC 子层逻辑链路控制（Logical Link Control）与高层协议交接，NSAP 即设在此交界处

对应于 OSI 参考模型，IEEE 参考模型中的高层协议（网络层以上）的制定仍以 OSI 参考模型作为依据。

层次对应关系：

OSI 参考模型IEEE 802 模型
应用层 / 表示层 / 会话层 / 传输层 / 网络层高层协议（仍以 OSI 为依据，不在 802 模型中定义）
数据链路层LLC 子层 + MAC 子层
物理层物理层

4.IEEE 802 委员会是什么？​

美国电气电子工程师学会（IEEE） 于 1980 年 2 月成立了局域网技术标准委员会，简称 IEEE 802 委员会，专门负责制定局域网的协议。

  • IEEE 802 委员会为局域网制定了一系列标准，统称为 IEEE 802 协议（标准）
  • 该标准已被**国际标准化组织（ISO）**采纳，作为局域网的国际标准系列，称为 ISO 802 标准
  • 在这些标准中，根据局域网（及城域网）的类型，规定了各自的拓扑结构、通信介质访问控制方法、帧的格式等内容

命名小知识：委员会成立于 1980 年 2 月，"80" + "2 月" = 802，这是 802 系列编号的由来。

5.IEEE 802 各子标准分别描述什么？​

标准号描述内容
IEEE 802.1描述局域网体系结构以及寻址方式、网络管理和网络互联协议
IEEE 802.2定义了逻辑链路控制（LLC）子层的功能与服务
IEEE 802.3描述带有冲突检测的载波监听/多路访问（CSMA/CD）的控制方法和物理层技术规范
IEEE 802.4描述**令牌总线网（Token Bus）**的介质访问控制方法和物理层技术规范
IEEE 802.5描述**令牌环网（Token Ring）**的介质访问控制方法和物理层技术规范
IEEE 802.6描述**城域网（MAN）**的介质访问控制方法和物理层技术规范
IEEE 802.7描述宽带网的介质访问控制方法和物理层技术规范
IEEE 802.8描述 FDDI 的介质访问控制方法和物理层技术规范
IEEE 802.9描述综合语音和数据局域网技术
IEEE 802.10描述局域网的网络安全标准
IEEE 802.11描述无线局域网的介质访问控制方法和物理层技术规范
IEEE 802.12描述 100VG-AnyLAN 的介质访问控制方法和物理层技术规范

高频记忆组：

  • 802.3 = CSMA/CD = 以太网
  • 802.4 = 令牌总线
  • 802.5 = 令牌环
  • 802.11 = 无线局域网
  • 802.2 = LLC（数据链路层的上半子层）
  • 802.6 = 城域网 MAN
  • 802.8 = FDDI

6.图 5-1 说明了 IEEE 802 标准之间的什么关系？​

图 5-1（IEEE 802 标准的内部关系）自下而上、由内到外的结构可以这样理解：

位置标准说明
跨层（纵向）802.10 可互操作的局域网安全安全是贯穿各层的问题，故纵向覆盖
数据链路层上方（横向长条）802.1 互联网涉及网络互联，横跨整个体系
数据链路层上部（横向长条）802.2 逻辑链路控制（LLC）LLC 是公共的上半子层，各局域网标准共用
数据链路层下部 + 物理层802.3 CSMA/CD 总线网、802.4 令牌总线网、802.5 令牌环网、802.6 城域网、802.9 语音数据综合局域网、802.11 无线局域网、802.12 交换式局域网每一列都包含各自的 MAC 子层 + 物理层，这正是"多种介质、多种访问控制方法"的体现
最底部（物理层之下）802.7 宽带技术、802.8 光纤技术面向传输介质的物理层技术规范（如 802.8 对应 FDDI）

两点结论：

  1. IEEE 802 标准实际上是一个由一系列协议组成的标准体系，随着局域网技术的发展，该体系还在不断增加新的标准和协议
  2. 802.1 呈"倒 L 形"，它的垂直部分涉及各层——因为该标准由许多子标准组成，不同的子标准与各层存在一定的协作关系。由此可以看到，网络互联并不固定在某一层，有时在高层互联，有时在低层互联

看图技巧：横条 = 公共的（LLC、互联、安全）；竖列 = 并列的局域网种类（每家都有自己的 MAC 与物理层）；底部 = 介质相关技术。

7.局域网的"简化"体现在哪里？​

简化点具体表现
层数简化只保留 OSI 的物理层、数据链路层两层，高层交由网络操作系统实现
去掉网络层无中间交换、无路由选择，只靠带地址的帧传送数据
数据链路层细分拆成 LLC + MAC，把"与高层无关的介质访问"和"与介质无关的逻辑链路控制"分开
标准按需分类802.3/802.4/802.5/802.11/802.12 各管一种介质与访问方法，互不干扰

一句话：局域网模型是"两层 + 两子层"的瘦身版 OSI，把复杂性交给了网卡（MAC）和网络操作系统（高层）。
