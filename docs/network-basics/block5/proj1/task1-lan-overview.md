## 知识点

### 1.本项目（局域网技术）要学什么？

**项目导读**：局域网是在一个**有限的地理范围**内，将各个节点进行连接的一种网络，使其能够**共享资源**和**交换信息**。

| 维度 | 内容 |
|------|------|
| **优点** | 传输速度快、性能稳定、框架简易、技术成熟 |
| **技术核心** | 在**一个网络内部**传递**协议数据单元**，即主要是**物理层和数据链路层**的设备 |
| **标准依据** | IEEE 802 委员会的各个子标准定义了不同要素下局域网的实现规范 |
| **组成** | **硬件**：组成局域网物理结构的传输介质、设备；**软件**：网络操作系统和协议软件 |
| **本模块学习** | 局域网的**模型**及**组成** |

**学习要点**（模块五整体）：

1. 掌握**以太网技术标准**
2. 掌握**令牌环、令牌总线**的工作原理与过程
3. 掌握**虚拟局域网**的划分方法
4. 了解**无线局域网**技术及标准

**重点难点**：IEEE 802 标准与以太网、令牌网络、虚拟局域网。

### 2.局域网是怎么发展起来的？

局域网（Local Area Network，LAN）产生于 **20 世纪 70 年代**。由于微型计算机应用的迅速普及和性能的提高，用户对计算机的需求不仅仅局限于单机功能的强弱，而是可以与其他计算机进行**快速的资源共享或信息交换**，甚至希望共享一些**昂贵的硬件或软件资源**——计算机局域网就是在这样的客观需求下应运而生的。

| 年份 | 重要事件 | 关键点 |
|------|----------|--------|
| **1973** | Bob Metcalfe 和 David Boggs **发明了以太网** | 起点 |
| **1979** | Bob Metcalfe 开始**以太网标准化**的研究工作 | 从技术走向标准 |
| **1980** | DEC、Intel、Xerox 三家公司共同制定 **10Mb/s 以太网的物理层和链路层标准** | 即 **Ethernet V1.0** 以太网规范（DIX 联盟） |
| **1983** | IEEE 802.3 委员会以 **Ethernet 2.0** 为基础，正式制定并颁布 **IEEE 802.3 以太网标准** | 被称为**标准以太网（10BASE-5）** |
| **1983** | 美国国家标准化委员会 **ANSI X3T9.5** 委员会提出光纤高速网标准 **FDDI**（光纤分布式数据接口） | 传输速率提高到 **100Mb/s** |
| **1985** | 在 **IBM 公司令牌环网**的基础上，IEEE 802 委员会制定了令牌环标准 **IEEE 802.5** | 令牌环标准化 |
| **1990** | 为提高以太网传输速率，IEEE 802 委员会在 10Mb/s 以太网技术基础上开发并推出**快速以太网**技术 | 10Mb/s → 100Mb/s |
| **1995.6** | 通过 **100BASE-T 快速以太网标准 IEEE 802.3u**，带宽比以太网**提高 10 倍** | 这一阶段是**共享传输通道、共享带宽**的**共享式局域网**技术 |
| **1995.11** | IEEE 802.3 委员会组建新的**"高速研究组"**，进行**千兆**速率以太网的研究 | 千兆起步 |
| **1996.3** | IEEE 组建新的 **802.3z 工作组**，专门研究**千兆以太网**、制定相应标准 | 千兆标准化 |
| **1999 至今** | **千兆和万兆以太网、无线局域网**等标准都已出台 | 成为当前局域网研究的热点领域 |

**现状小结**：到目前为止，局域网仍是网络技术发展中的一个**活跃领域**，在**运行速度、带宽**等指标方面都有了更大进步，在网络软硬件资源的**访问、服务、管理、安全和保密**等方面都有了进一步提高。

**记忆线索**：**1973 发明 → 1979 研究标准化 → 1980 三家公司 V1.0 → 1983 两个标准（802.3 与 FDDI）→ 1985 令牌环 802.5 → 1990 快速以太网 → 1995 100BASE-T / 802.3u → 1996 千兆 → 1999 至今 千兆万兆与无线**。

### 3.局域网的定义是什么？

**局域网（LAN）** 是将**分散在有限地理范围内**（如一栋大楼、一个部门）的**多台计算机**通过**传输介质**（如双绞线）连接起来的**通信网络**，通过**功能完善的网络软件**（如 Windows、Linux）实现计算机之间的**相互通信和资源共享**。

定义中的三个要件：

| 要件 | 含义 |
|------|------|
| **有限地理范围** | 一栋大楼、一个部门、一个校园 |
| **传输介质连接** | 双绞线、光缆、无线介质等 |
| **网络软件支撑** | 由网络操作系统（如 Windows、Linux）实现通信与资源共享 |

**辨析**：局域网不仅要有"**硬**"的连接（介质、设备），还必须有"**软**"的支撑（网络软件、协议）——缺一不成局域网。

### 4.局域网有哪些典型特点？

| 序号 | 特点 | 原因/表现 |
|------|------|-----------|
| **①** | **覆盖的地理范围有限** | 用于**企业、学校、机关等单一组织**、有限范围内的计算机联网，实现该组织**内部**的资源共享 |
| **②** | **数据传输速率较高** | 传输距离较短，一般采用通信性能好的通信介质，传输可靠性高，速率可达 **10~1000Mb/s**，甚至 **10Gb/s**；目前 **10Gb/s 以太网**技术已经成熟并应用 |
| **③** | **传输控制比较简单** | 对于**共享传输线路**的局域网来说，网络**没有中间节点**，**不需转发和路径选择** |
| **④** | **较低的延时和误码率** | 通信介质性能较好且通信距离较短，因此延时低、误码率大大降低 |
| **⑤** | **可以支持多种传输介质** | 如双绞线、光缆等 |
| **⑥** | **拓扑结构简单** | 主要采用**总线型、星型和环型**结构，便于网络的控制与管理，**低层协议也比较简单** |
| **⑦** | **共享资源、降低成本** | 可以方便地共享**昂贵的外部设备、软件和数据**，一定程度上降低了成本 |
| **⑧** | **易于安装、组建和维护** | 保密性好、可靠性高，便于系统的扩展和升级，各个设备的位置可灵活调整和改变 |

**内在逻辑**：**距离短**（①）→ 可用**好介质**（⑤）→ 于是**速率高**（②）、**延时小、误码率低**（④）；**共享线路、无中间节点**（⑥）→ 于是**传输控制简单**（③）。抓住"距离短"这个根，其余特点都能推出来。

### 5.局域网的 3 个主要技术要素是什么？

决定局域网特性的主要技术要素有 **3 个**：**网络拓扑结构、传输介质、介质访问控制方法**。

| 技术要素 | 内容 |
|----------|------|
| **① 网络拓扑结构** | 一般采用**总线型、星型、环型**等**共享线路**的拓扑结构 |
| **② 传输介质** | 因局域网**通信距离较短**，通信线路的成本在网络建设的总成本中所占比例不大，因此可以使用**价格较高、速率较高**的传输介质，由各个节点**一起共享** |
| **③ 介质访问控制方法** | 将**传输介质的频带有效地分配给网络上各站点用户**的方法；它是局域网中**最重要的一项基本技术**，用来解决局域网中**多站点如何共享公用传输介质**的问题 |

**考点提示**：三个要素中，**介质访问控制方法最重要**——它决定了"谁在什么时候可以发言"，是共享介质局域网的核心。

### 6.一种理想的介质访问控制方法要实现哪 3 个基本目标？

1. **协议要简单**，能获得有效的**信道利用率**，且**公平、合理**地对待网上各站点的用户
2. 要确定网络上**每一个节点何时**可以将本节点的信息发送到公共介质上去
3. 要解决**如何处置节点对共享介质的访问可能带来的冲突**问题

用一句话概括：**简单高效、定时有序、冲突可控**。

### 7.常用的介质访问控制方法有哪 3 种？

| 介质访问控制方法 | 英文/缩写 | 适配的拓扑结构 |
|------------------|-----------|----------------|
| **带冲突检测的载波监听/多路访问** | **CSMA/CD** | **总线型**拓扑结构常用 |
| **令牌环访问控制方法** | **Token Ring** | **环型**拓扑结构 |
| **令牌总线访问控制方法** | **Token Bus** | 总线型（逻辑环） |

**影响**：在局域网技术中，上述 3 种介质访问控制方法在很大程度上决定了局域网**传输数据的类型、网络的响应时间、吞吐量和利用率以及网络应用**等各种网络特性，对网络特性有着**十分重要**的影响。

**一句话对应**：**总线型 → CSMA/CD，环型 → 令牌环，总线型上的逻辑环 → 令牌总线**。
