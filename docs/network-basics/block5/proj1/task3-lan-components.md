## 知识点

### 1.局域网由哪些部件组成？

局域网的基本组成部件包括**服务器、客户机、网络适配器、传输介质、网络通信协议、网络操作系统及连接设备**等。这些部件（设备）按照**技术规范**连接在一起，**相互协同工作**，实现局域网的功能。

| 分类 | 组成 | 说明 |
|------|------|------|
| **硬件** | 服务器、客户机、网络适配器、传输介质、连接设备 | 组成局域网**物理结构**的传输介质、设备 |
| **软件** | 网络操作系统、网络通信协议 | 网络操作系统和协议软件 |

**搭建顺序**：先具备**前 4 种网络构件**（服务器、客户机、网卡、传输介质）→ 构成基本的**局域网硬件平台** → 再装上**网络操作系统（NOS）** → 局域网才能正常运行。

### 2.服务器（Server）是什么？

**定义**：把**安装了网络操作系统并提供共享资源**的计算机称为**服务器（Server）**。

| 维度 | 内容 |
|------|------|
| **硬件特征** | 一般比普通 PC 拥有**更强的处理能力、更多的内存和硬盘空间**；可以是**微机、小型机和大中型计算机** |
| **网络地位** | 在局域网中**发布和管理共享资源**，所以在**客户机/服务器（Client/Server）**网络中处于**重要地位** |
| **数量配置** | 根据服务分工的需要，可以配置**不同数量**的服务器；这些服务器可以提供**相同**的网络服务，也可以提供**不同**的网络服务 |
| **一机多服务** | 在**访问量不大、访问时间不集中**的网络中，一个服务器可以**同时提供多种服务**；当然在可能的情况下，**最好专机专用** |
| **常见类型** | **Web 服务器、FTP 服务器、打印服务器、代理服务器、通信服务器**以及**数据库和应用程序服务器**等 |

**考点提示**：判断一台计算机是不是服务器，关键看两条——**装了网络操作系统** + **提供共享资源**，而不是看它是不是"高档机器"。

### 3.客户机（Client）是什么？

在网络中，客户机一般又称为**工作站**，它是网络中**请求使用服务器上的资源或服务**的计算机。

| 维度 | 内容 |
|------|------|
| **硬件特征** | 通常**硬件配置低于**服务器的硬件配置 |
| **形态** | 可以是**网络主机**或者**终端**，也可以是**没有磁盘驱动器的无盘工作站** |
| **工作方式** | 用户通过客户机向服务器**请求服务和访问共享资源**，并通过网络从服务器中**获取所需的数据和应用程序** |
| **相互关系** | 客户机是**相对于服务器**的概念；客户机与服务器之间是**相互依存**的，而**客户机之间是相对独立**的 |

**一句话辨析**：**没有服务器，客户机无从取资源；没有客户机，服务器的资源无人使用**——二者相互依存；但客户机 A 与客户机 B 之间并不互相依赖。

### 4.服务器与客户机有什么区别？

| 比较项 | 服务器 | 客户机（工作站） |
|--------|--------|------------------|
| **角色** | **提供**共享资源与服务 | **请求**使用资源与服务 |
| **硬件配置** | 处理能力更强、内存与硬盘更大 | 通常**低于**服务器 |
| **软件** | 必须安装**网络操作系统** | 安装普通操作系统 + 网络客户端功能 |
| **在网络中的地位** | 处于**重要地位**（发布、管理共享资源） | 从属地位，**相互独立** |
| **典型形态** | 微机、小型机、大中型机 | 网络主机、终端、**无盘工作站** |
| **数量** | 可多可少（按服务分工配置） | 一般数量较多 |

### 5.网络适配器（网卡）有什么作用？

**网络适配器**又称为**网络接口卡**，简称**网卡**。

| 维度 | 内容 |
|------|------|
| **安装位置** | 一般安装在每台服务器或者客户机的**扩展插槽**中；现在大多数生产厂商已经将网卡**集成到主板上** |
| **地位** | 是网络通信的**主要部件**，也是网络通信的**主要瓶颈之一** |
| **影响** | 它的**品种和质量的好坏**直接影响**网络的性能**和**网络上软件运行的效果** |
| **结论** | **正确选用、连接和设置网卡**，往往是能否**正确连通网络**、**改善网络状态**的**前提和必要条件** |

**为什么说网卡是"瓶颈"**：网卡的速率、双工方式决定了单台主机进出网络的**上限**——链路带宽再高，网卡只有 100Mb/s，主机也就只能跑 100Mb/s。

**网卡与 802 模型的关系**（联系任务二）：网卡上实现的主要是 **MAC 子层**与**物理层**功能，因此**换网卡往往就换了介质访问控制方法**。

### 6.常用的传输介质有哪些？

**传输介质**是网络中**信息传输的媒体**，也是网络通信的**物质基础之一**。

- 传输介质的**性能特点**对**传输速率、通信距离、可连接的网络节点数目和数据传输的可靠性**等均有**很大的影响**
- 因此必须根据**不同的通信要求**，**合理**地选择传输介质

**局域网中常用的传输介质**：**双绞线、光导纤维、无线介质**等。

| 介质 | 特点（结合前序模块） |
|------|----------------------|
| **双绞线** | 成本低、布线方便，最常用（如 5 类/超 5 类 UTP） |
| **光导纤维** | 带宽高、抗干扰、传输距离远，用于主干 |
| **无线介质** | 无需布线、灵活，用于无线局域网（802.11） |

### 7.网络操作系统（NOS）与通信协议起什么作用？

具备了上述 **4 种网络构件**，便可搭建一个基本的**局域网硬件平台**。有了 LAN 硬件环境，还需要**控制和管理 LAN 正常运行**的软件，即**网络操作系统（NOS）**。

- 可以简单地认为：**NOS 是在每个计算机原有的操作系统上增加了网络应用所需要的功能**
- 一般来说，NOS 都已经在操作系统中**内置了网络通信协议**，如 **Windows 中就集成、内置了 TCP/IP 协议**

**NOS 的主要功能（归纳）**：**管理共享资源**（文件、打印机）、**管理用户与权限**（登录、访问控制）、**提供网络服务**（文件服务、打印服务）、**内置通信协议**、**网络管理与监控**。

**考点提示**：局域网 = **硬件平台**（4 构件）+ **软件平台**（NOS + 协议）。硬件决定"能不能连"，软件决定"能不能用、谁能用"。

### 8.局域网还有哪些网络互联设备？

用于局域网的**网络互联设备**主要包括**中继器、集线器、交换机、网桥**等，将在**模块六**进行详细介绍。

| 设备 | 工作层次（预告） | 作用 |
|------|------------------|------|
| **中继器** | 物理层 | 放大、再生信号，延长传输距离 |
| **集线器** | 物理层 | 多端口中继器，共享带宽 |
| **网桥** | 数据链路层 | 连接并隔离网段，按 MAC 地址转发 |
| **交换机** | 数据链路层 | 多端口网桥，独享带宽 |
