任务三 局域网的基本组成

知识点​

1.局域网由哪些部件组成？​

局域网的基本组成部件包括服务器、客户机、网络适配器、传输介质、网络通信协议、网络操作系统及连接设备等。这些部件（设备）按照技术规范连接在一起，相互协同工作，实现局域网的功能。

分类组成说明
硬件服务器、客户机、网络适配器、传输介质、连接设备组成局域网物理结构的传输介质、设备
软件网络操作系统、网络通信协议网络操作系统和协议软件

搭建顺序：先具备前 4 种网络构件（服务器、客户机、网卡、传输介质）→ 构成基本的局域网硬件平台 → 再装上网络操作系统（NOS） → 局域网才能正常运行。

2.服务器（Server）是什么？​

定义：把安装了网络操作系统并提供共享资源的计算机称为服务器（Server）。

维度内容
硬件特征一般比普通 PC 拥有更强的处理能力、更多的内存和硬盘空间；可以是微机、小型机和大中型计算机
网络地位在局域网中发布和管理共享资源，所以在客户机/服务器（Client/Server）网络中处于重要地位
数量配置根据服务分工的需要，可以配置不同数量的服务器；这些服务器可以提供相同的网络服务，也可以提供不同的网络服务
一机多服务在访问量不大、访问时间不集中的网络中，一个服务器可以同时提供多种服务；当然在可能的情况下，最好专机专用
常见类型Web 服务器、FTP 服务器、打印服务器、代理服务器、通信服务器以及数据库和应用程序服务器等

考点提示：判断一台计算机是不是服务器，关键看两条——装了网络操作系统 + 提供共享资源，而不是看它是不是"高档机器"。

3.客户机（Client）是什么？​

在网络中，客户机一般又称为工作站，它是网络中请求使用服务器上的资源或服务的计算机。

维度内容
硬件特征通常硬件配置低于服务器的硬件配置
形态可以是网络主机或者终端，也可以是没有磁盘驱动器的无盘工作站
工作方式用户通过客户机向服务器请求服务和访问共享资源，并通过网络从服务器中获取所需的数据和应用程序
相互关系客户机是相对于服务器的概念；客户机与服务器之间是相互依存的，而客户机之间是相对独立的

一句话辨析：没有服务器，客户机无从取资源；没有客户机，服务器的资源无人使用——二者相互依存；但客户机 A 与客户机 B 之间并不互相依赖。

4.服务器与客户机有什么区别？​

比较项服务器客户机（工作站）
角色提供共享资源与服务请求使用资源与服务
硬件配置处理能力更强、内存与硬盘更大通常低于服务器
软件必须安装网络操作系统安装普通操作系统 + 网络客户端功能
在网络中的地位处于重要地位（发布、管理共享资源）从属地位，相互独立
典型形态微机、小型机、大中型机网络主机、终端、无盘工作站
数量可多可少（按服务分工配置）一般数量较多

5.网络适配器（网卡）有什么作用？​

网络适配器又称为网络接口卡，简称网卡。

维度内容
安装位置一般安装在每台服务器或者客户机的扩展插槽中；现在大多数生产厂商已经将网卡集成到主板上
地位是网络通信的主要部件，也是网络通信的主要瓶颈之一
影响它的品种和质量的好坏直接影响网络的性能和网络上软件运行的效果
结论正确选用、连接和设置网卡，往往是能否正确连通网络、改善网络状态的前提和必要条件

为什么说网卡是"瓶颈"：网卡的速率、双工方式决定了单台主机进出网络的上限——链路带宽再高，网卡只有 100Mb/s，主机也就只能跑 100Mb/s。

网卡与 802 模型的关系（联系任务二）：网卡上实现的主要是 MAC 子层与物理层功能，因此换网卡往往就换了介质访问控制方法。

6.常用的传输介质有哪些？​

传输介质是网络中信息传输的媒体，也是网络通信的物质基础之一。

  • 传输介质的性能特点对传输速率、通信距离、可连接的网络节点数目和数据传输的可靠性等均有很大的影响
  • 因此必须根据不同的通信要求，合理地选择传输介质

局域网中常用的传输介质：双绞线、光导纤维、无线介质等。

介质特点（结合前序模块）
双绞线成本低、布线方便，最常用（如 5 类/超 5 类 UTP）
光导纤维带宽高、抗干扰、传输距离远，用于主干
无线介质无需布线、灵活，用于无线局域网（802.11）

7.网络操作系统（NOS）与通信协议起什么作用？​

具备了上述 4 种网络构件，便可搭建一个基本的局域网硬件平台。有了 LAN 硬件环境，还需要控制和管理 LAN 正常运行的软件，即网络操作系统（NOS）。

  • 可以简单地认为：NOS 是在每个计算机原有的操作系统上增加了网络应用所需要的功能
  • 一般来说，NOS 都已经在操作系统中内置了网络通信协议，如 Windows 中就集成、内置了 TCP/IP 协议

NOS 的主要功能（归纳）：管理共享资源（文件、打印机）、管理用户与权限（登录、访问控制）、提供网络服务（文件服务、打印服务）、内置通信协议、网络管理与监控。

考点提示：局域网 = 硬件平台（4 构件）+ 软件平台（NOS + 协议）。硬件决定"能不能连"，软件决定"能不能用、谁能用"。

8.局域网还有哪些网络互联设备？​

用于局域网的网络互联设备主要包括中继器、集线器、交换机、网桥等，将在模块六进行详细介绍。

设备工作层次（预告）作用
中继器物理层放大、再生信号，延长传输距离
集线器物理层多端口中继器，共享带宽
网桥数据链路层连接并隔离网段，按 MAC 地址转发
交换机数据链路层多端口网桥，独享带宽
