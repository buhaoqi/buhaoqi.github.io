任务二 认识IP协议-子网掩码15

知识点​

1.子网掩码是什么​

  • 本质：子网掩码是一个 32 位连续的二进制数字串。如：1111111111111111111111110000000
  • 表示形式1：为了阅读方便，子网掩码可以使用“点分十进制“的形式表示。如：255.255.255.0
  • 表示形式2：为了阅读方便，子网掩码可以使用“IP地址/掩码位数“的形式表示。如：192.168.20.80/24,表示IP地址的前24位是网络ID，
  • 作用：用来指定 IP 地址中哪一部分是网络位、哪一部分是主机位。如：255.255.255.0 说明前24位是网络位，后8位是主机位。
    • 1表示网络ID
    • 0表示主机ID

注意：

  • 掩码中的1必须高位连续，不能在1中间出现0（如239=11101111不能做掩码），必须前面全 1、后面全 0
  • 主机位不能全 0（子网网络地址）、不能全 1（子网广播地址）

2.默认的子网掩码是什么​

  • A 类地址默认的子网掩码：255.0.0.0
  • B 类地址默认的子网掩码：255.255.0.0
  • C 类地址默认的子网掩码：255.255.255.0

3.如何通过子网掩码求出网络ID和主机ID？​

  • 网络ID = IP地址 AND 子网掩码（按位与运算）；
  • 主机ID = 网络ID XOR IP地址（按位异或）。

4.例：求网络 ID、主机 ID​

  • 已知 IP：192.168.1.10，子网掩码：255.255.255.0
  • 求：网络 ID、主机 ID

第一步：分别把每一段转为8位二进制​

IP：11000000.10101000.00000001.00001010
子网掩码:11111111.11111111.11111111.00000000

第二步：按位与求网络ID​

IP        11000000  10101000  00000001  00001010
掩码      11111111  11111111  11111111  00000000
----------------------------------------------------------------
与运算结果11000000  10101000  00000001  00000000

网络ID：192.168.1.0

第三步：按位异XOR或求主机ID​

IP   11000000.10101000.00000001.00001010
掩码  11000000.10101000.00000001.00000000
----------------------------------------------------
     00000000.00000000.00000000.00001010

主机ID：0.0.0.10

  • 求：网络 ID、主机 ID

6.求192.168.20.80/24等价的子网掩码​

"/24"表示IP地址的前24位是网络ID

32 位掩码：前 24 位是 1，后 8 位是 0

11111111 . 11111111 . 11111111 . 00000000

等价的子网掩码为 255.255.255.0

7.求10.5.6.7/16等价的子网掩码​

32 位掩码：前 16 位是 1，后 16 位是 0

11111111. 11111111. 00000000. 00000000

等价的子网掩码为255.255.0.0

8.求子网ID、主机ID、地址范围和广播地址​

已知：IP地址150.100.12.178，子网掩码255.255.255.128（/25）

第一步转二进制

IP地址  10010110.01100100.00001100.10110010
子网掩码 11111111.11111111.11111111.10000000

第二步：按位与求网络ID

IP地址  10010110.01100100.00001100.10110010
子网掩码 11111111.11111111.11111111.10000000
  • 网络ID：10010110.01100100.00001100.10000000
  • 网络ID：150.100.12.128

第三步：按位异或求主机ID

IP地址  10010110.01100100.00001100.10110010
网络ID: 10010110.01100100.00001100.10000000
  • 主机ID：00000000.00000000.00000000.00110010
  • 主机ID：0.0.0.50

最终结果

  • 子网ID：150.100.12.128（25位网络位）
  • 主机ID：0.0.0.50
  • 可用主机范围：150.100.12.129 ~ 150.100.12.254
  • 广播地址：150.100.12.255

四、判断题

题号12345678910
答案√×√××√×√√×

判断题解析：

  • 第2题：C类主机ID为8位，去掉全0、全1两个保留地址，可用主机数为2⁸−2=254台，不是256台。
  • 第4题：私有B类地址范围是172.16.0.0~172.31.255.255，172.32已超出该范围，属于公网地址。
  • 第5题：回送地址的数据包不会被发送到网络接口，更不会被路由器转发，直接在本机内核中交付给目标进程。
  • 第7题：子网划分对外部路由器是透明的，Internet路由器仍认为这些子网都属于原来的大网络ID，无需重新配置。
  • 第10题：跨子网转发过程中，IP数据包头中的源IP和目的IP始终端到端不变；不断改变的是数据链路层帧首部中的源MAC和目的MAC地址。
