## 知识点

### 1. IPv6是什么
IPv6 全称**互联网协议第6版（Internet Protocol Version 6）**，是IP协议的下一代版本，用来解决IPv4地址枯竭的问题，工作在TCP/IP模型**网际层（网络层）**。

### 2. IPv6的特点
1. **地址空间巨大**：地址长度128位，地址数量极多，彻底解决IPv4地址不足。
2. **简化头部格式**：固定40字节基本首部，取消部分字段，路由器处理更快，转发效率更高。
3. **内置安全性**：原生支持IPSec加密认证，网络安全更好。
4. **支持即插即用**：可自动配置IP地址，不需要DHCP服务器也能获取地址。
5. **更好支持QoS**：标签流，方便流媒体等实时业务。
6. **支持组播、任意播**，不再只有单播、广播；IPv6**没有广播地址**。

### 3. IPv6的数据包格式
IPv6数据包 = **IPv6基本首部 + 扩展首部（可选，0个或多个） + 上层数据**
> 重点：IPv6基本首部固定40字节；扩展首部放在基本首部和传输层数据中间，按需选用。

### 4.IPv6的数据包头格式
IPv6**基本首部固定40字节**，字段：
1. 版本（4bit）：固定值6，代表IPv6
2. 通信类（流量类别）：QoS服务质量标记
3. 流标签（20bit）：标记同一业务流
4. 有效载荷长度：后面扩展首部+上层数据总长度
5. 下一个首部：标记后面是扩展首部还是TCP/UDP（类似IPv4协议字段）
6. 跳限制：等价IPv4的TTL，每经过一台路由器减1，到0丢弃
7. **源地址（128bit）**
8. **目的地址（128bit）**

> ✔考点：IPv6基本首部**没有首部校验和**，校验交给上层协议，提升路由器转发速度。

### 5. IPv6中的地址的表示方法

#### **冒号十六进制表示法**，

IPv6地址一共128位，划分为**8组，每组4位十六进制数**，组和组之间用冒号`:`隔开。

完整示例：`2001:0DB8:0000:0000:0008:0800:200C:417A`

把8组4位十六进制全部写出来，每组前面的0不能省略。
格式：`第1组:第2组:第3组:第4组:第5组:第6组:第7组:第8组`
示例：`2001:0DB8:0000:0000:0008:0800:200C:417A`


#### 前导零压缩法

**每一组十六进制内部最前面的0可以删掉**，每组内部末尾的0不能删。
上面例子使用前导零压缩：
`2001:DB8:0:0:8:800:200C:417A`
- `0DB8` → `DB8`（去掉前面的0）
- `0000` → `0`
- `0008` → `8`
- `0800` → `800`


#### 双冒号法 `::`）
在**整个IPv6地址里，如果有一段或多段连续全0组**，可以用一对`::`代替。
> ⚠️**核心必考限制：一个IPv6地址里面，双冒号`::`最多只能出现1次！**
接上例，连续两组0，使用双冒号压缩：
`2001:DB8::8:800:200C:417A`
2001:DB8:0:0:8:800:200C:417A

例子：
- `FF01:0:0:0:0:0:0:1` → `FF01::1`
错误写法（两个`::`）：`2001::0DB8::1` ❌

>原理：`::`代表一串连续的、全部为0的组；如果两处都写`::`，设备无法判断每处有多少个0组。

#### 内嵌IPv4表示法（IPv4映射IPv6地址）
当IPv6地址的最后32位存放IPv4地址时，可以**前6组写十六进制，最后两组改用点分十进制的IPv4格式**，方便阅读。
格式：**前6组十六进制 : IPv4地址**
示例：`::192.168.1.1`
等价完整IPv6：`0000:0000:0000:0000:0000:0000:192.168.1.1`

IPv6地址共128位，分为8组十六进制，4种表示方法：
1. **一般表示法**：完整写出8组4位十六进制；
2. **前导零压缩法**：每组内部开头的0可以省略；
3. **双冒号法**：连续全0的多个组，可用`::`代替，**一个地址仅能使用一次`::`**；
4. **内嵌IPv4表示法**：地址后32位使用点分十进制IPv4写法，用于IPv4/IPv6过渡场景。

### 6. IPv6的地址结构
总长度**128位**，分为两大部分：
**前缀（网络位） + 接口标识符（主机位）**
- 前缀：标识网络，相当于IPv4网络号
- 接口ID：标识子网内的网卡接口，相当于IPv4主机号

### 7. IPv6的地址分类
三大类（**IPv6无广播地址**，单选高频坑点）
1. **单播地址**：一对一通信
2. **组播地址**：一对多通信
3. **任意播地址**：一对最近通信

### 8. IPv6的单播地址是什么
**单播地址：一对一通信地址**。一个单播地址分配给**单个接口**，发给该地址的数据包，送达唯一对应的接口。

### 9. IPv6的单播地址的分类
1. **全球单播地址**：公网地址，可在互联网路由，相当于IPv4公网IP。前缀一般`2000::/3`开头。
2. **链路本地地址**：仅在当前链路（本网段）有效，不能跨路由器转发。前缀固定`FE80::/10`。
3. **唯一本地地址**：私有内网地址，不能在公网路由，相当于IPv4私有IP。前缀`FC00::/7`。

### 10. IPv6的组播地址是什么
**组播地址：一对多通信**。数据包发送给一组属于该组播组的所有接口。

### 11. IPv6的组播地址的特征
1. 前缀固定**FF开头**，以FF00::/8起始
2. 目标是一组接口，加入组播组的主机都接收报文
3. IPv6**没有广播**，广播功能全部用组播实现

### 12. IPv6的任意播地址是什么
**任意播地址：一对最近通信**。同一个地址分配给**多个设备接口**；发往任意播地址的数据包，路由到**距离源主机最近**的那个接口。

### 13. IPv6的任意播地址的特点
1. 多个接口共用同一个任意播地址
2. 报文转发到路由距离最近的节点
3. 一般用于服务器集群（DNS服务器）
4. **不能分配给主机作为源地址**，只能做目的地址

### 14. IPv4到IPv6的地址迁移（过渡技术）方案是什么
三种主流过渡方案（简答）
1. **双协议栈**：主机/路由器同时运行IPv4和IPv6两套协议栈，能处理两种IP数据包，是基础方案。
2. **隧道技术**：把IPv6数据包封装在IPv4数据包里面，通过现有IPv4网络传输IPv6流量（6to4隧道）。
3. **网络地址转换NAT-PT**：实现IPv4和IPv6地址、协议互相转换，让IPv4主机和IPv6主机直接通信。
