## 知识点
### 1.子网编址是什么

子网编址就是通过借用主机位，划分出多个子网。

### 2.如何进行子网编址？

- ① 求主机位：判断IP类别，确定原始网络位、原始主机位
    `A/B/C`类，写出默认网络位；原始主机位 = 32 − 默认网络位。
- ② 求子网位：计算需要借用的子网位n
    公式：`2^n` 所需子网数量，求出最小n（从主机位高位连续借位）。
- ③ 求总网位和剩余主机位：计算新总网络位、剩余主机位m
    新总网络位 = 原有网络位 + n；m=32-新总网络位。
- ④ 求出子网掩码
    32位二进制：前【新总网络位】写1，剩·余m位写0，转为点分十进制，也可用CIDR前缀`/x`表示。
- ⑤计算块大小（子网增量）
    块大小 = 256-掩码最后非255段的值。
- ⑥列出全部子网ID
    从主网起始地址开始，每次增加一个块大小，得到每个子网的子网ID。
- ⑦求每个子网的广播地址
    广播地址 = 本子网子网ID + 块大小 − 1（主机位全部置1）。
- ⑧求可用IP范围与可用主机数
    - 可用IP：子网ID+1 ～ 广播地址−1
    - 可用主机数量：`2^m-2`（减去子网ID、广播地址）

### 配套：已知IP+掩码，求该子网信息（计算题，另一种题型）
1. 将IP、子网掩码转为32位二进制。
2. IP 按位与子网掩码，得到子网ID。
3. 主机ID = IP XOR 子网ID。
4. 计算块大小，求广播地址。
5. 写出可用IP范围，计算可用主机数量。

### 简答默写短句（直接写试卷）
①确定主网原始网络位；②计算借位位数；③确定新子网掩码；④计算块大小，得到各个子网ID；⑤计算广播地址、可用IP范围与可用主机数。

### 2.为什么要划分子网？ 

两级IP结构变为三级IP结构,便于管理和提高地址利用率。

- 原始两级IP结构（网络ID+主机ID）在大型网络中难以管理（如一个B类网可容纳6万多台主机）。
- 子网编址从主机ID部分借用若干位作为子网号，形成三级结构：网络ID + 子网ID + 主机ID，把一个大网络划分成多个更小的子网，便于管理和提高地址利用率。

### 10.划分子网后，外部路由器能否识别内部子网划分？ 

不能。子网划分对外透明。

不能。Internet上的路由器仍认为这些子网都属于原来的大网络ID（如157.60.0.0/16），子网划分对外透明，不需要重新配置Internet中的路由器，只需配置本地路由器。

11. 子网编址的步骤是什么？

根据组织内部网络环境，规划需要的子网数n和每个子网容纳的主机数m；
选取最小的b使 n ≤ 2ᵇ，从主机号高位开始借b位作为子网ID；
子网ID编号从0…00到1…11（共b位）；
每个子网的主机ID从0…01到1…10（共 32−网络ID位数−子网ID位数 位）；
注意：主机ID全0和全1必须排除。

12. 例：对157.60.0.0/16借8位划分子网，可划分多少个子网？每个子网多少台主机？

借8位作子网号 → 2⁸ = 256个子网；
剩余8位主机号 → 2⁸−2 = 254台主机/子网；
例如：157.60.1.0/24、157.60.2.0/24、157.60.3.0/24……

13. 什么是ICMP？它的作用是什么？ 

ICMP（网际控制报文协议）是IP协议的一部分，由IP数据包承载。主要用于报告数据包无法到达目标以及对传输错误的解释信息（如"目标网络不可达"）。

14. ICMP差错报告报文的基本格式包含哪些字段？

类型（0~12）：识别消息类型；
代码：对特定类型的进一步描述；
检验和：检验ICMP数据包中的位错误；
未使用字段；
原始IP数据包：引起该ICMP报文生成的那个原始IP数据包首部+前8字节。

15. ICMP类型3（目标不可达）的常见代码有哪些含义？

0：网络不可达
1：主机不可达
2：协议不可达
3：端口不可达
4：需要分段但已设置DF（不分段位）
5：源路由失败

16. ping命令利用了ICMP的什么报文？ 

ping向目标主机发送ICMP类型8、代码0的"回复请求"（回显请求）报文；目标主机收到后回送ICMP类型0、代码0的"回复应答"（回显应答）报文，以此测试网络连通性。

17. ICMP能否使IP成为可靠协议？为什么？ 

不能。ICMP只是尝试报告错误并在特定情况下提供反馈，且ICMP消息本身也是靠IP数据包传输的（本身也可能丢失），因此IP仍然是不可靠的。

18. 为什么需要ARP协议？ 

IP数据包最终要通过具体物理网络的链路发送，而物理网络（如以太网）只能识别自己的48位MAC地址。源主机必须知道目标主机的MAC地址才能封装成帧投递。ARP（地址解析协议）就是用来根据已知IP地址查找对应的MAC地址的。

19. 简述ARP的工作过程（以A=192.168.0.1要给B=192.168.0.2发数据为例）。
A不知道B的MAC地址，先广播一个ARP请求报文，询问"192.168.0.2的MAC地址是什么？"；

同一以太网中所有主机都收到此广播，但只有B发现目标IP与自己相同，才做出响应；
B单播回复一个ARP响应报文，携带自己的IP地址和MAC地址给A；
A把B的IP↔MAC映射存入本机ARP缓冲区（ARP缓存），以后直接查表使用，不必每次都发ARP请求。

20. 什么是ARP缓冲区（ARP缓存）？为什么需要它？ 

每台计算机的ARP自动维护一张IP地址与物理地址的转换表（映射表）。有了缓存，A以后再给B发数据时直接从缓存取MAC地址，避免每次都广播ARP请求，减少网络流量。表项如果一段时间未被使用会被自动删除（超时老化）。

21. RARP协议的作用是什么？

 RARP（反向地址解析协议）完成与ARP相反的转换：已知MAC地址，查找对应的IP地址，常用于无盘工作站启动时获取自己的IP地址。

22. 同一子网内，客户机向服务器发送IP数据包的过程是怎样的？

查本机路由表，发现存在与服务器IP完全匹配的表项（说明在同一子网）；
通过ARP获得服务器的MAC地址；
IP包头附上源IP和目的IP，交给网卡；
网卡生成以太网帧，广播到局域网；
服务器网卡捕获帧，检查协议类型字段为IP后上传给IP协议；
IP协议识别目的IP是本机后，根据"协议"字段把数据部分交给上层协议（TCP/UDP）。

23. 不同子网时，客户机向服务器发送IP数据包的过程是怎样的？

查路由表，找到与服务器IP网络部分相匹配的表项（如219.220.243.0/24）；
若找不到具体表项，则使用默认网关表项；
通过ARP获得网关（路由器）的MAC地址（而非服务器的MAC地址）；
帧封装好后发给默认网关；
网关网卡收到帧后上传IP协议，发现目的IP不是本机，按路由表将IP数据包转发出去；
数据包经过多个路由器逐跳转发，最终到达服务器所在子网，再交付给服务器。

24. 同一子网与跨子网发送时，帧首部中的MAC地址和IP首部中的IP地址分别是谁？

同一子网：帧首部目的MAC = 服务器MAC；IP首部目的IP = 服务器IP。
跨子网：帧首部目的MAC = 默认网关的MAC；但IP首部目的IP = 服务器的IP（IP地址端到端不变，MAC地址每跳都变）。

子网编址（子网划分）标准解题步骤
> 分两大类题型：
> 题型1：已知【主网络+需要划分的子网数量】，求子网掩码、块大小、各个子网网段（规划类大题）
> 题型2：已知【IP+子网掩码】，求本子网的子网ID、主机ID、广播地址、可用IP范围（咱们一直在练的计算题）

## 题型1：给定主网，划分指定数量子网（规划子网）
例题：B类网络 `150.100.0.0/16`，要求划分500个子网
步骤1：确定主网默认网络位
B类默认网络位=16位，原始主机位 = 32−16 =16位

步骤2：计算需要借多少位子网位n
公式：2^n  需要的子网数量
本题：2^9=512 500，所以 n=9，向主机位借9位作为子网位

步骤3：计算新总网络位
新总网络位 = 原有网络位 + n
`(16+9=25) → 写成CIDR `/25

步骤4：求剩余主机位m
m=32-新总网络位 = 32-25(=7)

步骤5：求子网掩码
32位，前25位写1，后7位写0
二进制：`11111111.11111111.11111111.10000000`
转十进制：`255.255.255.128`

步骤6：计算块大小（子网增量）
块大小 = 2^m  或者 块大小 = 256-掩码最后一段
256-128=128，每128个IP为一个子网

步骤7：写出所有子网网段
150.100.0.0/25
150.100.0.128/25
150.100.1.0/25
150.100.1.128/25
……以此类推

步骤8：求每个子网参数
子网ID：网段起始地址
广播地址 = 子网ID + 块大小 −1
可用IP：子网ID+1 ~ 广播地址−1
单个子网可用主机数：2^m-2

## 题型2：已知IP+掩码，求该子网信息（高频计算题，咱们原题）
已知：IP：150.100.12.178，掩码255.255.255.128（/25）
步骤1：IP、掩码转为32位二进制
IP：`10010110.01100100.00001100.10110010`
掩码：`11111111.11111111.11111111.10000000`

步骤2：按位与（AND）求子网ID（网络ID）
IP AND 子网掩码 = 子网ID
结果：150.100.12.128

步骤3：求主机位位数m
`m=32-掩码前缀（/25）\(=7\)位`

步骤4：求主机ID
方法①：IP XOR 子网ID
方法②：IP AND 掩码反码
结果：0.0.0.50

步骤5：计算块大小
块大小 = 256 -掩码最后一段 = 256-128=128

步骤6：求广播地址
广播地址 = 子网ID + 块大小 −1
150.100.12.128 +128 −1 =150.100.12.255

步骤7：求可用主机IP范围
可用IP：子网ID+1 ～ 广播地址−1
150.100.12.129 ~ 150.100.12.254

步骤8：可用主机数量
2^m-2=2^7-2=126台

# 单招简答题背诵版（直接写卷子）
子网编址步骤：
1. 判断IP类型，确定原始网络位；
2. 根据需要的子网数量，计算需要向主机位借用的子网位；
3. 确定新的总网络位，得到子网掩码；
4. 计算块大小，确定各个子网的子网ID；
5. 计算每个子网广播地址、可用IP范围与可用主机数量。

## 单招避坑清单
1. 借位只能从主机位最高位连续借，不能零散挑选比特
2. 2^n：子网数量；2^m-2：单个子网可用主机
3. 子网ID（主机位全0）、广播地址（主机位全1）不能分配给主机
4. 块大小只看掩码中最后一段不为255的字节
