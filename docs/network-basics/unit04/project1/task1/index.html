任务一 TCP/IP参考模型概述12

知识点​

1.TCP/IP参考模型是什么​

TCP/IP参考模型是一个普遍使用的网络互联标准协议。（互联网实际真正使用的现实网络体系模型。）

  • TCP:传输控制协议，工作在传输层。负责跨网络寻址、路由选择，把数据包从源主机送到目的主机，实现不同网络之间互联，是整个互联网寻址转发的基础。没有 IP，不同网络之间无法互通。
  • IP: 互联网协议，工作在互联网层。提供可靠端到端传输，网页、文件传输大量业务依赖 TCP，保障数据可靠交付。

TCP/IP在事实上已经成为计算机网络的工业标准。(它不是理论模型，它是工业模型，也就是实际工程中落地的模型。)

以TCP/IP协议命名，是因为TCP 协议和 IP 协议是这套协议簇(上千个子协议)中两个最核心、最重要的协议

2.TCP/IP的起源​

ARPANet - 网络控制协议(NCP) - 传输控制协议(TCP) - 互联网协议(IP)

3.TCP/IP的管理部门是谁​

  • TCP/IP是开放的，不归属任何组织所有。
  • Internet工程任务组(IETF): 负责开发Internet标准和协议

4.TCP/IP参考模型的结构是什么​

TCP/IP 参考模型共分四个层次，从下到上依次是：网络接口层 → 互联网层 → 传输层 → 应用层。

层次层对应OIS层
④应用层会话层 + 表示层 + 应用层
③传输层传输层
②互联网层网络层
①网络接口层物理层 + 数据链路层

5.TCP/IP参考模型中各层的主要功能是什么​

层主要功能数据单元
应用层为应用程序提供网络服务(提供访问下层服务的接口)报文（Message）
传输层为应用层提供会话和数据包通信服务。端到端进程通信：端口寻址、可靠/不可靠传输、流量控制报文段（Segment）/ 数据报（Datagram）
互联网层传输分组数据到目标主机：分组转发、分组排序、路由选择、IP 编址、拥塞控制数据包 / 数据报（Packet）
网络接口层传输比特数据到相邻节点：发送和接收数据、ARP数据、RARP数据(封装成帧、MAC 寻址、比特传输)(网卡↔交换机、交换机↔路由器、路由器↔下一台路由器)帧（Frame）→ 比特流（Bits）

6.应用层的协议栈有哪些​

应用层协议：定义了应用程序之间通信的规则

层次协议名中文名协议用途
应用层HTTP
应用层FTP
应用层SMTP
应用层DNS
应用层RIP
应用层SNMP

7.传输层的协议栈有哪些​

层次协议名中文名协议用途
传输层TCP
传输层UDP

8.互联网层的协议栈有哪些​

层次协议名中文名协议用途
互联网层IPv4
互联网层IPv6
互联网层ARP
互联网层RARP
