## 知识点


### 七、专用IP地址与特殊用途地址

**27. 三个专用（私有）IP地址范围分别是什么？**
- 范围1：**10.0.0.0 ~ 10.255.255.255**（A类）
- 范围2：**172.16.0.0 ~ 172.31.255.255**（B类）
- 范围3：**192.168.0.0 ~ 192.168.255.255**（C类）

专用地址用在不直接与全球互联网相连的内联网（Intranet）中，通过网关代理/NAT访问Internet。

**28. 0.0.0.0是什么地址？有什么用途？**
称为**未指定的IP地址**，表示当前节点IP地址缺失。仅用作DHCP等动态配置场景下的源地址——某主机尚未配置IP地址、正尝试通过DHCP获取地址时使用。

**29. 127.0.0.X是什么地址？有什么用途？**
称为**回送地址（环回地址）**，用于网络软件测试和本机进程间通信。无论什么程序，一旦把回送地址作为目的地址，数据包都不会被发送到网络接口，而是直接交付给本机的目标应用进程。

**30. 子网广播地址和有限广播地址有什么区别？**
- **子网广播地址**：主机号部分全设为1（如192.168.7.255），数据包发送给本子网所有节点，**路由器会转发**到其他子网；
- **有限广播地址**：32位全为1，即**255.255.255.255**，用于本地子网"一对所有"传输，**路由器默认不转发**该数据包。

### 八、子网掩码与子网编址

**31. 子网掩码的作用是什么？它的格式有什么规定？**
子网掩码是32位二进制数，用于确定一个IP地址中网络部分占多少位：与网络ID对应的位用**1**标识，与主机ID对应的位用**0**标识。
- 常用掩码：255.0.0.0（A类）、255.255.0.0（B类）、255.255.255.0（C类）。
- 规定：掩码中的1必须**从最高位开始连续**，中间不能出现0（如239=11101111不能做掩码）。

**32. 如何通过子网掩码求出IP地址的网络ID和主机ID？**
- **网络ID = IP地址 AND 子网掩码**（按位逻辑与运算）；
- **主机ID = 网络ID XOR IP地址**（或 IP地址 AND 掩码反码）。

**33. "192.168.20.80/24"中"/24"是什么意思？等价的子网掩码是什么？**
"/24"表示IP地址的前24位是网络ID，等价的子网掩码为 **255.255.255.0**。

**34. 举例：IP地址150.100.12.178，子网掩码255.255.255.128（/25），求子网ID、主机ID、地址范围和广播地址。**
- 子网ID：150.100.12.128（25位网络位）
- 主机ID：01100000 = 96
- 可用主机范围：150.100.12.129 ~ 150.100.12.254
- 广播地址：150.100.12.255

**35. 为什么要划分子网？子网编址的思想是什么？**
原始两级IP结构（网络ID+主机ID）在大型网络中难以管理（如一个B类网可容纳6万多台主机）。子网编址从**主机ID部分借用若干位作为子网号**，形成三级结构：**网络ID + 子网ID + 主机ID**，把一个大网络划分成多个更小的子网，便于管理和提高地址利用率。

**36. 划分子网后，外部路由器能否识别内部子网划分？**
不能。Internet上的路由器仍认为这些子网都属于原来的大网络ID（如157.60.0.0/16），**子网划分对外透明**，不需要重新配置Internet中的路由器，只需配置本地路由器。

**37. 子网编址的步骤是什么？**
1. 根据组织内部网络环境，规划需要的子网数n和每个子网容纳的主机数m；
2. 选取最小的b使 n ≤ 2ᵇ，从主机号高位开始借b位作为子网ID；
3. 子网ID编号从0…00到1…11（共b位）；
4. 每个子网的主机ID从0…01到1…10（共 32−网络ID位数−子网ID位数 位）；
5. 注意：主机ID全0和全1必须排除。

**38. 例：对157.60.0.0/16借8位划分子网，可划分多少个子网？每个子网多少台主机？**
- 借8位作子网号 → 2⁸ = **256个子网**；
- 剩余8位主机号 → 2⁸−2 = **254台主机/子网**；
- 例如：157.60.1.0/24、157.60.2.0/24、157.60.3.0/24……

### 九、ICMP协议

**39. 什么是ICMP？它的作用是什么？**
ICMP（网际控制报文协议）是IP协议的一部分，由IP数据包承载。主要用于**报告数据包无法到达目标以及对传输错误的解释信息**（如"目标网络不可达"）。

**40. ICMP差错报告报文的基本格式包含哪些字段？**
- **类型**（0~12）：识别消息类型；
- **代码**：对特定类型的进一步描述；
- **检验和**：检验ICMP数据包中的位错误；
- **未使用**字段；
- **原始IP数据包**：引起该ICMP报文生成的那个原始IP数据包首部+前8字节。

**41. ICMP类型3（目标不可达）的常见代码有哪些含义？**
- 0：网络不可达
- 1：主机不可达
- 2：协议不可达
- 3：端口不可达
- 4：需要分段但已设置DF（不分段位）
- 5：源路由失败

**42. ping命令利用了ICMP的什么报文？**
ping向目标主机发送**ICMP类型8、代码0**的"回复请求"（回显请求）报文；目标主机收到后回送**ICMP类型0、代码0**的"回复应答"（回显应答）报文，以此测试网络连通性。

**43. ICMP能否使IP成为可靠协议？为什么？**
不能。ICMP只是尝试报告错误并在特定情况下提供反馈，且ICMP消息本身也是靠IP数据包传输的（本身也可能丢失），因此IP仍然是不可靠的。

### 十、ARP与RARP协议

**44. 为什么需要ARP协议？**
IP数据包最终要通过具体物理网络的链路发送，而物理网络（如以太网）只能识别自己的48位MAC地址。源主机必须知道目标主机的MAC地址才能封装成帧投递。ARP（地址解析协议）就是用来根据已知IP地址查找对应的MAC地址的。

**45. 简述ARP的工作过程（以A=192.168.0.1要给B=192.168.0.2发数据为例）。**
1. A不知道B的MAC地址，先广播一个**ARP请求报文**，询问"192.168.0.2的MAC地址是什么？"；
2. 同一以太网中所有主机都收到此广播，但只有B发现目标IP与自己相同，才做出响应；
3. B单播回复一个**ARP响应报文**，携带自己的IP地址和MAC地址给A；
4. A把B的IP↔MAC映射存入本机**ARP缓冲区（ARP缓存）**，以后直接查表使用，不必每次都发ARP请求。

**46. 什么是ARP缓冲区（ARP缓存）？为什么需要它？**
每台计算机的ARP自动维护一张IP地址与物理地址的转换表（映射表）。有了缓存，A以后再给B发数据时直接从缓存取MAC地址，避免每次都广播ARP请求，减少网络流量。表项如果一段时间未被使用会被自动删除（超时老化）。

**47. RARP协议的作用是什么？**
RARP（反向地址解析协议）完成与ARP相反的转换：**已知MAC地址，查找对应的IP地址**，常用于无盘工作站启动时获取自己的IP地址。

### 十一、IP数据包的发送与接收

**48. 同一子网内，客户机向服务器发送IP数据包的过程是怎样的？**
1. 查本机路由表，发现存在与服务器IP完全匹配的表项（说明在同一子网）；
2. 通过ARP获得服务器的MAC地址；
3. IP包头附上源IP和目的IP，交给网卡；
4. 网卡生成以太网帧，广播到局域网；
5. 服务器网卡捕获帧，检查协议类型字段为IP后上传给IP协议；
6. IP协议识别目的IP是本机后，根据"协议"字段把数据部分交给上层协议（TCP/UDP）。

**49. 不同子网时，客户机向服务器发送IP数据包的过程是怎样的？**
1. 查路由表，找到与服务器IP网络部分相匹配的表项（如219.220.243.0/24）；
2. 若找不到具体表项，则使用**默认网关**表项；
3. 通过ARP获得**网关（路由器）**的MAC地址（而非服务器的MAC地址）；
4. 帧封装好后发给默认网关；
5. 网关网卡收到帧后上传IP协议，发现目的IP不是本机，按路由表将IP数据包转发出去；
6. 数据包经过多个路由器逐跳转发，最终到达服务器所在子网，再交付给服务器。

**50. 同一子网与跨子网发送时，帧首部中的MAC地址和IP首部中的IP地址分别是谁？**
- **同一子网**：帧首部目的MAC = 服务器MAC；IP首部目的IP = 服务器IP。
- **跨子网**：帧首部目的MAC = **默认网关的MAC**；但IP首部目的IP = **服务器的IP**（IP地址端到端不变，MAC地址每跳都变）。

**判断题解析：**
- 第2题：C类主机ID为8位，去掉全0、全1两个保留地址，可用主机数为2⁸−2=**254台**，不是256台。
- 第4题：私有B类地址范围是172.16.0.0~172.31.255.255，**172.32已超出该范围**，属于公网地址。
- 第5题：回送地址的数据包**不会被发送到网络接口**，更不会被路由器转发，直接在本机内核中交付给目标进程。
- 第7题：子网划分**对外部路由器是透明的**，Internet路由器仍认为这些子网都属于原来的大网络ID，无需重新配置。
- 第10题：跨子网转发过程中，**IP数据包头中的源IP和目的IP始终端到端不变**；不断改变的是数据链路层帧首部中的源MAC和目的MAC地址。
