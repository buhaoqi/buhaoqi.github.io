任务二 认识IP协议-IP协议13

知识点​

4.TCP/IP的相关概念​

这些概念是 TCP/IP 网络里的一组基础名词，按"从小到大、从实到虚"的顺序给你逐条解释。先补全表格：

概念解释
节点（Node）能参与通信的设备都叫节点。网络中任何具备收发数据能力的连接点或设备，如主机、路由器、交换机、服务器等。
主机（Host）拥有 IP 地址、运行应用程序的终端设备（PC、服务器、手机）。它是数据的起点（源）和终点（目的），是通信的主角。
路由器（Router）工作在网络层（第 3 层）的互联设备，依据 IP 地址和路由表为数据包选择路径，负责连接不同网段/网络。它有多少个接口，就属于多少个网段。
局域网网段（LAN Segment）被路由器分隔出来的一个广播域范围。同一网段内设备可直接二层通信；不同网段之间必须经过路由器转发。
子网（Subnet）把一个大的 IP 网络，通过子网掩码从逻辑上划分出的更小网络。目的：缩小广播域、灵活分配地址、便于管理。一个网段可以就是一个子网。
TCP/IP 网络采用 TCP/IP 协议栈（IP 寻址 + TCP/UDP 传输）组建的网络。现代局域网和整个 Internet 都属于 TCP/IP 网络。
接口（Interface）设备连接网络的物理或逻辑通道，如网卡（eth0）、路由器端口。接口是 IP 地址的附着点，数据包从接口进、从接口出。
IP 地址网络层的逻辑地址，唯一标识网络中的一台设备（准确说是它的一个接口）。IPv4 是 32 位二进制，写成点分十进制（如 192.168.1.10），由网络号 + 主机号组成。
数据包（Packet）网络层传输的数据单元：IP 头部（源/目的 IP 地址）+ 数据载荷。发送时封装生成，由路由器沿路径逐跳转发，到达目的地后交给上层。
子网掩码（Subnet Mask）与 IP 地址配合使用的 32 位掩码，用来切分网络号和主机号：掩码中 1 对应的位是网络号，0 对应的位是主机号。如 255.255.255.0 表示前 3 段是网络号。

知识点​

1.IP协议是什么？​

  • IP协议是互联网层（网络层）的核心协议。
  • IP协议负责主机到主机的数据传输。

2.IP协议的特点是什么？​

  • 面向无连接：传递数据包之前，通信双方无需先就本次数据交换建立连接。
  • 不可靠：IP数据包在传输途中可能丢失、传输无序、被人复制或延迟到达，IP本身不负责差错恢复，而是把纠错任务交给更高层协议（如TCP）。

3.IP协议的主要功能是什么？​

  • 定义数据包格式
  • 编址：为每台设备分配IP地址
  • 分组转发：从源主机到目标主机

4.IP协议是如何定义数据包的？​

  • IP数据包 = IP数据包头 + IP负载
  • IP数据包头：是传输数据包的控制信息。包括：源IP地址、目的IP地址、数据包长度等信息。
  • IP负载：即运载的数据部分，如：TCP段、UDP消息，也可以是ICMP数据

5.IP数据包头中各关键字段的作用是什么？​

字段作用
版本是 IPv4 还是 IPv6，不同版本使用不同数据包格式
首部长度包头占多少字节（一般 20 字节），告诉负载从哪开始
服务类型标识数据包的服务质量要求
数据包长度（总长度）整个包（头 + 负载）多大，最大 65535 字节
标识、标志、偏移三件套，负责包太大时分段和到目的地后重组
标识（16位）管理分段和重组，识别一个分段属于哪个数据包
标志（3位）第1位保留；第2位"不分段"位（DF），置1则不分段；第3位"更多段"位（MF），置1表示后面还有段，置0表示最后一段
偏移字段（13位）确认一个段在原始数据包中的位置，以8字节为单位
TTL(寿命)每经过一台路由器TTL减1，减到0则丢弃。防止数据包在网络中无限循环；
上层协议指明数据部分交给哪个传输层协议；值6=TCP，值17=UDP
源IP地址发货人地址（32 位）
目的IP地址收货人地址（32 位）
首部检验和检查包头中的位错误；将头部每两个字节当成一个数，用反码运算求和

7.IP数据包为什么需要分段？​

一句话：为适应不同链路的承载能力。

不同物理网络的链路承载能力不同（以太网≤1500B，广域网≤576B）。

当路由器从某条链路收到一个数据包，而输出端链路无法承载原数据包长度时，就将IP负载拆成多个较小的"段"，分别封装成小包发出，以适应不同链路的承载能力。

8.IP数据包如何重组?​

IP数据包通过目标主机进行重组。目标主机通过检查：

  • 标识号：以确定这些数据包属于同一个数据包段。
  • MF=0：以确定最后一个段是否到达
  • 偏移：按正确顺序排好数据段

如果任意一个数据段丢失，则整个数据包被丢弃，不会重组。

9.IP分段和重组在什么设备上进行？​

  • 分段：在路由器上进行。
  • 重组：在目的主机上进行，中间路由器不重组。因为传输层希望从网络层收到完整的未分段数据包。

10.TTL是什么？​

  • TTL = Time To Live，IP 数据包的 "寿命"（生存时间）最多中转次数
  • 是 IP 数据包头里的一个字段。
  • 作用：给数据包设一个 "倒计时"，防止数据包在IP网络中无休止地循环传播。
    • 一开始由源主机设一个初始值（常见是 64、128 或 255）
    • 每经过一台路由器，TTL减1；
    • 当TTL减为0时，该数据包必须被丢弃。

  • 第1题：IP是面向无连接的，传递前无需建立连接。
  • 第2题：IP不负责差错恢复，交给TCP等高层协议。

  • 第7题：偏移字段以8字节块为单位，不是4字节。
