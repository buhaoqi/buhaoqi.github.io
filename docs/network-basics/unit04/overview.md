## 《复习指南》例题解析
1.以下关于网络协议的定义，正确的是（）。
A.网络协议是硬件设备的物理连接标准
B.网络协议是数据在传输媒介中的信号编码规则
C.网络协议是计算机之间通信时遵守的规则和约定
D.网络协议是应用程序的用户界面规范
【解析】网络协议是计算机网络中数据交换和通信时必须遵守的规则、标准或约定，涵盖语法、语义和时序等要素。
答案：C

2.OSI参考模型中，负责数据格式转换和加密的层级是（）。
A.应用层　B.表示层　C.会话层　D.传输层
【解析】表示层负责数据格式转换（如编码、压缩、加密）以确保不同系统间的兼容性。
答案：B

3.以下属于TCP/IP网络层协议的是（）。
A.HTTP、FTP　B.TCP、UDP　C.SMTP、DNS　D.IP、ICMP、IGMP
【解析】网络层协议包括IP（数据路由）、ICMP（错误报告）、IGMP（组播管理）、ARP（正向地址解析）、RARP（反向地址解析）。
答案：D

4.在TCP/IP网络配置中，DHCP协议的作用是（）。
A.解析域名到IP地址
B.将IP地址转换为MAC地址
C.提供端到端可靠传输
D.自动分配IP地址和其他网络参数
【解析】DHCP（动态主机配置协议）用于自动分配IP地址、子网掩码、默认网关等参数，工作过程为发现阶段：客户端发送广播请求发现DHCP服务器。提供阶段：服务器向客户端提供IP地址等配置信息。请求阶段：客户端请求使用特定的IP地址。确认阶段：服务器确认并完成IP地址的分配。
答案：D

5.ARP协议的主要功能是（）。
A.将IP解析为MAC地址　B.将域名解析为IP地址
C.提供可靠的端到端传输　D.动态分配IP地址
【解析】ARP（地址解析协议）通过广播查询目标设备的MAC地址，完成IP到MAC的映射。
答案：A

6.DNS协议默认使用的传输层协议及端口是（）。
A.UDP，53　B.TCP，80　C.TCP，53　D.UDP，67
【解析】NS通常使用UDP协议端口53进行域名解析，仅在响应较大时切换为TCP。
答案：A

7.某IP地址为192.168.1.100/27，其子网掩码是（）。
A.255.255.255.0　B.255.255.255.128　C.255.255.255.224　D.255.255.255.240
【解析】/27表示前27位为网络位，子网掩码为255.255.255.224。
答案：C

8.IPv6地址的长度是（）。
A.32位　B.128位　C.64位　D.256位
【解析】析：IPv6地址长度为128位，采用十六进制表示（如：2001:0db8:85a3:08a2:0370:7334）
答案：B
