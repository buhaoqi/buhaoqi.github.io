## 知识点

### 1.UDP是什么
UDP：**User Datagram Protocol，用户数据报协议**，是TCP/IP模型**传输层**协议。

### 2.UDP的特点是什么
1. **无连接**：通信前不用建立连接，发送数据前不需要握手。
2. **不可靠传输**：不确认、不重传、没有流量控制、没有拥塞控制，尽最大努力交付，可能丢包、乱序。
3. **面向报文**：应用层交给UDP多长的报文，UDP就原样打包发送，不拆分、不合并。
4. **支持一对一、一对多、多对一、多对多通信**（支持组播）。
5. **首部开销很小**，仅8字节，传输速度快。

>一句话速记：**无连接、不可靠、面向报文、首部短、速度快**

### 3.UDP适用的场景有哪些
适合**对实时性要求高，可以容忍少量丢包**的应用：
1. DNS域名解析（域名查询）
2. DHCP自动分配IP地址
3. 流媒体：视频直播、网络音频、视频通话
4. 网络游戏
5. TFTP简单文件传输

>考点对比：文件下载、网页访问用TCP（不能丢数据）；直播、游戏用UDP（优先速度）

### 4.UDP数据报格式中字段的作用是什么
UDP数据报 = **UDP首部（固定8字节） + 数据**

UDP首部一共4个字段，每个字段占2字节：
|字段|作用|
| ---- | ---- |
|源端口号|发送方应用进程端口；可选，不写可填0|
|目的端口号|接收方应用进程端口，**必须要有**，用于传输层寻址|
|长度|整个UDP数据报总长度（首部+数据），最小8字节（无数据）|
|校验和|校验UDP首部+数据，检测传输差错；可选择不校验|

>简答模板：UDP首部固定8字节，包含源端口、目的端口、长度、校验和四个字段。

### 总结
- UDP是传输层的用户数据报协议。
- 特点：无连接、不可靠、面向报文，首部只有8字节，传输速率快。
- 适合DNS、DHCP、视频直播、网络游戏这类实时性要求高，允许少量丢包的场景。
- UDP数据报由8字节首部和数据部分组成，首部包含源端口、目的端口、长度、校验和。
