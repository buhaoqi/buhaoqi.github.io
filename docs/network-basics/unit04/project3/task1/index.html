任务一 应用层协议20

知识点​

1. 应用层协议是什么​

应用层是TCP/IP模型最高一层，应用层协议是为网络应用程序提供通信规则，规定应用之间如何请求、交换数据。 依托下层TCP或UDP完成传输，常见：HTTP、FTP、DNS、DHCP、SMTP、POP3、IMAP。

2. 文件传输协议是什么​

FTP（File Transfer Protocol）文件传输协议。 作用：在网络上上传、下载文件。 底层：使用TCP，可靠传输；默认端口21（控制连接）、20（数据连接）。

3. 超文本传输协议是什么​

HTTP（HyperText Transfer Protocol）超文本传输协议。 用于浏览器和Web服务器之间传输网页（超文本），基于TCP，端口80。

HTTPS是HTTP+SSL/TLS加密，端口443。

4. 超文本传输协议的报文分为哪两类​

HTTP报文分两大类：HTTP请求报文、HTTP响应报文。

5. HTTP请求报文是什么​

由客户端（浏览器）发给Web服务器，向服务器申请资源。 组成：请求行、请求头部、空行、请求体。 请求行包含：请求方法（GET/POST等）、URL、HTTP版本。

6. HTTP响应报文是什么​

由Web服务器返回给客户端，携带请求的网页资源。 组成：状态行、响应头部、空行、响应体。 状态行包含：HTTP版本、状态码（200成功，404找不到页面，500服务器错误）。

7. 域名解析协议是什么​

DNS（Domain Name System）域名系统（域名解析协议）。 作用：把好记的域名（www.baidu.com）翻译成IP地址。底层使用UDP，端口53。

8. ICANN是什么​

互联网名称与数字地址分配机构。 负责管理全球域名体系、IP地址分配，管理顶级域名。

9. 顶级域名有哪些​

顶级域名是域名最后一段，分两类：

  1. 通用顶级域名 .com商业机构；.org组织；.net网络服务商；.edu教育；.gov政府；.info信息
  2. 国家顶级域名 .cn中国；.us美国；.jp日本

10. DHCP是什么​

DHCP动态主机配置协议。 作用：自动给局域网内主机分配IP地址、子网掩码、网关、DNS地址，不用手动设置IP。底层UDP，端口67/68。

11. DHCP服务的工作过程分为哪四步​

  1. 发现（Discover）：客户端广播发送，寻找DHCP服务器
  2. 提供（Offer）：DHCP服务器广播，提供可用IP地址
  3. 请求（Request）：客户端广播，申请选用该IP
  4. 确认（Acknowledge）：服务器广播确认，分配IP，租期生效 口诀：发现、提供、请求、确认（DORA）

12. SMTP是什么​

SMTP 简单邮件传输协议。 用于发送邮件，把邮件从发件人邮箱发送到邮件服务器；TCP，端口25。

13. POP（POP3）是什么​

POP3 邮局协议版本3。 用于接收邮件，从邮件服务器下载邮件到本地电脑。TCP，端口110。

14. IMAP是什么​

IMAP互联网消息访问协议。 接收邮件协议，邮件保留在邮件服务器上，本地只做查看、管理；TCP，端口143。

15. IMAP和POP3的区别是什么​

  1. POP3：邮件下载到本地，服务器一般删除原件；多设备不同步。
  2. IMAP：邮件保留在服务器；多终端同步邮件状态（已读/未读、文件夹），适合多设备使用。 一句话：POP3下载到本地；IMAP邮件留在服务器，多端同步。

16. MIME是什么​

MIME 多用途互联网邮件扩展。 原始SMTP只能传输纯文本；MIME扩展邮件格式，支持在邮件里发送图片、音频、视频、附件。

汇总​

  • 应用层协议规定应用软件之间通信规则。
  • FTP用于文件上传下载；
  • HTTP传输网页，报文分为请求报文和响应报文。
  • DNS做域名转IP；
  • ICANN管理域名与IP分配；顶级域名分为通用域名、国家域名。
  • DHCP自动分配IP，工作四阶段DORA。
  • 邮件协议：SMTP发邮件；POP3、IMAP收邮件，POP3下载邮件到本地，IMAP邮件保存在服务器、支持多端同步
  • MIME让邮件支持图片和附件。
