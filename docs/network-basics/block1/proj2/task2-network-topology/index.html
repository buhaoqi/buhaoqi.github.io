任务二 计算机网络拓扑结构

知识点​

1.什么是网络拓扑结构？​

拓扑学是几何学的分支，它由图论演变而来。在拓扑学中，先将实体抽象为与大小、形状无关的点，再将连接实体的线路抽象为线，进而研究点、线、面之间的关系。

如果不考虑实际网络的地理位置，把网络中的计算机、设备等视为节点，把通信线路视为连线，这就初步抽象出了计算机网络的拓扑结构。

网络拓扑结构：在计算机网络设计中，借助拓扑学的概念，将通信子网中的通信处理机和其他通信设备抽象为与大小和形状无关的点，并将连接节点的通信线路抽象为线，将这种点、线连接而成的几何图形称为网络拓扑结构。网络拓扑结构通常可以反映出网络中各实体之间的结构关系。

2.网络拓扑结构在网络设计中的作用是什么？​

在网络的设计中：

  1. 确定位置：必须确定各计算机和其他网络设备在网络中的位置
  2. 影响性能：网络的拓扑结构将直接关系到网络的性能、系统可靠性、通信及投资费用等因素。例如，选用总线型拓扑结构时，其传输介质的使用量较少，投资也就较少
  3. 协议基础：拓扑结构还是实现各种协议的基础

所以说，网络拓扑结构的选择和设计是计算机网络设计的第一步。

3.局域网有哪些典型拓扑结构？​

局域网的拓扑结构主要有星型、总线型和环型三种。另外，在实际的网络建设中，也存在混合结构和蜂窝拓扑结构。

4.星型拓扑结构的特点是什么？​

结构特点：

  • 星型拓扑结构是用一个节点作为中心节点，其他节点直接与中心节点相连构成的网络
  • 中心节点可以是文件服务器，也可以是连接设备，常见的中心节点为集线器或交换机
  • 星型拓扑结构的网络属于集中控制型网络，整个网络由中心节点执行集中式控制管理，各节点间的通信都要通过中心节点
  • 每一个要发送数据的节点都要将发送的数据发送至中心节点，再由中心节点负责将数据送到目的地节点
  • 因此，中心节点相当复杂，而各个节点的通信处理负担都很小，只需要满足链路的通信要求即可

优点：

  1. 控制简单：任何一个外围节点只和中心节点相连接，因而传输介质的访问控制方法简单，访问协议也十分简单，易于网络监控和管理
  2. 故障诊断和隔离容易：从中心节点对连接线路可以逐一隔离进行故障检测和定位，单个连接点的故障只影响一个设备，不会影响全网的连通性
  3. 方便服务：中心节点可以方便地对各个站点提供服务和网络重新配置

缺点：

  1. 需要耗费大量的电缆，安装、维护的工作量较大
  2. 中心节点负担重，容易形成"瓶颈"，一旦发生故障，则全网受影响

应用情况：星型拓扑结构相对简单，便于管理，建网容易，是目前局域网普遍采用的一种拓扑结构。采用星型拓扑结构的局域网，一般使用双绞线或光纤作为传输介质，符合综合布线标准，能够满足多种宽带需求。

5.总线型拓扑结构的特点是什么？​

结构特点：

  • 这种结构所有节点都直接连到一条主干电缆上，这条主干电缆就称为总线
  • 总线所采用的介质一般是同轴电缆（分为粗缆和细缆）或光缆
  • 总线结构是指每个联网的设备（工作站和服务器）均连接在一条总线上，没有中心节点进行控制
  • 公用总线上的信息多以基带形式进行串行传递，其传递方向总是从发送信息的节点开始向两端扩散，如同广播电台发射的信息一样，因此又称广播式网络
  • 各节点在接收信息时都进行地址检查，判断是否与自己的地址相符，相符则接收网上的信息

特点总结：

  1. 组网费用低：这种结构不需要另外的互联设备，是直接通过一条总线进行连接
  2. 传输速度随用户数增加而下降：因为各节点是共用总线带宽的
  3. 用户扩展较灵活：需要扩展用户时只需要添加一个接线器即可，但所能连接的用户数量有限
  4. 维护较容易：单个节点失效不影响整个网络的正常通信
  5. 故障排查困难：如果总线某处中断，则整个网络或者相应主干网络就中断了
  6. 一次仅能一个端用户发送数据：其他端用户必须等待到获得发送权

6.环型拓扑结构的特点是什么？​

结构特点：

  • 环型拓扑结构由网络中若干节点通过点到点的链路首尾相连形成一个闭合的环
  • 这种结构使公共传输电缆组成环型连接，数据在环路中沿着一个方向在各个节点间传输
  • 信息从一个节点传到另一个节点
  • 令牌网就是这种结构的网络

特点总结：

  1. 一般仅适用于IEEE 802.5的令牌网（Token Ring Network）：在这种网络中"令牌"在环型连接下的节点中依次传递，所用的传输介质一般是同轴电缆
  2. 令牌是一个数据帧：该数据帧由控制信息和数据信息两部分组成。控制信息包含了源地址、目标地址及数据帧的忙、闲状态（"忙"表示携带了数据信息）等信息
  3. 网络组建比较简单，投资较省：组成这个网络的除了各工作站就是传输介质以及一些连接器材，没有节点集中设备（如集线器和交换机等），功能最为简单
  4. 维护困难：由于网络各节点间是直接串联，任何一个节点出故障后都会造成整个网络的中断、瘫痪，维护起来非常不便。另外由于环型网络常用的同轴电缆所采用的是插针式的接触方式，非常容易造成接触不良，查找故障点非常困难
  5. 扩展性能差：如果要添加或移出节点，就必须中断整个网络

其他特点：

  • 信息流在网中是沿着固定方向流动的，两个节点仅有一条道路，故简化了路径选择的控制
  • 环路上各节点都是自举控制（所谓"自举"是指节点根据所安装的网络协议对收发的信息进行自动引导控制），故控制软件简单
  • 由于信息源在环路中是串行地穿过各个节点，当环中节点过多时，势必影响信息传输速率，使网络的响应时间延长

7.什么是混合结构？​

  • 混合结构是将多种拓扑结构的局域网连在一起而形成的
  • 例如一种混合拓扑结构由左侧的星型结构和右侧的总线结构组合而成
  • 混合拓扑结构的网络兼并了不同拓扑结构的优点

8.什么是蜂窝拓扑结构？​

  • 蜂窝拓扑结构是无线局域网中常用的结构
  • 以无线传输介质（微波、卫星、红外等）点到点传输和多点传输为特征
  • 是一种无线网使用的拓扑结构，适用于局域网和城域网
  • 处于每个蜂窝中心位置的为无线收发设备
