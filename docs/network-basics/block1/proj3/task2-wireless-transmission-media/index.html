任务二 无线传输介质

知识点​

1.什么是无线传输介质？适用于什么场合？​

无线传输介质主要包括各个波段的无线电波、地面微波接力线路、卫星微波线路，以及激光、红外线等。

适用场合：在一些电缆、光纤等有线介质难以通过或施工困难的场合，例如高山、湖泊或岛屿等，即使在城市中挖开道路铺设电缆有时也很不经济，特别是通信距离很远，对通信安全性要求不高，铺设电缆或光纤既昂贵又费时，若采用无线传输介质在自由空间传播就会有较大的机动灵活性和抗自然灾害能力，可靠性也较高。

2.无线电波的概念和频段划分是什么？​

无线电波是电磁波的一部分，它是频率在0~300MHz频段的电磁波。在这段频率内可人为地划分为几个波段，对应于不同的波段有不同的用途：

波段频率范围波长范围频道名使用情况
超长波0~30kHz万米波军用
长波30kHz~300kHz千米波军用
中波300kHz~3000kHz百米波无线电台
短波3000kHz~30MHz十米波短波电台
超短波30MHz~300MHz米波电视节目

3.为什么很少用0~300MHz的波段进行数据传输？​

实际上很少用0~300MHz的波段来进行数据传输，原因有两个：

  1. 带宽有限：它们的带宽有限，所传输的数据量有限
  2. 频段已被占用：此频段开发较早，大部分频段已经被占用，可利用频段较少

4.地面微波通信的特点是什么？​

数字微波通信系统在长途大容量的数据通信中占有极其重要的地位，其频率范围为300MHz~3000GHz。主要有两种应用方式：地面微波接力通信和卫星通信。

传播特点：

  • 微波在空间主要是直线传播，并且能穿透电离层进入宇宙空间
  • 不像短波那样经电离层反射可以传播到地面上很远的地方
  • 由于地球表面是个曲面，因此其传播距离受到限制且与天线的高度有关，一般只有50km左右
  • 长途通信时必须建立多个中继站，中继站把前一站发来的微波信号经过放大后再发往至下一站

5.卫星通信的原理和特点是什么？​

原理：卫星通信是利用位于36000km高空的人造地球同步卫星作为太空无人值守的微波中继站，是一种特殊形式的微波接力通信。

特点：卫星通信克服了地面微波通信的距离限制，其特点是通信距离远，通信费用与通信距离无关，只与租用的卫星转发器个数及租用的时间长短有关。

优点缺点
频带比微波接力通信更宽，通信容量更大传播时延较长
信号受到的干扰较小，误码率也较小
通信比较稳定可靠

6.红外线和激光的传输特点是什么？​

红外信号和激光信号在自由空间通常是沿直线进行传播的，它比微波具有更强的方向性，难以窃听、插入数据和进行干扰。

  • 现在许多PC机和手机上都配置有**IrDA（红外线）**接口
  • 但红外线和激光对雨雾等环境的干扰特别敏感，传输距离短

7.蓝牙技术的概念和特点是什么？​

概念：蓝牙（Bluetooth）是一种新型的用于替换电缆的短程无线传输技术，提供一点到多点的无线声音及数据传输。

技术参数：

参数数值
支持速度（不对称）723kb/s
支持速度（对称）432kb/s
传输距离10cm~10m
增强传输距离（增加功率或外设）可达100m
可传输内容数据和语音信号

主要特点：

  1. 采用无线接口代替有线电缆连接，具有很强的移植性
  2. 适用于多种场合
  3. 支持多种设备
  4. 可以穿过障碍物、全方向传输数据
  5. 内置数据安全性

蓝牙技术将各种通信设备、计算机及其终端设备、各种数字数据系统乃至家用电器，采用无线方式连接起来。随着更多新型蓝牙产品（如蓝牙手机、蓝牙耳机）投放市场，蓝牙技术将会给人们的生活带来更多的方便。
