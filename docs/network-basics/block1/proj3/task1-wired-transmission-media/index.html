任务一 有线传输介质

知识点​

1.什么是有线传输介质？​

有线传输介质是指网络中将各种终端与通信设备进行有形物理连接的部分，它能将网络信号沿物理线路从一方传输到另一方。有线传输介质主要包括双绞线、同轴电缆和光纤。双绞线和同轴电缆传输电信号，光纤传输光信号。

2.传输介质有哪两个主要特性？​

特性说明
物理特性物理结构、形态尺寸、覆盖范围、价格以及连通性与使用的方便性等
传输特性传输信号的带宽、传输损耗以及抗干扰能力等

传输介质的特性直接影响通信的质量指标，如信道容量、传输速率、误码率及线路费用等。

3.双绞线的基本概念是什么？​

双绞线也称双扭线，是把两根绝缘铜导线并排放在一起拧成有规则的螺旋形，然后在外层再套上一层保护套或屏蔽套，是组网中最常用的一种传输介质。

  • 如果把若干对双绞线集成一束，并用结实的保护外皮包住，就构成了双绞线电缆
  • 把多个线对扭在一起主要是为了消除各线对之间的电磁干扰
  • 计算机网络中使用的双绞线一般由4对双绞线组成
  • 公共交换电话网中也使用双绞线，但电话中的双绞线由1对双绞线组成

4.双绞线分为哪两类？​

按在外皮内是否有金属屏蔽层，双绞线可分为：

类型全称特点
屏蔽双绞线（STP）Shielded Twisted Pair有金属屏蔽层，抗干扰性能好，但价格较高
非屏蔽双绞线（UTP）Unshielded Twisted Pair无金属屏蔽层，抗干扰性能差一些，但价格低且易弯曲，应用更普遍

5.非屏蔽双绞线 UTP 的分类有哪些？​

美国电子/通信工业协会（EIA/TIA）按绞距大小（即铜线缠绕的紧密程度）等参数的差异把非屏蔽双绞线 UTP 分为以下类别：

类别适用场景说明
1类线（UTP-1）模拟电话用户线没有固定的性能要求
2类线（UTP-2）数字电话用户线、ISDN和T1线路（1.544Mb/s）包括4对双绞线
3类线（UTP-3）4Mb/s令牌环网、10Mb/s以太网及ISDN语音线路包括4对双绞线
4类线（UTP-4）16Mb/s令牌环网和10Mb/s大型以太网包括4对双绞线
5类线（UTP-5）16Mb/s以上令牌环网和10/100Mb/s大型以太网包括4对双绞线，有效传输距离约100m

随着技术的发展和网络带宽需求的提高，又出现了以下几种：

  • 超5类线（属UTP-5增强型）：主要用于100/1000Mb/s的局域网或大型主干网，包括4对双绞线
  • 6类双绞线：用于语音、ISDN、ATM155Mbps和622Mbps、快速以太网和千兆以太网，比5类和超5类具有传输距离长、传输损耗小、耐磨等优势。在千兆以太网中有效传输距离可达100m左右
  • 超6类线：6类线的改进版，在抗串扰、抗衰减和降低信噪比等方面有较大改善，最大传输速度为1000Mbps。结构上在4对双绞线中间加了十字形的线对分隔条
  • 7类线：主要使用在万兆以太网中，是一种屏蔽双绞线，传输速率可达10Gbps。每一对线都有一个屏蔽层，四对线合在一起还有一个公共的大屏蔽层

目前在连网实践中应用最广泛的是5类双绞线（百兆以太网）和6类双绞线（千兆以太网）。

6.双绞线水晶头的标准线序是什么？​

双绞线两端的接头俗称"水晶头"，其标准为 RJ45。在双绞线和水晶头连接时，线序应遵守 EIA/TIA 制定的 568标准。

网线类型适用场景线序规则
交叉网线（反绞线/反接线）连接相同种类的设备（如计算机连接计算机）一端按568A排列，另一端按568B排列
普通网线（直通网线/正接线）连接不同种类的网络设备（如计算机连接交换机）两端均按568B标准排列

交叉网线的制作中，第1和第3、第2和第6根芯线要对调。

7.同轴电缆的结构和特点是什么？​

结构：典型的同轴电缆由一根内导体外加绝缘层、密集网状编织导电金属屏蔽层以及外包装保护材料组成。内导体和外导体之间由绝缘材料隔离，外导体外还有外皮套或屏蔽物。

由于外导体屏蔽层的作用，同轴电缆具有较好的抗干扰性能。

在网络中使用的同轴电缆有两种：

类型阻抗传输速率有效传输距离（不加中继）
细缆50欧姆10Mb/s185m
粗缆50欧姆-500m

注意：用同轴电缆组网，其网络拓扑为总线型，不易管理、维护，且支持的数据传输速率较低，在网速飞跃发展的今天，同轴电缆已基本不再连网实践中使用。

8.光纤的工作原理是什么？​

光纤的工作原理基于全反射现象：射到光纤内表面的光线入射角大于某一临界角度时就会产生全反射现象。全反射是指光从光密介质射入光疏介质，当入射角增大到某一角度，使折射角达到90度时，折射光完全消失，只剩下反射光。

9.光纤分为哪两类？​

光纤按传输模式可分为单模光纤和多模光纤两种：

类型英文名纤芯直径传输模式特点
多模光纤Multimode Fiber50~100微米多条以不同角度入射的光线同时传输性能较差，由石英玻璃制成
单模光纤Single-mode fiber8~10微米以单一模式单色光传输传输频带宽、容量大、传输距离远，但价格较高

10.光纤有哪些优点？​

  1. 传输频带非常宽，因而通信容量大
  2. 传输速率高，能超过千兆位/秒，在实验室中已获得T级（1000Gb/s）传播速率
  3. 误码率极低，传输衰减小，无需中继，传输距离长，远距离传输特别经济
  4. 不受外界电磁波的干扰，适宜在电磁干扰严重的环境中使用
  5. 无串音干扰和辐射，不易被窃听或被截获数据，安全保密性好
  6. 体积小，重量轻

11.光纤有哪些不足？​

  1. 连接两根光纤时需要专用设备，保证对接的光纤端面平整，安装要求精确度高，技术难度大，需要专业技术人员操作
  2. 由于光的传输是单向的，双向传输需要两根光纤或一根光纤上的两个频段
  3. 分接困难且需要有光电转换设备

12.光缆的结构是什么？​

光缆包含一条或一条以上（可达数百条）的光纤，其结构大致可分为缆芯和保护层两大部分。
