二、选择题答案​

题号123456
答案ABDADC

逐题解析：

第 1 题 A——题眼是"范围可至上万千米"。B 是城域网（MAN），C、D 是局域网（LAN），只有 A 描述了广域网"跨城市、跨国家、跨洲"的本质。

第 2 题 B——广域网技术（PSTN、X.25、帧中继、DDN 的链路层规程）主要工作在 物理层和数据链路层，负责"把比特送过去、把帧传过去"；网络层以上的选路与端到端功能由用户网络（路由器、主机）负责。

第 3 题 D——逐项排除：A 错，广域网的地理区域不确定（这正是它与局域网的最大区别之一）；B 错，高速多重接入是局域网的特征，广域网速率相对低；C 错，令牌是令牌环、令牌总线（局域网）的介质访问控制方法；D 对，广域网使用电信运营商的通用载波服务（公共网络），这正是它必须"租用线路"的原因。

第 4 题 A——B、C 描述的是 DDN（同步数字专线、质量高但并不是"最快的广域网协议"这种说法）；D 描述的是帧中继／X.25 类的分组网特征；只有 A 抓住了 ISDN 的关键——在既有电话线上同时传语音和数据。

第 5 题 D——"宽带接入"要以Mbit/s 级速率为门槛：电话拨号（56kb/s）、ISDN（144kb/s／2Mb/s）、DDN（窄带专线）都属窄带；ADSL 下行可达 8Mb/s，属于宽带接入。同类的还有 HFC（Cable Modem）、FTTH 光纤接入。

第 6 题 C——路由器的核心功能是"为数据包选择一条最佳传输路径"，即路由选择（含路由表的建立、维护与查表转发）。A、B 只是路由协议的交互行为（是手段），D"通信管理"太笼统。

三、问答题参考答案​

1. WAN 和 LAN 两者的网络拓扑结构有何异同？

相同点：两者都是由节点与链路构成的网状连接关系，基本形态都包含星型、环型、树型、网状（分布式） 等。

不同点：

比较项局域网（LAN）广域网（WAN）
常用拓扑总线型、星型、环型为主（共享介质）树型（分级）、网状、混合型为主
结构特点结构规则、范围小、层次少采用两级结构——主干网 + 用户接入网
冗余要求一般不需要冗余（一条主干即可）强调冗余，网状拓扑可自动迂回
管理归属单位自建自管多由电信运营商提供（公用数据网 PDN）
拓扑动因受介质访问控制方法（CSMA/CD、令牌）约束受跨地域、多用户、可靠性要求约束

2. 广域网提供哪些服务？列举常见的广域网络。

两类服务：

  1. 面向连接的服务——虚电路服务（先建立连接、按序传送、最后释放）与电路交换服务（独占物理通路）；
  2. 面向无连接的服务——数据报服务（每个分组独立选路，可能乱序、可能丢失，由端系统负责重组与重传）。

常见的广域网络（公共网络系统）：PSTN（公共交换电话网）、X.25 分组交换网、DDN（数字数据网）、帧中继（Frame Relay）、ISDN（综合业务数字网）、ATM（异步传输模式）、光配线网络／光纤接入（ODN／FTTH），以及基于公用网构建的 VPN（虚拟专用网络）。

3. 广域网的两种组网方式有何不同？

比较项点对点方式分组交换式
连接形式两点之间独占一条链路（Modem 拨号、专线、网桥、DSU/CSU）各节点接入公共数据网，由网络内部转发
链路数量全连通时需 n × (n − 1) ÷ 2 条，成本极高每点只需一条接入链路，成本低
中间设备Modem、网桥、DSU/CSU路由器（+ 公共数据网）
带宽利用独占，空闲时浪费统计复用，多用户共享
时延与计费时延小、按距离／时长计费，长距离贵时延略大、按流量或包月计费，远距离便宜
适用场合两点之间、流量稳定、要求安全隔离多点互联、突发流量、跨地域

结论：点对点解决"两点连线"，分组交换解决"多点组网"——节点一多，点对点链路数呈平方增长，必须改用分组交换。

4. 什么是 ISDN？其特点有哪些？

定义：ISDN（Integrated Services Digital Network，综合业务数字网） 是在现有电话网基础上发展起来的、能够在一对用户线上同时传输语音、数据、图像等多种业务的数字通信网络，实现端到端的数字连接。

特点：

  1. 端到端的数字连接——用户环路由模拟变为数字，无需 Modem；
  2. 业务的综合性——语音、数据、传真、图像、视频多种业务共用一条线路；
  3. 标准的用户-网络接口——通过标准接口接入，终端可即插即用；
  4. 两种接口速率——BRI（2B+D） 为 2×64 + 16 = 144kb/s（含同步开销 192kb/s）；PRI（23B+D） 为 23×64 + 64 = 1.536Mb/s（含开销 1.544Mb/s）；
  5. 通道分工——B 通道（64kb/s） 传用户信息，D 通道（16kb/s 或 64kb/s） 传信令，H 通道 传高速用户信息；
  6. 接入设备——需要 NT1（网络终端） 和 TA（终端适配器）。

5. 列举广域网接入技术。

  1. PSTN 拨号接入（Modem，最高 56kb/s）；
  2. ISDN 接入（BRI／PRI）；
  3. xDSL 接入——ADSL（非对称）、HDSL／SDSL（对称）、VDSL（高速短距）；
  4. DDN 专线接入（半永久数字专线）；
  5. HFC／Cable Modem 接入（有线电视同轴网）；
  6. 光纤接入——FTTH／PON（OLT + ODN + ONT）；
  7. 分组交换网接入——X.25、帧中继、ATM；
  8. 无线接入——WLAN、4G／5G、卫星；
  9. VPN 接入（基于公用网的加密隧道）。

6. ADSL 接入方式是否需要拨号？与 HDSL 有何区别？

是否需要拨号：需要，但不是传统电话拨号。ADSL 采用 PPPoE 虚拟拨号——ADSL 本身是专线式的物理连接（一直在线），"拨号"只是向运营商做身份认证并获得 IP 地址的过程，不占用电话语音通道，可以上网、打电话同时进行。

与 HDSL 的区别：

比较项ADSL（非对称）HDSL（对称）
上下行速率非对称：下行 8Mb/s、上行 1Mb/s对称：上下行相同，160kb～2.084Mb/s
传输距离3~5km约 3.6km
线对数量1 对双绞线通常 2~3 对双绞线
设计目的居民／小型用户上网（下行流量大）替代传统 T1／E1 专线，企业点对点连接
是否需要拨号需要 PPPoE 虚拟拨号不需要，永久在线
典型应用家庭宽带企业专线、基站回传、局域网互联

7. 为什么 DDN 可以不采用交换技术？

因为 DDN 提供的是"半永久性"的数字连接，而不是"按需建立、逐段转发"的连接：

  1. 半永久连接——用户申请后，由交叉连接装置在约定的时间内把两端固定接通，通信期间通路独占，不需要每次通话都"拨号建链"；
  2. 中间节点不做存储-转发——DDN 节点只做数字信号的交叉连接与复用，不进行复杂的软件处理，所以时延小且固定；
  3. 差错处理交给终端——DDN 把检错、纠错功能交由智能化程度高的终端完成，网络本身不逐段检错重传，也就不需要分组交换那一套机制；
  4. 本质是"数字专线"——它把数字通信、计算机、光纤通信、数字交叉连接技术结合，为用户提供透明的高质量传输通道。

一句话：交换是为了"共用一条路"，而 DDN 卖的是"专属的一条路"——路是固定的，当然不需要交换。

8. DDN 和 ISDN 分别有什么用途？

网络主要用途
DDN① 企业／银行／税务等专线组网（点对点、点对多点）；② 局域网远程互联；③ Internet 专线接入；④ VOD 视频点播、监控图像传输；⑤ 帧中继的物理承载。特点：固定带宽、低时延、安全可靠，适合稳定的大流量业务
ISDN① 综合业务接入（语音 + 数据 + 图像同一线路）；② 拨号上网、小型办公上网；③ 视讯会议、远程教学／医疗；④ 专线的备份线路（主线路故障时拨号顶替）；⑤ POS 机、银行网点等按需连接。特点：按需建立、按时长计费，适合间歇性、多业务需求

一句话：DDN 是"常年包下的专线"，ISDN 是"随用随拨的多业务线路"。

9. VPN 的安全问题是如何解决的？

靠四项技术（教材四大安全技术）：

  1. 隧道技术——把私有网的原始数据包整体封装进公用网可传输的包里，在两端之间形成逻辑"隧道"。二层隧道协议有 L2F、PPTP、L2TP（L2TP 是 PPTP 与 L2F 结合的 IETF 标准）；三层隧道协议有 IPSec（工作在 IP 层）。
  2. 加解密技术——对隧道中传输的数据加密，即使被截获也无法读懂；常用 DES／3DES／AES 等算法。
  3. 密钥管理技术——保证密钥安全地产生、分发、更新与销毁。SKIP 通过网上传送密钥；ISAKMP／OAKLEY 采用公私钥体系，双方各持一把密钥。
  4. 身份认证技术——确认通信双方的身份，方式有用户名口令、智能卡、生物特征（指纹、虹膜） 等，安全级别依次提高。

补充：VPN 还应具备安全、QoS（服务质量保证）、灵活可扩充、可管理四项特性；实际部署中还配合访问控制列表、防火墙、审计日志。

10. VPN 与一般的文件传输服务 FTP 有何区别？

比较项VPNFTP
工作层次网络层／数据链路层（隧道）应用层（TCP 21 控制、20 数据）
保护范围整个 IP 包都加密（含源／目的地址、端口、载荷）只保护传输的文件内容（且默认明文，账号口令也是明文）
访问能力接入后如同身处内网，可访问所有内网资源（共享、打印、数据库、ERP）只能上传／下载文件，不能访问其他服务
连接方式建立点对点／点对网的加密隧道，长期在线一次会话传一个或一批文件，传完即断
地址处理两端可用私有地址重复（如都是 192.168.100.x）必须能路由到对方 IP
典型用途远程办公、分支机构互联、合作伙伴接入文件交换、网站维护、软件分发
安全性高（加密 + 认证 + 隧道）低（明文传输，需靠 FTPS／SFTP 增强）

一句话：FTP 是"把文件搬过来"，VPN 是"把整个内网搬到你面前"。

11. 简述 VPN 的原理及用途。

原理（四步）：

  1. 矛盾起点——私有网络与公用网络使用不同的地址空间或协议，两者不兼容，无法直接通信；
  2. 打包——发送端把私有网的原始数据包整体作为载荷，加上新的公用网包头（并加密）；
  3. 隧道传输——封装后的数据包穿过公用网（Internet），就像在一根专用管道里传输；
  4. 解包与转发——接收端拆除公用网包头、解密、还原原始数据包，再转发给内网主机。

教材的比喻：公用网像一根普通电缆，两端的 VPN 设备像两个特殊的"接头"——接头把私有包"接"到电缆上，另一端再"接"回来。

系统三要素：VPN 服务器、VPN 客户端、数据通道（连接建立后，服务器与客户端角色相同，区别只在于谁发起连接）。

用途（三类应用）：

  1. 远程访问（远程办公）——出差员工／家庭用户通过 Internet 安全接入公司内网；
  2. 内部网络互联（站点到站点）——总部与分支机构通过公用网互联，替代昂贵的专线；
  3. 与合作伙伴互联（Extranet）——向供应商、客户开放部分内网资源。

两种主流方案：IPSec VPN（厂商提供、基于用户设备，用户自己建）与 MPLS VPN（运营商提供、基于网络，用户租用）；此外还有面向小企业的 SOHO 型安全网关方案（网关 + 客户端 + 安全管理中心，一般支持 30 个以下用户）。

12. 简述广域网中的路由选择机制。

广域网的路由选择由路由器 + 路由表共同完成，机制可拆成五步：

  1. 建表——路由表通过直连路由（自动）、静态路由（手工）、缺省路由、动态路由（协议自动学习） 四种方式产生，每个表项包含掩码、目标地址、下一跳地址、标志、引用计数、使用、接口 7 个字段；
  2. 收包排队——分组到达路由器后排入等待处理队列，按**"先来先出"**处理；
  3. 提取目标地址查表——按 直接交付 → 特定主机交付 → 特定网络交付 → 默认交付 的顺序逐项匹配（越具体越优先，即最长掩码匹配）；
  4. 多源选优——同一目的网络有多条路由时，先比路由优先级（0~255，值小者优）：直连 0、静态 1、EBGP 20、OSPF 110、RIP 120、IBGP 200；只有完全相同的路由才比较优先级，不同掩码（如 /16 与 /24）同时入表、不比较；
  5. 转发或丢弃——选定最佳路径的下一跳后从对应接口转发；若下一网络允许的包长更小则先分段；若无匹配且无缺省路由，则丢弃并向源端回送 ICMP 不可达报文。

动态维护：网络拓扑变化时，动态路由协议自动交换路由信息、更新路由表；缺省路由也可由协议动态产生（如 OSPF 的 Stub 区域）。

13. 简述三层交换机的工作过程。

三层交换机是具有部分路由器功能的交换机，核心是 "一次路由，多次转发"：

（1）判断同网段——源节点用自己的 IP 与子网掩码计算网络地址，与目的地址比较，判断是否在同一网段。

（2）同网段：走二层

  1. 若不知道目的 MAC，发送 ARP 请求，目的主机返回 MAC 地址；
  2. 源节点用该 MAC 封装数据帧发给交换机；
  3. 交换机启用二层交换模块，查 MAC 地址表，把帧转发到相应端口。

（3）跨网段：首次走三层

  1. 在流缓存表中查找有无对应 MAC 地址；
  2. 没有则把数据帧封装为数据包，送给源节点的默认网关——即三层交换机的路由模块；
  3. 路由模块查路由表，确定通向目的网络的路由，从对应端口转发；
  4. 同时把目的 MAC 与转发端口的对应关系写入流缓存表。

（4）后续：回到二层

以后同一目的的数据帧，由二层交换模块直接按流缓存表转发，不再经过三层路由——这就是"一次路由，多次转发"。由于在第二层即被转发，省去了帧与包相互封装、转换的时间，减小了网络延时。

（5）内部结构——三层交换机实质上是一个增加了路由模块的二层交换机：路由模块负责路由选择、维护路由表、分组转发（软件完成）；二层交换结构负责按 MAC 转发、维护 MAC 与端口对应表、VLAN 划分（硬件完成规律性转发）。

14. 路由器、三层交换机、硬件防火墙都是网络层设备，它们有什么异同点？

相同点：

  1. 都工作在网络层（第三层），都能识别和处理 IP 数据包；
  2. 都具备连接不同网络／网段的能力，都能隔离广播域；
  3. 都维护某种"表"——路由器维护路由表，三层交换机维护路由表 + 流缓存表 + MAC 地址表，防火墙维护状态连接表 + 安全策略表；
  4. 都可以基于 IP 地址做转发控制，都能在一定程度上提升网络安全性。

不同点：

比较项路由器三层交换机硬件防火墙
核心目的连接不同网络、选择最佳路径加快局域网内部数据交换边界访问控制、保障内网安全
转发实现主要靠软件（CPU + 路由表）规律性转发由硬件（ASIC）完成，路由计算由软件转发不是主要目的，先检查策略再放行
处理速度慢（要把数据升到网络层）快（二层转发为主，一次路由、多次转发）中等，状态检测会降低速度
端口与接口端口少，有广域网接口（Serial、E1 等）端口多（24／48 个以太口），只有局域网接口端口少，分内网口／外网口／DMZ 口
功能丰富度最丰富——NAT、ACL、VPN、QoS、多种路由协议、广域网封装较简单——VLAN、静态／动态路由、ACL，不支持复杂广域网协议安全功能最强——包过滤、代理、状态检测、入侵检测、VPN、内容过滤
典型位置网络出口、主干网与子网之间大楼／园区核心与汇聚层内外网边界（DMZ 前）
价格较高按端口计，单位端口成本低较高（硬件 + 软件授权）

一句话总结：路由器"连",三层交换机"快",防火墙"守"——三者都站在网络层，但分工不同：路由器负责跨网络选路，三层交换机负责网内高速转发，硬件防火墙负责边界把关。
