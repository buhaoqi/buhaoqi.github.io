## 知识点

### 1.本项目要学什么？

**项目导读**：曾经出现以及目前仍在使用的广域网连接主要包括：**电话网络、X.25 网络、综合业务数字网、光配线网络**等，这些具体的广域网在**设备使用、连接方式、拓扑结构、带宽速率**等方面**各有特点**。**虚拟专用网络**（Virtual Private Network，**VPN**）是一种**利用公共网络（主要是互联网）** 将**多个私有网络或网络节点**连接起来组成的**私有专用网络**。

| 目标类别 | 内容 |
|----------|------|
| **知识目标** | ① 了解**广域网连接方式的发展历程**；② 理解**电话网、综合业务数字网、数字数据线路**的连接方式及特点；③ 熟悉**光配线网络**的连接方式；④ 了解 **VPN 的应用场景**；⑤ 理解**保障 VPN 安全性**的方法；⑥ 熟悉**实现 VPN 的解决方案** |
| **能力目标** | ① 掌握各种广域网连接的**特点**；② 掌握**电话网、光配线网络**的设备使用；③ 了解 **ISDN 和 DDN 线路**的使用特点；④ 掌握 **VPN 安全性**的实现；⑤ 掌握 **VPN 解决方案** |
| **素质目标** | ① 规范学生对各种广域网连接的理解；② 通过对典型广域网连接的认识，增强分析、应用广域网的能力；③ 规范学生对 **VPN** 的全面认识；④ 通过对 VPN 安全性的认识，增强网络使用中的安全防范意识 |

**任务描述**：广域网作为一种**跨地区的数据通信网络**，一般使用**公共传输网络**作为信息传输平台。公共传输网络的**内部结构和工作机制用户并不关心**，用户关心的是**公共传输网络提供的接口**——如何实现**和公共传输网络之间的连接**，并通过公共传输网络实现**远程端点之间的报文交换**。

### 2.公共传输网络的两类划分

**发展脉络**：传统的广域网一般采用**存储-转发分组交换技术**，但目前**帧中继和 ATM 快速分组技术**也开始大量使用。如果拥有主机资源的用户需要联网，只要**遵循子网所要求的接口标准**，**提出申请并付一定的费用**，就可接入该通信子网，利用其提供的服务来实现对特定资源子网的通信任务。

**目前提供公共传输网络服务的单位主要是电信部门。公共传输网络可以分成两类**：

| 类别 | 典型网络 | 交换特点 |
|------|----------|----------|
| **电路交换网络** | **公共交换电话网 PSTN**、**综合业务数字网 ISDN** | 通信期间**独占**一条通路（ISDN 另有分组交换功能） |
| **分组交换网络** | **X.25 分组交换网**、**帧中继网**、**ATM 网** | **存储-转发**，按分组/信元逐段转发 |

**记忆法**：**电路交换 = 打电话（先占线再说话）**；**分组交换 = 寄快递（一站一站转）**。

### 3.公共交换电话网（PSTN）

**定义**：**公共交换电话网**（Public Switched Telephone Network，**PSTN**），即通常说的**固定电话网络**。它最初的设计目的是**提供电话通信服务**，是**以电路交换技术为基础**的、用于传输**模拟语音信号**的网络；**经过信号调制后**，还可提供**非语音的数据通信服务**。

**（1）分级交换与线路构成**

- 由于**接入点众多、覆盖范围大**，PSTN 采用**分级交换**方式；
- 最初的 PSTN **全部采用模拟线路**组成；近年来经过不断改造，目前**干线和交换机已普遍采用数字传输和交换技术**，而**数量巨大的本地线路（也称用户环路）基本上仍采用模拟线路**。

**（2）为什么必须用 Modem**

由于 PSTN 的**本地线路是模拟的**，因此当两台计算机通过 PSTN 传输数据时，**中间必须经双方的 Modem 拨号连接**，实现计算机上的**数字信号**与线路上**模拟信号**的相互转换。

**图 7-6 解读**：**PC → 调制解调器 → PSTN（云）→ 调制解调器 → PC**——两端各一个 Modem，中间是电话网，这就是最典型的"拨号上网"。

**（3）PSTN 的五个局限**

| 局限 | 说明 |
|------|------|
| **无差错控制** | PSTN 的电路交换**只是物理层的一个延伸**，在 PSTN 内部**并没有上层协议进行差错控制**，**线路的传输质量较差** |
| **带宽有限** | 带宽受话音通道限制 |
| **交换机无存储功能** | 不能做存储-转发，只能"占线直通" |
| **速率上限低** | 通过 PSTN 进行数据通信的**最高速率不超过 56kb/s** |
| **频率范围窄** | 工作时所使用的**频率范围为 0~3.5kHz**，当**更高的频率接入交换网时会被过滤掉** |

**结论**：**使用 PSTN 实现计算机之间的数据通信是最廉价的**，但 **PSTN 只能用于对通信质量要求不高的场合**。

**其他细节**：PSTN 通常以**铜线**连接交换机与用户，近年来**光纤代替了铜线**。

**考点提示**：PSTN 三件事必背——**电路交换 + 模拟本地环路 + 必须 Modem**；三个数字：**56kb/s**、**0~3.5kHz**、**物理层延伸（无差错控制）**。

### 4.X.25 分组交换数据网

**（1）概述**

**X.25 分组交换数据网**，也称**公用数据网（PDN）**，是在 **20 世纪 70 年代**由**国际电报电话咨询委员会 CCITT** 制定的"**在公用数据网上以分组方式工作的数据终端设备 DTE 和数据电路设备 DCE 之间的接口**"，并正式成为**国际标准**，它是**最早被广泛应用的广域网技术**。

**特点总述**：这种分组交换数据网是广域网中的重要传输系统，其特点是**传输过程出错少、线路利用率高**。

**标准化过程**：为了让用户设备与 PDN 的连接标准化，**国际电信联盟委员会 ITU-T** 制定了 **X.25 规程**，它定义了**用户设备和网络设备之间的接口标准**，所以习惯上称 **PDN 为 X.25 网**。X.25 实际上包括相关的**一组协议**，如 CCITT **X.3、X.28、X.29、X.75** 等。

**关键定位**：X.25 协议是一个**面向用户接入 PDN 的接口规范**，是**公用数据网对于外部用户提供的标准界面**，它**不涉及网络内部的具体实现**，网络内部的具体实现由各个网络自己决定。

**（2）X.25 网的五大特点**

总评：X.25 网**通信成本低**，在**通信可靠性和灵活性**方面有很好的优势，但其**网络吞吐量和传输速率存在一定限制**。

| 特点 | 具体内容 |
|------|----------|
| **① 可以接入不同类型的用户设备** | 由于 X.25 网内各节点具有**存储-转发能力**，并向用户设备提供了**统一的接口**，从而使**不同速率、编码类型和传输控制规程**的用户设备都可以接入 X.25 网，并可以**相互通信** |
| **② 可靠性高** | X.25 网由**三层协议**组成，网络具有**动态路由**功能及**复杂、完备的误码纠错**功能；在**分组层**为用户提供了可靠的**面向连接的虚电路服务**，在**链路层**上也提供**流量控制和差错控制**机制；网内**每个节点交换机至少与另外两个交换机相连**，当一个中间交换机出现故障时，能**改变路由、不影响数据传输** |
| **③ 多路复用** | 当用户设备以**点对点方式**接入 X.25 网时，能在**单一物理链路上同时复用多条逻辑信道（即虚电路）**，使每个用户设备能**同时与多个用户设备**进行通信 |
| **④ 流量控制和拥塞控制** | 当某节点输入信息量过大、超过其承受能力时会**丢失分组**，丢失的分组需要**重传**，而重传会**加重网络负担**，最终导致**网络性能下降**。X.25 网采用**滑动窗口技术**实现流量控制，并用**拥塞控制机制**防止拥塞事件的发生 |
| **⑤ 点对点协议** | X.25 协议是**点对点协议**，**不支持广播方式** |

**（3）X.25 的三层协议**

**为什么用三层**：X.25 网是广域网中使用最广泛的协议标准，分组交换网**动态地为用户传输的信息流分配带宽**，解决了**突发性、大信息流**的传输问题；它同时可对传输的信息进行**加密和差错控制**——虽然**错误检测和相互之间的确认应答浪费了部分带宽**，使**报文传输延迟增加**，但对**早期可靠性较差的物理传输线路**来说，这是**一种提高报文传输可靠性的有效手段**。

| 层次 | 协议/内容 | 作用 |
|------|-----------|------|
| **物理层** | 协议是 **X.21** | 用于**定义主机与物理网络之间的物理、电气、功能以及过程特性** |
| **链路层** | 一般采用**高级数据链路控制协议 HDLC**（High-Level Data Link Control） | 描述**用户主机与分组交换机之间数据的可靠传输**，包括**帧格式定义、差错控制**等 |
| **分组层**（也称**网络层**） | — | 描述**主机与网络之间的相互作用**，主要解决**分组定义、寻址、流量控制以及拥塞控制**等问题；主要功能是**允许用户建立虚电路**，然后在已建立的虚电路上发送**最大长度为 128 个字节**的数据报文，使报文**可靠、按顺序**到达目标端 |

**（4）X.25 的虚电路类型**

**X.25 是面向连接的**，它支持两种虚电路：

| 类型 | 建立方式 | 特点 |
|------|----------|------|
| **交换式虚电路**（SVC） | **发送端向网络发送请求与目标端进行连接时建立** | 一旦建立，就可以在连接上发送数据，**可以保证数据正确、按顺序到达**目标端 |
| **永久式虚电路**（PVC） | 由双方**事先约定**、长期存在 | 无需每次建立，相当于"固定通道" |

**流量控制**：X.25 同时提供**流量控制机制**，以**防止快速的发送方淹没慢速的接收方**。

**（5）X.25 网的互联方案**

X.25 分组交换网络可用于**局域网之间互联**，构成更大规模的广域网。经常采用的互联方案有两种：

| 方案 | 做法 | 适用范围 |
|------|------|----------|
| **① 路由器 + 网关** | 采用**路由器和网关同时连接 X.25 和本地局域网** | 适合**规模较大、多种协议共存**的网络 |
| **② 计算机充当路由器** | 采用**一台计算机作为路由器**，安装相应的 **X.25 网卡和路由软件** | 适用于**中小规模、协议比较少**的网络 |

**适用场合**：由于 X.25 分组交换网络是在**早期低速、高出错率的物理链路**基础上发展起来的，其特性**已不适应目前高速远程连接的要求**，因此一般**只用于要求传输费用少、而远程传输速率要求又不高**的广域网环境。

### 5.综合业务数字网（ISDN）

**（1）为什么会出现 ISDN**

随着计算机技术与通信网络技术的迅速发展，除传统的电话业务外，社会对**数据传送、视频会议、电子信箱、可视电话**等各种**非语音业务**的需求急剧增长，出现了一种可把**包括语音和非语音在内的所有业务综合到一个网中**进行**传输、交换和处理**的数字网络——用户**只需要一对电话线**，就可以同时享有**语音、数据、图像**等多种媒体的数字通信服务，这种数字网络被称为**综合业务数字网**（Integrated Services Digital Network，**ISDN**）。

**但**：由于**非对称数字用户线路（ADSL）** 等其他**价格更低廉、性能更优良、接入更方便**的技术出现，**ISDN 被逐渐取代**。

**（2）ISDN 的特点**

ISDN 是 **CCITT 组织开发的一组标准**，这些标准可以**将用户设备连接到网络**，使之能用**数字形式同时处理声音、数据和图像**等信息。

**三个特点**：

1. 具有**标准开放的用户/网络接口**；
2. 支持**端到端的数字连接**；
3. 提供**通信业务自动识别**的特点。

**最突出的特点**：具有**综合业务的功能**，可以**同时传送电话的语音信息与计算机的数字信息**，**克服了 PSTN 拨号连网方式"电话通话与网络连接不能同时进行"的不足**。

**（3）ISDN 的五项功能（图 7-7）**

| 功能 | 内容 |
|------|------|
| **① 本地连接功能** | 连接**本地交换机或其他类似设备**，完成**用户认证、网络信令、计费**等功能 |
| **② 电路交换功能** | 提供**不低于 64kb/s** 的电路交换连接。ISDN 中电路交换功能的**基本传输速率是 64kb/s**，根据用户需要也可提供 **2 × 64kb/s** 和 **384kb/s** 的**中速**电路交换功能，以及 **1536kb/s** 和 **1920kb/s** 的**高速**电路交换功能 |
| **③ 分组交换功能** | 由**分组交换数据网**为 ISDN 提供分组交换功能 |
| **④ 专线功能** | 指 ISDN **可以不利用网内的交换功能**，在终端间建立**永久或非永久连接** |
| **⑤ 共路信令功能** | 共路信令**也称公共信道信令**，它将**信令通道与信息通道分离**，将若干条电路的**信令集中在一条专门用于传送信令的通道**上传输，以完成**呼叫等各种控制功能**。ISDN 的信令**都采用共路信令方式** |

**图 7-7 解读**：两侧各一台 **TE**（终端设备），一端连接**用户主机**，中间经 **ISDN 交换机** 互联；云内四个功能——**分组交换功能、电路交换功能、无交换连接（专线）功能、公共信道信令功能**；虚线上标注**用户—网络信令**（两侧）与**用户—用户信令**（贯穿两端）。

**（4）ISDN 的三种通道**

ISDN 标准定义了**三种通道类型**：

| 通道 | 名称 | 作用 | 速率 |
|------|------|------|------|
| **B 通道** | **信息通道**（Bearer） | 主要用来传输**各种各样的信息流**；以**端到端**的方式传输，是**基本的用户通道**。若传输速率不超过 64kb/s，B 通道就以**全双工**方式传送数字信息（如数字数据、数字化语音或其他低速率信息） | **64kb/s** |
| **D 通道** | **信令通道**（Delta） | 主要传送**用于控制用户和网络的信令信息**，功能主要是**为 B 通道传输信令**，也可用于**低速率的数据传输** | **16kb/s 或 64kb/s**（按用户需要设置） |
| **H 通道** | **混合通道** | **既可以传送信息流，也可以传送控制信息** | 较高（由若干 B 通道合并） |

**（5）ISDN 的两种接口**

**ITU-T 规定了 ISDN 的基本速率接口（BRI）和基群速率接口（PRI）** 两种类型的接口结构，每个类型接口适用于**不同用户的需求层次**，每个类型接口**都包括一个 D 通道和若干个 B 通道**。

**① 基本速率接口（BRI）**

- 定义了**一个包含两个 B 通道和一个 16kb/s 的 D 通道（2B+D）** 的数字管道；
- 两个 B 通道都是 **64kb/s**，**总共是 144kb/s**；
- **BRI 服务本身需要 48kb/s 的开销**，因此 **BRI 需要一个 192kb/s 的数字管道**；
- **注意**：两个 B 通道和一个 D 通道是**一个 BRI 接口所能支持的最大通道数**，但这三个通道**并不一定要分开使用**——**一个 BRI 所有的 192kb/s 数字管道可以全部用来传送一路信号**。

**② 基群速率接口（PRI）**

- 定义了由 **23 个 B 通道和 1 个 64kb/s 的 D 通道**组成的数字管道；
- 23 个 B 通道每个都是 **64kb/s**，加上 1 个 **64kb/s** 的 D 通道，**总共是 1.536Mb/s**；
- **PRI 服务本身需要 8kb/s 的开销**，所以 **PRI 需要 1 个有 1.544Mb/s 传输速率**的数字管道；
- **23 个 B 通道和 1 个 D 通道是一个 PRI 所能包含的最大通道数**，也就是说，**一个 PRI 可以支持多达 23 个源站点和目标站点之间的全双工传输**。

**两个接口的算法对照表**：

| 接口 | 结构 | 有效载荷 | 开销 | 线路总速率 |
|------|------|----------|------|------------|
| **BRI** | **2B + D** | 2 × 64 + 16 = **144kb/s** | **48kb/s** | **192kb/s** |
| **PRI** | **23B + D** | 23 × 64 + 64 = **1.536Mb/s** | **8kb/s** | **1.544Mb/s** |

**（6）ISDN 的接入方式**

**① ISDN 用户/网络设备接口**：是**用户设备与通信网的接口**。ISDN 要求**使用少量的兼容接口来实现大量的应用**，即要求用户网络接口具有**通用性、可移动性和隔离性**（指**终端和网络可独立地开发，不受对方的限制**）。ISDN 网络支持的用户终端设备包括 **ISDN 设备和非 ISDN 设备**，**非 ISDN 设备经过 ISDN 终端适配器转换后**也可以接入 ISDN 网络。

**② ISDN 接入**：利用不同的 ISDN 网络终端设备可以采用不同的方式接入因特网——可以利用 **ISDN 网卡和 NT1 接入**、**NT1 和 TA 接入**及 **ISDN 路由器**等接入方式。

| 设备 | 全称/作用 |
|------|-----------|
| **NT1** | 网络终端 1，是 **ISDN 应用中必备的设备**，主要完成**接口转换功能** |
| **TA** | **终端适配器**，主要完成**速率适配、信号及协议转换**，使**非标准 ISDN 终端**能接入 ISDN 网络的终端接口 |

### 6.数字用户线路（DSL）

**（1）基本思想**

**数字用户线路**（Digital Subscriber Line，**DSL**）是通过**传统的电话线路**进行数字通信，即**在电话线上同时进行数据收发**，实现**全双工数据传输**。

**为什么被广泛应用**：DSL 连网方案**无需对电话线路进行改造**，可以**充分利用电话线路**，**大大降低额外开销**，而且可以提供**更高速率的互联网接入**。

**（2）靠什么把电话和数据分开**

DSL 技术通过采用**频分复用技术**把电话线分成了**电话、上行数据和下行数据三个相对独立的信道**，从而**避免了相互之间的干扰**。

**（3）两大类 DSL**

根据**上、下行数据的传输速率**和**具体的实现技术**，DSL 技术分为两类：

**① 对称 DSL 技术**——**上、下行数据传输速度相同**，主要包括 **HDSL、SDSL、MVL 及 IDSL** 等：

| 技术 | 全称 | 速率与距离 |
|------|------|------------|
| **HDSL** | **高比特率 DSL** | **传输速率快**，支持 **N × 64kbps** 各种速率（N 为信道数量），**无需信号放大设备**即可实现 **3.6 公里以内**的正常数据传输 |
| **SDSL** | **单线 DSL** | **只使用 HDSL 的一对线缆**，可提供**双向高速、可变速率的连接**，速率范围从 **160kbps 到 2.084Mbps**，**最大传输距离可达 3 公里** |
| **MVL** | **多路虚拟 DSL** | 利用**一对线缆**实现**高速数据接入**，可进行**高密度安装**，能够利用与 **ISDN 技术相同的频率段**，**有效传输距离可达 7 公里左右** |
| **IDSL** | **ISDN DSL** | 基于 ISDN 技术的对称 DSL（教材仅列名） |

**② 非对称 DSL 技术**——**上、下行数据传输速度不同**，适用于**对双向带宽要求不一致**的应用，如 **Web 浏览、多媒体点播及信息发布**等，主要有 **ADSL、RADSL 及 VDSL** 等：

| 技术 | 全称 | 下行速率 | 上行速率 | 距离/其他 |
|------|------|----------|----------|-----------|
| **ADSL** | **非对称 DSL** | 高达 **8Mbps** | **1Mbps** | **有效传输距离为 3 至 5 公里** |
| **RADSL** | **速率自适应 ADSL** | **1.5Mbps 到 8Mbps** | **16Kbps 到 640Kbps** | 是 ADSL 的技术改进，可**自动调整 ADSL 连接的带宽**以适应实际传输需要；**支持同步和非同步传输方式** |
| **VDSL** | **超高速 DSL** | 最大 **55Mbps** | 可达 **19.2Mbps** | 是 ADSL 的**快速版本**，**平均传输速率可比 ADSL 高出 5 至 10 倍** |

**一句口诀**：**对称看"上下一样"（HDSL/SDSL/MVL/IDSL），非对称看"下快上慢"（ADSL/RADSL/VDSL）**；速率从小到大：**ADSL → RADSL → VDSL**。

**考点提示**：题干出现"**上行 1Mbps、下行 8Mbps、3~5 公里**"→ **ADSL**；"**55Mbps、19.2Mbps**"→ **VDSL**；"**用一对线、与 ISDN 同频段、7 公里**"→ **MVL**。

### 7.数字数据网（DDN）

**（1）简介**

**数字数据网**（Digital Data Network，**DDN**），是**利用数字信道传输数据信号**的数据传输网，它可向用户提供**专用的数字数据传输信道**，为用户**建立专用数据网**提供条件。它的**传输介质**有**光缆、数字微波、卫星信道**以及用户端可用的**普通电缆和双绞线**。

**三个关键机制**：

1. **半永久性数字连接**——DDN 向用户提供**半永久性数字连接**，**中间不进行复杂的软件处理**，因此**延时较短**，避免了网络中**传输时延大且不固定**的缺点；
2. **交叉连接装置**——采用**交叉连接装置**，可根据用户需要在**约定的时间内接通所需的带宽线路**；
3. **计算机控制**——**信道容量的分配和接续在计算机控制下进行**，具有**极大的灵活性**，使用户可以开通**种类繁多的信息业务**。

**为什么用数字信道**：对那些要求**流量大、传输质量高、速度快**的用户来讲，DDN 技术可以满足要求。过去大部分数据主要采用**模拟信道**传输（将数据信号**调制到音频频段**后传输），由于**调制解调器的技术限制**以及**实线传输的线间干扰、电平衰耗**的影响，模拟传输的**距离、质量、速度**都不能满足高速数据传输的要求；采用**数字信道**传输数据信号则**克服了模拟传输的弱点**，**大大提高了传输质量**。DDN 把**数字通信技术、计算机技术、光纤通信技术以及数字交叉连接技术**有机地结合在一起，提供了**高速度、高质量**的通信环境。

**（2）DDN 的五个特点**

| 特点 | 内容 |
|------|------|
| **① 同步数据传输网，不具备交换功能** | DDN 是**同步**的，**不具备交换功能**（只做"半永久"的交叉连接） |
| **② 高质量、高速度、低时延** | 数据传输过程具有**高质量、高速度、低时延**的特点 |
| **③ 透明传输** | **透明地**进行数据传输，可以支持**数据、图像、声音**等多种业务 |
| **④ 传输安全可靠** | DDN 通常采用**多个路由器的网状拓扑结构**，因此中继传输段中**任何一个节点发生故障、网络拥塞或线路中断**，只要**不是最终连接用户的线路**，节点均会**自动迂回路由**，而**不会中断用户的端到端数据通信** |
| **⑤ 网络运行管理简便** | DDN 将**检错、纠错功能交由智能化程度高的终端**来完成，因此**简化了网络运行管理和监控**的内容 |

**考点提示**：DDN 最容易与分组网混淆的地方——**DDN 没有交换功能**（不存储-转发、不逐段检错），它是**"半永久的数字专线"**；差错纠正交给**终端**而不是网络。

### 8.光配线网络（ODN）

**背景**：随着通信线路由**以铜线为基础**的线缆向**以光纤为基础**的线缆转变，网络连接技术也发生了很大的变化，**目前远程网络连接也以光纤连接为主**。

**（1）四个缩写的含义（必背）**

| 缩写 | 全称 | 含义与作用 |
|------|------|------------|
| **FTTH** | **光纤到户**（Fiber To The Home） | 是**由政府推动、电信部门实施**的工程，主要目的是**改善用户网络接入带宽、提高网络服务质量**；采用光纤通信的传输方法，可以**直接把光纤连接到用户所需的位置** |
| **ODN** | **光配线网络**（Optical Distribution Network） | 是**基于 PON 网络设备的 FTTH 光缆网络**，其作用是**为 OLT 和 ONT 之间提供光传输通道** |
| **PON** | **无源光纤网络**（Passive Optical Network） | ODN 所依托的网络设备体系，"**无源**"指中间不使用有源放大设备 |
| **OLT** | **光线路终端**（Optical Line Terminal） | 用于**连接光纤干线**的终端设备（局端） |
| **ONT** | **光网络终端**（Optical Network Terminal） | 可以完成**光电转换**后**直接连接用户终端设备**（用户端） |

**图 7-8 的信号流向**：**PON → OLT → 光分配点 → 光接入点 → ONT → 用户设备**，其中 OLT 到 ONT 之间就是 **ODN**（图中标注"FTTH ODN 基本结构"）。

**（2）ODN 的三种光缆**

在进行光纤线路连接的过程中，图 7-8 中的**光分配点一般放置在光交换箱中**，**光接入点放置在光配线箱中**。ODN 连接时用到三种光缆：

| 光缆 | 范围 | 特点 |
|------|------|------|
| **① 主干光缆**（馈线光缆） | **从 OLT 到光交接箱**之间的那段光缆 | 一般使用**室外型光缆**，**光缆纤芯数比较多**，**少则上百芯，甚至上千芯**；敷设通常包括**管道、直埋和架空**方式 |
| **② 配线光缆** | **从光交接箱到光配线箱**之间的光缆 | 一般选用**室外型的光缆**；在城市的**楼与楼之间**，经常能看到沿着**现有管道或外墙壁**绑扎整齐牢固的配线光缆 |
| **③ 入户光缆** | **连接到用户家中**的**单芯或多芯皮线光缆** | 一般 FTTH 入户光缆采用**蝶形光缆**，通常具备**弯曲性能好、抗侧压、抗扭曲、结构简单、方便开剥**等优点，便于在室内环境下通过**竖井、暗管、明管、线槽或室内钉固**方式敷设 |

**一句串起来**：**OLT（局端）——主干光缆——光交接箱——配线光缆——光配线箱——入户光缆——ONT（用户）**。
