## 知识点

### 1.本模块与项目一要学什么？

**模块七 学习要点**：

1. 掌握**广域网组网的特点**；
2. 掌握**路由器与网关的功能及使用方式**；
3. 了解 **PSTN、X.25、ISDN、DDN**；
4. 了解**虚拟专用网 VPN**。

**重点难点**：**路由器的功能及使用特点**；**网关的概念及实现**。

**项目导读**：**广域网（WAN）是互联网的一部分**，用于**局域网（LAN）之间**或**单个用户和局域网之间**的**远距离连接**。WAN 能跨越多个分散的地区，通常使用**本地和长途传输设备**。广域网通常跨接**很大的地理范围**——从**几十公里到几千公里**，能够连接**多个城市或国家**，或**横跨几个洲**并能提供远距离通信，形成**国际性的远程网络**。组网时一般需要**向运营商购买不同的广域网连接**，以使本地网络能够通过广域网访问远程网络、用户等。

| 目标类别 | 内容 |
|----------|------|
| **知识目标** | ① 了解广域网的**特点及组成**；② 理解**网状、混合型拓扑结构**；③ 熟悉**面向连接的虚电路**和**面向无连接的数据报**服务；④ 了解广域网的**远程组网方式**；⑤ 理解**点对点远程连接**方法；⑥ 理解**分组交换式**远程连接方式 |
| **能力目标** | ① 掌握面向连接的**虚电路服务**和面向无连接的**数据报服务**；② 了解**广域网与局域网的主要区别**；③ 掌握**点对点远程连接**方法；④ 掌握**分组交换式远程连接**方式；⑤ 了解远程连接时**中间设备的种类及作用** |
| **素质目标** | ① 规范学生对于广域网的理解；② 通过对广域网与局域网**拓扑结构**的对比认识，增强独立思考能力；③ 规范学生对于各种广域网**组网方式**的理解；④ 通过对**远程组网途径**的认识，增强对远程网络互连方式的认识 |

**一句话勾住本任务**：**局域网解决"一栋楼里怎么连"，广域网解决"相隔千里怎么连"**——所以它必须依赖**电信运营商的公共网络**和**分组交换**技术。

### 2.广域网的定义与两种类型

**定义**：**广域网**（Wide Area Network，**WAN**）指**使用本地或公用数据网络**，将分布在**不同国家、地域至全球范围内**的各种**局域网、计算机、终端**等设备，通过**互联设备**连接而形成的**大型计算机网络**。

**两种类型**：

| 类型 | 含义 | 典型网络 |
|------|------|----------|
| **第一种** | **电信部门提供的电话网或数据网络** | **公共交换电话网（PSTN）**、**分组交换数据网（X.25）**、**公用数字数据网（DDN）** 等，这些网络可以向用户提供**世界范围的数据通信服务** |
| **第二种** | 将分布在**同一城市、国家、洲，甚至几个洲**的局域网，通过**电信部门的公用通信网络**互联而组成的**专有广域网** | 企业/行业自建的跨地域专网 |

**分布范围量级**：由于广域网分布范围很广，一般为 **10km、100km 或 1000km 以上**的数量级，所以通常广域网中的主机可以和局域网**使用多种连接介质**进行连接。

**考点提示**：题干问"广域网通常由谁建设"→ **电信部门**；问"广域网属于谁"→ 第一种是**公用**（运营商建、大家用），第二种是**专有**（企业建在公用网之上）。

### 3.广域网的五大特点

**（1）由"节点交换机 + 链路"互联组成，距离没有限制**

广域网由一些**节点交换机**以及**连接这些交换机的链路（通信线路）**互联组成，**距离没有限制**。

**（2）节点交换机是智能型通信设备**

这些节点交换机实际上是**配置了通信协议软件的专用计算机**，是一种**智能型通信设备**。

**（3）采用存储-转发方式，基于分组交换技术**

除了**传统的公共交换电话网**之外，目前**大部分广域网都采用存储-转发的方式进行数据交换**，也就是说，**广域网是基于分组交换技术的**。

**（4）多链路冗余，提高可靠性**

为了提高网络的可靠性，**节点交换机同时与其他多个节点交换机相连**，目的是在两个节点交换机之间提供**多条冗余的链路**，这样当某个节点交换机或线路出现问题时，**不至于影响整个网络运行**。

**（5）一般由电信部门提供，故称"公用数据网"**

在广域网内，**节点交换机和它们之间的链路一般由电信部门提供**，网络由**多个部门或多个国家联合组建**而成，实现**整个网络范围内的资源共享**。由于广域网一般都是**开放**的，因而通常也被称为"**公用数据网**"（Public Data Network，**PDN**）。

**广域网"节点交换机"与局域网交换机的对比**（教材特意说明的易混点）：

| 对比项 | 局域网交换机 | 广域网**节点交换机** |
|--------|--------------|----------------------|
| **基本工作原理** | 相同（都做转发） | 相同 |
| **本质** | 二层硬件设备 | **配置了通信协议软件的专用计算机** |
| **背板带宽** | 相对低 | **更高**（使用环境特殊） |
| **路由选择** | 一般不做（三层交换机除外） | **支持路由选择** |
| **安全机制** | 一般无 | **内置安全机制** |
| **计费功能** | 无 | **提供计费功能** |

**考点提示**：这个对比表是"广域网设备"与"局域网设备"最容易被混淆的地方——记住广域网节点交换机"**四多**"：**更多背板带宽、更多路由、更多安全、更多计费**。

### 4.广域网的拓扑结构：树型与网状

对广域网而言，**除具有局域网的拓扑结构外，还包括树型结构、网状结构等**。

**（1）树型结构（也称层次结构）**

**结构特征**：树型拓扑结构是**分级的集中控制式网络**；在树型结构的网络中，**任意两个结点之间不产生回路**，**每条通路都支持双向传输**（教材图 7-1：根部一台中心交换机，向下分支出多台交换机，叶子位置挂主机）。

**三个特点**：

1. **易于扩充**——树型结构可以延伸出**很多分支和子分支**，这些新节点和新分支都能**容易地加入网内**；
2. **故障隔离较容易**——如果某一分支的节点或线路发生故障，很容易将**故障分支与整个系统隔离开来**；
3. **叶节点对其上级根节点的依赖性大**——如果**根节点发生故障**，则该根节点**以下的网络不能正常工作**。

**适用场合**：树型结构适合于**区分主次或划分等级的、进行层次型管理的网络**，如**中国教育科研网络（CERNET）** 就是一种**树型拓扑**结构的网络。

**（2）网状结构（也称分布式结构）**

**结构特征**：在网状拓扑结构中，网络的**每个节点之间均有直接或间接的点到点的链路连接**（教材图 7-2：六个节点两两之间大量交叉连线，形成全互联的"网"）。

**五个优点**：

1. **网络可靠性高**——一般通信子网中**任意两个节点之间存在着两条或两条以上的通信路径**，当一条路径发生故障时，还可以通过**另一条路径**把信息送至节点；
2. **网络可组建成各种形状**，采用**多种通信信道、多种传输速率**；
3. **网内节点共享资源容易**；
4. 可以根据**网络数据的密集程度**进行线路的**信息流量分配**；
5. 可**选择最佳路径**，**传输延迟小**。

**两个缺点**：

1. **控制逻辑繁复，软件实现复杂**；
2. **线路费用高，网络不易扩充**。

**（3）混合型拓扑**

在广域网中也**广泛使用混合型拓扑**。由于广域网所覆盖的**地理范围较大**，所以**联网介质、线路等常常租用通信公司的既有线路**——这是"混合"的现实原因：不可能为每个节点新铺一条线。

**三种拓扑对比表**：

| 对比项 | **树型** | **网状** | **混合型** |
|--------|----------|----------|------------|
| **别名** | **层次结构** | **分布式结构** | — |
| **控制方式** | **分级集中控制** | **分散、多路径** | 两者结合 |
| **是否存在回路** | **无回路** | 多回路（冗余） | 视结构而定 |
| **可靠性** | 中（依赖根节点） | **最高** | 较高 |
| **扩充性** | **好**（易加分支） | **差**（不易扩充） | 较好 |
| **成本** | 较低 | **线路费用高** | 中（租用既有线路） |
| **典型实例** | **CERNET** | 国家骨干网、金融专网 | 企业跨地域网 |

**拓扑结构为什么重要**：一般来说，**拓扑结构会影响传输介质的选择和控制方法**，因而会影响**网上结点的运行速度**和**网络软件、硬件接口的复杂程度**。**网络的拓扑结构和介质访问控制方法是影响网络性能的最重要因素**，因此应根据实际情况选择最合适的拓扑结构，选用相应的网络适配器和传输介质，确保组建的网络具有较高的性能。

### 5.广域网的两级结构与常用公共网络系统

**两级结构**：广域网一般可分为**主干网**和**用户接入网**两部分。根据广域网的**类型**和**用户接入端线路**的不同，可以有**多种接入广域网的技术**。用户只要**遵循通信网络的接口标准**，**提出申请并支付一定的费用**就可接入该公共通信网。

**目前常用的公共网络系统**：

| 缩写 | 全称 | 特点（本模块后续会展开） |
|------|------|--------------------------|
| **PSTN** | **公共交换电话网**（Public Switched Telephone Network） | 最普及、按时间计费、速率低 |
| **X.25** | **分组交换数据网** | 早期分组网，逐段差错控制，速率低但可靠 |
| **DDN** | **数字数据网**（Digital Data Network） | 数字专线，速率稳定、时延小 |
| **Frame Relay** | **帧中继网** | 简化协议的高速分组网 |
| **ODN** | **光配线网络**（Optical Distribution Network） | 光纤接入的基础网络 |

### 6.广域网提供的两类服务

广域网可以提供**面向连接的服务**和**面向无连接的服务**：

| 服务类别 | 具体方式 | 所属网络 |
|----------|----------|----------|
| **面向连接** | **电路交换**方式 | **传统公共交换电话网** |
| **面向连接** | **虚电路交换**方式 | **分组数据交换网** |
| **面向无连接** | **数据报**方式 | **分组数据交换网** |

**一句话记**：**面向连接有"三次约定"（建链—传数据—拆链），面向无连接"随手就发"。**

### 7.面向连接的虚电路服务

**（1）三个阶段**

虚电路服务在双方进行通信之前，首先要**建立连接**：

1. **建立连接**：**源站发出一个请求报文分组**（该报文分组中要有**源站和目标站的全地址**），请求与目标站建立连接；当**目标站接受**这个请求后，将发回一个**报文分组作为应答**，这样双方就建立起一个**数据通路（即连接）**；
2. **传输数据**：双方开始传送信息；
3. **释放连接**：当双方通信完成之后，**还必须拆除这个建立的连接**。

所以采用虚电路服务就必须有**建立连接、传输数据和释放连接**这**三个阶段**。

**（2）虚电路号的作用**

**虚电路一经建立就要赋予其虚电路号**，它**反映信息的传输通道**。这样在**传输报文分组时，就不必再注明源站和目标站的全部地址**，从而**减少了通信量**。

**（3）与电路交换的本质区别——"虚"在哪里**

虚电路服务在传输数据时采用**存储-转发**技术，即某个节点**先把报文分组接收下来，进行验证**，然后再把该报文分组**转发**出去。

| 对比项 | **电路交换**（PSTN） | **虚电路**（分组网） |
|--------|----------------------|----------------------|
| **三阶段** | 有（建立、传输、释放） | **有**（建立、传输、释放） |
| **是否独占物理信道** | **通信期间自始至终占用一条端到端的物理信道**，**不允许其他用户使用** | **只是断续地占用一段一段的链路**（基于存储-转发的分组交换） |
| **用户感觉** | 真独占 | **好像**占用了一条端到端的物理通路，**实际上并非完全占用** |
| **"虚"的含义** | — | **不是真正独占的物理通路，故称"虚"电路** |
| **顺序与流量** | 天然有序 | **由网络保证报文分组按顺序到达**，且**网络负责端到端的流量控制** |

**考点提示**：问"虚电路为什么叫虚"→ 答"**通信期间并不完全独占端到端物理通路，只是断续占用一段段链路，用户感觉像独占**"。问"虚电路和电路交换的共同点"→ **都是三个阶段、都面向连接**。

### 8.面向无连接的数据报服务

**（1）工作方式**

分组交换数据网中提供**面向无连接的数据报服务**。这种服务方式的特点是：**主机可以随时发送数据**，**每个报文分组独立地选择路由**。

**（2）优点：不需预留资源**

报文分组经过的节点交换机**不需要事先为该报文分组保留资源**，而只需在**对分组进行传输时进行动态地分配信道资源**。

**（3）缺点：不能保证顺序，必须重组**

由于**每个报文分组走不同的路径**，所以数据报服务**不能保证先发送出去的报文分组一定先到达目标主机**，也就是说，这种数据报服务的报文分组**不一定能按原来顺序交给目标主机**。因此，**目标主机就必须对收到的报文分组进行缓冲，并且重新组装成报文**再传送给目标主机的应用系统。

**（4）缺点：拥塞时丢弃分组，服务不可靠**

当网络发生**拥塞**时，网络中的**某个节点交换机可能会将一些分组丢弃**，所以数据报的服务是**不可靠的**，它**不能保证服务质量**。

**（5）报文分组头的三个字段**

数据报服务的**每一个报文分组都有一个报文分组头**，它包含着一些控制信息，如**源地址、目标主机地址和报文分组号**等：

| 字段 | 作用 |
|------|------|
| **源地址、目标地址** | 可使**每个报文分组独立选择路由**所必需的信息 |
| **报文分组号** | 为了**使目标主机能对收到的报文分组进行重新排序组装**；但**这个报文分组号增加了网络传输的数据量** |

**考点提示**：数据报服务的"三不"——**不建连接、不保证顺序、不保证可靠**；对应的"一要"——**要主机自己缓冲重组**。

### 9.三种交换/服务方式总对比

| 对比项 | **电路交换** | **虚电路** | **数据报** |
|--------|--------------|------------|------------|
| **连接** | 面向连接（物理通路） | 面向连接（逻辑通路） | **无连接** |
| **是否三阶段** | **是** | **是** | **否** |
| **信道占用** | **完全独占** | **断续占用** | **动态分配** |
| **选路** | 建立时确定，全程不变 | 建立时确定，全程不变 | **每分组独立选路** |
| **顺序** | **保证** | **网络保证** | **不保证，主机重组** |
| **可靠性** | 高 | 较高（有流量控制） | **不可靠**（拥塞丢弃） |
| **额外开销** | 无分组头开销 | 只需**虚电路号** | 需**源/目的地址 + 分组号** |
| **典型网络** | **PSTN** | **X.25、帧中继** | **IP 网络** |

### 11.本任务速查表

| 考点 | 结论 |
|------|------|
| WAN 全称 | **Wide Area Network** |
| 覆盖范围 | **几十公里到几千公里**，量级 **10km / 100km / 1000km 以上** |
| 广域网组成 | **节点交换机 + 连接链路** |
| 节点交换机的本质 | **配置了通信协议软件的专用计算机** |
| 数据交换方式 | **存储-转发**，即**基于分组交换技术** |
| 广域网别名 | **公用数据网（PDN）** |
| 谁提供线路 | **电信部门** |
| 拓扑补充类型 | **树型**（层次）、**网状**（分布式）、**混合型** |
| 树型三特点 | 易扩充、故障隔离易、**依赖根节点** |
| 树型实例 | **CERNET** |
| 网状优点数 | **5 个**（可靠性高、形状多样、共享易、按流量分配、选路最佳） |
| 网状缺点 | **控制复杂、线路贵且不易扩充** |
| 两级结构 | **主干网 + 用户接入网** |
| 五个公共网络 | **PSTN、X.25、DDN、帧中继、ODN** |
| 两类服务 | **面向连接（电路交换/虚电路）、面向无连接（数据报）** |
| 虚电路三阶段 | **建立连接、传输数据、释放连接** |
| "虚"的含义 | **不独占端到端物理通路，只断续占用链路** |
| 虚电路号的用处 | **省去每包写全地址，减少通信量** |
| 数据报特点 | **随时发、独立选路、可能乱序、拥塞丢包、不可靠** |
| 数据报分组头 | **源地址、目标地址、报文分组号** |
