## 知识点

### 1.广域网有哪两种组网方式？

**任务描述**：广域网的组网方式主要有**两种**，即**点对点**和**分组交换式**的连接组网。这两种组网方式**各有特点**，在**拓扑结构、连接方式**等方面有所不同。

**教材原文一句话**：广域网的组网方式主要有两种：**点到点的连接**和**通过分组交换方式的连接**。

**为什么远程联网比局域网复杂**：若使用**多种本地设备或远距离设备**来连接网络，则**必须进行多方面的考虑**——本地设备的接口、远距离线路的类型、中间设备的转换能力、费用，都要一起算。

### 2.图 7-3：三种网络连接选择

从教材图 7-3 可知，组建广域网有**三条路可选**：

1. 用**调制解调器**通过**点到点的连接**组建广域网；
2. 用**专线**组建广域网；
3. 用**公共数据网的分组交换网络**连接构成广域网。

**图中出现的设备与线路**：

| 图中标注 | 位置/作用 |
|----------|-----------|
| **LAN**（左、右两端） | 需要互联的两个**局域网** |
| **WAN**（上方大椭圆） | 中间跨越的**广域网云** |
| **网桥/路由器** | 局域网**接入广域网**的**边界设备**（图中每条路径两端都有） |
| **调制解调器**（Modem） | 走**电话拨号线**时的**数模转换**设备 |
| **电话拨号线** | 图 7-3 上方那条路径，**借用电话网**传输数据 |
| **公共数据网**（云） | 中间的**分组交换网**，提供分组转发服务 |
| **数据服务单元/快捷服务单元** | 图中写作"**数据服务单元/快捷服务单元**"，即 **DSU/CSU**，是**用户设备与数字线路之间的接口设备**，做**信号整形、线路均衡、接入控制** |
| **专线** | 图 7-3 下方那条路径，**长期租用的固定线路**，不经过拨号 |

**三条路径的直观对照**：

| 路径 | 中间设备 | 线路性质 | 特点 |
|------|----------|----------|------|
| **上：电话拨号线** | **Modem — Modem** | **拨号**，按次/按时计费 | 只要有电话就能用，**速率低、建立连接慢** |
| **中：公共数据网** | **DSU/CSU — 公共数据网 — DSU/CSU** | **分组交换虚电路** | **按需占用、多用户共享**，费用与距离关系弱 |
| **下：专线** | **DSU/CSU — 专线 — DSU/CSU** | **固定租用** | **速率稳定、时延小、时刻在线**，**费用高** |

### 3.点对点（点到点）式连接

**教材原文**：若以**点对点连接**的方式组建广域网，有**两种情况**：

| 情况 | 做法 | 评价 |
|------|------|------|
| **① 全连通式网络** | **所有路由器节点互相连通**（任意两点之间都有一条专线） | **这种方式成本太高，也没有必要** |
| **② 网桥或 Modem 点到点连接** | 用**网桥或 Modem** 把两端连起来（教材图 7-4：**PC — Modem —（电话线）— Modem — PC**） | **实际常用** |

**为什么全连通"成本太高、也没有必要"**：

- **线路数按公式增长**：n 个节点全互联需要 **n × (n − 1) ÷ 2** 条链路——10 个节点要 **45** 条，100 个节点要 **4950** 条，费用与维护量**爆炸式上升**；
- **多数节点之间并无直接通信需求**：流量集中在少数方向上，为"偶尔一次"的通信铺一条专线**不划算**；
- 所以现实中**用公共数据网代替"每两点一条线"**——把全连通的负担交给运营商的分组网。

**一般情况**：**局域网使用网桥和路由器等接入设备进行网络互联。**

**图 7-4 的解读**（点到点的连接）：两台 **PC** 各接一个 **Modem**，两个 Modem 之间通过**电话线**相连——这是**最简单的远程点对点**，本质是"**把一段电话线当成一根网线用**"。

### 4.分组交换式的连接

**教材原文**：**路由器比网桥更常用于网络间的互联**（教材图 7-5）。通过**点到点网络并经由公共数据网的交换网络**，**路由器与远端路由器进行连接**。

**图 7-5 的解读**（路由器连接）：一侧是 **PC — Router**，另一侧是 **PC — Router**，两台路由器之间接入**公共数据网（云）**，数据由分组网内的节点交换机逐段转发。

**为什么"路由器比网桥更常用于网络间互联"**：

| 对比项 | **网桥** | **路由器** |
|--------|----------|------------|
| **工作层次** | **数据链路层** | **网络层** |
| **转发依据** | **MAC 地址**（物理地址） | **IP 地址中的网络号** |
| **地址规模** | MAC 地址**无结构**，转发表随主机数增长 | **网络号有层次**，一条表项代表一整个网段，表小 |
| **广播处理** | **转发广播**（广播域不隔离） | **不转发广播**，天然隔离广播域 |
| **异构互联** | 只能互联**同类型**局域网（MAC 网桥），LLC 网桥也受限 | 可互联**不同类型**的网络（以太网、DDN、帧中继等），**屏蔽差异** |
| **路径选择** | **无**，只有一条生成树路径 | **有**，可选**最佳路径**、支持多路径与策略路由 |
| **安全性** | 无 | 可做**访问控制、NAT、包过滤** |

**一句话**：广域网要跨越**多种介质、多种协议、多个运营商网络**，只有**工作在网络层的路由器**才能"**翻译 + 选路**"，网桥做不到。

### 5.两种组网方式对比

| 对比项 | **点对点连接** | **分组交换式连接** |
|--------|----------------|--------------------|
| **拓扑** | 点到点（一条链路两端） | 星型/网状（经公共数据网多跳转发） |
| **中间设备** | **Modem** 或**网桥/路由器**（直连） | **路由器 + 公共数据网的节点交换机** |
| **链路占用** | **独占**（专线或拨号期间独占） | **共享**（统计复用，按需占用） |
| **计费方式** | 按**距离与带宽**（专线）或**时长**（拨号） | 按**流量/连接时长**，与距离关系弱 |
| **时延** | **小且稳定**（专线） | 稍大且有**抖动**（排队） |
| **速率** | 取决于线路，可较高 | 取决于所购服务等级 |
| **可靠性** | 单链路故障即中断（无冗余） | 分组网内**多路径冗余**，可靠性较高 |
| **适用场合** | **两点之间流量大而稳定**、要求时延稳定（如总部—分部专线） | **多点互联、流量突发**、跨地域跨运营商（如企业分支经帧中继/MPLS 互联） |
| **成本** | 距离越远越贵，**全连通不可行** | **按需付费**，多点组网更经济 |

**考点提示**：题目问"广域网两种组网方式"→ **点对点连接**与**分组交换式连接**；问"点对点组网的两种做法"→ **全连通（成本太高、没必要）** 与 **用网桥/Modem 点到点连接**；问"网络互联首选设备"→ **路由器**（不是网桥）。

### 7.本任务速查表

| 考点 | 结论 |
|------|------|
| 广域网组网方式 | **点对点连接、分组交换式连接**（两种） |
| 组建广域网的三条路径 | **Modem 拨号、公共数据网、专线** |
| 拨号路径的设备 | **Modem（调制解调器）**，走**电话拨号线** |
| 数字线路接口设备 | **数据服务单元/快捷服务单元（DSU/CSU）** |
| 两端接入广域网的边界设备 | **网桥/路由器** |
| 点对点组网的两种情况 | **全连通**（成本太高、没必要）、**网桥/Modem 点到点** |
| 图 7-4 示意 | **PC — Modem — 电话线 — Modem — PC** |
| 图 7-5 示意 | **PC — 路由器 — 公共数据网 — 路由器 — PC** |
| 网络互联更常用的设备 | **路由器**（比网桥更常用） |
| 路由器的核心优势 | **按网络号选路、屏蔽异构、隔离广播、多路径** |
