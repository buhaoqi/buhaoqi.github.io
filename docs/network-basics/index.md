# 计算机网络基础

本课程系统介绍计算机网络的基本概念、体系结构、协议标准及组网技术，涵盖以下主要模块：

- **模块一 计算机网络概述**：网络发展历程、基本概念、分类与拓扑结构、传输介质
- **模块三 OSI参考模型体系**：OSI七层模型及各层功能
- **模块四 TCP/IP参考模型体系**：IP协议、传输层协议、应用层协议
- **模块五 局域网技术**：局域网基础、以太网、环型网络
- **模块六 局域网组网技术**：组网设备与方法、虚拟局域网和无线网络
- **模块七 广域网技术概述**：广域网组网、实例与设备
- **模块八 Internet技术与应用**：Internet接入与使用、服务与内外联网
- **模块九 网络安全**：网络安全概念、数据安全与安全威胁
- **模块十 网络管理与结构化布线**：网络管理、结构化布线技术
