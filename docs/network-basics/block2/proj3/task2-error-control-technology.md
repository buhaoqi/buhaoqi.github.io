## 知识点

### 1.差错产生的原因是什么？

在数据通信过程中，由于干扰和设备故障的影响，难免发生数据信号失真的情况。电信号在传输信道上传送时，信道在提供数据信号通路的同时也会收到电磁干扰，使数据传输出现差错。

**热噪声有两大类**：

| 类型 | 特点 | 产生原因 |
|------|------|---------|
| **随机热噪声** | 时间上分布较平稳，强度小 | 通信信道中固有的、持续存在的，由线路本身的电子或电气特性引起（如自由电子的布朗热运动） |
| **冲击热噪声** | 随机性强，强度大 | 由外界某种原因突发产生，如大气中的闪电、电源开关的开启、电源的波动等 |

### 2.提高通信可靠性的方法有哪两种？

| 方法 | 说明 |
|------|------|
| **选用高质量传输介质和提高信号功率** | 改善信道传输特性，采取最佳的信号编码和变换方式，使传输信号特性与信道特性达到最好匹配，尽可能降低原始误码率 |
| **传输过程中进行差错控制处理** | 将传输中出现的差错消除在传输过程中，尽量避免落入到目标节点中 |

### 3.什么是差错控制编码？

要纠正计算机通信系统中的传输差错，首先必须检测出错误。基本思想是：

1. 在发送端将要传送的二进制序列中截取k位信息码元
2. 根据某种编码算法以一定规则产生r个冗余码元（校验码）
3. 由信息码元和冗余码元形成n位编码序列（码字），n=k+r
4. 接收端收到的n位码字中，信息元与冗余码元之间应符合编码规则
5. 根据规则进行检验，从而确定是否存在错误

### 4.差错控制的工作方式有哪四种？

| 方式 | 英文缩写 | 说明 |
|------|---------|------|
| **检错重发** | ARQ | 接收端检测到错误后，发送端重新传送 |
| **向前纠错** | FEC | 接收端通过纠错码和适当算法自行纠正错误 |
| **混合纠错** | HEC | 结合检错和纠错功能 |
| **反馈校验** | IRQ | 接收端将收到的信息原封不动发回发送端进行校验 |

### 5.什么是垂直冗余检验（VRC/奇偶校验）？

**原理**：把一个位（称奇偶校验位）添加到每个字符的信息位中，强制字符中1的总数是奇数（奇校验）或偶数（偶校验）。

**示例**：字母A的ASCII码是十六进制的41（二进制 `1000001`），代码中有2个1：

- **奇校验**：在最高位添加1，变为 `11000001`，1的总数为奇数3
- **偶校验**：在最高位添加0，变为 `01000001`，1的总数为偶数2

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 规则简单 | 能检测出奇数数量的位出错，但检测不出偶数数量的位出错 |
| | 理论上只能检测到50%的传输错误 |

### 6.什么是检验和（Checksum）？

**原理**：

1. 把要发送的信息数据相加，产生一个检验和字符
2. 检验和被附加到信息末尾
3. 接收端对收到的信息数据重复相同的求和操作，确定检验和
4. 将计算出的检验和与附加的检验和比较：相同则无错，不同则有错

### 7.什么是纵向冗余校验（LRC）？

**原理**：将发送信息中每个字符的相同位进行**异或**，计算出LRC位。发送时将LRC作为冗余字符附加在信息末尾。接收端重新计算LRC并与收到的LRC比较。

**检测能力**：能够检测到所有传输错误的**95%~98%**。

**局限性**：当偶数数量的字符在相同位置上出现错误时，LRC将检测不到传输错误。

**实际应用**：可以同时使用VRC和LRC来提高检测能力。

### 8.什么是循环冗余校验（CRC）？

**基本思想**：将要传送的信息表示为一个多项式 `M(x)`，用 `M(x)` 除以一个预先确定的多项式 `C(x)`（除数多项式），得到的余式就是所需的CRC校验码。

**工作过程**：

1. **发送端**：信息码 + CRC冗余码一同传送
2. **接收端**：对收到的信息码字用发送时的同一多项式去除
3. 若**能除尽（余数为零）**：传输正确
4. 若**不能除尽（余数非零）**：传输出错

**CRC计算示例**：

- 8位信息序列：`10011010`，多项式表示为 `M(x) = x^7 + x^4 + x^3 + x^1`
- 除数多项式 `G(x) = x^3 + x^2 + 1`（3阶多项式），对应二进制 `1101`
- 在信息位后附加3个0（相当于用 `x^3` 乘以 `M(x)`），得到 `10011010000`
- 用 `1101` 除 `10011010000`，余数为 `101`（3位CRC码）
- 完整传送数据：`10011010101`（8位数据位 + 3位CRC码）

### 9.什么是自动重发请求法（ARQ）？

**原理**：接收端将传输是否正确的信息作为应答反馈给发送端，对于传输有误的数据，发送端要重新传送，直至传送正确为止。

**特点**：

- 接收端只负责检错，不负责纠错
- 错误纠正由发送端重传来实现
- 绝大多数通信系统都采用此方法

### 10.什么是前向纠错法（FEC）？

**原理**：接收端发现错误后，不是通过发送端的重传来纠正，而是由接收端通过纠错码和适当的算法进行纠正。

**特点**：

- **海明码**就是一种前向纠错方法
- 所需的冗余码元较多，实现比较困难
- 很少使用

### 11.四种检错技术的综合对比

| 检错技术 | 缩写 | 原理 | 检测能力 | 复杂度 |
|---------|------|------|---------|--------|
| **垂直冗余检验** | VRC | 奇偶校验，检查1的个数 | 约50%（检测奇数个错） | 最低 |
| **检验和** | - | 对数据求和后比较 | 一般 | 低 |
| **纵向冗余校验** | LRC | 对相同位异或 | 95%~98% | 中 |
| **循环冗余校验** | CRC | 多项式除法取余 | 很高 | 较高 |

### 12.两种纠错方法的综合对比

| 纠错方法 | 英文缩写 | 纠错方式 | 是否需要反馈 | 适用性 |
|---------|---------|---------|------------|--------|
| **自动重发请求** | ARQ | 接收端检错，发送端重传 | 需要（反馈应答） | 广泛使用（绝大多数通信系统） |
| **前向纠错** | FEC | 接收端自行纠正 | 不需要 | 较少使用（冗余码多，实现复杂） |
