## 知识点

### 1.什么是数据交换技术？

通信子网是由若干网络节点和链路按照一定的拓扑结构互连起来的网络，中间的交换节点并不处理流经的数据，而只是简单地把数据从一个交换设备传送到另一个交换设备，直至到达目标节点。通信子网为所有进入子网的数据提供一条完整的传输通路，实现这种数据通路的技术即为**数据交换技术**。

### 2.为什么需要交换节点？

数据通信最简单的形式是两个站点直接用线路连接进行通信，但如果两个站点相距遥远或者要进行多站点之间的通信，采用直接连接显然不合适：

- 若n个站点全连通，一共需要 `n(n-1)/2` 条专线
- 例如 n=6 时需要15条专线，既不方便又昂贵

解决方法是设置**交换节点**，各通信站点和交换节点相连，再把各交换节点用通信线路相连，组成通信网络。每个通信站点只用一条线路和通信网络的节点相连。

### 3.常用的数据交换技术有哪几种？

按照通信子网中的网络节点对进入子网的数据所实施的转发方式的不同，常用的交换技术有三种：

1. **电路交换（Circuit Switching）**
2. **存储-转发交换（Store-and-Forward Switching）**
3. **快速分组交换（Fast Packet Switching）**

### 4.什么是电路交换？

电路交换是一种直接交换方式，源于电话交换网，由交换机负责在两个通信站点之间建立一条物理专用线路。

**特点**：在整个传输期间，该通路一直被通信双方完全占用，直到通信结束后才释放线路。

**三个阶段**：

| 阶段 | 说明 |
|------|------|
| **1. 线路连接** | 由一端通信站点发起呼叫，交换网建立连接，直到两端通信站点间建立起一条转接式数据通路 |
| **2. 数据传输** | 双方进行数据传输 |
| **3. 线路拆除** | 通信结束后释放线路 |

### 5.什么是存储-转发交换？

存储-转发交换源于传统的电报传输方式，不需要通过呼叫建立物理传输通路，而是以接力方式，数据在网络的节点之间逐段传送，直到系统目标节点。

**工作原理**：在发送节点，将要发送的信息在交换设备控制下先在存储区暂存，并对存储的信息进行处理，待指定输出线路空闲时再将信息转发出去。

**优点**：均衡负荷、可进行差错控制等。

**缺点**：实时性不够好，网络传输延迟较大。

### 6.存储-转发交换有哪两种实现形式？

根据被交换数据单元长度的不同，存储-转发交换技术主要有两种实现形式：**报文交换**和**报文分组交换**。

**（1）报文交换**

- **概念**：以报文为单位交换信息。发送方把待传送的信息分为多个报文正文，在报文正文上增加发送、接收节点的地址及其他控制信息，形成完整的报文
- **报文结构**：包括报头（Header）、报文正文（Text）和报尾（Trailer）三部分
- **工作过程**：以报文为单位在交换式网络的各节点间传送，节点接收整个报文后进行缓存和处理，等到指定输出端的线路和下一节点空闲时再将报文转发出去，直到传送到目标节点
- **优点**：线路利用率高；不需要同时启动发送端和接收端；可"群发"；可进行速度适配和代码转换
- **缺点**：传输延迟较大

**（2）分组交换（报文分组交换/包交换）**

- **概念**：把报文分成若干个长度较短的分组（Packet，也称"包"），以分组为单位进行暂存、处理和转发
- **最早运用**：ARPAnet
- **每个分组包含**：收发节点地址信息、分组编号、分组起始/结束标志、差错校验信息等
- **工作过程**：发送端对报文进行分组（组包），接收端对报文分组进行重装（拆包并组成报文）

### 7.分组交换与报文交换相比有哪些优势？

| 优势 | 说明 |
|------|------|
| **降低存储容量要求** | 分组长度较短，大大降低了对网络节点存储容量的要求 |
| **加快处理速度** | 可利用节点设备的主存储器进行存储转发处理，不需要访问外部存储器 |
| **降低传输延迟** | 分组的接收节点和线路的响应时间较短 |
| **提高传输速率** | 分组较短，在传输中出错的概率减小，即使有差错，重发的只是一个分组而非整个报文 |
| **提高线路利用率** | 多个分组可在网络中的不同链路上并发传送 |

### 8.分组交换的主要特点是什么？

1. **线路利用率高**：以虚电路的形式进行信道的多路复用，实现资源共享。虚电路在一条物理线路上提供多条逻辑信道
2. **信息传输可靠性高**：节点交换机之间采用差错校验与重发机制，误码率大大降低。网络中的路由机制可使分组自动选择新路径避开故障点
3. **分组多路通信**：每个分组都包含有控制信息，各分组可以单独传送，同时与多个用户终端进行通信

### 9.分组交换中分组长度的选择原则是什么？

- 分组越短，冗余信息（控制信息）的比例越大，影响传输效率
- 分组越大，传输中出错的概率也越大，增加重发次数

**典型分组长度**：

| 网络/协议 | 分组长度 |
|----------|---------|
| X.25分组交换网 | 131B |
| 以太网 | 1500B |
| 一般情况 | 1000~3000B |
| 一般线路质量、较低传输效率要求 | 100~200B |

### 10.什么是快速分组交换？

快速分组交换（Fast Packet Switching，FPS）是一种协议简化、只有核心网络功能的交换技术，提供高速、高吞吐量、低时延的服务。

广义的FPS包括：

| 技术 | 英文缩写 | 特点 |
|------|---------|------|
| **帧中继** | FR | 采用可变长度帧，适用于LAN互联 |
| **信元中继** | CR | 固定长度信元 |
| **ATM交换** | ATM | 异步传输模式，最典型代表 |

### 11.什么是帧中继（FR）交换？

**原理**：在OSI第二层上用简化的方法传送和交换数据单元的一种技术。

**协议简化层次**：

| 技术 | 涉及OSI层次 |
|------|-----------|
| **X.25分组交换** | 第1、2、3层 |
| **帧交换（FS）** | 第1、2层（不涉及第3层） |
| **帧中继（FR）** | 第1层 + 第2层核心功能（不涉及第3层，第2层只保留链路层核心功能） |

**特点**：

- 仅完成OSI物理层和链路层的核心功能
- 将流量控制、纠错等留给智能终端完成
- 采用虚电路技术，充分利用网络资源
- 具有吞吐量高、时延低、适合突发性业务等特点

**前提条件**：传输网光纤化和用户终端智能化。

**典型应用**：LAN互联和X.25网络互联。

### 12.什么是ATM信元交换？

**概念**：ATM（Asynchronous Transfer Mode）是异步传输模式的简称，是CCITT为B-ISDN制定的信息传送标准。

**关键技术特征**：

| 特征 | 说明 |
|------|------|
| **复用技术** | 采用异步时分复用数据传输技术 |
| **信元长度** | 固定长度（53B） |
| **信元格式** | 统一格式，种类各不相同 |
| **传输速率** | 可达155Mb/s以上 |
| **"异步"含义** | 用户信息与时隙的位置在不同的帧中不是固定不变的（与同步时分交换TDM不同） |

**ATM综合了分组交换和线路交换的优点**，具有高带宽、无速率限制、进网灵活、时延小等优点，可大大提高网络资源利用率。

### 13.三种数据交换技术的综合对比

| 对比项 | 电路交换 | 存储-转发交换 | 快速分组交换 |
|-------|---------|-------------|------------|
| **代表技术** | 电话交换 | 报文交换、分组交换 | 帧中继、ATM |
| **连接建立** | 需要建立物理通路 | 不需要 | 虚电路 |
| **线路占用** | 独占 | 共享 | 共享 |
| **传输延迟** | 小 | 较大 | 小 |
| **线路利用率** | 低 | 高 | 高 |
| **差错控制** | 无 | 有 | 简化/由终端完成 |
| **适用场景** | 实时通信 | 计算机网络 | 高速数据传输、LAN互联 |
