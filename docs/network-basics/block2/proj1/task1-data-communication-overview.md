## 知识点

### 1.数据通信的概念是什么？

数据通信是按照某种通信协议，利用数据传输技术在两个终端之间传递数据信息的一种通信方式，可实现计算机和计算机、计算机和终端以及终端与终端之间的数据信息传递。现代网络数据通信中传递的信息均以二进制数据形式来表现。

### 2.数据通信的发展经历了哪几个阶段？

现代意义上的数据通信是在电流发现之后产生的，可大致划分为3个阶段：

**（1）初级数据通信阶段**

| 时间 | 事件 | 意义 |
|------|------|------|
| 1837年 | 莫尔斯（Samuel B. Morse）研制了实用的电报系统 | 通过铜线发送短的或长的电流脉冲传送Morse码，实现长距离文本信息传输，是现代数据通信系统的先驱 |
| 1876年 | 贝尔（Bell）发明了有线电话 | 实时传输完整语音信号，采用多路复用技术后一条线路能传送多路音频电话信号 |
| 1901年 | 马克尼发明了无线电报 | 无线数据通信开辟了崭新领域 |
| 1938年 | 出现电视广播 | 数据通信从文本、语音发展到实时图像 |

**（2）近代数据通信阶段**

- 1946年计算机产生，数字化技术快速崛起，计算机技术是现代数据通信产生的基础
- 1960年集成电路为各种电子设备提供了高速、微小、功能强大的"心"
- 20世纪70年代出现光纤传输系统和卫星通信
- 20世纪80年代开始出现蜂窝移动通信

**（3）现代数据通信阶段**

- 20世纪90年代以来，随着计算机网络技术发展和Internet的快速普及
- 分布在世界各地的计算机之间能够进行快速的数据通信
- 从单纯的数字数据演变为集数据、语音和图像等多种信息格式的多媒体信息通信平台

### 3.什么是模拟信号？

模拟信号是一种信号幅度随时间**连续变化**的电信号，其波形为连续曲线，中间无断裂和不连续。信号的强度取值随时间变化而连续变化。

**正弦信号**是最简单的模拟信号，一个正弦波形可用以下3个参数来描述：

| 参数 | 说明 |
|------|------|
| **振幅（A）** | 信号的峰值或最大强度 |
| **频率（f）** | 信号周期重复的速率，每秒周期数（赫兹，Hz），是信号周期T的倒数，即 `f=1/T` |
| **相位** | 时间零点时的位置 |

改变正弦波中振幅、频率和相位中任何一个参数的值，就改变了信号的波形，这3个要素之一的改变即可用于表示不同的数据，进行信息的传输。

模拟信号都可以分解为多个具有不同频率的正弦信号，而正弦信号是模拟信号的最简化形式，不能再进行分解。

### 4.什么是数字信号？

数字信号是一种**非连续变化**的电信号，其波形为不连续的曲线。信号的强度始终在有限个数的值之间变化。

- 当信号强度只有两种取值时，即为**二进制数字信号**，这是数据通信中实际使用的数字信号
- 19世纪初法国数学家傅立叶（Joseph Fourier）证明：任何正常的周期为T的函数g(t)，都可以表示成无数个具有不同振幅、频率和相位的正弦波之和
- 因此，任何数字信号都可以用具有不同频率分量的正弦波的合成来表示
- **信号的带宽**就是信号包含的不同频率正弦波形中的最高频率和最低频率之差

### 5.基带信号、频带信号和宽带信号的区别是什么？

| 信号类型 | 本质 | 传输方式 | 特点 |
|---------|------|---------|------|
| **基带信号** | 数字信号1或0直接用两种不同的电压来表示 | 传送到数字信道上传输，占据传输信道的全部带宽 | 近距离功率衰减不大，信道容量不变，局域网中通常使用 |
| **频带信号** | 模拟信号 | 用数字信号对特定频率的载波进行调制，变成适合于模拟线路传送的信号 | 适合远距离传输或无线传输 |
| **宽带信号** | 模拟信号 | 借助于频带信号，将链路容量分解为两个或多个信道 | 每个信道可携带不同的频带信号，所有信道可同时但互不干扰地收发信号 |

### 6.数据通信系统的一般模型是怎样的？

通信系统必须包括3个基本组成部分：**信源、传输介质和信宿**。

一般认为数据通信系统由以下三部分构成：

**（1）数据终端设备（DTE）**

- 充当信源和信宿的设备通称为数据终端设备（Data Terminal Equipment）
- 可能是大、中、小型计算机、PC，也可能是可以直接接收网络数据的打印机
- 是信息的输入/输出工具
- 还必须设置通信控制器（也称适配器，如网卡）及相关的控制软件，控制收发双方同步、差错控制、传输链路的建立/维持/拆除及数据流量控制等

**（2）数据通信设备（DCE）**

- 连接DTE与传输信道的设备称为数据通信设备（Data Communication Equipment）
- DCE的功能是完成数据信号的变换
- 如果DTE发出的数据信号不适合于信道传输，DCE要把原始数据信号变成适合信道传输的模拟信号或数字信号形式
- 典型设备：调制解调器（Modem）、数字编码解码器（Codec）等

**（3）通信信道**

- 也叫传输信道，是通信系统必不可少的组成部分
- 由传输介质和相关的电子设备（如放大器、滤波器等）或光学设备组成
- 常见传输介质：铜线、同轴电缆、双绞线、光纤和空间等
- 根据传输介质的不同，可以传输模拟信号，也可以传输数字信号

### 7.数据通信的性能指标有哪些？

**（1）带宽**

- 原指某个信号具有的频带宽度，即最高频率和最低频率之差
- 单位：赫兹（Hz）、千赫（kHz）、兆赫（MHz）等
- 对于**模拟信道**，带宽是信道能够传送的电磁波信号的最高频率与最低频率之差
- 对于**数字信道**，在很多情况下带宽就是数据传输速率或比特率
- 通信信道的带宽必须大于或等于信号的带宽，才能保证传输的信号不失真

**（2）数据传输速率（比特率）**

- 每秒能够传输多少位数据，单位为比特/秒（`b/s`、`bit/s`或`bps`）
- 例如：每秒传输9600bit，则数据传输率为9600b/s（9.6kbps）
- 在100Mb/s速率下，每比特传输时间为10ns；在10Mb/s速率下，每比特传输时间为100ns

**（3）信道容量**

- 信道可以无错误传送的最大信息量，是信道传输信息的速率上限
- 单位：`b/s`
- 例如：一条具有3kHz带宽的普通电话线路，其最大传输速率为20kb/s

**（4）波特率（传码率或调制速率）**

- 码元是数据在传输过程中最小的传输单位
- 单位：码元/秒，称为波特（Baud）
- 对于模拟信号，波特率是指调制信号每秒钟调制载波状态改变的次数
- 对于数字信号，波特率是指线路上每秒钟传送的波形个数
- 波特率一般**小于或等于**比特率

**（5）吞吐量**

- 信道在单位时间内成功传输的信息量
- 单位：`bit/s`
- 例如：某信道10min内成功传输了8.4Mbit的数据，吞吐量为8.4Mb/600s=14.3kb/s

**（6）延迟**

- 从发送方传出第一位数据开始，到接收方成功接收到最后一位数据为止所经历的时间
- 分为**传输延迟**和**传播延迟**两种

**（7）错误率**

- 衡量通信信道可靠性的重要指标
- **比特错误率**：二进制比特位在传输过程中被误传的概率
- **分组错误率**：数据分组被误传的概率
