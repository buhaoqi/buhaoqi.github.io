## 知识点

### 1.通信方式按什么标准分类？

通信方式指通信过程中双方在信号发送、传输和接收这三个环节中对信号的处理方式，涉及传送信号的位数、方向、数量等。

- 按数字信号码元排列与组织方法的不同，可分为**串行通信**和**并行通信**
- 按数据传送的方向与时间的关系，可分为**单工通信**、**半双工通信**和**全双工通信**

### 2.并行通信与串行通信的区别是什么？

| 对比项 | 并行通信 | 串行通信 |
|-------|---------|---------|
| **传输方式** | 至少有8个数据位同时在两台设备之间传输 | 一次只发送或接收一位数据位 |
| **所需数据线** | 8条以上数据线 | 只需一根传输线 |
| **适用场景** | 计算机内部各部件之间或近距离设备之间 | 计算机与计算机或终端设备之间的远距离传输 |
| **接口** | 并行接口（LPT） | 串行接口（COM） |
| **传输速率** | 快 | 慢 |
| **成本** | 高（需要多根数据线） | 低（只需一根传输线） |
| **应用** | 计算机内部总线通信（8位总线、16位总线等） | 计算机网络通信（网卡负责串行/并行数据转换） |

在现行的计算机网络通信中，**串行通信**应用得较为广泛。

### 3.什么是单工通信？

**概念**：传送的信息始终是一个方向的通信。发送端把信息发往接收端，根据信息流向即可决定一端是发送端，另一端就是接收端。

**特点**：

- 一般是**二线制**
- 信息只能单方向传输

**典型例子**：

- 主机发往显示器的通信
- 收看广播电视（信息只能从电视台发射并传输到各用户接收，用户信息不能传输到广播电台或电视台）

### 4.什么是半双工通信？

**概念**：信息流可以在两个方向传输，但同一时刻只能进行一个方向的传输。

**特点**：

- 通信的双方都具备发送和接收装置
- 每一端既可以是发送端也可以是接收端
- 信息流轮流使用发送和接收装置

**典型例子**：对讲机在使用时属于半双工通信

### 5.什么是全双工通信？

**概念**：在同一时间可以作双向的通信，即通信的一方在发送信息的同时也能接收信息。

**实现方式**：

- 一般通过采用多条线路或频分法来实现
- 也可采用时分复用或回波抵消等技术
- 一般采用**四线制**，一组用来发送信息，另一组用来接收信息

**适用场景**：适合计算机与计算机之间的通信

**典型例子**：电话机之间的通信

### 6.广播式通信与点到点式通信的区别是什么？

| 对比项 | 广播式通信 | 点到点式通信 |
|-------|-----------|------------|
| **连接方式** | 所有联网计算机共享一个公共信道 | 每条物理线路连接一对计算机 |
| **数据接收** | 发送的数据中带有目标地址与源地址，所有计算机都能"收听"，检查地址是否匹配 | 两台计算机间可直接通信，或通过中间节点存储转发 |
| **寻址方式** | 通过目标地址匹配决定是否接收 | 通过路由选择算法决定数据传输路径 |
| **是否需要存储转发与路由选择** | 不需要 | 需要（这是与广播式网络的重要区别） |
| **典型网络** | 总线型拓扑网络、环型拓扑网络、集线器组建的星型网络 | 各种专用网、VPN广域网、交换机网等 |

### 7.什么是基带通信？

**概念**：由计算机或终端等数字设备产生的、未经调制的数字数据相对应的电脉冲信号通常呈矩形波形式，占据的频率范围从直流和低频开始，这种电脉冲信号称为**基带信号**。基带信号占有固有的频率范围称为基带频带，简称"基带"（Baseband）。在信道中直接传输基带信号的通信方式就叫基带通信。

**特点**：

- 整个信道只传输一种信号
- 是最简单、最基本的通信方式
- 适用于传输各种速率要求的数据，特别是在近距离的场合
- 在计算机局域网中广泛采用（如以太网和令牌环网）
- 基带信号频率很低，含有直流成分，远距离传输时信号功率衰减或干扰较大，**不适合远距离数据通信**

### 8.什么是宽带通信？

**概念**：宽带（Broadband）是指比音频带宽更宽的频带，它包括大部分电磁波频谱，利用宽带进行的通信方式称为宽带通信。

**特点**：

- 可以是模拟传输系统或数字传输系统
- 能够在同一信道上进行数字信息和模拟信息的传输
- 可容纳全部广播信号，并可进行高速的数据传输
- 通过把一个宽带信道划分为多个逻辑基带子信道，能够把声音、图像、数据等多媒体信息综合到一个物理信道上进行传输

**与基带通信对比**：在局域网中，基带通信的数据速率比宽带通信低。
