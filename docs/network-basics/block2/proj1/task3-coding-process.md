## 知识点

### 1.什么是编码/解码技术？

编码/解码（Coding/Decoding）技术用于实现**模拟信号与数字信号之间的转换**。

- **编码**：将模拟信号转换为数字信号的过程，通常采用脉码调制技术（Pulse Code Modulation，PCM）实现
- **解码**：将数字信号还原为模拟信号的逆过程
- 对应的设备称为编码/解码器（Codec）

### 2.编码/解码技术的应用场景有哪些？

- 当使用计算机对生产装置进行控制时，首先将模拟信号（如温度、电压等）通过传感器采样变成数字信息，输入计算机处理，再把数字结果转换成模拟信号反馈给控制装置
- 利用光纤数字信道作为电话网络的长途干线，使用数字传输技术有利于消除模拟信号传输过程中的噪声分量，提高声音传输质量
- 电话网的主干线路采用光纤，用户端采用普通电话线时，需要用编码/解码器进行模拟信号与数字信号之间的转换

### 3.脉码调制（PCM）包括哪几个步骤？

脉码调制技术最初用于将电话模拟信号转换为数字信号，转换过程包括3个步骤：**采样、量化和编码**。

### 4.什么是采样？

**概念**：通过某种频率的采样脉冲将模拟信号等间隔取样，变连续的模拟信号为时间离散信号的过程称为采样。

**理论依据**：基于**香农采样定理**——只要采样频率大于或者等于有效信号最高频率的两倍，采样值可以基本包含原始信号的所有信息，被采样的信号可以不失真地还原原始信号。

**注意**：抽样频率必须大于或者等于有效信号最高频率的两倍，否则就会发生**混叠和失真**。

### 5.什么是量化？

**概念**：将时间离散的信号转换为幅度离散的信号。

**具体过程**：

1. 将时间离散的信号的幅度分为若干个等级
2. 对采样的离散值进行"取整"量化
3. 将每个等级对应一个数字，形成一个幅度离散的信号

**量化精度**：

- 量化精度越高，信号的质量就越好
- 但需要的比特数也就越多

### 6.什么是编码？

**概念**：将量化后的值编码成一定位数的二进制数值。

**编码位数公式**：当量化级为N时，对应的二进制位数为 `log2N`。

**示例**：

- 采用8级量化时（N=8），编码的二进制位数取3位即可（因为 `log2 8 = 3`）
- 量化级为256时，对应的二进制位数为 `log2 256 = 8` 位

### 7.电话语音信号的编码实例是怎样的？

以人类语音信号为例：

| 参数 | 数值 |
|------|------|
| 语音频率范围 | 300~3400Hz |
| 量化级 | 256 |
| 采样间隔 | 每125微秒（us）采样一次 |
| 采样频率 | 8000次/秒 |
| 每次采样位数 | 8位（`log2 256 = 8`） |
| 所需传输速率 | 8000 x 8 = 64000 bit/s = 64kb/s |

因此，目前公共交换电话网采用**64kbit/s**的带宽传输。

### 8.编码/解码器在实际通信系统中如何使用？

一个典型的应用场景：电话网的主干线路采用光纤（数字传输），而到用户端仍然采用普通的电话线（模拟传输）。

**信号转换流程**：

1. 用户电话机的模拟信号通过电话线传输
2. 到达编码/解码器（Codec）后，将模拟信号转换为适合光纤传输的数字信号
3. 数字信号经光纤数字网传输到另一端
4. 再由编码/解码器将数字信号转换为适合电话线的模拟信号
5. 传到目标电话机

### 9.如何保证不同类型信号和信道的正确匹配？

只要合理地使用**Modem（调制解调器）**和**Codec（编码/解码器）**，就可以保证以下各种传输过程正确实现：

- 模拟信息通过模拟信道传输
- 模拟信息通过数字信道传输
- 数字信息通过模拟信道传输
- 数字信息通过数字信道传输

换句话说，计算机设备之间的通信可被认为总存在一条数字链路支持实现数据信息的传输，用户无需担心信号和信道的类型不一致的问题。
