## 知识点

### 1.什么是同步？为什么需要同步？

在数据通信系统中，接收端收到的信息应与发送端发出的信息完全一致，这就要求在通信中收发双方必须有统一的、协调一致的动作。

- 若收发两端的动作互不联系、不协调，则收发之间就会出现误差
- 随着时间的增加和误差的积累将导致收发"失步"，使系统不能正确传输信息
- **同步**：统一收发两端动作、保持收发步调一致的过程

常用的同步方式有两种：**同步传输方式**和**异步传输方式**。

### 2.什么是同步传输方式？

同步传输方式不以字符为单位，而以**数据块**（一组字符或比特流）为单位传输。在传输中，字符之间不加起始位和停止位。

**同步标志**：为了使接收方容易确定数据块的开始和结束，需要在每个数据块的前后加上起始和结束标志，以便使发送方和接收方之间能建立起一个同步的传输过程，同时还可以用这些标志来区分与隔离连续传输的数据块。

**数据块起始和结束标志的特征取决于数据块是面向字符的还是面向比特的：**

| 类型 | 数据块内容 | 起始和结束标志 |
|------|-----------|--------------|
| **面向字符的方式** | 由若干个字符组成 | 特殊的字符（如SYN、EOT等） |
| **面向比特的方式** | 一串比特流 | 某一特殊的位模式（如在HDLC中用 `01111110` 作为数据块的起始和结束标志） |

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 传输效率高 | 如果在传输的数据中有一位出错，必须重新传输整个数据块 |
| 时间消耗少 | 控制比较复杂 |

### 3.什么是异步传输方式？

异步传输方式是计算机网络中常用的同步方式。在异步传输中，同一个字符内相邻两位的间隔是固定的，而两个字符之间的间隔是不固定的，即所谓的**"字符内同步，字符间异步"**。

### 4.异步传输方式的字符结构是怎样的？

在不传送字符时，线路一直处于高电平"1"状态。传送字符时，发送端在每个字符的首尾分别设置：

| 组成部分 | 电平 | 位数 | 作用 |
|---------|------|------|------|
| **起始位** | 低电平（相当于数字"0"） | 1位 | 表示字符的开始 |
| **数据位（信息位）** | - | 5位或8位 | 字符内容，8位字符中包含1位校验位 |
| **停止位** | 高电平（相当于数字"1"） | 1.5位或2位 | 表示字符的结束 |

**位数规则**：
- 5位二进制数的字符的停止位设为**1.5位**
- 8位二进制数的字符的停止位设为**2位**

### 5.异步传输的工作过程是怎样的？

1. 发送端按确定的时间间隔（或位宽）或固定的时钟发送一个字符的各位
2. 接收端识别起始位和停止位并按相同的时钟（或位宽）来实现收发双方在一个字符内各位的同步
3. 当接收端在线路上检测到起始位的脉冲前沿（从"1"到"0"跃变）到来时，启动本端的定时器，产生接收时钟
4. 接收端按发送端相同的时间间隔顺序接收该字符的各位
5. 当接收端一旦接收到停止位就将定时器复位，准备接收下一个字符代码
6. 若无字符发送，系统连续以"1"电平填充字符的空间，直至下一个字符到来

### 6.异步传输方式的特点是什么？

**特点总结**：

- 每个字符含相同的位数，字符每位的位宽相同
- 传送每个字符所用的时间由字符的起始位和停止位之间的时间间隔决定，为一固定值
- 起始位起到一个字符内的各位的同步作用，故异步传输方式又称**起止式同步**

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 控制简单，实现容易 | 附加了起始位和停止位，增加了传输开销 |
| 如果出现错误，只需重发一个字符即可 | 传输效率有所下降 |
| 适用于低速率场合 | |

### 7.同步传输与异步传输的对比

| 对比项 | 同步传输 | 异步传输 |
|-------|---------|---------|
| **传输单位** | 数据块（一组字符或比特流） | 字符 |
| **起始位/停止位** | 不加（用数据块前后标志） | 每个字符首尾各加起始位和停止位 |
| **同步方式** | 数据块级同步 | 字符内同步，字符间异步 |
| **传输效率** | 高（开销少） | 较低（附加起始位和停止位） |
| **错误处理** | 一位出错需重传整个数据块 | 出错只需重发一个字符 |
| **控制复杂度** | 较复杂 | 简单，实现容易 |
| **适用场合** | 高速率场合 | 低速率场合 |
