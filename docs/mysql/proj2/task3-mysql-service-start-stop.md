## 知识点

### 1.MySQL安装完成后，为什么要启动MySQL服务？

答：MySQL数据库分为客户端和服务器两部分。MySQL安装完成后，需要启动服务器进程，否则客户端无法连接数据库。安装MySQL时一般默认MySQL服务为自动启动，如果MySQL服务没有启动，可以用图形化和命令行两种方式来启动和停止MySQL服务。

### 2.通过"计算机管理"启动和停止MySQL服务的步骤是什么？

答：在Windows平台下，右击"计算机"→选择"管理"→双击"服务和应用程序"→双击"服务"，打开服务窗口（也可在开始菜单的运行框中输入命令services.msc打开）。在该窗口中找到"MySQL57"服务项，查看其状态：如果显示"正在运行"，表明服务已启动。选中"MySQL57"服务项右击，在快捷菜单中选择"启动"或"停止"，即可启动或停止MySQL服务。

### 3.如何更改MySQL服务的启动类型？

答：在服务窗口中右击"MySQL57"服务项，在快捷菜单中选择"属性"，弹出属性对话框。在"启动类型"下拉列表中可以选择以下三种类型：
- 自动：MySQL服务开机自动启动，可以手动将服务状态变为停止、暂停和重新启动等。适合经常练习MySQL数据库操作的用户。
- 手动：MySQL服务需要手动启动，启动后可以改变服务状态（如停止和暂停等）。适合使用MySQL数据库频率很低的用户，可避免MySQL服务长时间占用系统资源。
- 禁用：MySQL服务不能启动，也不能改变服务状态。

### 4.通过"任务管理器"启动和停止MySQL服务的步骤是什么？

答：右击"任务栏"→选择"任务管理器"→单击"服务"选项卡，在服务列表中找到"MySQL57"服务项，右击选择"开始"或"停止"，即可启动或停止MySQL服务。如果右击后选择"打开服务"，则会打开计算机管理中的服务窗口。

### 5.使用命令行启动和停止MySQL服务的命令是什么？

答：以管理员身份打开命令提示符窗口（CMD），输入以下命令：
- 启动MySQL服务：net start mysql57
- 停止MySQL服务：net stop mysql57

注意：命令中的mysql57为服务名称，必须和安装时命名一致。

### 6.使用命令行启动MySQL服务时出现"发生系统错误5"怎么办？

答：出现"发生系统错误 5。拒绝访问。"的错误信息，是因为没有以管理员身份打开命令提示符窗口。需要关闭该窗口，重新右击"命令提示符"，选择"以管理员身份运行"，然后重新执行启动命令。

### 7.如何以管理员身份打开命令提示符？

答：在Windows平台下，从"开始"菜单搜索"命令提示符"，右击"命令提示符"，选择"以管理员身份运行"，即可以管理员身份打开命令提示符窗口。

### 8.MySQL服务的三种启动类型（自动、手动、禁用）有何区别？

答：（1）自动：MySQL服务开机自动启动，可以手动将服务状态变为停止、暂停和重新启动等。适合经常使用MySQL的用户，可避免每次手动启动MySQL服务。
（2）手动：MySQL服务需要手动启动，启动后可以改变服务状态（如停止和暂停等）。适合使用MySQL频率很低的用户，可避免MySQL服务长时间占用系统资源。
（3）禁用：MySQL服务不能启动，也不能改变服务状态。

### 9.如何查看MySQL服务的当前运行状态？

答：可以通过以下两种方式查看MySQL服务状态：
（1）图形化方式：打开"计算机管理"→"服务和应用程序"→"服务"，在服务列表中找到"MySQL57"，查看其状态列。如果显示"正在运行"，表明服务已启动；如果没有"正在运行"字样，说明MySQL服务未启动。
（2）任务管理器：打开任务管理器→"服务"选项卡，找到"MySQL57"，查看其状态。

### 10.在MySQL服务属性窗口中可以执行哪些操作？

答：在MySQL服务的属性窗口中，可以查看服务名称、显示名称、描述、可执行文件路径、启动类型和服务状态等信息。在服务状态区域可以执行"启动"、"停止"、"暂停"、"恢复"等操作。还可以在"启动类型"下拉列表中选择"自动"、"手动"或"禁用"。
