## 知识点

逻辑结构设计的核心任务是把 **E-R 图转换为关系模式集合**，即确定每张表的结构、主键和外键。

### 1. 实体转换为关系模式

**规则**：每个实体型转换为一个关系模式。

- 实体的**属性**成为关系的**属性**；
- 实体的**码（主键）**成为关系的**主键**。

**示例**：

```
学生(学号, 姓名, 性别, 年龄)   —— 主键：学号
课程(课程号, 课程名, 学分)    —— 主键：课程号
```

### 2. 一对一（1:1）联系的转换

**规则**：可以在**任意一个**实体对应的关系模式中加入另一个关系模式的主键作为外键。

- 通常选择在一方加入另一方的码；
- 联系本身的属性也一并加入。

**示例**：班级与班长是 1:1 联系

```
班级(班级号, 班级名称, 班长学号)   —— 班长学号为外键，引用学生(学号)
学生(学号, 姓名, ...)
```

> 也可在学生表中加入班级号，两种方案均可，按需选择。

### 3. 一对多（1:n）联系的转换

**规则**：在**"多"方**实体对应的关系模式中加入"一"方的主键作为外键。

- 联系的属性也加入到"多"方关系中。

**示例**：班级（1）—学生（n）

```
班级(班级号, 班级名称)                        —— 主键：班级号
学生(学号, 姓名, 性别, 班级号)                —— 主键：学号，外键：班级号
```

> ⚠️ 不能把外键加在"一"方，否则无法表示多个学生属于同一班级。

### 4. 多对多（m:n）联系的转换

**规则**：**必须为联系单独建立一个新的关系模式**。

- 新关系的属性由**双方实体的主键**加上**联系自身的属性**组成；
- 新关系的主键为**双方主键的组合**（联合主键）；
- 双方主键在新关系中均为外键。

**示例**：学生（m）—课程（n）的"选修"联系，联系有属性"成绩"

```
学生(学号, 姓名, 性别)                        —— 主键：学号
课程(课程号, 课程名, 学分)                    —— 主键：课程号
选修(学号, 课程号, 成绩)                      —— 主键：(学号, 课程号)
                                              外键：学号、课程号
```

### 5. 确定关系模式的主键

- 能**唯一标识**每条记录的属性或属性集；
- 实体转换：实体的码即主键；
- 多对多转换：双方主键的组合作主键；
- 主键应**非空、不重复、稳定**（不随业务变化）。

### 6. 确定关系模式之间的外键

- 外键用于**实现表与表之间的联系**；
- 1:1 联系：外键放在任一方；
- 1:n 联系：外键放在"多"方；
- m:n 联系：通过中间表，双方主键均为外键；
- 外键的值必须存在于被引用表的主键中，或为 NULL（参照完整性）。

| 联系类型 | 转换规则 |
| --- | --- |
| 实体 | 每个实体转为一个关系模式，实体属性→关系属性，实体的码→主键 |
| 1:1 | 在任一方加入另一方主键作外键 |
| 1:n | 在"多"方加入"一"方主键作外键 |
| m:n | 新建一个关系模式，主键为双方主键组合，双方主键均为外键 |

## 考点提示

- 高频考点：三种联系的转换规则，尤以 **m:n 必须新建关系模式**为最常考。
- 易错点：1:n 联系外键必须加在"多"方；多对多转换后中间表的主键是**组合主键**。
- 常考题型：给出 E-R 图，要求写出关系模式并指出主键、外键。
