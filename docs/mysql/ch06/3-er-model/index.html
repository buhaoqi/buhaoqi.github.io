概念结构设计——E-R 模型

知识点​

6.3.1 E-R 模型的基本概念​

**E-R 模型（Entity-Relationship Model，实体-联系模型）**用实体、属性和联系来描述现实世界的概念模型，是概念结构设计的主要工具。

（1）实体（Entity）​

  • 客观存在并可相互区别的事物，是 E-R 模型的基本对象；
  • 可以是具体的人或物（如学生、图书），也可以是抽象的事件（如选课、借阅）。

（2）属性（Attribute）​

  • 实体所具有的某一特性；
  • 如学生的学号、姓名、性别、年龄；
  • 属性可分为简单属性与复合属性、单值属性与多值属性、派生属性等（了解）。

（3）联系（Relationship）​

  • 实体之间的相互关联关系；
  • 如"学生"与"课程"之间的"选课"联系；
  • 联系也可以有自己的属性（如选课联系的成绩）。

（4）实体型与实体集​

概念含义示例
实体型用实体名及其属性名集合来抽象同类实体学生(学号, 姓名, 性别)
实体集同型实体的集合全体学生
实体实体集中的一个具体个体学生"张三"

（5）联系的类型​

类型含义示例
一对一（1:1）实体集 A 中每个实体至多与 B 中一个实体联系，反之亦然班级 ↔ 班长
一对多（1:n）A 中每个实体可与 B 中多个实体联系，B 中每个实体至多与 A 中一个联系班级 ↔ 学生
多对多（m:n）A 中每个实体可与 B 中多个实体联系，反之亦然学生 ↔ 课程

6.3.2 E-R 图的绘制​

（1）实体的表示方法​

  • 用矩形表示实体型，矩形框内写明实体名。

（2）属性的表示方法​

  • 用椭圆形表示属性，椭圆内写明属性名，用无向边与实体连接；
  • 主键属性的属性名下加下划线。

（3）联系的表示方法​

  • 用菱形表示联系，菱形框内写明联系名；
  • 用无向边分别与相关实体连接，在边上标注联系类型（1:1、1:n、m:n）；
  • 联系本身若有属性，也用椭圆表示并与菱形相连。

（4）图例汇总​

图形表示对象
矩形实体
椭圆形属性（主键加下划线）
菱形联系
无向边连接实体与属性、实体与联系

（5）根据实际需求绘制 E-R 图（示例）​

需求：学校中有多个班级，每个班级有多名学生，每名学生可选修多门课程，每门课程可被多名学生选修；课程由教师讲授，一名教师讲授多门课程，一门课程由一名教师讲授。

绘制步骤：

  1. 确定实体：班级、学生、课程、教师；
  2. 确定各实体属性：
    • 班级（班级号、班级名称）
    • 学生（学号、姓名、性别、年龄）
    • 课程（课程号、课程名、学分）
    • 教师（教师号、姓名、职称）
  3. 确定联系及类型：
    • 班级 —1:n— 学生（"属于"）
    • 学生 —m:n— 课程（"选修"，属性：成绩）
    • 教师 —1:n— 课程（"讲授"）
  4. 用矩形、椭圆、菱形绘制并标注联系类型；
  5. 检查是否完整表达需求。
erDiagram
    CLASS ||--o{ STUDENT : "属于"
    TEACHER ||--o{ COURSE : "讲授"
    STUDENT }o--o{ COURSE : "选修"

考点提示​

  • 高频考点：E-R 图三种图形的含义（矩形=实体、椭圆=属性、菱形=联系），主键加下划线。
  • 易错点：联系也可能有属性（如"选修"的"成绩"），应连接在菱形上而非实体上。
  • 能根据需求描述画出 E-R 图、判断联系类型是常考综合题。
