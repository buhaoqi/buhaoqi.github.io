## 知识点

### 1. 数据与信息

- **数据（Data）**：描述客观事物的符号记录，是数据库中存储的基本对象。数据不仅包括数字，还包括文字、图形、图像、音频、视频等。
- **信息（Information）**：经过加工处理后具有特定含义、对决策有用的数据。
- **二者关系**：数据是信息的载体，信息是数据的内涵；数据经过解释和处理后成为信息，信息可以用数据来表示。

### 2. 数据库（DB）

数据库（Database，简称 DB）是**长期存储在计算机内、有组织的、可共享的大量相关数据的集合**。

基本特征：

- 永久存储：数据长期保存在外存中；
- 有组织：按一定的数据模型组织、描述和存储；
- 可共享：可被多个用户和应用程序共同使用；
- 冗余度低、易扩充。

### 3. 数据库管理系统（DBMS）

数据库管理系统（Database Management System，简称 DBMS）是**位于用户与操作系统之间的一层数据管理软件**，负责数据库的建立、使用和维护。

主要功能：

1. **数据定义功能（DDL）**：定义数据库的模式、表、视图、索引等对象；
2. **数据操纵功能（DML）**：对数据进行查询、插入、修改、删除；
3. **数据库的运行管理**：并发控制、安全性检查、完整性约束、事务管理；
4. **数据库的建立与维护**：数据装载、转储、恢复、重组织与性能监视；
5. **数据通信与接口**：提供与其他软件系统交互的接口。

常见 DBMS：MySQL、Oracle、SQL Server、PostgreSQL、SQLite、Access 等。

### 4. 数据库系统（DBS）

数据库系统（Database System，简称 DBS）是指**引入数据库技术后的整个计算机系统**。

组成：数据库（DB）、数据库管理系统（DBMS）及其开发工具、应用系统、数据库管理员（DBA）和用户。

> 注意：DBS 是一个"系统"概念，范围最大，包含 DB 和 DBMS。

### 5. DB、DBMS、DBS 之间的关系

三者是**包含关系**：`DBS ⊃ DBMS ⊃ DB`

- DB 是被管理的**数据集合**（被管理对象）；
- DBMS 是管理数据的**软件**（管理工具）；
- DBS 是采用数据库技术后的**整个系统**（管理对象 + 管理工具 + 人员 + 应用）。

**类比理解**：图书馆中，藏书相当于 DB，图书管理系统和管理员相当于 DBMS，整个图书馆（藏书 + 系统 + 管理员 + 读者 + 规章制度）相当于 DBS。

### 6. 数据库系统的特点

1. **数据结构化**：数据按数据模型组织，面向整个组织而非某个应用；
2. **数据共享性高、冗余度低、易扩充**：同一数据可供多个用户共享，避免重复存储；
3. **数据独立性高**：包括物理独立性和逻辑独立性；
4. **数据由 DBMS 统一管理和控制**：提供安全性控制、完整性控制、并发控制、数据库恢复；
5. **具有方便的用户接口**。

## 考点提示

- 高频考点：DB / DBMS / DBS 的概念辨析及三者关系（选择题常考"DBS 包含 DBMS 和 DB"）。
- 易混点：DBMS 是**软件**，DBS 是**系统**，DB 是**数据集合**。
- 数据库系统特点中，"数据共享性高、冗余度低""数据独立性高"是常考表述。
