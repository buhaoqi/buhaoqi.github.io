## 知识点

### 1. 数据库备份的概念

**数据库备份**是指将数据库中的数据、结构和相关对象**复制并存储到其他存储介质**的过程，形成数据库的副本（备份文件）。

- 备份的是某一时刻数据库的**一致性快照**；
- 备份文件应存放在**安全可靠、独立于数据库服务器**的位置；
- 备份是防范数据丢失的最基本、最有效的手段。

### 2. 数据库恢复的概念

**数据库恢复**是指当数据库发生故障或数据损坏时，利用**备份文件**将数据库还原到某个正常状态的过程。

- 恢复是备份的逆过程；
- 恢复目标：尽可能减少数据损失，保证数据一致性和完整性；
- 恢复后应验证数据的完整性和正确性。

### 3. 备份与恢复的作用

1. **灾难恢复**：应对硬件故障、断电、火灾、地震等灾害；
2. **人为错误恢复**：误删表、误改数据后及时还原；
3. **应对软件故障与病毒攻击**：如勒索病毒加密数据；
4. **数据迁移与复制**：用于环境迁移、搭建测试库、主从复制初始化；
5. **历史数据归档**：保留特定时间点的数据快照；
6. **保证业务连续性**：将停机时间和数据损失降到最低。

### 4. 备份与恢复的基本原则

- **定期备份**：制定备份计划并严格执行；
- **多种备份方式结合**：完全备份 + 增量/差异备份；
- **异地存放**：备份文件与生产数据分离存储；
- **定期演练恢复**：备份是否有效必须通过实际恢复验证；
- **记录备份日志**：记录备份时间、内容、存放位置和负责人。

> ⚠️ 只备份不演练恢复，等于没有备份——这是数据库运维的重要原则。

## 考点提示

- 高频考点：备份与恢复的概念及作用（灾难恢复、误操作恢复、数据迁移）。
- 易错点：备份是"复制数据"，恢复是"还原数据"，两者是互逆过程。
- 常考简答题："为什么要定期演练恢复？"——验证备份的有效性和可用性。
