## 知识点

### 1. 数据库安全性的基本概念

**数据库安全性**是指保护数据库，防止因**不合法的使用**而造成的数据泄露、更改或破坏。

- 数据库安全性保护的是**数据本身**；
- 与数据库完整性不同：安全性防范的是**非法用户和非法操作**，完整性防范的是**不符合语义的错误数据**；
- 安全性是信息系统安全的重要组成部分。

### 2. 数据库不安全因素

1. **非授权用户的访问**：黑客入侵、越权访问、内部人员滥用权限；
2. **口令泄露或过于简单**：弱密码、密码被猜测或窃取；
3. **SQL 注入攻击**：通过输入构造恶意 SQL 语句，非法获取或修改数据；
4. **恶意软件与病毒**：木马、病毒破坏数据库文件；
5. **备份数据泄露**：备份文件未加密、保管不当；
6. **系统漏洞与配置不当**：DBMS 补丁未更新、默认账户未修改、权限过大；
7. **物理安全威胁**：硬件被盗、自然灾害、断电；
8. **人为错误**：误删数据、误改配置。

### 3. 数据库安全控制的基本方法

| 方法 | 说明 |
| --- | --- |
| **用户身份鉴别（认证）** | 用户名 + 口令、双因素认证，验证用户身份 |
| **访问控制（授权）** | 通过 `GRANT` / `REVOKE` 为用户分配最小必要权限，遵循**最小权限原则** |
| **视图机制** | 通过视图隐藏敏感数据，只向用户提供可访问的数据 |
| **数据加密** | 对存储数据和传输数据加密（如 SSL/TLS） |
| **审计（审计日志）** | 记录用户对数据库的操作，便于追踪和事后分析 |
| **备份与恢复** | 定期备份，灾难发生后及时恢复 |
| **防火墙与网络隔离** | 限制访问来源 IP，数据库部署在内网 |
| **补丁管理与安全配置** | 及时更新 DBMS 补丁，关闭不必要的服务和端口 |

### 4. 计算机与信息安全技术相关标准（了解）

| 标准 | 说明 |
| --- | --- |
| **TCSEC（橘皮书）** | 美国国防部《可信计算机系统评估准则》，将安全等级分为 D、C（C1、C2）、B（B1、B2、B3）、A（A1）四级七等 |
| **CC（通用准则，ISO/IEC 15408）** | 国际通用的信息技术安全评估标准，我国采用 GB/T 18336 等同采用 |
| **GB 17859-1999** | 我国《计算机信息系统安全保护等级划分准则》，分为五级：第一级用户自主保护级、第二级系统审计保护级、第三级安全标记保护级、第四级结构化保护级、第五级访问验证保护级 |
| **等级保护 2.0** | 我国网络安全等级保护制度，分五级，是信息系统安全建设的重要依据 |

## 考点提示

- 高频考点：数据库安全性的定义；安全控制的基本方法（认证、授权、视图、加密、审计）。
- 易错点：安全性防范"非法访问"，完整性防范"错误数据"——常考概念辨析题。
- 最小权限原则、SQL 注入是常考的简答题切入点。
