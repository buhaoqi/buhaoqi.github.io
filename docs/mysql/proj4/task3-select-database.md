## 知识点

### 1.什么是当前数据库？为什么需要选择当前数据库？

答：在MySQL数据库中，通常会有多个数据库存在，用户在进行查询、修改等操作时，都需要选定某个数据库才能继续进行，这个特定的数据库称为当前库（当前数据库）。创建了数据库之后，该数据库并不会自动成为当前数据库，要选定或使用某个数据库作为当前数据库，必须执行明确的操作。

### 2.选择数据库的语法格式是什么？

答：选择数据库的基本语法格式为：
```
USE <数据库名>
```
该语句用于指定某个数据库作为当前默认的数据库，执行后可以对当前数据库及其存储的数据对象执行各种操作。

### 3.如何验证当前正在使用的数据库？

答：使用 `SELECT DATABASE()` 语句可以测试当前正在使用的数据库。例如：
```
mysql> USE db_student;
Database changed

mysql> SELECT DATABASE();
+------------+
| DATABASE() |
+------------+
| db_student |
+------------+
```
执行USE命令后提示"Database changed"表示设置成功，再通过SELECT DATABASE()验证当前数据库确实是db_student。

### 4.如何使用Navicat选择数据库？

答：（1）启动Navicat控制台。
（2）在左侧导航栏展开的数据库列表中双击要选择的数据库对象，或者右击数据库对象，在弹出的快捷菜单中选择"打开数据库"命令。

选择后可以在查询选项卡中输入 `SELECT DATABASE()` 语句验证当前数据库。

### 5.在Navicat中如何切换不同的数据库？

答：在Navicat查询窗口中，可以通过数据库下拉列表框进行不同数据库的切换，直接从下拉列表中选择要使用的数据库即可。也可以在查询选项卡中使用USE语句选择数据库，例如输入 `USE db_student;` 来切换当前数据库。

### 6.选择数据库后可以进行哪些操作？

答：选择当前数据库后，可以对该数据库及其存储的数据对象（如表、视图、查询等）执行各种操作，包括创建表、插入数据、查询数据、修改数据、删除数据等。在进行任何针对特定数据库中数据对象的操作之前，都必须先选择该数据库为当前数据库。
