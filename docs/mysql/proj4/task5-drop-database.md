## 知识点

### 1.删除数据库的语法格式是什么？

答：删除数据库的基本语法格式为：
```
DROP {DATABASE|SCHEMA} [IF EXISTS] <数据库名>
```

删除数据库时将已创建的数据库文件夹从磁盘上清除，数据库中的所有数据也将同时被删除。

### 2.IF EXISTS选项在删除数据库时的作用是什么？

答：在使用DROP删除数据库时，若待删除的数据库不存在，MySQL服务器会报错。使用IF EXISTS选项后，若MySQL服务器中存在此数据库则删除该库，如果不存在则不执行删除操作，系统不报错，只返回一条警告信息。可以通过 `SHOW WARNINGS` 命令查看警告信息。这与创建数据库时使用IF NOT EXISTS的原理相同。

### 3.删除数据库需要什么权限？删除后会产生什么后果？

答：删除数据库需要具有数据库的DROP权限。

删除数据库的后果非常严重：此命令不仅会删除指定的数据库，该数据库中的所有表以及表中的所有数据也将被永久删除，无法恢复。MySQL缺省安装路径下的对应数据库文件夹也会被删除。

### 4.删除数据库时需要注意什么？

答：DROP语句执行删除数据库的操作时，MySQL不会给出任何提醒确认信息，直接执行删除。因此在执行此操作前，一定要注意：
（1）备份需要保留的数据，确保数据安全。
（2）确认要删除的数据库名称正确，避免误删。
（3）确保不会删除系统数据库（mysql、information_schema、performance_schema、sys），否则会导致MySQL系统不能正常工作。
（4）避免"删库跑路"等违法行为，具备认真严谨的工作态度，坚守良好的职业道德。

### 5.如何使用Navicat删除数据库？

答：（1）在Navicat控制台中，右击要删除的数据库对象。
（2）在弹出的快捷菜单中选择"删除数据库"命令。
（3）弹出"确认删除"对话框，提示确认删除操作。
（4）如果确定要删除，选中"我了解此操作是永久性的且无法撤销"复选框，单击"删除"按钮；否则单击"取消"按钮。
（5）删除成功后，左侧导航栏中该数据库不再显示。

### 6.在Navicat中使用SQL语句删除数据库后需要注意什么？

答：在Navicat查询窗口中输入DROP DATABASE语句并执行后，虽然消息栏显示OK表示删除成功，但导航栏中该数据库可能仍然显示。此时需要右击连接对象，选择"刷新"命令（或按F5键）刷新导航栏，即可看到该数据库已从列表中消失。

### 7.如何查看警告信息？

答：使用 `SHOW WARNINGS` 命令可以查看MySQL服务器返回的警告信息。例如在使用IF EXISTS删除一个不存在的数据库时，系统不报错但会返回警告信息，通过SHOW WARNINGS可以查看具体的警告内容。
