  2. 字符串类型：

  5. 数据库创建、删除命令建议统一写作CREATE DATABASE和DROP DATABASE；SHOW DATABASES与SHOW SCHEMAS均可用于查看数据库。
  6. 候选键是关系模型中的理论概念，UNIQUE是MySQL中的唯一性约束机制，两者不应混为一谈。
  7. DROP TABLE是删除数据表，DROP FOREIGN KEY是删除外键约束，二者作用不同。
  8. MySQL的ALTER PROCEDURE和ALTER FUNCTION主要用于修改特定特性，不能直接重写程序主体；修改主体通常需要删除后重新创建。
