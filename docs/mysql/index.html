考试大纲

1. 数据库基础知识​

1.1 数据库理论基础​

  • 1.1.1 理解数据库相关的基本概念；
  • 1.1.2 掌握数据库系统的特点与结构；
  • 1.1.3 理解概念模型、逻辑模型和物理模型等数据模型的概念；掌握层次模型、网状模型、关系模型等数据模型的概念；
  • 1.1.4 掌握关系模型、表、列、关键字、候选键和外部关键字、域、数据类型等常用关系术语。

1.2 MySQL概述​

  • 1.2.1 了解MySQL系统特性；
  • 1.2.2 了解MySQL服务器的安装与配置；
  • 1.2.3 掌握MySQL服务器的启动与关闭；
  • 1.2.4 掌握MySQL客户端管理工具。

1.3 MySQL编程语言​

  • 1.3.1 了解结构化查询语言SQL的作用和主要特点；
  • 1.3.2 掌握MySQL语言组成；
  • 1.3.3 掌握MySQL聚合函数、数学函数、字符串函数、日期和时间函数和其他常用函数的概念及使用；
    • 聚合函数：COUNT()、SUM()、AVG()、MAX()、MIN()；
    • 数学函数：ABS()、FLOOR()、RAND()、TRUNCATE()、SQRT()、ROUND()；
    • 字符串函数：UPPER()、UCASE()、LEFT()、SUBSTRING()、RTRIM()、REVERSE()、FIELD()、LOCATE()、POSITION()、INSTR()；
    • 日期和时间函数：CURDATE()、CURRENT_DATE()、CURTIME()、NOW()、CURRENT_TIME()、DATEDIFF()、ADDDATE()、SUBDATE()；
    • 其他常用函数：IF()、IFNULL()、VERSION()。

2. 数据定义（DDL）​

2.1 定义数据库​

  • 2.1.1 掌握数据库的创建、查看、选择、修改和删除等操作；
  • 2.1.2 掌握数据库的建立命令：CREATE DATABASE；
  • 2.1.3 掌握选择数据库的命令：USE db_name；
  • 2.1.4 掌握查看数据库的命令：SHOW DATABASES、SHOW SCHEMAS；
  • 2.1.5 掌握修改数据库的命令：ALTER DATABASE、ALTER SCHEMA；
  • 2.1.6 掌握删除数据库的命令：DROP DATABASE、DROP SCHEMA。

2.2 定义表​

  • 2.2.1 掌握MySQL常用的数据类型；掌握创建表、查看表、修改表、重命名表、复制表和删除表的基本操作；
  • 2.2.2 掌握MySQL的常用数据类型：数字类型、字符串类型、日期和时间类型等；
  • 2.2.3 掌握建立数据表的命令：CREATE TABLE；
  • 2.2.4 掌握查看表结构的命令：SHOW COLUMNS、DESCRIBE；
  • 2.2.5 掌握修改表结构的命令：ALTER TABLE；
  • 2.2.6 掌握重命名表的命令：RENAME TABLE；
  • 2.2.7 掌握复制表的命令：CREATE TABLE … LIKE；
  • 2.2.8 掌握删除表的命令：DROP TABLE。

2.3 数据完整性约束​

  • 2.3.1 理解实体完整性、参照完整性、用户定义完整性的概念；
  • 2.3.2 掌握主键、候选键、外键的概念；
  • 2.3.3 掌握完整性约束的命名：CONSTRAINT；
  • 2.3.4 掌握用户定义的完整性；
  • 2.3.5 掌握删除约束命令：DROP TABLE、ALTER TABLE <表名> DROP FOREIGN KEY、ALTER TABLE <表名> DROP PRIMARY KEY、ALTER TABLE <表名> DROP 约束名；
  • 2.3.6 掌握添加约束的相关命令：
    • 建表时添加约束：CREATE TABLE；
    • ALTER TABLE <表名> ADD [CONSTRAINT <约束名>] PRIMARY KEY (主键字段)；
    • ALTER TABLE <表名> ADD [CONSTRAINT <约束名>] FOREIGN KEY (外键字段名) REFERENCES 被参照表(主键字段名)；
    • ALTER TABLE <表名> ADD [CONSTRAINT <约束名>] UNIQUE KEY (字段名)。

3. 数据查询（DML-SELECT）​

3.1 掌握基本查询语句SELECT的使用；​

3.2 掌握单表查询的相关操作：​

  • 3.2.1 查询所有字段：SELECT * FROM <表名>
  • 3.2.2 查询部分字段：SELECT <字段名1>[,字段名2,… ] FROM <表名>
  • 3.2.3 按条件查询：SELECT <字段名1>[,字段名2,… ] FROM <表名> WHERE <条件表达式>

3.3 掌握分组聚合查询：​

SELECT <字段名1>[,字段名2,… ] FROM <表名> GROUP BY <字段名1> [，<字段名2> …] ORDER BY <字段名1>[， <字段名2> …]；

3.4 掌握连接查询：​

SELECT <字段名1> [,字段名2,… ] FROM <表名1> INNER|LEFT|RIGHT JOIN <表名2> ON 表名1.字段名1 = 表名2.字段名2;

3.5 掌握子查询；​

3.6 掌握合并查询结果。​

4. 数据更新（DML）​

  • 4.1 掌握插入数据的语句：INSERT … VALUES、INSERT … SET、INSERT … SELECT；
  • 4.2 掌握修改数据的语句：UPDATE … SET；
  • 4.3 掌握删除数据的语句：DELETE FROM、TRUNCATE TABLE；
  • 4.4 掌握带子查询的删除语句：DELETE FROM … WHERE …=(SELECT)。

  • 5.6 掌握修改数据表结构同时为数据表添加索引的语句：ALTER TABLE … ADD [UNIQUE|FULLTEXT] [INDEX|KEY] index_name；
  • 5.7 掌握删除索引的语句：DROP INDEX、ALTER TABLE … DROP INDEX。
