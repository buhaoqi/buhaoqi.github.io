## 知识点

### 1. MySQL 的基本概念

MySQL 是一个**开源的关系型数据库管理系统（RDBMS）**，使用结构化查询语言（SQL）进行数据管理。

- 由瑞典 MySQL AB 公司开发，后被 Sun 公司收购，现属于 Oracle 公司；
- 采用**客户端/服务器（C/S）**架构：服务器端负责数据存储与管理，客户端负责发起请求；
- 关系型数据库：数据以二维表的形式组织，表与表之间通过外键建立联系。

> MySQL 中的常见概念对应关系：数据库（Database）→ 表（Table）→ 行（Row）/ 列（Column）。

### 2. MySQL 的主要特点与系统特性

1. **开源免费**：源代码开放，使用成本低；
2. **跨平台**：支持 Windows、Linux、macOS 等多种操作系统；
3. **性能高**：支持多线程、查询缓存（旧版本）、索引优化，处理速度快；
4. **支持大型数据库**：可处理上千万条甚至更多记录；
5. **支持多种存储引擎**：InnoDB（默认，支持事务和外键）、MyISAM、MEMORY 等，可根据需求选择；
6. **支持 SQL 标准**：兼容标准 SQL，并扩展了若干实用功能；
7. **安全与灵活**：提供用户权限管理、视图、存储过程、触发器、事件等机制；
8. **易使用、易维护**：安装配置简单，提供命令行和图形化管理工具；
9. **良好的可扩展性**：支持主从复制、分区、集群等高可用方案。

### 3. MySQL 的基本应用场景

- **Web 应用开发**：与 PHP、Java、Python、Node.js 等配合，是 LAMP/LNMP 架构的核心组件；
- **中小型网站与企业信息系统**：如论坛、博客、电商、内容管理系统（CMS）；
- **数据分析与报表**：存储业务数据并提供查询统计；
- **嵌入式与移动应用后端**：作为轻量级数据库服务；
- **教学与学习**：因其开源、易上手，是数据库教学的主流选择。

## 考点提示

- 高频考点：MySQL 是**关系型**数据库管理系统，采用**客户端/服务器**架构，默认存储引擎是 **InnoDB**。
- 易错点：MySQL 是 DBMS（软件），不是数据库（DB）本身。
- 常考特点：开源、跨平台、性能高、支持多种存储引擎。
