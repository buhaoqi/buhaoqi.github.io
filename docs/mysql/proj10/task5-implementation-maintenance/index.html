任务五 数据库的实施和维护

知识点​

1. 什么是数据库实施阶段？​

答：在数据库实施阶段中，系统设计人员要运用DBMS提供的数据定义语言和宿主语言，根据数据库的逻辑设计和物理设计的结果建立数据库，编制与调试应用程序，组织数据入库并进行系统试运行。

2. 数据库实施一般包括哪些步骤？​

答：数据库的实施一般包括四个步骤：

  1. 定义数据库结构：使用DBMS提供的工具建立数据库结构
  2. 组织数据入库：将数据筛选、转换格式、输入并校验
  3. 应用程序的编码与调试：编制与调试应用程序，可使用模拟数据
  4. 数据库试运行：联合调试，测试应用程序的功能和性能

3. 组织数据入库的步骤是什么？​

答：组织数据入库是数据库实施阶段的主要工作。来自各部门的数据通常不符合系统的格式，需要对数据格式进行统一。对于小型系统，可以用人工方法完成数据入库：

  1. 筛选数据：选择需要入库的数据
  2. 转换数据格式：将数据转换为系统要求的格式
  3. 输入数据：将转换后的数据输入数据库
  4. 校验数据：验证数据的完整性和有效性

对于中、大型系统，应设计一个数据输入子系统辅助数据的入库工作。

4. 什么是数据库试运行？包含哪些测试？​

答：在将一部分数据加载到数据库后，就可以开始对数据库系统进行联合调试，这个过程称为数据库试运行。这个阶段要实际运行数据库应用程序，执行对数据库的各种操作，测试应用程序在功能和性能上是否满足设计要求。

试运行的工作主要有两个：

  • 功能测试：运行应用程序，执行各种操作，测试程序是否满足设计要求
  • 性能测试：测量系统的性能指标，分析是否符合设计目标

如果不满足要求，则要对应用程序进行修改、调整，直到满足设计要求为止。

5. 数据库运行维护的基本工作包括哪些？​

答：数据库运行维护的基本工作包括四项：

  1. 数据库的转储与恢复
  2. 数据库的安全性和完整性控制
  3. 数据库的性能监测及分析改进
  4. 数据库的重组和重构

6. 数据库的转储和恢复包括什么内容？​

答：数据库的转储和恢复是系统正式运行后重要的维护工作之一。数据库管理员要针对不同的应用要求制定不同的转储计划，以保证一旦发生故障尽快将数据库恢复到某种一致的状态，并尽可能减少对数据库的破坏。

7. 数据库的安全性和完整性控制包括什么内容？​

答：在数据库运行过程中，由于应用环境的变化，对安全性的要求也会发生变化。例如有的数据原来是机密的，现在变成可以公开查询的了，而新加入的数据又可能是机密的。系统中用户的密级也会变化，这些都需要数据库管理员根据实际情况修改原有的安全性机制。同样，数据库完整性的约束条件也会变化，也需要数据库管理员不断修正。

8. 数据库的性能监测及分析改进包括什么内容？​

答：在数据库运行过程中，监测系统运行、对监测数据进行分析，并找出改进系统性能的方法，是数据库管理员的重要任务。目前有些DBMS产品提供了监督系统性能的参数工具，数据库管理员可以利用这些工具方便地得到系统运行过程中一系列性能参数的值，仔细分析这些数据，判断当前系统运行状况是否最佳，应做哪些改进（如调整物理参数或对数据库进行重组和重构造）。

9. 什么是数据库的重组？与重构有什么区别？​

答：

  • 数据库重组：数据库运行一段时间后，由于记录不断增、删、改，数据库的物理存储情况变坏，降低了数据的存取效率。数据库管理员对数据库进行重组织，按原设计要求重新安排存储位置、回收垃圾、减少指针链等，以提高系统性能。重组不修改原设计的逻辑和物理结构。
  • 数据库重构：由于数据库应用环境的变化，原有的数据库设计不能满足新的需求，需要部分修改数据库的模式和内模式（如增加或删除数据项、改变数据类型、增加或删除表、改变容量、增删索引等）。重构要部分修改数据库的模式和内模式。

10. 数据库重构是无限的吗？​

答：数据库的重构是有限的，只能做部分修改。如果应用变化太多、太大，重构也无济于事，说明此数据库应用系统的生命周期已经结束，应该设计新的数据库应用系统了。

11. 应用程序设计与数据库设计的关系是什么？​

答：数据库应用程序的设计应与数据库的设计同时进行。在编制与调试应用程序的同时，需要实现数据的入库。如果调试应用程序时数据的入库尚未完成，可先使用模拟数据进行调试。应用程序的编码与调试是数据库实施阶段的重要组成部分。

12. 数据库设计的完整流程是什么？​

答：数据库系统设计的基本步骤包括六个阶段：

  1. 需求分析：调查用户需求，建立数据字典和数据流图
  2. 概念结构设计：将需求抽象为信息模型（E-R模型）
  3. 逻辑结构设计：将E-R图转换为关系模型，进行优化
  4. 物理结构设计：选择存取方法，确定存储结构
  5. 数据库实施：建立数据库，组织数据入库，编码调试应用程序，试运行
  6. 数据库运行维护：转储恢复、安全完整性控制、性能监测、重组重构
