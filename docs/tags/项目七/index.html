任务一 单表查询

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务一 单表查询知识点总结。涵盖SELECT语句基本语法、简单查询（ALL/DISTINCT/AS/LIMIT）、条件查询（WHERE/LIKE/BETWEEN AND/IN/IS NULL）、ORDER BY排序、GROUP BY分组与聚合函数、HAVING子句等核心知识点。

任务一 类

算法与程序设计《C#》项目七 面向对象基础 任务一 类知识点总结。介绍类的概念、类的声明语法、类的命名规范、类的成员（字段/属性/方法）、构造函数概念与重载、对象的创建与生命周期、属性声明与get/set访问器、this关键字三种用法，含完整代码示例。

任务三 嵌套查询

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务三 嵌套查询知识点总结。涵盖子查询的概念与分类、比较运算符子查询、IN/NOT IN子查询、EXISTS/NOT EXISTS子查询、ANY/ALL子查询的语法格式与使用方法。

任务二 方法

算法与程序设计《C#》项目七 面向对象基础 任务二 方法知识点总结。介绍方法的概念、方法声明语法、方法命名规范、四种参数类型（值参数/引用参数ref/输出参数out/数组参数params）、static关键字（静态字段/静态属性/静态方法）、静态成员与实例成员的区别，含完整代码示例和运行结果。

任务二 连接查询

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务二 连接查询知识点总结。涵盖内连接（INNER JOIN）、左外连接（LEFT JOIN）、右外连接（RIGHT JOIN）、交叉连接（CROSS JOIN）的语法格式与使用方法，以及连接查询的条件指定方式。

任务五 修改数据

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务五 修改数据知识点总结。涵盖UPDATE语句的语法格式、SET子句设置新值、WHERE子句限定修改范围、多字段同时修改、使用表达式修改、基于多表条件的修改等核心知识点。

任务五 同步训练

算法与程序设计《C#》项目七 面向对象基础 任务五 同步训练。包含7道选择题、5道填空题、5道判断题、2道简答题、1道程序改错题、1道程序分析题，覆盖类与对象概念、方法参数类型、this关键字、构造函数、静态成员等知识点，附答案与解析。

任务六 删除数据

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务六 删除数据知识点总结。涵盖DELETE语句删除指定记录、TRUNCATE TABLE清空表数据、DELETE与TRUNCATE的区别、删除数据时的注意事项等核心知识点。

任务四 同步实验

算法与程序设计《C#》项目七 面向对象基础 任务四 同步实验。包含4道实验题：定义学生类输出姓名年龄、定义图书信息类控制借用数量、学科类构造函数重载修改默认科目、学生录取状态与分数显示，培养面向对象编程综合能力。

任务四 插入数据

数据库原理与应用技术《MySQL》项目七 数据查询与更新 任务四 插入数据知识点总结。涵盖INSERT语句的三种形式：INSERT...VALUES插入单行或多行数据、INSERT...SET指定字段赋值、INSERT...SELECT从查询结果插入数据，以及插入数据时的注意事项。
