考纲新变化

2027年信息技术考试大纲的新变化

一、最核心变化：分值直接翻倍​

项目2026年2027年
职测满分350分350分
信息技术分值约105分（占30%）约210分（占60%）
历史分值约105分（30%）约140分（40%）
综合素质约140分（40%），单独成模块取消单独模块，内容融入历史和信息技术

信息技术从"配角"变成九类职测的绝对大头。

二、考试内容​

考试内容从"办公软件操作"变为"高中课标8大模块"

2026年信息技术考什么​

仅覆盖基础应用类，零散且偏操作：

  • 网络基础
  • 操作系统基础
  • 文字处理（Word）
  • 电子表格（Excel）
  • 幻灯片制作（PowerPoint）

2027年信息技术考什么​

考：高中课标8大模块

模块2026年是否有2027年变化
（一）信息技术基础知识部分有新增"数据、信息、知识"三者关系、大数据与数据分析
（二）数据与编码无（全新）全新模块：二/八/十/十六进制互转、ASCII/Unicode、模拟信号→数字信号、数据加密解密、数据保护
（三）算法基础与编程无（全新）全新模块：算法概念与特征、三种基本结构（顺序/分支/循环）、流程图、编程语言（Python）、递归算法
（四）数据与结构无（全新）全新模块：数据类型（整数/浮点/字符/字符串/布尔）、队列、栈、树、图
（五）信息系统与社会网络基础部分扩展：信息系统组成与功能、计算机/移动终端作用、网络协议、小型网络组建、信息安全风险与防范
（六）信息处理有（Word/Excel/PPT）保留Word、Excel；PPT未再单独列出；明确单元格/工作表/工作簿概念、数据管理分析、图表创建
（七）人工智能基础知识无（全新）全新模块：AI基本概念与特征、发展历程、典型应用与趋势
（八）信息社会责任无（全新）全新模块：信息文化内涵、辩证认识信息技术影响、信息伦理道德与法律法规、负责任地使用信息

三、一张图总结​

哪些是新增、哪些保留、哪些删除

全新增加​

2026年完全不考，2027年必考

  1. 进制转换（二进制↔八进制↔十进制↔十六进制）
  2. 字符编码（ASCII、Unicode）
  3. 数据加密解密与数据保护
  4. 算法三种基本结构（顺序/分支/循环）
  5. 流程图描述算法
  6. Python编程（读代码、判输出）
  7. 递归算法
  8. 数据结构：队列、栈、树、图
  9. 数据类型：整数、浮点数、字符型、字符串、布尔型
  10. 大数据与数据分析
  11. 人工智能基础概念、发展历程、应用
  12. 信息安全风险与防范技术
  13. 信息社会责任（伦理道德、法律法规）
  14. 模拟信号转数字信号

保留并整合​

  • Word文字处理 → 并入"信息处理"
  • Excel电子表格 → 并入"信息处理"，要求更细（单元格/工作表/工作簿、图表）
  • 网络基础 → 并入"信息系统与社会"，扩展到网络协议、设备配置

删除/不再单独考​

  • PowerPoint幻灯片制作：2027年大纲8个模块中未出现
  • 操作系统具体操作：不再单独列点，融入"计算机软硬件基础知识"
  • 原"综合素质"模块（思想道德、沟通能力、科学思维等）：不再单独命题，相关能力融入信息技术的算法题和信息系统题中间接考查

四、对你学习的直接影响​

  1. 必须新增：进制转换、流程图、Python代码阅读、栈/队列/树/图概念、AI基础——这些是2027年全新考点，占了信息技术分值的大头。
  2. 可以精简：PPT制作不用再花时间讲。
  3. Word/Excel不能丢：保留在"信息处理"模块，仍会考。
  4. 网络基础要加深：从"知道有哪些网络"升级到"网络协议、设备配置、安全防范"。
  5. 备考方向：全部对标高中信息技术必修教材，不要再按2026年那种"背办公软件操作步骤"的老路子复习。
