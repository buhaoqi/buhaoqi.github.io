## 知识点

### 1.进位计数制是什么

- 进位计数制简称“进制“。
- 进制是一种通过进位表示数的方法。
- 进制就是“满几进一“的计数规则。十进制是"逢十进一"，二进制是"逢二进一"。

### 2.常见的进制有哪些？

对口升学、中职单招只考查：

- 二进制
- 八进制
- 十进制
- 十六进制

### 3.进制的表示方法

- B — Binary 二进制
- Q — Octal 八进制（O 容易和 0 混淆，教材多用 Q）
- D — Decimal 十进制（可省略不写）
- H — Hexadecimal 十六进制


### 4.数码是什么
数码是进制的合法符号。比如：

- 十进制的数码：0~9
- 二进制的数码：0和1
- 八进制的数码：0 ~ 7
- 十六进制的数码：0 ~ 9 A ~ F

### 5.基数是什么
数码的个数就是基数，用R表示。如十进制基数R是10，二进制基数R是2。



### 6.计算机内部为什么采用二进制存储数据？
答：

1. 二进制只有0、1两种状态
2. 容易用电子元件实现；表示低电压或高电压两种状态。
3. 运算规则简单；便于进行逻辑判断。


### 7.比特是什么
答：

- 比特（bit）也叫位，用小写b表示。
- 是计算机存储数据的最小单位，用来存放一个二进制数字0或者1。


### 8.比特与表示状态的关系是什么

- 1个比特可以表示00和01两种状态
- 2个比特可以表示00、01、10、11四种状态
- 以此类推
- 8个比特可以表示00000000、00000001、...、11111111，也就是256种状态

### 9. 字节是什么
答：经过实践，人们发现使用8位表示一个字节最经济。于是人们规定

> 1字节 = 8比特（1B=8bit）

- 字节的英文是：Byte，简写为大写B


### 10. 写出KB、MB、GB之间的换算关系。
答：

- 1KB = 1024B
- 1MB = 1024KB
- 1GB = 1024MB

### 11.位权是什么

> 好！终于讲到了位权。前面讲的都是铺垫，位权才是进制里最核心、最硬核的概念。只有搞懂位权，你才真正明白一个数在计算机里到底代表多少。

位权，就是“每个位置上的1所代表的真实大小”。

同样是数字1，站在不同位置上，身价完全不同：

个位上的1 → 代表1 十位上的1 → 代表10 百位上的1 → 代表100 千位上的1 → 代表1000

位置变了，1的身价就变了。这个身价，就是位权。

### 12.位权的计算公式是什么

> 位权 = 基数的 N 次方

字母N 表示该数字所在位置的序号。以十进制623为例：

从右往左数，第1位的n是0，第2位的 N是1，第3位的 N是2，依次类推

```
 百位    十位    个位
   6       2       3
   ↓       ↓       ↓
6×10² + 2×10¹ + 3×10⁰
= 600  +  20   +   3
= 623
```

### 15.位权相加法是什么

定义：其他进制转十进制的方法。即：将 R 进制每一位上的数字乘以该位对应的位权，然后全部相加，结果就是对应的十进制数

公式：`N =  d1 * R的n-1次方 + d2 * R的n-1次方`

示例：二进制 1011B 转十进制

```
1011B = 1×2^3+0×2^2+1×2^1+1×2^0 
      = 1×8+0×4+1×2+1×1 
      = 8+0+2+1
      = 11D
```

示例：八进制 25Q 转十进制

```
25Q = 2×8^1 + 5×8^0
    = 16+5
    =21D
```

### 17.除基数取余法是什么
定义：十进制整数转 R 进制整数的方法。

规则：十进制整数反复除以目标进制的基数，记录余数；先得到的余数是低位，后得到的余数是高位，直到商为 0，逆序取出余数。

示例：11D 转二进制
```
11 ÷ 2 = 5 余 1
5 ÷ 2 = 2 余 1
2 ÷ 2 = 1 余 0
1 ÷ 2 = 0 余 1
```

逆序取余：1011，即 11D = 1011B


### 18.乘基数取整法是什么

定义：十进制小数转 R 进制小数的方法。

规则：十进制小数反复乘以目标进制基数，取出整数部分作为对应数位；先取出的整数是小数高位，后取出是低位，直到小数部分为 0 或者达到要求精度。

示例：0.625D 转二进制

```
0.625 × 2 = 1.25 取整数1
0.25 × 2 = 0.5 取整数0
0.5 × 2 = 1.0 取整数1
```
顺序读取：0.101，即 0.625D = 0.101B


### 19.三位分组法是什么
定义：二进制和八进制互相转换专用方法。

二进制→八进制：从小数点向左右两边，每 3 位分成一组；整数左边不足 3 位补 0，小数右边不足 3 位补 0，每组对应 1 位八进制。

八进制→二进制：1 位八进制直接展开成 3 位二进制。

示例：10110B 转八进制
```
分组：010 110
     010→2，110→6
```
结果：10110B = 26Q 

### 20.四位分组法是什么

定义：二进制和十六进制互相转换专用方法。

二进制→十六进制：从小数点向左右，每 4 位一组；整数左侧不足 4 补 0，小数右侧不足 4 补 0，每组对应 1 位十六进制。

十六进制→二进制：1 位十六进制展开为 4 位二进制。

示例：110101B 转十六进制

```
分组：0011 0101
0011→3，0101→5
```
结果：110101B = 35H

### 21.二进制中介法是什么

定义：八进制、十六进制之间互相转换时，不直接转换，先把原进制转为二进制，再用分组法转为目标进制，以二进制作为中间桥梁。

示例：将 26Q 转十六进制
```
①八转二：2→010，6→110，得到 010110B
②重新四位分组：0001 0110
③分组转十六：0001→1，0110→6
```
结果：26Q = 16H

#### 三、简答题参考答案（单招踩分背诵版）
1. **位权相加法**
答：①确定二进制每一位对应的位权（2的n次方，从右从0开始计数）；
②每一位数字 × 对应位权；
③全部乘积相加得到十进制。
例：10010，从右编号：第1位是1，第4位是1
$1×2^4+0×2^3+0×2^2+1×2^1+0×2^0 =16+2=18$

2. **除基数取余法**
答：①将十进制整数反复除以基数2；
②每次记录余数；
③直到商为0；
④**逆序**读取余数，得到二进制。
例：18÷2=9 余0；9÷2=4余1；4÷2=2余0；2÷2=1余0；1÷2=0余1；逆序余数：10010。

3. **幂次拆分法**
答：①把十进制数拆成若干**2的整数次幂相加**；
②有该幂次的位置写1，没有的位置写0；
③按位组合得到二进制。
例：18 = $2^4+2^1$，第4位、第1位为1，其余位0，得到10010。
