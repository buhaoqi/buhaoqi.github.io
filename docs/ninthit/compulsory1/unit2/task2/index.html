2.2 变量入门

一、教学目标​

知识目标

  1. 理解变量是“给数据起名字”。
  2. 掌握变量赋值、命名规则、使用方法。
  3. 认识常见类型：整数、小数、字符串、布尔值。
  4. 会用 input() 接收输入，并做简单类型转换。
  5. 会交换变量、多个变量同时赋值。

技能目标

  • 能正确定义变量并输出。
  • 能发现并改正变量命名错误、类型错误。

重点

  • 变量赋值 变量名 = 值
  • 变量命名规则
  • input() 返回字符串，数字要转换

难点

  • = 与 == 的区别
  • 动态类型：变量可以重新赋值为不同类型
  • 字符串和数字不能直接相加

二、核心知识点清单​

1. 什么是变量​

变量可以理解为“给数据贴标签”。
例如：

score = 100

意思是：把 100 赋值给 score，以后用 score 就能找到 100。

讲解话术：
“变量像贴了名字的盒子，盒子里放数据。名字就是变量名，数据就是值。”

2. 赋值语句​

格式：

变量名 = 值

注意：

  • = 是赋值，不是“等于”。
  • 读作：把右边的值赋给左边的变量。
  • 等于判断用 ==。

示例：

age = 18
name = "小明"
height = 1.75
is_student = True

3. 变量命名规则​

必须遵守：

  1. 只能包含字母、数字、下划线。
  2. 不能以数字开头。
  3. 区分大小写，Age 和 age 是两个变量。
  4. 不能使用 Python 关键字，如 if、else、for、while、class、def、True、False、None。
  5. 不能有空格、连字符。

推荐：

  • 见名知义：student_name、score、age
  • 小写字母 + 下划线：my_age
  • 中文变量名合法，但不推荐。

正反例：

name1 = "对"
my_name = "对"
_score = "对"

1name = "错"
my-name = "错"
class = "错"

4. 使用变量​

定义后可以输出、计算：

name = "小明"
age = 18
print(name)
print("年龄：", age)
print(age + 1)

5. 变量可以重新赋值​

变量后面的值会覆盖前面的值。

x = 10
print(x)   # 10
x = 20
print(x)   # 20

也可以改变类型：

x = 10
x = "hello"
print(x)

这说明 Python 是动态类型语言，变量类型由当前值决定。

6. 常见数据类型与 type()​

初学者先掌握 4 种：

类型含义示例
int整数10, -3
float小数3.14, 1.0
str字符串"Python"
bool布尔值True, False

用 type() 查看类型：

age = 18
print(type(age))   # <class 'int'>

7. input() 与类型转换​

input() 得到的永远是字符串。

name = input("请输入姓名：")
print("你好，", name)

如果要数字运算，必须转换：

age = int(input("请输入年龄："))
print("明年你", age + 1, "岁")

常见转换：

  • int("123") → 123
  • float("3.14") → 3.14
  • str(100) → "100"

错误示例：

age = input("年龄：")
print(age + 1)   # 报错，因为 age 是字符串

8. 多个变量赋值与交换​

同时赋值：

a, b, c = 1, 2, 3

相同值：

a = b = 0

交换两个变量：

a = 10
b = 20
a, b = b, a
print(a, b)   # 20 10

9. 常见错误​

  1. 变量未定义就使用：NameError
  2. 数字开头：1name = 1
  3. 使用关键字：class = 1
  4. 字符串和数字相加："1" + 2
  5. input() 后不转换就运算
  6. 大小写混用：Age 和 age 不同
  7. 把 = 当成 ==

三、建议教学流程（45分钟）​

时间内容
0-5分钟导入：变量像贴标签
5-12分钟赋值语句与使用
12-20分钟命名规则，正反例判断
20-28分钟类型与 type()
28-38分钟input() 与类型转换
38-43分钟多变量赋值与交换
43-45分钟总结、作业

如果只有 40 分钟，可把“交换变量”作为选讲。

四、课堂示例代码​

# 个人信息卡
name = "小明"
age = 18
height = 1.75
is_student = True

print("姓名：", name)
print("年龄：", age)
print("身高：", height)
print("是学生吗：", is_student)

# 输入版
name = input("请输入姓名：")
age = int(input("请输入年龄："))
print("你好，", name, "明年你", age + 1, "岁")

五、课堂互动与练习​

1. 判断变量名是否合法 1name、name1、my_name、my-name、class、_score、姓名

答案：
合法：name1、my_name、_score、姓名（不推荐中文）
不合法：1name、my-name、class

2. 预测输出

x = 10
y = x
x = 20
print(y)

答案：10

3. 改错

age = input("年龄：")
print(age + 1)

改正：

age = int(input("年龄："))
print(age + 1)

4. 小任务 输入两个数字，输出它们的和。

a = int(input("第一个数："))
b = int(input("第二个数："))
print("和：", a + b)

六、板书设计​

变量 = 给数据起名字

赋值：变量名 = 值
= 是赋值，== 是等于

命名：字母数字下划线，不能数字开头
      区分大小写，不用关键字

类型：int float str bool
查看：type()

输入：input() → 字符串
数字：int(input())

交换：a, b = b, a

七、课后作业​

  1. 定义 3 个变量：姓名、年龄、身高，输出自我介绍。
  2. 输入两个数字，输出它们的和。
  3. 定义两个变量并交换它们的值。
  4. 找出 5 个错误变量名并改正。
  5. 输入长方形长和宽，输出面积。

  1. 给变量赋值使用的符号是 ______。
  2. 判断两个值是否相等使用的符号是 ______。
  3. 变量名只能包含字母、数字和 ______。
  4. 变量名不能以 ______ 开头。
  5. 要把字符串 "3.14" 转换成小数，应写：______("3.14")。
  6. input() 返回的数据类型是 ______。
  7. 将字符串 "25" 转换为整数的代码是 ______("25")。
  8. 执行 a, b = 1, 2 后，a 的值是 ______，b 的值是 ______。
  9. 交换 x 和 y 的值，可以写：x, y = ______, ______。
  10. 代码 x = 5; x = "abc"; print(x) 输出 ______。

三、代码题（每题3分，共30分）​

  1. 定义变量 name 为 "小明"，age 为 18，输出：姓名：小明 年龄：18
  2. 输入姓名，输出：你好，xxx
  3. 输入年龄，输出明年年龄。
  4. 输入两个整数，输出它们的和。
  5. 定义 length = 5，width = 3，输出面积。
  6. 定义 a = 10，b = 20，交换后输出 a 和 b。
  7. 输入半径，输出圆面积（π 取 3.14）。
  8. 输入三个整数，输出平均值。
  9. 已知 x = "100"，将其转换为整数并加 1 后输出。
  10. 改正下面代码：age = input("年龄："); print(age + 1)

参考答案​

一、单选题答案​

1B 2B 3C 4C 5B 6A 7B 8C 9A 10C 11B 12D 13B 14B 15B 16C 17A 18B 19B 20B

二、填空题答案​

  1. =
  2. ==
  3. 下划线
  4. 数字
  5. float
  6. 字符串（str）
  7. int
  8. 1；2
  9. y；x
  10. abc

三、代码题答案​

  1. name = "小明"; age = 18; print("姓名：", name, "年龄：", age)
  2. name = input("请输入姓名："); print("你好，", name)
  3. age = int(input("请输入年龄：")); print("明年你", age + 1, "岁")
  4. a = int(input("第一个数：")); b = int(input("第二个数：")); print("和：", a + b)
  5. length = 5; width = 3; print("面积：", length * width)
  6. a = 10; b = 20; a, b = b, a; print(a, b)
  7. r = float(input("请输入半径：")); print("面积：", 3.14 * r * r)
  8. a = int(input("第一个数：")); b = int(input("第二个数：")); c = int(input("第三个数：")); print("平均值：", (a + b + c) / 3)
  9. x = "100"; y = int(x); print(y + 1)
  10. age = int(input("年龄：")); print(age + 1)
