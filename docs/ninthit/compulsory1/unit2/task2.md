> Python 中输出用 `print()` 函数，是必考基础简答、选择、编程题。
语法格式：
```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```
考试重点掌握前4个参数：`objects`、`sep`、`end`，后面两个了解即可。

## 一、基础用法：输出内容
### 1. 输出字符串（引号包裹，单双引号都可以）
```python
print("Hello Python")
print('对口升学')
```
✅ 特点：原样输出引号里面的文字，**引号不会打印出来**。

### 2. 输出数字、表达式（不加引号，会计算）
```python
print(66)          # 直接输出数字
print(10 + 20)     # 先计算，输出结果30
print(10 * 5)
```

### 3. 同时输出多个内容（多个对象，逗号隔开）
```python
print("总分", 580, "分")
```
👉 默认：多个内容之间**用空格隔开**，就是 `sep` 默认值 `sep=' '`

---
## 二、sep 参数：设置多个输出项之间的分隔符
sep：separator，分隔符，默认是空格
```python
# 默认sep是空格
print(1,2,3)        # 输出：1 2 3

# 修改sep为短横线
print(1,2,3, sep="-")   # 输出：1-2-3

# sep设置为空，紧贴在一起
print("2026","10","23", sep="")  # 输出：20261023
```

## 三、end 参数：设置输出末尾符号（高频考点！）
end 默认值是 `end='\n'`，`\n` 是**换行符**，默认打印完自动换行。
```python
# 默认，自动换行
print("A")
print("B")
#输出
A
B

# end="" 末尾不加换行，下一个print接在同一行
print("A", end="")
print("B")
#输出：AB

# end="---" 末尾加横线，不换行
print("开始", end="---")
print("结束")
#输出：开始---结束
```
> 考点简答：`\n` 代表换行；`\t` 制表符（tab缩进）

## 四、格式化输出（对口升学常考三种）
### 方式1：f-string（推荐）
```python
name = "张三"
score = 560
print(f"学生{name}，成绩：{score}")
```
大括号 `{变量名}` 里面放变量。

### 方式2：%格式化（老式，考题里经常出现）
```python
name = "张三"
score = 560
print("学生%s，成绩：%d" % (name, score))
```
- `%s` 字符串
- `%d` 整数
- `%f` 浮点数（小数）

### 方式3：format() 方法
```python
print("学生{}，成绩{}".format("张三",560))
```

## 五、转义字符（选择题、填空题考点）
放在字符串里面，`\` 开头
|转义字符|作用|
| ---- | ---- |
|`\n`|换行|
|`\t`|水平制表符（空4格左右）|
|`\\`|输出一个反斜杠\ |
|`\"`|输出双引号|
|`\'`|输出单引号|

示例：
```python
print("第一行\n第二行")
```

> 如果想让转义字符失效，原样输出，用原始字符串 `r""`
```python
print(r"第一行\n第二行")
#直接打印文字：第一行\n第二行，不会换行
```

## 六、补充考点简答背诵版（直接背）
1. print()作用：向控制台（屏幕）输出数据。
2. sep参数：控制多个输出对象之间的分隔符号，默认空格。
3. end参数：控制输出结尾的符号，默认是换行符`\n`，默认打印后换行。
4. 多个输出项用逗号隔开传给print，逗号不是字符串拼接，自动加sep分隔。

⚠️ 易错题区分：
```python
print("a"+"b")   # + 是字符串拼接，输出ab，只能字符串相加
print("a","b")   # 逗号分隔两个参数，默认空格隔开，输出a b
```
