## 考点

## Python是解释型语言

1. Python 代码不需要先整体编译成机器码，而是由 **Python 解释器逐行翻译并执行**。
2. 解释型语言和编译型语言的区别，知道 **Python 是解释型语言**。
3. 能应对单招考试中的判断题、选择题：**“Python 是编译型语言”是错误的**。


### 比喻一：翻译官

> 你面前有一本英文书。
>
> - **编译型语言**：先把整本书全部翻译成中文，装订成一本新书，你再去读。
> - **解释型语言**：你直接读英文书，旁边坐着一个翻译官，你读一句，他翻译一句，你马上就能听懂。
>
> Python 就是那个“有翻译官”的语言。这个翻译官就是 **Python 解释器**。

### 比喻二：做菜

> - **编译型**：先把菜谱全部翻译成中文，抄一遍，然后照着做。
> - **解释型**：你拿原文菜谱，旁边站个翻译，你说一步，他翻一步，你跟着做一步。
>
> Python 不需要提前生成“翻译好的菜谱”，而是边做边翻译。

### 编译型语言 VS 解释型语言

| 对比项 | 编译型语言 | 解释型语言 |
|---|---|---|
| 代表语言 | C、C++ | Python、JavaScript |
| 执行方式 | 先整体编译成机器码，再运行 | 由解释器逐行翻译并执行 |
| 是否生成可执行文件 | 通常会生成 `.exe` 等 | 一般不生成，直接运行 `.py` |
| 运行速度 | 较快 | 相对较慢 |
| 开发效率 | 较低 | 较高 |
| 跨平台性 | 较差 | 较好 |

> 教师话术：  
> “Python 不是先把所有代码变成电脑能懂的机器码，而是你写一句，解释器就翻译一句、执行一句。所以它叫解释型语言。”

### 四、课堂讲解步骤（建议 8—10 分钟）

#### 第 1 步：提问引入

> “如果让你读一本英文书，你希望先把整本翻译好，还是旁边坐个翻译官一句一句翻？”
>
> 学生一般会选“翻译官”，因为方便、灵活。
>
> 教师接着说：“Python 就是这种‘有翻译官’的语言。”

#### 第 2 步：给出简单定义

> Python 是一门**解释型语言**。  
> 我们写好的 `.py` 代码，不需要先整体编译，而是交给 **Python 解释器**，由它一行一行翻译并执行。

#### 第 3 步：展示执行过程

板书或 PPT：

```text
编写 Python 代码（.py）
        ↓
Python 解释器
        ↓
逐行翻译并执行
        ↓
输出结果
```

对比编译型：

```text
编写 C 代码（.c）
        ↓
编译器
        ↓
生成机器码 / .exe
        ↓
运行
```

#### 第 4 步：用一段代码演示

```python
print("你好")
print("Python")
```

教师说：

> “解释器先看到第一行，翻译并执行，屏幕上出现‘你好’；然后再看第二行，翻译并执行，出现‘Python’。如果第一行有错，它可能到第一行就停下来了，不会像编译型那样先整体检查完再运行。”

#### 第 5 步：点明考试考点

> 单招判断题经常考：  
> **“Python 是一种编译型语言。”** → 错误。  
> **“Python 代码由解释器逐行解释执行。”** → 正确。

### 五、考试易错点提醒

1. Python 是**解释型**语言，不是编译型。
2. Python 代码文件扩展名是 `.py`。
3. Python 解释器负责把代码逐行翻译并执行。
4. 解释型语言通常开发快、跨平台好，但运行速度比编译型慢。
5. 不要和“Python 是高级语言”混淆：高级语言是按层次分，解释型是按执行方式分。

### 七、一句话总结

> **Python 是解释型语言，解释器就像翻译官，你写一句，它翻一句、执行一句。考试记住：Python 不是编译型语言。**

### 第3页：Python是什么
- Python是一种**解释型**、面向对象、动态数据类型的高级程序设计语言。
- **特点**：简单易学、代码少、功能强。
- **小知识**：Python的名字来自“蒙提·派森的飞行马戏团”，不是蟒蛇。
- **考试提醒**：判断题常考“Python是编译型语言”——**错误**，它是解释型。


### 第4页：第一个Python程序——print()
- `print()` 函数：把括号里的内容**输出**到屏幕上。
- 示例：
  ```python
  print("Hello, World!")
  print("你好，Python!")
  ```
- **强调**：字符串要用引号（单引号或双引号都可以）。
- **运行结果**：
  ```
  Hello, World!
  你好，Python!
  ```


### 第5页：print()的更多用法
- 输出数字：`print(100)` → `100`
- 输出表达式：`print(3 + 5)` → `8`
- 输出多个内容：`print("年龄：", 18)` → `年龄： 18`（逗号分隔，中间有空格）
- **对比**：
  - `print("3 + 5")` → `3 + 5`
  - `print(3 + 5)` → `8`


### 第6页：变量是什么
- 变量就像一个“**盒子**”，用来存放数据。
- 赋值语句：`变量名 = 数据`
- 示例：
  ```python
  age = 18
  name = "小明"
  print(age)
  print(name)
  ```
- **解释**：把18放进`age`盒子，把“小明”放进`name`盒子。


### 第7页：变量的命名规则
- **规则**：
  1. 只能包含字母、数字、下划线，不能以数字开头。
  2. 不能使用Python关键字（如 `if`、`for`、`while`、`class` 等）。
  3. 区分大小写（`age` 和 `Age` 是不同的变量）。
  4. 尽量见名知意。
- **示例判断**：
  - `my_name` ✔
  - `2age` ✘（数字开头）
  - `my-name` ✘（有减号）
  - `if` ✘（关键字）
  - `Age` ✔（但和 `age` 不同）
- **小练习**：下列哪些是合法变量名？


### 第8页：变量的重新赋值
- 变量可以多次赋值，后面的值会**覆盖**前面的值。
- 示例：
  ```python
  x = 10
  print(x)   # 输出 10
  x = 20
  print(x)   # 输出 20
  ```
- **强调**：程序从上到下依次执行。


### 第9页：print()与变量结合
- 示例：
  ```python
  a = 5
  b = 3
  print(a + b)          # 输出 8
  print("a + b =", a + b) # 输出 a + b = 8
  ```
- **注意**：`print("a + b")` 和 `print(a + b)` 的区别。


### 第10页：课堂练习（口头/举手）
1. `print("你好")` 输出什么？
2. `x = 8; print(x)` 输出什么？
3. `x = 8; x = 9; print(x)` 输出什么？
4. `print(4 + 6)` 输出什么？
5. `print("4 + 6")` 输出什么？
6. 下列变量名哪个合法：a) `1x`  b) `x_1`  c) `x-1`  d) `for`


### 第11页：小结
- `print()`：输出内容，字符串加引号。
- 变量：存储数据的盒子，用 `=` 赋值。
- 变量命名：字母数字下划线，不以数字开头，不用关键字，区分大小写。
- 程序从上到下顺序执行。
