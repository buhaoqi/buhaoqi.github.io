## 三、赋值运算符

赋值运算符用于给变量赋值，或者根据变量原来的值计算出新值，再赋回变量。

### 1. 基本赋值 `=`

```python
money = 100
name = "张三"
```

这里的 `=` 不是数学中的等号，而是赋值操作。

### 2. 复合赋值运算符

| 运算符 | 等价写法     | 示例（假设 `x = 10`） | 结果  |
| ------ | ------------ | --------------------- | ----- |
| `+=`   | `x = x + 3`  | `x += 3`              | `13`  |
| `-=`   | `x = x - 3`  | `x -= 3`              | `7`   |
| `*=`   | `x = x * 3`  | `x *= 3`              | `30`  |
| `/=`   | `x = x / 2`  | `x /= 2`              | `5.0` |
| `//=`  | `x = x // 3` | `x //= 3`             | `3`   |
| `%=`   | `x = x % 3`  | `x %= 3`              | `1`   |
| `**=`  | `x = x ** 2` | `x **= 2`             | `100` |

这些示例是分别执行的，不是连续执行。

### 3. 为什么要使用复合赋值？

例如，模拟游戏角色受到伤害：

```python
hp = 100
hp -= 30print(hp)  # 70
```

它相当于：

```python
hp = hp - 30
```

再例如，购物后扣除余额：

```python
balance = 500
price = 128
balance -= price
print(balance)  # 372
```

初学者要记住： `x += 1` 表示把 `x` 的值增加 1，并将结果重新赋给 `x`。它不是单纯的数学等式。
