想让学生真正掌握 Python 的逻辑运算符，我建议重点训练三个核心运算符：`and`、`or`、`not`，再把它们与比较运算符、`if` 分支结合起来。

逻辑运算符的难点不是记住符号，而是能否把一句话中的条件关系，准确地翻译成代码。例如：

- “成绩及格，并且出勤率达标” → `and`
- “可以刷身份证，或者可以使用学生证” → `or`
- “不是会员” → `not`

下面设计了 60 道循序渐进的练习题，从理解结果到独立编程，适合 Python 初学者。建议每个阶段完成后，再进入下一阶段。

# 第一阶段：认识逻辑运算符（1—10）

训练目标：理解 `and`、`or`、`not` 的基本含义。

要求：不运行程序，直接判断每个表达式的结果。

| 题号 | 表达式                 |
| ---- | ---------------------- |
| 1    | `True and True`        |
| 2    | `True and False`       |
| 3    | `False and False`      |
| 4    | `True or False`        |
| 5    | `False or False`       |
| 6    | `not True`             |
| 7    | `not False`            |
| 8    | `not (5 > 3)`          |
| 9    | `(10 > 5) and (3 < 8)` |
| 10   | `(10 < 5) or (3 == 3)` |

建议让学生先记住下面三条规则：

| 表达式    | 结果规律                     |
| --------- | ---------------------------- |
| `A and B` | 两边都为真，结果才为真       |
| `A or B`  | 两边至少一个为真，结果就为真 |
| `not A`   | 把真假结果反过来             |

# 第二阶段：逻辑运算符与比较运算符（11—20）

训练目标：把比较表达式与逻辑运算符组合起来，理解多个条件如何共同决定结果。

给定变量：

```
age = 20score = 85money = 50is_member = True
```

要求：判断每个表达式的结果，并说明理由。

| 题号 | 表达式                                            |
| ---- | ------------------------------------------------- |
| 11   | `age >= 18 and score >= 60`                       |
| 12   | `age < 18 or score >= 60`                         |
| 13   | `age >= 18 and score < 60`                        |
| 14   | `money >= 100 or is_member`                       |
| 15   | `not is_member`                                   |
| 16   | `not (age < 18)`                                  |
| 17   | `score >= 80 and score <= 100`                    |
| 18   | `age < 18 or money < 0`                           |
| 19   | `not (score < 60)`                                |
| 20   | `(age >= 18) and (score >= 60) and (money >= 50)` |

加练： 把 `score = 85` 改为 `score = 55`，重新判断第 11、12、13、17、19、20 题。

这个环节很重要：学生必须学会从左到右分析每个条件，而不是凭感觉猜整个表达式的结果。

# 第三阶段：`and`——多个条件必须同时满足（21—30）

训练目标：把“必须同时满足”的需求转换成 `and`。

要求：编写完整的 Python 程序，使用 `if` 判断。

| 题号 | 练习题                                                       |
| ---- | ------------------------------------------------------------ |
| 21   | 输入年龄，年龄大于等于 18 且小于等于 60 时，输出“符合年龄要求”。 |
| 22   | 输入成绩，成绩大于等于 60 且小于等于 100 时，输出“成绩有效”。 |
| 23   | 输入一个整数，如果它大于 10 且小于 20，输出“符合范围”。      |
| 24   | 输入用户名和密码，用户名为 `admin` 且密码为 `123456` 时，输出“登录成功”。 |
| 25   | 输入身高和年龄，身高大于等于 160 厘米且年龄大于等于 18 岁时，输出“符合报名条件”。 |
| 26   | 输入商品价格和库存数量，价格大于 0 且库存大于 0 时，输出“商品可以购买”。 |
| 27   | 输入数学成绩和英语成绩，两门成绩都大于等于 60 分时，输出“两门都及格”。 |
| 28   | 输入一个年份，如果它能被 4 整除且不能被 100 整除，输出“符合普通闰年条件”。 |
| 29   | 输入一个整数，如果它大于 0 且能被 2 整除，输出“正偶数”。     |
| 30   | 输入三个整数，如果三个数都大于 0，输出“三个数都是正数”。     |

第 23 题要特别强调边界：大于 10 且小于 20，意味着 10 和 20 都不符合条件。

```
num = int(input("请输入一个整数："))if num > 10 and num < 20:    print("符合范围")else:    print("不符合范围")
```

学会后，可以进一步简化为：

```
if 10 < num < 20:    print("符合范围")
```

# 第四阶段：`or`——满足任意一个条件即可（31—40）

训练目标：把“满足其中一个条件就可以”的需求转换成 `or`。

| 题号 | 练习题                                                       |
| ---- | ------------------------------------------------------------ |
| 31   | 输入一个整数，如果它小于 0 或大于 100，输出“超出范围”。      |
| 32   | 输入一个整数，如果它能被 3 或 5 整除，输出“符合条件”。       |
| 33   | 输入年龄，如果年龄小于 12 岁或大于等于 60 岁，输出“符合优惠年龄条件”。 |
| 34   | 输入星期数，如果是 6 或 7，输出“今天是周末”。                |
| 35   | 输入用户名，如果用户名是 `admin` 或 `teacher`，输出“允许进入管理页面”。 |
| 36   | 输入一个整数，如果它等于 0 或等于 100，输出“命中指定数值”。  |
| 37   | 输入数学成绩和英语成绩，只要有一门成绩大于等于 90 分，就输出“获得奖励”。 |
| 38   | 输入天气情况（晴天或阴天），如果天气是“晴天”或“阴天”，输出“适合户外活动”。 |
| 39   | 输入一个月份，如果月份是 1、2 或 12，输出“冬季月份”。        |
| 40   | 输入一个整数，如果它不能被 2 整除或不能被 3 整除，输出“至少有一个整除条件不满足”。 |

示例：第 32 题。

```
num = int(input("请输入一个整数："))if num % 3 == 0 or num % 5 == 0:    print("符合条件")else:    print("不符合条件")
```

要提醒学生：第 32 题的意思是“能被 3 整除，或者能被 5 整除”，所以同时能被 3 和 5 整除的数也符合条件。

# 第五阶段：`not`——对条件取反（41—50）

训练目标：理解 `not` 的作用，学会判断“不满足某个条件”的情况。

| 题号 | 练习题                                                       |
| ---- | ------------------------------------------------------------ |
| 41   | 输入一个布尔变量 `is_raining`，如果没有下雨，输出“可以出门”。 |
| 42   | 输入一个整数，如果它不是 0，输出“非零数”。                   |
| 43   | 输入一个成绩，如果它不在 0—100 之间，输出“成绩无效”。        |
| 44   | 输入一个布尔变量 `is_member`，如果不是会员，输出“请先注册”。 |
| 45   | 输入一个整数，如果它不能被 2 整除，输出“奇数”。              |
| 46   | 输入一个整数，如果它不是 10，输出“不是目标数字”。            |
| 47   | 输入用户名和密码，如果用户名或密码有任何一个不正确，输出“登录失败”。 |
| 48   | 输入一个布尔变量 `is_weekend`，如果今天不是周末，输出“正常上课”。 |
| 49   | 输入一个整数，如果它不在 10 到 20 之间（包含 10 和 20），输出“超出范围”。 |
| 50   | 输入一个整数，如果它既不是正数，也不是负数，输出“这个数是零”。 |

示例：第 43 题。

```
score = int(input("请输入成绩："))if not (0 <= score <= 100):    print("成绩无效")else:    print("成绩有效")
```

建议在学生熟练之后，再要求他们把 `not` 改写为不使用 `not` 的等价条件。这样可以加深对逻辑关系的理解。

# 第六阶段：综合应用（51—60）

训练目标：不再直接告诉学生使用 `and`、`or` 还是 `not`，而是要求他们根据实际需求自行分析。

| 题号 | 练习题                                                       |
| ---- | ------------------------------------------------------------ |
| 51   | 考试资格： 输入成绩和出勤率。成绩大于等于 60 且出勤率大于等于 80% 时，输出“允许参加考试”。 |
| 52   | 购物优惠： 输入购物金额和会员状态。金额大于等于 200 元，或者是会员且金额大于等于 100 元时，可以享受优惠。 |
| 53   | 三角形判断： 输入三条边，只有三条边都大于 0，且任意两边之和大于第三边时，才能组成三角形。 |
| 54   | 登录验证： 输入用户名、密码和验证码。三项全部正确才能登录；任意一项错误都要提示“登录失败”。 |
| 55   | 闰年判断： 输入年份，能被 400 整除，或者能被 4 整除但不能被 100 整除时，判断为闰年。 |
| 56   | 商品库存： 输入价格和库存数量。价格小于等于 0 或库存小于等于 0 时，提示“商品信息无效”；否则提示“可以购买”。 |
| 57   | 乘车优惠： 输入年龄和是否持有优惠证件。年龄小于 12 岁，或者持有有效优惠证件时，可以享受优惠。 |
| 58   | 游戏获胜： 输入玩家生命值、攻击力和敌人生命值。玩家生命值大于 0，且攻击力大于等于敌人生命值时，输出“可以一击获胜”。 |
| 59   | 日期初步校验： 输入月份和日期。月份不在 1—12 之间，或者日期不在 1—31 之间时，提示“日期输入无效”。暂不考虑各月份实际天数。 |
| 60   | 智能门禁： 输入是否为员工、是否持有访客许可、当前时间是否在开放时段。员工在开放时段内可以进入；访客必须同时持有访客许可并处于开放时段内。 |

第 60 题可以引导学生先把需求拆成两种允许进入的情况：

- 员工，并且处于开放时段。
- 访客，并且持有许可，并且处于开放时段。

然后再将两种情况组合起来。这样比直接写一长串条件更容易理解。

# 七、教师可以额外安排的挑战题

完成 60 道基础练习后，再用下面 5 道题检查学生是否真的理解逻辑关系，而不是只会照抄代码。

挑战 1：判断表达式

```
a = 5b = 10print(a > 3 and b < 5)print(a > 3 or b < 5)print(not (a < b))
```

要求：先预测三行输出，再运行程序验证。

挑战 2：找出错误

下面的代码想判断成绩是否在 60—100 分之间，但写法有问题。请找出问题并修正。

```
score = int(input("请输入成绩："))if score >= 60 or score <= 100:    print("成绩有效")
```

挑战 3：改写条件

把下面的条件改写为不使用 `not` 的形式：

```
not (age >= 18 and age <= 60)
```

挑战 4：分析边界

条件如下：

```
if score > 60 and score < 100:    print("符合条件")
```

分别输入 `60`、`61`、`99`、`100`，哪些会输出“符合条件”？

挑战 5：综合逻辑

一家游乐园规定：年龄小于 12 岁的儿童，或者年龄大于等于 65 岁的老人，可以享受优惠；但必须持有有效证件。请编写程序判断是否符合优惠条件。

# 八、怎样安排教学，效果最好？

我建议分成 4 次课，每次约 30—45 分钟。

## 01

第一次：看懂真假

练习 1—20

先不写程序，只判断表达式结果。让学生说清楚每个条件为什么成立或不成立。

## 02

第二次：掌握 and 与 or

练习 21—40

重点理解“必须全部满足”和“满足任意一个”。让学生先用中文解释条件，再写代码。

## 03

第三次：理解 not

练习 41—50

要求学生将否定条件改写成正向条件，重点练习范围判断和边界值。

## 04

第四次：综合解决问题

练习 51—60 与挑战题

不提示应该用哪个逻辑运算符，让学生自行分析、编码、测试和解释。

最后给你一个教学上的关键建议： 每道题都让学生做三件事——先用中文说清楚条件，再写出逻辑表达式，最后用至少三个测试数据验证结果。

例如“成绩在 60—100 分之间”，先说“成绩大于等于 60，并且小于等于 100”，再写 `60 <= score <= 100`，最后测试 59、60、100、101。

当学生能够独立完成这三个步骤时，才算真正掌握了逻辑运算符，而不是仅仅记住了 `and`、`or`、`not` 的含义。
