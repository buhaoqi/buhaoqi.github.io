> `input()` 功能：接收用户从键盘输入的数据，**返回值永远是字符串类型 str**，这是最高频考点！
语法：
```python
input([提示文字])
```
参数说明：中括号代表可选参数，是给用户看的提示信息。

## 一、基础用法
### 1. 不带提示
```python
s = input()
print(s)
```
运行后程序暂停，等待键盘输入，回车结束输入，输入内容存入变量`s`。

### 2. 带提示文字（考试最常用）
```python
name = input("请输入你的姓名：")
print(name)
```
> 提示文字只是显示给用户，**不会被当作输入内容**。

## 二、核心考点：input返回值类型（必考！）
✅ `input()` 拿到的所有内容，不管输入数字、字母，**全部是字符串 str**
示例：
```python
num = input("请输入一个数字：")
print(type(num))
```
如果你输入 `100`，`num` 并不是整数，而是字符串 `"100"`。

👉 想做算术运算，必须**强制类型转换**：
```python
# 转整数 int()
a = int(input("请输入整数："))
# 转小数 float()
b = float(input("请输入小数："))
```
错误示范（直接计算会报错）：
```python
a = input("输入a：")
b = input("输入b：")
print(a + b)  
# 输入3和5，结果输出"35"，不是8！是字符串拼接，不是加法
```

正确写法：
```python
a = int(input("输入a："))
b = int(input("输入b："))
print(a + b)
```

## 三、一次性输入多个数据（拓展考点）
配合 `split()` 分割，默认按空格分割
```python
# 输入格式：10 20
x, y = input("请输入两个数，空格隔开：").split()
# 此时x,y依然是字符串，需要转换
x, y = map(int, input("请输入两个数：").split())
print(x + y)
```

## 四、简答背诵要点（直接背，简答题）
1. input() 函数作用：接收键盘上用户输入的数据。
2. input() 的返回类型：**字符串（str）**。
3. 如果想要得到整数，使用 `int(input())`；想要浮点数，使用 `float(input())`。
4. 程序执行到input时，会暂停运行，等待用户输入并按下回车，才继续往下执行。

## 五、易混对比（print 和 input，选择题高频）
- `print()`：输出，程序→屏幕
- `input()`：输入，键盘→程序
