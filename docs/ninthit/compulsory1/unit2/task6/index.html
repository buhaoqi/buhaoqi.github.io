  • 认识比较运算符

想让学生真正掌握 Python 的比较运算符，我建议不要只让他们做“判断两个数谁大谁小”的题，而是按照 看懂表达式 → 判断结果 → 编写条件 → 组合判断 → 解决实际问题 这条路线逐步训练。

比较运算符看起来简单，但初学者很容易在 >、>=、==、!= 和多个条件的组合上出错。下面给你设计了 60 道循序渐进的练习题，可以直接作为课堂练习或课后作业。

一、第一阶段：认识比较运算符（1—10）

训练目标： 理解比较运算符的含义，知道表达式的结果是 True 或 False。

要求：判断每个表达式的结果，不运行程序，直接写出答案。

题号表达式
15 > 3
28 < 2
36 == 6
47 != 7
510 >= 10
69 <= 12
73 + 4 > 6
810 - 5 == 5
92 * 4 != 8
1015 // 2 >= 7

建议让学生不仅写出结果，还要说出理由。例如：第 5 题中，10 等于 10，所以 10 >= 10 的结果是 True。

二、第二阶段：变量与比较运算符（11—20）

训练目标： 将变量的值代入比较表达式，理解变量值变化对判断结果的影响。

要求：根据给定变量，写出表达式的结果。

a = 10b = 6c = 10
题号要求
11判断 a > b 的结果
12判断 a < b 的结果
13判断 a == c 的结果
14判断 a != c 的结果
15判断 b <= 6 的结果
16判断 a >= 11 的结果
17判断 a + b > c 的结果
18判断 a - b == 4 的结果
19判断 a * 2 <= 20 的结果
20判断 a % 2 == 0 的结果

课堂加练： 将 a = 10 改为 a = 11，让学生重新判断第 13、14、16、20 题，观察哪些结果发生了变化。

三、第三阶段：单条件分支（21—30）

训练目标： 将比较运算符用于 if 语句。

要求：编写完整的 Python 程序，不能只写判断表达式。

题号练习题
21输入一个整数，如果大于 0，就输出“正数”。
22输入一个整数，如果小于 0，就输出“负数”。
23输入一个年龄，如果年龄大于等于 18，就输出“已成年”。
24输入一个成绩，如果成绩大于等于 60，就输出“考试通过”。
25输入一个数，如果等于 100，就输出“恭喜，满分！”
26输入一个密码，如果不等于 123456，就输出“密码错误”。
27输入一个整数，如果等于 0，就输出“这个数是零”。
28输入商品价格，如果价格大于 100，就输出“属于高价商品”。
29输入一个整数，如果不等于 0，就输出“非零数”。
30输入一个年份，如果年份大于 2020，就输出“这是 2021 年及以后的年份”。

示例：第 23 题。

age = int(input("请输入年龄："))if age >= 18:    print("已成年")

提醒学生：if 后面的条件必须能够得到布尔值；条件成立时，才会执行缩进的代码。

四、第四阶段：if-else 双分支（31—40）

训练目标： 根据条件成立与否，执行不同的操作。

题号练习题
31输入一个整数，判断它是正数还是非正数。
32输入一个整数，判断它是奇数还是偶数。
33输入一个成绩，判断是否及格，60 分及以上为及格。
34输入一个年龄，判断是否成年，18 岁及以上为成年。
35输入两个整数，输出其中较大的数；如果相等，输出“两个数相等”。
36输入一个整数，判断它是否能被 5 整除。
37输入一个商品价格，满 100 元打九折，否则不打折，输出最终价格。
38输入一个年份，判断它是否为闰年。闰年规则：能被 400 整除，或者能被 4 整除但不能被 100 整除。
39输入一个整数，判断它是否为三位数。
40输入两个数，判断它们是否相等。

第 38 题是很好的综合题，可以检验学生是否理解比较运算符与算术运算符的配合。闰年条件可以写成：

year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)

这里先让学生掌握逻辑条件即可，不必一开始就要求他们熟记复杂的逻辑规则。

五、第五阶段：多个条件组合（41—50）

训练目标： 综合使用比较运算符和 and、or、not，这是从简单判断走向真正编程的重要一步。

题号练习题
41输入一个成绩，如果成绩在 0 到 100 之间（包含边界），输出“成绩有效”。
42输入一个年龄，如果年龄在 18 到 60 岁之间（包含边界），输出“符合条件”。
43输入一个整数，如果它大于 10 且小于 100，输出“符合两位数范围”。
44输入一个整数，如果它小于 0 或大于 100，输出“超出范围”。
45输入一个年份，如果它是闰年，输出“闰年”，否则输出“平年”。
46输入一个整数，如果它既能被 3 整除，又能被 5 整除，输出“符合条件”。
47输入一个整数，如果它能被 3 或 5 整除，输出“符合条件”。
48输入用户名和密码，只有用户名为 admin 且密码为 123456 时，才输出“登录成功”。
49输入一个月份，如果月份小于 1 或大于 12，输出“月份无效”。
50输入三个整数，如果三个数都相等，输出“三个数相等”；否则输出“三个数不全相等”。

第 41 题可以这样写：

score = int(input("请输入成绩："))if score >= 0 and score <= 100:    print("成绩有效")else:    print("成绩无效")

等学生掌握后，再介绍 Python 的链式比较：

if 0 <= score <= 100:    print("成绩有效")

这也是 Python 比较运算符很有特色的用法，值得专门练习。

六、第六阶段：综合应用（51—60）

训练目标： 不再直接告诉学生应该使用哪个运算符，而是让学生根据题意，自己分析条件、选择运算符并完成程序。

题号练习题
51购物优惠： 输入购物金额，满 200 元打八折，否则满 100 元打九折，否则原价，输出最终金额。
52成绩评级： 输入成绩，90 分及以上为优秀，80—89 分为良好，60—79 分为及格，低于 60 分为不及格；超出 0—100 的成绩提示无效。
53三角形判断： 输入三条边的长度，判断能否组成三角形。三条边必须都大于 0，且任意两边之和大于第三边。
54数字比较： 输入三个整数，找出其中的最大值。如果最大值有多个，正常输出最大值即可。
55考试资格： 输入出勤率和成绩，只有出勤率大于等于 80% 且成绩大于等于 60 分，才能获得考试资格。
56登录验证： 输入用户名、密码和验证码，只有三项都正确才允许登录。自行设定正确的用户名、密码和验证码。
57电费计算： 输入用电量，0—100 度每度 0.5 元，超过 100 度的部分每度 0.8 元。输入负数时提示无效。
58快递收费： 输入包裹重量，1 千克及以内收费 8 元，超过 1 千克的部分每千克加收 3 元；重量必须大于 0。
59日期合法性初判： 输入月份和日期，先判断月份是否在 1—12 之间，再判断日期是否在 1—31 之间。暂时不考虑不同月份天数的区别。
60游戏获胜判断： 输入玩家的攻击力、敌人的防御力和敌人的剩余生命值。当攻击力大于防御力，且造成的伤害大于等于敌人剩余生命值时，输出“击败敌人”；否则输出“未能击败敌人”。假设伤害等于攻击力减防御力。

对于第 53 题，可以要求学生先画出判断流程，再写代码。对于第 60 题，可以要求学生把计算伤害和判断是否获胜拆成两步，避免把所有条件塞进一行。

七、怎样安排练习，学生才能真正掌握？

我建议不要把 60 道题一次性全部布置下去，而是分阶段训练。

第一步：看表达式，判断结果

练习 1—20

让学生先脱离键盘，判断 ==、!=、>、>= 等表达式的结果。重点检查他们是否真正理解符号。

第二步：给出需求，独立写代码

练习 21—40

暂时不要给出代码模板。让学生自己决定用 if 还是 if-else，并选择合适的比较符号。

第三步：分析多个条件

练习 41—50

重点训练边界值、and、or 和链式比较。让学生解释为什么使用 >= 而不是 >。

第四步：独立解决实际问题

练习 51—60

不再提示使用哪些运算符。让学生自己分析需求、拆分条件、编写代码，再用不同输入测试。

八、必须专门训练的 5 个易错点​

  1. = 和 == 不一样。 = 是赋值，== 是比较。
  2. > 和 >= 不一样。 如果年龄恰好为 18，age > 18 不成立，而 age >= 18 成立。
  3. 边界值必须测试。 例如及格线是 60 分，就测试 59、60、61，而不只是测试 80 分。
  4. 多个条件不能只看一半。 对于 a > 10 and a < 20，两个条件必须同时成立。
  5. 不要只测试正常数据。 还要测试 0、负数、最大边界值以及不符合输入要求的数据。

最后，我最推荐你在课堂上采用一个方法：每道题都要求学生写出“正常值、边界值、异常值”三组测试数据。例如，成绩有效性判断至少测试 -1、0、100、101。学生不仅会写比较表达式，还会逐渐养成真正的编程思维。
