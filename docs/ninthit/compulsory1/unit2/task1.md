## 知识点
# ✅ 教科版高中信息技术必修1 要求：**只需要安装【Python官方解释器】**
> 课本配套使用 **IDLE**（IDLE是Python解释器自带，不需要单独下载安装）

## 官方Python安装包里包含这4个核心东西（全部一次性装好）
1. **Python解释器（核心）**：电脑读懂、执行Python代码的程序，没有它代码无法运行。
2. **IDLE集成开发环境（课本用！）**：自带代码编辑器+交互式Shell，教科版必修1全部例题、习题都用IDLE，**不用额外装PyCharm、VS Code**。
3. **pip包管理器**：用来后续安装第三方模块（课本基础阶段暂时不用）。
4. **Python标准库**：内置函数、模块（`print()`、`input()`等基础功能都在这里）。

## 安装重点（Windows，考试/学生上机必记）
1. 官网：python.org，下载 **Python3.x（推荐3.8~3.12，不要Python2）**
2. ⚠️ **安装界面左下角一定要勾选 Add Python 3.x to PATH（添加到环境变量）**，这是最容易踩坑的点。
3. 直接点「Install Now」立即安装即可，默认就把IDLE一起装上。

## 区分（给学生讲清楚，避免混淆）
- ✅ **必装：Python解释器（自带IDLE）** → 教科版课本标准环境
- ❌ **不是必须：PyCharm、VS Code**：属于第三方高级编辑器，课本不用，学考不需要
- ❌ **Anaconda**：数据科学发行版，体积很大，高中必修1完全没必要

## 验证是否安装成功
打开cmd，输入：
```
python --version
```
能输出版本号，并且开始菜单能找到 **IDLE**，就成功了。
