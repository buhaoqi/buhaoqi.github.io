Python 常用函数很多，但单招九类职测零基础阶段，重点掌握下面这些**内置函数**就够了。考试中主要是“识读代码、判断输出结果”，不要求默写全部。

## 一、最核心的常用函数

| 函数 | 作用 | 示例 | 结果 |  
|---|---|---|---|
| `print()` | 输出内容 | `print("你好")` | 你好 |
| `input()` | 输入内容，返回字符串 | `input("姓名：")` | 用户输入的内容 |
| `int()` | 转成整数 | `int("123")` | `123` |
| `float()` | 转成浮点数 | `float("3.14")` | `3.14` |
| `str()` | 转成字符串 | `str(100)` | `"100"` |
| `bool()` | 转成布尔值 | `bool(0)` | `False` |
| `type()` | 查看数据类型 | `type(10)` | `<class 'int'>` |
| `range()` | 生成整数序列 | `range(3)` | `0, 1, 2` |
| `len()` | 求长度 | `len("abc")` | `3` |
| `sum()` | 求和 | `sum([1, 2, 3])` | `6` |
| `max()` | 求最大值 | `max(3, 7, 2)` | `7` |
| `min()` | 求最小值 | `min([5, 1, 9])` | `1` |
| `abs()` | 求绝对值 | `abs(-4)` | `4` |
| `round()` | 四舍五入 | `round(3.14159, 2)` | `3.14` |

## 二、按类别记忆

### 1. 输入输出
- `print()`：输出到屏幕
- `input()`：从键盘输入，**返回字符串**

### 2. 类型转换
- `int()`：转整数
- `float()`：转浮点数
- `str()`：转字符串
- `bool()`：转布尔值

### 3. 类型判断
- `type()`：查看变量或数据是什么类型

### 4. 循环与序列
- `range()`：常和 `for` 循环搭配
- `len()`：求字符串、列表等的长度
- `sum()`：对一组数字求和

### 5. 数学运算
- `max()`、`min()`：最大值、最小值
- `abs()`：绝对值
- `round()`：四舍五入

## 三、综合示例

```python
name = input("请输入姓名：")
age = int(input("请输入年龄："))

print("你好，", name)
print("明年你", age + 1, "岁")
```

说明：
- `input()` 得到的是字符串；
- 要做数学运算，需要用 `int()` 转换；
- `print()` 可以一次输出多个内容，用逗号隔开。

## 四、考试高频提醒

1. `range(5)` 生成的是 `0,1,2,3,4`，不是 `1,2,3,4,5`。
2. `input()` 返回的是字符串，不是数字。
3. `int("123")` 可以，`int("abc")` 会报错。
4. `len("hello")` 结果是 `5`。
5. `sum([1,2,3])` 结果是 `6`。
6. `bool(0)`、`bool("")` 是 `False`，其他大多数是 `True`。
7. `type(3.14)` 输出 `<class 'float'>`。
