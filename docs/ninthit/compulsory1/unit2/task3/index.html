Python 常见运算符详解：从入门到熟练使用

在 Python 中，运算符就是用来完成某种运算的符号。例如，+ 用来加法，> 用来比较大小，and 用来组合条件。

对于初学者，建议按照下面的顺序学习：

  1. 算术运算符：计算数值。
  2. 比较运算符：比较大小、判断相等。
  3. 赋值运算符：给变量赋值、更新变量。
  4. 逻辑运算符：组合多个条件。
  5. 成员运算符：判断元素是否存在。
  6. 身份运算符：判断两个变量是否指向同一个对象。
  7. 位运算符：直接操作整数的二进制位。
  8. 运算符优先级：多个运算符同时出现时，确定计算顺序。

一、算术运算符​

算术运算符用于进行数学计算，是 Python 初学者最先接触的一类运算符。

运算符名称示例结果
+加法10 + 313
-减法10 - 37
*乘法10 * 330
/除法10 / 33.333...
//整除（向下取整）10 // 33
%取余10 % 31
**幂运算2 ** 38

1. 加法、减法、乘法​

a = 10
b = 3
print(a + b)  # 13
print(a - b)  # 7
print(a * b)  # 30

这里要注意，+ 不仅可以做数字加法，还可以拼接字符串：

print("Python" + "入门")  # Python入门

但不能直接将字符串和整数相加：

print("年龄：" + 18)  # TypeError

2. 除法 /​

/ 表示普通除法，即使两个数能够整除，结果通常也是 float 类型。

print(10 / 2)  # 5.0
print(7 / 2)   # 3.5
print(type(10 / 2))  # <class 'float'>

应用场景：计算平均数、单价、比例等。

3. 整除 //​

// 表示向下取整除法。它不是简单地删除小数部分，而是将商向负无穷方向取整。

print(10 // 3)    # 3
print(9 // 2)     # 4
print(-10 // 3)   # -4

为什么 -10 // 3 是 -4？

因为：

[ -10 \div 3 \approx -3.333 ]

向下取整后是 -4，而不是 -3。

典型应用： 将总秒数转换为小时、将总数量转换为整箱数、计算某个数字的十位或百位。

seconds = 3675
hours = seconds // 3600
minutes = seconds % 3600 // 60
remaining_seconds = seconds % 60
print(hours, minutes, remaining_seconds) # 1 1 15

4. 取余 %​

% 用于求除法的余数。

print(10 % 3)  # 1
print(12 % 4)  # 0
print(7 % 2)   # 1

它最常见的用途有三个：

用途一：判断奇偶数

num = 7
if num % 2 == 0:    
  print("偶数")
else:    
  print("奇数")

用途二：判断能否整除

num = 15
if num % 5 == 0:    
  print("能被 5 整除")

用途三：提取整数的某一位数字

num = 583
ones = num % 10
tens = num // 10 % 10
hundreds = num // 100
print(ones)      # 3
print(tens)      # 8
print(hundreds)  # 5

注意：Python 的取余结果与除数的符号有关。例如，-10 % 3 的结果是 2，因为 Python 的整除和取余遵循同一套计算关系。

5. 幂运算 **​

** 表示乘方。

print(2 ** 3)   # 8
print(5 ** 2)   # 25
print(9 ** 0.5) # 3.0

其中：

  • 2 ** 3 表示 2 的 3 次方。
  • 5 ** 2 表示 5 的平方。
  • 9 ** 0.5 可以用于计算 9 的平方根。

注意，^ 不是乘方运算符，它是后面要讲的位运算符。

二、比较运算符​

比较运算符用于比较两个值，比较结果是布尔值 True 或 False。

运算符含义示例结果
==等于5 == 5True
!=不等于5 != 3True
>大于5 > 3True
<小于5 < 3False
>=大于或等于5 >= 5True
<=小于或等于3 <= 5True

1. == 和 = 有什么区别？​

这是初学者最容易混淆的地方。

age = 18       # 赋值：把 18 赋给 age
print(age == 18)  # 比较：age 是否等于 18
  • = 是赋值运算符。
  • == 是比较运算符。

错误示例：

if age = 18:    
  print("成年")

这不是合法的 Python 条件表达式，会产生语法错误。

2. 比较运算符的应用​

例如，判断一个人是否成年：

age = 20
if age >= 18:    
  print("已成年")
else:    
  print("未成年")

判断成绩是否及格：

score = 59
if score >= 60:    
  print("及格")
else:    
  print("不及格")

3. Python 支持连续比较​

Python 有一个很实用的特点：可以像数学表达式一样连续比较。

score = 85
print(60 <= score <= 100)  # True

它相当于：

60 <= score and score <= 100

因此，判断成绩是否在 60～100 之间，可以写成：

if 60 <= score <= 100:    print("成绩有效")

这种写法比其他一些编程语言更简洁。

三、赋值运算符​

赋值运算符用于给变量赋值，或者根据变量原来的值计算出新值，再赋回变量。

1. 基本赋值 =​

money = 100
name = "张三"

这里的 = 不是数学中的等号，而是赋值操作。

2. 复合赋值运算符​

运算符等价写法示例（假设 x = 10）结果
+=x = x + 3x += 313
-=x = x - 3x -= 37
*=x = x * 3x *= 330
/=x = x / 2x /= 25.0
//=x = x // 3x //= 33
%=x = x % 3x %= 31
**=x = x ** 2x **= 2100

这些示例是分别执行的，不是连续执行。

3. 为什么要使用复合赋值？​

例如，模拟游戏角色受到伤害：

hp = 100
hp -= 30print(hp)  # 70

它相当于：

hp = hp - 30

再例如，购物后扣除余额：

balance = 500
price = 128
balance -= price
print(balance)  # 372

初学者要记住： x += 1 表示把 x 的值增加 1，并将结果重新赋给 x。它不是单纯的数学等式。

四、逻辑运算符​

逻辑运算符用于组合条件，尤其常用于 if、elif 和 while 语句。

Python 最常见的逻辑运算符有三个：

运算符含义规则
and逻辑与两个条件都成立，结果才成立
or逻辑或至少一个条件成立，结果就成立
not逻辑非将条件的真假反转

1. and：并且​

例如，学生必须同时满足年龄和成绩要求才能参加活动：

age = 20
score = 85
if age >= 18 and score >= 80:    
  print("符合参加条件")
else:    
  print("不符合参加条件")

and 要求两个条件都成立。

条件 A条件 BA and B
TrueTrueTrue
TrueFalseFalse
FalseTrueFalse
FalseFalseFalse

2. or：或者​

例如，会员满足任意一项条件即可获得优惠：

is_member = False
total = 300
if is_member or total >= 200:    
  print("可以享受优惠")
else:    
  print("不能享受优惠")

这里，因为购物金额达到 200 元，所以即使不是会员，也能享受优惠。

条件 A条件 BA or B
TrueTrueTrue
TrueFalseTrue
FalseTrueTrue
FalseFalseFalse

3. not：取反​

is_raining = False
if not is_raining:    
  print("可以考虑户外活动")

not False 的结果是 True，所以条件成立。

4. 综合使用三个逻辑运算符​

age = 20
score = 85
is_banned = False
if age >= 18 and score >= 60 and not is_banned:    
  print("允许参加考试")
else:    
  print("不允许参加考试")

这个条件可以读成：

年龄达到 18 岁，并且成绩达到 60 分，并且没有被禁考。

5. 逻辑运算符的短路特性​

Python 的 and 和 or 有短路求值的特点：

  • and：如果左侧已经为假，就不会再计算右侧。
  • or：如果左侧已经为真，就不会再计算右侧。

例如：

x = 0
if x != 0 and 10 / x > 1:    
  print("条件成立")
else:    
  print("条件不成立")

因为 x != 0 为假，Python 不会继续计算 10 / x，所以不会发生除以零错误。

这在编写安全的条件判断时非常有用。

补充： and 和 or 不一定返回 True 或 False，它们会返回最后实际求值的操作数。例如 0 or 5 的结果是 5。初学阶段可以先掌握条件判断中的用法。

五、成员运算符​

成员运算符用于判断一个值是否存在于某个容器中，常见于字符串、列表、元组、集合和字典。

运算符含义
in存在于其中
not in不存在于其中

1. 判断字符串中是否包含某段文字​

text = "Python 入门教程"
print("Python" in text)      # True
print("Java" in text)        # False
print("Java" not in text)    # True

2. 判断列表中是否存在某个元素​

scores = [70, 85, 92, 60]
if 85 in scores:    
  print("找到了 85 分")

3. 判断用户名是否在允许名单中​

allowed_users = ["村长", "奇奇", "小明"]username = "奇奇"if username in allowed_users:    print("允许登录")else:    print("用户不存在")

4. in 在字典中的特殊规则​

对于字典，in 默认检查的是键（key），不是值（value）。

student = {    "name": "小明",    "age": 18}print("name" in student)  # Trueprint("小明" in student) # False

如果要检查字典中是否存在某个值，需要使用：

print("小明" in student.values())  # True

六、身份运算符​

身份运算符有两个：

  • is：判断两个变量是否指向同一个对象。
  • is not：判断两个变量是否没有指向同一个对象。

这是初学者容易和 == 混淆的地方。

1. == 和 is 的区别​

a = [1, 2, 3]b = [1, 2, 3]print(a == b)  # Trueprint(a is b)  # False

为什么？

  • a == b：比较两个列表的内容是否相等。内容相同，所以为 True。
  • a is b：比较两个变量是否指向同一个对象。这里创建了两个独立的列表，所以为 False。

再看一个例子：

a = [1, 2, 3]b = aprint(a == b)  # Trueprint(a is b)  # True

因为 b = a 让 b 指向了 a 所指向的同一个列表对象。

2. is 最常见的用途：判断 None​

result = Noneif result is None:    print("暂时没有结果")

判断是否为 None 时，推荐使用 is None 或 is not None。

记忆口诀：

  • ==：看内容是否相等。
  • is：看是不是同一个对象。

初学者不需要用 is 来比较整数、字符串等普通数据的值。

七、位运算符​

位运算符直接对整数的二进制位进行操作。对于刚学完 if 和算术运算符的初学者，可以先认识它们，不必马上深入底层原理。

| 运算符 | 名称 | 作用 | |---|---|---| | & | 按位与 | 对应位都为 1，结果位才为 1 | | | | 按位或 | 对应位至少有一个为 1，结果位就为 1 | | ^ | 按位异或 | 对应位不同时结果为 1 | | ~ | 按位取反 | 将整数的二进制位取反 | | << | 左移 | 二进制位向左移动 | | >> | 右移 | 二进制位向右移动 |

1. 按位与 &​

a = 5   # 二进制：0101b = 3   # 二进制：0011print(a & b)  # 1

对齐后逐位计算：

  0101
& 0011
------
  0001

结果为 1。

2. 按位或 |​

print(5 | 3)  # 7
  0101
| 0011
------
  0111

结果为 7。

3. 按位异或 ^​

print(5 ^ 3)  # 6
  0101
^ 0011
------
  0110

结果为 6。

注意：这里的 ^ 是按位异或，不是乘方。Python 的乘方运算符是 **。

4. 按位取反 ~​

print(~5)  # -6

为什么不是简单的 10 或 0？

Python 的整数采用无限精度整数语义，按位取反满足：

[ \sim x = -x - 1 ]

因此，~5 等于 -6。

5. 左移 << 和右移 >>​

print(5 << 1)  # 10print(5 >> 1)  # 2

对于非负整数，左移一位相当于乘以 2，右移一位相当于整除 2。

位运算常见于底层编程、权限标志、协议处理等场景。普通初学者写成绩计算、购物结算时，通常使用不到它们。

八、条件表达式：用一行代码完成简单判断​

严格来说，条件表达式不是独立的运算符类别，但它是 Python 中非常常用的表达式写法。

基本形式：

结果1 if 条件 else 结果2

含义是：如果条件成立，就取前面的结果；否则取 else 后面的结果。

例如，判断奇偶数：

num = 7result = "偶数" if num % 2 == 0 else "奇数"print(result)  # 奇数

等价于：

num = 7if num % 2 == 0:    result = "偶数"else:    result = "奇数"print(result)

再例如，求两个数中的较大值：

a = 10b = 20maximum = a if a > b else bprint(maximum)  # 20

什么时候使用？

适合只有两个结果、判断逻辑简单的场景。如果分支很多，仍然建议使用正常的 if、elif、else，更容易阅读。

九、运算符优先级：多个运算符一起出现时怎么办？​

这是初学者从单个运算符走向综合编程时，必须掌握的知识。

例如：

print(2 + 3 * 4)  # 14

为什么不是 20？

因为乘法的优先级高于加法，先算 3 * 4，再算 2 + 12。

1. 常见运算符优先级（从高到低）​

| 优先级 | 运算符或表达式 | 示例 | |---|---|---| | 高 | () | (2 + 3) * 4 | | 高 | ** | 2 ** 3 | | 较高 | +x、-x、~x | -5、~5 | | 较高 | *、/、//、% | 10 // 3 | | 中 | +、- | 5 + 3 | | 中 | <<、>> | 5 << 1 | | 中 | &、^、| | 5 & 3 | | 较低 | <、<=、>、>=、==、!=、in、is | 5 > 3 | | 较低 | not | not True | | 较低 | and | True and False | | 较低 | or | True or False | | 低 | if ... else ... | 条件表达式 | | 低 | =、+= 等赋值 | x += 1 |

这张表列出的是常见运算符的主要层级，并非 Python 完整优先级表。特别要注意，幂运算 ** 与左侧的一元负号组合时存在特殊规则。

2. 算术运算的优先级​

print(10 + 6 / 2)       # 13.0print((10 + 6) / 2)     # 8.0print(2 ** 3 * 2)       # 16print(2 ** (3 * 2))     # 64

括号可以改变计算顺序。

3. 比较运算与逻辑运算的优先级​

age = 20score = 85print(age >= 18 and score >= 60)  # True

Python 会先计算比较表达式，再计算 and。

但是，实际写代码时，我建议你养成一个习惯：当条件比较复杂时，主动使用括号，让代码更容易读懂。

if (age >= 18) and (score >= 60):    print("符合条件")

这不一定是语法上的必要要求，但对初学者特别有帮助。

4. 一个容易出错的例子​

print(not 5 > 3)  # False

这里先比较 5 > 3，得到 True，再进行 not 取反，得到 False。

等价于：

print(not (5 > 3))

十、容易混淆的运算符对比​

这部分特别适合用来给初学者查漏补缺。

容易混淆的符号区别示例
= 和 ==赋值 vs 比较相等x = 5、x == 5
/ 和 //普通除法 vs 向下取整除法7 / 2 得到 3.5，7 // 2 得到 3
% 和 /求余数 vs 求商7 % 2 得到 1
** 和 ^乘方 vs 按位异或2 ** 3 得到 8
and 和 &逻辑与 vs 按位与True and False、5 & 3
or 和 |逻辑或 vs 按位或True or False、5 | 3
== 和 is内容相等 vs 对象身份相同[1] == [1] 为 True，两个独立列表之间的 is 为 False
not 和 !=逻辑取反 vs 判断不等not (x > 3)、x != 3

十一、综合示例：用多种运算符解决实际问题​

题目：输入一个学生的成绩，判断成绩是否合法、是否及格，并判断成绩是否为偶数。

score = int(input("请输入学生成绩："))if score < 0 or score > 100:    print("成绩无效")else:    if score >= 60:        print("及格")    else:        print("不及格")    if score % 2 == 0:        print("成绩是偶数")    else:        print("成绩是奇数")

这个程序综合使用了：

  • =：给变量赋值。
  • int()：将输入转换为整数。
  • <、>、>=：比较运算符。
  • or：逻辑运算符。
  • %：取余运算符。
  • if、else：分支语句。

它也体现了一个很重要的编程思路：先判断输入是否合法，再处理正常情况。

十二、初学者应该优先掌握哪些运算符？​

第一优先级：必须熟练

+、-、*、/、//、%、**、==、!=、>、<、>=、<=、=、+=、and、or、not

用于算术计算、变量更新和分支语句，是入门编程的核心。

第二优先级：认识并会使用

in、not in、is、is not、条件表达式

随着字符串、列表、字典和对象知识的学习逐步掌握。

第三优先级：后续深入

&、|、^、~、<<、>>

主要用于二进制处理、底层开发及特定算法。

最后，给初学者一个最实用的建议：学习运算符时，不要只背符号的含义。每学一个运算符，都尝试用它解决一个实际问题。例如，用 % 判断奇偶数，用 // 拆分时间，用 and 组合成绩条件，用 += 更新游戏角色的分数。

能够把运算符组合起来解决问题，才算真正学会了运算符。
