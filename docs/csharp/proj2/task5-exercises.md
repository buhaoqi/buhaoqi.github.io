## 知识点

### 同步训练（选择题）

### 1.（ ）是.NET平台的核心部分。

A. .NET Framework
B. C#
C. VB.NET
D. 操作系统

> **答案：A**

### 2.项目文件的扩展名为（ ）。

A. .csproj
B. .cs
C. .sln
D. .suo

> **答案：A**

### 3.利用C#一般可以创建三种应用程序，其中不包括（ ）。

A. 控制台应用程序
B. Windows窗体应用程序
C. SQL程序
D. Web应用程序

> **答案：C**

### 4.在Visual Studio.Net开发环境中，在代码编辑器内输入对象的名称后将自动显示出对应的属性、方法、事件列表，以方便选择和避免书写错误，这种技术被称为（ ）。

A. 自动访问
B. 动态帮助
C. 协助编程
D. 智能感知

> **答案：D**

### 5.在Visual C#.Net中，解决方案和项目之间是（ ）关系。

A. 一个解决方案可以有多个项目
B. 一个项目可以有多个解决方案
C. 一个解决方案只能有一个项目
D. 一个项目只能有一个解决方案

> **答案：A**

### 6.CLR是一种（ ）。

A. 程序设计语言
B. 运行环境
C. 开发环境
D. API编程接口

> **答案：B**

### 7.C#语言源代码文件的后缀名为（ ）。

A. .C#
B. .CC
C. .CSP
D. .CS

> **答案：D**

### 8.构建桌面应用程序需要.NET提供的类库是（ ）。

A. ADO.NET
B. Windows Form
C. XML
D. ASP.NET

> **答案：B**

### 9.C#中导入某命名空间的关键字是（ ）。

A. using
B. use
C. import
D. include

> **答案：A**

### 10.C#中程序的入口方法名是（ ）。

A. Main
B. main
C. Begin
D. using

> **答案：A**（注意：C#区分大小写，Main的M必须大写）
