任务二 Visual C# 2010开发环境

知识点​

子任务一 Visual Studio 2010简介​

1.什么是Visual Studio 2010？​

Visual Studio 2010的全称是Microsoft Visual Studio 2010，简称为VS 2010。它是由微软公司所推出的一款开发环境，不仅可以支持C#、C++、VB等许多种开发语言，而且可以用于创建Windows平台下的应用程序以及网络应用程序。除此之外，它还可以用作创建网络服务、智能设备应用程序以及Office的插件。

VS 2010于2010年4月12日上市，其IDE界面被重新设计和组织，变得更加简单明了。VS 2010同时带来了.NET Framework 4.0、CTP（Community Technology Preview），并且支持开发面向Windows 7的应用程序，数据库方面除了支持Microsoft SQL Server以外，它还支持IBM DB2和Oracle数据库。

2.Visual Studio 2010的九大功能创新是什么？​

  1. C# 4.0中的动态类型和动态编程
  2. 多显示器支持
  3. 支持TDD
  4. 支持Office
  5. Quick Search特性
  6. C++ 0x新特性
  7. IDE增强
  8. 使用Visual C++ 2010创建Ribbon界面
  9. 新增基于.NET平台的函数型程序设计语言Visual F#

3.VS 2010有哪五个版本？​

  • 专业版（Professional）
  • 高级版（Premium）
  • 旗舰版（Ultimate）
  • 学习版（Express）
  • 测试版（Test）

子任务二 Visual Studio 2010环境安装与设置​

4.VS 2010的安装步骤是什么？​

  1. 将Visual Studio 2010安装文件解压，双击运行"autorun.exe"
  2. 在打开的窗体中点击"安装 Microsoft Visual Studio 2010"
  3. 等待加载完成后继续下一步
  4. 选择"我已阅读并接受许可条款"，点击"下一步"
  5. 选择安装功能：完全（安装所有的编程语言和工具）或自定义（选择要安装的编程语言和工具）
  6. 选择安装位置，点击"下一步"
  7. 勾选需要的开发工具（如Visual C#），去掉不需要的，点击"安装"
  8. 等待安装完成

注意：如果安装完成界面出现了很多错误提示，就表示安装失败，需要进一步检查原因，然后重新安装。

5.首次启动VS 2010如何设置？​

从开始菜单启动Microsoft Visual Studio 2010，如果是第一次启动，将会出现"选择默认环境设置"对话框，提示用户选择默认的开发环境设置。在此对话框的列表中选择"Visual C#开发设置"选项，单击"启动Visual Studio"按钮，即可进入VS 2010的起始页界面。

子任务三 Visual Studio 2010项目管理​

6.什么是项目和解决方案？它们之间是什么关系？​

  • 项目：以逻辑方式管理、生成和调试构成应用程序的诸多项，包括创建应用程序所需的引用、数据链接、文件夹和文件等。项目的输出通常是可执行程序（.exe）、动态链接库（.dll）文件或模块等
  • 解决方案：是一类相关项目的集合，一个解决方案可包含多个项目

VS 2010为解决方案提供了指定的文件夹，用于管理和组织该方案下的各种项目和项目组。

7.解决方案资源管理器的作用是什么？​

"解决方案资源管理器"是查看和管理解决方案、项目及其关联项的界面，它将方案中所有关联的项以"树型结构图"的形式分类显示。针对Visual C#，这些项包括：

  • Properties：程序集属性
  • 引用：名字空间
  • Resources：项目用到的资源（如图片、音频、视频等）
  • .cs文件：源文件

8..NET中常见的文件类型有哪些？​

扩展名说明
.sln解决方案文件，为解决方案资源管理器提供显示管理文件的图形接口所需的信息。打开.sln文件，能快速定位打开整个项目的所有文件
.csproj项目文件，创建应用程序所需的引用、数据连接、文件夹和文件的信息
.csC#源代码文件，表示C#源程序文件、Windows窗体文件、Windows用户控件文件、类模块代码文件和接口文件等
.resx资源文件，包括一个Windows窗体、Web窗体等文件的资源信息
.aspxWeb窗体文件，表示Web窗体，由HTML标记、Web服务器控件和脚本组成
.asmxXML Web服务文件，表示Web服务，链接一个特定的.cs文件，用作XML Web services的可寻址入口点
.configWeb.config文件向它们所在的目录和所有子目录提供配置信息
.suo解决方案用户选项，记录所有将与解决方案建立关联的选项，以便在每次打开时都包含用户所做的自定义设置

子任务四 Visual Studio 2010 IDE界面​

9.VS 2010 IDE界面由哪些部分组成？​

VS 2010 IDE主要包括以下组成部分（图2-14）：

（1）标题栏：位于窗口顶部，显示当前正在编辑的项目名称和使用的应用程序名称。

（2）菜单栏：涵盖了VS 2010能够提供的所有命令。可以通过鼠标单击执行菜单命令，也可以通过Alt键加上菜单项上的字母（热键）执行菜单命令。灰色的选项是不可用的。

（3）工具栏：提供了常用命令的快捷访问方式。常用的工具栏有：

  • 标准工具栏：新建项目、添加新项、打开文件、保存、全部保存等
  • 布局工具栏：对齐、间距、叠放层次等
  • 调试工具栏：启动调试、停止调试、全部中断、逐过程、逐语句等

（4）工具箱：提供了Windows窗体应用程序开发所必需的控件，划分为10个选项卡：公共控件、容器、菜单和工具栏、数据、组件、打印、对话框、WPF互操作性、报表、常规。

（5）窗体设计器窗口：开发人员可以使用工具箱中提供的各种控件来对该窗口进行设计。

（6）解决方案资源管理器：提供项目及其文件的有组织的视图，允许对项目和文件进行便捷访问（添加、删除、重命名等）。

（7）属性窗口：允许对Windows窗体应用程序的对象进行属性设置及事件管理。窗口中有五个按钮：按分类顺序、字母顺序、属性、事件、属性页。

（8）代码设计器窗口：用于编写C#代码，包含对象列表框、成员列表框和代码编辑区。代码窗口与窗体设计器窗口在同一位置，但被放在不同的标签页中。

（9）错误列表窗口：程序调试时如果出现错误，将自动弹出该窗口，提供错误提示信息及可能的解决方法。双击错误说明即可定位到错误所在行。

10.工具箱的10个选项卡分别是什么？​

  1. 公共控件
  2. 容器
  3. 菜单和工具栏
  4. 数据
  5. 组件
  6. 打印
  7. 对话框
  8. WPF互操作性
  9. 报表
  10. 常规
