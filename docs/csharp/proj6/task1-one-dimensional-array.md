## 知识点

### 1.什么是数组？

数组是数据的集合，包含若干相同类型的变量，这些变量都可以通过索引进行访问。数组中的变量称为数组的**元素**，数组能够容纳元素的数量称为数组的**长度**。数组中的每个元素都具有唯一的索引与其相对应，数组的索引从**零**开始。

数组是具有相同类型的若干元素按有序的形式组织起来的线性集合，用于存储多个相同类型数据的集合。

特点：
1. 数组是相同数据类型的元素的集合。
2. 数组中的各元素的存储是有先后顺序的，在内存中按照这个先后顺序连续存放在一起。
3. 数组元素用整个数组的名字和它在数组中的顺序位置来表示。例如 `score[0]` 表示第一个元素，`score[1]` 表示第二个元素。

### 2.一维数组的声明语法是什么？

```csharp
type[] arrayName
```

- **type**：数组存储数据的数据类型
- **arrayName**：数组名称

例如，声明一个整数类型的一维数组：

```csharp
int[] score;    //声明了一个整数类型的一维数组
```

### 3.一维数组有哪几种初始化方式？

**方式一**：通过 `new` 运算符创建数组，将元素初始化为默认值

```csharp
int[] score = new int[5];    //创建5个元素的数组，每个元素初始化为0
```

**方式二**：在声明数组时初始化为用户自定义的值

```csharp
int[] score = new int[4]{ 23, 87, 98, 45 };
```

> 注意：数组大小必须与括号中的元素个数相匹配，否则产生编译错误。

**方式三**：省略 `new` 运算符和数组长度，编译器根据初始值数量自动计算

```csharp
string[] arrStr = { "Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat" };
```

### 4.数组元素的默认值是什么？

| 数据类型 | 默认值 |
|---|---|
| 整型、单精度型、双精度型 | 0 |
| 布尔型 | false |
| 字符型 | `'\0'` |
| 字符串型 | null |

### 5.如何通过一维数组求最大值和最小值？

声明一个整型一维数组存放5个数值，求最大值和最小值：

```csharp
static void Main(string[] args)
{
    int[] array = { 10, 30, 20, 15, 18 };
    Console.Write("初始数组：");
    for (int i = 0; i < array.Length; i++)
    {
        Console.Write(array[i] + " ");
    }
    Console.WriteLine();
    int max = array[0], min = array[0];    //假设第一个元素为最大值最小值
    for (int i = 1; i < array.Length; i++)
    {
        if (array[i] > max)
        {
            max = array[i];
        }
        if (array[i] < min)
        {
            min = array[i];
        }
    }
    Console.WriteLine("数组的最大值是：" + max);
    Console.WriteLine("数组的最小值是：" + min);
}
```

**运行结果：**

```
初始数组：10 30 20 15 18
数组的最大值是：30
数组的最小值是：10
```

**算法要点：**
- 先假设数组的第一个元素既是最大值也是最小值
- 从第二个元素开始逐个比较
- 如果当前元素比max大，则更新max
- 如果当前元素比min小，则更新min
- 使用 `array.Length` 属性获取数组长度
