## 知识点(一)
### 1.计算机软件是什么

- 软件是一个总称。
- 软件是程序、文件、数据的总称。
  - 数据：指文字、数值、图片、音频、视频等一切使用二进制表示的信息。
  - 程序：是处理数据的步骤。
  - 文件：存储数据的形式。

### 2. 计算机软件的分类

- 系统软件：是运行、维护、管理计算机的软件。
- 应用软件：解决具体问题~~提供某种需求~~的软件
  - word：处理文字
  - excel：处理表格
  - ppt：处理幻灯片
  - ps：处理图像的软件
  - 抖音：视频社交软件
  - 微信：社交
  - QQ 音乐：音乐软件

### 3.系统软件分为哪几类

- 操作系统：运行、维护、管理计算机的软件（最重要的系统软件）
- 程序设计语言：是一套控制计算机完成特定功能的符号系统。
- 语言处理程序：就是翻译程序。把汇编语言和高级语言编写的程序翻译为二进制代码
- 数据库管理系统：具备管理功能(增删改查)的存储数据的仓库。

### 4.程序设计语言分为哪几类？

- 机器语言（低级）用 0 和 1 编写程序的语言。性能最强，最难学
- 汇编语言(低级)：是符号化的机器语言。性能次强，很难学
- 高级语言（高级）：用人类的语言编写程序。性能最弱，很好学

### 5.操作系统的任务是什么

- 第一：管理资源
- 第二：是用户与计算机的桥梁（接口）

### 6.操作系统的功能是什么

- CPU 管理：分配任务（多线程）
- 文件管理： 对计算机中的文件进行增删改查的管理
- 存储管理：管理内存(释放内存等) + 外存（硬盘分区、磁盘碎片整理）
- 作业管理：管理任务 = 程序 + 数据
- 设备管理：对计算机的各种硬件设备进行增删改查的管理，比如添加打印机

## 知识点(二)

### 1. 操作系统分类的标准有哪些

- 支持的用户数目
- 工作模式
- 应用领域

### 2.根据支持的用户数目，操作系统分为几类

- 单用户操作系统：只支持一个用户使用
- 多用户操作系统：支持多用户使用

### 3. 根据工作模式，操作系统分为几类

- 批处理操作系统：
- 分时操作系统
- 实时操作系统
- 网络操作系统(重点)
- 分布式操作系统( 重点) ： 把一个服务器的任务分布到若干个服务器上共同完成。

### 4. 根据应用领域，操作系统分为哪几类

- 桌面操作系统：用于个人计算机
  - 硬件架构：PC 机和 Mac 机
  - 软件：Windows 操作系统、Unix 操作系统
- 服务器操作系统：安装在大型计算机上的操作系统
- 嵌入式操作系统：就是在各种设备、实物产品中嵌入计算机操作系统。

### 5. 手机操作系统是什么

定义：运行在移动终端上的操作系统。

### 6. 主流的手机操作系统有哪些

- 安卓（美国谷歌）：世界上首个移动操作系统
  - 小米 （MIUI → 澎湃）
  - VIVO
  - OPPO
- IOS(美国 Apple) ： 
- 华为鸿蒙： 2021 年 6 月 2 日 鸿蒙 OS 发布。

### 7. 程序设计语言分为哪几种

- 机器语言
- 汇编语言
- 高级语言

### 8. 机器语言是什么

- 机器语言是 0 和 1 组成的二进制语言，属于“低级语言”
- 机器语言是计算机唯一能听懂的语言
- 机器语言执行效率最高、语法晦涩难懂

### 9.汇编语言是什么

- 是符号化的机器语言，属于“低级语言”
- 汇编语言需要编译(翻译)
- 汇编语言也是面向机器设计的语言

### 10.高级语言是什么

- 用人类的语言设计的编程语言。属于高级语言
- 优点：易读、易学、易维护
- 缺点：必须经过编译或解释，计算机才能执行（性能低）
- 记住：几乎 100% 我们能听到的语言都属于高级语言。

### 11. 语言处理程序是什么

语言处理程序就是把汇编语言或高级语言翻译成计算机能理解的二进制机器语言的程序。

### 12. 语言处理程序的分类

以下是三种翻译方式：

- 汇编程序：这种翻译程序只能翻译汇编语言编写的程序。
- 编译程序：全部翻译完，才能执行程序。
- 解释程序：一边翻译，一边执行程序。

### 13.数据库管理系统是什么

- 简称是 DBMS（ Data Base Management  System）
- 是具有管理功能的存储数据的仓库。
  - 管理功能：增删改查
- 常见数据库：DBASE   FoxBase  FoxPro     SQL    MySQL  Oracle   Access

### 14. 服务型程序是什么

是支持和维护计算机正常工作的系统软件。主要包括：

- 错误诊断
- 程序检查
- 自动纠错
- 测试程序

### 15. 应用软件是什么

解决具体问题~~提供某种需求~~的软件

### 16. 源程序

源程序是用汇编或高级语言编写的程序文件。 源程序不能直接执行

### 17.目标程序

把源程序翻译后的程序，称为目标程序。目标程序可以直接执行
