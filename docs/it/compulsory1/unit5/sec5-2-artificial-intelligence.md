## 知识点

### 1.什么是人工智能

**定义**：人工智能（Artificial Intelligence，**AI**）是**研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统**的一门技术科学。

**通俗理解**：**让机器做那些"原本需要人的智能才能完成"的事**——看、听、说、读、判断、学习、决策。

**AI 的能力范围（四类典型任务）**：

| 能力 | 对应技术 | 例子 |
|---|---|---|
| **感知**（看、听） | 计算机视觉、语音识别 | 人脸解锁、语音输入 |
| **理解**（读懂语言） | 自然语言处理 | 机器翻译、智能客服 |
| **思考**（推理决策） | 知识推理、专家系统、强化学习 | 医疗辅助诊断、下棋 |
| **学习**（从数据中变强） | 机器学习、深度学习 | 推荐系统、图像分类 |

**关键区分**：

| 概念 | 含义 |
|---|---|
| **人工智能** | **最大的范畴**（让机器智能的总称） |
| **机器学习** | 实现 AI 的**一种方法**（让机器从数据中学习规律） |
| **深度学习** | 机器学习的**一种方法**（用多层神经网络） |

**包含关系**：**人工智能 ⊃ 机器学习 ⊃ 深度学习**。

### 2.图灵测试：怎么判断"机器有没有智能"

**提出者**：英国数学家**阿兰·图灵**，1950 年在论文《计算机器与智能》中提出。

**测试方法（模仿游戏）**：

```text
测试者（人）——通过文字（不见面）——同时与 A（人）和 B（机器）对话
若测试者无法可靠地区分哪个是人、哪个是机器，
则判定该机器具有智能（通过图灵测试）。
```

**三个要点**：

1. **只看"行为表现"，不看"内部机制"**——不问机器"你怎么想的"，只看"你答得像不像人"；
2. **用自然语言对话**作为媒介；
3. **至今没有机器被公认真正通过**（早期一些程序靠"抬杠、转移话题"骗过人，被认为是"取巧"）。

**意义与局限**：

- **意义**：第一次给出了**可操作的智能判定标准**，奠定了 AI 的哲学基础；
- **局限**：只测"像不像人"，不测"是否真懂"；也无法衡量"超人类"的智能（如计算器算得比人快，但没人说它有智能）。

**中国的"中文屋"思想实验（塞尔）**：一个人按规则手册把中文问题"对答如流"，但他**并不懂中文**——说明"**表现得懂**"≠"**真的懂**"。这是对图灵测试最著名的批评。

### 3.人工智能的发展历程（关键节点必记）

| 时间 | 事件 | 意义 |
|---|---|---|
| **1950 年** | 图灵发表《计算机器能思维吗》，提出**图灵测试** | AI 的思想起点 |
| **1956 年** | **达特茅斯会议**，**麦卡锡**等人首次提出"**人工智能**"一词 | **AI 作为学科诞生的标志** |
| 1950s~60s | 早期乐观期：跳棋程序、定理证明、机器翻译 | **第一次浪潮** |
| 1970s | 计算能力不足、期望过高 → **第一次低谷** | — |
| 1980s | **专家系统**兴起（如医疗诊断系统 MYCIN） | **第二次浪潮** |
| 1980s 末~90s | 专家系统维护成本高、难以普及 → **第二次低谷** | — |
| **1997 年** | IBM **"深蓝"** 击败国际象棋世界冠军**卡斯帕罗夫** | 计算能力路线的里程碑 |
| **2006 年** | **深度学习**（Hinton 等）取得突破 | 第三次浪潮的技术基础 |
| **2011 年** | IBM **Watson** 在电视问答节目夺冠 | 自然语言理解突破 |
| **2012 年** | 深度神经网络在 **ImageNet** 图像识别大赛中大幅领先 | 深度学习引爆点 |
| **2016 年** | **AlphaGo** 击败围棋世界冠军**李世石** | 强化学习 + 深度学习的标志性事件 |
| 2017 年至今 | Transformer 架构、大语言模型（ChatGPT 等） | **生成式 AI** 时代 |

**记忆口诀**：**"1956 起名，1997 下棋，2016 下围棋"**。

**三次浪潮的共同规律**：**"算法突破 + 算力提升 + 数据积累"三者同时具备，AI 才能跃升**。低谷往往因为**算力不足或期望过高**。

### 4.三大流派（理解各自的"信念"）

| 流派 | 核心信念 | 方法 | 代表成果 | 局限 |
|---|---|---|---|---|
| **符号主义**（符号学派） | 智能 = **符号的逻辑推理** | 把知识写成**规则**，用逻辑推理求解 | **专家系统**、定理证明、深蓝（部分） | **规则写不全**（常识太多）、难以处理感知问题 |
| **连接主义**（神经网络学派） | 智能 = **大量神经元的连接** | 用**神经网络**从数据中学习 | **深度学习**、图像识别、语音识别、AlphaGo | **黑箱**（难解释）、**需要大量数据与算力** |
| **行为主义**（进化学派） | 智能 = **在与环境交互中涌现** | **感知—动作**循环，试错学习 | **智能机器人**、强化学习、波士顿动力 | 复杂任务学习慢、真实环境试错成本高 |

**一句话区分**：

- **符号主义"讲道理"**（按规则推理）；
- **连接主义"凭感觉"**（从数据学模式）；
- **行为主义"靠实践"**（在环境中试错）。

**当代主流**：**以连接主义（深度学习）为主导，融合符号推理（知识图谱）与强化学习**。

### 5.关键技术

#### （1）专家系统（符号主义的典型）

**结构**：

| 组成 | 作用 |
|---|---|
| **知识库** | 存放领域专家的**规则**（IF…THEN…） |
| **推理机** | 根据事实与规则**推导结论** |
| **综合数据库（工作存储）** | 存放当前问题的事实与中间结论 |
| **人机界面** | 与用户交互、解释推理过程 |

**工作过程**：用户输入事实 → 推理机在知识库中**匹配规则** → 推出新事实 → 直到得出结论。

**经典例子**：**MYCIN**（血液感染诊断，准确率接近专家）。

**优点**：**推理过程可解释**（能说出"因为 A 和 B，所以 C"）；
**缺点**：**知识获取困难**（专家经验难以完整表达）、**规则多了会冲突**、**不会学习**。

#### （2）机器学习

**定义**：让计算机**从数据中自动学习规律**，并用于预测或决策，而**不需要显式编程每一条规则**。

**与传统编程的对比（极重要）**：

| | 传统编程 | 机器学习 |
|---|---|---|
| 输入 | **数据 + 规则** | **数据 + 答案（标签）** |
| 输出 | **答案** | **规则（模型）** |
| 人的工作 | 写规则 | **准备数据、调参、评估** |

**三种学习方式（必考）**：

| 类型 | 有无标签 | 任务 | 例子 |
|---|---|---|---|
| **监督学习** | **有标签**（给了正确答案） | **分类**、**回归**（预测数值） | 垃圾邮件识别、房价预测、手写数字识别 |
| **无监督学习** | **无标签** | **聚类**、降维 | 用户分群、商品推荐中的相似用户发现 |
| **强化学习** | 无标签，但有**奖励信号** | **试错学习最优策略** | **AlphaGo**、机器人走路、自动驾驶决策 |

**记忆**：**有答案照着学（监督）、没答案自己分堆（无监督）、给奖惩自己试（强化）**。

**机器学习的一般流程**：

```text
收集数据 → 数据标注/清洗 → 划分训练集与测试集 → 训练模型 → 评估 → 调优 → 部署应用
```

**重要概念**：

- **训练集**：用来"学习"的数据；
- **测试集**：用来"考试"的数据，**必须与训练集分开**；
- **过拟合**：**在训练集上表现很好、在新数据上很差**（"死记硬背"）；
- **欠拟合**：**连训练集都学不好**（"没学会"）。

#### （3）深度学习

**定义**：使用**多层神经网络**（"深度"指层数多）的机器学习方法。

**为什么"深"有用**：**浅层学边缘与颜色 → 中层学纹理与部件 → 深层学物体整体**，逐层抽象，自动提取特征（**不需要人工设计特征**）。

**三大要素（缺一不可）**：

| 要素 | 说明 |
|---|---|
| **算法** | 网络结构（CNN、RNN、Transformer 等） |
| **算力** | **GPU／TPU** 并行计算 |
| **数据** | **大规模标注数据**（ImageNet 上千万张图） |

**典型网络**：

| 网络 | 擅长 | 应用 |
|---|---|---|
| **CNN**（卷积神经网络） | **图像** | 人脸识别、医学影像、自动驾驶感知 |
| **RNN／LSTM** | **序列**（语音、文本） | 语音识别、机器翻译 |
| **Transformer** | **长序列与注意力** | **大语言模型**（GPT 等） |

#### （4）自然语言处理（NLP）

**任务**：让机器**理解与生成人类语言**。

| 任务 | 说明 | 例子 |
|---|---|---|
| **机器翻译** | 一种语言转另一种 | 中英互译 |
| **文本分类** | 判断文本类别 | 情感分析（好评／差评）、垃圾信息识别 |
| **信息抽取** | 从文本中抽结构化信息 | 从简历抽姓名、学历 |
| **问答与对话** | 理解问题并回答 | 智能客服、语音助手 |
| **文本生成** | 生成通顺文本 | 摘要、写作辅助 |

**难点**：**歧义**（"咬死了猎人的狗"）、**上下文依赖**、**常识推理**、**讽刺与隐喻**。

#### （5）计算机视觉

**任务**：让机器"看懂"图像与视频。

| 任务 | 说明 |
|---|---|
| **图像分类** | 判断图中是什么（猫／狗） |
| **目标检测** | 找出**位置**并分类（框出所有行人） |
| **图像分割** | 逐像素分类（抠图、医学病灶分割） |
| **人脸识别** | 身份比对（**注意：与人脸检测不同**） |

**易混**：**人脸检测**（找出"有没有脸、在哪"）≠ **人脸识别**（判断"这是谁"）。

#### （6）语音识别与合成

- **语音识别（ASR）**：声音 → 文字（语音输入、会议记录）；
- **语音合成（TTS）**：文字 → 声音（导航播报、有声阅读）。

#### （7）智能机器人

**组成**：**感知系统**（摄像头、雷达、传感器）+ **决策系统**（算法）+ **执行系统**（电机、机械臂）。

**分类**：工业机器人（焊接、装配）、服务机器人（送餐、扫地）、特种机器人（排爆、深海、太空）。

### 6.人工智能的典型应用

| 领域 | 应用 | 依赖技术 |
|---|---|---|
| **交通** | 自动驾驶、智能调度、车牌识别 | 计算机视觉、强化学习 |
| **医疗** | 影像辅助诊断、药物筛选、健康监测 | 深度学习（CNN） |
| **教育** | 个性化推荐、智能批改、学情分析 | 数据分析、NLP |
| **金融** | 风控、反欺诈、智能投顾 | 机器学习、异常检测 |
| **家居** | 智能音箱、扫地机器人 | 语音识别、SLAM |
| **农业** | 病虫害识别、无人机植保 | 计算机视觉 |
| **安防** | 人脸门禁、行为分析 | 人脸识别、目标检测 |
| **内容** | 推荐系统、AI 写作与绘画、AIGC | 推荐算法、生成模型 |

**推荐系统为什么"懂你"**：**收集你的行为数据（点击、停留、购买）→ 找与你相似的用户或相似的商品 → 预测你可能喜欢什么**。本质是 5.1 讲的"数据分析 + 机器学习"。

### 7.人工智能与人类：机遇与挑战

#### （1）积极影响

- **解放重复劳动**（流水线、客服、数据录入）；
- **提升效率与精度**（医学影像读片、气象预测）；
- **拓展人类能力**（深海探测、太空探索、无障碍辅助）；
- **催生新职业**（数据标注师、AI 训练师、算法工程师）。

#### （2）挑战与风险

| 风险 | 说明 |
|---|---|
| **就业结构冲击** | **重复性、规则性强的岗位**易被替代；**创造性、情感性、复杂决策**岗位相对安全 |
| **算法偏见** | 训练数据有偏见 → 结果歧视某群体（如招聘模型偏向某性别） |
| **黑箱问题** | 深度学习难以解释"为什么这样判断"，医疗、司法等高风险领域难放心使用 |
| **隐私与数据滥用** | 训练需要海量数据，可能侵犯个人信息 |
| **深度伪造（Deepfake）** | 换脸、伪造语音，被用于诈骗与造谣 |
| **责任归属** | 自动驾驶事故、AI 医疗误诊，**谁负责**？ |
| **安全与可控** | 大模型"幻觉"（编造事实）、被恶意诱导 |

#### （3）应有的态度（素质目标）

1. **理性看待**——AI 是**工具**，不是万能，也不是威胁；
2. **人机协同**——**人负责价值判断与创造，机器负责计算与重复**；
3. **保持批判**——对 AI 的输出**核实来源**，不盲信（尤其"幻觉"）；
4. **遵守伦理与法律**——不制作深度伪造、不用 AI 作弊、尊重他人数据与肖像权；
5. **持续学习**——**会被淘汰的不是"不会用 AI 的人"，而是"只会做 AI 能做之事的人"**。

### 8.大数据与人工智能的关系

| 关系 | 说明 |
|---|---|
| **大数据是"燃料"** | 深度学习需要**海量数据**才能训练好 |
| **算力是"发动机"** | GPU 集群支撑大规模训练 |
| **算法是"设计图纸"** | 网络结构与训练方法决定能力上限 |
| **AI 反哺大数据** | AI 用于数据清洗、标注、分析与可视化（5.1 的工具链） |

**一句话**：**"数据、算力、算法"是 AI 的三驾马车**。

### 10.课堂提示（讲课参考）

- **开场做一次"人机对话"**：把两个 AI 回答和一段真人回答混在一起让学生分辨，再引出图灵测试——**体验先于概念**。
- **三大流派用"识别猫"讲**：符号主义要写"有毛、四条腿、有尾巴"的规则（写不全）；连接主义喂几万张猫图自己学（效果好但说不清）；行为主义让机器人追着猫跑学会"猫会跑"（交互中学习）——一个例子讲透三派。
- **"监督/无监督/强化"用三道题对照**：给图与标签分猫狗（监督）、只给图自己分堆（无监督）、下棋赢了加分（强化）。
- **专家系统与深度学习对比讲"可解释性"**：医生更愿意相信能说出理由的系统——这解释了为什么医疗领域至今仍用大量规则系统。
- **伦理部分不要空谈**：用"AI 换脸诈骗""招聘算法歧视女性"两个真实新闻案例，让学生讨论"该由谁负责"，比讲原则有效。
