## 知识点

### 1.本单元要学什么

**单元主题**：信息社会的建设——技术跑得很快，规则与价值观必须跟上。

| 小节 | 核心问题 |
|---|---|
| **5.1 信息社会的伦理与道德** | 该做什么、不该做什么？靠什么约束？ |
| **5.2 信息社会的法律与法规** | 哪些事是违法的？违了要担什么责任？ |
| **5.3 信息社会的未来发展** | 新技术往哪走？我们怎样适应？ |

**三者的关系**：**道德是"高线"（倡导），法律是"底线"（强制），发展是"方向"（趋势）**。

**一句话**：**法律管住"不能做"，道德引导"应该做"，两者共同支撑信息社会的秩序。**

### 2.信息社会是什么

**信息社会**是以**信息活动**为基础、以**信息和知识**为主要资源、以**信息技术**为关键工具的社会形态。

**五个基本特征（必背）**：

| 特征 | 含义 | 生活中的表现 |
|---|---|---|
| **信息资源化** | 信息成为**重要的生产要素与资产** | 数据被称为"新石油" |
| **网络化** | 人与人、物与物**普遍互联** | 移动支付、在线教育、远程办公 |
| **智能化** | 由"人操作机器"转向"机器辅助人" | 推荐算法、智能客服、自动驾驶 |
| **数字化** | 大量活动**从物理空间迁移到数字空间** | 电子证照、线上办事 |
| **全球化** | 信息**跨越国界即时流动** | 跨境协作、全球开源社区 |

**需要注意的另一面**：信息社会在带来便利的同时，也带来**隐私风险、信息过载、数字鸿沟、算法操控**等新问题——**这正是本单元要讨论的内容**。

### 3.信息素养：信息社会的"基本生存能力"

**信息素养**指**能意识到信息需求、并能有效地获取、评价、利用和创造信息**的能力。

**四个层面（可作为一个完整链条记）**：

| 层面 | 要做什么 | 举例 |
|---|---|---|
| **信息意识** | 意识到"我需要什么信息" | 写论文前先想清要查什么 |
| **信息获取** | 会用工具、会检索 | 用关键词、限定来源检索 |
| **信息评价** | 判断**真实性、权威性、时效性** | 分辨自媒体与官方通报 |
| **信息创造与伦理** | 合法合规地使用与创造 | 引用标注来源，不抄袭 |

**信息评价的四问（非常实用，建议学生背下来）**：

1. **谁说的**？（作者／机构是否权威）
2. **什么时候说的**？（是否过时）
3. **依据是什么**？（有无数据与出处）
4. **他想让我相信什么**？（有无立场与利益）

**这四问是抵御谣言与算法操控最有效的思维工具。**

### 4.信息伦理的四大议题

**（1）隐私保护**

| 问题 | 表现 |
|---|---|
| **过度采集** | 一个手电筒 `APP` 要读通讯录、要定位 |
| **超范围使用** | 为办卡收集的信息被用于推销 |
| **非法买卖** | 个人信息被批量出售 |
| **"人肉搜索"** | 公开他人身份信息，引发网络暴力 |

**核心原则**：**最小必要**（只采集业务必需的信息）、**告知同意**（说清用途并取得同意）、**目的限定**（不能挪作他用）。

**（2）知识产权**

| 类型 | 保护对象 | 常见误区 |
|---|---|---|
| **著作权（版权）** | 文字、音乐、图片、视频、软件 | "网上搜到的就能随便用"——**错** |
| **专利权** | 技术方案 | "改一点就不算侵权"——不一定 |
| **商标权** | 品牌标识 | 冒用他人商标 |

**学生最容易踩的三个坑**：

1. **图片、字体、音乐直接商用**——需授权或使用可免费商用的素材；
2. **作业／论文抄袭**——引用要标注来源，直接复制粘贴即为抄袭；
3. **使用盗版软件**——学校教学应使用正版或开源替代（如 `WPS`、`LibreOffice`、`GIMP`）。

**合理使用**：为**学习、研究、评论**等目的少量引用可以，但**必须注明出处**，且**不得影响原作品的正常使用**。

**（3）信息真实性**

| 现象 | 说明 |
|---|---|
| **网络谣言** | 编造或歪曲事实，博取流量或制造恐慌 |
| **断章取义** | 截取片段，曲解原意 |
| **AI 伪造（深度伪造）** | 用 `AI` 换脸、拟声，制造"有图有视频"的假象 |
| **数据造假** | 伪造统计结果支撑结论 |

**"有图有真相"已经失效**：`AI` 生成的图片与视频足以乱真。**判断真伪要看来源与多源印证，不能只看"像不像"。**

**（4）算法公平**

**算法推荐**在提高效率的同时带来三个问题：

| 问题 | 表现 |
|---|---|
| **信息茧房** | 只推你爱看的，视野越来越窄 |
| **算法歧视** | 因性别、地域、年龄给出不同价格或机会 |
| **算法操控** | 用推荐影响情绪、消费甚至观点 |

**"信息茧房"要讲透**：**你看到的不是世界的全部，而是算法认为你想看的那一部分。** 破茧的办法只有一个——**主动接触不同来源、不同立场的优质信息**。

### 5.网络空间的常见失范行为

| 行为 | 性质 | 后果 |
|---|---|---|
| **网络谣言** | 违法（视情节） | 行政处罚，严重者追究刑责 |
| **网络暴力** | 违法 | 侮辱、诽谤可能构成犯罪 |
| **人肉搜索** | 侵犯个人信息权益 | 民事赔偿，情节严重追刑责 |
| **抄袭剽窃** | 侵犯著作权 | 学术处分、民事赔偿 |
| **传播不良信息** | 违法 | 依法处置 |
| **恶意差评／刷单** | 不正当竞争 | 行政处罚、民事赔偿 |
| **破解、外挂** | 侵犯著作权、破坏系统 | 可能构成犯罪 |

**"转发也有责任"** 必须强调：**明知是谣言仍转发扩散，同样要承担责任**。"我只是转发"不是免责理由。

**网络暴力的特点**：**参与门槛极低、传播极快、伤害极重**。一句"随口一说"，汇聚起来可能摧毁一个人。

### 6.青少年网络道德规范（可操作版）

| 规范 | 具体做法 |
|---|---|
| **文明用语** | 不谩骂、不人身攻击、不搞"地域黑" |
| **尊重隐私** | 不传播他人照片、住址、聊天记录 |
| **诚实守信** | 不造谣、不刷单、不冒充他人 |
| **尊重版权** | 转载注明来源，使用正版软件 |
| **理性表达** | 就事论事，不煽动情绪 |
| **适度用网** | 控制时长，不影响学习与睡眠 |
| **保护自己** | 不轻信陌生人，不单独赴约，不外传验证码 |

**"网络不是法外之地"这句话要落到具体**：**屏幕对面是真实的人，键盘敲出的话要负真实的责**。

### 7.数字鸿沟与网络成瘾

**（1）数字鸿沟**

| 层次 | 含义 |
|---|---|
| **接入鸿沟** | 有没有设备、有没有网络 |
| **使用鸿沟** | 会不会用、用来做什么 |
| **素养鸿沟** | 能不能用好、能否辨别与创造 |

**关键认识**：**有了手机不等于跨越了鸿沟**。有人用手机学习、创作，有人只用它娱乐——**真正的差距在"怎么用"**。

**弥合鸿沟的办法**：公共数字服务（图书馆、政务大厅）、适老化改造、学校信息课程、家庭引导。

**（2）网络成瘾**

| 成因 | 表现 |
|---|---|
| **即时反馈**（点赞、弹窗） | 不断刷手机，停不下来 |
| **算法推荐** | 越看越想看 |
| **逃避现实** | 用网络回避学业与人际压力 |
| **社交需求** | 怕错过消息（错失焦虑） |

**应对**：**设定使用时长、关闭非必要推送、培养线下兴趣、保证睡眠与运动、必要时寻求专业帮助**。

**提醒学生**：**"用多久"不是唯一标准，"用来做什么"更重要**——每天用 3 小时学编程，和每天刷 3 小时短视频，性质完全不同。

### 8.人工智能时代的伦理新课题

| 课题 | 说明 |
|---|---|
| **深度伪造** | 换脸、拟声被用于诈骗与造谣 |
| **算法黑箱** | 决策过程不透明，难以追责 |
| **责任归属** | 自动驾驶出事，谁负责？ |
| **偏见放大** | 训练数据有偏见，模型就放大偏见 |
| **学术与创作诚信** | 用 `AI` 生成内容是否署名、能否作为作业 |
| **就业替代** | 部分岗位被自动化取代 |

**基本共识（可作为答题落脚点）**：

1. **科技向善**——技术应用应以增进人的福祉为目的；
2. **人是责任主体**——`AI` 是工具，**责任在人**；
3. **透明与可解释**——重要决策应可追溯、可申诉；
4. **以人为本**——效率不能凌驾于尊严与公平之上。

### 9.信息社会公民的行动准则

**五条"能做到"的准则**（建议作为课堂公约）：

1. **不造谣、不信谣、不传谣**——转发前先查来源；
2. **不侵害他人隐私**——不拍、不传、不"人肉"；
3. **尊重知识产权**——用正版、标来源、不抄袭；
4. **理性表达**——不谩骂、不煽动、不跟风；
5. **保护自己**——强密码、不外传验证码、不轻信陌生人。

**一句话总结**：**做一个"有分寸"的数字公民——知道边界，也守住边界。**

### 11.课堂提示（讲课参考）

- **开场做一次"隐私账单"**：让学生列出手机里至少 10 个 `APP`，逐个想"它要了哪些权限、真的需要吗"。多数人会发现自己把通讯录、位置、相册都给了不需要的软件。**这个活动比讲"隐私很重要"有力得多。**
- **"信息茧房"最好用两台手机对比**：同一时间、同一关键词，用两个不同账号（或新老账号）搜索，结果差异明显。学生亲眼看到"算法在给我看什么"，破茧的自觉就建立了。
- **深度伪造建议现场演示**：用公开的换脸工具做一段 5 秒视频，让学生判断真假。当他们发现"看不出来"时，再讲"要看来源、要多源印证"，效果极佳。
- **网络暴力要讲"被暴力者视角"**：读一段真实的受害者的自述，再问"如果你是转发链上的第 100 个人，你会转发吗"。**道德教育的关键是唤起共情，不是说教。**
- **收尾建议做成"班级数字公约"**：让学生分组讨论并投票，形成 5~8 条全班共同遵守的用网公约，贴在教室。**自己定的规则，才愿意遵守。**
