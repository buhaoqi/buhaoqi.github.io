1.2 信息系统的功能

知识点​

1.从"组成"到"功能"​

1.1 把系统"拆开"看要素，1.2 把系统"合上"看功能。两节的关系可以用一句话概括：

有什么要素，决定了能做什么功能；有什么功能，决定了该配什么要素。

要素主要支撑的功能
输入设备、传感器输入
处理器、程序处理
存储器、数据库存储
显示、打印、网络输出
操作系统、管理制度控制

答题时的通用思路：问"功能"，答"五功能"；问"靠什么实现"，把要素一一对应上去。

2.信息系统的五项基本功能（必背）​

输入 → 处理 → 存储 → 输出 → 控制

功能定义关键动作举例
输入把原始数据采集并送入系统采集、录入、校验、转换扫码、刷卡、键盘录入、传感器上报
处理按既定规则对数据进行运算与判断计算、比对、分类、汇总、排序、检索计算总分、判断余额、统计各科平均分
存储把数据与结果长期保存，供再次使用写入、更新、索引、备份存入数据库表、写入日志文件
输出把处理结果以人能理解的形式呈现显示、打印、导出、推送成绩单、报表、短信通知、网页图表
控制协调各环节有序运行，保证正确与安全流程控制、权限控制、异常处理、日志审计余额不足拒绝交易、越权访问被拦截

容易混的两个概念：

  • "处理"是对数据做运算，"控制"是对过程做管理。计算平均分是处理；规定"只有教务员才能改成绩"是控制。
  • "输出"是给用户看结果，"存储"是给系统留底。同一份数据，既要输出给人，也要存起来备查。

3.输入功能：数据从哪来​

输入是系统的"入口"，输入质量直接决定输出质量——这就是"垃圾进、垃圾出"（GIGO）。

常见的五种输入方式：

方式说明优点缺点／适用
人工录入键盘输入灵活、无需设备慢、易错，适合小批量
设备识读扫码枪、读卡器、RFID快、准需标签或卡片
传感器采集温湿度、光敏、红外等自动上报自动、连续、实时需部署硬件
文件导入批量导入 Excel、CSV效率高需规范模板
网络获取接口调用、网页表单、系统对接跨系统共享依赖对方接口与授权

输入环节的两个关键要求：

  1. 准确——通过校验保证（格式校验、范围校验、必填校验、逻辑校验）；
  2. 规范——编码统一（如学号规则、日期格式 YYYY-MM-DD），否则后续处理会出错。

4.处理功能：系统的"大脑"​

处理是信息系统的核心价值所在——同样的数据，处理方式不同，产出的价值完全不同。

处理的四种基本类型：

类型做什么举例
计算加减乘除、求平均、累计计算总分、算折扣
比对判断与规则或历史数据比较密码是否正确、库存是否不足
分类汇总按条件分组统计按班级统计平均分、按品类统计销量
检索排序查找与排序按学号查人、按成绩排名

处理的两条实现路径：

  1. 程序自动处理——由代码按算法执行，快、准、可重复，是主流方式；
  2. 人工辅助处理——异常情况、复杂判断由人介入，系统提供提示与依据。

性能关注点：处理能力通常用响应时间与并发处理量衡量。像 12306 抢票、双十一秒杀，考验的就是"高并发下的处理能力"。

5.存储功能：系统的"记忆"​

存储解决"数据留得住、找得到、取得快"三个问题。

存储的三个层次（从快到慢、从贵到便宜）：

层次介质特点用途
内存内存条速度极快、断电丢失、容量小程序运行时的临时数据
外存硬盘、固态硬盘、U盘速度较慢、断电保留、容量大长期保存数据与文件
云存储云端服务器可远程访问、可扩容、依赖网络备份、跨设备共享

信息系统中的存储组织：数据库是主要形式，它把数据按表结构组织，支持高效查询、并发访问与权限控制（第3单元详讲）。

存储必须考虑的三件事：

  1. 容量——数据会持续增长，要预留空间；
  2. 备份——防止硬件损坏、误删、勒索病毒（第4单元详讲）；
  3. 安全——敏感数据要加密存储，访问要有权限。

6.输出功能：结果怎么给人看​

输出的本质是"把数据翻译成人能理解、能决策的形式"。

输出形式说明适用场景
屏幕显示界面、弹窗、指示灯实时查询与操作反馈
打印输出报表、票据、证件需要纸质凭证
文件导出Excel、PDF、图片二次加工与存档
消息推送短信、微信、邮件、APP 通知主动提醒（成绩发布、缴费提醒）
可视化大屏图表、地图、仪表盘集中监控与汇报
控制信号继电器、电机指令物联网系统的"动作输出"

输出的三条设计原则：

  1. 准确——不能有歧义（金额、单位、时间格式必须清楚）；
  2. 简洁——一屏之内看到关键信息，不堆砌；
  3. 有用——面向使用者的决策需要，而不是"把所有数据都列出来"。

7.控制功能：系统的"指挥"​

控制是让前四项功能"协同成一个整体"的关键，也是最容易被学生忽略的一项。

控制的四个层面：

层面控制什么举例
流程控制各环节的先后顺序与触发条件先校验再入库；提交后锁定不可改
权限控制谁能做什么学生只能查自己成绩，教务员可录入
异常控制出错时怎么处理网络中断重试、数据非法时提示并拒绝
审计控制留下可追溯的记录记录谁在什么时间改了什么

控制的价值：保证系统的正确性、安全性与可靠性。一个没有控制的信息系统，数据再准也会被误操作毁掉。

闭环控制（拓展，2.5 会用到）：

  • 开环控制：按设定执行，不检测结果（定时浇水，不管土干不干）；
  • 闭环控制：检测结果并反馈修正（土壤湿度低于阈值才浇水）。

8.信息系统的五类（按业务层次）​

这是本小节第二个必背考点，五类系统的服务对象逐层升高。

类型英文缩写服务对象主要任务举例
事务处理系统TPS一线操作人员处理日常具体业务，快而准收银、订票、借还书、刷卡
管理信息系统MIS中层管理者用数据支持计划、组织、控制成绩管理、库存管理、人事管理
决策支持系统DSS高层决策者提供分析模型与方案比较销售预测、选址分析、招生计划测算
专家系统ES需要专业经验的场景模拟专家推理给出建议疾病辅助诊断、设备故障诊断
办公自动化系统OA全体办公人员公文流转、协同办公、信息发布请假审批、通知公告、会议安排

记忆线索：TPS 管"事"、MIS 管"人"、DSS 管"策"、ES 管"专"、OA 管"文"。

层次关系（常考简答）：

  • TPS 处于最底层，产生原始业务数据；
  • MIS 在 TPS 之上，把数据汇总成管理信息；
  • DSS 在 MIS 之上，用模型辅助非结构化决策；
  • 下层为上层提供数据，上层对下层提出要求。

9.信息系统的特点​

特点含义举例
开放性能与外部系统交换数据，可扩展教务系统与支付平台对接
共享性数据与资源可被多用户同时使用多位教师同时录入成绩
实时性能在业务发生时即时响应刷卡秒级扣款、抢票实时锁座
可靠性长时间稳定运行、故障可恢复银行系统 7×24 小时服务
交互性人与系统之间有来有往查询—反馈—修正
可维护性易修改、易升级、易排错模块化设计，功能可插拔
安全性数据不被非法获取、篡改、破坏加密传输、权限分级

答题提醒：特点类题目**不要只写"方便、快捷"**这类空话，要写出"哪个特点 + 具体表现 + 带来什么价值"。

10.功能分析示例：校园一卡通​

（1）功能拆解

功能具体实现
输入刷卡／扫码读取卡号，食堂 POS 机输入消费金额
处理查余额、判断是否足够、扣款、累计当日消费
存储写入消费流水表，更新卡内余额与账户余额
输出POS 机显示扣款金额与余额，微信推送消费提醒
控制余额不足拒绝交易；单笔限额；挂失后立即冻结

（2）它属于哪类系统

  • 按范围：局域网系统（校内）；
  • 按用途：以事务处理（TPS）为主，同时向管理部门提供统计报表（兼有 MIS 功能）。

（3）价值分析（答"意义类"题可用）

  1. 提高效率——替代现金，几秒完成交易；
  2. 降低风险——减少现金保管与找零差错；
  3. 沉淀数据——消费数据可用于分析就餐规律、优化档口配置；
  4. 便于管理——挂失、冻结、限额等手段保障资金安全。

11.速查表​

序号考点结论
1五项基本功能输入、处理、存储、输出、控制
2系统的"入口"输入，质量决定输出（GIGO）
3系统的"大脑"处理
4系统的"记忆"存储
5最易漏写的功能控制
6输入的五种方式人工录入、设备识读、传感器、文件导入、网络获取
7四种数据校验格式、范围、必填、逻辑
8处理的四种类型计算、比对判断、分类汇总、检索排序
9存储三层次内存、外存、云存储
10输出形式显示、打印、导出、推送、可视化、控制信号
11控制四层面流程、权限、异常、审计
12开环与闭环闭环有反馈检测，开环没有
13TPS 服务对象一线操作人员
14MIS 服务对象中层管理者
15DSS 服务对象高层决策者，靠模型
16ES 的核心模拟专家经验推理
17OA 的核心公文流转与协同办公
18系统层次关系TPS → MIS → DSS，下层供数据、上层提要求
19信息系统七个特点开放、共享、实时、可靠、交互、可维护、安全
20一卡通属于局域网系统，以 TPS 为主兼有 MIS

12.课堂提示（讲课参考）​

  • 五项功能用"食堂刷卡"一条线讲完：刷卡（输入）→ 查余额扣款（处理）→ 写流水（存储）→ 显示余额（输出）→ 余额不足拒绝（控制）。学生每天都在用，抽象概念立刻具体。
  • "控制"要让学生自己找：提问"如果一卡通没有控制功能，会出现什么问题"，学生能说出"钱扣成负数""一卡多人用""丢了被人刷爆"，比教师讲四条定义更有效。
  • 五类系统建议"层层盖楼"画图：底部写 TPS（收银员），中间写 MIS（教务员），顶部写 DSS（校长），旁边挂 ES 和 OA，讲清"越往上人越少、决策越不结构化"。
  • 易错点强调：学生常把"处理"和"控制"混为一谈，也常把"输出"只理解成"打印"。可以用一个对比小题当场检测："系统提示'密码错误，请重试'"属于哪项功能？（答案：控制＋输出，控制做判断、输出做提示）。
  • 作业建议：让学生任选身边一个系统（快递驿站、奶茶店点单、图书馆借阅），填"五要素 + 五功能 + 属于哪一类"三张表，下节课互评，正好为第2单元的"集成"做铺垫。
