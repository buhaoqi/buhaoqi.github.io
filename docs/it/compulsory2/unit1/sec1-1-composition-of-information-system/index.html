1.1 信息系统的组成

知识点​

1.本单元要学什么​

单元主题：信息系统的组成与功能——先拆开看"它由什么构成"，再合起来看"它能干什么"。

小节核心问题
1.1 信息系统的组成信息系统由哪几个部分组成？各部分起什么作用？
1.2 信息系统的功能信息系统能完成哪些功能？不同功能的系统怎么分类？

贯穿全书的逻辑：必修1 讲的是"数据怎么算"，必修2 讲的是"数据放在什么样的系统里用"。所以本单元是全册的概念地基——后面第2单元"集成"是在讲要素怎么连起来，第3单元"设计与开发"是在讲要素怎么造出来，第4单元"安全"是在讲要素怎么护住，第5单元"社会"是在讲系统怎么影响人。

2.什么是信息系统​

定义：信息系统是由人、硬件、软件、数据和通信网络等要素构成的，能够对信息进行采集、加工、存储、传输、输出，以支持组织运行与决策的人机交互系统。

这个定义里有三个采分点，答题时缺一不可：

  1. 有要素——不是一台机器，而是"人 + 机器 + 数据 + 网络"的组合；
  2. 有过程——要能完成采集、加工、存储、传输、输出这一整套信息处理活动；
  3. 有人机交互——人参与其中，不是纯自动装置。

三句话理解：

  1. 信息系统不等于计算机。一台没装任何软件、没接任何网络的电脑只是"硬件"；只有配上软件、数据、使用者，并且承担某项信息处理任务时，才构成信息系统。
  2. 信息系统不等于软件。软件只是其中的"软件"要素，"人"和"数据"缺一不可。
  3. 信息系统的核心目的是支持组织的运行、管理与决策，不是为了"用电脑"而用电脑。

判断是不是信息系统的三个自检问题（课堂上非常好用）：

  • 有没有明确的信息处理任务？（要解决什么问题）
  • 有没有数据输入与输出？（数据从哪来、到哪去）
  • 有没有人参与使用或管理？（谁在用、谁在维护）

三个都答"有"，基本可以判定为信息系统。

3.信息系统的五个基本要素​

这是本小节最重要的考点，五要素必须能背、能对应实例。

要素通俗说法具体包括作用缺失后果
人使用者与管理者用户、管理员、开发者、维护人员系统的核心与主导，提出需求、操作使用、管理维护系统无人使用，失去存在意义
硬件看得见的设备计算机、服务器、手机、传感器、交换机、路由器、打印机提供物理基础与运行平台系统无法运行
软件看不见的程序系统软件（操作系统、数据库管理系统）、应用软件（业务系统、APP）指挥硬件工作，实现具体业务功能硬件成"裸机"，不能处理业务
数据系统的"原料"与"产品"文字、数字、图片、音视频、数据库中的记录信息系统的处理对象与价值载体系统空转，无任何产出
通信网络连接的"通道"有线网络、无线网络、互联网、移动通信网实现数据传输与资源共享，把分散的要素连成整体只能单机使用，无法协同与远程访问

记忆口诀：人、硬、软、数、网——"人硬软数网，缺一不成系统"。

补充说明（教材有的版本会提"六要素"）：部分教材把规程与规范（管理制度、操作规程、技术标准）列为第六要素。它虽不是"设备"，却决定了系统能否被正确、安全地使用。考试若问"五要素"就答上面五个；若题目出现"规章制度"，把它理解为"人"这一要素的延伸即可，答题时补一句更稳。

4.人：信息系统中最活跃的要素​

五要素不是平级的——人是核心，这一点最容易被学生忽略，也最爱出简答题。

人为什么是核心（四条理由）：

  1. 人是系统的设计者——需求由人提出，方案由人设计；
  2. 人是系统的使用者——系统价值只有被人使用才能实现；
  3. 人是系统的管理者——权限分配、数据维护、故障处理都靠人；
  4. 人是系统的改进者——业务变化时由人升级、迭代系统。

系统中的三类人（按角色分，答简答题时分层写更完整）：

角色主要职责举例
最终用户使用系统完成本职工作学生查成绩、顾客下单
管理维护人员数据维护、权限管理、日常运维教务员、系统管理员
开发人员需求分析、设计、编码、测试程序员、系统分析师

一句话结论：技术再先进，信息系统也是"为人服务"的；评价一个系统好不好，最终看它是否好用、管用、愿意用。

5.硬件与软件：系统的"躯体"与"灵魂"​

硬件是信息系统的物理基础，按功能可分四类：

类别作用举例
输入设备把外部信息送入系统键盘、鼠标、扫描枪、摄像头、传感器
处理设备完成运算与控制服务器、计算机主机、单片机
存储设备保存数据与程序硬盘、固态硬盘、U盘、云存储
输出设备把结果呈现出来显示器、打印机、音箱、指示灯

软件分两大类，这个二分法必须清楚：

类别定义举例地位
系统软件管理硬件、支撑应用运行的基础软件操作系统（Windows、Linux、Android）、数据库管理系统（MySQL）、语言处理程序、驱动程序系统的"平台"
应用软件为特定业务开发的软件学籍管理系统、微信、WPS、图书借阅系统系统的"功能"

两者关系（常考）：系统软件是应用软件的运行基础，应用软件必须在系统软件支持下才能工作；没有操作系统，应用软件无法启动；没有应用软件，系统软件也无法满足具体业务需求。

6.数据：系统的处理对象​

数据是信息系统的"原料"，也是"产品"——系统输入的是数据，输出的仍是数据（只是被加工得更有价值）。

信息系统中的数据有三层含义：

  1. 输入数据：业务发生时采集的原始记录（如刷卡时间、商品条码）；
  2. 存储数据：长期保存在数据库中、可反复使用的数据（如学生基本信息）；
  3. 输出数据：经过加工后呈现给用户的结果（如成绩单、统计报表）。

数据的组织层次（了解即可，第3单元会展开）：字段 → 记录 → 数据表 → 数据库。

关键认识：数据是信息系统中最有价值的资产。硬件会折旧、软件会过时，而积累下来的业务数据往往无法复制——这也是第4单元要重点讲"数据安全"的原因。

7.通信网络：把要素连成整体​

通信网络解决的是**"分散的要素如何协同"**的问题。

层次作用举例
局域网一个单位内部互联校园网、机房、办公室网络
广域网／互联网跨地域互联教育城域网、Internet
移动通信网随时随地的无线接入4G／5G、Wi-Fi

网络带来的三个变化（讲课时点出来，学生更容易理解"为什么网络是要素"）：

  1. 数据可以远程传输——从"本机处理"变成"多地协同"；
  2. 资源可以共享——打印机、数据库、计算能力共享，降低成本；
  3. 系统可以扩展——从单机走向 B/S 架构，用户只需浏览器即可访问。

8.信息系统的工作过程​

信息系统干活，走的是同一条流水线，五个环节必须按顺序记住：

输入 → 处理 → 存储 → 输出 → 控制

环节做什么举例（食堂刷卡）
输入采集并录入原始数据刷卡机读卡号、读消费金额
处理按规则计算、比对、判断查询余额、判断是否足够、扣款
存储保存原始数据与结果写入消费流水表、更新余额
输出把结果呈现给用户显示屏显示"扣款 12 元，余额 88 元"
控制协调各环节、监督运行余额不足时拒绝交易并提示

注意：控制这一环节常被漏写，但它恰恰是最能体现"系统"的一环——没有控制，前四个环节只是各自为政的动作，不能成为一个整体。

闭环理解：输出往往会成为下一轮输入的起点（消费记录 → 月度统计 → 采购决策），这就是信息系统持续运行的方式。

9.信息系统的分类​

（1）按覆盖范围（规模）分

类型范围特点举例
单机系统一台计算机结构简单、成本低、数据不共享单机版记账软件
局域网系统一个单位内部数据共享、管理集中学校机房管理系统、超市收银系统
广域网系统跨地区、全国乃至全球用户多、数据量大、依赖互联网12306、网上银行、电商平台

（2）按用途（业务层次）分（详见 1.2，这里先建立概念）

类型服务对象举例
事务处理系统一线业务人员收银、订票、借还书
管理信息系统中层管理者成绩管理、库存管理
决策支持系统高层决策者销售预测、选址分析
专家系统需要专业经验的场景疾病辅助诊断、故障诊断
办公自动化系统全体办公人员OA、公文流转

（3）按行业分：教务管理系统、医疗信息系统、银行信息系统、物流信息系统、交通管理信息系统等。

分类题的答题技巧：先看题目问的是"范围"还是"用途"，两者不能混答；同一系统可以同时属于多个类别（如"校园一卡通"既是局域网系统，又含事务处理功能）。

10.三个典型实例（要素落地）​

（1）学校学籍管理系统

要素具体内容
人学生（查询）、班主任（录入）、教务员（审核）、管理员（维护）
硬件服务器、办公电脑、校园网交换机、打印机
软件Windows Server、MySQL、学籍管理应用软件
数据学号、姓名、班级、身份证号、成绩、奖惩记录
网络校园局域网 + 互联网（家长端查询）

工作过程：新生信息录入（输入）→ 分班与校验（处理）→ 存入数据库（存储）→ 生成班级名册（输出）→ 权限控制与日志（控制）。

（2）公交 IC 卡系统

要素具体内容
人乘客、司机、公交公司结算人员
硬件车载刷卡机、IC 卡、充值终端、服务器
软件刷卡扣费程序、清分结算系统
数据卡号、余额、刷卡时间、线路、车辆编号
网络车载移动网络（数据回传）

特点：实时性要求高（刷卡必须秒级响应），因此采用"脱机交易 + 联机结算"的方式——先在本机记账，事后统一上传汇总。

（3）网上购物系统

要素具体内容
人买家、卖家、平台运营、客服、物流人员
硬件云服务器、用户手机／电脑、仓储扫码设备
软件电商平台、支付系统、订单系统、物流跟踪系统
数据商品信息、订单、支付记录、评价、浏览行为
网络互联网、移动通信网

特点：用户规模大、并发高、数据类型多，是典型的广域网信息系统，也是第4单元"安全"问题最集中的场景。

11.信息系统与信息技术的关系​

信息技术（IT） 主要包括传感技术、计算机技术、通信技术、控制技术（常称"四大基石"）。信息系统是信息技术综合应用的产物：

  • 传感技术解决"怎么采集"——对应输入；
  • 计算机技术解决"怎么处理与存储"——对应处理与存储；
  • 通信技术解决"怎么传输"——对应网络；
  • 控制技术解决"怎么自动调节"——对应控制。

一句话：信息技术是"零件"，信息系统是"整机"；单个技术解决单点问题，集成起来才能支撑业务。

序号考点结论

11最易漏写的环节控制
12按规模分类单机、局域网、广域网

13.课堂提示（讲课参考）​

  • 开场先拆一台"废电脑"：一台没装系统、没联网的旧主机摆在讲台上，问学生"这是信息系统吗"，多数人会说是。再装上系统、连上网、登录学籍系统，一步步补齐"软件、网络、人、数据"，五要素就自然被"找"出来了，比直接念定义有效得多。
  • 五要素用"开一家奶茶店"类比：人是店员和老板，硬件是收银机和封口机，软件是收银系统，数据是订单和库存，网络是外卖平台对接。学生熟悉，容易记住"缺一个就转不起来"。
  • "控制"环节要专门设计一个反例：如果没有控制，刷卡机在余额不足时也照扣，系统就崩了。让学生自己想"还有哪些地方需要控制"（权限、超时、重复提交），比讲概念印象深。
  • 三个实例建议分组任务：三组分别拆解学籍系统、公交 IC 卡、网上购物，用同一张五要素表填，最后对比"为什么公交卡要脱机、网购要云端"，自然过渡到 1.2 的功能与分类。
  • 易错点提前打预防针：学生写简答题时几乎都会漏"人"和"数据"，强调"五要素缺一不可，人是核心"，并让他们当场默写一遍。
