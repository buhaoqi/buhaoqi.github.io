2.2 计算机系统互联

知识点​

1.为什么要把计算机连起来​

单台计算机的能力有边界：数据在自己机器里、设备不能共享、通信只能靠U盘拷。把计算机连成网络，才能突破这三个限制。

计算机网络的四大功能（必背）：

功能含义举例
数据通信在网络中快速传递数据发消息、传文件、视频通话
资源共享共享硬件、软件与数据共享打印机、共享文件夹、共用数据库
分布式处理把大任务分散到多台机器协同完成云渲染、分布式计算
提高可靠性一台故障可由另一台接管服务器集群、异地备份

网络的三个组成要素：通信线路与设备（网卡、交换机、传输介质）＋ 计算机（含软件）＋ 通信协议。缺协议，设备再多也无法互通。

2.网络的分类​

（1）按覆盖范围分（最常考）

类型英文范围举例
局域网LAN一个房间到一栋楼、一个校园（几米到几千米）机房、办公室、校园网
城域网MAN一个城市（几十千米）城市政务网、教育城域网
广域网WAN跨城市、跨国家、全球Internet、银行专网

（2）按拓扑结构分

（3）按传输介质分：有线网、无线网。

（4）按使用范围分：公用网（如 Internet）、专用网（如校园内网、企业内网）。

3.三种基本拓扑结构​

拓扑结构指网络中节点与连接线的几何排列方式。

拓扑连接方式优点缺点
星型所有节点连到中心设备（交换机）结构简单、易扩展、单点故障只影响自己、易管理依赖中心设备，中心坏则全网瘫
总线型所有节点挂在一条总线上布线省、成本低总线断则全网瘫，冲突多、难排查
环型节点首尾相连成环传输确定、无冲突单点故障影响全网，增删节点麻烦

现实中的主流是星型：现在的交换机组成的局域网，物理上就是"星型"（逻辑上可以是其他结构）。

扩展：网状结构——节点之间多条路径互连，可靠性最高，用于骨干网、数据中心。

4.传输介质​

介质类型特点适用
双绞线（网线）有线便宜、易施工，传输距离约 100 m室内布线、桌面接入
同轴电缆有线抗干扰较好，已逐步淘汰早期总线型网络、有线电视
光纤有线带宽大、距离远、抗电磁干扰骨干网、楼宇之间、光纤入户
无线电波无线Wi-Fi、蓝牙、4G／5G移动接入、不便布线场所

双绞线的两种接法（实操必考）：

标准线序（1~8）
T568B橙白、橙、绿白、蓝、蓝白、绿、棕白、棕
T568A绿白、绿、橙白、蓝、蓝白、橙、棕白、棕

用法规则：

  • 两端同标准（B-B 或 A-A）→ 直通线，用于不同类设备之间（计算机—交换机）；
  • 两端不同标准（A-B）→ 交叉线，用于同类设备之间（计算机—计算机、交换机—交换机）；
  • 现在多数设备支持端口自动翻转（Auto-MDIX），直通线也能互通，但考试仍按上述规则答。

5.网络设备：各管一段​

设备工作层次（了解）作用关键点
网卡物理层／数据链路层计算机接入网络的接口每块网卡有唯一的 MAC 地址
集线器（Hub）物理层多端口转发，共享带宽所有端口同一个冲突域，已淘汰
交换机（Switch）数据链路层按 MAC 地址转发，独享带宽局域网核心设备
路由器（Router）网络层连接不同网络，按 IP 地址选路实现跨网通信与共享上网
无线 AP数据链路层提供无线接入点与无线路由器配合扩展覆盖
调制解调器（光猫）物理层完成信号转换接入运营商线路

一句话区分：

  • 交换机管"同一张网内"，靠 MAC 地址；
  • 路由器管"不同网之间"，靠 IP 地址。

这是本节最容易混的一对概念，务必分清。

6.网络协议与 TCP/IP​

协议：通信双方共同遵守的规则与约定，包括语法、语义、时序三要素。

没有协议，就像两个人一个说中文一个说英文还都抢着说——设备再多也通不了。

TCP/IP 协议族是 Internet 的通用语言，采用四层结构：

层次主要功能典型协议
应用层面向具体应用HTTP、FTP、SMTP、DNS、DHCP
传输层端到端的数据传输TCP（可靠、面向连接）、UDP（快、无连接）
网络层寻址与路由选择IP、ICMP、ARP
网络接口层物理传输与帧的收发以太网、Wi-Fi

TCP 与 UDP 的对比（常在选择题出现）：

对比TCPUDP
连接方式面向连接（先握手）无连接
可靠性可靠，丢失重传、有序不可靠，不重传
速度较慢较快
适用网页、文件传输、邮件视频直播、语音通话、DNS 查询

7.IP 地址：网络中的"门牌号"​

IP 地址是给网络中每台主机分配的唯一逻辑地址，用于标识与寻址。

IPv4 地址的组成：

  • 共 32 位二进制，通常写成点分十进制四段，每段 0~255，例如 192.168.1.10；
  • 由网络号与主机号两部分组成，靠子网掩码划分。

子网掩码：用连续的 1 标识网络号、连续的 0 标识主机号。

掩码含义
255.255.255.0前三段是网络号，最后一段是主机号（可容纳 254 台主机）
255.255.0.0前两段是网络号

判断两台主机是否在同一网段：IP 与掩码按位"与"运算，结果相同即同网段。

例：192.168.1.10/24 与 192.168.1.20/24，掩码都是 255.255.255.0，与运算后都是 192.168.1.0，同网段，可直接通信。

三个特殊地址（必记）：

地址含义
网络地址主机号全 0，代表整个网段，不能分配给主机
广播地址主机号全 1，向本网段所有主机发送
127.0.0.1本机回环地址，用于测试本机协议栈

私有地址（内网地址）三段：

  • 10.0.0.0 ~ 10.255.255.255
  • 172.16.0.0 ~ 172.31.255.255
  • 192.168.0.0 ~ 192.168.255.255

家用路由器分配的通常是 192.168.x.x，这就是"内网地址"，出公网要靠路由器做地址转换（NAT）。

IPv6：地址长度 128 位，写成 8 组十六进制，彻底解决 IPv4 地址枯竭问题，且原生支持更大的地址空间与更好的安全性。

8.网络配置的四个参数​

在 Windows 中手工配置网络，需要填四项：

参数作用举例
IP 地址本机在网络中的门牌号192.168.1.10
子网掩码划分网络号与主机号255.255.255.0
默认网关出本网段的出口，通常是路由器地址192.168.1.1
DNS 服务器把域名解析成 IP114.114.114.114、8.8.8.8

两个关键理解：

  1. 网关填错，就上不了外网——但同网段内互访仍正常，这是排障的重要线索；
  2. DNS 填错，能上QQ但打不开网页——因为域名解析失败，而 QQ 可直接用 IP 连服务器。

自动获取（DHCP）：由路由器自动分配上述四项，家庭与校园网络普遍采用，避免手工配置冲突。

9.常用网络命令（实操必考）​

命令作用典型输出解读
ipconfig查看本机 IP、掩码、网关确认配置是否生效
ipconfig /all查看详细信息（含 MAC 地址、DNS）排查物理地址与 DNS
ping测试连通性有"回复"即通，超时即不通
ipconfig /release释放 IP重获地址前先释放
ipconfig /renew重新获取 IP解决地址冲突
netstat查看网络连接状态看端口占用、连接数

ping 的经典用法（排障顺序）：

  1. ping 127.0.0.1 —— 测本机协议栈是否正常；
  2. ping 本机IP —— 测网卡是否正常；
  3. ping 网关 —— 测局域网是否通；
  4. ping 外网地址 —— 测出口与互联网是否通；
  5. ping 域名 —— 测 DNS 是否正常。

这个"由内到外"的顺序，是网络排障的标准套路。

10.文件共享与工作组​

工作组（Workgroup）：一种对等网络的组织方式，各计算机地位平等，各自管理自己的账户与资源，适合小型局域网（如机房、办公室）。

概念含义
工作组计算机的逻辑分组，同组内可在"网络"中互相看到
共享文件夹把本机文件夹开放给他人访问，可设读取／读写权限
映射网络驱动器把共享文件夹当作本地盘符使用，方便访问
访问权限控制谁能读、谁能改，是共享安全的关键

共享设置要点（Windows）：

  1. 确认网络位置为"专用网络"（公用网络默认关闭共享）；
  2. 启用"文件和打印机共享"；
  3. 右键文件夹 → 属性 → 共享 → 添加用户并设置权限；
  4. 访问方式：在"运行"中输入 \\目标IP\共享名。

安全提醒：共享权限只给必要的人、只给必要的权限；公共机房不建议开启"所有人可读写"，否则容易被误删或植入病毒。

12.课堂提示（讲课参考）​

  • 先做实物演示再讲概念：两台电脑用一根网线直连，配好 IP 后互 ping 通，再拔掉网线 ping 一次。学生对"连通"和"不通"的差别有了体感，再讲协议、掩码就不抽象了。
  • 交换机与路由器用"楼内／楼间"类比：交换机是"楼里的传达室"，认识楼里每个人（MAC）；路由器是"小区大门"，只管把包裹送出小区（IP 选路）。这个类比几乎不会被记混。
  • ping 排障顺序做成课堂任务：故意把某台机器的网关改错、DNS 清空，让学生按"回环 → 本机 → 网关 → 外网 → 域名"五步定位故障，比讲十遍命令有用。这也是对口升学实操题的常见形态。
  • 子网掩码只讲"与运算"一个动作：不必展开二进制长除法，用"前三段相同就是同一网段（掩码 255.255.255.0）"的快捷判断法先让学生会做题，再补原理。
  • 网线制作安排一次动手：两人一组压一根 T568B 直通线，用测线仪看八芯灯序。学生印象极深，而且这是技能考核常见项目。
