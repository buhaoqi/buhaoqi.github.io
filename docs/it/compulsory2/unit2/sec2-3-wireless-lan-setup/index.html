2.3 无线局域网的组建

知识点​

1.无线局域网是什么​

定义：无线局域网（WLAN） 是以无线电波（或红外线）作为传输介质、在一定范围内实现设备互联的局域网，是有线局域网的无线延伸。

日常说的 Wi-Fi 是基于 IEEE 802.11 系列标准的无线局域网技术的通用叫法。

对比项有线局域网无线局域网
传输介质双绞线、光纤无线电波
布线需要，施工量大无需布线
移动性位置固定可移动接入
速率与稳定性高、稳定受距离与干扰影响，波动较大
安全性需物理接入，相对可控信号在空间传播，更易被截获

无线局域网的三个优势：免布线、可移动、易扩展。 三个不足：易受干扰、覆盖有限、安全性相对较弱。

2.IEEE 802.11 系列标准（必背对比）​

标准频段理论速率特点
802.112.4 GHz2 Mbps最早的无线局域网标准
802.11b2.4 GHz11 Mbps早期普及，兼容性好
802.11a5 GHz54 Mbps速率高但设备少、成本高
802.11g2.4 GHz54 Mbps兼顾速率与兼容性，广泛使用
802.11n（Wi-Fi 4）2.4／5 GHz最高 600 Mbps引入 MIMO 多天线，双频
802.11ac（Wi-Fi 5）5 GHz可达数 Gbps面向高清视频与高密度场景
802.11ax（Wi-Fi 6）2.4／5／6 GHz更高高并发、低时延、省电

记忆要点：

  1. b／g 在 2.4 GHz，a／ac 在 5 GHz——这是最常考的对应关系；
  2. 数字顺序不代表性能顺序：a 比 b 晚、比 g 早，性能不是简单递增；
  3. n 是分水岭：从此开始普遍支持双频与多天线。

3.频段与信道：无线信号走哪条"路"​

频段是无线电波的频率范围，常用两个：

频段优点缺点
2.4 GHz穿墙能力强、覆盖范围大、兼容设备多干扰多（微波炉、蓝牙、无线鼠标都用它），速率较低
5 GHz速率高、干扰少穿墙能力弱、覆盖范围小

信道：把频段切成若干条"车道"，设备在某个信道上通信。

  • 2.4 GHz 共 13 个信道，其中只有 1、6、11 三个互不重叠；
  • 相邻网络若都用同一信道，会互相干扰、速率骤降；
  • 优化原则：多个路由器相邻部署时，分别用 1、6、11，避免"撞车道"。

一句话：2.4 GHz 跑得远但路挤，5 GHz 跑得快但腿短。

4.无线网络的关键设备与术语​

名称含义作用
无线 AP无线接入点提供无线信号接入，本身不路由（相当于"无线交换机"）
无线路由器路由器＋AP＋交换机＋DHCP 一体家庭与小办公室最常见，既能发射信号又能分配地址、共享上网
无线网卡终端侧的无线接口笔记本内置，台式机可外接 USB 无线网卡
SSID无线网络名称用户搜索到的"网络名"，可隐藏
BSSIDAP 的 MAC 地址唯一标识一个 AP
WDS无线桥接用无线把两个网络连起来，扩展覆盖

AP 与无线路由器的区别（易错）：

  • AP 只做"接入"，不分配 IP、不做 NAT，需要上游设备提供地址；
  • 无线路由器集成了 AP、路由、DHCP、交换功能，可独立组网。

5.两种组网模式​

模式英文结构适用
基础设施模式Infrastructure所有终端连到中心 AP，由 AP 转发家庭、教室、办公室（主流）
自组网模式Ad-Hoc终端之间点对点直连，无中心临时两台设备互传文件

现实中使用的基本都是基础设施模式，其拓扑相当于有线网络的星型——中心就是无线路由器。

无线桥接（WDS）与中继：当面积大、单台路由器覆盖不到时，用第二台设备无线接收再转发，扩展覆盖范围。代价是带宽减半（同一信道收发）。

6.无线加密方式（安全重点）​

方式安全性说明
不加密（开放网络）无任何人可接入，公共场所慎用
WEP很低，已被破解早期标准，不建议使用
WPA／WPA2（AES）较高目前主流，家用选 WPA2-PSK
WPA3最高新一代标准，新设备逐步支持
MAC 地址过滤辅助只允许指定设备接入，可被伪造，不能单独依赖
隐藏 SSID辅助不广播网络名，专业工具仍可发现

设置原则（答题可用）：

  1. 必须设密码，选 WPA2 及以上；
  2. 密码足够长（12 位以上，含字母、数字、符号），定期更换；
  3. 修改路由器管理密码（默认 admin 是最大漏洞）；
  4. 关闭 WPS 一键连接（存在被暴力破解风险）；
  5. 不用时关闭无线，或降低发射功率。

7.无线路由器的配置步骤（实操必考）​

第一步：物理连接

  1. 宽带线（或光猫出线）接入路由器的 WAN 口；
  2. 计算机用网线接 LAN 口，或直接连默认无线信号。

第二步：登录管理界面

  1. 查看路由器背面标签上的管理地址（常见 192.168.1.1、192.168.0.1、tplogin.cn）；
  2. 浏览器输入地址，输入默认用户名与密码；
  3. 首次登录立即修改管理密码。

第三步：设置上网方式

方式适用需要填写
PPPoE 拨号宽带账号上网宽带账号与密码
动态 IP（DHCP）光猫已拨号、上层有 DHCP无需填写
静态 IP专线、校园网分配固定地址IP、掩码、网关、DNS

第四步：设置无线参数

  1. SSID：改成易识别、不含个人信息的名称（不要用姓名、门牌号）；
  2. 信道：2.4 GHz 选 1／6／11 中较空闲的一个；
  3. 加密方式与密码：WPA2-PSK＋强密码；
  4. 频段：双频路由器建议分开命名（如 Home-2.4G、Home-5G），便于按需连接。

第五步：验证

  • 手机搜索 SSID → 输入密码 → 连接成功；
  • 打开网页测试能否上网；
  • 在终端查看获取到的 IP（应为路由器分配的私有地址）。

8.信号覆盖与优化​

影响覆盖的四个因素：

因素影响对策
距离越远信号越弱合理布点、加中继
墙体与金属承重墙、钢筋、金属柜衰减大避免穿多道墙，AP 放高处无遮挡处
干扰源微波炉、蓝牙、无绳电话、邻网同信道换信道、改用 5 GHz
设备能力天线数量、发射功率、终端网卡选双频千兆设备

优化要点：

  1. AP 放在空间中心、离地 1.5 m 以上，不要塞进弱电箱或柜子里；
  2. 2.4 GHz 管覆盖、5 GHz 管速度，双频协同；
  3. 大面积场所多 AP 组网，且相邻 AP 用不同信道；
  4. 高密度场景（机房、报告厅）要考虑并发接入数，不是只看速率。

9.常见故障排查​

现象可能原因排查方法
搜不到 SSID无线未开启、SSID 被隐藏、距离过远检查无线开关、手动添加网络
能连上但上不了网WAN 口未接好、拨号失败、欠费看路由器指示灯、查拨号状态
网速很慢、时断时续信号弱、信道干扰、终端过多换信道、靠近 AP、限速
连上就掉线IP 冲突、DHCP 地址池耗尽重启路由器、扩大地址池
提示"无法获取 IP"DHCP 未开启开启 DHCP 或改静态 IP

指示灯速读：PWR 常亮为通电、WAN 闪烁为有数据、LAN／无线闪烁为有终端通信——先用灯判断"物理层通不通"，再看配置。

10.无线局域网的安全风险​

风险说明防范
蹭网他人接入占用带宽，甚至窃取内网数据强密码、WPA2、定期查 connected 设备
中间人攻击伪造同名 SSID 诱骗接入核对 SSID、避免连开放网络
公共 Wi-Fi 窃密同一网络内可嗅探明文数据不传敏感信息、用 HTTPS、必要时用 VPN
弱口令被暴力破解WEP 或短密码易被攻破长密码、WPA3、关闭 WPS
路由器漏洞固件未更新存在后门定期升级固件、改默认管理密码

一条实用建议：在外面连公共 Wi-Fi 时，登录网银、输入身份证号这类操作不要做——这比任何技术手段都有效。

序号考点结论

12.课堂提示（讲课参考）​

  • 拿一台真实无线路由器上讲台：现场登录管理界面，改 SSID、换信道、设密码，学生看一遍比看十张截图管用。重点演示"改完保存后要重启才生效"这个细节。
  • 信道干扰做个可视化实验：用手机装 Wi-Fi 分析类 APP，投屏显示周围十几个网络挤在信道 1 和 6 上，再把自己路由器改到 11，测速对比。学生对"信道"这个抽象概念立刻有感觉。
  • 加密方式用"门锁"类比：WEP 是"一把能被万能钥匙开的旧锁"，WPA2 是"现在的防盗锁"，WPA3 是"最新款"。强调不加密等于门都不关。
  • 安全部分建议做"攻防演示"：教师用手机热点起一个名为 School-WiFi 的假热点，看有多少学生下意识去连——顺势讲中间人攻击与公共 Wi-Fi 风险，教育效果远胜说教。
  • 实操考核建议就考"配一台能上网的路由器"：从接线、登录、改密码、设 SSID 和加密、验证上网，五步限时完成。这是对口升学技能测试的典型题型，也是学生家里真用得上的本领。
