2.4 基于物联网的信息系统

知识点​

1.物联网是什么​

定义：物联网（IoT） 是通过信息传感设备，按约定协议把物品与互联网连接起来，进行信息交换与通信，以实现智能化识别、定位、跟踪、监控和管理的一种网络。

通俗理解：互联网连接的是"人与人"，物联网连接的是"物与物、人与物"——让物体"能感知、能说话、能被控制"。

物联网的三个特征（必背）：

特征含义举例
全面感知利用传感器随时采集物理世界的信息温湿度、光照、位置、图像
可靠传输通过有线或无线网络把数据传出去Wi-Fi、NB-IoT、以太网
智能处理对数据进行分析并作出判断与响应超温报警、自动开灯、远程断电

一句话：感知是入口，传输是通道，处理是大脑，控制是出口。

2.三层架构（核心考点）​

层次别称作用组成举例
感知层感知识别层采集数据、识别物体传感器、摄像头、RFID、二维码、执行器温度传感器测到 32 ℃
网络层传输层把数据可靠地传上去有线网络、Wi-Fi、移动通信网、NB-IoT、物联网网关通过 Wi-Fi 上报到云平台
应用层处理与应用层存储、分析、呈现、决策与控制云平台、数据库、应用软件、手机 APP、大屏APP 显示曲线并推送报警

三层关系：感知层"看得见"，网络层"传得到"，应用层"想得清、管得住"。

答题模板：遇到"分析某物联网系统"的题，按三层各写一句"它在这一层做了什么"，几乎不会丢分。

3.感知层：传感器是"感官"​

传感器：能感受被测量并按一定规律转换成可用信号的器件，是把物理量变成电信号／数据的关键。

传感器测什么典型应用
温度传感器温度空调、温室、体温检测
湿度传感器空气或土壤湿度智能浇灌、粮仓防潮
光敏传感器光照强度路灯自动开关、窗帘控制
红外传感器人体红外、避障感应灯、安防报警、机器人避障
超声波传感器距离倒车雷达、液位检测
烟雾／气体传感器烟雾、可燃气体火灾报警、燃气泄漏
加速度／陀螺仪运动与姿态手机横竖屏、跌倒检测

执行器：接受控制指令做出动作的装置——继电器、电机、舵机、电磁阀、LED、蜂鸣器。

"传感器 + 执行器"构成一个最小闭环：感知 → 判断 → 动作。

识别技术（让系统知道"这是哪个物体"）：

技术原理特点应用
RFID无线电波读取电子标签非接触、可批量、可穿透门禁卡、图书管理、仓储盘点
二维码图像编码成本极低、需光学扫描扫码支付、资产标签
NFC近场通信距离极近（约 10 cm 内）、安全手机刷公交、门禁
摄像头＋图像识别视觉分析信息量大、需算力车牌识别、人脸门禁

三者区分要点：RFID 靠射频、可远距离批量读；二维码靠"看"；NFC 必须贴近。

4.网络层：数据怎么"传上去"​

通信方式距离／范围功耗速率适用
Wi-Fi几十米较高高家庭、教室（有电源、有路由）
蓝牙约 10 m低中低耳机、手环、近距配网
ZigBee几十米，可自组网很低低智能家居多设备组网
NB-IoT广域（运营商网络）极低低水表电表、井盖监测
LoRa数千米低低农业大棚、园区远距
有线以太网100 m 每段—高且稳定机房、工业现场

选择的三个考虑：距离、功耗、数据量。

  • 电池供电、数据量小、距离远 → NB-IoT／LoRa；
  • 家庭室内、有电源、要传图片 → Wi-Fi；
  • 多设备低功耗自组网 → ZigBee。

物联网网关：连接"感知侧协议"与"互联网协议"的翻译官，负责协议转换、数据汇聚与初步处理。

MQTT 协议：物联网常用的轻量级消息协议，采用发布／订阅模式，设备把数据"发布"到主题，应用"订阅"主题即可收到，开销小、适合弱网与海量设备。

5.应用层：数据变成"决策与动作"​

应用层要完成四件事：

  1. 存储——把海量感知数据存入数据库（时序数据尤其多）；
  2. 分析——统计、对比、找出异常（如温度连续 3 次超阈值）；
  3. 呈现——网页、APP、大屏仪表盘（详见 3.5）；
  4. 控制——下发指令让执行器动作，或向人推送提醒。

两种决策方式：

方式说明举例
阈值判断（规则驱动）数据超过设定值就触发温度高于 30 ℃ 开风扇
数据分析（模型驱动）用历史数据建模预测根据用电曲线预测明天负荷

6.微控制器：物联网系统的"小脑"​

真实搭建物联网系统，通常用微控制器（单片机）作为现场控制核心。

平台特点常见用途
Arduino开源、资料多、上手快教学实验、原型制作
micro:bit集成蓝牙与传感器、图形化编程中小学教学
掌控板国产、集成 Wi-Fi 与屏幕、支持 Python物联网与 STEM 课程
树莓派运行完整操作系统，算力强需要图像识别、做网关或小型服务器

典型搭建结构：

传感器 → 微控制器（采集与判断）→ 通信模块（Wi-Fi）→ 云平台 → 手机 APP／网页 → 控制指令回传 → 执行器

编程逻辑基本都是这个三段式：

  1. 读——读取传感器数值；
  2. 判——与阈值比较；
  3. 做——上传数据、点亮灯、启动电机、发报警。

7.三个典型系统实例​

（1）智能家居

层次内容
感知层温湿度传感器、人体红外、门磁、摄像头、烟雾传感器
网络层家庭 Wi-Fi、ZigBee 组网、路由器
应用层家庭网关／云平台、手机 APP、语音助手

功能：回家自动开灯（人体感应）、燃气泄漏自动关阀并报警、远程查看摄像头、空调按室温自动调节。

（2）智慧农业（温室大棚）

层次内容
感知层空气温湿度、土壤湿度、光照、CO₂ 浓度传感器
网络层LoRa／NB-IoT／Wi-Fi 回传
应用层农业云平台、手机端、自动控制柜

功能：土壤湿度低于阈值自动滴灌、温度过高自动开风机与遮阳帘、光照不足补光、数据曲线辅助判断施肥时机。

价值：节水节肥、减少人工、提高产量与品质，还能把种植经验数据化。

（3）智慧校园（一卡通＋环境监测）

层次内容
感知层读卡器、RFID、摄像头、教室温湿度与 CO₂ 传感器
网络层校园网、Wi-Fi、专线
应用层一卡通平台、教务系统、能耗监测平台、大屏

功能：刷卡考勤与消费、教室空气质量监测并联动新风、图书馆自助借还、用电用水统计。

8.物联网信息系统的价值与挑战​

价值（四个"更"）：

  1. 更准——机器采集，减少人工记录误差；
  2. 更快——实时上报，异常即时发现；
  3. 更省——按需运行，节水节电省人力；
  4. 更智——数据积累后可预测、可优化。

挑战（四个"难"）：

挑战说明
安全设备数量巨大、算力弱、默认口令多，易被入侵（如摄像头被劫持）
隐私摄像头、可穿戴设备采集的是个人行为数据，一旦泄露危害大
标准与兼容协议众多，不同厂商设备难以互通
成本与运维设备分散、供电与维护困难，电池寿命是关键

安全建议（答题可用）：

  1. 改掉默认密码，为每台设备设独立强口令；
  2. 固件及时升级，修补漏洞；
  3. 网络隔离——智能设备单独一个网段，不与办公电脑混用；
  4. 最小必要采集——不采集与业务无关的个人数据；
  5. 数据加密传输，云端存储做好权限控制。

9.速查表​

序号考点结论
1物联网连接对象物与物、人与物
2三大特征全面感知、可靠传输、智能处理
3三层架构感知层、网络层、应用层
4感知层核心器件传感器
5执行器作用接受指令做出动作
6RFID 特点非接触、可批量、可穿透读取
7二维码特点成本低、需光学扫描
8NFC 距离约 10 cm 内
9家庭室内首选Wi-Fi
10广域低功耗首选NB-IoT
11多设备低功耗组网ZigBee
12网关作用协议转换与数据汇聚
13MQTT 模式发布／订阅，轻量
14应用层四件事存储、分析、呈现、控制
15阈值判断数据超设定值即触发
16微控制器举例Arduino、micro:bit、掌控板、树莓派
17程序三段式读 → 判 → 做
18智能家居组网常用ZigBee＋Wi-Fi
19智慧农业核心数据土壤湿度、温湿度、光照

10.课堂提示（讲课参考）​

  • 用一个"会报警的温度计"做开场演示：掌控板＋温度传感器，超过设定温度就亮红灯、蜂鸣并上传一条数据到网页。三分钟演示，把"感知—传输—处理—控制"整条链路走通，比画三层架构图有效十倍。
  • 三层架构让学生"贴标签"：给出一张智能家居系统图，让学生把十几个部件分别贴到感知层／网络层／应用层。这个活动最能暴露"摄像头算哪层"这类混淆（答案：采集侧属感知层，图像识别分析属应用层）。
  • 传感器部分建议实物传阅：把温湿度、光敏、红外、超声波几种传感器摆在桌上让学生轮流看、用手遮光看数值变化。"传感器把物理量变成电信号"这句话，看一次就懂了。
  • 通信方式用"寄快递"类比：Wi-Fi 是"自己开车送"（快但费油）、NB-IoT 是"邮政平邮"（慢但省）、LoRa 是"长途货运"（远但载重小）。学生选型时的判断依据立刻清晰。
  • 安全部分务必强调：家用摄像头被入侵的新闻是很好的切入点，讲完"改默认密码、单独网段、固件升级"三条，让学生回家检查自家的智能设备——这个作业家长也会支持。
