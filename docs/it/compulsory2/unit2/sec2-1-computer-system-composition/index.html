2.1 计算机系统的组成

知识点​

1.本单元要学什么​

单元主题：信息系统的集成——把一台台孤立的设备，连成能协同工作的整体。

小节核心问题
2.1 计算机系统的组成一台计算机由哪些部分组成？各部分怎样配合工作？
2.2 计算机系统互联多台计算机怎样连成网络？IP 地址怎么配？
2.3 无线局域网的组建不用网线怎么组网？Wi-Fi 怎么配、怎么加密？
2.4 基于物联网的信息系统传感器怎么把"物理世界"变成"数据"？
2.5 远程控制系统的组建怎么在远处控制设备？信号怎么走？
2.6 小型信息系统的组建从需求到运行，一个完整系统怎样搭起来？

单元主线：单机 → 有线互联 → 无线互联 → 物联感知 → 远程控制 → 系统集成。这是"由小到大、由近到远"的六步，学完就能自己搭一个能用的信息系统。

2.计算机系统 = 硬件系统 + 软件系统​

定义：计算机系统由硬件系统和软件系统两部分组成，二者缺一不可。

组成内容关系
硬件系统看得见、摸得着的物理设备是物质基础，没有硬件软件无处运行
软件系统程序、数据、相关文档是灵魂，没有软件硬件只是"裸机"

一句话：硬件是躯体，软件是灵魂；躯体提供舞台，灵魂决定演什么。

3.冯·诺依曼体系结构（本小节核心）​

冯·诺依曼在 1946 年提出"存储程序"原理，奠定了现代计算机的基本结构。

核心思想（三条）：

  1. 存储程序——把程序和数据都事先存进存储器，计算机自动按顺序取出执行；
  2. 程序控制——计算机的工作由指令序列控制，不需人工干预每一步；
  3. 二进制——程序和数据都用二进制表示。

五大部件（必背）：

部件别称作用举例
运算器ALU，算术逻辑单元完成算术运算与逻辑运算加法、比较大小
控制器CU指挥、协调各部件工作，取指令、分析指令、发控制信号指令译码、时序控制
存储器内存、外存存放程序与数据内存条、硬盘
输入设备输入把外部信息送入计算机键盘、鼠标、扫描仪、麦克风
输出设备输出把结果送出计算机显示器、打印机、音箱

CPU = 运算器 + 控制器（中央处理器，是计算机的"心脏"）。

注意概念的对应关系（极易混）：

  • "主机" 通常指 CPU + 内存 + 主板（不含外设）；
  • "外设" 指 输入设备、输出设备、外存；
  • "中央处理器" 只含运算器与控制器，不含存储器。

4.总线：部件之间的"高速公路"​

各部件不是各自为战，而是通过总线连接。

总线类型传输什么方向
数据总线数据双向
地址总线存储单元或设备的地址单向（由 CPU 发出）
控制总线控制信号、状态信号双向

总线宽度决定性能：数据总线越宽，一次能传的数据越多（如 64 位）；地址总线越宽，能寻址的空间越大。

5.存储器：分层的"记忆系统"​

存储器的两个大类：

类别特点举例
内存储器（主存）速度快、容量小、断电后数据丢失（RAM）内存条、Cache
外存储器（辅存）速度较慢、容量大、断电后数据保留硬盘、固态硬盘、U盘、光盘

存储层次（由快到慢、由贵到廉）：

寄存器 → Cache（高速缓存） → 内存 → 固态硬盘 → 机械硬盘 → 光盘／磁带

为什么要分层：速度快的太贵、容量小；容量大的太慢。分层后常用数据放上层、海量数据放下层，用较低成本获得较高整体性能。

内存与外存的分工（常考对比）：

对比项内存外存
断电后数据丢失数据保留
容量小（GB 级）大（TB 级）
速度快慢
存放内容正在运行的程序与数据长期保存的程序与文件

6.存储单位与换算（必考计算）​

单位换算
位（bit，比特）最小单位，取值 0 或 1
字节（Byte，B）1 B = 8 bit
千字节（KB）1 KB = 1024 B
兆字节（MB）1 MB = 1024 KB
吉字节（GB）1 GB = 1024 MB
太字节（TB）1 TB = 1024 GB

记忆要点：

  1. B 与 bit 差 8 倍——带宽常用 bit（如 100 Mbps），文件大小常用 Byte，换算要除以 8；
  2. 计算机内部按 1024（2 的 10 次方）进位，而硬盘厂商常按 1000 标注，所以标称 1 TB 的硬盘在系统里显示约 931 GB。

典型算例：一段 100 Mbps 的网络，理论下载速度约为 100 ÷ 8 = 12.5 MB/s。

7.输入输出设备​

类型设备说明
输入键盘、鼠标最基本的字符与指针输入
输入扫描仪、摄像头图像输入
输入麦克风声音输入
输入触摸屏兼具输入与输出
输入传感器、扫码枪物联网与业务系统常用
输出显示器最主要的输出设备
输出打印机纸质输出（针式、喷墨、激光）
输出音箱、耳机声音输出
输出投影仪大屏展示

注意：触摸屏、一体机既是输入设备又是输出设备，这类"双向设备"是常考的小陷阱。

8.软件系统：系统软件与应用软件​

类别定义主要组成举例
系统软件管理、监控、维护硬件，为应用软件提供运行环境操作系统、语言处理程序、数据库管理系统、设备驱动程序、服务性程序Windows、Linux、Android、MySQL、编译器
应用软件为解决特定问题而开发的软件通用应用软件、专用业务软件WPS、浏览器、学籍系统、Photoshop

操作系统的作用（五大管理）：

  1. 处理器管理——分配 CPU 时间；
  2. 存储管理——分配与回收内存；
  3. 设备管理——驱动外设；
  4. 文件管理——组织与保护文件；
  5. 作业管理——调度任务。

操作系统是"最基础的系统软件"，是用户与硬件之间的接口。

语言处理程序：把高级语言源程序翻译成机器语言，编译程序（整体翻译，如 C 语言）与解释程序（逐句翻译，如 Python）是两种方式。

9.指令与程序：计算机怎么"听懂"人话​

指令：计算机执行某种操作的命令，是 CPU 能识别的最小操作单位。

一条指令通常包含两部分：

部分作用
操作码说明"做什么"（加、减、传送、跳转）
地址码说明"对谁做"（操作数或数据所在地址）

程序：为完成某项任务而组织起来的有序指令序列。

指令执行的基本过程（四步，常考流程）：

取指令 → 分析指令 → 执行指令 → 存放结果

由控制器统一指挥，按程序计数器的顺序逐条执行，遇到跳转指令则改变顺序。

"存储程序"的意义：程序像数据一样存在存储器里，计算机就能自动、连续地执行，不需要人一步步拨开关——这是现代计算机区别于早期计算工具的根本。

10.计算机的主要性能指标​

指标含义说明
主频CPU 时钟频率，单位 GHz一定范围内越高越快，但不能跨架构直接比
字长CPU 一次能处理的二进制位数常见 32 位、64 位，字长越长精度与寻址能力越强
核心数／线程数CPU 内集成的运算核心数量多核利于并行处理，需软件支持
内存容量可同时运行的程序规模容量不足会频繁读写硬盘，明显变慢
运算速度每秒执行的指令数（MIPS 等）综合反映性能
存取周期存储器完成一次读写所需时间越短越好

常见误区纠正：

  • "主频越高一定越快"——错，还取决于架构、核心数、缓存、内存等；
  • "硬盘容量越大计算机越快"——错，容量影响"能存多少"，速度才影响"跑多快"；
  • "内存越大越好"——不一定，超出需求的部分不会被利用，且受主板与系统限制。

12.课堂提示（讲课参考）​

  • 拆机箱是最有效的开场：打开一台旧主机，指着 CPU、内存条、硬盘、主板逐一对应五大部件，学生对"运算器＋控制器＝CPU"的记忆会牢固得多。没有实物可用主板结构图代替。
  • "存储程序"用对比讲：早期 ENIAC 改题目要重新插线几小时，现在改程序只需改代码几秒钟——差别就在"程序是否存进存储器"。这个对比学生一听就懂。
  • 存储单位换算必做三道题：① 2 GB 等于多少 MB；② 一张 4 MB 照片能存多少张进 32 GB 卡；③ 100 Mbps 宽带实际下载速度。第三题错误率最高，务必讲清 bit 与 Byte 的区别。
  • 性能指标要"破除迷信"：拿两台真实机器比参数（一台主频高但内存小，一台主频低但固态硬盘＋大内存），让学生猜谁更快，再解释原因，比背定义深刻。
  • 为 2.2 埋伏笔：结尾提问"这台计算机要跟隔壁那台交换文件，需要加什么？"——自然引出网卡、网线、IP 地址，衔接下一节。
