任务四 幻灯片动画效果设置

知识点​

1.动画效果有什么作用？​

答：动画可以提高观众对演示文稿的兴趣，集中其注意力。PowerPoint可以将演示文稿中的文本、图形、图像和表格等对象制成动画，例如为它们设置进入、退出、大小或颜色变化等视觉效果，同时还可以添加声音来增强动画效果。

2.幻灯片中对象的动画效果有哪4种类型？​

答：幻灯片中对象的动画效果有4种类型：

  1. 进入动画：指幻灯片中的对象在进入放映画面时从无到有出现在幻灯片中的动态过程，它包括百叶窗、擦除、劈裂等效果。
  2. 退出动画：指幻灯片中的对象在放映过程中从有到无逐渐消失的动画效果，它是在入场动画的逆过程。
  3. 强调动画：为了使幻灯片中的对象能够引起观众的注意，常常会为其添加强调动画效果，如放大、缩小等。
  4. 动作路径动画：指幻灯片中的对象沿着系统自带的路径或根据用户绘制的路径运动，可以是对象进入或退出的过程，也可以是强调对象的方式。

3.如何为对象添加动画效果？​

答：步骤如下：

  1. 在幻灯片中选择添加动画效果的对象。
  2. 单击"动画"选项卡→单击"动画"组的"其他"按钮，打开动画效果下拉列表框。
    • "无"可以删除对象原有动画。
    • "进入"栏设置对象从无到出现的动画效果。
    • "强调"是对已出现的对象，以动画效果再次显示，引起突出和强调的作用。
    • "退出"栏设置对象从有到无的动画效果。
    • "动作路径"栏给对象添加某种效果以使其按照指定的模式移动。
  3. 单击"动画"组的"效果选项"按钮，可设置动画出现的方向和序列：
    • "作为一个对象"是将选择的所有对象作为一个整体制作并播放动画。
    • "整批发送"是将选择的对象分别制作成动画但同时播放。
    • "按段落"是将文本对象以段落作为单位，逐段播放动画。
  4. 单击"高级动画"组的"添加动画"按钮并选择动画，可为同一对象应用多个动画效果。

4."动画窗格"有什么作用？其中有哪些操作？​

答：单击"高级动画"组的"动画窗格"按钮，打开"动画窗格"，显示有关动画效果的类型、多个动画效果之间的相关顺序、对象的名称和效果的持续时间等。

  • 单击窗格下部的"重新排序"的上移箭头或下移箭头，可调整动画的播放顺序，也可直接用鼠标拖动对象调整。
  • 在"动画窗格"的列表框中单击带编号的对象右侧的下拉箭头，打开下拉菜单，单击"单击开始"选项，可选择单击鼠标时开始播放动画；"从上一项开始"选项可使当前动画与上一个动画同时播放；"从上一项之后开始"选项可使当前动画在上一个动画播放完之后才开始自动播放。
  • 单击"效果选项"菜单项，会根据不同的动画，弹出不同名称的对话框，如"彩色脉冲"对话框。

5.动画的"开始"方式有哪3种？各有什么作用？​

答：动画的开放方式有3种，其作用如下：

  1. 如果要手工控制动画的播放，可以选择"单击开始"选项。
  2. 如果要让当前动画与上一个动画同时播放，可以选择"从上一项开始"选项。
  3. 如果当前动画要在上一个动画播放完之后才开始自动播放，可以选择"从上一项之后开始"选项。

6."效果"选项卡可以设置哪些内容？​

答：在"效果"选项卡中，可以设置动画播放时是否发出声音、动画播放后是否变暗；如果设置的对象是文本，可以设置文字是"整批发送"、"按字/词"或"按字母"播放。

  • "整批发送"：文本以段落作为一个整体播放动画。
  • "按字/词"：文本按词语播放动画。
  • "按字母"：英文字母，中文字逐个播放动画。

7."计时"选项卡可以设置哪些内容？​

答：在"计时"选项卡中，可以设置动画播放开始、完成的时间，以及重复播放几次等。

  • "单击时"：鼠标单击之后对象会按设定的动画效果在幻灯片中出现。
  • "与上一动画同时"：当前选中的对象与上一个对象一起出现。
  • "上一动画之后"：上一个对象出现结束后，当前选中的对象才开始出现。
  • "延迟"：设置当前对象在多少时间间隔后才开始出现。

8.什么是动画刷？有什么用途？​

答：PowerPoint 2010提供了一个类似格式刷的工具，叫作动画刷。它可以将PowerPoint 2010中对象的动画照搬到目标对象上面，如图3-63所示。单击"动画"按钮，完成动画效果的设置，重复以上步骤继续为对象添加动画效果。放映幻灯片时，各对象根据编号顺序播放动画。

9."动画"选项卡的"高级动画"组包含哪些工具？​

答："高级动画"组包含以下工具：

  • 添加动画
  • 动画窗格
  • 触发
  • 动画刷
  • 高级效果（高级动画组展开后可见）

10.本任务的实施步骤是什么？​

答：

  1. 为"目录"幻灯片中的SmartArt图形设置动画效果，自定义动画的"进入"效果为"缩放"，效果选项的"序列"为"逐个"。并将动画效果复制到演示文稿中所有的SmartArt图形对象中。
  2. 将标题为"网络安全的概念"的动画效果设置为"进入"→"飞入"，方向为"自左上部"，开始方式为"上一动画之后"。将左边图片的动画效果设置为"进入"→"玩具风车"，播放速度为"快速"，开始方式为"与上一动画同时"，并伴随着"风铃"声。动画顺序为先标题后图片。
  3. 将第三张幻灯片中各对象的动画分别复制到第五张、第十张、第十二张、第十四张幻灯片中相对应的对象上。
  4. 将标题为"什么是网络安全？"的动画效果设置为"进入"→"飞入"，方向为"自顶部"，文本动画设置为"进入"→"擦除"，方向为"自顶部"，图片动画设置为"旋转"，开始方式均为"单击时"。动画顺序为先标题，后文本，最后图片。
  5. 将第四张幻灯片中标题的动画复制到第六张、第十一张、第十三张、第十五张幻灯片中的标题对象上。
  6. 将标题为"网络安全为何重要？"幻灯片和标题为"如何树立正确的网络安全观？"幻灯片的正文文本的动画效果设置为"进入"→"翻转式远近"，序列方式"按段落"，开始方式为"单击时"。
  7. 为标题"常见的网络安全隐患"幻灯片中的视频设置动画效果为"进入"→"出现"，开始方式为"与上一动画同时"。
  8. 为带有图表的幻灯片设置动画效果为"进入"→"擦除"，方向为"底部"，计时为"非常快（0.5秒）"，序列方式为"按类别中的元素"。
