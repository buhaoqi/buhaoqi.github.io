## 知识点

### 1.什么是作品打包？有什么作用？

答：为了能在没有安装PowerPoint的计算机上放映演示文稿，可以对演示文稿进行打包。本任务将介绍作品打包的设置操作。

### 2.如何打包成CD？

答：（1）单击"文件"选项卡→选择"保存并发送"命令→在下一级菜单中选择"将演示文稿打包成CD"选项→单击"打包成CD"按钮，弹出"打包成CD"对话框。

"打包成CD"对话框的说明是："将一组演示文稿复制到计算机上的文件夹或CD。"其中：
- "将 CD 命名为"：设置CD的名称，默认是"演示文稿 CD"。
- "要复制的文件"列表框：列出要一起打包的演示文稿文件。
- "添加"按钮：添加更多要打包的文件。
- "删除"按钮：删除不打包的pptx文档。
- "复制到文件夹"按钮：打开"复制到文件夹"对话框，可以将演示文稿复制到指定的文件夹中。
- "选项"按钮：打开"选项"对话框。

### 3."选项"对话框中包含哪些设置项？

答：（2）单击"选项"按钮，打开"选项"对话框。
- **包含这些文件**：
  - "链接的文件"（这些文件将不显示在"要复制的文件"列表中）
  - "嵌入的TrueType字体"（不勾选则可能出现字体失真）
  - "嵌入的 TrueType 字体"（选择"嵌入的TrueType"字体，以避免字体失真）
- **增强安全性和隐私保护**：
  - "打开每个演示文稿时所用密码"
  - "修改每个演示文稿时所用密码"
  - "检查演示文稿中是否有不适宜信息或个人信息"

还可以设置打开和修改演示文稿的密码。

### 4.如何将演示文稿复制到指定的文件夹？

答：（3）在"打包成CD"对话框中可以选择添加更多的pptx文档一起打包，也可以删除不打包的pptx文档，单击"复制到文件夹"按钮，打开"复制到文件夹"对话框，可以将演示文稿复制到指定的文件夹中。

"复制到文件夹"对话框中需要设置：
- "文件夹名称"（默认为"演示文稿 CD"）
- "位置"（默认路径）
- "完成后打开文件夹"复选框

### 5.打包完成后会发生什么？

答：（4）单击"确定"按钮后，系统自动运行打包复制到文件夹程序，完成后自动弹出打包好的文件夹，其中有一个AUTORUN.INF自动运行文件。打包到CD光盘上时，这个文件具有自动播放功能。

（5）将打包后的文档刻录成CD光盘就可以在没有PowerPoint或版本不兼容的计算机上播放了。

### 6.PPT文件能否在没有安装PowerPoint的计算机上直接放映？

答：不能。扩展名为 .pptx 的文件在没有安装PowerPoint 2010的系统中不能直接放映，必须通过"打包成CD"功能将演示文稿打包，生成包含播放器或相关组件的文件夹，再刻录成CD，才能在没有安装PowerPoint或版本不兼容的计算机上播放。

### 7.PowerPoint 2010的"打包"功能有什么价值？

答：PowerPoint 2010提供了"打包"功能，可以将演示文稿、所链接的各种声音、图片等外部文件，以及有关的播放程序都存放在一起，便于在没有安装PowerPoint的计算机上放映，同时还能保护演示文稿的隐私信息。

### 8.本任务的实施步骤是什么？

答：
1. 将演示文稿"校园网络安全知识宣讲.pptx"另存为以放映方式打开的类型，保存在原目录中。
2. 将演示文稿"校园网络安全知识宣讲.pptx"文件打包成CD，保存在原目录中。

### 9.本项目的整体操作思路是什么？

答：打开演示文稿→设置超链接→设置动作按钮→页面设置和打印设置→设置放映方式→制作作品打包→保存演示文稿。
