任务三 SmartArt图形的应用

知识点​

1.什么是SmartArt图形？有什么作用？​

答：SmartArt图形是信息和观点的视觉表示形式，可以通过从多种不同布局中进行选择来创建SmartArt图形，从而快速、轻松、有效地传递信息。本任务将学习如何使用SmartArt图形。

2.PowerPoint 2010的SmartArt图形有哪7种类型？​

答：PowerPoint 2010的SmartArt图形有列表、流程、循环、层次结构、关系、矩阵和棱锥图7种类型，每种类型又包含不同的布局。

3.插入SmartArt图形的操作步骤是什么？​

答：1. 插入SmartArt图形 插入SmartArt图形的步骤如下： （1）单击"插入"选项卡→单击"插图"组的"SmartArt"按钮→弹出"选择SmartArt图形"对话框→在"列表"栏中选择需要的SmartArt图形布局→单击"确定"按钮。

4."选择SmartArt图形"对话框由哪几部分组成？​

答："选择SmartArt图形"对话框左侧为类型列表（全部、列表、流程、循环、层次结构、关系、矩阵、棱锥图、图片），中间为该类型下的各种布局缩略图，右侧为所选布局的预览效果与基本列表说明，下方为"确定"和"取消"按钮。

5.什么是SmartArt图形的"文本"窗格？有什么作用？​

答：（2）当前幻灯片中出现SmartArt图形及其"文本"窗格，左边是"文本"窗格，右边是SmartArt图形。在"文本"窗格顶部，编辑将在SmartArt图形中显示的文字，在"文本"窗格底部，可以查看有关该SmartArt图形的其他信息。SmartArt图形及其"文本"窗格由占位符填充，用户使用自己的信息替换这些占位符。通过"文本"窗格输入和编辑内容时，SmartArt图形会自动更新，即根据需要添加或删除形状。

6.插入SmartArt图形后，"SmartArt工具"选项卡包含哪些操作？​

答：（3）插入SmartArt图形后，功能区新添"SmartArt工具"选项卡，其下方包含"设计"和"格式"两个选项卡，通过这两个选项卡可以对SmartArt图形进行一些复杂的设置。 表3-2 "设计"和"格式"选项卡：

  • "设计"选项卡：创建图形、布局、SmartArt样式、重置、形状、形状样式。
  • "格式"选项卡：艺术字样式、排列、大小。

7.如何将图形文本转换成SmartArt图形？​

答：2. 图形文本转换成SmartArt图形 演示文稿通常包含带有项目符号列表的幻灯片，PowerPoint 2010可以快速地将幻灯片文字转换为SmartArt图形，还可以给SmartArt图形添加动画。 步骤如下：选中需要转换为SmartArt图形的文字→单击鼠标右键，从快捷菜单中选择"转换为SmartArt（M）"命令→在下级菜单中选择合适的SmartArt图形→文本就转换成SmartArt图形。

8.任务实施的具体步骤是什么？​

答：任务实施步骤如下：

  1. 在第一张幻灯片后插入一张幻灯片，版式为"空白"，在新插入的幻灯片中插入SmartArt图形中的"层次结构—线型列表"，并输入相应文字，设置颜色为"彩色范围—强调文字颜色2至3"。
  2. 在"目录"幻灯片中插入图片"image2.jpg"。
  3. 在第十三张幻灯片中插入SmartArt图形中的"交替六边形"，并输入相应文字，设置颜色为"彩色填充—强调文字颜色3"。
  4. 将第十五张幻灯片的文字转换为SmartArt图形中的"垂直曲形列表"，设置颜色为"彩色填充—强调文字颜色1"。
  5. 将演示文稿存盘。

9.本项目的操作思路是什么？​

答：打开演示文稿→插入图片→插入并设置艺术字→插入并设置音频、视频→插入并设置表格、图表→插入并设置SmartArt图形→保存演示文稿。

10.关于SmartArt图形的常见错误辨析是什么？​

答：

  • 在PowerPoint 2010中，插入表格、图片、艺术字、视频、音频时，应在"插入"选项卡中进行操作（正确）。
  • 在图表中选择需要删除的数据系列，按Delete键或Delete按钮，即可删除所选系列（正确）。
  • PowerPoint 2010的SmartArt图形有列表、流程、循环、层次结构、关系、矩阵和棱锥图7种类型，每种类型又包含不同的布局（正确）。
  • 在PowerPoint中不能进行屏幕截图（正确）。
  • 可以对幻灯片中的图片进行位置和大小、旋转、裁剪、重新着色、对比度等设置（正确）。
  • 在PowerPoint 2010中，不能插入Excel图表，只能使用自带的图表向导建立图表（错误，可以插入Excel图表，"插入"→"插图"组的"插入图表"按钮）。
