## 知识点
### 1.什么是样式？

**答：** 样式是Word中一项非常重要的功能，它其实就是一些**字符格式和段落格式的集合**。

### 2.样式的作用是什么？
作用：
- 先创建一种格式样式，然后在需要的时候调用
- 可以帮助我们快速地设置文本和段落的格式
- 使文档排版更加规范统一
- 节省大量手动设置格式的时间
- 提高文档排版的效率

Word自带很多样式，包括标题、正文、引文、目录等，可以直接在样式库中选择，也可以根据自己的需求创建样式。

---

### 3.如何应用样式？

**答：** 选择文本或段落（或将光标定位在段落中），在**样式库**中单击选择一种合适的样式，即可将该样式应用到选中的文本或段落中。

---

### 4.如何新建样式？

**答：** 依次单击"开始"选项卡 → "样式"组 → 打开"样式"对话框 → "新建样式"按钮，打开"根据格式设置创建新样式"对话框。

在对话框中依次设置：
- **名称**
- **样式类型**
- **样式基准**
- **后续段落样式**

单击"格式"按钮，还可以根据实际需要设置字体、段落、文本效果等格式。

---

### 5.如何修改样式？
**答：** 样式库中的样式和自定义的样式都可以根据实际情况进行修改。

修改方法：右击需要修改的样式，选择"修改"命令，弹出"修改样式"对话框，在对话框中进行修改后单击"确定"按钮。

### 6.修改后有何影响？

影响：样式修改后，**原先使用该样式的文本或段落将自动修改**。

---

### 7.管理样式可以进行哪些操作？

**答：** 在"样式"对话框中单击"管理样式"按钮，弹出"管理样式"对话框，可以进行以下操作：
1. 将样式排序
2. 设置样式的显示和隐藏
3. 设置所选样式的可用性
4. 设置字体、段落的默认值
5. 导入或导出样式

---

### 8.多级列表和项目编号的区别是什么？

**答：**
- **多级列表：** 是一个分层的结构，可以清晰地显示出各标题之间的层次关系。可以实现不同级别之间的嵌套，如第1章、第2章属于一级标题，2.1、3.2属于二级标题，2.1.2、3.3.1属于三级标题。
- **项目编号：** 通常用来表示一些并列的项目，各项目之间处于同一级别，不分主次。

多级列表最大的优势在于：更改标题的级别后，编号会自动更新，而手动输入的编号则需要重新修改。

---

### 9.如何创建多级列表？

**答：** 单击"段落"组中的"多级列表"按钮，在列表库中选择一种列表样式，可将此样式应用于文档中。若列表库中没有合适的列表样式，也可自定义一个新的多级列表。

在"定义新多级列表"对话框中可以设置：
- 单击要修改的级别
- 输入编号的格式
- 起始编号
- 编号的字体
- 对齐位置
- 文本缩进位置
- 编号对齐方式等

---

### 10.如何生成目录？

**答：**

**生成目录：**
1. 将光标定位在文档开头
2. 单击"引用"选项卡中的"目录"按钮
3. 在下拉列表中选择"插入目录"
4. 弹出"目录"对话框，更改"显示级别"
5. 单击"确定"即可在文档开头生成目录

### 11.如何更新目录？
**更新目录：** 如果文档中的标题发生变化，则需要单击"更新目录"按钮进行更新，使目录与文档标题完全一样。更新时可选择：
- 只更新页码
- 更新整个目录

| 8 | 系统默认行间距 → **单倍行距** |

| 10 | 首字下沉 → **"插入"**选项卡 → "文本"组 → "首字下沉" |
| 11 | 设置段落边框和底纹 → "开始"选项卡 → **"段落"组** |
| 12 | 输入新文字同时替换原有文字 → 选定需替换的内容，直接输入新内容 |
| 13 | 段间距 = 一个段落的**段前间距和段后间距之和** |
| 14 | "增加缩进量"/"减少缩进量"调整的是**左缩进** |

| 16 | 改变字体第一步 → **选定要改变字体的文字** |
| 17 | 直观改变段落缩进方式 → 使用**标尺** |
| 18 | 使各行等宽的对齐方式 → **分散对齐** |
| 19 | 设置空心字、阴影字 → "开始"选项卡 → "字体"对话框 → **"文字效果"**按钮 |
| 20 | 首行缩进与**悬挂缩进**不能同时起作用 |
| 21 | 设置上标 → "开始"选项卡 → **"字体"组** |
| 22 | 复制字符格式 → 使用**格式刷** |
| 23 | 进入扩展选取状态 → 按下**F8**键 |
