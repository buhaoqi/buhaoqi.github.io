### 简答题1：什么是图文混排？Word 2010中可插入的对象有哪些？

**答：** 图文混排是指在文档中插入各种图片、图形、表格、图表等对象，对这些内容进行综合编辑和排版，使文档呈现图文并茂的效果，增强文档的可读性和实用性。

Word 2010中可插入的对象有很多，这些对象都是先通过**"插入"选项卡**插入到文档中，再进行编辑排版。这些对象和普通文本一样，遵循**先选择再编辑**的原则。

---

### 简答题2：Word文档中可以插入哪些格式的图片？如何插入图片？

**答：** Word文档中可以插入多种类型的图片，如**JPG格式、PNG格式、BMP格式**等。

插入方法：将光标定位在需要插入图片的位置，依次单击"插入"选项卡 → "插图"组 → "图片"按钮，弹出插入图片对话框，选择图片后点击"插入"按钮或者双击图片都可以把图片插入到文档中。

---

### 简答题3：选择图片后可以设置哪些图片格式？

**答：** 选择图片后，功能区中会自动出现"图片工具" → "格式"选项卡，可进行以下设置：
1. **更改图片样式：** 在图片样式库中选择，也可单独设置图片边框、图片效果、图片版式
2. **设置图片边框：** 多种线型（实线、圆点线、方点线、短划线等），可设置颜色、线型和粗细
3. **设置图片效果：** 包括预设、阴影、映像、发光、柔化边缘、棱台、三维旋转等
4. **设置图片版式：** 如圆形图片标注、图片题注列表、蛇形图片块等
5. **设置图片格式对话框：** 单击"图片样式"组的对话框启动器，可进行图片边框、图片效果、图片颜色、艺术效果等多种设置

---

### 简答题4：Word提供了哪几种图片效果？

**答：** Word提供了多种图片效果，包括：**预设、阴影、映像、发光、柔化边缘、棱台、三维旋转**等。每种效果还包括多种子样式，可以做更精细的设置。

---

### 简答题5："设置图片格式"对话框有什么特点？

**答：** 单击"图片样式"组的对话框启动器可打开"设置图片格式"对话框。对话框中包含了图片边框、图片效果、图片颜色、艺术效果等多种设置。先在左侧区域选择设置的类型，然后在右侧对话框中进行详细设置。对话框中**没有"确定"按钮**，设置完成后单击**"关闭"按钮**，设置即刻生效。

---

### 简答题6：图片在文档中有哪几种环绕方式？默认是什么？

**答：** 图片在文档中的环绕方式有**七种**：

| 环绕方式 | 特点 |
|---------|------|
| **嵌入型** | 默认方式。Word将图片看作文本中的一个普通字符，图片左右都有文字，跟随文本变动而变动 |
| **四周型环绕** | 不管图片是否为矩形，文字以矩形方式环绕在图片四周 |
| **紧密型环绕** | 如果图片是矩形则以矩形方式环绕；如果是不规则图形，文字将紧密环绕在图片四周 |
| **穿越型环绕** | 与紧密型类似，但严重凹陷的图片会有部分文字在图片内部显示（好像穿越了一样） |
| **上下型环绕** | 文字环绕在图片上方和下方，泾渭分明，版面整洁 |
| **衬于文字下方** | 图片在下，文字在上分为两层，文字将图片覆盖 |
| **浮于文字上方** | 图片在上，文字在下分为两层，图片将文字覆盖 |

插入图片后，默认的环绕方式是**嵌入型**。

---

### 简答题7：如何设置图片的位置、环绕方式和大小？

**答：** 右击图片，在弹出的快捷菜单中选择"大小和位置"，弹出"布局"对话框：
- **位置：** 在"位置"选项卡中设置图片在文档中的位置
- **环绕方式：** 在"文字环绕"选项卡中设置
- **大小：** 在"大小"选项卡中更改图片大小。如果勾选了**"锁定纵横比"**，只需要设置图片的高度，系统将自动计算宽度值

---

### 简答题8：如何插入剪贴画？

**答：** 依次单击"插入"选项卡 → "插图"组 → "剪贴画"，窗口右侧会显示"剪贴画"任务窗格，在"搜索"框中输入剪贴画类型关键字，单击"搜索"按钮即可。

双击剪贴画将其插入到文档中，或者单击图片右侧下拉菜单，选择"插入"按钮也可。剪贴画的设置方法与图片一样。
