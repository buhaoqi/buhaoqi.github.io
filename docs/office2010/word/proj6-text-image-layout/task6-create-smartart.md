### 简答题24：什么是SmartArt图形？包括哪些类型？

**答：** SmartArt图形能够以更直观的方式表达信息，Word 2010中内置了多种SmartArt图形样式，包括：
- **图形列表**
- **流程图**
- **层次结构图**
- **关系图**
- **矩阵图**等

利用这些样式可以很轻松地制作出多样化的复杂图形。

---

### 简答题25：如何插入SmartArt图形？

**答：** 单击"插入"选项卡 → "插图"组 → SmartArt，弹出"选择SmartArt图形"对话框，在对话框左侧选择类别（如层次结构），右侧选择图形样式（如组织结构图），单击"确定"按钮。

此时页面上出现组织结构图，在各个文本框中填充文字内容，可在左侧文本列表框中输入，也可直接在图形中输入。

---

### 简答题26：如何设置SmartArt图形格式？

**答：** 选中SmartArt图形，功能区会自动显示"SmartArt工具"选项卡，包括**"设计"**和**"格式"**两个选项卡。

- **"格式"选项卡：** 可以像设置图形一样进行设置（形状填充、形状轮廓、形状效果等）
- **"设计"选项卡：** 可以进一步对SmartArt图形进行布局以及样式的设置

---

### 简答题27：如何在SmartArt图形中添加形状？不同添加方式有什么区别？

**答：** 插入的SmartArt图形给出的形状往往不够用，可以使用"设计"选项卡中的**"添加形状"**按钮进行添加。

不同添加方式的区别：
- 在**前面或后面**添加：添加后的形状与原形状是**同级**关系
- 在**上方或下方**添加：添加后的形状与原形状是**上、下级**关系

---

### 简答题28：如何更改SmartArt图形的颜色和样式？

**答：** 选中SmartArt图形，单击"SmartArt样式"组中的**"更改颜色"**按钮，可以更改图形的颜色；单击"SmartArt样式"组中的样式，可以更改图形的外观样式。

以下为教材课后习题中涉及的高频考点：

| 序号 | 知识点 |
|------|--------|
| 1 | 插入图片后可进行的操作：**填充颜色、裁剪、缩放**（以上均可） |
| 2 | 绘制文本框使用的选项卡 → **"插入"** |
| 3 | 选定图形的简单方法 → **单击图形** |
| 4 | 绘制"曲线"时停止绘制 → **双击鼠标左键** |
| 5 | 用"插入→形状"直接绘制的图形**不能裁剪**（可移动复制、放大缩小、删除） |
| 6 | 插入图片后默认的环绕方式 → **嵌入型** |
| 7 | 按住Shift拖动图形角控点 → **按比例改变图片大小** |
| 8 | **嵌入型的图片不能与其他图片组合**（环绕方式为非嵌入型才能组合） |
| 9 | 不属于图形叠放次序的是 → **四周型**（叠放次序有置于顶层、衬于文字下方、上移/下移一层等） |
| 10 | 图片版式设置不能用 → **滚动型**（可用嵌入型、四周型、紧密型等） |
| 11 | 选项卡工具组内的按钮**可以增减** |
| 12 | 可以使用**其他图形软件中转换过的图片**（不限于Word本身提供的） |
| 13 | 艺术字可以像图片一样设置**与文字的环绕方式** |
| 14 | "图片工具"下"格式"选项卡中**有"排列"组** |
| 15 | Word提供的文字环绕方式不包括 → **左右型** |
| 16 | 形成水印图案（文字与图案重叠）→ 将图片置于**文本层之下** |
| 17 | 绘制图形首先选择 → "插入"选项卡 → **"形状"**命令按钮 |
| 18 | 有文字的区域绘制图形 → 文字**可能被覆盖** |
| 19 | 多个图形对象**既可以"组合"也可以"取消组合"** |
| 20 | 图片裁剪后**可以恢复**到裁剪前的状态 |
