### 简答题9：Word提供了哪几类图形样式？

**答：** Word提供了**8类**图形样式，分别是：
1. **线条**
2. **矩形**
3. **基本形状**
4. **箭头总汇**
5. **公式形状**
6. **流程图**
7. **星与旗帜**
8. **标注**

选中形状样式后在页面上拖动鼠标画出来。

---

### 简答题10：如何插入图形？按住Shift键绘制图形有什么作用？

**答：** 插入图形方法：依次单击"插入"选项卡 → "插图"组 → "形状"，选择一种形状样式，鼠标指针变为**十字形状**，在页面拖动鼠标画出选定的图形。

按住Shift键的作用：
- 绘制图形的同时按住**Shift键**，可以画出**方正的图形**（如选择矩形按住Shift可画正方形，选择椭圆按住Shift可画正圆形）
- 改变图形大小时按住**Shift键**可将图形**等比例缩放**

### 简答题11：如何设置图形格式？

**答：** 选中图形，功能区会自动显示"绘图工具" → "格式"选项卡，可进行以下设置：

1. **更改图形样式：** 在形状样式库中选择，也可单独设置形状填充、形状轮廓、形状效果
2. **设置形状填充：** 可设置颜色填充、图片填充、渐变填充、纹理填充
3. **设置形状轮廓：** 可设置轮廓颜色、轮廓线型、线型磅值
4. **设置形状效果：** 在下拉列表中选择一种效果及子样式
5. **设置形状格式对话框：** 单击"形状样式"组中的对话框启动器打开，设置完成后单击"关闭"按钮
6. **设置位置、环绕方式和大小：** 右击图形选择"其他布局选项"，在"布局"对话框中设置，操作方法与设置图片一样

---

### 简答题12：形状填充包括哪几种填充方式？

**答：** 形状填充包括四种填充方式：
1. **颜色填充：** 在主题颜色或标准色中选择一种颜色
2. **图片填充：** 选择"图片…"选项，在对话框中选择图片插入
3. **渐变填充：** 选择"渐变"选项，选择渐变颜色和变体样式
4. **纹理填充：** 选择"纹理"选项，在弹出的纹理样式中选择

---

### 简答题13：如何在图形中添加文字？

**答：** 在页面中绘制的任意图形都可以添加文字。右击图形，在弹出的快捷菜单中选择**"添加文字"**，图形中会显示光标，在光标处可输入文字。这种功能是图片不具备的。
