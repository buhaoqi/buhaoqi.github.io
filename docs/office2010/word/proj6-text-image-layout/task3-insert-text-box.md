### 简答题14：什么是文本框？它有什么特点？

**答：** Word文本框是一种**可移动、可调节大小**的文字或图形容器，有**横排**和**竖排**两种形式，用于存放文字和图形。

特点：
- 文本框可以放到文档的任何位置
- 可以覆盖在文本之上，也可以隐藏在文本下面
- 文本框是一种**图形对象**，可以像设置图片、图形一样设置填充色、线条色、边框线型和粗细等
- 可以将文档中的文字以不同的方式环绕在文本框周围

---

### 简答题15：如何插入和绘制文本框？

**答：**

**插入文本框：** Word中内置了多种文本框样式，单击"插入"选项卡 → "文本"组 → "文本框"，选择一种样式即可插入。

**绘制文本框：** 单击"插入"选项卡 → "文本"组 → "文本框" → "绘制文本框"或"绘制竖排文本框"，鼠标指针变为十字形，拖动鼠标可以在页面中画出一个横排或竖排的文本框，此时文本框处于编辑状态，可输入文字或添加其他对象。

### 简答题16：如何设置文本框格式？

**答：**
1. 文本框处于编辑状态和选中状态时，功能区会自动显示"绘图工具 → 格式"选项卡，利用"格式"选项卡中的各种按钮及下拉列表可以对文本框进行设置。
2. 鼠标指针对准文本框的边线右击，选择"设置形状格式"，在弹出的对话框中进行相关设置，操作方法与设置图形一样。
