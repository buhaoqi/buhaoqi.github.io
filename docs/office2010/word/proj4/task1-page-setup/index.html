任务一 页面设置

1.Word 2010中的页面设置主要包括哪些内容？​

答： 页面设置是文档排版的重要组成部分，合理布局页面可以使页面整体结构更规范美观，增强文档的可读性和实用性。页面设置主要包括：文字方向、页边距、纸张方向、纸张大小、分栏、分隔符、稿纸设置、页面背景（水印、页面颜色、页面边框）等。

2.主要通过哪个选项卡完成？​

Word 2010中的页面设置主要通过**"页面布局"**选项卡完成。

3.默认文字方向是什么？​

答： Word 2010中默认的文字方向是水平方向（即横排方式）。某些特殊情况需要用到竖排方式（如请柬），设置方法：

4.如何设置文字方向？​

选中文字 → "页面布局"选项卡 → "文字方向"按钮 → 选择"垂直"，也可以打开"文字方向选项"对话框，在对话框中进行设置，还可以预览效果。

5.什么是页边距？​

答： 页边距是指文档四周的空白区域。

6.如何设置页边距？​

设置方法：

  1. "页面布局"选项卡 → "页面设置"组 → "页边距"按钮，在下拉列表中选择。
  2. 打开"页面设置"对话框，在"页边距"选项卡中设置上、下、左、右及装订线的具体数值。

7.Word 2010的纸张方向有哪几种？默认是什么？​

答： Word 2010的纸张方向有**"横向"和"纵向"两种，默认的纸张方向是纵向**。

8.如何设置纸张方向？​

设置方法：

  1. 通过"页面布局"选项卡中的"纸张方向"按钮进行设置。
  2. 打开"页面设置"对话框，在"页边距"选项卡中设置。

注意：如果将文字方向从"水平"改为"垂直"，纸张方向会自动从"纵向"改为"横向"。如果不想让纸张方向发生变化，只需再次设置纸张方向为"纵向"即可。

9.Word 2010默认的纸张大小是什么？​

答： Word 2010默认的纸张大小是A4（21厘米×29.7厘米）。

10.如何设置纸张大小？​

设置方法：

  1. 单击"页面布局"选项卡中的"纸张大小"按钮，在下拉列表中选择。
  2. 打开"页面设置"对话框，在"纸张"选项卡中选择或自定义纸张大小。

11.什么是分栏？​

答： 分栏是指将文档中的内容分成两栏或多栏，是文档排版的一个基本方法，能够让文档版面看起来更规范更专业。

12.如何设置分栏？​

设置方法：

  1. 单击"页面设置"组中的"分栏"按钮，在下拉列表中选择一种分栏样式。
  2. 单击"页面设置"组中的"分栏"按钮，选择"更多分栏"，打开"分栏"对话框，可设置分栏数、栏宽、栏间距、分隔线等。

注意：

  • Word 2010默认对全文进行分栏，如果只对个别段落分栏，必须先选择后分栏。
  • 如果勾选了"栏宽相等"，只需设定一栏的宽度；如果没有勾选，则各栏的宽度都需要设定。

13.Word文档排版时常用的分隔符有哪四种？​

答：

分隔符作用
分页符当文本或图形等内容填满一页时，Word会插入自动分页符并开始新的一页。如需在特定位置强制分页，将光标定位在特定位置，依次单击"页面布局"→"分隔符"→"分页符"，或使用快捷键Ctrl+Enter
分栏符对文档进行分栏时，若希望某一内容出现在下一栏，先定位光标，再依次单击"页面布局"→"分隔符"→"分栏符"，光标后面的内容将在下一栏中显示
自动换行符从光标所在处强制断行，换行符显示为灰色"↓"，通常称为软回车。这种方法产生的新行仍属于当前段落，是当前段落的一部分
分节符节是文档的一部分，在需要改变行号、分栏数或页眉页脚、页边距等特性时，需要创建新的节

14.Word提供了哪几种分节符？​

答： Word提供了4种分节符：

  1. 下一页分节符： 插入分节符并在下一页上开始新节。
  2. 连续分节符： 插入分节符并在同一页上开始新节。
  3. 偶数页分节符： 插入分节符并在下一偶数页上开始新节。
  4. 奇数页分节符： 插入分节符并在下一奇数页上开始新节。

注意：删除分节符的同时，也就删除了该分节符之前文本所应用的格式，并且自动沿用后面一节的格式。

15.分页符与分节符有什么区别？​

答：

对比项分页符分节符
作用将光标以后的内容快速移动到下一页将一节内容分成两节
节关系分页后的内容和分页前的内容仍属于同一节，格式一样分节后的各部分是独立的，可单独设置纸张大小、方向、页边距等
页面位置内容在下一页内容可以在同一页面也可以不在同一页面
草稿视图显示一条虚线两条虚线
删除方式选中后用Delete键删除（Word自动生成的分页符不可删除）选中后用Delete键删除

16.Word 2010提供了哪几种稿纸样式？​

答： Word 2010提供了3种稿纸样式：

  1. 方格式稿纸
  2. 行线式稿纸
  3. 外框式稿纸

17.如何设置稿纸样式？​

设置方法：新建一个空白文档，选择"页面布局"选项卡中的"稿纸设置"按钮，弹出"稿纸设置"对话框，在对话框中依次设置网格格式、行数×列数、网格颜色、纸张大小、方向等，最后单击"确认"按钮。

注意：生成稿纸时行数和列数已经固定，所以稿纸中只能设置字体，不可更改字号。

18.页面背景的设置包括哪些内容？​

答： Word 2010页面背景的设置包括三个方面：

  • 设置水印效果
  • 设置页面背景
  • 设置页面边框

19.如何设置水印效果​

  • 选择"页面布局"选项卡 → "页面背景" → "水印" → "自定义水印"，打开"水印"对话框
  • 图片水印： 选择图片、设置缩放，单击"确定"
  • 文字水印： 依次设置文字内容、字体、字号、颜色、版式，单击"确定"

20.如何设置页面颜色​

  • 选择"页面布局"选项卡 → "页面背景" → "页面颜色"，在颜色面板中选择一种颜色
  • 也可选择"填充效果"，在对话框中设置。页面颜色可以设置成渐变色、纹理、图案、图片等填充效果

21.如何设置页面边框​

  • 选择"页面布局"选项卡 → "页面背景" → "页面边框"，在"边框和底纹"对话框中依次设置边框的样式、颜色、宽度、艺术型式

注意：页面边框的作用范围默认是整篇文档，如果只想对文档中部分页面设置边框，需要手动插入分节符，再进行边框设置。
