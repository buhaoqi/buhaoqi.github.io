任务三 插入脚注、尾注和题注

简答题19：什么是脚注？有什么特点？​

答： 脚注位于页面的底部，随文档内容同步出现，随文档内容的变化而自动调整，通常采用自动编号的形式，适用于需要立即解释或补充的少量信息。

简答题20：什么是尾注？有什么特点？与脚注有何区别？​

答： 尾注位于文档末尾，不与文档内容同步，不会随内容的变化而自动调整，尾注的编号在文档末尾集中显示，通常用于汇总文档中引用的所有参考文献或补充说明。

对比项脚注尾注
位置页面底部文档末尾
是否同步随文档内容同步出现不与文档内容同步
用途立即解释或补充的少量信息汇总引用的参考文献或补充说明
编号显示分散在各页底部集中在文档末尾

简答题21：如何插入脚注？​

答： 将光标定位在需要设置脚注的位置（或选中需要设置脚注的文本），单击"引用"选项卡，选择"插入脚注"按钮，在所选位置右上方自动显示数字1，同时页面底端会出现一条水平线（注释分隔符），在该分隔符下面可以输入脚注内容。

可以在文档多处位置插入脚注，编号会自动排列。更改了脚注的位置，编号及脚注内容也会随之更改。

简答题22：如何插入尾注？​

答： 将光标定位在需要设置尾注的位置，单击"引用"选项卡，选择"插入尾注"按钮，在所选位置右上方自动显示数字Ⅰ，同时光标自动跳转到文档末尾，文档末尾会出现一条水平线（注释分隔符），在该分隔符下面可以输入尾注内容。

可以在文档多处位置插入尾注，编号会自动排列。更改了尾注的位置，编号及尾注内容也会随之更改。

简答题23：如何查看脚注和尾注？​

答： 由于脚注和尾注的数字都是以上标的形式体现的，在文档中不容易查找，查看方法：

  1. 双击脚注或尾注的编号，光标将快速定位在相应位置（页面底端的脚注或文档末尾的尾注）。
  2. 将鼠标指针对准文档中的脚注或尾注的编号，注释内容会自动显示。

简答题24：脚注和尾注如何相互转换？​

答： 在"脚注和尾注"对话框中单击"转换"按钮，弹出"转换注释"对话框，可以将文档中所有的脚注转换成尾注（集中显示在文档末尾），也可以将所有的尾注转换成脚注（自动分配在对应的页面底端）。

简答题25：如何区分脚注和尾注的数字格式？​

答： 在"引用"选项卡中打开"脚注和尾注"对话框，可以将脚注的位置设成"页面底端"，格式设为"1, 2, 3……"；将尾注的位置设成"文档结尾"，格式设为"Ⅰ, Ⅱ, Ⅲ……"，单击"应用"按钮即可。

简答题26：什么是题注？如何插入题注？​

答： 题注就是给文档中插入的各种对象如图片、表格、图表等添加的名称和编号。题注可以单独生成一个表目录。如果题注的编号和内容发生变化，目录也会随之更新。

插入方法（以图片为例）：选中图片 → 单击"引用"选项卡 → 选择"插入题注" → 弹出"题注"对话框 → 在"标签"框选择"图片"，"题注"框中会自动显示"图片1" → 完善"题注"框中的内容 → 单击"确定"按钮。按同样方法可以给其他图片分别插入题注，编号会自动排列（图片2、图片3……）。

简答题27：如何删除脚注或尾注？​

答： 在文档中找到脚注或尾注的编号，选中删除即可。

简答题28：什么是图表目录？如何生成和更新？​

答： 图表目录是Word中一种常见的目录形式，目录中可以列出文档中的图片、图表、表格、公式等的说明及它们在文档中的页码。

生成方法： 将光标定位在文档开头，单击"引用"选项卡中的"插入表目录"按钮，弹出"图表目录"对话框，勾选"显示页码""包含标签和编号"，选择合适的格式，单击"确定"。

更新方法： 如果文档中的题注发生变化，可通过"更新表格"按钮更新目录。

跳转方法： 按住Ctrl键的同时单击图表目录，即可快速跳转到所对应的图片处。

注意：表目录是以插入的题注为基础创建的，目录与文档中的题注是链接关系。
