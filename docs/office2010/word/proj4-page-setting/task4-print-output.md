### 简答题29：如何打开打印设置界面？打印参数包括哪些内容？

**答：** 单击"文件"选项卡，选择下拉列表中的"打印"命令，弹出打印设置界面。

打印参数包括：

| 参数 | 说明 |
|------|------|
| **打印机** | 显示打印机名称、位置和状态，如果安装了多台打印机，可以选择用哪一台 |
| **份数** | 输入要打印的份数，默认打印1份 |
| **打印所有页** | 默认打印所有页面，也可选择打印当前页、打印所选内容或打印自定义范围 |
| **页数** | 输入指定页码或页码范围（用逗号分隔，如1,3,5-10表示打印第1页、第3页和第5至第10页） |
| **单面打印** | 设置单面打印还是手动双面打印 |
| **调整** | 打印数量在1份以上时，每份按文档顺序打印；也可"取消排序"（按页打印，第1页打够份数后再打第2页） |
| **每版打印页** | 实现多版缩放打印功能，可以将多页文档打印在一页纸上 |

### 简答题30：如何进行打印预览？

**答：** Word文档的打印效果可以采用打印预览的方式查看。打开方法：
1. 单击快速访问工具栏中的"打印预览和打印"按钮。
2. 单击"文件"选项卡中的"打印"命令。

通过调整窗口右下角的"显示比例"可以实现一屏多页的显示效果。

---

### 简答题31：如何设置打印背景色和图像？

**答：** 一般情况下Word文档中插入的图像以及背景色是不能打印出来的，如果需要将这些内容打印在纸上，可以依次单击"文件" → "选项" → "显示"命令，在"打印选项"中勾选**"打印背景色和图像"**即可。

---

### 简答题32：如何打印文档？

**答：** 如果打印的相关参数已经设置好，可以：
1. 直接单击快速访问工具栏中的"快速打印"按钮直接打印。
2. 在"打印预览"对话框中点击"打印"按钮进行打印。

## 附：重要选择题/填空题知识点速记

以下为教材课后习题中涉及的高频考点：

| 序号 | 知识点 |
|------|--------|
| 1 | 同一文档中某一页为横向页面 → 在该页开始处和下一页开始处插入**分节符**，再调整"本节的"页面设置 |
| 2 | 查看打印效果 → 选择**打印预览** |
| 3 | 文字下面有**红色**波浪下划线 → 可能有**拼写错误** |
| 4 | 文字下面有**绿色**波浪下划线 → 可能有**语法错误** |
| 5 | 统计文档行数和段落数 → "审阅"选项卡中的**字数统计**功能 |
| 6 | 页眉奇偶页不同 → "页面设置"对话框中选择**版式**标签 |
| 7 | "样式"命令在**"开始"**选项卡中 |
| 8 | 分栏可以设置**分隔线** |
| 9 | 页眉中**不能插入分隔符**（可以插入剪贴画、日期，可以建立奇偶页不同） |
| 10 | 页码范围"4-16,25,41" → 打印第4页至第16页、第25页、第41页 |
| 11 | 文字分为左右两栏 → 选定文字，**页面布局→分栏** |
| 12 | 打开页眉页脚 → **双击页眉页脚区** |
| 13 | 横向打印 → "页面设置"对话框选择**页边距**选项卡 |
| 14 | 行距设为24磅 → 选择"固定值" |
| 15 | 调整段落左右边界最直观的方法 → **拖动标尺上的缩进标记** |
| 16 | 页眉下的横线**可以删除** |
| 17 | 页眉页脚中**可以插入图片对象** |
| 18 | "页面设置"默认对**整篇文档**生效 |
| 19 | 编辑页眉/页脚时，**不能同时编辑文档正文** |
| 20 | 制作目录前需将各级标题设置为**标题样式** |
| 21 | 打印预览功能可在打印前看到打印效果 |
| 22 | 页眉页脚使用**"插入"**选项卡中的命令 |
| 23 | 首字下沉功能可将段落第一个字放大突出显示 |
| 24 | Shift+Home 选定到行首；Ctrl+Shift+Home 选定到文档开头；Ctrl+Shift+End 选定到文档结尾 |
| 25 | 水平标尺两端的灰色部分显示的是**页边距** |
| 26 | "拼写和语法"检查在**"审阅"**选项卡中 |
| 27 | "查找和替换"对话框快捷键是**Ctrl+H**；打印当前文档快捷键是**Ctrl+P** |
| 28 | 全部替换 → 单击"查找和替换"对话框中的**全部替换**按钮 |
