任务四 表格数据的排序与计算

简答题26：Word表格中的排序有哪些规则？​

答：

  • 排序的对象可以在表格中，也可以不在表格中
  • 可以给某列单独排序，也可对整个表格排序
  • 以关键字为排序依据，最多可以指定三个关键字（主要关键字、次要关键字、第三关键字）
  • 排序类型可以是数字、日期、笔画、拼音
    • 对文字列排序，Word自动设置排序类型为"拼音"
    • 对数据列排序，Word自动设置排序类型为"数字"
    • 对日期排序，Word自动设置排序类型为"日期"

简答题27：如何进行数据排序？​

答： 单击任意单元格使表格处于编辑状态，依次单击"表格工具" → "布局" → "数据"组 → "排序"按钮，弹出"排序"对话框。在对话框中依次设置主要关键字、次要关键字和第三关键字，最后单击"确定"按钮完成排序。

简答题28：Word表格中常用的函数有哪些？公式中表示计算范围的域名称有哪三个？​

答： 常用函数：

  • SUM： 求和
  • AVERAGE： 求平均值
  • MAX： 求最大值
  • COUNT： 计数

公式中表示计算范围的域名称有三个：

域名称含义
LEFT当前单元格左侧同一行中所有包含数字的单元格
RIGHT当前单元格右侧同一行中所有包含数字的单元格
ABOVE当前单元格上面同一列中所有包含数字的单元格

注意：函数名称及域名称都不区分大小写。

简答题29：如何用公式进行数据计算？​

答： 将光标定位在需要放置结果的单元格中，选择"表格工具" → "布局" → "数据" → "公式"，弹出"公式"对话框。

对话框中显示默认公式 =SUM(LEFT)，表示要对左侧数据求和，单击"确定"即可显示结果。如果需要更改计算类型，可在对话框中的"粘贴函数"下拉列表中选择其他函数。

简答题30：如何在Word表格中进行数据批量计算？​

答： Word表格中的公式只对某一行或某一列起作用，计算结果不能直接填充，但可以进行批量计算，有两种方法：

方法一（复制+F9）：

  1. 先用公式计算出第一个数值
  2. 选中这个数值并复制
  3. 选中其他用来存放计算结果的单元格区域进行粘贴
  4. 此时数值被原原本本粘贴到选中区域，不要取消选定
  5. 按一下F9功能键，数值会自动更新
  6. 如果对数据进行了修改，选定存放结果的单元格区域，同样用F9更新

方法二（F4重复操作）：

  1. 先用公式计算出第一个数值
  2. 鼠标选中下一个单元格
  3. 按一下F4功能键（F4的用法是重复上一步操作），结果会自动计算出来
  4. 继续选择其他单元格，用F4实现批量计算

附：重要选择题/填空题知识点速记​

以下为教材课后习题中涉及的高频考点：

序号知识点
1选定整个表格 → 单击表格左上角的表格移动控点（全选图标）
2调整表格中同列单元格宽度 → 利用水平标尺
3给选定段落、表、单元格添加的背景称为底纹
4插入点在表格最后一行的最后一个单元格内，按Enter → 插入点所在行增高
5插入点在表格最后一行的最后一个单元格外，按Enter → 在插入点所在行下方增加一行
6"插入表格"对话框默认是2行5列
7Word表格数据不具有筛选功能（可求和、排序、求平均值）
8表格设置为无边框时，"查看网格线" → 草稿视图中可见虚线，打印预览时看不见虚线
9选择整个表格后执行"删除行" → 整个表格被删除
10计算某列数值总和 → 使用函数SUM()
11光标在单元格中切换到下一列 → 按Tab键；切换到上一列 → 按Shift+Tab
12快速拆分表格 → 按Ctrl+Shift+回车键
13合并单元格 → "表格工具/布局"中的"合并单元格"命令
14对表格数据进行计算 → 选择**"布局"**选项卡
15单独改变某列宽度不影响其他列 → 先按住Shift键，再拖动某列右边线
16选定一列后按Delete键 → 仅删除这一列单元格中的内容（不删除列）
17拆分表格前光标应放在原表格的第二行（若拆成两个二行表格）
18已有文字制作成表格最快捷 → 使用**"文字转换表格"**命令
19表格样式可根据需要新建，也可更改为其他样式
20单元格边距指的是单元格中正文与上下左右边框线的距离
21文字转换表格时中文逗号不能作为分隔符（可用段落标记、逗号、空格、制表符）
22行高设为4磅实际高度 → 选择固定值
23选定行后再选定列 → 表格被选择的部分是插入点所在行和列（整个表格）
24表格拆分是从某两行之间把原来的表格分成上下两个表格
25合并三个连续单元格后再拆分，行数可选择1和3
26Word表格中可以再插入表格
27合并单元格后不会删除原单元格中的数据
28光标在最后一个单元格按Tab键可在表格末尾添加一行
29新建表格默认位置是左对齐（不是居中）
30选定表格一行后按退格键（Backspace）→ 删除该行
31水平垂直都居中 → 选择单元格对齐方式中的中部居中
32用橡皮工具擦掉两个相邻单元格中间线 = 合并单元格操作
33创建表格时默认边框线宽度是0.5磅
34计算上方各单元格数据之和 → 公式 =SUM(ABOVE)
35拆分表格命令在"表格工具"下的**"布局"**选项卡中
36表格居中对齐 → 使用"开始"选项卡中的段落命令
37铅笔工具最多在一个单元格中可绘制2条斜线
38设置表格列宽在"表格工具"下的**"布局"**选项卡
