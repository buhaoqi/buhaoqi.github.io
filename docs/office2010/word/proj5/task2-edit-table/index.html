任务二 表格的编辑

简答题8：表格编辑的基本原则是什么？主要的编辑操作包括哪些？​

答： 对Word表格进行编辑同样遵循先选择再操作的原则。主要的编辑操作包括：选定表格、行、列及单元格；插入行和列；删除表格、行、列、单元格；合并拆分表格、单元格；调整行高和列宽等。

这些编辑操作都可以利用**"表格工具"选项卡中的"布局"**选项卡完成。

简答题9：如何选择表格中的单元格、行、列和整个表格？（鼠标操作）​

答：

选择对象鼠标操作
单元格将光标定位在单元格左侧，指针变为黑色右上斜箭头时，单击
一行将光标定位在行左侧空白区域，指针变为空心右上斜箭头时，单击
一列将光标定位在列上方，指针变为黑色下箭头时，单击
整个表格表格处于编辑状态时或鼠标指针掠过表格区域时，表格左上角会出现全选图标，单击即可
  • 选择多个连续的单元格、行或列：用鼠标拖动
  • 选择不连续的多个单元格、行或列：按住Ctrl键的同时，用鼠标点选

也可以使用"布局"选项卡中的"选择"命令来选择单元格、行、列和表格。

简答题10：删除表格、行、列、单元格的方法有哪些？​

答：

  1. 使用"删除"命令： 选择"布局"选项卡中的"删除"命令，在弹出的下拉列表中进行单元格、行、列、表格的删除。（删除单元格时会弹出对话框，需要选择"右侧单元格左移""下方单元格上移""删除整行""删除整列"）
  2. 使用快捷菜单： 选择单元格、行、列后，右击弹出快捷菜单，选择"删除单元格""删除行""删除列"。
  3. 使用键盘： 选择表格后，使用Backspace键可删除表格；Delete键不能删除表格，只能清除表格中的内容。

简答题11：如何插入行和列？​

答： 将光标定位在任一单元格内，选择"布局"选项卡，单击"行和列"组中的四个插入按钮即可插入行和列：

  • 可以在所选行的上方和下方插入空行
  • 可以在所选列的左侧和右侧插入空列

如果需要同时插入多行或多列，可先选择好行和列的数目再进行插入。也可以在表格区域内右击，选择"插入"子菜单中的命令。

简答题12：合并单元格的方法有哪些？​

答： 合并单元格有三种方法：

  1. 选择需要合并的单元格（必须是连续区域），选择"布局"选项卡 → "合并"组 → "合并单元格"。
  2. 在选中区域右击，在弹出的快捷菜单中选择"合并单元格"命令。
  3. 依次单击"表格工具" → "设计" → "绘图边框" → "擦除"按钮，鼠标指针变为橡皮样式，对准单元格边线单击可擦除边线，达到合并目的。

注意：如果单元格中有内容，内容也将合并在一起。

简答题13：拆分单元格时有什么注意事项？​

答： 拆分单元格方法：选择"布局"选项卡 → "合并"组 → "拆分单元格"，弹出"拆分单元格"对话框，输入行数和列数，单击"确定"。

注意事项：

  • 如果只对一个单元格拆分，行数和列数可以任意
  • 如果对合并后的单元格拆分，列数可以任意，但行数不可任意，拆分的行数必须是原单元格数目的约数

简答题14：什么是拆分表格？如何操作？​

答： 拆分表格是指在水平方向上拆分，也就是把一个表格拆分成两个或多个小表格，拆分后各个小表格的列数不变。

操作方法：将光标定位在除第一行外的其他行，单击"布局"选项卡 → "合并"组 → "拆分表格"，即可将表格拆分成两个，选中的这一行将成为新表格的首行。

简答题15：调整行高和列宽的方法有哪些？​

答：

  1. 使用"表格属性"对话框： 单击"布局"选项卡中的"属性"按钮，打开"表格属性"对话框，单击"行"或"列"，可以指定行的高度或列的宽度，默认单位是厘米。
  2. 拖动边线： 将鼠标指针对准行边线或列边线，指针变为双向可移动箭头，拖动鼠标调整。简单但不能精确调整。
  3. 使用标尺滑块： 插入表格后，水平标尺和垂直标尺上会显示与行、列对应的滑块，用鼠标拖动滑块调整。按住Alt键的同时拖动可进行更细微的调整。
  4. 分布行/分布列： 选择多行或多列后，单击"布局"选项卡中的"分布行"或"分布列"按钮，可使选择的这些行或列具有相同的行高或列宽。

简答题16：表格的对齐方式和文字环绕方式各有哪几种？如何设置？​

答：

  • 对齐方式： 左对齐、居中、右对齐三种
  • 文字环绕方式： 无环绕和环绕两种
  • 新创建的表格默认左对齐、无环绕

设置方法：

  1. 依次单击"表格工具" → "布局" → "表" → "属性"，打开"表格属性"对话框，在对话框中设置对齐方式和环绕方式。
  2. 选中表格 → "开始"选项卡 → "段落"，使用段落组中的左对齐、居中、右对齐按钮也可设置表格的对齐方式。

简答题17：什么是重复标题行？如何设置？有什么注意事项？​

答： 当表格很长时，将自动跨越多个页面，为了在每个页面上能够正常显示标题，可以设置"重复标题行"。

设置方法：

  1. 选择要在每页上重复的标题行，依次单击"表格工具" → "布局" → "数据"组中的"重复标题行"。
  2. 选择要重复的行，打开"表格属性"对话框，在"行"选项卡上，勾选"在各页顶端以标题行形式重复出现"。

注意事项：

  1. 重复的标题行仅在页面视图或打印文档时可见，其他视图不可见。
  2. 如果需要修改标题行格式，只能修改第一页的标题行，后续页面上的标题行都被锁定无法修改，修改第一页后其他所有页面上的标题行会自动更改。
  3. 重复标题行仅限于表格自动分页时可用，表格中插入的手动分页符不可用。
