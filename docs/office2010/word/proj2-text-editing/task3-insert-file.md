## 知识点

### 1.如何在Word文档中插入另一个文件的内容？

**答：** 在打开的 Word 2010 文档中，依次单击"插入"选项卡 → "文本"组 → "对象" → **"文件中的文字"**，在弹出的"插入文件"对话框中选择需要的文件，再单击"插入"按钮即可将该文件中的所有文字插入到文档中。此操作不需要打开源文档，也不需要选定任何文字。

---

### 2.如何在Word文档中新建其他类型的文档？

**答：** 在打开的 Word 文档中依次单击"插入"选项卡 → "文本"组 → "对象"，在弹出的"对象"对话框中选择需要的对象类型（如 Microsoft PowerPoint 演示文稿），勾选"显示为图标"，单击"确定"按钮，可在文档中嵌入一个 PPT 演示文稿。**双击即可在当前文档中直接播放演示文稿。**

---

### 3.如何由文件创建其他类型的文档？

**答：** 在打开的 Word 2010 文档中依次单击"插入"选项卡 → "文本"组 → "对象"，在弹出的"对象"对话框中选择"由文件创建"，单击"浏览"按钮，选择需要的文件，勾选"链接到文件"和"显示为图标"，文档中就会出现源文档的一个图标。


### 4.链接到文件有何作用？
作用：双击即可打开该文件，相当于在文档中给源文件创建了一个快捷方式，并且**源文档的修改会直接作用于该快捷方式**。
