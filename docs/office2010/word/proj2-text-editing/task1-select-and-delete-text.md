## 知识点

### 1.什么是"选定区"？

**答：** 在文档编辑区，鼠标指针呈 I 形指针形状；在文档左侧的空白区域，鼠标指针呈右上空心箭头形状，该区域称&#x4E3A;**"选定区"**。

### 2.如何利用选定区选定文本？
在选定区内可以通过鼠标快速选定文本：

| 鼠标操作    | 文本选择   |
| ------- | ------ |
| 单击      | 选择一行   |
| 双击      | 选择一个段落 |
| 三击      | 选择全文   |
| Ctrl+单击 | 选择全文   |
| 拖动      | 选择连续行  |

---

### 3.编辑区中用鼠标选定文本的方法有哪些？

**答：**

| 鼠标操作    | 文本选择    |
| ------- | ------- |
| 单击      | 定位光标    |
| 双击      | 选择一个词组  |
| 三击      | 选择一个段落  |
| 拖动      | 选择一个文字块 |
| Ctrl+单击 | 选择一个整句  |

---

### 4.用键盘选定文本的常用组合键有哪些？

**答：**

| 组合键             | 功能          |
| --------------- | ----------- |
| Shift+↑         | 向上选定一行      |
| Shift+↓         | 向下选定一行      |
| Shift+←         | 向左选定一个字符    |
| Shift+→         | 向右选定一个字符    |
| Shift+Home      | 选定内容扩展至行首   |
| Shift+End       | 选定内容扩展至行尾   |
| Ctrl+Shift+↑    | 选定内容扩展至段首   |
| Ctrl+Shift+↓    | 选定内容扩展至段尾   |
| Ctrl+Shift+Home | 选定内容扩展到文档开头 |
| Ctrl+Shift+End  | 选定内容扩展到文档末尾 |
| Ctrl+A          | 选择全文        |
| Ctrl+小键盘区数字5    | 选择全文        |

---

### 5.如何选定矩形文字块？

**答：** 在文档中如果想要选择一个矩形文字块，首先按键盘上的 **Alt 键**，同时用鼠标进行拖动，即可选定一个矩形区域。

---

### 6.如何选取大块连续文本？

**答：**

- **选取大块连续文本：** 先将光标定位在文本开头处，按下 **Shift 键** 不放手，再用鼠标单击文本末尾处，即可选定该文本区域。

### 7.如何选取多个不连续的文本区域？


- **选取多个不连续的文本区域：** 按下 **Ctrl 键** 不放手，用鼠标依次选取需要的文字块。

---

### 8.如何使用F8键进行扩展选取？

**答：** 选定某一部分后，按一下键盘功能键区的 **F8**，可以进入扩展选取状态，使用光标键 ↑↓←→ 依次向上、向下、向左、向右进行扩展选取，选取完成后用 **Esc 键** 取消扩展选取。

---

### 9.删除文本的方法有哪些？

**答：**

| 操作键             | 操作方法                  |
| --------------- | --------------------- |
| **Delete 键**    | 按一下，可删除插入点**后面**的一个字符 |
| **Backspace 键** | 按一下，可删除插入点**前面**的一个字符 |

此外，选定要修改的文本块后，直接录入正确的文本，可以实现**直接替换**。
