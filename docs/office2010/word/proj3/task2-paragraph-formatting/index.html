任务二 段落格式的设置

知识点​

1.什么是段落？​

答： 在Word文档中输入内容时，每按一次回车键就会产生一个段落标记，凡是以段落标记结尾的一段内容称为一个段落。

2.段落格式设置包括哪些内容？​

段落格式设置主要包括：对齐方式、缩进、间距、行距、边框和底纹等。合理设置这些格式，可使文档结构清晰，层次分明。

3.段落对齐方式有哪几种？​

答： 段落的对齐方式有五种：

  1. 文本左对齐
  2. 居中
  3. 文本右对齐
  4. 两端对齐
  5. 分散对齐

默认情况下，段落的对齐方式为两端对齐。

4."文本左对齐"与"两端对齐"有何区别？​

答： 从表面上看两种对齐方式没有什么区别，但当行尾输入较长的英文单词而被迫换行时：

  • 左对齐： 文字会按照不满页宽的方式进行排列
  • 两端对齐： 文字的距离将被拉开，从而自动填满页面

5.设置段落对齐方式的快捷键分别是什么？​

答：

对齐方式快捷键
文本左对齐Ctrl+L
居中Ctrl+E
文本右对齐Ctrl+R
两端对齐Ctrl+J
分散对齐Ctrl+Shift+J

6.段落缩进有哪几种？​

答： Word提供了四种缩进段落的方法：

  1. 左缩进： 整个段落左边界距离页面左侧的缩进量。
  2. 右缩进： 整个段落右边界距离页面右侧的缩进量。
  3. 首行缩进： 段落的第1行缩进，其他行不缩进，大多数文档都采用首行缩进的方式，默认缩进量为2个字符。
  4. 悬挂缩进： 段落第1行不缩进，其他行缩进，一般用于杂志、报刊等较特殊的场合，默认缩进量为2个字符。

默认情况下，段落的左、右缩进都是0字符。

7.设置段落缩进的方法有哪些？​

答：

  1. 使用"段落"组中的"增加缩进量"/"减少缩进量"按钮
  2. 打开"段落"对话框，在"缩进"项目组中的"左侧"或"右侧"的"磅值框"中设置缩进量
  3. 打开"页面布局"选项卡 → "段落"组，设置左、右缩进量
  4. 打开"段落"对话框，在"特殊格式"下拉选项框中选择"首行缩进"或"悬挂缩进"
  5. 使用标尺设置段落缩进

8.什么是段间距和行距？​

答：

  • 段间距： 相邻两个段落之间的距离，包括段前间距和段后间距。
  • 行距： 段落中各行之间的距离。常用的行间距有单倍行距、1.5倍行距、2倍行距、最小值、固定值、多倍行距等。

9.设置方法有哪些？​

设置方法：

  1. 选中段落，在"段落"组中单击"行和段落间距"按钮，在下拉列表中选择合适的行距或选择"增加段前间距"/"增加段后间距"
  2. 选中段落，打开"段落"对话框，在对话框中设置段间距和行距
  3. 打开"页面布局"选项卡 → "段落"组，设置段前、段后间距

Word 2010 默认的行间距是单倍行距。

10.项目符号和编号的作用是什么？​

答： 项目符号和编号都是以段落为单位进行标识的，在每个段首处添加的字符或编号。合理使用项目符号和编号不但可以美化文档还可以使文档层次清楚，条理清晰。

11.如何添加项目符号和编号？​

添加项目符号： 选中需要添加的段落 → 单击"开始"选项卡 → "段落"组 → "项目符号"右侧下拉三角 → 选择合适的符号。

添加编号： 选中需要添加的段落 → 单击"开始"选项卡 → "段落"组 → "编号"右侧下拉三角 → 选择合适的编号。编号形式有阿拉伯数字、大写字母、小写字母、罗马数字等。

注意：设置了项目符号后，必须输入内容后再回车，才会自动在下一段落产生项目符号；若没有输入内容就回车，将会取消项目符号，恢复到常规状态。

12.什么是中文版式？​

答： 中文版式是Word 2010提供的一种特殊的排版形式，经常运用于报告、杂志、报刊排版等场景中，它可以合并多个文本字符，可以将两行文本内容排版成一行，还可以调整字符的宽度与字符的缩放。

13.中文版式包括哪些功能？​

包括四种功能：

  1. 纵横混排
  2. 合并字符
  3. 双行合一
  4. 字符缩放

操作路径：选中文本 → "开始"选项卡 → "段落"组 → "中文版式"

14。什么是纵横混排？​

答： 纵横混排是指在横排文字中加入纵排文字，同时保持其他文本为水平方向。

操作方法：选中文本 → "开始"选项卡 → "段落"组 → "中文版式" → "纵横混排"

15.什么是合并字符？有何特点？​

答： 合并字符是指将多个字符合并成一个整体的操作。这些字符可以是多个文字、中文、西文、符号等，最多同时支持6个字符合并。

特点：

  • 合并字符可以用于压缩和排列多个字符
  • 可以将已经合并的字符还原为普通字符
  • 可以设置字体、字号
  • 默认字号为原文本字号的一半（如原文本20磅，合并字符默认10磅）

操作方法：选中文本 → "开始"选项卡 → "段落"组 → "中文版式" → "合并字符"

16.什么是双行合一？​

答： 双行合一是指将选择的文字（可以是中文、西文、符号等，不限字数，但必须是两行）并合成一个整体。双行合一后，文字大小与高度减半。

17.双行合一与合并字符有何区别？​

与合并字符的区别：

对比项合并字符双行合一
字数限制最多6个字符不限字数
行数要求无要求必须是两行
字号变化默认为原字号一半大小与高度减半

操作方法：选中文本 → "开始"选项卡 → "段落"组 → "中文版式" → "双行合一"

18.如何为文字或段落添加边框和底纹？​

答： 有三种方法：

  1. 选择文字或段落 → "段落"组 → "边框"右侧下拉三角 → 任选一种边框样式
  2. 选择文字或段落 → "段落"组 → "底纹"按钮右侧下拉三角 → 任选一种颜色
  3. 选择文字或段落后依次单击"段落"组 → "边框"右侧下拉三角 → "边框和底纹"，打开"边框和底纹"对话框，可自定义边框的样式、底纹的颜色及图案

在"边框和底纹"对话框中：

  • 可依次选择边框类型、样式、颜色、宽度，在"应用于"选框中选择"文字"或"段落"
  • 单击"选项"按钮，可设置边框与正文之间的间距
  • 在"底纹"选项卡中可设置填充色、图案样式和颜色

19.什么是制表位？​

答： 制表位功能是在不使用表格的情况下在垂直方向按列快速对齐文本，制表位用符号表示即为制表符，通过按下Tab键，可以从一个制表位跳到下一个制表位。常见应用包括名单、简单列表、制作页眉页脚等。

20.Word提供了哪几种制表符？​

Word提供了7种制表符形式：

  1. 左对齐式制表符： 文本左对齐
  2. 居中式制表符： 键入时文本居中
  3. 右对齐式制表符： 文本右对齐，并向左扩展
  4. 小数点对齐式制表符： 数字的小数点对齐
  5. 竖线对齐式制表符： 不定位文本，提供一个参考线
  6. 首行缩进： 缩进段落的第一行中的文本
  7. 悬挂缩进： 缩进段落除第一行外的其他行的文本

21.如何插入和设置制表位？​

答：

  • 通过对话框插入： 打开"段落"对话框，单击"制表位"按钮，弹出"制表位"对话框，在"制表位位置"框中输入数字，选择对齐方式和前导符样式，单击"设置"按钮。
  • 手动添加： 单击垂直标尺最上端的制表位切换按钮，先选择一种制表位形式，再依次单击水平标尺上的位置。这种方法简单直观但位置不够精准。

其他操作要点：

  • 按Alt键的同时拖动鼠标，可精确调整制表位
  • 回车产生的新段落，制表位与前一段相同
  • 已有的段落，可同时选定设置相同的制表位

22.什么是制表位的前导符？有何应用？​

答： 前导符就是制表位与前一制表位之间连接的字符。最广泛的应用就是制作目录。

其他应用场景包括：表格顶部或底部一些分列文字、名单列表、菜谱类的文档、教师制作的学生试卷等。
