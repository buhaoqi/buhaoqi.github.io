任务一 字符格式的设置

1.字符格式的设置主要包括哪些内容？​

答： 字符格式的设置包括：

  • 基本设置： 字体、字形、字号、颜色、文字效果、下划线、着重号、删除线等
  • 高级设置： 字符缩放、字符间距、字符位置等

基本设置可通过"字体"组中的按钮或"字体"对话框完成，高级设置需使用"字体"对话框的"高级"选项进行设置。

2.Word 2010中常用的中文字体有哪些？​

答：

  • 常用中文字体： 宋体、仿宋体、黑体、楷体、隶书等。

3.如何设置字体和字号？​

  • 设置字体： 选中文本后，单击"字体"框右侧下拉三角，打开"字体"下拉列表，单击选择一种字体即可。
  • 设置字号： 选中文本后，单击"字号"框右侧下拉三角，打开"字号"下拉列表，单击选择一种字号即可。

4.Word中的字形有哪几种？​

答： Word中的字形包括四种：常规、加粗、倾斜、加粗倾斜，默认的字形格式是"常规"。

5.字形对应的快捷键是什么？​

字形快捷键
加粗Ctrl+B
倾斜Ctrl+I

6.下划线、着重号、删除线分别是什么？​

答：

  • 下划线： 显示在文本下面的一种标记，在文档中起强调作用或引起注意的作用。常用线型有单下划线、双下划线、粗体下划线、虚线、波浪线等，还可以给下划线设置颜色。
  • 着重号： 显示在文本下面的点状标记，作用类似于下划线，在文档中起强调或引起注意的作用，着重号的颜色与字体颜色保持一致。
  • 删除线： 显示在文字中间的一条线，是一种特殊标记，可以用来标记文档中需要删除的文本内容。双删除线是显示在文字中间并排的两条平行线，作用与删除线相同。

7.上标和下标是什么？​

答： 上标和下标是一种小于普通行高的数字、图、符号等，它稍微位于上方或下方位置，在编辑数学公式时常用到它们。

效果快捷键
上标Ctrl+Shift+"+"（等号键）
下标Ctrl+"="

8.如何设置字体颜色？​

答： 单击"字体颜色"右侧下拉三角，可以打开"字体颜色"面板，可以在"主题颜色"或"标准色"中选择合适的颜色。

也可以单击"字体"组的对话框启动器，打开"字体"对话框进行设置。如果需要高级效果设置，可以单击"字体"对话框下面的"文字效果"按钮，打开"设置文本效果格式"对话框进行设置。

9.增大字体、缩小字体按钮的作用是什么？​

答： 在设置文本字号的时候，如果不清楚几号字合适，可以选择文本后使用"增大字体"和"缩小字体"这两个按钮调整到合适的大小，可以更直观地显示字号效果。

10."更改大小写"按钮的作用是什么？​

答： "更改大小写"按钮是专为编辑英文文档而设置的一个非常实用的按钮，

11.可以设置哪些大小写形式？​

可以设置：

  • 句首字母大小
  • 全部小写
  • 全部大写
  • 每个单词首字母大写

12.如何设置拼音文字？​

答： Word软件专门为制作拼音文字提供了拼音指南。选择需要标注拼音的文本内容后单击"拼音指南"按钮，打开拼音指南对话框，在对话框中可以设置拼音与文字的对齐方式、偏移量、字体、字号等。

13.：什么是首字下沉？如何设置？​

答： 首字下沉是把段落中的第一个字用下沉或悬挂的方式突出显示，是一种特殊的排版效果。

设置方法：

  1. 将光标定位在段落中（不需要选择整个段落或第一个字）
  2. 选择"插入"选项卡 → "文本"组 → "首字下沉选项"
  3. 打开"首字下沉"对话框，选择"下沉"样式或"悬挂"样式
  4. 可以设置字体、下沉行数（相当于字号）、距正文的距离

13.：如何设置字符缩放、间距和位置？​

答： 打开"字体"对话框，选择"高级"选项，在对话框中可以设置：

  • 字符缩放： 更改字符的显示比例（注意：字符本身的字号没有发生变化）
  • 字符间距： 调整字符之间的间距（加宽、紧缩等）
  • 字符位置： 调整字符的提升或降低位置

14.：格式刷的作用是什么？如何使用？​

答： 格式刷是Word中用来复制文字格式、段落格式的一种工具，当需要给文档中的内容重复添加相同的格式时，可以用它来进行复制，避免大量重复操作。

使用方法：

  1. 选择已设置格式的文本（源文本）
  2. 依次单击"开始"选项卡 → "剪贴板"组 → "格式刷"按钮
  3. 鼠标指针变成一把小刷子，拖动选择要设置格式的文本（目标文本）

注意：

  • 单击"格式刷"：只能刷一次格式
  • 双击"格式刷"：可以连续刷多次

15.：如何清除格式？​

答： 选定要清除格式的文本或段落，在"字体"组中单击**"清除格式"**按钮，即可清除所选内容的全部格式，只留下纯文本。

16.：什么是浮动工具栏？​

答： Word 2010 提供了一个浮动工具栏。选择文字后，将鼠标指针指向所选文字右上方区域，系统会自动弹出浮动工具栏，其中包含了常用的设置文字格式的命令，方便用户更快捷地进行设置。
