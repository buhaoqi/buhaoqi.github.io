任务三 新建文档

考点​

  • 2.1 掌握文档的创建的基本操作；

知识点​

1.创建新文档的方法有哪些？​

  • ①启动Word2010程序，系统会自动创建一个名为"文档1"的新文档；
  • ②依次单击"文件"选项卡→"新建"→"空白文档"→"创建"按钮；
  • ③使用组合键Ctrl+N；
  • ④根据模板创建：依次单击"文件"选项卡→"新建"→"样本模板"→具体模板→"创建"按钮。

2.Word2010内置了哪些文档模板类型？​

答： 博客文章、书法字帖、贺卡、报表、简历等。

3. 写出移动插入点的快捷键​

  • ↑：向上移动一行、
  • ↓：向下移动一行、
  • ←：向左移动一列、
  • →: 向右移动一列；
  • Home: 快速定位于本行行首、
  • End:快速定位于本行行尾
  • Ctrl+Home: 快速定位于文档开头 - Ctrl+End`: 快速定位于文档末尾。

4. 如何插入日期？​

选择"插入"选项卡：

  • 在"文本"组中单击"日期和时间"按钮
  • 弹出"日期和时间"对话框
  • 选择一种合适的日期格式
  • 单击"确定"即可插入

5."自动更新"选项的作用是什么？​

答：勾选"自动更新"按钮是为了把插入的日期通过F9功能键更新到当天日期。
