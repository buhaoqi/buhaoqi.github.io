### 简答题26：Word表格中的排序有哪些规则？

**答：**
- 排序的对象可以在表格中，也可以不在表格中
- 可以给某列单独排序，也可对整个表格排序
- 以关键字为排序依据，**最多可以指定三个关键字**（主要关键字、次要关键字、第三关键字）
- 排序类型可以是**数字、日期、笔画、拼音**
  - 对文字列排序，Word自动设置排序类型为"拼音"
  - 对数据列排序，Word自动设置排序类型为"数字"
  - 对日期排序，Word自动设置排序类型为"日期"

---

### 简答题27：如何进行数据排序？

**答：** 单击任意单元格使表格处于编辑状态，依次单击"表格工具" → "布局" → "数据"组 → "排序"按钮，弹出"排序"对话框。在对话框中依次设置主要关键字、次要关键字和第三关键字，最后单击"确定"按钮完成排序。

### 简答题28：Word表格中常用的函数有哪些？公式中表示计算范围的域名称有哪三个？

**答：** 常用函数：
- **SUM：** 求和
- **AVERAGE：** 求平均值
- **MAX：** 求最大值
- **COUNT：** 计数

公式中表示计算范围的域名称有三个：

| 域名称 | 含义 |
|--------|------|
| **LEFT** | 当前单元格左侧同一行中所有包含数字的单元格 |
| **RIGHT** | 当前单元格右侧同一行中所有包含数字的单元格 |
| **ABOVE** | 当前单元格上面同一列中所有包含数字的单元格 |

注意：函数名称及域名称都**不区分大小写**。

---

### 简答题29：如何用公式进行数据计算？

**答：** 将光标定位在需要放置结果的单元格中，选择"表格工具" → "布局" → "数据" → "公式"，弹出"公式"对话框。

对话框中显示默认公式 **=SUM(LEFT)**，表示要对左侧数据求和，单击"确定"即可显示结果。如果需要更改计算类型，可在对话框中的"粘贴函数"下拉列表中选择其他函数。

---

### 简答题30：如何在Word表格中进行数据批量计算？

**答：** Word表格中的公式只对某一行或某一列起作用，计算结果不能直接填充，但可以进行批量计算，有两种方法：

**方法一（复制+F9）：**
1. 先用公式计算出第一个数值
2. 选中这个数值并复制
3. 选中其他用来存放计算结果的单元格区域进行粘贴
4. 此时数值被原原本本粘贴到选中区域，**不要取消选定**
5. 按一下**F9功能键**，数值会自动更新
6. 如果对数据进行了修改，选定存放结果的单元格区域，同样用F9更新

**方法二（F4重复操作）：**
1. 先用公式计算出第一个数值
2. 鼠标选中下一个单元格
3. 按一下**F4功能键**（F4的用法是重复上一步操作），结果会自动计算出来
4. 继续选择其他单元格，用F4实现批量计算

| 17 | 拆分表格前光标应放在原表格的**第二行**（若拆成两个二行表格） |
| 18 | 已有文字制作成表格最快捷 → 使用**"文字转换表格"**命令 |
| 19 | 表格样式可根据需要**新建**，也可更改为其他样式 |

| 24 | 表格拆分是从某两行之间把原来的表格分成**上下两个表格** |
| 25 | 合并三个连续单元格后再拆分，行数可选择**1和3** |
| 26 | Word表格中**可以再插入表格** |
| 27 | 合并单元格后**不会删除**原单元格中的数据 |
| 28 | 光标在最后一个单元格按**Tab键**可在表格末尾添加一行 |
| 29 | 新建表格默认位置是**左对齐**（不是居中） |
| 30 | 选定表格一行后按**退格键（Backspace）**→ 删除该行 |

| 32 | 用橡皮工具擦掉两个相邻单元格中间线 = **合并单元格**操作 |

| 36 | 表格居中对齐 → 使用"开始"选项卡中的**段落**命令 |
| 37 | 铅笔工具最多在一个单元格中可绘制**2条**斜线 |
