## 考点

- 1.2 掌握Word的启动方法。

## 知识点

### 1. 启动Word2010的四种方法是什么
- ①执行"开始"→"所有程序"→Microsoft Office→Microsoft Word 2010；
- ②单击任务栏"快速启动工具栏"或桌面上的Word快捷方式图标；
- ③双击任意一个Word文件图标（可同时启动Word并打开该文档）；
- ④直接运行WINWORD.EXE应用程序。
