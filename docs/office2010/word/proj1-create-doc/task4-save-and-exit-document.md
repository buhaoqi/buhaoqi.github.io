## 考点

- 1.2 掌握Word的退出方法。
- 2.1 掌握保存文档的基本操作；

## 知识点

### 1. Word2010默认的保存类型是什么？
答： DOCX格式（Word 文档 *.docx）。

### 2. 保存新文档的方法是什么？
- 方法一：选择"文件"选项卡中的"保存"命令
- 方法二：单击快速访问工具栏中的"保存"按钮
- 方法三：组合键Ctrl+S

### 3. "保存"与"另存为"命令有什么区别？
- 保存：就是将文件保存到指定位置。
- 另存为：就是将文件保存到三新:新位置、新名字、新格式

### 4. 将文档保存为PDF格式的好处是什么？
- 可以保留文档的原始格式和布局
- 可以在不同设备和平台上打开，无需安装特定的软件或字体；
- 无论通过电子邮件、云存储还是其他方式，都能确保接收者可以轻松访问和查看文档。

### 5. 如何给文档设置密码保护？

- 在"另存为"对话框中单击"工具"右侧的下拉按钮，
- 在下拉列表中选择"常规选项"
- 在"常规选项"对话框中设置打开密码和修改密码
- 勾选"建议以只读方式打开文档"
- 最后单击"确定"即可。

### 6. 自动保存的默认时间间隔是多少？
答： 自动保存功能默认的自动保存时间间隔是10分钟。

### 7. 如何修改自动保存的默认时间？
- 单击"文件"选项卡中的"选项"
- 在弹出的"Word选项"对话框中选择"保存"选项
- 修改"保存自动恢复信息时间间隔"的数字即可。

### 8. 关闭文档与退出Word有什么区别？
- 关闭文档:只关闭正在运行的文档，此时Word程序并没有退出；
- 退出文档:则既关闭文档也关闭Word程序。

### 9.关闭文档的方法是什么？
- 可单击"文件"选项卡中的"关闭"
- 使用组合键Ctrl+F4。

### 10. 退出Word2010的常用方法有哪些？
- ①"文件"选项卡→"退出"；
- ②组合键Alt+F4；
- ③单击标题栏右侧的"关闭"按钮；
- ④双击标题栏左侧的控制菜单图标；
- ⑤单击或右击控制菜单图标→"关闭"。
