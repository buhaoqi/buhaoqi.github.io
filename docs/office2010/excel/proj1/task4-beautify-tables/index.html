任务四 利用Excel 2010美化表格

知识点​

  1. 设置单元格格式
  2. 设置条件格式
  3. 使用样式

二、设置单元格格式​

如何打开设置单元格格式​

  • 方法1：开始选项卡
  • 方法2：右键菜单
  • 方法3：Ctrl + 1

如何打开“设置条件格式”​

  • 通过“开始“选项卡打开。

如何打开“使用样式”​

  • 通过“开始“选项卡打开。

设置单元格格式包括什么？​

  • 数字
  • 对齐：水平对齐、垂直对齐、方向
  • 字体：字体、字形、字号、下划线、颜色、特殊效果
  • 边框：线型、颜色、有无
  • 填充：背景色、背景图案、图案样式
  • 保护

三、设置条件格式​

条件格式是什么​

定义：条件格式是预置的单元格格式。在预置条件被满足时自动应用格式。

如何设置条件格式​

1.选中要设置条件格式的单元格 2.单击"开始"选项卡 > 样式功能区中的“条件格式“按钮。

四、使用样式设置​

样式是什么​

  • 定义：样式是系统预设的单元格样式。
  • 优点：使用单元格样式可提高工作效率，减少重复的格式设置

如何使用内部样式​

选中单元格区域，单击“开始”→“样式”功能区“单元格样式”按钮，打开“样式”列表，在列表中选择所需的内置样式（如“20%—强调文字颜色2”）即可应用。

如何创建样式​

  1. 选中单元格区域。
  2. 单击“样式”列表中的“新建单元格样式”命令，打开“样式”对话框。
  3. 在“样式名”文本框中输入新样式名称（如“姓名格式”）。
  4. 单击“格式”按钮，打开“设置单元格格式”对话框，设置所需的字体、字形、字号、填充等格式。
  5. 单击“确定”按钮，返回“样式”对话框。
  6. 单击“确定”按钮完成样式创建。

如何修改样式​

  1. 单击“开始”→“样式”功能区的“单元格样式”按钮，打开“样式”列表。
  2. 在需要修改的样式上右击，在弹出的快捷菜单中选择“修改”命令。
  3. 在弹出的“样式”对话框中单击“格式”命令按钮，打开“单元格格式”对话框。
  4. 设置需要修改的格式。
  5. 单击“确定”按钮完成修改。

如何删除样式​

右击需要删除的样式，在弹出的快捷菜单中，选择“删除”命令即可。常规样式不可以被删除。

如何合并样式​

  1. 打开包含所需样式的源工作簿文件。
  2. 返回当前工作簿，选择“开始”→“样式”功能区的“单元格样式”按钮，打开“样式”列表。
  3. 选择“合并样式”命令，打开“合并样式”对话框。
  4. 在“合并样式来源”列表框中，选定要合并的源工作簿。
  5. 单击“确定”按钮，源工作簿中的样式即合并到目标工作簿中。

五、扩展​

如何自定义格式​

利用 Excel 自定义格式批量添加前缀的方法：

  1. 选定目标单元格，按组合键“Ctrl+1”打开【设置单元格格式】对话框。
  2. 单击【数字】选项卡【分类】中的【自定义】。
  3. 在【类型】文本框中输入格式代码，例如：“重复出现的前缀@”。
  4. 单击【确定】即可。

1."设置单元格格式"对话框包含哪些选项卡？各选项卡的主要功能是什么？​

答：该对话框包含6个选项卡。 ①"数字"选项卡：设置单元格中数据的类型。 ②"对齐"选项卡：可以对选定单元格或单元格区域中的文本和数字进行定位、更改方向和指定文本控制功能。 ③"字体"选项卡：可以设置选定单元格或单元格区域中中文的格式，包括字体、字号、字形、下划线、颜色和特殊效果等选项。 ④"边框"选项卡：可以为选定单元格或单元格区域添加边框，还可以设置边框的线条样式、线条粗细和线条颜色。 ⑤"填充"选项卡：填充指定的单元格或单元格区域。其中，使用"图案颜色"和"图案样式"选项可以为单元格填充双色底纹，使用"填充效果"选项可以为单元格填充渐变。 ⑥"保护"选项卡：用来保护工作表数据和公式的设置。

2.如何设置单元格格式？打开"设置单元格格式"对话框有哪两种方式？​

答：①选中A1单元格，按"Ctrl+1"组合键，打开"设置单元格格式"对话框。 ②单击"开始"选项卡中"字体"组的对话框启动器按钮，打开"设置单元格格式"对话框。 在"字体"选项卡中，设置"字体"为"隶书"，"字形"为"加粗"，"字号"为"22"，单击"确定"按钮。

3.如何设置单元格背景色？​

答：选中第二行中所有数据，打开"设置单元格格式"对话框的"填充"选项卡，设置单元格背景色为"黄色"，单击"确定"按钮。

4."对齐"选项卡中水平对齐有哪几种方式？"跨列居中"有什么作用？​

答：水平对齐包括常规、靠左、居中、靠右、填充、两端对齐、跨列居中、分散对齐等选项。其中"跨列居中"是指将A1单元格中的内容在A1:C1区域中居中显示。

5.如何设置数据在单元格中居中显示？​

答：①选中A2:G9单元格区域，打开"对齐"选项卡，在"文本对齐方式"选项区中，设置水平对齐为"居中"、垂直对齐为"居中"，即数据在单元格中部显示，单击"确定"按钮。 ②选中第1行，右击行号，在弹出的快捷菜单中选择"行高"命令，打开"行高"对话框，在"行高"文本框中输入"40"，行高的单位是"磅"，单击"确定"按钮。行高的范围在0~409磅之间。

6.如何设置列宽？列宽的单位是什么？范围是多少？​

答：选中第1列，单击"单元格"功能区的"格式"按钮右侧下拉列表按钮，在列表中选择"列宽"选项，打开"列宽"对话框，设置列宽为10，单击"确定"按钮。列宽的单位为字符。列宽的范围在0~255个字符之间。

7.如何设置单元格边框？​

答：选中A2:G9单元格区域，打开"边框"选项卡，选择线条样式为"细实线"，颜色为"橙色"后，单击"外边框"和"内部"按钮，给选中的每一个单元格添加边框，单击"确定"按钮。

8.如何设置数值的小数位数？​

答：选定G3:C9单元格区域，打开"单元格格式"对话框的"数字"选项卡，在"分类"列表框中选择"数值"，在"小数位数"框中输入1，即最多只能有一位小数，单击"确定"按钮。

9.什么是条件格式？它有什么作用？​

答：使用Excel中的条件格式功能，可以预置一种单元格格式，并能在指定的单元格区域中根据单元格中的数据值满足某一条件时，自动应用该预置的单元格格式。可以预置的单元格格式包括边框、底纹、字体颜色等。 例如在图2-24所示的"学生成绩单"工作表中，将成绩单中80分以上的成绩用红色显示，60分以下为绿色填充色深绿色文本。

10.设置条件格式的操作步骤是什么？​

答：（1）选中成绩单中B2:D21单元格区域。 （2）单击"开始"→"样式"功能区中的"条件格式"按钮，选择"突出显示单元格规则"中"大于"一项，打开"大于"对话框，在左侧文本框中输入80，在右侧列表框中选择"红色文本"，单击"确定"按钮。 （3）单击"开始"→"样式"功能区中的"条件格式"按钮，选择"突出显示单元格规则"中"小于"一项，打开"小于"对话框，在左侧文本框中输入60，在右侧列表框中选择"绿色填充色深绿色文本"，单击"确定"按钮。 在Excel中，使用条件格式可以快速查找相关数据，还可以使用图标、数据条、色阶等方式清晰显示数据。

11.如何清除或修改已设置的条件格式？​

答：对设置的条件格式可以进行清除或编辑，在图2-25中选择"清除规则"或"管理规则"命令即可完成清除或修改编辑操作。

12.什么是单元格样式？使用样式设置单元格格式有什么好处？​

答：为了提高工作效率，减少重复的格式设置，在Excel中可使用样式进行单元格格式设置。单元格样式包括"数字、对齐、字体、边框、填充、保护"六个方面。自定义样式在创建它的工作簿中有效，并可像内置样式一样被应用。

13.如何使用内置样式？操作步骤是什么？​

答：（1）使用内置样式：选中单元格区域A1:E1，单击"开始"→"样式"功能区"单元格样式"按钮，打开"样式"列表，选择样式"20%－强调文字颜色2"。 （2）创建样式：选中单元格区域A2:A21，单击"样式"列表中的"新建单元格样式"命令，打开"样式"对话框。在"样式名"文本框中输入新样式名称"姓名格式"，单击"格式"按钮，打开"设置单元格格式"对话框，设置字体："楷体"，字形："加粗"，字号："20"，填充："白色，背景1，深色5%"，单击"确定"按钮，返回"样式"对话框，单击"确定"按钮完成设置。

14.如何修改样式？修改样式与内置样式有什么区别？​

答：（3）修改样式。无论是内置样式还是自定义样式，均可对其进行修改。单击"开始"→"样式"功能区的"单元格样式"按钮，打开"样式"列表，或在需要修改的样式上右击，在弹出的快捷菜单中选择"修改"命令，在弹出的"样式"对话框中单击"格式"命令，打开"设置单元格格式"对话框，设置需要修改的格式。

15.如何删除样式？有什么限制？​

答：（4）删除样式。右击需要删除的样式，在弹出的快捷菜单中，选择"删除"命令即可。常规样式不可以被删除。

16.什么是合并样式？有什么用途？操作步骤是什么？​

答：（5）合并样式。如果在当前活动工作簿中想使用另一个工作簿中创建的样式，可通过合并样式来实现。 打开包含所需样式的源工作簿文件，然后返回当前工作簿，选择"开始"→"样式"功能区的"单元格样式"按钮，打开"样式"列表，选择"合并样式"命令，打开"合并样式"对话框。在"合并样式来源"列表框中，选择要合并的源工作簿，单击"确定"按钮。执行上述操作后，源工作簿中的样式合并到目标工作簿中，在"样式"下拉列表中，可以观察到目标工作簿中样式的变化。

17.如何利用Excel自定义格式批量添加前缀？​

答：利用Excel自定义格式，批量添加前缀。方法：选定目标单元格，按组合键"Ctrl+1"打开"设置单元格格式"对话框。单击"数字"选项卡"分类"列表框中的"自定义"，在"类型"文本框中输入："重复出现的前缀@"，单击"确定"按钮即可。
