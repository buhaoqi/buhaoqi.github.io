## 知识点

### 1.Windows10的主要特点是什么

1. 跨平台操作系统；可运行于台式机、平板电脑、手机、Xbox One设备。

2. 在易用性和安全性方面有极大提升
    - ①全新开始菜单：融合传统开始菜单与Win8开始屏幕，支持动态磁贴，可自定义磁贴大小位置。
    - ②强大多任务：支持虚拟桌面创建多个桌面；Snap Assist分屏显示，提高工作效率。
    - ③内置Cortana语音助手，语音完成搜索、提醒、发邮件等操作。
    - ④安全保护：Windows Hello（指纹、面部识别生物登录）；Windows Defender杀毒防护。
    - ⑤便捷应用商店，下载、一键更新应用程序。
    - ⑥优秀游戏体验，支持Xbox应用、DirectX12。
    - ⑦生产力工具：内置Office套件；Windows Ink手写标注绘图。

### 2.Windows10有哪几个版本

一共分为7个版本：

- 1）家庭版Home：普通家庭用户，日常上网娱乐办公，家长控制。
- 2）专业版Pro：商业、专业人士；包含家庭版全部功能，增加域加入、远程桌面、虚拟化。
- 3）企业版Enterprise：大中型企业；硬盘加密BitLocker、高级安全防护、组策略等企业级功能。
- 4）教育版Education：学校教育机构，具备企业版全部功能，增加教学相关工具。
- 5）移动版Mobile：手机、平板移动触屏设备。
- 6）企业移动版Mobile Enterprise：面向企业移动设备，批量授权，管控系统更新。
- 7）物联网核心版IoT Core：面向低成本物联网硬件设备。
