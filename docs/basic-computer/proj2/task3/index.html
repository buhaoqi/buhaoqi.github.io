任务三　计算机的工作原理​

任务描述

  • 一台小小的计算机就可以做那么多工作，它怎么会这么厉害呢！

预备知识

  • 计算机的基本工作原理主要分为存储程序和程序控制。
  • 预先要把控制计算机如何进行操作的指令序列（称为程序）和原始数据通过输入设备输送到计算机内存中。
  • 每一条指令中明确规定了计算机从哪个地址取数，进行什么操作，然后送到什么地址去等步骤。

1. 指令与程序​

  • 计算机指令，简称指令，就是指挥计算机执行某种操作的命令。
  • 程序就是一系列按一定顺序排列的指令的集合，程序的执行过程就是计算机的工作过程。
  • 人们用指令表达自己的意图，并交给控制器执行；控制器靠指令指挥计算机工作。
  • 指令由操作码和地址码组成：
    • 操作码：决定要完成什么样的操作；
    • 地址码：指明参加运算的操作数和操作结果的存放地址。
  • 一台计算机所能执行的全部指令的集合，称为指令系统。
  • 指令系统描述了计算机内全部的控制信息和"逻辑判断"能力。
  • 用户可以利用指令系统的指令来为计算机编写程序。

2. 存储程序及程序控制工作原理​

  • 目前，计算机都遵循冯·诺依曼体系结构，其主要思想是：

    1. 计算机硬件由运算器、控制器、存储器、输入设备、输出设备五大部件构成；
    2. 计算机内部采用二进制来表示指令和数据；
    3. 采用存储程序和程序控制方式，即将程序和数据预先存放在存储器中，计算机在程序的控制下自动运行，无需人工干预。

  • 计算机能在程序的控制下自动运行的理论基础是存储程序工作原理。

  • "存储程序"：人们必须使用输入设备将事先编制好的程序（完成某个任务的若干指令的有序集合）和运行时所需的数据一起存放在存储器中。

  • "程序控制"：计算机运行程序时能自动从内存中逐条取出程序中的指令，由 CPU 分析并执行指令。

  • 存储程序工作原理的具体过程：

    1. 为解决某个问题，用户事先编制好程序；
    2. 通过计算机输入设备将程序输入到计算机，并存储在外存中；
    3. 执行程序时，控制器将程序读入内存中；
    4. 控制器按照程序在内存中的存储地址，依次取出每条指令到控制器中；
    5. 控制器分析指令，并指挥运算器、存储器、输入设备和输出设备协调执行指令所规定的操作。

图2（图2-3-1　计算机工作原理）​

标题：计算机的整个工作过程及基本硬件结构（储存程序工作原理）

五大部件及数据/指令流向：

  1. 输入设备

    • 输入：程序 + 数据
    • 输出：将程序和数据送入（内）存储器
    • 与控制器之间：双向信号（请求信号 / 响应信号）

  2. （内）存储器

    • 接收输入设备送来的程序和数据；
    • 向控制器发送 1. 指令；
    • 接收控制器发来的 2. 地址；
    • 向运算器 3. 读取数据；
    • 接收运算器 4. 存储回来的运算结果；
    • 向输出设备输出数据。

  3. 控制器

    • 从内存储器读取指令（1. 指令）；
    • 向内存储器发送地址（2. 地址）；
    • 向输出设备发送：响应信号、请求信号。

  4. 运算器

    • 从内存储器读取数据（3. 读取）；
    • 将运算结果写回内存储器（4. 存储）；
    • 接收控制器发来的"操作指令"。

  5. 输出设备

    • 从内存储器接收数据；
    • 输出：处理结果；
    • 与控制器之间：双向信号（请求信号 / 响应信号）。

四、简答题​

1. 冯·诺依曼体系结构的主要思想：

  • ①计算机硬件由运算器、控制器、存储器、输入设备、输出设备五大部件构成；
  • ②计算机内部采用二进制来表示指令和数据；
  • ③采用存储程序和程序控制方式，即将程序和数据预先存放在存储器中，计算机在程序的控制下自动运行，无需人工干预。

2. 存储程序工作原理的具体执行过程：

  • ①为解决问题，用户事先编制好程序；
  • ②通过输入设备将程序输入计算机，并存放在外存中；
  • ③执行程序时，控制器将程序从外存读入内存中；
  • ④控制器按照程序在内存中的存储地址，依次取出每条指令到控制器中；
  • ⑤控制器分析指令，并指挥运算器、存储器、输入设备和输出设备协调执行指令所规定的操作。
