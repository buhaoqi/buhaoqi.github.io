任务二 Win10的主要特点和版本

考点​

  • 了解Windows的特点；

知识点​

1.Windows10的主要特点是什么​

  1. 跨平台操作系统；可运行于台式机、平板电脑、手机、Xbox One设备。

  2. 在易用性和安全性方面有极大提升

    • ①全新开始菜单：融合传统开始菜单与Win8开始屏幕，支持动态磁贴，可自定义磁贴大小位置。
    • ②强大多任务：支持虚拟桌面创建多个桌面；Snap Assist分屏显示，提高工作效率。
    • ③内置Cortana语音助手，语音完成搜索、提醒、发邮件等操作。
    • ④安全保护：Windows Hello（指纹、面部识别生物登录）；Windows Defender杀毒防护。
    • ⑤便捷应用商店，下载、一键更新应用程序。
    • ⑥优秀游戏体验，支持Xbox应用、DirectX12。
    • ⑦生产力工具：内置Office套件；Windows Ink手写标注绘图。

2.Windows10有哪几个版本​

一共分为7个版本：

  • 1）家庭版Home：普通家庭用户，日常上网娱乐办公，家长控制。
  • 2）专业版Pro：商业、专业人士；包含家庭版全部功能，增加域加入、远程桌面、虚拟化。
  • 3）企业版Enterprise：大中型企业；硬盘加密BitLocker、高级安全防护、组策略等企业级功能。
  • 4）教育版Education：学校教育机构，具备企业版全部功能，增加教学相关工具。
  • 5）移动版Mobile：手机、平板移动触屏设备。
  • 6）企业移动版Mobile Enterprise：面向企业移动设备，批量授权，管控系统更新。
  • 7）物联网核心版IoT Core：面向低成本物联网硬件设备。

试卷​

一、填空题（3分/空 10空 共30分）​

  1. Windows 10启动完成后显示的整个屏幕区域称为________。[多选题] 答案:桌面
  2. 桌面下方长条区域叫做________，默认包含开始按钮、任务按钮、通知区域。[多选题] 答案:任务栏
  3. ________是Windows中程序、文件、文件夹的图形标识。[多选题] 答案:图标
  4. 打开程序后出现的矩形区域称为________，是Windows的基本操作界面。[多选题] 答案:窗口
  5. 窗口右上角三个按钮分别是最小化、________、关闭。[多选题] 答案:最大化/还原
  6. 菜单命令后带有“…”，表示单击该命令会弹出________。[多选题] 答案:对话框
  7. 剪贴板是一块临时的________区域，用于传递数据。[多选题] 答案:内存
  8. 按下快捷键________可以将选中内容复制到剪贴板。[多选题] 答案:Ctrl+C
  9. 按下快捷键________可以将剪贴板中的内容粘贴到目标位置。[多选题] 答案:Ctrl+V
  10. 对话框中，________按钮用于确认设置并关闭对话框；取消按钮不保存设置直接关闭。[多选题] 答案:确定

二、单项选择题（3.5分/空 10道 共35分）​

  1. 下列不属于Windows桌面组成部分的是（D）[单选题] A.图标 B.任务栏 C.桌面背景 D.主机箱
  2. 窗口中用来移动窗口位置的是（A）[单选题] A.标题栏 B.菜单栏 C.状态栏 D.滚动条
  3. 不能关闭窗口的操作是（C）[单选题] A.单击关闭按钮 B.Alt+F4 C.双击标题栏 D.右击任务栏图标选择关闭窗口
  4. 菜单命令呈灰色显示，表示该命令（B）[单选题] A.可执行 B.当前不可用 C.是级联菜单 D.会弹出对话框
  5. 剪贴板的作用是（B）[单选题] A.长期保存文件 B.临时存放复制、剪切的数据 C.存放系统程序 D.存放桌面图标
  6. 复制的快捷键是（B）[单选题] A.Ctrl+A B.Ctrl+C C.Ctrl+V D.Ctrl+X
  7. 剪切快捷键是（A）[单选题] A.Ctrl+X B.Ctrl+C C.Ctrl+V D.Ctrl+Z
  8. 多个窗口同时打开时，当前正在操作的窗口叫做（B）[单选题] A.后台窗口 B.活动窗口 C.子窗口 D.对话框
  9. 对话框和普通窗口最大区别是对话框（B）[单选题] A.可以改变大小 B.没有最大化、最小化按钮 C.有标题栏 D.可以移动
  10. Alt+Tab快捷键功能是（B）[单选题] A.关闭窗口 B.切换打开的窗口 C.复制文件 D.保存文件

三、多项选择题（5分/道 3道 共15分）​

  1. 窗口的组成部分包含（ABCD）[多选题] A.标题栏 B.菜单栏 C.滚动条 D.状态栏
  2. 下列关于剪贴板说法正确的有（ABCD）[多选题] A.属于内存空间 B.关机后剪贴板内容丢失 C.可以存放文字、图片 D.内容可以多次粘贴
  3. 能够实现窗口切换的操作有（ABC）[多选题] A.Alt+Tab B.单击任务栏窗口按钮 C.Win+Tab D.Ctrl+V

四、判断题（2分/道 10道 共20分）​

  1. 桌面是Windows10启动后的主屏幕界面。（对）
  2. 任务栏只能放在屏幕底部，不能移动位置。（错）
  3. 双击图标一般可以打开对应的程序或者文件。（对）
  4. 最小化窗口就是关闭该程序。（错）
  5. 活动窗口标题栏颜色和其他窗口有区别。（对）
  6. 菜单命令右侧带有▶符号，代表是级联菜单（子菜单）。（对）
  7. 剪贴板中的数据，关机之后仍然保留。（错）
  8. Ctrl+V是粘贴快捷键。（对）
  9. 对话框可以调整窗口大小。（错）
  10. 可以同时打开多个窗口，但同一时刻只有一个活动窗口。（对）
