任务三 Win10开机关机重启睡眠

考点​

无

知识点​

根据教材任务三内容作答

1.开机是什么​

答：启动计算机就是在计算机没有打开电源的情况下，将计算机电源打开，并引导操作系统，直到可以在操作系统下操作计算机。

2.正确启动计算机的步骤是什么​

答：①按一下显示器的电源开关，显示器上的指示灯亮。 ②按一下机箱上的电源开关，机箱上的指示灯亮，并能听到机箱上风扇的响声。 ③2011年以后生产的计算机还支持UEFI启动方式，实现快速开机；不需要设置BIOS，不要按键盘按键。

3.为什么要关机​

答：长时间不使用计算机时关机，不仅可以节省电能，还能延长计算机硬件的寿命。

4.“死机“是什么​

答：开启某程序后，鼠标指针无法移动，不能进行任何操作，这种现象就是死机。

5.遇到"死机"怎么处理？​

答：死机无法正常关机，需要强制关机：按下机箱电源开关不放，数秒后主机电源关闭再松开；若无效，直接关闭插线板电源开关或拔掉电源插头；笔记本可拔出电池。

6.重启是什么？​

答：重启是开机状态下重新引导操作系统；安装更新、修改系统设置、系统故障时需要重启。

7.睡眠是什么​

答：计算机睡眠模式即待机模式。系统将工作数据存储在内存中，关闭除内存外所有设备的供电，内存数据保持不变。如果睡眠过程中供电异常，内存中的数据会丢失、不可恢复。

8.睡眠的优点是什么​

答：可以节约电能；唤醒速度快，可以直接恢复之前的工作状态，省去繁琐开机过程。

9.如何唤醒睡眠？​

答：①点击鼠标唤醒电脑；②按下键盘上的ESC键唤醒电脑；③按下电脑上的电源键唤醒电脑。

10.正确关闭计算机的方法是什么​

答：关闭计算机前，最好先关闭桌面上已经打开的窗口，再执行关机操作，执行关机后等待提示“正在关机”，主机自动断电，之后关闭显示器，再关闭插座电源或者拔掉电源插头。

11.关闭计算机有几种方法​

关机前建议关闭打开的窗口，再执行关机。

  • ①开始菜单：点击开始→电源→关机；
  • ②按主机Power按钮（电源管理默认设置）；
  • ③快捷键Win+X，弹出菜单选择关机或注销→关机；
  • ④Ctrl+Alt+Delete，界面右下角电源按钮选择关机。

12.重启计算机的操作方法是什么​

答：在Windows的“开始”菜单的“电源”子菜单中，选择“重启”命令，计算机会重新引导Windows10操作系统。

13.睡眠的操作方法是什么​

答：在Windows的“开始”菜单的“电源”子菜单中，选择“睡眠”命令，计算机即可进入睡眠状态。

14. 死机与强制关机是什么？​

答：死机：程序开启后鼠标无法移动，无法执行任何操作。 强制关机：死机无法正常关机时，长按主机Power电源键数秒断电；该操作属于非正常关机，容易造成数据丢失。

15.简述注销、重启、睡眠、关机四者区别。​

  • 关机：全部程序终止，内存清空，整机断电；
  • 重启：结束系统，重新引导开机；
  • 睡眠：数据驻留内存，硬件大部分断电，快速恢复工作；
  • 注销：不重启计算机，结束当前用户会话，回到登录界面。
