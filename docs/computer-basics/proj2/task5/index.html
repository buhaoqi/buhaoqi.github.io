任务五 微型计算机的主要性能指标

知识点​

    • 配置：13代 i5-13400 / 16G / 1TB HDD + 512G SSD / win11 / 23英寸
  • 小王：戴尔（Dell）成就3020
    • 配置：13代 i5-13400 / 16G / 512G SSD + 1TB / 23.8英寸

一、微型计算机的主要性能指标​

1. 字长​

  • 在计算机中，计算机每次作为一个整体来处理的一串二进制数码，称为一个计算机字，简称字。
  • 每个字中所包含的二进制位数，称为字长。
  • 简单说：CPU一次最多可同时传送和处理的二进制位数。
  • 字长是计算机性能的一个重要指标。
  • 字长越大，运算精度越高，CPU处理能力越强。
  • 通常一个字由若干个字节组成。
  • 不同计算机系统字长不同，发展过程中有：8位、16位、32位、64位等。
  • 相应微型机称为：8位机、16位机、32位机、64位机。

2. 时钟主频​

  • 时钟主频也叫主频，指CPU的工作频率。
  • 主频越高，单位时间内CPU完成的操作越多，速度越快。
  • 单位为兆赫兹（MHz）或吉赫兹（GHz），用来表示CPU运算、处理数据的速度。
  • CPU主频 = 外频 × 倍频系数。
  • 举例：P4（奔四）1.8GHz（1800MHz）就是CPU主频。

3. 存储容量​

  • 存储容量指存储器可以容纳的二进制信息总量。
  • 分为内存容量和外存容量。
  • 因为内存容量对计算机性能影响大，所以影响性能的存储容量一般指内存RAM的容量。
  • 存储容量基本单位是字节B。
  • 内存容量一般是2的整次方倍，如128MB、256MB等。
  • 内存容量越大越有利于系统运行。
  • 21世纪后微机内存：2GB、4GB，到8GB、16GB、32GB或更高。

4. 运算速度​

  • 运算速度指计算机每秒所能执行的加法指令的条数。
  • 用**每秒百万条指令（MIPS）**来描述。
  • 是用于衡量计算机运算速度快慢的指标。

5. 存取速度​

  • 存取速度指对存储单元中的数据进行一次存或取（读或写）所需的时间。
  • 以**纳秒（ns）**为单位。
  • 数值越小，存取周期越短，存取速度越快。

二、计算机中的数据单位​

1. 位（bit）​

  • 计算机内部最小的数据单位。
  • 一个二进制0和1就代表一个位，简称位。
  • 英文 bit，简写为 b，中文"比特"。

2. 字节（Byte）​

  • Byte：拜特，简称 B，是存储容量的基本单位。
  • 更大单位：千字节（KB）、兆字节（MB）、吉字节（GB）、太字节（TB）。
  • 更高还有：PB、EB、ZB、YB、BB。

换算关系：

  • 1KB = 1024 B
  • 1MB = 1024 KB = 1024 × 1024 B
  • 1GB = 1024 MB
  • 1TB = 1024 GB

（手写笔记：一字节=8位）

3. 字节与位的关系​

  • 数据存储以"字节"为单位。
  • 数据传输大多以"位"为单位。
  • 每 8个位 组成一个字节，是最小一级的信息单位。
  • 8位（bit）= 1个字节（Byte），即 8 bit = 1B。

五、简答题​

  1. 五大性能指标：①字长——CPU一次可同时传送处理的二进制位数，越大精度越高；②时钟主频——CPU工作频率，单位MHz/GHz，主频越高速度越快，主频=外频×倍频系数；③存储容量——存储器容纳二进制信息总量，一般指内存RAM容量，越大越有利；④运算速度——每秒执行加法指令条数，用MIPS衡量；⑤存取速度——一次存取所需时间，单位ns，越小越快。

  2. 位和字节：**位（bit）**是计算机内部最小的数据单位，一个0或1就是一位，简写b，中文比特；**字节（Byte）**是存储容量的基本单位，简写B。关系：8位=1个字节；数据存储以字节为单位，数据传输大多以位为单位。换算：1KB=1024B，1MB=1024KB，1GB=1024MB，1TB=1024GB。
