任务三 计算机的应用

知识点​

一、总述​

  • 计算机以其卓越的性能和强大的生命力，在科学技术、国民经济、社会生活等各方面得到广泛应用，取得明显的社会效益和经济效益。
  • 计算机的应用几乎涉及人类的一切领域，按应用特点可归纳为 8 大类。

二、8 大应用领域​

1. 科学计算（数值计算）​

  • 是计算机最早的应用领域，早期计算机主要用于此，至今仍是重要领域。
  • 用途：将计算机用于科学研究和工程技术中提出的数学问题的计算。
  • 典型领域：高能物理、工程设计、地震预测、气象预报、航天、导弹技术等。

2. 数据处理（信息处理）​

（1）信息管理​
  • 是目前计算机应用最广泛的一个领域。
  • 用途：利用计算机加工、管理与操作任何形式的数据资料。
  • 应用举例：企业管理、物资管理、报表统计、账目计算、信息情报检索。
  • 相关系统：
    • MIS（管理信息系统）
    • MRP Ⅱ（制造资源规划管理软件，用于全面资源管理、生产自动化和集成化）
    • EDI（电子信息交换系统，即"无纸贸易"，改变商业流通货币交易方式，减少现金流通量与交易风险）
（2）云计算​
  • 当前热门计算模式之一，继个人计算机变革、互联网变革之后被看作第三次 IT 浪潮。
  • 是中国战略性新兴产业的重要组成部分。
  • 本质：传统计算机和网络技术发展融合的产物；使计算分布在大量分布式计算机上，而非本地计算机或远程服务器中。
  • 效果：企业可将资源切换到需要的应用上，根据需求访问计算机和存储系统。
（3）物联网​
  • 正促进 5G、窄带物联网、云计算、大数据、人工智能、区块链、边缘计算等新一代信息技术向各领域渗透。
  • 工业互联网：从网络连接的终端设备获取和分析数据，结合远程监视与控制设备监控工业系统；通过**射频识别（RFID）**对生产资料电子化标识，通过传感器实时采集数据并分析，实现生产过程及供应链智能化管理。
  • 智慧农业：收集温度、降雨量、湿度、风速、病虫害、土壤含量等数据，实现耕种智能决策与精确施肥，减少风险、浪费与管理工作量。
  • 生活领域：家居、交通、医疗健康；如语音控制帮助视力/行动不便者、人工耳蜗连接警报系统、跌倒/癫痫健康事故报警。
  • 智能交通与车联网：车内车外通信、智能交通控制、智能停车、电子收费系统、车辆管理控制；物流车队中用无线传感器监控货物位置状况并异常报警。
  • 智慧医疗：药品保健品快速跟踪定位（降低监管成本）；临床数据应用中心开展精准医疗；智能穿戴设备（智能手环、指环等）+ RFID 采集健康信息，建立健康大数据云服务平台。

3. 过程控制（实时控制、自动控制）​

  • 定义：利用计算机对工业生产过程中的某些信号自动检测，数据存入计算机并按需处理。
  • 智能化仪器仪表将工业自动化推向更高水平。
  • 计算机按预先编制的程序指令运行，不同程序指令产生不同处理结果，故可用于工农业生产、国防、文教、科研及日常生活。
  • 应用举例：
    1. 工业生产自动化：巡回检测、自动记录、监视报警、自动启停、自动调控
    2. 交通运输：行车调度
    3. 农业：人工气候箱的温、湿度控制
    4. 家用电器：某些自动功能
    5. 卫星、导弹发射中的计算机实时控制

4. 计算机辅助系统​

  • CAD（计算机辅助设计）：帮助设计人员进行产品和工程设计，提高自动化程度，节省人力物力；应用于电路、机械、土木建筑、服装等设计。
  • CAM（计算机辅助制造）：利用计算机进行生产设备的管理、控制与操作；提高产品质量、降低成本、缩短生产周期、改善制造人员工作条件。
  • CAT（计算机辅助测试）：利用计算机进行复杂而大量的测试工作。
  • CAE（计算机辅助工程）：计算机在现代生产领域（尤其制造业）的应用，主要包括 CAD、CAM 和计算机集成制造系统等。
  • CAI（计算机辅助教学）：利用互联网实现远距离双向交互式、多媒体结合的网上教学；改变"一支粉笔、一块黑板、教师讲授为主、学生被动学习"的传统模式；举例：白板教学、《几何画板》《数学实验室》、网上考试系统、在线课堂、慕课。

5. 数据库应用​

  • 定义：在计算机存储设备中按某种关联方式存放的一批数据。
  • 分类：按存放地点分为集中式（数据集中在一台计算机）和分布式（分散在多台计算机）两类。
  • 借助 **DBMS（数据库管理系统）**对数据实施控制、管理和使用。
  • 举例：科技情报检索系统、银行储户管理系统、飞机票售票系统。
  • OA（办公自动化）与生产自动化都离不开数据库支持。

6. 人工智能（AI）​

  • 研究方向：模式识别、自然语言识别、专家系统、自动程序设计、定理证明、联想与思维的机理、数据智能检索等。
  • 已广泛应用：自动翻译、密码分析、机械手、医学专家系统、智能机器人。
  • 智能机器人：伴随人工智能产生；举例——2017 年北京机器人大会（弹钢琴机器人、陪练羽毛球机器人、机器人搏斗）；Alpha1 曾登上央视春晚，Alpha2 增加语音交互，可控制智能家电（灯、锁）、设置 WiFi 闹钟和安全系统、报天气、拍照拍视频、讲故事、模仿动作，被称为"多功能家庭助理"。
  • 趋势：随 5G 普及，以智能语音为重要入口的万物交互对话将更普遍；未来是人工智能黄金时期，将在脑科学方面获新发展，推动进入人机共存时代。

7. 网络应用​

  • 网络已渗透日常生活方方面面：网上浏览、检索信息、收发电子邮件、观看体育比赛、电子商务、视频会议、远程教育、网上购物、微商活动、网络直播等。
  • 远程教育：建立在互联网上的教学环境，以现代信息技术为手段，以适合远程传输和交互式学习的教学资源为教材构成开放式教育网络；任何人在任何时间、任何地点都可选择所需内容学习，是终身学习系统。
  • 网上购物：互联网检索商品信息→电子订购单发出购物请求→网上支付→厂商邮购或快递送货上门；足不出户满足衣、食、住、行。
  • 微商：基于互联网络、使用移动智能终端社交软件、以社交圈为中心开展的新式商业活动；对传统经商行业造成很大冲击。
  • 网络直播：利用视讯方式网上现场直播，可发布产品展示、会议、背景介绍、方案测评、网上调查、对话访谈、在线培训等；特点——直观、快速、表现形式好、内容丰富、交互性强、地域不受限制、受众可划分；直播后可重播、点播，延长时间和空间；直播卖货是网上购物的又一种形式。

8. 虚拟现实（VR）​

  • 已在游戏、直播、仿真等领域落地，并向制造、医疗、教育、智慧城市等领域渗透。
  • 应用新场景：
    • 医学：外科医生在显示器上重复模拟手术、移动体内器官，寻找最佳手术方案、提高熟练度。
    • 工程设计/装修：将构思变成看得见的虚拟物体和环境，提升到"数字化、即看即所得"境界，提高设计和规划的质量与效率。
    • 应急演练：将事故现场模拟到虚拟场景，人为制造事故情况组织参演人员正确响应；降低成本、提高推演实训时间、打破空间限制；是消防、电力、石油、矿产等危险性行业的关注重点和趋势。
    • 训练环境：如飞行员在训练座舱戴头盔显示器，看到高度逼真的空中环境，产生身临其境的感觉（图1-3-1 VR 虚拟现实技术）。

三、结尾总结​

  • 计算机应用领域非常广泛，随计算机技术不断发展和创新，应用将进一步拓展，为人类生活和工作带来更多便利和创新。
