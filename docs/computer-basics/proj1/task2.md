## 知识点
### 一、计算机的主要特点
1. **运算速度快**
    - 定义：计算机单位时间内执行指令的平均速度，可用每秒完成多少次操作（如加法运算）或每秒执行多少条指令描述。
    - 发展：从最初每秒几千次发展到几十万、几百万、几十亿次；巨型机可达每秒百亿次、上千亿次甚至亿亿次，速度仍在提升。
    - 实例：我国“神威·太湖之光”，峰值性能12.5亿亿次/秒，持续性能9.3亿亿次/秒。
2. **计算精确度高**
    - 精确度取决于**字长**，字长越长精度越高。
    - 微型计算机字长常见：8位、16位、32位、64位。
    - 一般可提供十几位有效数字，满足日常精度需求。
3. **很强的“记忆”能力**
    - 可存储原始数据、中间结果、运算指令；可长期存储文字、图形、图像、声音等信息，随时调用。
    - 是电子计算机与其他计算装置的重要区别。
4. **具有逻辑判断能力**
    - 依靠二进制，能够进行逻辑运算、做出判断选择。
    - 可完成高精度控制、高速操作，实现工作自动化。
5. **程序运行自动化**
    - 由程序控制操作；预先编写并输入程序，计算机就可以自动、连续完成任务。
    - 可存储大量程序和数据；**存储程序**是计算机自动控制处理的基础。
6. **支持人机会话**
    - 又称人机交互：人干预时，人机一问一答，针对性解决问题。
7. **通用性强**
    - 各行各业广泛应用；依靠存储的指令序列处理信息；同一台计算机安装不同软件、外接不同设备，就能完成不同任务。

### 二、计算机分类
#### 表格1：按用途及其使用范围分类
|类别|特点|
| ---- | ---- |
|通用计算机|通用性强，综合处理能力强，能够解决各种类型的问题|
|专用计算机|功能单一，配备了解决特定问题的软、硬件，高速、可靠地解决特定问题|

#### 表格2：按规模大小（综合性能指标）分类
|类别|核心特点|主要应用场景|
| ---- | ---- | ---- |
|巨型机（超级计算机）|速度最快、处理能力最强、造价昂贵；存储容量极大、数据处理速度极快|人口普查、天气预报、人体基因排序、武器研制；供高校、政府、科研单位使用，国产：银河、曙光|
|大型机|性能低于巨型机；大型通用，较快处理速度，完善指令系统，支持多用户同时使用|大银行、大企业、高校科研；科学计算、数据处理、大型商业管理，作为服务器/主机|
|小型机|规模小、结构简单、研制周期短；易操作维护，易推广|工业自动控制、仪器医疗设备数据采集；可作为巨型/大型机辅助机，企业管理、科研计算|
|微型机（PC/个人计算机）|诞生于20世纪70年代初，以微处理器CPU为核心；体积小、重量轻、功耗小、价格低廉|日常办公、家用，现代社会最常用计算机|
|工作站|介于小型机和微型机之间的高档微机；大容量主存、大屏幕显示器，适合计算机辅助工程|图形处理，图形输入、存储、处理、输出（CAD图形设计）|
|服务器|强大处理能力、大容量存储、高速I/O与联网能力；网络环境多用户共享设备|网络服务：文件服务器、邮件服务器、WWW服务器、FTP服务器|

#### 表格3：按处理信号分类
|类别|核心特点|使用现状|
| ---- | ---- | ---- |
|数字计算机|当今行业主流；运算速度快、精度高、通用性强，具备记忆、逻辑判断、自动控制能力|广泛使用，若无特殊说明，计算机一般指数字计算机|
|模拟计算机|采用连续变化的模拟量作为运算对象，依靠电子线路构成运算部件|现在已经很少使用|

#### 表格4：按计算机技术发展方向分类
|类别|核心特点|实例|
| ---- | ---- | ---- |
|冯·诺依曼结构计算机|迄今为止，传统计算机全部采用该体系结构|普通PC、服务器、巨型机等传统计算机|
|非冯·诺依曼结构计算机|突破传统体系架构，提升计算性能，结构和冯·诺依曼机不完全相同|量子计算机、光子计算机、纳米计算机、DNA计算机（中国九章量子计算机）|
